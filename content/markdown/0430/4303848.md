# Golygon

::: {#o1 .subject cue=lead name="Golygon"}

*Image: Octagon Golygon.svg.* The smallest golygon has 8 sides. It is the only solution with fewer than 16 sides. It contains two [concave](wikipedia://en/605156) corners, and fits on an 8×10 grid. It is also a [spirolateral](wikipedia://en/67378893), 8<sub>90°</sub><sup>1,5</sup>.

A **golygon**, or more generally a **serial isogon of 90°**, is any [polygon](wikipedia://en/23621) with all [right angles](wikipedia://en/76956) (a [rectilinear polygon](wikipedia://en/8779182)) whose sides are consecutive [integer](wikipedia://en/14563) lengths. Golygons were invented and named by [Lee Sallows](wikipedia://en/32308380), and popularized by [A.K. Dewdney](https://en.wikipedia.org/wiki/A.K._Dewdney) in a 1990 *[Scientific American](https://en.wikipedia.org/wiki/Scientific_American)* column (Smith).[^o2] Variations on the definition of golygons involve allowing edges to cross, using sequences of edge lengths other than the consecutive integers, and considering turn [angles](wikipedia://en/1196) other than 90°.[^o3]

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

In any golygon, all horizontal edges have the same [parity](wikipedia://en/143135) as each other, as do all vertical edges. Therefore, the number *n* of sides must allow the solution of the system of equations

$$\pm 1 \pm 3 \pm \cdots \pm (n-1) = 0$$

$$\pm 2 \pm 4 \pm \cdots \pm n = 0.$$

It follows from this that *n* must be a [multiple](wikipedia://en/3912709) of 8. For example, in the figure we have $-1 + 3 + 5 - 7 = 0$ and $2 - 4 - 6 + 8 = 0$.

The number of golygons for a given permissible value of *n* may be computed efficiently using [generating functions](wikipedia://en/160993) . The number of golygons for permissible values of *n* is 4, 112, 8432, 909288, etc. Finding the number of solutions that correspond to non-crossing golygons seems to be significantly more difficult.

There is a unique eight-sided golygon (shown in the figure); it can [tile](wikipedia://en/321671) the plane by 180-degree rotation using the [Conway criterion](wikipedia://en/42806211).

## Generalizations {#Generalizations}

A **serial-sided isogon** of order *n* is a closed polygon with a constant angle at each vertex and having consecutive sides of length 1, 2, ..., *n* units. The polygon may be self-crossing.[^o11] Golygons are a [special case](wikipedia://en/31308010) of serial-sided isogons.[^o12]

A [spirolateral](wikipedia://en/67378893) is similar construction, notationally *n*<sub>θ</sub><sup>*i*<sub>1</sub>,*i*<sub>2</sub>,...,*i*<sub>*k*</sub></sup> which sequences lengths 1,2,3,...,*n* with internal angles θ, with option of repeating until it returns to close with the original vertex. The *i*<sub>1</sub>,*i*<sub>2</sub>,...,*i*<sub>*k*</sub> superscripts list edges that follow opposite turn directions.

::: {#o14 .pointer-item cue=pointer name="Golyhedron"}

### Golyhedron {#Golyhedron}

The three-dimensional generalization of a golygon is called a **golyhedron** – a closed [simply-connected](https://en.wikipedia.org/wiki/Simply-connected) solid figure confined to the faces of a cubical lattice and having face areas in the sequence 1, 2, ..., *n*, for some integer *n*, first introduced in a MathOverflow question.[^o15][^o16]

Golyhedrons have been found with values of *n* equal to 32, 15, 12, and 11 (the minimum possible).[^o17]
