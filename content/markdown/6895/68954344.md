# Freightos Baltic Index

::: {#o1 .subject cue=lead name="Freightos Baltic Index"}

The **Freightos Baltic Index** (**FBX**) (also sometimes known as the **Freightos Baltic Daily Index**[^o2] or **Freightos Baltic Global Container Index**[^o13]) is a daily freight container index issued by the [Baltic Exchange](https://en.wikipedia.org/wiki/Baltic_Exchange)[^o3] and [Freightos](https://en.wikipedia.org/wiki/Freightos). The index measures global container [freight rates](https://en.wikipedia.org/wiki/Freight_rate)[^o4] by calculating [spot rates](https://en.wikipedia.org/wiki/Spot_rate) for 40-foot containers on 12 global tradelanes.[^o5] It is reported around the world as a proxy for shipping stocks, and is a general shipping market [bellwether](https://en.wikipedia.org/wiki/Bellwether_%28politics%29). The FBX is currently one of the most widely used [freight rate](https://en.wikipedia.org/wiki/Freight_rate) indices.[^o6]

:::

## History {#History}

The Freightos International Freight Index was first launched as a weekly freight index in early 2017.[^o8] The Freightos Baltic Index has been in wide use since 2018.[^o9] It is currently the only [freight rate](https://en.wikipedia.org/wiki/Freight_rate) index that is issued daily, and is also the only [IOSCO](https://en.wikipedia.org/wiki/International_Organization_of_Securities_Commissions)-compliant freight index that is currently regulated by the EU (in particular, the [European Securities and Markets Authority](https://en.wikipedia.org/wiki/European_Securities_and_Markets_Authority)). The index is calculated from real-time anonymized data.[^o10] As of February 2020, 50 to 70 million [price points](https://en.wikipedia.org/wiki/Price_point) were collected by the FBX each month.[^o19] The FBX was converted into a daily index in February 2021.[^o11]

## Calculation {#Calculation}

12 regional tradelane indices are first calculated. The weighted average of these 12 indices is then used to obtain the FBX Global Container Index (FBX). The formulas given below are in use as of October 2020.[^o13] Note that the FBX calculating formula is updated periodically, with the last update issued in mid-2021.[^o14]

### Tradelane index {#Tradelane_index}

The FBX tradelanes are calculated using the median port to port all-in [freight rate](https://en.wikipedia.org/wiki/Freight_rate). This median price (freight rate) is calculated for standard 40-foot containers that are not refrigerated.

The tradelane index is calculated as follows.[^o13]

$$\frac{\sum_{i=1}^{n} ({median}(L, C_i) \times V_i)}{\sum_{i=1}^{n} (V_i)}$$

Where:

- $L$ = tradelane value (rounded to the nearest integer)
- $C_1, C_2,\cdots, C_n$ = carriers
- $V_1, V_2,\cdots, V_n$ = carrier volumes on the tradelane
- ${median} (L, C_i,\cdots,C_j)$ = the median price for carriers $C_i,\cdots,C_j$ on the tradelane $L$

For reference, a list of the 12 tradelanes used in the index calculations is also provided in the section below.

### FBX Global Container Index {#FBX_Global_Container_Index}

The FBX Global Container Index (FBX) is a weighted average of 12 regional tradelane indices. It is calculated as follows.[^o13]

$$\frac{\sum_{i=1}^{12} (I_i \times V_i)}{\sum_{i=1}^{12} (V_i)}$$

Where:

- $I_1, I_2,\cdots, I_{12}$ = the 12 regional tradelanes indices
- $V_1, V_2,\cdots, V_{12}$ = respectives volumes of the 12 regional tradelanes indices

The FBX prices used are rolling short-term Freight All Kind (FAK) spot tariffs and related surcharges between carriers, freight forwarders, and high-volume shippers.[^o19]
