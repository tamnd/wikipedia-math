# Underdetermined system

::: {#o1 .subject cue=lead name="Underdetermined system"}

In [mathematics](wikipedia://en/18831), a [system of linear equations](wikipedia://en/113087) or a [system of polynomial equations](wikipedia://en/27420015) is considered **underdetermined** if there are fewer equations than unknowns[^o2] (in contrast to an [overdetermined system](wikipedia://en/10160606), where there are more equations than unknowns). The terminology can be explained using the concept of [constraint counting](wikipedia://en/2471934). Each [unknown](wikipedia://en/3728109) can be seen as an available [degree of freedom](wikipedia://en/176622). Each equation introduced into the system can be viewed as a [constraint](wikipedia://en/7418540) that restricts one degree of freedom.

:::

Therefore, the critical case (between overdetermined and underdetermined) occurs when the number of equations and the number of free variables are equal. For every variable giving a degree of freedom, there exists a corresponding constraint removing a degree of freedom. An [indeterminate system](wikipedia://en/5957084) has additional constraints that are not equations, such as restricting the solutions to integers.[^o3] The **underdetermined** case, by contrast, occurs when the system has been underconstrained—that is, when the unknowns outnumber the equations.

::: {#o5 .pointer-item cue=pointer name="Solutions of underdetermined systems"}

## Solutions of underdetermined systems {#Solutions_of_underdetermined_systems}

An underdetermined linear system has either no solution or infinitely many solutions.

For example,

$$\begin{aligned} x+y+z&=1\\ x+y+z&=0 \end{aligned}$$

is an underdetermined system without any solution; any system of equations having no solution is said to be [inconsistent](wikipedia://en/113087#Consistency). On the other hand, the system

$$\begin{aligned} x+y+z&=1\\ x+y+2z&=3 \end{aligned}$$

is consistent and has an infinitude of solutions, such as (*x*, *y*, *z*) = (1, −2, 2), (2, −3, 2), and (3, −4, 2). All of these solutions can be characterized by first subtracting the first equation from the second, to show that all solutions obey *z* = 2; using this in either equation shows that any value of *y* is possible, with *x* = −1 − *y*.

More specifically, according to the [Rouché–Capelli theorem](wikipedia://en/28648000), any system of linear equations (underdetermined or otherwise) is inconsistent if the [rank](wikipedia://en/26561) of the [augmented matrix](wikipedia://en/3676187) is greater than the rank of the [coefficient matrix](wikipedia://en/4636611). If, on the other hand, the ranks of these two matrices are equal, the system must have at least one solution; since in an underdetermined system this rank is necessarily less than the number of unknowns, there are indeed an infinitude of solutions, with the general solution having *k* free parameters where *k* is the difference between the number of variables and the rank.

There are [algorithms](wikipedia://en/775) to decide whether an underdetermined system has solutions, and if it has any, to express all solutions as linear functions of *k* of the variables (same *k* as above). The simplest one is [Gaussian elimination](wikipedia://en/13035). See [System of linear equations](wikipedia://en/113087) for more details.

:::

## Homogeneous case {#Homogeneous_case}

The homogeneous (with all constant terms equal to zero) underdetermined linear system always has non-trivial solutions (in addition to the trivial solution where all the unknowns are zero). There are an infinity of such solutions, which form a [vector space](wikipedia://en/32370), whose dimension is the difference between the number of unknowns and the [rank](wikipedia://en/26561) of the matrix of the system.

## Underdetermined polynomial systems {#Underdetermined_polynomial_systems}

The main property of linear underdetermined systems, of having either no solution or infinitely many, extends to [systems of polynomial equations](https://en.wikipedia.org/wiki/Systems_of_polynomial_equations) in the following way.

A system of polynomial equations which has fewer equations than unknowns is said to be **underdetermined**. It has either infinitely many complex solutions (or, more generally, solutions in an [algebraically closed field](wikipedia://en/1018)) or is inconsistent. It is inconsistent if and only if 0 = 1 is a linear combination (with polynomial coefficients) of the equations (this is [Hilbert's Nullstellensatz](wikipedia://en/149215)). If an underdetermined system of *t* equations in *n* variables (*t* \< *n*) has solutions, then the set of all complex solutions is an [algebraic set](https://en.wikipedia.org/wiki/Algebraic_set) of [dimension](wikipedia://en/253251) at least *n* - *t*. If the underdetermined system is chosen at random the dimension is equal to *n* - *t* with probability one.

## Underdetermined systems with other constraints and in optimization problems {#Underdetermined_systems_with_other_constraints_and_in_optimization_problems}

In general, an underdetermined system of linear equations has an infinite number of solutions, if any. However, in [optimization problems](wikipedia://en/52033) that are subject to linear equality constraints, only one of the solutions is relevant, namely the one giving the highest or lowest value of an [objective function](https://en.wikipedia.org/wiki/Objective_function).

Some problems specify that one or more of the variables are constrained to take on integer values. An integer constraint leads to [integer programming](wikipedia://en/411215) and [Diophantine equations](https://en.wikipedia.org/wiki/Diophantine_equations) problems, which may have only a finite number of solutions.

Another kind of constraint, which appears in [coding theory](wikipedia://en/321869), especially in [error correcting codes](https://en.wikipedia.org/wiki/Error_correcting_codes) and [signal processing](wikipedia://en/29324) (for example [compressed sensing](wikipedia://en/11403316)), consists in an upper bound on the number of variables which may be different from zero. In error correcting codes, this bound corresponds to the maximal number of errors that may be corrected simultaneously.
