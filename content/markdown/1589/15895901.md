# Prescribed Ricci curvature problem

::: {#o1 .subject cue=lead name="Prescribed Ricci curvature problem"}

In [Riemannian geometry](wikipedia://en/195243), a branch of [mathematics](wikipedia://en/18831), the **prescribed Ricci curvature problem** is as follows: given a [smooth manifold](https://en.wikipedia.org/wiki/Smooth_manifold) *M* and a symmetric 2-tensor *h*, construct a [metric](https://en.wikipedia.org/wiki/Riemannian_metric) on *M* whose [Ricci curvature](wikipedia://en/276582) [tensor](wikipedia://en/29965) equals *h*.

:::
