# Bing's recognition theorem

::: {#o1 .subject cue=lead name="Bing's recognition theorem"}

In [topology](wikipedia://en/29954), a branch of [mathematics](wikipedia://en/18831), **Bing's recognition theorem**, named for [R. H. Bing](wikipedia://en/967353), asserts that a necessary and sufficient condition for a [3-manifold](wikipedia://en/1018257) *M* to be [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to the [3-sphere](wikipedia://en/39792) is that every [Jordan curve](https://en.wikipedia.org/wiki/Jordan_curve) in *M* be contained within a topological [ball](wikipedia://en/160556). It is a weak version of the [Poincaré conjecture](wikipedia://en/23798).

:::
