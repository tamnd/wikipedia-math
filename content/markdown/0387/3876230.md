# Hereditary set

::: {#o1 .subject cue=lead name="Hereditary set"}

In [set theory](wikipedia://en/27553), a **hereditary set** (or **pure set**) is a [set](wikipedia://en/26691) whose elements are all hereditary sets. That is, all elements of the set are themselves sets, as are all elements of the elements, and so on.

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

For example, it is [vacuously true](https://en.wikipedia.org/wiki/Vacuously_true) that the empty set is a hereditary set, and thus the set $\{\varnothing\}$ containing only the [empty set](wikipedia://en/9566) $\varnothing$ is a hereditary set. Similarly, a set $\{\varnothing,\{\varnothing\} \}$ that contains two elements: the empty set and the set that contains only the empty set, is a hereditary set.

:::

## In formulations of set theory {#In_formulations_of_set_theory}

In formulations of set theory that are intended to be interpreted in the [von Neumann universe](wikipedia://en/445980) or to express the content of [Zermelo–Fraenkel set theory](wikipedia://en/152214), *all* sets are hereditary, because the only sort of object that is even a candidate to be an element of a set is another set. Thus the notion of hereditary set is interesting only in a context in which there may be [urelements](wikipedia://en/643648).

## Assumptions {#Assumptions}

The inductive definition of hereditary sets presupposes that set membership is [well-founded](wikipedia://en/319712) (i.e., the [axiom of regularity](wikipedia://en/2113)), otherwise the recurrence may not have a unique solution. However, it can be restated non-inductively as follows: a set is hereditary if and only if its [transitive closure](wikipedia://en/2462396#Transitive_closure) contains only sets. In this way the concept of hereditary sets can also be extended to [non-well-founded set theories](https://en.wikipedia.org/wiki/Non-well-founded_set_theories) in which sets can be members of themselves. For example, a set that contains only itself is a hereditary set.
