# Simple (abstract algebra)

::: {#o1 .subject cue=lead name="Simple"}

In [mathematics](wikipedia://en/18831), the term **simple** is used to describe an [algebraic structure](wikipedia://en/106364) which in some sense cannot be divided by a smaller structure of the same type. Put another way, an algebraic structure is simple if the [kernel](wikipedia://en/45240) of every homomorphism is either the whole structure or a single element. Some examples are:

:::

- A [group](wikipedia://en/19447) is called a [simple group](wikipedia://en/47600) if it does not contain a nontrivial proper [normal subgroup](wikipedia://en/21918).
- A [ring](wikipedia://en/48404) is called a [simple ring](wikipedia://en/443387) if it does not contain a nontrivial [two sided ideal](https://en.wikipedia.org/wiki/Two_sided_ideal).
- A [module](wikipedia://en/276410) is called a [simple module](wikipedia://en/29430) if it does not contain a nontrivial [submodule](https://en.wikipedia.org/wiki/Submodule).
- An [algebra](https://en.wikipedia.org/wiki/Algebra_%28ring_theory%29) is called a [simple algebra](wikipedia://en/577486) if it does not contain a nontrivial [two sided ideal](https://en.wikipedia.org/wiki/Two_sided_ideal).

The general pattern is that the structure admits no non-trivial [congruence relations](wikipedia://en/48167#Universal_algebra).

The term is used differently in [semigroup](wikipedia://en/27799) theory. A semigroup is said to be *simple* if it has no nontrivial [ideals](wikipedia://en/27799#Subsemigroups_and_ideals), or equivalently, if [Green's relation](wikipedia://en/1192012) *J* is the universal relation. Not every congruence on a semigroup is associated with an ideal, so a simple semigroup may have nontrivial congruences. A semigroup with no nontrivial congruences is called *congruence simple*.
