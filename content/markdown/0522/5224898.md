# Grundy number

::: {#o1 .subject cue=lead name="Grundy number"}

*Image: Greedy colourings.svg.* An optimal greedy coloring (left) and Grundy coloring (right) of a [crown graph](wikipedia://en/21062705). The numbers indicate the order in which the greedy algorithm colors the vertices.

In [graph theory](wikipedia://en/12401), the **Grundy number** or **Grundy chromatic number** of an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) is the largest number of colors in any [greedy coloring](wikipedia://en/21051195) of the graph. More precisely, it is the number of colors used by a [greedy coloring](wikipedia://en/21051195) strategy that considers the vertices of the graph in sequence and assigns each vertex its [first available](wikipedia://en/2395424) color, using a vertex ordering chosen to use as many colors as possible. Grundy numbers are named after [P. M. Grundy](wikipedia://en/46968203), who studied an analogous concept for [directed graphs](wikipedia://en/19721986) in 1939.[^o2] The undirected version was introduced by (Christen Selkow 1979).[^o4]

:::

## Examples {#Examples}

The [path graph](wikipedia://en/4587190) with four vertices provides the simplest example of a graph whose [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number) differs from its Grundy number. This graph can be colored with two colors, but its Grundy number is three: if the two endpoints of the path are colored first, the greedy coloring algorithm will use three colors for the whole graph.[^o14]

The [complete bipartite graphs](wikipedia://en/525320) are the only connected graphs whose Grundy number is two. All other connected graphs contain either a triangle or a four-vertex path, which cause the Grundy number to be at least three.[^o14]

The [crown graphs](wikipedia://en/21062705) are obtained from complete bipartite graphs $K_{n,n}$ by removing a [perfect matching](wikipedia://en/44031). As a result, for each vertex on one side of the bipartition, there is exactly one vertex on the opposite side of the bipartition that it is not adjacent to. As bipartite graphs, they can be colored with two colors, but their Grundy number is $n$: if a greedy coloring algorithm considers each matched pair of vertices in order, each pair will receive a different color. As this example shows, the Grundy number can be larger than the chromatic number by a factor linear in the number of graph vertices.[^o7]

## Atoms {#Atoms}

(Zaker 2006) defines a sequence of graphs called $t$-*atoms*, with the property that a graph has Grundy number at least $t$ if and only if it contains a $t$-atom. Each $t$-atom is formed from an [independent set](wikipedia://en/524501) and a $(t - 1)$-atom, by adding one edge from each vertex of the $(t - 1)$-atom to a vertex of the independent set, in such a way that each member of the independent set has at least one edge incident to it. A Grundy coloring of a $t$-atom can be obtained by coloring the independent set first with the smallest-numbered color, and then coloring the remaining $(t - 1)$-atom with an additional $t - 1$ colors. For instance, the only 1-atom is a single vertex, and the only 2-atom is a single edge, but there are two possible 3-atoms: a triangle and a four-vertex path.[^o14]

## In sparse graphs {#In_sparse_graphs}

For a graph with $n$ vertices and [degeneracy](wikipedia://en/27545816) $d$, the Grundy number is $O(d \log n)$. In particular, for graphs of bounded degeneracy (such as [planar graphs](wikipedia://en/24314)) or graphs for which the [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number) and degeneracy are bounded within constant factors of each other (such as [chordal graphs](wikipedia://en/744165)) the Grundy number and chromatic number are within a logarithmic factor of each other.[^o11] For [interval graphs](wikipedia://en/363423), the chromatic number and Grundy number are within a factor of 8 of each other.[^o12]

## Computational complexity {#Computational_complexity}

Testing whether the Grundy number of a given graph is at least $k$, for a fixed constant $k$, can be performed in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time), by searching for all possible $k$-atoms that might be subgraphs of the given graph. However, this algorithm is not [fixed-parameter tractable](wikipedia://en/603026), because the exponent in its running time depends on $k$. When $k$ is an input variable rather than a parameter, the problem is [NP-complete](https://en.wikipedia.org/wiki/NP-complete).[^o14] The Grundy number is at most one plus the maximum degree of the graph, and it remains NP-complete to test whether it equals one plus the maximum degree.[^o15] There exists a constant $c > 1$ such that it is [NP-hard](https://en.wikipedia.org/wiki/NP-hard) under randomized reductions to [approximate](wikipedia://en/563105) the Grundy number to within an [approximation ratio](https://en.wikipedia.org/wiki/Approximation_ratio) better than $c$.[^o16]

There is an exact [exponential time](https://en.wikipedia.org/wiki/Exponential_time) algorithm for the Grundy number that runs in time $O(2.443^{n})$.[^o19]

For [trees](wikipedia://en/48560), and [graphs of bounded treewidth](https://en.wikipedia.org/wiki/Partial_k-tree), the Grundy number may be unboundedly large.[^o17] Nevertheless, the Grundy number can be computed in polynomial time for trees, and is fixed-parameter tractable when parameterized by both the [treewidth](wikipedia://en/3987086) and the Grundy number,[^o18] although (assuming the [exponential time hypothesis](wikipedia://en/26434552)) the dependence on treewidth must be greater than singly exponential.[^o19] When parameterized only by the Grundy number, it can be computed in fixed-parameter tractable time for [chordal graphs](wikipedia://en/744165) and [claw-free graphs](wikipedia://en/12415907),[^o19] and also (using general results on [subgraph isomorphism](https://en.wikipedia.org/wiki/Subgraph_isomorphism) in [sparse graphs](https://en.wikipedia.org/wiki/Sparse_graph) to search for atoms) for graphs of [bounded expansion](wikipedia://en/47843724).[^o19][^o20][^o21] However, on general graphs the problem is W\[1\]-hard when parameterized by the Grundy number.[^o22]

## Well-colored graphs {#Well-colored_graphs}

A graph is called [well-colored](wikipedia://en/60128175) if its Grundy number equals its chromatic number. Testing whether a graph is well-colored is [coNP-complete](wikipedia://en/54680).[^o14] The [hereditarily](wikipedia://en/13552465) well-colored graphs (graphs for which every [induced subgraph](wikipedia://en/1655188) is well-colored) are exactly the [cographs](wikipedia://en/1175666), the graphs that do not have a four-vertex path as an induced subgraph.[^o4]
