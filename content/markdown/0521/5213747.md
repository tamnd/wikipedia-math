# Slutsky's theorem

::: {#o1 .subject cue=lead name="Slutsky's theorem"}

In [probability theory](wikipedia://en/23542), **Slutsky's theorem** extends some properties of algebraic operations on [convergent sequences](wikipedia://en/285773) of [real numbers](wikipedia://en/20646438) to sequences of [random variables](wikipedia://en/25685).[^o2]

:::

The theorem was named after [Eugen Slutsky](https://en.wikipedia.org/wiki/Eugen_Slutsky).[^o3] Slutsky's theorem is also attributed to [Harald Cramér](wikipedia://en/223129).[^o4]

::: {#o6 .statement cue=heading name="Statement"}

## Statement {#Statement}

Let $X_n, Y_n$ be sequences of scalar/vector/matrix [random elements](wikipedia://en/5215393). If $X_n$ converges in distribution to a random element $X$ and $Y_n$ converges in probability to a constant $c$, then

- $$X_n + Y_n \ \xrightarrow{d}\ X + c ;$$
- $$X_nY_n \ \xrightarrow{d}\ Xc ;$$
- $X_n/Y_n \ \xrightarrow{d}\ X/c,$ provided that *c* is non-zero,

where $\xrightarrow{d}$ denotes [convergence in distribution](https://en.wikipedia.org/wiki/Convergence_in_distribution).

**Notes:**

1. The requirement that *Y<sub>n</sub>* converges to a constant is important — if it were to converge to a non-degenerate random variable, the theorem would be no longer valid. For example, let $X_n \sim {\rm Uniform}(0,1)$ and $Y_n = -X_n$. The sum $X_n + Y_n = 0$ for all values of *n*. Moreover, $Y_n \, \xrightarrow{d} \, {\rm Uniform}(-1,0)$, but $X_n + Y_n$ does not converge in distribution to $X + Y$, where $X \sim {\rm Uniform}(0,1)$, $Y \sim {\rm Uniform}(-1,0)$, and $X$ and $Y$ are independent.[^o7]
1. The theorem remains valid if we replace all convergences in distribution with convergences in probability.

:::

::: {#o9 .proof cue=heading name="Proof"}

## Proof {#Proof}

This theorem follows from the fact that if *X*<sub>*n*</sub> converges in distribution to *X* and *Y*<sub>*n*</sub> converges in probability to a constant *c*, then the joint vector (*X*<sub>*n*</sub>, *Y*<sub>*n*</sub>) converges in distribution to (*X*, *c*) ([see here](wikipedia://en/50723#propB3)).

Next we apply the [continuous mapping theorem](wikipedia://en/20813286), recognizing the functions *g*(*x*,*y*) = *x* + *y*, *g*(*x*,*y*) = *xy*, and *g*(*x*,*y*) = *x* *y*<sup>−1</sup> are continuous (for the last function to be continuous, *y* has to be invertible).

:::
