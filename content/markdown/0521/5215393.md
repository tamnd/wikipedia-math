# Random element

::: {#o1 .subject cue=lead name="Random element"}

In [probability theory](wikipedia://en/23542), **random element** is a generalization of the concept of [random variable](wikipedia://en/25685) to more complicated spaces than the simple [real line](https://en.wikipedia.org/wiki/Real_line). The concept was introduced by () who commented:[^o3]

> \[the\] development of probability theory and expansion of area of its applications have led to necessity to pass from schemes where (random) [outcomes](wikipedia://en/39778851) of experiments can be described by number or a finite set of numbers, to schemes where outcomes of experiments represent, for example, [vectors](https://en.wikipedia.org/wiki/Random_vector), [functions](wikipedia://en/185427), processes, [fields](wikipedia://en/10603), [series](wikipedia://en/15287), [transformations](https://en.wikipedia.org/wiki/Transformation_%28geometry%29), and also [sets](wikipedia://en/26691) or collections of sets.

:::

The modern-day usage of “random element” frequently assumes the space of values is a [topological vector space](wikipedia://en/45752), often a [Banach](wikipedia://en/3989) or [Hilbert space](wikipedia://en/20598932) with a specified natural [sigma algebra](https://en.wikipedia.org/wiki/Sigma_algebra) of subsets.[^o4]

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $(\Omega, \mathcal{F}, P)$ be a [probability space](wikipedia://en/43325), and $(E, \mathcal{E})$ a [measurable space](wikipedia://en/43333). A **random element** with values in *E* is a function *X*: Ω→*E* which is $(\mathcal{F}, \mathcal{E})$-[measurable](wikipedia://en/44055). That is, a function X such that for any $B\in \mathcal{E}$, the [preimage](https://en.wikipedia.org/wiki/Preimage) of B lies in $\mathcal{F}$.

Sometimes random elements with values in $E$ are called $E$-valued random variables.

Note if $(E, \mathcal{E})=(\mathbb{R}, \mathcal{B}(\mathbb{R}))$, where $\mathbb{R}$ are the real numbers, and $\mathcal{B}(\mathbb{R})$ is its [Borel σ-algebra](https://en.wikipedia.org/wiki/Borel_σ-algebra), then the definition of random element is the classical definition of [random variable](wikipedia://en/25685).

The definition of a random element $X$ with values in a [Banach space](wikipedia://en/3989) $B$ is typically understood to utilize the smallest $\sigma$-algebra on *B* for which every [bounded linear functional](https://en.wikipedia.org/wiki/Bounded_linear_functional) is measurable. An equivalent definition, in this case, to the above, is that a map $X: \Omega \rightarrow B$, from a probability space, is a random element if $f \circ X$ is a random variable for every bounded linear functional *f*, or, equivalently, that $X$ is [weakly measurable](wikipedia://en/14502271).

:::

## Examples of random elements {#Examples_of_random_elements}

### Random variable {#Random_variable}

A *random variable* is the simplest type of random element. It is a map $X\colon \Omega \to \mathbb{R}$ is a [measurable function](wikipedia://en/44055) from the set of possible outcomes $\Omega$ to $\mathbb{R}$.

As a real-valued function, $X$ often describes some numerical quantity of a given event. E.g. the number of heads after a certain number of coin flips; the heights of different people.

When the [image](wikipedia://en/579311) (or range) of $X$ is finite or [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite), the random variable is called a discrete random variable[^o9] and its distribution can be described by a [probability mass function](wikipedia://en/154725) which assigns a probability to each value in the image of $X$. If the image is uncountably infinite then $X$ is called a continuous random variable. In the special case that it is [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous), its distribution can be described by a [probability density function](wikipedia://en/43487), which assigns probabilities to intervals; in particular, each individual point must necessarily have probability zero for an absolutely continuous random variable. Not all continuous random variables are absolutely continuous,[^o10] for example a [mixture distribution](wikipedia://en/708242). Such random variables cannot be described by a probability density or a probability mass function.

### Random vector {#Random_vector}

A **random vector** is a [column](https://en.wikipedia.org/wiki/Column_vector) [vector](wikipedia://en/32370) $\mathbf{X}=(X_1,...,X_n)^T$ (or its [transpose](wikipedia://en/173844), which is a [row vector](https://en.wikipedia.org/wiki/Row_vector)) whose components are [scalar](wikipedia://en/3588331)-valued [random variables](wikipedia://en/25685) on the same [probability space](wikipedia://en/43325) $(\Omega, \mathcal{F}, P)$, where $\Omega$ is the [sample space](wikipedia://en/22958), $\mathcal{F}$ is the [sigma-algebra](https://en.wikipedia.org/wiki/Sigma-algebra) (the collection of all events), and $P$ is the [probability measure](wikipedia://en/45437) (a function returning each event's [probability](wikipedia://en/22934)).

Random vectors are often used as the underlying implementation of various types of aggregate [random variables](wikipedia://en/25685), e.g. a [random matrix](wikipedia://en/1648765), [random tree](wikipedia://en/22192834), [random sequence](wikipedia://en/48256), [random process](https://en.wikipedia.org/wiki/Random_process), etc.

### Random matrix {#Random_matrix}

A **random matrix** is a [matrix](wikipedia://en/20556859)-valued random element. Many important properties of [physical systems](https://en.wikipedia.org/wiki/Physical_system) can be represented mathematically as matrix problems. For example, the [thermal conductivity](https://en.wikipedia.org/wiki/Thermal_conductivity) of a [lattice](wikipedia://en/291472) can be computed from the dynamical matrix of the particle-particle interactions within the lattice.

### Random function {#Random_function}

A random function is a type of random element in which a single outcome is selected from some family of functions, where the family consists some class of all maps from the [domain](wikipedia://en/50263) to the [codomain](wikipedia://en/50264). For example, the class may be restricted to all [continuous functions](wikipedia://en/6122) or to all [step functions](wikipedia://en/170939). The values determined by a random function evaluated at different points from the same realization would not generally be [statistically independent](https://en.wikipedia.org/wiki/Statistically_independent) but, depending on the model, values determined at the same or different points from different realisations might well be treated as independent.

### Random process {#Random_process}

A **Random process** is a collection of [random variables](wikipedia://en/25685), representing the evolution of some system of random values over time. This is the probabilistic counterpart to a deterministic process (or [deterministic system](wikipedia://en/522958)). Instead of describing a process which can only evolve in one way (as in the case, for example, of solutions of an [ordinary differential equation](wikipedia://en/32742753)), in a stochastic or random process there is some indeterminacy: even if the initial condition (or starting point) is known, there are several (often infinitely many) directions in which the process may evolve.

In the simple case of [discrete time](https://en.wikipedia.org/wiki/Discrete-time_stochastic_process), as opposed to [continuous time](wikipedia://en/12466697), a stochastic process involves a [sequence](https://en.wikipedia.org/wiki/Sequence_%28mathematics%29) of random variables and the [time series](wikipedia://en/406624) associated with these random variables (for example, see [Markov chain](wikipedia://en/60876), also known as discrete-time Markov chain).

### Random field {#Random_field}

Given a [probability space](wikipedia://en/43325) $(\Omega, \mathcal{F}, P)$ and a [measurable space](wikipedia://en/43333) X, an *X*-valued random field is a collection of *X*-valued [random variables](wikipedia://en/25685) indexed by elements in a topological space *T*. That is, a random field *F* is a collection

$$\{ F_t : t \in T \}$$

where each $F_t$ is an *X*-valued random variable.

Several kinds of random fields exist, among them the [Markov random field](wikipedia://en/1323985) (MRF), [Gibbs random field](https://en.wikipedia.org/wiki/Gibbs_random_field) (GRF), [conditional random field](wikipedia://en/4118276) (CRF), and [Gaussian random field](wikipedia://en/1803858). An MRF exhibits the Markovian property

$$P(X_i=x_i|X_j=x_j, i\neq j) =P(X_i=x_i|\partial_i), \,$$

where $\partial_i$ is a set of neighbours of the random variable *X*<sub>*i*</sub>. In other words, the probability that a random variable assumes a value depends on the other random variables only through the ones that are its immediate neighbours. The probability of a random variable in an MRF is given by

$$P(X_i=x_i|\partial_i) = \frac{P(\omega)}{\sum_{\omega'}P(\omega')},$$

where Ω' is the same realization of Ω, except for random variable *X*<sub>*i*</sub>. It is difficult to calculate with this equation, without recourse to the relation between MRFs and GRFs proposed by [Julian Besag](wikipedia://en/28095997) in 1974.

### Random measure {#Random_measure}

A **random measure** is a [measure](wikipedia://en/19873)-valued random element.[^o17][^o18] Let X be a complete separable metric space and $\mathfrak{B}(X)$ the [σ-algebra](https://en.wikipedia.org/wiki/Sigma-algebra#Generated_.CF.83-algebra) of its Borel sets. A [Borel measure](wikipedia://en/4322) μ on X is boundedly finite if μ(A) \< ∞ for every bounded Borel set A. Let $M_X$ be the space of all boundedly finite measures on $\mathfrak{B}(X)$. Let (Ω, ℱ, *P*) be a [probability space](wikipedia://en/43325), then a random measure maps from this probability space to the [measurable space](wikipedia://en/43333) ($M_X$, $\mathfrak{B}(M_X)$).[^o19] A measure generally might be decomposed as:

$$\mu=\mu_d + \mu_a = \mu_d + \sum_{n=1}^N \kappa_n \delta_{X_n},$$

Here $\mu_d$ is a diffuse measure without atoms, while $\mu_a$ is a purely atomic measure.

### Random set {#Random_set}

A random set is a set-valued random element.

One specific example is a [random compact set](wikipedia://en/5308916). Let $(M, d)$ be a [complete](https://en.wikipedia.org/wiki/Complete_space) [separable](wikipedia://en/27855) [metric space](wikipedia://en/20018). Let $\mathcal{K}$ denote the set of all compact subsets of $M$. The Hausdorff metric $h$ on $\mathcal{K}$ is defined by

$$h(K_{1}, K_{2}) := \max \left\{ \sup_{a \in K_{1}} \inf_{b \in K_{2}} d(a, b), \sup_{b \in K_{2}} \inf_{a \in K_{1}} d(a, b) \right\}.$$

$(\mathcal{K}, h)$ is also а complete separable metric space. The corresponding open subsets generate a [σ-algebra](https://en.wikipedia.org/wiki/Sigma_algebra) on $\mathcal{K}$, the [Borel sigma algebra](https://en.wikipedia.org/wiki/Borel_sigma_algebra) $\mathcal{B}(\mathcal{K})$ of $\mathcal{K}$.

A **random compact set** is а [measurable function](wikipedia://en/44055) $K$ from а [probability space](wikipedia://en/43325) $(\Omega, \mathcal{F}, \mathbb{P})$ into $(\mathcal{K}, \mathcal{B} (\mathcal{K}) )$.

Put another way, a random compact set is a measurable function $K \colon \Omega \to 2^{M}$ such that $K(\omega)$ is [almost surely](wikipedia://en/351908) compact and

$$\omega \mapsto \inf_{b \in K(\omega)} d(x, b)$$

is a measurable function for every $x \in M$.

### Random geometric objects {#Random_geometric_objects}

These include random points, random figures,[^o22] and random shapes.[^o22]
