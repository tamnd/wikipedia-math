# Computational complexity of mathematical operations

::: {#o1 .subject cue=lead name="Computational complexity of mathematical operations"}

*Image: comparison computational complexity.svg.* Graphs of functions commonly used in the analysis of algorithms, showing the number of operations $N$ versus input size $n$ for each function

The following tables list the [computational complexity](wikipedia://en/6511) of various [algorithms](wikipedia://en/775) for common [mathematical operations](https://en.wikipedia.org/wiki/Mathematical_operation).

:::

Here, complexity refers to the [time complexity](wikipedia://en/405944) of performing computations on a [multitape Turing machine](wikipedia://en/4631387).[^o2] See [big O notation](wikipedia://en/44578) for an explanation of the notation used.

Note: Due to the variety of multiplication algorithms, $M(n)$ below stands in for the complexity of the chosen multiplication algorithm.

## Algebraic functions {#Algebraic_functions}

Here we consider operations over polynomials and $n$ denotes their degree; for the coefficients we use a **unit-cost** model, ignoring the number of bits in a number. In practice this means that we assume them to be machine integers. For this section $M(n)$ indicates the time needed for multiplying two polynomials of degree at most $n$.[^o28]p. 242

::: {#o24 .table cue=table}

| Operation | Input | Output | Algorithm | Complexity |
|---|---|---|---|---|
| [Polynomial](wikipedia://en/23000) evaluation | One polynomial of degree $n$ with integer coefficients | One number | Direct evaluation | $\Theta(n)$ |
|  |  |  | [Horner's method](wikipedia://en/14263) | $\Theta(n)$ |
| Polynomial multipoint evaluation | One polynomial of degree less than $n$ with integer coefficients and $n$ numbers as evaluation points | $n$ numbers | Direct evaluation | $\Theta(n^2)$ |
|  |  |  | [Fast multipoint evaluation](https://en.wikipedia.org/wiki/Fast_multipoint_evaluation)[^o28]p. 295 | $O(M(n) \log n)$ |
| Polynomial gcd (over $\mathbb{Z}[x]$ or $F[x]$) | Two polynomials of degree $n$ with integer coefficients | One polynomial of degree at most $n$ | [Euclidean algorithm](wikipedia://en/10377) | $O\mathord\left(n^{2}\right)$ |
|  |  |  | Fast Euclidean algorithm[^o28]p. 318 (Lehmer[^o28]p. 324) | $O(M(n) \log n)$ |

:::

## Special functions {#Special_functions}

Many of the methods in this section are given in Borwein & Borwein.[^o30]

### Elementary functions {#Elementary_functions}

The [elementary functions](wikipedia://en/10412) are constructed by composing arithmetic operations, the [exponential function](wikipedia://en/9678) ($\exp$), the [natural logarithm](wikipedia://en/21476) ($\log$), [trigonometric functions](https://en.wikipedia.org/wiki/Trigonometric_function) ($\sin, \cos$), and their inverses. The complexity of an elementary function is equivalent to that of its inverse, since all elementary functions are [analytic](wikipedia://en/61478) and hence invertible by means of Newton's method. In particular, if either $\exp$ or $\log$ in the complex domain can be computed with some complexity, then that complexity is attainable for all other elementary functions.

Below, the size $n$ refers to the number of digits of precision at which the function is to be evaluated.

::: {#o32 .table cue=table}

| Algorithm | Applicability | Complexity |
|---|---|---|
| [Taylor series](wikipedia://en/30448); repeated argument reduction (e.g. $\exp(2x) = [\exp(x)]^2$) and direct summation | $\exp, \log, \sin, \cos, \arctan$ | $O\mathord\left(M(n) n^{1/2}\right)$ |
| Taylor series; [FFT](wikipedia://en/11512)-based acceleration | $\exp, \log, \sin, \cos, \arctan$ | $O\mathord\left(M(n) n^{1/3} (\log n)^2\right)$ |
| Taylor series; [binary splitting](wikipedia://en/4226251) + [bit-burst algorithm](https://en.wikipedia.org/wiki/Bit-burst_algorithm)[^o36] | $\exp, \log, \sin, \cos, \arctan$ | $O\mathord\left(M(n) (\log n)^2\right)$ |
| [Arithmetic–geometric mean](wikipedia://en/3090) iteration[^o38] | $\exp, \log, \sin, \cos, \arctan$ | $O(M(n) \log n)$ |

:::

It is not known whether $O(M(n) \log n)$ is the optimal complexity for elementary functions. The best known lower bound is the trivial bound [$\Omega$](wikipedia://en/44578#Family_of_Bachmann–Landau_notations)$(M(n))$.

## Transforms {#Transforms}

Algorithms for computing [transforms](wikipedia://en/1904373) of functions (particularly [integral transforms](wikipedia://en/430912)) are widely used in all areas of mathematics, particularly [analysis](wikipedia://en/48396) and [signal processing](wikipedia://en/29324).

::: {#o114 .table cue=table}

| Operation | Input | Output | Algorithm | Complexity |
|---|---|---|---|---|
| [Discrete Fourier transform](wikipedia://en/8811) | Finite data sequence of size $n$ | Set of complex numbers | Schoolbook | $O(n^2)$ |
|  |  |  | [Fast Fourier transform](wikipedia://en/11512) | $O(n \log n)$ |

:::
