# Balloon hashing

::: {#o1 .subject cue=lead name="Balloon hashing"}

**Balloon hashing** is a [key derivation function](wikipedia://en/449781) presenting proven memory-hard password-hashing and modern design. It was created by [Dan Boneh](https://en.wikipedia.org/wiki/Dan_Boneh), Henry Corrigan-Gibbs (both at [Stanford University](https://en.wikipedia.org/wiki/Stanford_University)) and Stuart Schechter ([Microsoft Research](https://en.wikipedia.org/wiki/Microsoft_Research)) in 2016.[^o2][^o3]

:::

The authors claim that Balloon:

- has *proven* [memory-hardness](https://en.wikipedia.org/wiki/Memory-hard_function) properties,
- is built from standard primitives: it can use any standard non-space-hard [cryptographic hash function](wikipedia://en/439526) as a sub-algorithm (e.g., [SHA-3](wikipedia://en/20394543), [SHA-512](https://en.wikipedia.org/wiki/SHA-512)),
- is resistant to [side-channel attacks](wikipedia://en/667678): the memory access pattern is independent of the data to be hashed,
- is easy to implement and matches the performance of similar algorithms.

Balloon is compared by its authors with [Argon2](wikipedia://en/48963187), a similarly performing algorithm.[^o2]

::: {#o5 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

There are three steps in the algorithm:[^o2]

1. Expansion, where an initial buffer is filled with a [pseudorandom](https://en.wikipedia.org/wiki/Pseudorandom) byte sequence derived from the password and salt repeatedly hashed.
1. Mixing, where the bytes in the buffer are mixed *time\_cost* number of times.
1. Output, where a portion of the buffer is taken as the hashing result.

:::
