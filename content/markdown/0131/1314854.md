# Diagonal subgroup

::: {#o1 .subject cue=lead name="Diagonal subgroup"}

In the [mathematical](wikipedia://en/18831) discipline of [group theory](wikipedia://en/41890), for a given [group](wikipedia://en/19447) $G,$ the **diagonal subgroup** of the *n*-fold [direct product](wikipedia://en/3706015) $G^{\,\,n}$ is the [subgroup](wikipedia://en/28011)

:::

$$\{(g, \dots, g) \in G^n : g \in G\}.$$

This subgroup is [isomorphic](wikipedia://en/12397) to $G.$

::: {#o3 .statement kind=statement/fact cue=heading name="Properties and applications"}

## Properties and applications {#Properties_and_applications}

- If $G$ [acts](wikipedia://en/12781) on a [set](wikipedia://en/26691) $X,$ the *n*-fold diagonal subgroup has a natural action on the [Cartesian product](wikipedia://en/24104095) $X^{\,n}$ induced by the action of $G$ on $X,$ defined by

$$(x_1, \dots, x_n) \cdot (g, \dots, g) = (x_1 \!\cdot g, \dots, x_n \!\cdot g).$$

- If $G$ acts $n$-[transitively](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29#Remarkable_properties_of_actions) on $X,$ then the $n$-fold diagonal subgroup acts transitively on $X^{\,n}.$ More generally, for an [integer](wikipedia://en/14563) $k,$ if $G$ acts $kn$-transitively on $X,$ $G$ acts $k$-transitively on $X^{\,n}.$
- [Burnside's lemma](wikipedia://en/251900) can be [proved](wikipedia://en/82285) using the action of the twofold diagonal subgroup.

:::
