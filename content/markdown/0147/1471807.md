# Radó's theorem (harmonic functions)

::: {#o1 .subject cue=lead name="Radó's theorem"}

In [mathematics](wikipedia://en/18831), **Radó's theorem** is a result about [harmonic functions](wikipedia://en/55762), named after [Tibor Radó](wikipedia://en/1490393). Informally, it says that any "nice looking" shape without holes can be smoothly deformed into a disk.

:::

Suppose Ω is an [open](wikipedia://en/39358), [connected](wikipedia://en/6233) and [convex](wikipedia://en/6292) [subset](wikipedia://en/27631) of the [Euclidean space](wikipedia://en/9697) **R**<sup>2</sup> with [smooth](https://en.wikipedia.org/wiki/Smooth_function) [boundary](wikipedia://en/72824) ∂Ω and suppose that **D** is the [unit disk](wikipedia://en/252738). Then, given any [homeomorphism](wikipedia://en/13660) μ : ∂**D** → ∂Ω, there exists a unique harmonic function *u* : **D** → Ω such that *u* = μ on ∂**D** and *u* is a [diffeomorphism](wikipedia://en/8564).
