# JMulTi

::: {#o1 .subject cue=lead name="JMulTi"}

**JMulTi** is an [open-source](https://en.wikipedia.org/wiki/Open-source_software) interactive [software](https://en.wikipedia.org/wiki/Software) for [econometric analysis](https://en.wikipedia.org/wiki/Econometric_analysis), specialised in univariate and multivariate [time series](wikipedia://en/406624) analysis. It has a [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29) [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface).

:::

The motivation for its designed was to provide the means by which some time-series econometric procedures that were difficult or unavailable in other packages could be undertaken. Such procedures include Impulse Response Analysis with bootstrapped confidence intervals for [VAR](wikipedia://en/2399016)/[VEC](https://en.wikipedia.org/wiki/VECM) modelling.[^o3]
