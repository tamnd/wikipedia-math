# Prismatic uniform polyhedron

::: {#o1 .subject cue=lead name="Prismatic uniform polyhedron"}

*Image: Pentagrammic antiprism.png.* A [pentagrammic antiprism](wikipedia://en/4157315) is made of two regular [pentagrams](wikipedia://en/197544) and 10 equilateral [triangles](wikipedia://en/30654).

In [geometry](wikipedia://en/18973446), a **prismatic uniform polyhedron** is a [uniform polyhedron](wikipedia://en/2537223) with [dihedral symmetry](wikipedia://en/2922089). They exist in two infinite families, the uniform [prisms](wikipedia://en/283007) and the uniform [antiprisms](wikipedia://en/1851). All have their vertices in parallel planes and are therefore [prismatoids](wikipedia://en/23917).

:::

## Vertex configuration and symmetry groups {#Vertex_configuration_and_symmetry_groups}

Because they are [isogonal](wikipedia://en/581560) (vertex-transitive), their [vertex arrangement](wikipedia://en/14308644) uniquely corresponds to a [symmetry group](wikipedia://en/2694525).

The difference between the prismatic and antiprismatic symmetry groups is that **D<sub>*p*h</sub>** has the vertices lined up in both planes, which gives it a reflection plane perpendicular to its *p*-fold axis (parallel to the {p/q} polygon); while **D<sub>*p*d</sub>** has the vertices twisted relative to the other plane, which gives it a rotatory reflection. Each has *p* reflection planes which contain the *p*-fold axis.

The **D<sub>*p*h</sub>** symmetry group contains [inversion](https://en.wikipedia.org/wiki/Inversion_in_a_point) if and only if *p* is even, while **D<sub>*p*d</sub>** contains inversion symmetry if and only if *p* is odd.

::: {#o4 .definition kind=definition/construction cue=heading name="Enumeration"}

## Enumeration {#Enumeration}

There are:

- [prisms](wikipedia://en/283007), for each rational number *p/q* > 2, with symmetry group **D<sub>*p*h</sub>**;
- [antiprisms](wikipedia://en/1851), for each rational number *p/q* > 3/2, with symmetry group **D<sub>*p*d</sub>** if *q* is odd, **D<sub>*p*h</sub>** if *q* is even.

If *p/q* is an integer, i.e. if *q* = 1, the prism or antiprism is convex. (The fraction is always assumed to be stated in lowest terms.)

An antiprism with *p/q* \< 2 is *crossed* or *retrograde*; its [vertex figure](wikipedia://en/1005719) resembles a bowtie. If *p/q* \< 3/2 no uniform antiprism can exist, as its vertex figure would have to violate the [triangle inequality](wikipedia://en/53941). If *p/q* = 3/2 the uniform antiprism is degenerate (has zero height).

:::
