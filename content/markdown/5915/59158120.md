# Tropical analysis

::: {#o1 .subject cue=lead name="Tropical analysis"}

In the mathematical discipline of [idempotent analysis](wikipedia://en/59158118), **tropical analysis** is the study of the [tropical semiring](wikipedia://en/3892336).

:::

::: {#o3 .application cue=heading name="Applications"}

## Applications {#Applications}

The max tropical semiring can be used appropriately to determine marking times within a given [Petri net](wikipedia://en/225192) and a vector filled with marking state at the beginning: $-\infty$ (unit for max, tropical addition) means "never before", while 0 (unit for addition, tropical multiplication) is "no additional time".

[Tropical cryptography](wikipedia://en/57414658) is cryptography based on the tropical semiring.

[Tropical geometry](wikipedia://en/867041) is an analog to [algebraic geometry](wikipedia://en/1997), using the tropical semiring.

:::
