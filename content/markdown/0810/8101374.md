# Ultraconnected space

::: {#o1 .subject cue=lead name="Ultraconnected space"}

In [mathematics](wikipedia://en/18831), a [topological space](wikipedia://en/30450) is said to be **ultraconnected** if no two nonempty [closed sets](wikipedia://en/47279) are [disjoint](https://en.wikipedia.org/wiki/Disjoint_%28sets%29).[^o2] Equivalently, a space is ultraconnected if and only if the closures of two distinct points always have non trivial intersection. Hence, no [T<sub>1</sub> space](wikipedia://en/148721) with more than one point is ultraconnected.[^o3]

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Every ultraconnected space $X$ is [path-connected](https://en.wikipedia.org/wiki/Path-connected) (but not necessarily [arc connected](https://en.wikipedia.org/wiki/Arc_connected)). If $a$ and $b$ are two points of $X$ and $p$ is a point in the intersection $\operatorname{cl}\{a\}\cap\operatorname{cl}\{b\}$, the function $f:[0,1]\to X$ defined by $f(t)=a$ if $0 \le t < 1/2$, $f(1/2)=p$ and $f(t)=b$ if $1/2 < t \le 1$, is a continuous path between $a$ and $b$.[^o3]

Every ultraconnected space is [normal](wikipedia://en/48629), [limit point compact](wikipedia://en/9861462), and [pseudocompact](wikipedia://en/5075659).[^o2]

:::

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

The following are examples of ultraconnected topological spaces.

- A set with the [indiscrete topology](https://en.wikipedia.org/wiki/Indiscrete_topology).
- The [Sierpiński space](wikipedia://en/387651).
- A set with the [excluded point topology](wikipedia://en/5539197).
- The [right order topology](https://en.wikipedia.org/wiki/Right_order_topology) on the real line.[^o8]
