# Treyfer

::: {#o1 .subject cue=lead name="Treyfer"}

In [cryptography](wikipedia://en/18934432), **Treyfer** is a [block cipher](wikipedia://en/4594)/[MAC](wikipedia://en/567523) designed in 1997 by Gideon Yuval. Aimed at [smart card](https://en.wikipedia.org/wiki/Smart_card) applications, the algorithm is extremely simple and compact; it can be implemented in just 29 bytes of [8051](https://en.wikipedia.org/wiki/8051) [machine code](https://en.wikipedia.org/wiki/Machine_code).[^o3]

:::

Treyfer has a rather small [key size](wikipedia://en/5749) and [block size](wikipedia://en/294065) of 64 bits each. All operations are byte-oriented, and there is a single 8×8-bit [S-box](https://en.wikipedia.org/wiki/Substitution_box). The S-box is left undefined; the implementation can simply use whatever data is available in memory. In each round, each byte has added to it the S-box value of the sum of a [key](wikipedia://en/53039) byte and the previous data byte, then it is rotated left one bit. The design attempts to compensate for the simplicity of this round transformation by using 32 rounds.

Due to the simplicity of its [key schedule](wikipedia://en/609603), using the same eight key bytes in each round, Treyfer was one of the first ciphers shown to be susceptible to a [slide attack](wikipedia://en/1821327). This cryptanalysis, which is independent of the number of rounds and the choice of S-box, requires 2<sup>32</sup> [known plaintexts](wikipedia://en/517019) and 2<sup>44</sup> computation time.

After Alex Biryukov broke it, it gave way to the Parve cipher (same author)

## Implementation {#Implementation}

A simple implementation of Treyfer can be done as follows[^o6]

```C
#include <stdint.h>

#define NUMROUNDS 32
extern uint8_t const sbox[256];

void treyfer_encrypt(uint8_t * text[8], uint8_t const key[8]) {
    unsigned i;
    uint8_t t = *text[0];

    for (i = 0; i < 8 * NUMROUNDS; i++) {
        t += key[i % 8];
        t = sbox[t] + *text[(i + 1) % 8];
        t = (t << 1) | (t >> 7);        /* Rotate left 1 bit */
        *text[(i + 1) % 8] = t;
    }
}

void encrypt(uint8_t * text[8], uint8_t const key[8]) {
    unsigned int i = 0;
    unsigned int j = 0;
    uint8_t t = 0;

    t = text[0];
    for (j = 0; j < NUMROUNDS; j++) {
        for (i = 0; i < 8; i++) {
            t = t + key[i];
            t = sbox[t] + *text[(i + 1) % 8];
            t = (t << 1) | (t >> 7);
            *text[(i + 1) % 8] = t;
        }
    }
}

void decrypt(uint8_t *text[8], uint8_t const key[8]) {
    int i = 0;
    int j = 0;
    uint8_t top = 0;
    uint8_t bottom = 0;

    for (j = 0; j < NUMROUNDS; j++) {
        for (i = 7; i >= 0; i--) {
            top = *text[i] + key[i];
            top = sbox[top];
            bottom = *text[(i + 1) % 8];
            bottom = (bottom >> 1) | (bottom << 7);
            *text[(i + 1) % 8] = bottom - top;
        }
    }
}
```
