# Enumerative definition

::: {#o1 .subject cue=lead name="Enumerative definition"}

An **enumerative definition**[^o2] of a concept or term is a special type of [extensional definition](https://en.wikipedia.org/wiki/Extensional_definition) that gives an explicit and exhaustive listing of all the [objects](https://en.wikipedia.org/wiki/Object_%28philosophy%29) that fall under the concept or term in question. Enumerative definitions are only possible for finite sets and only practical for relatively small sets.

:::

::: {#o4 .example cue=heading name="Example"}

## Example {#Example}

An example of an enumerative definition for the set **[extant](https://en.wikipedia.org/wiki/Extant_species) [monotreme](https://en.wikipedia.org/wiki/Monotreme) species** (for which the [intensional definition](https://en.wikipedia.org/wiki/Intensional_definition) is "species of currently-living mammals that [lay eggs](https://en.wikipedia.org/wiki/Oviparity)") would be:

[platypuses](https://en.wikipedia.org/wiki/Platypus)

echidnae:

[short-beaked echidna](https://en.wikipedia.org/wiki/Short-beaked_echidna)

long-beaked echidnae:

[Sir David's long-beaked echidna](https://en.wikipedia.org/wiki/Sir_David's_long-beaked_echidna)

[eastern long-beaked echidna](https://en.wikipedia.org/wiki/Eastern_long-beaked_echidna)

[western long-beaked echidna](https://en.wikipedia.org/wiki/Western_long-beaked_echidna)

:::
