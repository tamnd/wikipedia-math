# Hann function

::: {#o1 .subject cue=lead name="Hann function"}

*Image: Window function and its Fourier transform – Hann (n = 0...N).svg.* Hann function (left), and its frequency response (right)

The **Hann function** is named after the Austrian meteorologist [Julius von Hann](https://en.wikipedia.org/wiki/Julius_von_Hann). It is a [window function](wikipedia://en/244097) used to perform **Hann smoothing** or **hanning**.[^o9][^o13] The function, with length $L$ and amplitude $1/L,$ is given by:

:::

$w_0(x) \triangleq \left\{ \begin{array}{ccl} \tfrac{1}{L}\left(\tfrac{1}{2} + \tfrac{1}{2} \cos \left(\frac{2\pi x}{L} \right) \right) = \tfrac{1}{L}\cos^2 \left(\frac{\pi x}{L}\right),\quad &\left|x\right| \leq L/2\\ 0,\quad &\left|x\right| > L/2 \end{array}\right\}.$ Nuttall 1981, p 84 (3)

For [digital signal processing](https://en.wikipedia.org/wiki/Digital_signal_processing), the function is sampled symmetrically (with spacing $L/N$ and amplitude $1$)**:**

$$\left . \begin{aligned} w[n] = L\cdot w_0\left(\tfrac{L}{N} (n-N/2)\right) &= \tfrac{1}{2} \left[1 - \cos \left ( \tfrac{2 \pi n}{N} \right) \right]\\ &= \sin^2 \left ( \tfrac{\pi n}{N} \right) \end{aligned} \right \},\quad 0 \leq n \leq N,$$

which is a sequence of $N+1$ samples, and $N$ can be even or odd. It is also known as the **raised cosine window**, **Hann filter**, **von Hann window**, **Hanning window**, etc.[^o13][^o14][^o11]

## Fourier transform {#Fourier_transform}

*Image: DFT-even Hann window & spectral leakage.png.* Top: 16 sample [DFT-even](wikipedia://en/545288#DFT-symmetry) Hann window. Bottom: Its discrete-time Fourier transform (DTFT) and the 3 non-zero values of its discrete Fourier transform (DFT).

The [Fourier transform](wikipedia://en/52247) of $w_0(x)$ is given by:

$W_0(f) = \frac{1}{2}\frac{\operatorname{sinc}(Lf)}{(1 - L^2f^2)} = \frac{\sin(\pi Lf)}{2\pi L f(1 - L^2f^2)}$ Nuttall 1981, p 86 (17)

::: {#o3 .proof cue=math-proof name="Derivation"}

**Derivation.**

Using [Euler's formula](wikipedia://en/9613) to expand the cosine term in $w_0(x),$ we can write:

$w_0(x)= \tfrac{1}{L} \left(\tfrac{1}{2}\operatorname{rect}(x/L) +\tfrac{1}{4} e^{i 2\pi x/L} \operatorname{rect}(x/L) + \tfrac{1}{4}e^{-i 2\pi x/L} \operatorname{rect}(x/L)\right),$ which is a linear combination of modulated [rectangular windows](wikipedia://en/1261615):

$$\tfrac{1}{L} \operatorname{rect}(x/L)\quad \stackrel{\text{Fourier transform}}{\longleftrightarrow}\quad \operatorname{sinc}(Lf) \triangleq \frac{\sin(\pi L f)}{\pi L f}.$$

Transforming each term:

$$\begin{aligned} W_0(f) &= \tfrac{1}{2}\operatorname{sinc}(Lf) + \tfrac{1}{4} \operatorname{sinc}(L(f-1/L)) + \tfrac{1}{4} \operatorname{sinc}(L(f+1/L))\\ &= \tfrac{1}{2}\frac{\sin(\pi Lf)}{\pi Lf} + \tfrac{1}{4} \frac{\sin(\pi (Lf-1))}{\pi (Lf-1)} + \tfrac{1}{4} \frac{\sin(\pi (Lf+1))}{\pi (Lf+1)}\\ &= \frac{1}{2\pi}\left( \frac{\sin(\pi Lf)}{Lf} -\tfrac{1}{2} \frac{\sin(\pi Lf)}{Lf-1} -\tfrac{1}{2} \frac{\sin(\pi Lf)}{Lf+1}\right)\\ &= \frac{\sin(\pi Lf)}{2\pi}\left(\frac{1}{Lf} +\tfrac{1}{2} \frac{1}{1-Lf} -\tfrac{1}{2} \frac{1}{1+Lf}\right)\\ &= \frac{\sin(\pi Lf)}{2\pi}\cdot \frac{1}{Lf (1-Lf) (1+Lf)} = \frac{1}{2}\frac{\operatorname{sinc}(Lf)}{(1 - L^2f^2)}. \end{aligned}$$

:::

## Discrete transforms {#Discrete_transforms}

The [discrete-time Fourier transform](wikipedia://en/1216914) (DTFT) of the $N+1$ length, time-shifted sequence is defined by a [Fourier series](wikipedia://en/59038), which also has a 3-term equivalent that is derived similarly to the Fourier transform derivation:

$$\begin{aligned} \mathcal{F}\{w[n]\} &\triangleq \sum_{n=0}^{N} w[n]\cdot e^{-i 2 \pi f n}\\ &= e^{-i \pi f N}\left[\tfrac{1}{2} \frac{\sin(\pi(N+1)f)}{\sin(\pi f)} + \tfrac{1}{4} \frac{\sin(\pi(N+1)(f-\tfrac{1}{N}))}{\sin(\pi (f-\tfrac{1}{N}))} + \tfrac{1}{4} \frac{\sin(\pi(N+1)(f+\tfrac{1}{N}))}{\sin(\pi (f+\tfrac{1}{N}))}\right]. \end{aligned}$$

The truncated sequence $\{w[n],\ 0 \le n \le N-1\}$ is a [DFT-even](wikipedia://en/545288#DFT-symmetry) (aka *periodic*) Hann window. Since the truncated sample has value zero, it is clear from the Fourier series definition that the DTFTs are equivalent. However, the approach followed above results in a significantly different-looking, but equivalent, 3-term expression:

$$\mathcal{F}\{w[n]\} = e^{-i \pi f (N-1)}\left[\tfrac{1}{2} \frac{\sin(\pi N f)}{\sin(\pi f)} + \tfrac{1}{4} e^{-i\pi/N} \frac{\sin(\pi N (f-\tfrac{1}{N}))}{\sin(\pi (f-\tfrac{1}{N}))} + \tfrac{1}{4} e^{i\pi/N} \frac{\sin(\pi N (f+\tfrac{1}{N}))}{\sin(\pi (f+\tfrac{1}{N}))}\right].$$

An *N*-length DFT of the window function samples the DTFT at frequencies $f = k/N,$ for [integer](wikipedia://en/14563) values of $k.$ From the expression immediately above, it is easy to see that only 3 of the N DFT coefficients are non-zero. And from the other expression, it is apparent that all are real-valued. These properties are appealing for real-time applications that require both windowed and non-windowed (rectangularly windowed) transforms, because the windowed transforms can be efficiently derived from the non-windowed transforms by [convolution](wikipedia://en/8811#Convolution_theorem_duality).[^o15]Nuttall 1981, p 85 Harris 1978, p 62

## Name {#Name}

The function is named in honor of von Hann, who used the three-term weighted average smoothing technique on meteorological data.[^o16][^o13] However, the term *Hanning* function is also conventionally used,[^o10] derived from the paper in which the term *hanning a signal* was used to mean applying the Hann window to it.[^o11][^o12] It is distinct from the similarly-named [Hamming function](https://en.wikipedia.org/wiki/Hamming_function), named after [Richard Hamming](wikipedia://en/99326).
