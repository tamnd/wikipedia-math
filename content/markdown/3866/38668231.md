# Kemeny's constant

::: {#o1 .subject cue=lead name="Kemeny's constant"}

In [probability theory](wikipedia://en/23542), **Kemeny’s constant** is the [expected](wikipedia://en/9653) number of time steps required for a [Markov chain](wikipedia://en/60876) to transition from a starting state *i* to a random destination state sampled from the Markov chain's stationary distribution. Surprisingly, this quantity does not depend on which starting state *i* is chosen.[^o2] It is in that sense a constant, although it is different for different Markov chains. When first published by [John Kemeny](https://en.wikipedia.org/wiki/John_Kemeny_%28computer_scientist%29) in 1960 a prize was offered for an intuitive explanation as to why the quantity was constant.[^o3][^o4]

:::

Beyond its theoretical importance, Kemeny’s constant is also applied in practice to evaluate the efficiency of robotic surveillance strategies. More precisely, Kemeny's constant measures how quickly a robot can navigate its environment using Markov chain-based methods.[^o5][^o6]

::: {#o8 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a finite ergodic Markov chain[^o9] with [transition matrix](wikipedia://en/217313) *P* and invariant distribution *π*, write *m*<sub>*ij*</sub> for the mean first passage time from state *i* to state *j* (denoting the mean recurrence time for the case *i* = *j*). Then

$$K = \sum_{j} \pi_j m_{ij}$$

is a constant and not dependent on *i*.[^o10]

:::

## Prize {#Prize}

Kemeny wrote, (for *i* the starting state of the Markov chain) “A prize is offered for the first person to give an intuitively plausible reason for the above sum to be independent of *i*.”[^o3] Grinstead and [Snell](wikipedia://en/33962324) offer an explanation by Peter Doyle as an exercise, with solution “he got it!”[^o12][^o13]

> In the course of a walk with Snell along Minnehaha Avenue in Minneapolis in the fall of 1983, Peter Doyle suggested the following explanation for the constancy of Kemeny's constant. Choose a target state according to the fixed vector **w**. Start from state *i* and wait until the time *T* that the target state occurs for the first time. Let *K*<sub>*i*</sub> be the expected value of *T*. Observe that
>
> $K_i+w_i \cdot 1/w_i = \sum_j P_{ij}K_j + 1$ and hence
>
> $K_i = \sum_j P_{ij}K_j.$ By the [maximum principle](wikipedia://en/1436104), *K*<sub>*i*</sub> is a constant. Should Peter have been given the prize?
