# Aggregative game

::: {#o1 .subject cue=lead name="Aggregative game"}

In [game theory](wikipedia://en/11924), an **aggregative game (AG)**,[^o2] sometimes called a **summarization game**,[^o31] is a game in which every player's payoff is a function of the player's own strategy and the aggregate of all players’ strategies. The concept was first proposed by Nobel laureate [Reinhard Selten](https://en.wikipedia.org/wiki/Reinhard_Selten) in 1970.[^o3]

:::

::: {#o5 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Consider a standard [non-cooperative game](https://en.wikipedia.org/wiki/Non-cooperative_game) with *n* players, where the set of strategies (actions) available to each player *i* is denoted by *S<sub>i</sub>*. The set of all possible strategy profiles is denoted by $S=S_1 \times S_2 \times \ldots \times S_n$. Each player *i* has a [payoff function](https://en.wikipedia.org/wiki/Payoff_function) and $u_i:S \to \mathbb{R}$.

### Simple aggregative game {#Simple_aggregative_game}

In the simplest setting studied in the context of aggregative games, *S<sub>i</sub>* is assumed to be *one-dimensional*, $S_i \subseteq \mathbb{R}$. That is, the game amounts to each player choosing a number simultaneously with the others. The game is called an **aggregative game** if for each player *i* there exists a function $\tilde{u}_i:S_i \times \mathbb{R} \to \mathbb{R}$ such that for all $s \in S$:

$$u_i(s)=\tilde{u}_i \left( s_i,\sum_{j=1}^n s_j \right)$$

In words, payoff functions in aggregative games depend on players' *own strategies* and the *aggregate* $\sum s_j$.

### Generalized aggregative game {#Generalized_aggregative_game}

The definition can be generalized by replacing the sum with an arbitrary increasing function.[^o8] Formally, in a **generalized aggregative game** (with one-dimensional strategy sets), there exists a function $\tilde{u}_i:S_i \times \mathbb{R} \to \mathbb{R}$ and a function $g:S \to \mathbb{R}$ such that for all $s \in S$:

> $$u_i(s)=\tilde{u}_i \left( s_i, g(s) \right).$$

Usually, it is assumed that the aggregator function is additively separable, that is,

> $$g(s_1,\ldots,s_n)=g_0(\sum_{j=1}^n g_j(s_j))$$

where $g_j: S_j\to \mathbb{R}$ and $g_0: \mathbb{R}\to \mathbb{R}$. So

> $$u_i(s)=\tilde{u}_i \left( s_i, g_0(\sum_{j=1}^n g_j(s_j)) \right),$$

Obviously, any aggregative game is generalized aggregative as seen by taking $g(s_1,\ldots,s_n)=\sum s_i$.

### Quasi-aggregative games {#Quasi-aggregative_games}

The definition above can be further generalized by allowing each player to have a different aggregation function. This is called a **quasi-aggregative game**.[^o10][^o11][^o12]

### Multi-dimensional aggregators {#Multi-dimensional_aggregators}

The aggregator can be multi-dimensional: $g:S \to \mathbb{R}^d$, for some positive integer *d*. Each coordinate of the aggregator is assumed to be additively-separable, that is:[^o14]

> $g(s) = [g^1(s),\ldots,g^d(s)]$ where
>
> $$g^k(s) = g^k_0(\sum_{j=1}^n g^k_j(s_j))$$

where $g^k_j: S_j\to \mathbb{R}$ and $g^k_0: \mathbb{R}\to \mathbb{R}$. This class of games generalizes both [anonymous games](https://en.wikipedia.org/wiki/Anonymous_game) and weighted [congestion games](wikipedia://en/25827396):

- In anonymous games, each player selects an action from a [finite set](wikipedia://en/11742), and the utility of each player depends only on his own action and on the number of players who chose each action. Here, *d* is the number of actions, and for each action *k*, $g^k_j(s_j)$ is 1 if $s_j=k$ and 0 otherwise, and $g^k_0$ is the [identity function](wikipedia://en/15069). Hence, $g^k(s)$ is the number of players who chose action *k* in profile *s*.
- In weighted congestion games, each player selects a subset of resources from a finite family of allowed subsets, and the utility of each player depends only on his own subset and on the total weight of players who choose each resource. Here, *d* is the number of resources, and for each resource *k*, $g^k_j(s_j)$ is the weight of player *j* if $k \in s_j$ and 0 otherwise, and $g^k_0$ is the identity function.

:::

::: {#o16 .example cue=heading name="Example"}

## Example {#Example}

Consider the [Cournot competition](https://en.wikipedia.org/wiki/Cournot_model), where firm *i* has payoff/profit function $u_i(s)=s_i P\left(\sum s_j\right)-C_i(s_i)$ , where:

- $P$ is the [inverse demand function](https://en.wikipedia.org/wiki/Inverse_demand_function) - it maps the total supplied amount to the price of the product;
- $C_i$ is the cost function of firm *i*.

This is an aggregative game since $u_i(s)=\tilde{u}_i\left(s_i,\sum s_j\right)$ where $\tilde{u}_i(s_i,X)=s_i P(X)-C_i(s_i)$.

Some other natural examples of aggregative games are:

- [Public goods game](https://en.wikipedia.org/wiki/Public_goods_game) - the utility of each player depends only on his own contribution to the public good, and on the total amount contributed by all players.
- [Pollution game](https://en.wikipedia.org/wiki/Pollution_game)[^o17] - the utility of each player depends on its own pollution level and on the total pollution level.
- [Congestion game](wikipedia://en/25827396) - the utility of each player depends on his own choice, and the aggregate congestion caused by others.
- [Bertrand competition](wikipedia://en/1462677).[^o10]
- Games of [Budget-proposal aggregation](wikipedia://en/75060458).[^o18]

:::

::: {#o20 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Generalized AGs (hence AGs) admit **backward reply correspondences** and in fact, is the most general class to do so.[^o8] Backward reply correspondences, as well as the closely related **share correspondences**, are powerful analytical tools in game theory. For example, backward reply correspondences were used to give the first general proof of the existence of a [Nash equilibrium](wikipedia://en/45337) in the [Cournot model](https://en.wikipedia.org/wiki/Cournot_model) without assuming [quasiconcavity](https://en.wikipedia.org/wiki/Quasiconcavity) of firms' profit functions.[^o21] Backward reply correspondences also play a crucial role for [comparative statics](https://en.wikipedia.org/wiki/Comparative_statics) analysis (see below).
- Quasi-AGs (hence generalized AGs, hence AGs) are **best-response potential games** if best-response correspondences are either increasing or decreasing.[^o22][^o12] Precisely as games with [strategic complementarities](https://en.wikipedia.org/wiki/Strategic_complementarities), such games therefore have a **pure strategy [Nash equilibrium](wikipedia://en/45337)** regardless of whether payoff functions are [quasiconcave](https://en.wikipedia.org/wiki/Quasiconcave) and/or strategy sets are [convex](wikipedia://en/6292). The existence proof of Novshek for a [Cournot equilibrium](wikipedia://en/1481119)[^o21] is a special case of such more general existence results.
- AGs have strong **[comparative statics](https://en.wikipedia.org/wiki/Comparative_statics)** properties. Under very general conditions one can predict how a change in exogenous parameters will affect the [Nash equilibria](https://en.wikipedia.org/wiki/Nash_equilibria).[^o2][^o23]

:::

## History of terms and results {#History_of_terms_and_results}

### One-dimensional strategy sets, one-dimensional aggregators {#One-dimensional_strategy_sets,_one-dimensional_aggregators}

AGs were first studied under the assumption that the players' strategy sets are one-dimensional (each player chooses a number), and the aggregator function is also one-dimensional (returns a number).

Dubey, Mas-Collel and Shubik (1980)[^o26] presented the "Aggregation Axiom": each player's utility depends on the player's action and the sum of all players' actions.

Corchon (1994)[^o2] introduced the term "aggregative game" to mean a game that satisfies this aggregation axiom. He studied one-dimensional AGs in which the best-response function of each player is *decreasing* in the sum of actions --- a situation called [strategic substitutes](https://en.wikipedia.org/wiki/Strategic_substitutes). Moreover, he required a stronger condition: the utility function of each player should be continuously differentiable, strictly decreasing in the sum of players' actions, and strictly concave in both variables. Under these assumptions, he proved some [comparative statics](https://en.wikipedia.org/wiki/Comparative_statics) results, such as, when new players enter, the strategy of each player decreases, the sum of strategies increases, and the payoff of each player decreases. He proved that strategic substitution alone, without the strong concavity assumption, is insufficient.

Kukushkin (1994),[^o27] refining a previous result by Novshek (1985),[^o28] studied one-dimensional AGs in which the best-response correspondence of each player has a selection that is a decreasing function (a condition called *weak strategic substitute*). He proved that such games always have a PNE. The proof proceeds in three propositions: (1) for a special case that the strategies of each player are integers in the interval \[0,m\]; (2) for a more general case that the strategies are arbitrary integers; (3) for the most general case that the strategies are real numbers. He claims that Proposition 1 can be easily adapted to multi-dimensional strategy sets.

Kukushkin (2004),[^o29] studied one-dimensional AGs where the strategy sets are *finite* subsets of R. He proved that, if one of three [single crossing](https://en.wikipedia.org/wiki/Single-crossing_condition) conditions is satisfied, then every best response improvement path leads to a NE.

Dubey, Haimanko and Zapecheinyuk (2006)[^o22] studied one-dimensional AGs with weak strategic substitutes or weak strategic complements. They proved that all these games are [pseudo-potential games](wikipedia://en/9394324), and therefore have a PNE. When the strategy sets are finite, and the utilities are generic, the best response is unique. Hence, a pseudo-potential is a best-response potential; hence, every best-response sequence converges to a PNE in finite time.[^o22] They show that their results can be extended to more general aggregation functions: not only sums, but also weighted sums of products.[^o22] They also extend their results to some classes of discontinuous best-reply functions, which include some aggregative games with indivisibilities.[^o22]

Dindos and Mezzetti (2006)[^o30] studied one-dimensional AGs with [quasiconcave](https://en.wikipedia.org/wiki/Quasiconcave) utilities. They showed that the *better-reply dynamics* converges globally to a [Nash equilibrium](wikipedia://en/45337) if actions are either [strategic substitutes](https://en.wikipedia.org/wiki/Strategic_substitutes) or [strategic complements](wikipedia://en/12645144) for all players around each asymptotically-stable equilibrium. In contrast, if the derivatives of the best-reply functions have different signs, then the better-reply dynamics might not converge even with two players. They assumed that the player who deviates, as well as the improving strategy he deviates too, are determined randomly.

Cornes and Hartley (2012)[^o8] generalized one-dimensional AGs by allowing the utility of each player to depend on his own action and on an arbitrary aggregation function of the others' actions (same aggregation function to all players), instead of the sum. In addition, they assumed that the *marginal* utility of each player (that is, the derivative of *u<sub>i</sub>* w.r.t. the strategy of *i*) also depends on his own action and on the same aggregation function. They call such games **fully aggregative games**. They show that every such game with three or more players is equivalent to an aggregative game in which the aggregator is a simple sum.

Jensen (2018)[^o10] studied a more general notion called **quasi-aggregation**, where each player may have a different aggregator function, but still with one-dimensional strategy sets. He proved that every quasi-aggregative game satisfying certain assumptions has a best-response potential function or a best-response pseudo-potential function, and therefore has a PNE. Moreover, every reasonable sequence of improvement paths converges to a PNE.

Kearns and Mansour (2002)[^o31] assume that each player can choose one of two actions "0" or "1" (they say their results are easily generalizable to a finite set of actions). The utility of each player depends only on his own action and some global *summarization function*, which is allowed to be asymmetric and non-linear (they use the term **summarization game** instead of aggregative game). They also assume that (a) each player has a bounded influence on the summarization function; (b) the utility functions are continuous and have bounded derivatives; (c) the summarization function and payoff functions are computable in unit time. Under these assumptions, they present polytime algorithms for computing and learning approximate Nash equilibria. They also compute the rates of convergence as a function of the influence bound, the derivatives of utility functions, and the population size.

Babichenko (2013)[^o32] assume that each player can choose any [real number](wikipedia://en/20646438) in \[0,1\]. The utility of each player depends only on his own action and some aggregator function (the same for all players). He assumes that the aggregator function is [Lipschitz continuous](wikipedia://en/51731) w.r.t. the individual actions, and each utility function is Lipschitz continuous w.r.t. the aggregator, which means that each player has a bounded influence on the aggregation and on the utilities of others. He calls such game **quasi-aggregative**. He presents a [best-reply dynamic](https://en.wikipedia.org/wiki/Best_reply_dynamic) that converges to approximate NE in O(*n* log *n*) steps.

Siddharth Barman and [Katrina Ligett](https://en.wikipedia.org/wiki/Katrina_Ligett) (2015)[^o33] presented a polytime algorithm for computing an approximate [correlated equilibrium](wikipedia://en/3366108) with near-optimal welfare in aggregative games.

### One-dimensional strategy sets, multi-dimensional aggregators {#One-dimensional_strategy_sets,_multi-dimensional_aggregators}

Cummings, Kearns, Roth and Wu (2015)[^o14] study AGs with finite strategy sets --- each player can choose an action from a set of *m* actions. They allow the aggregator to be multi-dimensional. This class of games generalizes both [anonymous games](https://en.wikipedia.org/wiki/Anonymous_game) and weighted [congestion games](wikipedia://en/25827396). They present an algorithm, based on a [weak mediator](https://en.wikipedia.org/wiki/Weak_mediator), that converges in polynomial time to an asymptotic Nash equilibrium, when the population is large. The algorithm for computing the weak mediator runs in time polynomial in the number of players and actions, but exponential in the number of dimensions of the aggregator. They use tools from [differential privacy](wikipedia://en/23473696).

### Multi-dimensional strategy sets {#Multi-dimensional_strategy_sets}

In the most general setting, both the strategy sets and the aggregator output can be multi-dimensional.

Jensen (2005)[^o11] studied AGs in which the strategy set of each agent i is a *d*-dimensional box in R^d, for some d ≥ 1. He required the aggregator to be "separable" in the sense that each coordinate of the aggregator depends on different coordinates of [strategy profile](wikipedia://en/1434441); in particular, this implies that the aggregator has at most *d* coordinates. He proved that, if such a game has strategic substitutes and satisfies some other technical conditions, then it has a PNE. He also analyzes the structure of the set of PNE, their [comparative statics](https://en.wikipedia.org/wiki/Comparative_statics), and sufficient conditions for uniqueness and stability.

Jensen (2010)[^o12] also studied AGs with multi-dimensional strategy sets. He extended the definition by allowing each player to have a different aggregator function. He named the extended notion "quasi-aggregative game". He proved that, under certain technical assumptions, such games have best-response potential functions, and thus the best-response dynamics converges to a PNE.

Parise, Grammatico, Gentile and Lygeros (2015[^o36]-2020[^o37]) study **network AGs** --- a variant in which the utility of each agent depends on his own strategy and on an [aggregate function](https://en.wikipedia.org/wiki/Aggregate_function) of his neighbors in the network (in the earlier version[^o36] they assume that the players' dis-utility functions are quadratic). The strategy sets are multi-dimensional. They present a class of distributed algorithms that are guaranteed to converge to a PNE, both for network aggregative games and for classic aggregative games (where the utility of each player depends on the sum of all other players' actions), under different sufficient conditions depending on the utility functions and the communication network. Their algorithms in both cases require only local communication.

Xu, Chen, Qi and Hong (2023)[^o38] present a [distributed algorithm](https://en.wikipedia.org/wiki/Distributed_algorithm) for multi-dimensional AGs; they show that their algorithm has [linear convergence](https://en.wikipedia.org/wiki/Linear_convergence). However, it converges to an approximate PNE, not to the exact PNE.

Deng and Nian (2018)[^o39] study AGs over weight-balanced [digraphs](wikipedia://en/19721986). Players have constraint sets coupled by linear constraints. Players have first-order dynamics and are influenced by exogenous disturbances. For the case of smooth utility functions, they present a distributed continuous-time algorithm for finding the variational [generalized NE](https://en.wikipedia.org/wiki/Generalized_Nash_equilibrium). Their algorithm uses [gradient descent](wikipedia://en/201489), [internal model](https://en.wikipedia.org/wiki/Internal_model_%28motor_control%29) and dynamic average consensus. They prove that their algorithm converges exponentially to the variational generalized NE. Later, Deng and Nian (2020)[^o40] they study non-smooth utility functions. They present another continuous-time algorithm that converges asymptotically, but without guarantees in its convergence rate. Deng (2022)[^o41] extends these results to players with second-order dynamics, but no constraints on the strategy sets. He presents two continuous-time algorithms with exponential convergece rates.

Wang, Chen, Chen, Lian and Wang[^o42] extend the above works to weight-unbalanced digraphs; they, too, develop continuous-time algorithms with exponential convergence.

Li, Li, Rang, Zheng and Huang (2025)[^o43] survey distributed algorithms for aggregative games with multi-dimensional strategy sets. Importantly, they assume that there is a fixed undirected network that describes the possible connections between players, and each player can communicate only with its neighbors in the network.

Wang and Nedic (2024)[^o44] present a distributed and privacy-preserving algorithm for computing a NE in an aggregative game over a network. In their model, the strategy sets are multi-dimensional - compact and convex subsets of R<sup>*d*</sup>. The aggregator function is the [arithmetic mean](wikipedia://en/612) (or the sum) of all strategy vectors. The utility functions are continuously differentiable, and they are *[concave function](wikipedia://en/263321)*s of the player's action (equivalently, the *cost* is a *[convex function](wikipedia://en/245568)* of the player's action). Their algorithm guarantees both a finite "privacy budget" and accurate convergence.

## Mean field games {#Mean_field_games}

**Mean field game** can be seen as the limit of an aggregative game when the number of players goes to infinity. Thus, the effect of each player on the aggregate is negligible.

Acemoglu and Jensen (2010)[^o46] generalized aggregative games to allow for infinitely many players, in which case the aggregator will typically be an integral rather than a linear sum.

Grammatico, Parise, Colombino and Lygeros (2016)[^o47] present distributed algorithms for computing PNE in mean-field games. Their main contribution over previous work is that they allow agents to have different constraints (as long as the constraint set of each agent is convex). They present a decentralized algorithm for computing a mean field PNE.
