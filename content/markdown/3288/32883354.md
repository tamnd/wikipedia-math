# Poset game

::: {#o1 .subject cue=lead name="Poset game"}

In [combinatorial game theory](wikipedia://en/292231), **poset games** are [mathematical](wikipedia://en/20434) [games of strategy](https://en.wikipedia.org/wiki/Game_of_strategy), generalizing many well-known games such as [Nim](wikipedia://en/21885) and [Chomp](wikipedia://en/1306265).[^o9] In such games, two players start with a [poset](https://en.wikipedia.org/wiki/Poset) (a **partially ordered set**), and take turns choosing one point in the poset, removing it and all points that are greater. The player who is left with no point to choose, loses.

:::

## Gameplay {#Gameplay}

Given a [partially ordered set](wikipedia://en/23572) (*P*, \<), let

$$P_x = P - \{ a\mid a \geq x\}$$

denote the poset formed by removing *x* from *P*.

A poset game on *P*, played between two players conventionally named [Alice and Bob](wikipedia://en/679079), is as follows:

- Alice chooses a point *x* ∈ *P*; thus replacing *P* with *P*<sub>*x*</sub>, and then passes the turn to Bob who plays on *P*<sub>*x*</sub>, and passes the turn to Alice.
- A player loses if it is their turn and there are no points to choose.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

If *P* is a [finite](wikipedia://en/11742) [totally ordered set](https://en.wikipedia.org/wiki/Totally_ordered_set), then game play in *P* is exactly the same as the game play in a game of [Nim](wikipedia://en/21885) with a heap of size |*P*|. For, in both games, it is possible to choose a move that leads to a game of the same type whose size is any number smaller than |*P*|. In the same way, a poset game with a disjoint union of total orders is equivalent to a game of Nim with multiple heaps with sizes equal to the chains in the poset.

A special case of [Hackenbush](wikipedia://en/1613052), in which all edges are green (able to be cut by either player) and every configuration takes the form of a [forest](wikipedia://en/48560), may be expressed similarly, as a poset game on a poset in which, for every element *x*, there is at most one element *y* for which *x* [covers](wikipedia://en/14835049) *y*. If *x* covers *y*, then *y* is the parent of *x* in the forest on which the game is played.

[Chomp](wikipedia://en/1306265) may be expressed similarly, as a poset game on the [product](wikipedia://en/1956306) of total orders from which the [infimum](https://en.wikipedia.org/wiki/Infimum) has been removed.

:::

## Grundy value {#Grundy_value}

Poset games are [impartial games](https://en.wikipedia.org/wiki/Impartial_game), meaning that every move available to Alice would also be available to Bob if Alice were allowed to [pass](wikipedia://en/4927933), and vice versa. Therefore, by the [Sprague–Grundy theorem](wikipedia://en/41372), every position in a poset game has a Grundy value, a number describing an equivalent position in the game of Nim. The Grundy value of a poset may be calculated as the least natural number which is not the Grundy value of any *P*<sub>*x*</sub>, *x* ∈ *P*. That is,[^o10]

$$G(P)=\min\bigl(\mathbb{N}\setminus \{G(P_x)\mid x\in P\}\bigr).$$

This number may be used to describe the optimal game play in a poset game. In particular, the Grundy value is nonzero when the player whose turn it is has a winning strategy, and zero when the current player cannot win against optimal play from his or her opponent. A winning strategy in the game consists of moving to a position whose Grundy value is zero, whenever this is possible.

## Strategy stealing {#Strategy_stealing}

A [strategy-stealing argument](wikipedia://en/709783) shows that the Grundy value is nonzero for every poset that has a [supremum](https://en.wikipedia.org/wiki/Supremum). For, let *x* be the supremum of a partially ordered set *P*. If *P<sub>x</sub>* has Grundy value zero, then *P* itself has a nonzero value, by the formula above; in this case, *x* is a winning move in *P*. If, on the other hand, *P<sub>x</sub>* has a nonzero Grundy value, then there must be a winning move *y* in *P<sub>x</sub>*, such that the Grundy value of (*P<sub>x</sub>*)<sub>*y*</sub> is zero. But by the assumption that *x* is a supremum, *x* > *y* and (*P<sub>x</sub>*)<sub>*y*</sub> = *P<sub>y</sub>*, so the winning move *y* is also available in *P* and again *P* must have a nonzero Grundy value.[^o9]

For more trivial reasons a poset with an infimum also has a nonzero Grundy value: moving to the infimum is always a winning move.

## Complexity {#Complexity}

Deciding the winner of an arbitrary finite poset game is [PSPACE-complete](wikipedia://en/54685).[^o11] This means that unless P=PSPACE, computing the Grundy value of an arbitrary poset game is computationally difficult.
