# Scatter matrix

*For the notion in quantum mechanics, see [scattering matrix](https://en.wikipedia.org/wiki/Scattering_matrix).*

::: {#o1 .subject cue=lead name="Scatter matrix"}

In [multivariate statistics](wikipedia://en/19384) and [probability theory](wikipedia://en/23542), the **scatter matrix** is a [statistic](wikipedia://en/26703) that is used to make [estimates](wikipedia://en/974723) of the [covariance matrix](wikipedia://en/191752), for instance of the [multivariate normal distribution](wikipedia://en/50347).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given *n* samples of *m*-dimensional data, represented as the m-by-n matrix, $X=[\mathbf{x}_1,\mathbf{x}_2,\ldots,\mathbf{x}_n]$, the [sample mean](https://en.wikipedia.org/wiki/Sample_mean) is

$$\overline{\mathbf{x}} = \frac{1}{n}\sum_{j=1}^n \mathbf{x}_j$$

where $\mathbf{x}_j$ is the *j*-th column of $X$.[^o4]

The **scatter matrix** is the *m*-by-*m* [positive semi-definite](https://en.wikipedia.org/wiki/Positive_definite_matrix) matrix

$$S = \sum_{j=1}^n (\mathbf{x}_j-\overline{\mathbf{x}})(\mathbf{x}_j-\overline{\mathbf{x}})^T = \sum_{j=1}^n (\mathbf{x}_j-\overline{\mathbf{x}})\otimes(\mathbf{x}_j-\overline{\mathbf{x}}) = \left( \sum_{j=1}^n \mathbf{x}_j \mathbf{x}_j^T \right) - n \overline{\mathbf{x}} \overline{\mathbf{x}}^T$$

where $(\cdot)^T$ denotes [matrix transpose](https://en.wikipedia.org/wiki/Matrix_transpose),[^o5] and multiplication is with regards to the [outer product](wikipedia://en/103109). The scatter matrix may be expressed more succinctly as

$$S = X\,C_n\,X^T$$

where $\,C_n$ is the *n*-by-*n* [centering matrix](wikipedia://en/11395056).

:::

::: {#o7 .application cue=heading name="Application"}

## Application {#Application}

The [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) estimate, given *n* samples, for the covariance matrix of a multivariate normal distribution can be expressed as the normalized scatter matrix

$C_{ML}=\frac{1}{n}S.$[^o8]

When the columns of $X$ are independently sampled from a multivariate normal distribution, then $S$ has a [Wishart distribution](wikipedia://en/364996).

:::
