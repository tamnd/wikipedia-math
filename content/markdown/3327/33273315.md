# Submodular set function

::: {#o1 .subject cue=lead name="Submodular set function"}

In mathematics, a **submodular set function** (also known as a **submodular function**) is a [set function](wikipedia://en/25911217) that, informally, describes the relationship between a set of inputs and an output, where adding more of one input has a decreasing additional benefit ([diminishing returns](https://en.wikipedia.org/wiki/Diminishing_returns)). The natural [diminishing returns](https://en.wikipedia.org/wiki/Diminishing_returns) property which makes them suitable for many applications, including [approximation algorithms](https://en.wikipedia.org/wiki/Approximation_algorithms), [game theory](wikipedia://en/11924) (as functions modeling user preferences) and [electrical networks](wikipedia://en/9559). Recently, submodular functions have also found utility in several real world problems in [machine learning](wikipedia://en/233488) and [artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence), including [automatic summarization](https://en.wikipedia.org/wiki/Automatic_summarization), [multi-document summarization](https://en.wikipedia.org/wiki/Multi-document_summarization), [feature selection](wikipedia://en/1179950), [active learning](https://en.wikipedia.org/wiki/Active_learning_%28machine_learning%29), sensor placement, image collection summarization and many other domains.[^o50][^o51][^o52][^o48]

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

If $\Omega$ is a finite [set](wikipedia://en/26691), a submodular function is a set function $f:2^{\Omega}\rightarrow \mathbb{R}$, where $2^\Omega$ denotes the [power set](wikipedia://en/23799#Representing_subsets_as_functions) of $\Omega$, which satisfies one of the following equivalent conditions.

1. For every $X, Y \subseteq \Omega$ with $X \subseteq Y$ and every $x \in \Omega \setminus Y$ we have that $f(X\cup \{x\})-f(X)\geq f(Y\cup \{x\})-f(Y)$.
1. For every $S, T \subseteq \Omega$ we have that $f(S)+f(T)\geq f(S\cup T)+f(S\cap T)$.
1. For every $X\subseteq \Omega$ and $x_1,x_2\in \Omega\backslash X$ such that $x_1\neq x_2$ we have that $f(X\cup \{x_1\})+f(X\cup \{x_2\})\geq f(X\cup \{x_1,x_2\})+f(X)$, or equivalently, $f(X\cup \{x_1\}) - f(X) \geq f(X\cup \{x_1,x_2\}) - f(X\cup \{x_2\})$.

A nonnegative submodular function is also a [subadditive](wikipedia://en/37998626) function, but a subadditive function need not be submodular. If $\Omega$ is not assumed finite, then the above conditions are not equivalent. In particular a function $f$ defined by $f(S) = 1$ if $S$ is finite and $f(S) = 0$ if $S$ is infinite satisfies the first condition above, but the second condition fails when $S$ and $T$ are infinite sets with finite intersection.

:::

## Types and examples of submodular functions {#Types_and_examples_of_submodular_functions}

::: {#o7 .pointer-item cue=pointer name="Monotone set function"}

### Monotone {#Monotone}

A set function $f$ is *monotone* if for every $T\subseteq S$ we have that $f(T)\leq f(S)$. Examples of monotone submodular functions include:

**Linear (Modular) functions**

Any function of the form $f(S)=\sum_{i\in S}w_i$ is called a linear function. Additionally if $\forall i,w_i\geq 0$ then f is monotone.

**[Budget-additive functions](https://en.wikipedia.org/wiki/Budget-additive_valuation)**

Any function of the form $f(S)=\min\left\{B,~\sum_{i\in S}w_i\right\}$ for each $w_i\geq 0$ and $B\geq 0$ is called budget additive.[^o55]

**Coverage functions**

Let $\Omega=\{E_1,E_2,\ldots,E_n\}$ be a collection of subsets of some [ground set](wikipedia://en/244321) $\Omega'$. The function $f(S)=\left|\bigcup_{E_i\in S}E_i\right|$ for $S\subseteq \Omega$ is called a coverage function. This can be generalized by adding non-negative weights to the elements.

**[Entropy](wikipedia://en/15445)**

Let $\Omega=\{X_1,X_2,\ldots,X_n\}$ be a set of [random variables](https://en.wikipedia.org/wiki/Random_variables). Then for any $S\subseteq \Omega$ we have that $H(S)$ is a submodular function, where $H(S)$ is the entropy of the set of random variables $S$, a fact known as [Shannon's inequality](wikipedia://en/17519721#Shannon-type_inequalities_and_Γn).[^o8] Further inequalities for the entropy function are known to hold, see [entropic vector](wikipedia://en/17519721).

**[Matroid](wikipedia://en/244321) [rank functions](wikipedia://en/37123010)**

Let $\Omega=\{e_1,e_2,\dots,e_n\}$ be the ground set on which a matroid is defined. Then the rank function of the matroid is a submodular function.[^o9]

:::

### Non-monotone {#Non-monotone}

A submodular function that is not monotone is called *non-monotone*. In particular, a function is called non-monotone if it has the property that adding more elements to a set can decrease the value of the function. More formally, the function $f$ is non-monotone if there are sets $S,T$ in its domain s.t. $S \subset T$ and $f(S)> f(T)$.

#### Symmetric {#Symmetric}

A non-monotone submodular function $f$ is called *symmetric* if for every $S\subseteq \Omega$ we have that $f(S)=f(\Omega-S)$. Examples of symmetric non-monotone submodular functions include:

**Graph cuts**

Let $\Omega=\{v_1,v_2,\dots,v_n\}$ be the vertices of a [graph](wikipedia://en/325806). For any set of vertices $S\subseteq \Omega$ let $f(S)$ denote the number of edges $e=(u,v)$ such that $u\in S$ and $v\in \Omega-S$. This can be generalized by adding non-negative weights to the edges.

**[Mutual information](wikipedia://en/427282)**

Let $\Omega=\{X_1,X_2,\ldots,X_n\}$ be a set of [random variables](wikipedia://en/25685). Then for any $S\subseteq \Omega$ we have that $f(S)=I(S;\Omega-S)$ is a submodular function, where $I(S;\Omega-S)$ is the mutual information.

#### Asymmetric {#Asymmetric}

A non-monotone submodular function which is not symmetric is called asymmetric.

**Directed cuts**

Let $\Omega=\{v_1,v_2,\dots,v_n\}$ be the vertices of a [directed graph](wikipedia://en/19721986). For any set of vertices $S\subseteq \Omega$ let $f(S)$ denote the number of edges $e=(u,v)$ such that $u\in S$ and $v\in \Omega-S$. This can be generalized by adding non-negative weights to the directed edges.

## Continuous extensions of submodular set functions {#Continuous_extensions_of_submodular_set_functions}

Often, given a submodular set function that describes the values of various sets, we need to compute the values of *fractional* sets. For example: we know that the value of receiving house A and house B is V, and we want to know the value of receiving 40% of house A and 60% of house B. To this end, we need a *continuous extension* of the submodular set function.

Formally, a set function $f:2^{\Omega}\rightarrow \mathbb{R}$ with $|\Omega|=n$ can be represented as a function on $\{0, 1\}^{n}$, by associating each $S\subseteq \Omega$ with a binary vector $x^{S}\in \{0, 1\}^{n}$ such that $x_{i}^{S}=1$ when $i\in S$, and $x_{i}^{S}=0$ otherwise. A *continuous [extension](wikipedia://en/1589032#Extension_of_a_function)* of $f$ is a [continuous function](wikipedia://en/6122) $F:[0, 1]^{n}\rightarrow \mathbb{R}$, that matches the value of $f$ on $x\in \{0, 1\}^{n}$, i.e. $F(x^{S})=f(S)$.

Several kinds of continuous extensions of submodular functions are commonly used, which are described below.

### Lovász extension {#Lovász_extension}

This extension is named after mathematician [László Lovász](wikipedia://en/1623938).[^o54] Consider any vector $\mathbf{x}=\{x_1,x_2,\dots,x_n\}$ such that each $0\leq x_i\leq 1$. Then the Lovász extension is defined as

$$f^L(\mathbf{x})=\mathbb{E}(f(\{i|x_i\geq \lambda\}))$$

where the expectation is over $\lambda$ chosen from the [uniform distribution](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) on the interval $[0,1]$. The Lovász extension is a convex function [if and only if](wikipedia://en/14922) $f$ is a submodular function.

::: {#o16 .pointer-item cue=pointer name="Multilinear extension"}

### Multilinear extension {#Multilinear_extension}

Consider any vector $\mathbf{x}=\{x_1,x_2,\ldots,x_n\}$ such that each $0\leq x_i\leq 1$. Then the multilinear extension is defined as [^o17][^o18]$F(\mathbf{x})=\sum_{S\subseteq \Omega} f(S) \prod_{i\in S} x_i \prod_{i\notin S} (1-x_i)$.

Intuitively, *x<sub>i</sub>* represents the probability that item *i* is chosen for the set. For every set *S*, the two inner products represent the probability that the chosen set is exactly *S*. Therefore, the sum represents the [expected value](wikipedia://en/9653) of *f* for the set formed by choosing each item *i* at random with probability xi, independently of the other items.

:::

### Convex closure {#Convex_closure}

Consider any vector $\mathbf{x}=\{x_1,x_2,\dots,x_n\}$ such that each $0\leq x_i\leq 1$. Then the convex closure is defined as $f^-(\mathbf{x})=\min\left(\sum_S \alpha_S f(S):\sum_S \alpha_S 1_S=\mathbf{x},\sum_S \alpha_S=1,\alpha_S\geq 0\right)$.

The convex closure of any set function is convex over $[0,1]^n$.

### Concave closure {#Concave_closure}

Consider any vector $\mathbf{x}=\{x_1,x_2,\dots,x_n\}$ such that each $0\leq x_i\leq 1$. Then the concave closure is defined as $f^+(\mathbf{x})=\max\left(\sum_S \alpha_S f(S):\sum_S \alpha_S 1_S=\mathbf{x},\sum_S \alpha_S=1,\alpha_S\geq 0\right)$.

### Relations between continuous extensions {#Relations_between_continuous_extensions}

For the extensions discussed above, it can be shown that $f^{+}(\mathbf{x}) \geq F(\mathbf{x}) \geq f^{-}(\mathbf{x})=f^L(\mathbf{x})$ when $f$ is submodular.[^o56]

::: {#o23 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

1. The class of submodular functions is [closed](wikipedia://en/293802) under non-negative [linear combinations](wikipedia://en/55632). Consider any submodular function $f_1,f_2,\ldots,f_k$ and non-negative numbers $\alpha_1,\alpha_2,\ldots,\alpha_k$. Then the function $g$ defined by $g(S)=\sum_{i=1}^k \alpha_i f_i(S)$ is submodular.
1. For any submodular function $f$, the function defined by $g(S)=f(\Omega \setminus S)$ is submodular.
1. The function $g(S)=\min(f(S),c)$, where $c$ is a [real number](wikipedia://en/20646438), is submodular whenever $f$ is monotone submodular. More generally, $g(S)=h(f(S))$ is submodular, for any non decreasing concave function $h$.
1. Consider a random process where a set $T$ is chosen with each element in $\Omega$ being included in $T$ independently with probability $p$. Then the following inequality is true $\mathbb{E}[f(T)]\geq p f(\Omega)+(1-p) f(\varnothing)$ where $\varnothing$ is the [empty set](wikipedia://en/9566). More generally consider the following random process where a set $S$ is constructed as follows. For each of $1\leq i\leq l, A_i\subseteq \Omega$ construct $S_i$ by including each element in $A_i$ independently into $S_i$ with probability $p_i$. Furthermore let $S=\cup_{i=1}^l S_i$. Then the following inequality is true $\mathbb{E}[f(S)]\geq \sum_{R\subseteq [l]} \Pi_{i\in R}p_i \Pi_{i\notin R}(1-p_i)f(\cup_{i\in R}A_i)$.

:::

## Optimization problems {#Optimization_problems}

Submodular functions have properties which are very similar to [convex](wikipedia://en/245568) and [concave functions](wikipedia://en/263321). For this reason, an [optimization problem](wikipedia://en/1126536) which concerns optimizing a convex or concave function can also be described as the problem of maximizing or minimizing a submodular function subject to some constraints.

### Submodular set function minimization {#Submodular_set_function_minimization}

The hardness of minimizing a submodular set function depends on constraints imposed on the problem.

1. The unconstrained problem of minimizing a submodular function is computable in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time),[^o34][^o35] and even in [strongly-polynomial](https://en.wikipedia.org/wiki/Strongly_polynomial) time.[^o36][^o37] Computing the [minimum cut](wikipedia://en/3562453) in a graph is a special case of this minimization problem.
1. The problem of minimizing a submodular function with a cardinality lower bound is [NP-hard](https://en.wikipedia.org/wiki/NP-hard), with polynomial factor lower bounds on the approximation factor.[^o47][^o38]

### Submodular set function maximization {#Submodular_set_function_maximization}

Unlike the case of minimization, maximizing a generic submodular function is [NP-hard](https://en.wikipedia.org/wiki/NP-hard) even in the unconstrained setting. Thus, most of the works in this field are concerned with polynomial-time approximation algorithms, including [greedy algorithms](wikipedia://en/89247) or [local search algorithms](https://en.wikipedia.org/wiki/Local_search_%28optimization%29).

1. The problem of maximizing a non-negative submodular function admits a 1/2 approximation algorithm.[^o42][^o45] Computing the [maximum cut](wikipedia://en/19636775) of a graph is a special case of this problem.
1. The problem of maximizing a monotone submodular function subject to a cardinality constraint admits a $1 - 1/e$ approximation algorithm.[^o43][^o27] The [maximum coverage problem](wikipedia://en/24221954) is a special case of this problem.
1. The problem of maximizing a monotone submodular function subject to a [matroid](wikipedia://en/244321) constraint (which subsumes the case above) also admits a $1 - 1/e$ approximation algorithm.[^o44][^o53][^o46]

Many of these algorithms can be unified within a semi-differential based framework of algorithms.[^o38]

### Related optimization problems {#Related_optimization_problems}

Apart from submodular minimization and maximization, there are several other natural optimization problems related to submodular functions.

1. Minimizing the difference between two submodular functions[^o41] is not only NP hard, but also inapproximable.[^o40]
1. Minimization/maximization of a submodular function subject to a submodular [level set](wikipedia://en/559622) constraint (also known as submodular optimization subject to submodular cover or submodular knapsack constraint) admits bounded approximation guarantees.[^o39]
1. Partitioning data based on a submodular function to maximize the average welfare is known as the submodular welfare problem, which also admits bounded approximation guarantees (see [welfare maximization](wikipedia://en/72703925)).

::: {#o30 .application cue=heading name="Applications"}

## Applications {#Applications}

Submodular functions naturally occur in several real world applications, in [economics](https://en.wikipedia.org/wiki/Economics), [game theory](wikipedia://en/11924), [machine learning](wikipedia://en/233488) and [computer vision](https://en.wikipedia.org/wiki/Computer_vision)[^o48][^o49] as well as general [artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence)[^o31]. Owing to the diminishing returns property, submodular functions naturally model costs of items, since there is often a larger discount, with an increase in the items one buys. Submodular functions model notions of complexity, similarity and cooperation when they appear in minimization problems. In maximization problems, on the other hand, they model notions of diversity, information and coverage.
