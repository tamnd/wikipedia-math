# Kaiser–Meyer–Olkin test

::: {#o1 .subject cue=lead name="Kaiser–Meyer–Olkin test"}

The **Kaiser–Meyer–Olkin (KMO) test** is a statistical measure to determine how suited data is for [factor analysis](wikipedia://en/253492). The test measures sampling adequacy for each variable in the model and the complete model. The statistic is a measure of the proportion of variance among variables that might be common variance. The higher the proportion, the higher the KMO-value, the more suited the data is to factor analysis.[^o2]

:::

## History {#History}

[Henry Kaiser](wikipedia://en/57320838) introduced a Measure of Sampling Adequacy (MSA) of factor analytic data matrices in 1970.[^o4] Kaiser and Rice then modified it in 1974.[^o5]

## Measure of sampling adequacy {#Measure_of_sampling_adequacy}

The measure of sampling adequacy is calculated for each indicator as

$$MSA_j = \frac{\displaystyle \sum_{k\neq j} r_{jk}^2}{\displaystyle \sum_{k\neq j} r_{jk}^2+\sum_{k\neq j} p_{jk}^2}$$

and indicates to what extent an indicator is suitable for a factor analysis.

::: {#o8 .statement cue=named-heading name="Kaiser–Meyer–Olkin criterion"}

## Kaiser–Meyer–Olkin criterion {#Kaiser–Meyer–Olkin_criterion}

The Kaiser–Meyer–Olkin criterion is calculated and returns values between 0 and 1.

$$KMO = \frac{\displaystyle \underset{j\neq k}{\sum\sum} r_{jk}^2}{\displaystyle \underset{j\neq k}{\sum\sum} r_{jk}^2+\underset{j\neq k}{\sum\sum} p_{jk}^2}$$

Here $r_{jk}$ is the correlation between the variable in question and another, and $p_{jk}$ is the [partial correlation](wikipedia://en/8771567).

This is a function of the squared elements of the \`image' matrix compared to the squares of the original correlations. The overall MSA as well as estimates for each item are found. The index is known as the Kaiser–Meyer–Olkin (KMO) index.[^o9]

:::

## Interpretation of result {#Interpretation_of_result}

In flamboyant fashion, Kaiser proposed that a KMO > 0.9 was marvelous, in the 0.80s, meritorious, in the 0.70s, middling, in the 0.60s, mediocre, in the 0.50s, miserable, and less than 0.5 would be unacceptable. [^o5] In general, KMO values between 0.8 and 1 indicate the sampling is adequate. KMO values less than 0.6 indicate the sampling is not adequate and that remedial action should be taken. In contrast, others set this cutoff value at 0.5.[^o11] A KMO value close to zero means that there are large partial correlations compared to the sum of correlations. In other words, there are widespread correlations which would be a large problem for factor analysis.[^o2]

An alternative measure of whether a matrix is factorable is the [Bartlett test](https://en.wikipedia.org/wiki/Bartlett_test), which tests the degree that the matrix deviates from an [identity matrix](wikipedia://en/59718).[^o2]

## Example in R {#Example_in_R}

If the following is run in [R](wikipedia://en/376707) with the library(psych)

```R
library(psych)
set.seed(5L)
five.samples <- data.frame("A"=rnorm(100), "B"=rnorm(100), "C"=rnorm(100),
                           "D"=rnorm(100), "E"=rnorm(100))
cor(five.samples)
KMO(five.samples)
```

The following is produced:

```R
Kaiser-Meyer-Olkin factor adequacy
Call: KMO(r = five.samples)
Overall MSA =  0.53
MSA for each item = 
   A    B    C    D    E 
0.52 0.56 0.52 0.48 0.54 
```

This shows that the data is not that suited to Factor Analysis.[^o13]
