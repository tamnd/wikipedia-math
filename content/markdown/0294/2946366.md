# Saturated measure

::: {#o1 .subject cue=lead name="Saturated measure"}

In [mathematics](wikipedia://en/18831), a [measure](wikipedia://en/19873) is said to be **saturated** if every locally measurable set is also [measurable](https://en.wikipedia.org/wiki/Measurable).[^o2] A set $E$, not necessarily measurable, is said to be a **locally measurable set** if for every measurable set $A$ of finite measure, $E \cap A$ is measurable. [$\sigma$-finite](wikipedia://en/4316174) measures and measures arising as the restriction of [outer measures](wikipedia://en/488605) are saturated.

:::
