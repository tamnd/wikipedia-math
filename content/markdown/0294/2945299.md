# Lefschetz zeta function

::: {#o1 .subject cue=lead name="Lefschetz zeta function"}

In [mathematics](wikipedia://en/18831), the **[Lefschetz](https://en.wikipedia.org/wiki/Lefschetz) [zeta-function](https://en.wikipedia.org/wiki/Zeta_function)** is a tool used in topological periodic and [fixed point](wikipedia://en/449738) theory, and [dynamical systems](https://en.wikipedia.org/wiki/Dynamical_systems). Given a [continuous map](https://en.wikipedia.org/wiki/Continuous_map) $f\colon X\to X$, the zeta-function is defined as the formal series

:::

$$\zeta_f(t) = \exp \left( \sum_{n=1}^\infty L(f^n) \frac{t^n}{n} \right),$$

where $L(f^n)$ is the [Lefschetz number](https://en.wikipedia.org/wiki/Lefschetz_number) of the $n$-th [iterate](wikipedia://en/1448702) of $f$. This zeta-function is of note in topological periodic point theory because it is a single invariant containing information about all iterates of $f$.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

The identity map on $X$ has Lefschetz zeta function

$$\frac{1}{(1-t)^{\chi(X)}},$$

where $\chi(X)$ is the [Euler characteristic](wikipedia://en/148420) of $X$, i.e., the Lefschetz number of the identity map.

For a less trivial example, let $X = S^1$ be the [unit circle](wikipedia://en/27072071), and let $f\colon S^1\to S^1$ be reflection in the *x*-axis, that is, $f(\theta) = -\theta$. Then $f$ has Lefschetz number 2, while $f^2$ is the identity map, which has Lefschetz number 0. Likewise, all odd iterates have Lefschetz number 2, while all even iterates have Lefschetz number 0. Therefore, the zeta function of $f$ is

$$\begin{aligned} \zeta_f(t) & = \exp \left( \sum_{n=1}^\infty \frac{2t^{2n+1}}{2n+1} \right) \\ &=\exp \left( \left\{2\sum_{n=1}^\infty \frac{t^n}{n}\right\} -\left \{2 \sum_{n=1}^\infty\frac{t^{2n}}{2n}\right\} \right) \\ &=\exp \left(-2\log(1-t)+\log(1-t^2)\right)\\ &=\frac{1-t^2}{(1-t)^2} \\ &=\frac{1+t}{1-t} \end{aligned}$$

:::

::: {#o5 .statement cue=named-heading name="Formula"}

## Formula {#Formula}

If *f* is a continuous map on a compact manifold *X* of dimension *n* (or more generally any compact polyhedron), the zeta function is given by the formula

$$\zeta_f(t)=\prod_{i=0}^{n}\det(1-t f_\ast|H_i(X,\mathbf{Q}))^{(-1)^{i+1}}.$$

Thus it is a rational function. The polynomials occurring in the numerator and denominator are essentially the characteristic polynomials of the map induced by *f* on the various homology spaces.

:::

## Connections {#Connections}

This generating function is essentially an [algebraic](wikipedia://en/18716923) form of the [Artin–Mazur zeta function](wikipedia://en/1342156), which gives [geometric](wikipedia://en/18973446) information about the fixed and periodic points of *f*.
