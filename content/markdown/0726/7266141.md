# Strongly positive bilinear form

::: {#o1 .subject cue=lead name="Strongly positive bilinear form"}

A [bilinear form](wikipedia://en/449477), *a*(•,•) whose arguments are elements of [normed vector space](wikipedia://en/21538) *V* is a **strongly positive bilinear form** if and only if there exists a constant, *c*>0, such that

:::

$$a(u,u) \geq c \cdot \|u\|^2$$

for all $u\in V$ where $\|\cdot\|$ is the norm on *V*.
