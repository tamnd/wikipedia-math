# Graphical password

::: {#o1 .subject cue=lead name="Graphical password"}

A **graphical password** or **graphical user authentication** is a form of [authentication](wikipedia://en/47967) using [images](wikipedia://en/71925) rather than [letters](https://en.wikipedia.org/wiki/Letter_%28alphabet%29), [digits](wikipedia://en/280582), or [special characters](https://en.wikipedia.org/wiki/Special_characters). The type of images used and the ways, in which users interact with them vary between implementations.

:::

## Content types and mechanisms {#Content_types_and_mechanisms}

### Image sequence {#Image_sequence}

Graphical passwords frequently require the user to select images in a particular order or respond to images presented in a particular order.[^o11]

### Image-generated text {#Image-generated_text}

CAPTCHA Another graphical password solution creates a [one-time password](wikipedia://en/1190077) using a randomly generated grid of images. Each time the user is required to authenticate, they look for the images that fit their pre-chosen categories and enter the randomly generated alphanumeric character that appears in the image to form the one-time password.[^o12][^o13]

### Facial recognition {#Facial_recognition}

One system requires users to select a series of [faces](https://en.wikipedia.org/wiki/Face) as a password, utilizing the [human brain](https://en.wikipedia.org/wiki/Human_brain)'s ability to [recall faces](https://en.wikipedia.org/wiki/Face_perception) easily.[^o10]

### Draw-a-Secret (DAS) {#Draw-a-Secret_(DAS)}

[Draw-a-Secret](https://en.wikipedia.org/wiki/Draw_a_Secret) is a type of graphical password that requires the user to draw a picture over a grid. The user must exactly remember the user-drawn gestures in order to be authenticated. A larger stroke count corresponds with an increase in security, since it is harder for an attacker to copy the strokes and the order in which they are performed.[^o7]

## Weaknesses {#Weaknesses}

When not used in a private setting, graphical passwords are typically more susceptible than text-based passwords to "shoulder-surfing attacks", in which an attacker learns the password by watching the screen, as a user gains access.[^o14]
