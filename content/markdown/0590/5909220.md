# Grid cell topology

::: {#o1 .subject cue=lead name="Grid cell topology"}

The **grid cell topology** is studied in [digital topology](wikipedia://en/5907688) as part of the theoretical basis for (low-level) algorithms in [computer image analysis](https://en.wikipedia.org/wiki/Computer_image_analysis) or [computer graphics](https://en.wikipedia.org/wiki/Computer_graphics).

:::

The elements of the *n*-dimensional grid cell [topology](wikipedia://en/29954) (*n* ≥ 1) are all *n*-dimensional grid cubes and their *k*-dimensional faces ( for 0 ≤ *k* ≤ *n*−1); between these a [partial order](https://en.wikipedia.org/wiki/Partial_order) *A* ≤ *B* is defined if *A* is a subset of *B* (and thus also dim(*A*) ≤ dim(*B*)). The grid cell topology is the [Alexandrov topology](wikipedia://en/542198) (open sets are up-sets) with respect to this partial order. (See also [poset topology](wikipedia://en/5909536).)

[Alexandrov](https://en.wikipedia.org/wiki/Pavel_Sergeevich_Alexandrov) and [Hopf](wikipedia://en/543082) first introduced the grid cell topology, for the [two-dimensional](https://en.wikipedia.org/wiki/Two-dimensional) case, within an exercise in their text *Topologie* I (1935).

A recursive method to obtain *n*-dimensional grid cells and an intuitive definition for grid cell manifolds can be found in Chen, 2004. It is related to [digital manifolds](wikipedia://en/27123668).
