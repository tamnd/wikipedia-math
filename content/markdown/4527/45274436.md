# Rules extraction system family

::: {#o1 .subject cue=lead name="Rules extraction system family"}

The **rules extraction system (RULES) family** is a [family](https://en.wikipedia.org/wiki/Strategy_pattern) of [inductive learning](https://en.wikipedia.org/wiki/Observational_learning) that includes several covering [algorithms](wikipedia://en/775). This [family](https://en.wikipedia.org/wiki/Strategy_pattern) is used to build a [predictive model](wikipedia://en/2538775) based on given [observation](https://en.wikipedia.org/wiki/Observation). It works based on the concept of [separate-and-conquer](wikipedia://en/201154) to directly [induce rules](https://en.wikipedia.org/wiki/Rule_induction) from a given [training set](wikipedia://en/1514392) and build its [knowledge repository](https://en.wikipedia.org/wiki/Knowledge_base).

:::

[Algorithms](wikipedia://en/775) under RULES [family](https://en.wikipedia.org/wiki/Strategy_pattern) are usually available in [data mining](wikipedia://en/42253) tools, such as KEEL and [WEKA](https://en.wikipedia.org/wiki/Weka_%28machine_learning%29), known for [knowledge extraction](https://en.wikipedia.org/wiki/Knowledge_extraction) and [decision making](https://en.wikipedia.org/wiki/Decision-making_software).

## Overview {#Overview}

RULES [family algorithms](https://en.wikipedia.org/wiki/Strategy_pattern) are mainly used in [data mining](wikipedia://en/42253) to create a [model](https://en.wikipedia.org/wiki/Model) that predicts the actions of a given [input](https://en.wikipedia.org/wiki/Input/output) features. It goes under the umbrella of [inductive learning](https://en.wikipedia.org/wiki/Observational_learning), which is a [machine learning](wikipedia://en/233488) approach. In this type of [learning](https://en.wikipedia.org/wiki/Learning), the [agent](https://en.wikipedia.org/wiki/Agentic_AI) is usually provided with previous [information](wikipedia://en/18985062) to gain [descriptive knowledge](https://en.wikipedia.org/wiki/Declarative_knowledge) based on the given historical data. Thus, it is a [supervised learning](wikipedia://en/20926) paradigm that works as a [data analysis](wikipedia://en/2720954) tool, which uses the [knowledge](https://en.wikipedia.org/wiki/Knowledge) gained through [training](https://en.wikipedia.org/wiki/Training) to reach a general conclusion and identify new objects using the produced [classifier](wikipedia://en/34062152).

[Inductive learning](https://en.wikipedia.org/wiki/Observational_learning) had been divided into two types: [decision tree](wikipedia://en/232602) (DT) and [covering algorithms](wikipedia://en/870399) (CA). DTs discover rules using [decision tree](wikipedia://en/232602) based on the concept of [divide-and-conquer](wikipedia://en/201154), while CA directly induces rules from the [training set](wikipedia://en/1514392) based on the concept of [separate and conquers](wikipedia://en/201154). Although DT [algorithms](wikipedia://en/775) was well recognized in the past few decades, CA started to attract the attention due to its [direct rule induction](wikipedia://en/18881) property, as emphasized by Kurgan et al.[^o3] Under this type of inductive learning approach, several families have been developed and improved. RULES family,[^o4] known as rule extraction system, is one family of covering algorithms that separate each instance or example when inducing the best rules. In this family, the resulting rules are stored in an ‘IF condition THEN conclusion’ structure. It has its own induction procedure that is used to induce the best rules and build the knowledge repository.

## Induction procedure {#Induction_procedure}

To induce the best rules based on a given observation, RULES family start by selecting (separating) a seed example to build a rule, condition by condition. The rule that covers the most positive examples and the least negative examples are chosen as the best rule of the current seed example. It allows the best rule to cover some negative examples to handle the increase flexibility and reduce the [overfitting](wikipedia://en/173332) problem and noisy data in the rule induction. When the coverage performance reaches a specified threshold, it marks the examples that match the induced rules without deletion. This prevents the repetition of discovering the same rule as well as preserves the coverage accuracy and the generality of new rules. After that, the algorithm is repeated to select (conquer) another seed example until all the examples are covered. Hence, only one rule can be generated at each step.

## Algorithms {#Algorithms}

Several versions and algorithms have been proposed in RULES family, and can be summarized as follows:

- **RULES-1** is the first version in RULES family and was proposed by prof. Pham and prof. Aksoy in 1995.[^o8]
- **RULES-2** is an upgraded version of RULES-1, in which every example is studied separately.[^o9]
- **RULES-3** is another version that contained all the properties of RULES-2 as well as other additional features to generates more general rules.[^o10]
- **RULES-3Plus** is an extended version of RULES-3 with two additional functionalities.[^o11]
- **RULES-4** is the first incremental version in the RULES family.[^o12]
- **RULES-5** is the first RULES version that handles continuous attributes without discretization. It was also extended to produce RULES-5+,[^o13] which improves the performance using a new rule space representation scheme.[^o14]
- **RULES-6** is a scalable version of RULES family developed as an extension of RULES-3 plus.[^o15]
- **RULES-F** is an extension of RULES-5 that handles not only continuous attributes but also continuous classes. A new rule space representation scheme was also integrated to produce an extended version called RULES-F+.[^o13][^o16]
- **RULES-SRI** is another scalable RULES algorithm, developed to improve RULES-6 scalability.[^o17]
- **Rule Extractor-1 (REX-1)** is an improvement of RULES-3, RULES-3 Plus, and RULES-4 to shortened the process time and produced simpler models with fewer rules.[^o18]
- **RULES-IS** an incremental algorithm inspired by the immune systems.[^o19]
- **RULES-3EXT** is an extension of RULES-3 with additional features.[^o20]
- **RULES-7** is an extension of RULES-6, in which it applies specialization over one seed at a time.[^o21]
- **RULES-8** is an improved version that deals with continuous attributes online.[^o22]
- **RULES-TL** is another scalable algorithm that was proposed to enhance the performance and speed while introducing more intelligent aspects.[^o23]
- **RULES-IT** is an incremental version that is built based on RULES-TL to incrementally deal with large and incomplete problems.[^o24]

## Applications {#Applications}

Covering algorithms, in general, can be applied to any machine learning application field, as long as it supports its data type. Witten, Frank and Hall identified six main fielded applications that are actively used as ML applications, including sales and marketing, judgment decisions, image screening, load forecasting, diagnosis, and web mining.[^o27]

RULES algorithms, in particular, were applied in different manufacturing and engineering applications.[^o28] RULES-3 EXT was also applied over signature verification and the algorithm performance was verified by Aksoy and Mathkour.[^o29] Recently, Salem and Schmickl[^o30] have studied the efficiency of RULEs-4 in predating agent's density.
