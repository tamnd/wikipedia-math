# PSPP

PPSSPP

::: {#o2 .subject cue=lead name="PSPP"}

**PSPP** is a [free software](https://en.wikipedia.org/wiki/Free_software) application for analysis of sampled data, intended as a free alternative for [IBM SPSS Statistics](wikipedia://en/179088). It has a [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface)[^o3] and conventional [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface). It is written in [C](https://en.wikipedia.org/wiki/C_%28programming_language%29) and uses [GNU Scientific Library](https://en.wikipedia.org/wiki/GNU_Scientific_Library) for its mathematical routines. The name has "no official acronymic expansion".[^o4]

:::

## Features {#Features}

This software provides a comprehensive set of capabilities including frequencies, cross-tabs comparison of means ([t-tests](wikipedia://en/536080) and [one-way ANOVA](wikipedia://en/14344439)), linear regression, logistic regression, reliability ([Cronbach's alpha](wikipedia://en/379269), not failure or [Weibull](wikipedia://en/11772928)), and re-ordering data, non-parametric tests, [factor analysis](wikipedia://en/253492), cluster analysis, principal components analysis, chi-square analysis and more.

At the user's choice, statistical output and graphics are available in [ASCII](https://en.wikipedia.org/wiki/ASCII), [PDF](https://en.wikipedia.org/wiki/PDF), [PostScript](https://en.wikipedia.org/wiki/PostScript), [SVG](https://en.wikipedia.org/wiki/Scalable_Vector_Graphics) or [HTML](https://en.wikipedia.org/wiki/HTML) formats. A range of statistical graphs can be produced, such as [histograms](wikipedia://en/13266), [pie-charts](https://en.wikipedia.org/wiki/Pie-chart), [scree plots](wikipedia://en/11233996), and [np-charts](wikipedia://en/12010034).

PSPP can import [Gnumeric](https://en.wikipedia.org/wiki/Gnumeric) and [OpenDocument](https://en.wikipedia.org/wiki/OpenDocument) [spreadsheets](https://en.wikipedia.org/wiki/Spreadsheet), [Postgres](https://en.wikipedia.org/wiki/Postgres) [databases](https://en.wikipedia.org/wiki/Database), [comma-separated values](https://en.wikipedia.org/wiki/Comma-separated_values) and [ASCII](https://en.wikipedia.org/wiki/ASCII) files. It can export files in the SPSS 'portable' and 'system' file formats and to ASCII files. Some of the libraries used by PSPP can be accessed programmatically; [PSPP-Perl](http://search.cpan.org/~pdonelan/PSPP-Perl-0.7.2.20090730/lib/PSPP.pm) provides an interface to the libraries used by PSPP.

### Origins {#Origins}

The PSPP project (originally called "Fiasco") was born at the end of the 1990s as a [free software](https://en.wikipedia.org/wiki/Free_software) replacement for [SPSS](wikipedia://en/179088), which is a data management and analysis tool, at the time produced by [SPSS Inc.](https://en.wikipedia.org/wiki/SPSS_Inc.) The nature of SPSS's [proprietary](https://en.wikipedia.org/wiki/Proprietary_software) licensing and the presence of [digital restrictions management](https://en.wikipedia.org/wiki/Digital_restrictions_management) motivated the author to write an alternative which later became functionally identical, but with permission for everyone to copy, modify and share.

## Third Party Reviews {#Third_Party_Reviews}

In the book "SPSS [For Dummies](https://en.wikipedia.org/wiki/For_Dummies)", the author discusses PSPP under the heading of "Ten Useful Things You Can Find on the Internet".[^o8] Another review of free to use statistical software also finds that the statistical results from PSPP match statistical results for SAS, for frequencies, means, correlation and regression.[^o9]

## Research about PSPP {#Research_about_PSPP}

One study found that students who used PSPP became more positive about learning statistics while using PSPP.[^o11]

## Examples of Research Performed using PSPP {#Examples_of_Research_Performed_using_PSPP}

Among the studies done using PSPP are one about posttraumatic stress in adolescents,[^o13] another about nutrition software,[^o14] and another about internet addiction.[^o15]
