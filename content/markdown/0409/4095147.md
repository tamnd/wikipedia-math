# Value (mathematics)

::: {#o1 .subject cue=lead name="Value"}

In [mathematics](wikipedia://en/18831), a mathematical **value** is a broad term that refers to any definite entity that can be manipulated with [operators](wikipedia://en/22213) according to the well-defined rules of its [mathematical system](https://en.wikipedia.org/wiki/Mathematical_system).

:::

Certain values can correspond to the real world, although most values in mathematics generally exist purely as abstract objects with no connection to the real world.

## Numerical values {#Numerical_values}

*[Numbers](wikipedia://en/21690)* (specifically the [reals](wikipedia://en/20646438)) are values that represent [quantities](wikipedia://en/691277). In that sense, **numerical values** are values that comprises or are made up of said numbers. In simpler terms, a numerical value are represented by numbers. Both numbers and numerical values tend to be synonymous and interchangeable with each other.[^o3]

The following table shows certain values that are considered numerical values themselves.

::: {#o4 .table cue=table}

| Value | Brief description |
|---|---|
| [Digit value](wikipedia://en/280582) | Digit value of a place of a number would simply be its digit or numeral. |
| [Place value](wikipedia://en/437052) | The contribution of a digit to the value of a number is the value of the digit multiplied by a factor of 10 raised to the power of the digit's position. |
| [Ratio](wikipedia://en/87837) | How many times one number contains another. |
| [Rates](wikipedia://en/332372) | The [quotient](wikipedia://en/332640) of two quantities. |
| [Percentage](wikipedia://en/64493) | A number or ratio expressed as a fraction of 100 |
| [Central tendencies](https://en.wikipedia.org/wiki/Central_tendency) | A typical value for a [probability distribution](wikipedia://en/23543). |

:::

Because numerical values can also be a part of composite objects, various terminologies are given. For example, a [complex number](wikipedia://en/5826) $z=a+bi$, has $a$ as considered its *[real part](https://en.wikipedia.org/wiki/Real_part)*, likewise $b$ as its *[imaginary part](https://en.wikipedia.org/wiki/Imaginary_part)*.

## Variables {#Variables}

A **[variable](wikipedia://en/3728109)** is a symbol that represents an unspecified object. Homogeneous to numbers, variables themselves are considered as values.

## Functions {#Functions}

The **value** of a [function](wikipedia://en/185427), given the value(s) assigned to its [argument](wikipedia://en/32842052)(s), is the quantity assumed by the function for these argument values.[^o13][^o14]

For example, if the function $f$ is defined by $f(x) = 2x^2 - 3x + 1$, then assigning the value 3 to its argument $x$ yields the function value 10, since $f(3) = 2\cdot 3^2 - 3\cdot 3 + 1 = 10$.

If the variable, expression or function only assumes [real](wikipedia://en/20646438) values, it is called **real-valued**. Likewise, a **complex-valued** variable, expression or function only assumes [complex values](https://en.wikipedia.org/wiki/Complex_value).
