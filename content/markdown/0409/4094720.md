# Latent class model

::: {#o1 .subject cue=lead name="Latent class model"}

In [statistics](wikipedia://en/26685), a **latent class model** (**LCM**) is a model for [clustering](wikipedia://en/669675) [multivariate](wikipedia://en/19384) [discrete](wikipedia://en/46561894) data. It assumes that the data arise from a mixture of [discrete distributions](https://en.wikipedia.org/wiki/Discrete_distribution), within each of which the variables are independent. It is called a latent class model because the class to which each data point belongs is unobserved (or latent).

:::

**Latent class analysis** (**LCA**) is a subset of [structural equation modeling](wikipedia://en/2007748) used to find groups or subtypes of cases in multivariate [categorical data](https://en.wikipedia.org/wiki/Categorical_data). These groups or subtypes of cases are called "latent classes".[^o2][^o3]

When faced with the following situation, a researcher might opt to use LCA to better understand the data: [Symptoms](https://en.wikipedia.org/wiki/Symptoms) a, b, c, and d have been recorded in a variety of patients diagnosed with diseases X, Y, and Z. [Disease](https://en.wikipedia.org/wiki/Disease) X is associated with symptoms a, b, and c; disease Y is linked to symptoms b, c, and d; and disease Z is connected to symptoms a, c, and d.

In this context, the LCA would attempt to detect the presence of latent classes (i.e., the disease entities), thus creating patterns of association in the symptoms. As in [factor analysis](wikipedia://en/253492), LCA can also be used to classify cases according to their [maximum likelihood](https://en.wikipedia.org/wiki/Maximum_likelihood) class membership probability.[^o2][^o4]

The key criterion for resolving the LCA is identifying latent classes in which the observed symptom associations are effectively rendered null. This is because within each class, the diseases responsible for the symptoms create a structure of dependencies. As a result, the symptoms become [conditionally independent](https://en.wikipedia.org/wiki/Conditionally_independent), meaning that, given the class a case belongs to, the symptoms are no longer related to one another.[^o2]

## Model {#Model}

Within each latent class, the observed variables are [statistically independent](https://en.wikipedia.org/wiki/Statistically_independent)—an essential aspect of latent class modeling. Usually, the observed variables are statistically dependent. By introducing the latent variable, independence is restored in the sense that within classes, variables are independent ([local independence](wikipedia://en/9269164)). Therefore, the association between the observed variables is explained by the classes of the latent variable (McCutcheon, 1987).

In one form, the LCM is written as

$$p_{i_1, i_2, \ldots, i_N} \approx \sum_t^T p_t \, \prod_n^N p^n_{i_n, t},$$

where $T$ is the number of latent classes and $p_t$ are the so-called recruitment or unconditional probabilities that should sum to one. $p^n_{i_n, t}$ are the marginal or conditional probabilities.

For a two-way latent class model, the form is

$$p_{ij} \approx \sum_t^T p_t \, p_{it} \, p_{jt}.$$

This two-way model is related to [probabilistic latent semantic analysis](wikipedia://en/2088675) and [non-negative matrix factorization](wikipedia://en/3681279).

The probability model used in LCA is closely related to the [Naive Bayes classifier](wikipedia://en/87339). The main difference is that in LCA, the class membership of an individual is a latent variable, whereas in Naive Bayes classifiers, the class membership is an observed label.

## Related methods {#Related_methods}

There are a number of methods with distinct names and uses that share a common relationship. [Cluster analysis](wikipedia://en/669675) is, like LCA, used to discover [taxon](https://en.wikipedia.org/wiki/Taxon)-like groups of cases in data. [Multivariate mixture estimation](wikipedia://en/871681) (MME) is applicable to continuous data and assumes that such data arise from a mixture of distributions, such as a set of heights arising from a mixture of men and women. If a multivariate mixture estimation is constrained so that measures must be uncorrelated within each distribution, it is termed [latent profile analysis](https://en.wikipedia.org/wiki/Latent_profile_analysis). Modified to handle discrete data, this constrained analysis is known as LCA. Discrete latent trait models further constrain the classes to form from segments of a single dimension, allocating members to classes based on that dimension. An example would be assigning cases to [social classes](https://en.wikipedia.org/wiki/Social_classes) based on ability or [merit](https://en.wikipedia.org/wiki/Meritocracy).

In a practical instance, the variables could be [multiple choice](https://en.wikipedia.org/wiki/Multiple_choice) items of a political questionnaire. In this case, the data consists of an N-way [contingency table](wikipedia://en/935515) with answers to the items for a number of respondents. In this example, the latent variable refers to [political opinion](https://en.wikipedia.org/wiki/Political_opinion), and the latent classes to political groups. Given group membership, the [conditional probabilities](https://en.wikipedia.org/wiki/Conditional_probabilities) specify the chance that certain answers are chosen.

## Application {#Application}

LCA may be used in many fields, such as: [collaborative filtering](https://en.wikipedia.org/wiki/Collaborative_filtering),[^o9] *[Behavior Genetics](https://en.wikipedia.org/wiki/Behavior_Genetics)*[^o10] and [Evaluation of diagnostic tests](http://www.nature.com/nrmicro/journal/v8/n12_supp/full/nrmicro1523.html).[^o11]

:::
