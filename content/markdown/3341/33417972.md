# Cantor tree surface

::: {#o1 .subject cue=lead name="Cantor tree surface"}

*Image: Fractal-tree.png.* The bark of a fractal tree, splitting in two directions at each branch point, forms a Cantor tree surface. Drilling a hole through the tree at each branch point would produce a blooming Cantor tree.

*Image: Alexander horned sphere.png.* An [Alexander horned sphere](wikipedia://en/685665). Its non-singular points form a Cantor tree surface.

In [dynamical systems](wikipedia://en/9087), the **Cantor tree** is an infinite-[genus](wikipedia://en/61891) surface [homeomorphic](wikipedia://en/13660) to a [sphere](wikipedia://en/27859) with a [Cantor set](wikipedia://en/6172) removed. The **blooming Cantor tree** is a Cantor tree with an infinite number of handles added in such a way that every [end](wikipedia://en/6862105) is a limit of handles.

:::
