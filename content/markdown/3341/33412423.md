# Size (statistics)

::: {#o1 .subject cue=lead name="Size"}

In [statistics](wikipedia://en/26685), the **size** of a [test](https://en.wikipedia.org/wiki/Statistical_test) is the probability of [falsely rejecting](https://en.wikipedia.org/wiki/Type_I_error#Type_I_error) the [null hypothesis](https://en.wikipedia.org/wiki/Null_hypothesis). That is, it is the probability of making a [type I error](https://en.wikipedia.org/wiki/Type_I_error). It is denoted by the Greek letter α (alpha).

:::

For a [simple hypothesis](https://en.wikipedia.org/wiki/Simple_hypothesis),

$$\alpha = P(\text{test rejects } H_0 \mid H_0).$$

In the case of a [composite null hypothesis](https://en.wikipedia.org/wiki/Composite_hypothesis), the size is the supremum over all data generating processes that satisfy the null hypotheses.[^o2]

$$\alpha = \sup_{h\in H_0} P(\text{test rejects } H_0 \mid h).$$

A test is said to have [significance level](https://en.wikipedia.org/wiki/Significance_level) $\alpha$ if its size is less than or equal to $\alpha$.[^o3][^o4] In many cases the size and level of a test are equal.
