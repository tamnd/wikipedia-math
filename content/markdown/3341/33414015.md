# Predictable process

::: {#o1 .subject cue=lead name="Predictable process"}

In [stochastic analysis](https://en.wikipedia.org/wiki/Stochastic_analysis), a part of the mathematical theory of [probability](wikipedia://en/22934), a **predictable process** is a [stochastic process](wikipedia://en/47895) whose value is knowable at a prior time. The predictable processes form the smallest class that is closed under taking limits of sequences and contains all [adapted](wikipedia://en/6583420) left-continuous processes.

:::

## Mathematical definition {#Mathematical_definition}

### Discrete-time process {#Discrete-time_process}

Given a [filtered probability space](https://en.wikipedia.org/wiki/Filtered_probability_space) $(\Omega,\mathcal{F},(\mathcal{F}_n)_{n \in \mathbb{N}},\mathbb{P})$, then a stochastic process $(X_n)_{n \in \mathbb{N}}$ is *predictable* if $X_{n+1}$ is [measurable](wikipedia://en/44055) with respect to the [σ-algebra](https://en.wikipedia.org/wiki/Sigma_algebra) $\mathcal{F}_n$ for each *n*.[^o4]

### Continuous-time process {#Continuous-time_process}

Given a filtered probability space $(\Omega,\mathcal{F},(\mathcal{F}_t)_{t \geq 0},\mathbb{P})$, then a [continuous-time stochastic process](wikipedia://en/12466697) $(X_t)_{t \geq 0}$ is *predictable* if $X$, considered as a mapping from $\Omega \times \mathbb{R}_{+}$, is measurable with respect to the σ-algebra generated by all left-continuous adapted processes.[^o6] This [σ-algebra](wikipedia://en/29586) is also called the **predictable σ-algebra**.

::: {#o8 .example cue=heading name="Examples"}

## Examples {#Examples}

- Every [deterministic process](wikipedia://en/522958) is a predictable process.
- Every continuous-time adapted process that is [left continuous](https://en.wikipedia.org/wiki/Left_continuous) is a predictable process.
