# Fuzzy relation

::: {#o1 .subject cue=lead name="Fuzzy relation"}

*Image: Cartesian Product qtl1.svg.* Cartesian Product

A **fuzzy relation** is the cartesian product of mathematical fuzzy sets.[^o2] Two [fuzzy sets](wikipedia://en/56601) are taken as input, the fuzzy relation is then equal to the cross product of the sets which is created by [vector multiplication](wikipedia://en/22130008). Usually, a rule base is stored in a matrix notation which allows the [fuzzy controller](https://en.wikipedia.org/wiki/Fuzzy_controller) to update its internal values.[^o3][^o4]

:::

From a historical perspective, the first fuzzy relation was mentioned in the year 1971 by [Lotfi A. Zadeh](https://en.wikipedia.org/wiki/Lotfi_A._Zadeh).[^o5]

A practical approach to describe a fuzzy relation is based on a 2d table. At first, a table is created which consists of fuzzy values from 0..1. The next step is to apply the if-then-rules to the values. The resulting numbers are stored in the table as an array.

Fuzzy relations can be utilized in fuzzy databases.[^o6]
