# Morris method

::: {#o1 .subject cue=lead name="Morris method"}

In [applied statistics](https://en.wikipedia.org/wiki/Applied_statistics), the **Morris method** for global [sensitivity analysis](wikipedia://en/620083) is a so-called [one-factor-at-a-time method](wikipedia://en/1759969), meaning that in each run only one input parameter is given a new value. It facilitates a global sensitivity analysis by making a number $r$ of local changes at different points $x(1 \rightarrow r)$ of the possible range of input values.

:::

## Method's details {#Method's_details}

### Elementary effects' distribution {#Elementary_effects'_distribution}

The finite distribution of elementary effects associated with the $i_{th}$ input factor, is obtained by randomly sampling different $x$ from $\Omega$, and is denoted by $F_i$.[^o4]

::: {#o6 .statement kind=statement/generalization cue=heading name="Variations"}

### Variations {#Variations}

In the original work of Morris the two sensitivity measures proposed were respectively the mean, $\mu$, and the [standard deviation](wikipedia://en/27590), $\sigma$, of $F_i$. However, choosing Morris has the drawback that, if the distribution $F_i$ contains negative elements, which occurs when the model is non-monotonic, when computing the mean some effects may cancel each other out. Thus, the measure $\mu$ on its own is not reliable for ranking factors in order of importance. It is necessary to consider at the same time the values of $\mu$ and $\sigma$, as a factor with elementary effects of different signs (that cancel each other out) would have a low value of $\mu$ but a considerable value of $\sigma$ that avoids underestimating the factors.[^o4]

:::

### $\mu*$ {#\mu*}

If the distribution $F_i$ contains negative elements, which occurs when the model is non-monotonic, when computing the mean some effects may cancel each other out. When the goal is to rank factors in order of importance by making use of a single sensitivity measure, scientific advice is to use $\mu*$, which by making use of the [absolute value](wikipedia://en/991), avoids the occurrence of effects of opposite signs.[^o4]

In Revised Morris method $\mu*$ is used to detect input factors with an important overall influence on the output. $\sigma$ is used to detect factors involved in interaction with other factors or whose effect is non-linear.[^o4]

## Method's steps {#Method's_steps}

The method starts by sampling a set of start values within the defined ranges of possible values for all input variables and calculating the subsequent model outcome. The second step changes the values for one variable (all other inputs remaining at their start values) and calculates the resulting change in model outcome compared to the first run. Next, the values for another variable are changed (the previous variable is kept at its changed value and all other ones kept at their start values) and the resulting change in model outcome compared to the second run is calculated. This goes on until all input variables are changed. This procedure is repeated $r$ times (where $r$ is usually taken between 5 and 15), each time with a different set of start values, which leads to a number of $r(k+1)$ runs, where $k$ is the number of input variables. Such number is very efficient compared to more demanding methods for [sensitivity analysis](wikipedia://en/620083).[^o9]

A [sensitivity analysis](wikipedia://en/620083) method widely used to screen factors in models of large dimensionality is the design proposed by Morris.[^o10] The Morris method deals efficiently with models containing hundreds of input factors without relying on strict assumptions about the model, such as additivity or monotonicity of the model input-output relationship. The Morris method is simple to understand and implement, and its results are easily interpreted. Furthermore, it is economic in the sense that it requires a number of model evaluations that is linear in the number of model factors. The method can be regarded as global as the final measure is obtained by averaging a number of local measures (the elementary effects), computed at different points of the input space.[^o9]
