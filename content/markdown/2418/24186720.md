# LCF notation

*Image: Nauru graph LCF.svg.* The [Nauru graph](wikipedia://en/24052345)[^o1] has LCF notation $[5, -9, 7, -7, 9, -5]^{4}$.

::: {#o2 .subject cue=lead name="LCF notation"}

In the [mathematical](https://en.wikipedia.org/wiki/Mathematical) field of [graph theory](wikipedia://en/12401), **LCF notation** or **LCF code** is a notation devised by [Joshua Lederberg](https://en.wikipedia.org/wiki/Joshua_Lederberg), and extended by [H. S. M. Coxeter](https://en.wikipedia.org/wiki/Harold_Scott_MacDonald_Coxeter) and [Robert Frucht](wikipedia://en/27069553), for the representation of [cubic graphs](wikipedia://en/980508) that contain a [Hamiltonian cycle](wikipedia://en/244437).[^o3][^o4] The cycle itself includes two out of the three adjacencies for each [vertex](wikipedia://en/638899), and the LCF notation specifies how far along the cycle each vertex's third neighbor is. A single graph may have multiple different representations in LCF notation.

:::

## Description {#Description}

In a Hamiltonian graph, the vertices can be [arranged in a cycle](wikipedia://en/38903361), which accounts for two edges per vertex. The third edge from each vertex can then be described by how many positions clockwise (positive) or counter-clockwise (negative) it leads. The basic form of the LCF notation is just the sequence of these numbers of positions, starting from an arbitrarily chosen vertex and written in square brackets. The numbers between the brackets are interpreted [modulo](wikipedia://en/20087) *N*, where *N* is the number of vertices. Entries congruent modulo *N* to 0, 1, or *N* − 1 do not appear in this sequence of numbers,[^o6] because they would correspond either to a [loop](wikipedia://en/1449083) or [multiple adjacency](wikipedia://en/1774970), neither of which are permitted in simple graphs.

Often the pattern repeats, and the number of repetitions can be indicated by a superscript in the notation. For example, the [Nauru graph](wikipedia://en/24052345),[^o1] shown on the right, has four repetitions of the same six offsets, and can be represented by the LCF notation \[5, −9, 7, −7, 9, −5\]<sup>4</sup>. A single graph may have multiple different LCF notations, depending on the choices of Hamiltonian cycle and starting vertex.

::: {#o8 .application cue=heading name="Applications"}

## Applications {#Applications}

LCF notation is useful in publishing concise descriptions of Hamiltonian cubic graphs, such as the examples below. In addition, some software packages for manipulating graphs include utilities for creating a graph from its LCF notation.[^o9]

If a graph is represented by LCF notation, it is straightforward to test whether the graph is [bipartite](wikipedia://en/244431): this is true if and only if all of the offsets in the LCF notation are odd.[^o10]

## Extended LCF notation {#Extended_LCF_notation}

A more complex extended version of LCF notation was provided by Coxeter, Frucht, and Powers in later work.[^n2] In particular, they introduced an "anti-palindromic" notation: if the second half of the numbers between the square brackets was the reverse of the first half, but with all the signs changed, then it was replaced by a semicolon and a dash. The Nauru graph satisfies this condition with \[5, −9, 7, −7, 9, −5\]<sup>4</sup>, and so can be written \[5, −9, 7; −\]<sup>4</sup> in the extended notation.[^n3]
