# Lukacs's proportion-sum independence theorem

::: {#o1 .subject cue=lead name="Lukacs's proportion-sum independence theorem"}

In [statistics](wikipedia://en/26685), **Lukacs's proportion-sum independence theorem** is a result that is used when studying proportions, in particular the [Dirichlet distribution](wikipedia://en/1117833). It is named after [Eugene Lukacs](https://en.wikipedia.org/wiki/Eugene_Lukacs).[^o2]

:::

::: {#o4 .statement cue=heading name="The theorem"}

## The theorem {#The_theorem}

If *Y*<sub>1</sub> and *Y*<sub>2</sub> are non-degenerate, [independent](https://en.wikipedia.org/wiki/Statistical_independence) [random variables](wikipedia://en/25685), then the random variables

$$W=Y_1+Y_2\text{ and }P = \frac{Y_1}{Y_1+Y_2}$$

are independently distributed [if and only if](wikipedia://en/14922) both *Y*<sub>1</sub> and *Y*<sub>2</sub> have [gamma distributions](wikipedia://en/207079) with the same scale parameter.

::: {#o6 .statement kind=statement/corollary cue=named-heading name="Corollary"}

### Corollary {#Corollary}

Suppose *Y*<sub>*i*</sub>, *i* = 1, ..., *k* be non-degenerate, independent, positive random variables. Then each of *k* − 1 random variables

$$P_i=\frac{Y_i}{\sum_{i=1}^k Y_i}$$

is independent of

$$W=\sum_{i=1}^k Y_i$$

if and only if all the *Y*<sub>*i*</sub> have gamma distributions with the same scale parameter.[^o7]

:::
