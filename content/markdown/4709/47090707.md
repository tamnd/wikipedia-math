# Sylvester graph

::: {#o2 .subject cue=lead name="Sylvester graph"}

The **Sylvester graph** is the unique [distance-regular](https://en.wikipedia.org/wiki/Distance_regular_graph) graph with intersection array $\{5,4,2;1,1,4\}$.[^o3] It is a subgraph of the [Hoffman–Singleton graph](wikipedia://en/4112667).

:::
