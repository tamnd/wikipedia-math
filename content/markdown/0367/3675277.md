# Bochner integral

::: {#o1 .subject cue=lead name="Bochner integral"}

In [mathematics](wikipedia://en/18831), the **Bochner integral**, named for [Salomon Bochner](wikipedia://en/987847), extends the definition of a multidimensional [Lebesgue integral](wikipedia://en/26064288) to functions that take values in a [Banach space](wikipedia://en/3989), as the limit of integrals of [simple functions](wikipedia://en/1890594).

:::

The Bochner integral provides the mathematical foundation for extensions of basic [integral transforms](https://en.wikipedia.org/wiki/Integral_transforms) into more abstract spaces, vector-valued functions, and operator spaces. Examples of such extensions include vector-valued [Laplace transforms](https://en.wikipedia.org/wiki/Laplace_transforms) and abstract [Fourier transforms](https://en.wikipedia.org/wiki/Fourier_transforms).[^o2]

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $(X, \Sigma, \mu)$ be a [measure space](wikipedia://en/45270), and $B$ be a [Banach space](wikipedia://en/3989), and define a measurable function $f : X \to B$. When $B = \mathbb{R}$, we have the standard Lebesgue integral $\int_X f d\mu$, and when $B = \mathbb{R}^n$, we have the standard multidimensional Lebesgue integral $\int_X \vec f d\mu$. For generic Banach spaces, the Bochner integral extends the above cases.

First, define a simple function to be any finite sum of the form

$$s(x) = \sum_{i=1}^n \chi_{E_i}(x) b_i,$$

where the $E_i$ are disjoint members of the $\sigma$-algebra $\Sigma,$ the $b_i$ are distinct elements of $B,$ and χ<sub>E</sub> is the [characteristic function](wikipedia://en/240790) of $E.$ If $\mu\left(E_i\right)$ is finite whenever $b_i \neq 0,$ then the simple function is **integrable**, and the integral is then defined by

$$\int_X \left[\sum_{i=1}^n \chi_{E_i}(x) b_i\right]\, d\mu = \sum_{i=1}^n \mu(E_i) b_i$$

exactly as it is for the ordinary Lebesgue integral.

A measurable function $f : X \to B$ is **Bochner integrable** if there exists a sequence of integrable simple functions $s_n$ such that

$$\lim_{n\to\infty}\int_X \|f-s_n\|_B\,d\mu = 0,$$

where the integral on the left-hand side is an ordinary Lebesgue integral.

In this case, the **Bochner integral** is defined by

$$\int_X f\, d\mu = \lim_{n\to\infty}\int_X s_n\, d\mu.$$

It can be shown that the sequence $\left\{\int_Xs_n\,d\mu \right\}_{n=1}^{\infty}$ is a [Cauchy sequence](wikipedia://en/6085) in the Banach space $B ,$ hence the limit on the right exists. $\lim_{n\to\infty}\int_X s_n\, d\mu$ is an element of $B$.

Furthermore, the limit is independent of the approximating sequence of simple functions $\{s_n\}_{n=1}^{\infty}.$ These remarks show that the integral is well-defined (i.e independent of any choices). It can be shown that a function is Bochner integrable if and only if it lies in the [Bochner space](wikipedia://en/6751583) $L^1.$

:::

## Properties {#Properties}

::: {#o8 .statement kind=statement/fact cue=heading name="Elementary properties"}

### Elementary properties {#Elementary_properties}

Many of the familiar properties of the Lebesgue integral continue to hold for the Bochner integral. Particularly useful is Bochner's criterion for integrability, which states that if $(X, \Sigma, \mu)$ is a measure space, then a Bochner-measurable function $f \colon X \to B$ is Bochner integrable if and only if

$$\int_X \|f\|_B\, \mathrm{d} \mu < \infty.$$

Here, a function $f \colon X \to B$ is called **Bochner measurable** if it is equal $\mu$-almost everywhere to a function $g$ taking values in a separable subspace $B_0$ of $B$, and such that the inverse image $g^{-1}(U)$ of every open set $U$ in $B$ belongs to $\Sigma$. Equivalently, $f$ is the limit $\mu$-almost everywhere of a sequence of countably-valued simple functions.

:::

::: {#o10 .pointer-item cue=pointer name="Hille's theorem"}

### Linear operators {#Linear_operators}

If $T \colon B \to B'$ is a continuous linear operator between Banach spaces $B$ and $B'$, and $f \colon X \to B$ is Bochner integrable, then it is relatively straightforward to show that $T f \colon X \to B'$ is Bochner integrable and integration and the application of $T$ may be interchanged:

$$\int_E T f \, \mathrm{d} \mu = T \int_E f \, \mathrm{d} \mu$$

for all measurable subsets $E \in \Sigma$.

A non-trivially stronger form of this result, known as **Hille's theorem**, also holds for [closed operators](https://en.wikipedia.org/wiki/Closed_operator).[^o11] If $T \colon B \to B'$ is a closed linear operator between Banach spaces $B$ and $B'$ and both $f \colon X \to B$ and $T f \colon X \to B'$ are Bochner integrable, then

$$\int_E T f \, \mathrm{d} \mu = T \int_E f \, \mathrm{d} \mu$$

for all measurable subsets $E \in \Sigma$.

:::

::: {#o13 .statement kind=statement/theorem cue=named-heading name="Dominated convergence theorem"}

### Dominated convergence theorem {#Dominated_convergence_theorem}

A version of the [dominated convergence theorem](wikipedia://en/351853) also holds for the Bochner integral. Specifically, if $f_n \colon X \to B$ is a sequence of measurable functions on a complete measure space tending almost everywhere to a limit function $f$, and if

$$\|f_n(x)\|_B \leq g(x)$$

for almost every $x \in X$, and $g \in L^1(\mu)$, then

$$\int_E \|f-f_n\|_B \, \mathrm{d} \mu \to 0$$

as $n \to \infty$ and

$$\int_E f_n\, \mathrm{d} \mu \to \int_E f \, \mathrm{d} \mu$$

for all $E \in \Sigma$.

If $f$ is Bochner integrable, then the inequality

$$\left\|\int_E f \, \mathrm{d} \mu\right\|_B \leq \int_E \|f\|_B \, \mathrm{d} \mu$$

holds for all $E \in \Sigma.$ In particular, the set function

$$E\mapsto \int_E f\, \mathrm{d} \mu$$

defines a countably-additive $B$-valued [vector measure](wikipedia://en/9399072) on $X$ which is [absolutely continuous](https://en.wikipedia.org/wiki/Absolutely_continuous) with respect to $\mu$.

:::

::: {#o15 .pointer-item cue=pointer name="Radon–Nikodym property"}

## Radon–Nikodym property {#Radon–Nikodym_property}

An important fact about the Bochner integral is that the [Radon–Nikodym theorem](wikipedia://en/338746) fails to hold in general, and instead is a property (the **Radon–Nikodym property**) defining an important class of ″nice″ Banach spaces.

Specifically, if $\mu$ is a measure on $(X, \Sigma),$ then $B$ has the Radon–Nikodym property with respect to $\mu$ if, for every countably-additive [vector measure](wikipedia://en/9399072) $\gamma$ on $(X, \Sigma)$ with values in $B$ which has [bounded variation](wikipedia://en/9399072#The_variation_of_a_vector_measure) and is absolutely continuous with respect to $\mu,$ there is a $\mu$-integrable function $g : X \to B$ such that

$$\gamma(E) = \int_E g\, d\mu$$

for every measurable set $E \in \Sigma.$[^o16]

The Banach space $B$ has the Radon–Nikodym property if $B$ has the Radon–Nikodym property with respect to every finite measure.[^o16] Equivalent formulations include:

- Bounded discrete-time [martingales](wikipedia://en/274536) in $B$ converge a.s.[^o17]
- Functions of bounded-variation into $B$ are differentiable a.e.[^o18]
- For every bounded $D\subseteq B$, there exists $f\in B^*$ and $\delta\in\mathbb{R}^+$ such that $$\{x:f(x)+\delta>\sup{f(D)}\}\subseteq D$$ has arbitrarily small diameter.[^o17]

It is known that the space [$\ell_1$](wikipedia://en/45194) has the Radon–Nikodym property, but [$c_0$](https://en.wikipedia.org/wiki/C0_space) and the spaces $L^{\infty}(\Omega),$ $L^1(\Omega),$ for $\Omega$ an open bounded subset of $\mathbb{R}^n,$ and $C(K),$ for $K$ an infinite compact space, do not.[^o19] Spaces with Radon–Nikodym property include separable dual spaces (this is the [Dunford–Pettis theorem](https://en.wikipedia.org/wiki/Dunford–Pettis_theorem)) and [reflexive spaces](wikipedia://en/210091), which include, in particular, [Hilbert spaces](wikipedia://en/20598932).[^o16]

:::

## Probability {#Probability}

The Bochner integral is used in [probability theory](wikipedia://en/23542) for handling random variables and stochastic processes that take values in a Banach space. The classical convergence theorems—such as the dominated convergence theorem—when applied to the Bochner integral, generalize laws of large numbers and central limit theorems for sequences of Banach-space-valued random variables. Such integrals are central to the analysis of distributions in functional spaces and have applications in fields such as [stochastic calculus](wikipedia://en/228001), [statistical field theory](wikipedia://en/4686460), and [quantum field theory](wikipedia://en/25267).

Let $(\Omega, \mathcal{F}, \mathbb{P})$ be a [probability space](wikipedia://en/43325), and consider a random variable $X \colon \Omega \to B$ taking values in a Banach space $B$. When $X$ is Bochner integrable, its expectation is defined by

$$E[X] = \int_\Omega X \, d\mathbb{P},$$

and inherits the usual linearity and continuity properties of the classical expectation.

### Stochastic process {#Stochastic_process}

Consider $(X_t)_{t\in T}$, a [stochastic process](wikipedia://en/47895) that is Banach-space-valued. The Bochner integral allows us to define the mean function

$$\mu(t) = E[X_t] = \int_\Omega X_t \, d\mathbb{P}$$

whenever each $X_t$ is Bochner integrable. This approach is useful in stochastic partial differential equations, where each $X_t$ is a random element in a functional space.

In [martingale theory](wikipedia://en/274536), a sequence $(M_n)_{n\geq 1}$ of $B$-valued random variables is called a **martingale** with respect to a [filtration](wikipedia://en/726014) $(\mathcal{F}_n)_{n\geq 1}$ if each $M_n$ is $\mathcal{F}_n$-measurable and Bochner integrable, and satisfies

$$E[M_{n+1} \mid \mathcal{F}_n] = M_n.$$

The Bochner integral ensures that conditional expectations are well-defined in this Banach space setting.

### Gaussian measure {#Gaussian_measure}

The Bochner integral allows one to define moments for the [Gaussian measure](wikipedia://en/6572909) on a Banach space. If the Bochner integral exists, then it is equivalent to the [Pettis integral](wikipedia://en/20983125) $\eta$ defined by

$$\langle \eta,b^*\rangle=\int_B \langle x, b^* \rangle \, d\mu(x),$$

where $b^* \in B^*$ and $\langle \cdot, \cdot \rangle$ denotes the [dual pairing](wikipedia://en/609737).

## Extension to locally convex spaces {#Extension_to_locally_convex_spaces}

There are several extensions of the Bochner integral to functions $f\colon X\to E$ with values in some [locally convex space](https://en.wikipedia.org/wiki/Locally_convex_space) $E$ (1975 Rybakov,[^o24] 1981 Blondia,[^o25] 2015 Beckmann and Deitmar[^o26]). The extension by Beckmann and Deitmar uses the original approach of Bochner but generalized to [nets](wikipedia://en/22170) and they distinguish three cases of assumptions on the locally convex space:[^o27]

- $E$ is complete,
- $E$ is [quasi-complete space](wikipedia://en/63948433) and the function $f\colon X\to E$ is bounded,
- $E$ ist quasi-complete and the measure $\mu(X)<\infty$ is finite.

Beckmann and Deitmar use the term of *Bochner-approximability* as a condition for defining the Bochner integral. A function is Bochner-approximable if there exists a net $(s_j)_{j\in J}$ of simple functions such that for every continuous seminorm $p$ on $E$

$$\int_X p(f-s_j)d\mu\to 0$$

They provide several equivalent characterizations of this property.

Blondia defines the extensions to locally convex spaces as follows[^o28]

Let $(X,\Sigma,\mu)$ be $\sigma$-finite, complete measure space and $(E,\mathcal{P})$ a complete Hausdorff locally convex space whose topology is induced by the family of seminorms $\mathcal{P}$. A function $f\colon X\to E$ is called Bochner integrable or strong integrable if there exists a sequence $(f_n)$ such that

- $f_n(\omega)\to f(\omega)$ for $\omega\in X$ $\mu$-almost surely
- $p(f(\omega)-f_n(\omega))\in L^1(X;\mathbb{R})$ for each $n\in \mathbb{N}$ and alle $p\in \mathcal{P}$, i.e.

$$\lim\limits_{n\to \infty}\int_{X} p(f(\omega)-f_n(\omega))d\mu=0.$$

- $\int_A f_n(\omega) d\mu$ converges for each measurable subset $A$ of $X$.
