# Markov logic network

::: {#o1 .subject cue=lead name="Markov logic network"}

A **Markov logic network** (**MLN**) is a [probabilistic logic](wikipedia://en/5017608) which applies the ideas of a [Markov network](https://en.wikipedia.org/wiki/Markov_network) to [first-order logic](wikipedia://en/10983), defining probability distributions on [possible worlds](wikipedia://en/780566) on any given [domain](wikipedia://en/229180).

:::

## History {#History}

In 2002, [Ben Taskar](https://en.wikipedia.org/wiki/Ben_Taskar), [Pieter Abbeel](https://en.wikipedia.org/wiki/Pieter_Abbeel) and [Daphne Koller](https://en.wikipedia.org/wiki/Daphne_Koller) introduced relational Markov networks as templates to specify [Markov networks](https://en.wikipedia.org/wiki/Markov_networks) abstractly and without reference to a specific [domain](wikipedia://en/229180).[^o3][^o4] Work on Markov logic networks began in 2003 by [Pedro Domingos](https://en.wikipedia.org/wiki/Pedro_Domingos) and Matt Richardson.[^o5][^o6] Markov logic networks is a popular formalism for [statistical relational learning](wikipedia://en/19667111).[^o7]

## Syntax {#Syntax}

A Markov logic network consists of a collection of [formulas](https://en.wikipedia.org/wiki/Formula_%28mathematical_logic%29) from [first-order logic](wikipedia://en/10983), to each of which is assigned a [real number](wikipedia://en/20646438), the weight. The underlying idea is that an interpretation is more likely if it satisfies formulas with positive weights and less likely if it satisfies formulas with negative weights.[^o12]

For instance, the following Markov logic network codifies how smokers are more likely to be friends with other smokers, and how stress encourages smoking:[^o9]

$$\begin{array}{lcl} 2.0 & :: & \mathrm{smokes}(X) \leftarrow \mathrm{smokes}(Y) \land \mathrm{influences}(X,Y) \\ 0.5 & :: & \mathrm{smokes}(X) \leftarrow \mathrm{stress}(X) \end{array}$$

## Semantics {#Semantics}

*Image: Grounded Markov logic network.jpg.* Markov network induced by the theory from [Syntax](wikipedia://en/3670357#Syntax) to a two-element domain.

Together with a given domain, a Markov logic network defines a [probability distribution](wikipedia://en/23543) on the set of all [interpretations](wikipedia://en/14511671) of its predicates on the given domain. The underlying idea is that an interpretation is more likely if it satisfies formulas with positive weights and less likely if it satisfies formulas with negative weights.

For any [$n$-ary](wikipedia://en/42301) [predicate symbol](https://en.wikipedia.org/wiki/Predicate_symbol) $R$ that occurs in the Markov logic network and every [$n$-](wikipedia://en/42301)[tuple](wikipedia://en/132729) $a_1, \dots, a_n$ of domain elements, $R(a_1, \dots, a_n)$ is a *grounding* of $R$. An *interpretation* is given by allocating a [Boolean](wikipedia://en/3954077) [truth value](wikipedia://en/161711) (*true* or *false*) to each grounding of an element. A *true grounding* of a formula $\varphi$ in an interpretation with free variables $x_1, \dots, x_n$ is a [variable assignment](https://en.wikipedia.org/wiki/Variable_assignment) of $x_1, \dots, x_n$ that makes $\varphi$ true in that interpretation.

Then the probability of any given interpretation is [directly proportional](https://en.wikipedia.org/wiki/Directly_proportional) to $\exp (\sum_{j} w_j n_j)$, where $w_j$ is the weight of the $j$-th sentence of the Markov logic network and $n_j$ is the number of its true groundings.[^o3][^o6]

This can also be seen as inducing a [Markov network](https://en.wikipedia.org/wiki/Markov_network) whose nodes are the groundings of the predicates occurring in the Markov logic network. The feature functions of this network are the groundings of the sentences occurring in the Markov logic network, with value $e^w$ if the grounding is true and 1 otherwise (where again $w$ is the weight of the formula).[^o3]

## Inference {#Inference}

The probability distributions induced by Markov logic networks can be queried for the probability of a particular event, given by an atomic formula (*marginal inference*), possibly conditioned by another atomic formula.[^o12]

Marginal inference can be performed using standard Markov network inference techniques over the minimal subset of the relevant Markov network required for answering the query. Exact inference is known to be [\#P](wikipedia://en/27924)-complete in the size of the domain.[^o12]

In practice, the exact probability is often approximated.[^o13] Techniques for approximate inference include [Gibbs sampling](wikipedia://en/509709), [belief propagation](wikipedia://en/800010), or approximation via [pseudolikelihood](wikipedia://en/4925416).

The class of Markov logic networks which use only two variables in any formula allows for polynomial time exact inference by reduction to [weighted model counting](https://en.wikipedia.org/wiki/Weighted_model_counting).[^o14][^o12]
