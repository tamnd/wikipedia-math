# Pancyclic graph

::: {#o1 .subject cue=lead name="Pancyclic graph"}

*Image: Pancyclic octahedron.svg.* Cycles of all possible lengths in the graph of an [octahedron](wikipedia://en/80177635), showing it to be pancyclic.

In the mathematical study of [graph theory](wikipedia://en/12401), a **pancyclic graph** is a [directed graph](wikipedia://en/19721986) or [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) that contains [cycles](wikipedia://en/168609) of all possible lengths from three up to the number of [vertices](wikipedia://en/638899) in the graph.[^o2] Pancyclic graphs are a generalization of [Hamiltonian graphs](https://en.wikipedia.org/wiki/Hamiltonian_graph), graphs which have a cycle of the maximum possible length.

:::

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

An $n$-vertex graph $G$ is **pancyclic** if, for every $k$ in the range $3 \leq k \leq n$, it contains a cycle of length $k$.[^o2] It is **node-pancyclic** or **vertex-pancyclic** if, for every vertex $v$ and every $k$ in the same range, it contains a cycle of length $k$ that contains $v$.[^o5] Similarly, it is **edge-pancyclic** if, for every edge $e$ and every $k$ in the same range, it contains a cycle of length $k$ that contains $e$.[^o5]

A [bipartite graph](wikipedia://en/244431) cannot be pancyclic, because it does not contain any odd-length cycles, but it is said to be **bipancyclic** if it contains cycles of all even lengths from 4 to $n$.[^o6]

:::

## Planar graphs {#Planar_graphs}

A [maximal](https://en.wikipedia.org/wiki/Maximal_element) [outerplanar graph](wikipedia://en/352343) is a graph formed by a [simple polygon](wikipedia://en/1059530) in the plane by [triangulating](wikipedia://en/679384) its interior. Every maximal outerplanar graph is pancyclic, as can be shown by induction. The outer face of the graph is an $n$-vertex cycle, and removing any triangle connected to the rest of the graph by only one edge (a leaf of the tree that forms the [dual graph](wikipedia://en/2536864) of the triangulation) forms a maximal outerplanar graph on one fewer vertex, that by induction has cycles of all the remaining lengths. With more care in choosing which triangle to remove, the same argument shows more strongly that every maximal outerplanar graph is node-pancyclic.[^o9] The same holds for graphs that have a maximal outerplanar [spanning subgraph](https://en.wikipedia.org/wiki/Spanning_subgraph), as do for instance the [wheel graphs](wikipedia://en/1655876).

A maximal [planar graph](wikipedia://en/24314) is a planar graph in which all faces, even the outer face, are triangles. A maximal planar graph is node-pancyclic if and only if it has a Hamiltonian cycle:[^o10] if it is not Hamiltonian, it is certainly not pancyclic, and if it is Hamiltonian, then the interior of the Hamiltonian cycle forms a maximal outerplanar graph on the same nodes, to which the previous argument for maximal outerplanar graphs can be applied.[^o11] For instance, the illustration shows the pancyclicity of the graph of an [octahedron](wikipedia://en/80177635), a Hamiltonian maximal planar graph with six vertices. More strongly, by the same argument, if a maximal planar graph has a cycle of length $k$, it has cycles of all smaller lengths.[^o12]

*Image: Halin no 8-cycle.svg.* An almost-pancyclic [Halin graph](wikipedia://en/19658548), with cycles of all lengths up to $n$ except length 8

[Halin graphs](wikipedia://en/19658548) are the planar graphs formed from a planar drawing of a [tree](wikipedia://en/48560) that has no degree-two vertices, by adding a cycle to the drawing that connects all the leaves of the tree. Halin graphs are not necessarily pancyclic, but they are **almost pancyclic** in the sense that there is at most one missing cycle length. The length of the missing cycle is necessarily even. If none of the interior vertices of a Halin graph has degree three, then it is necessarily pancyclic.[^o13]

(Bondy 1971) observed that many classical conditions for the existence of a Hamiltonian cycle were also sufficient conditions for a graph to be pancyclic, and on this basis conjectured that every 4-connected planar graph is pancyclic. However, (Malkevitch 1971) found a family of counterexamples.

## Tournaments {#Tournaments}

A [tournament](wikipedia://en/1427502) is a directed graph with one directed edge between each pair of vertices. Intuitively, a tournament can be used to model a [round-robin sports competition](https://en.wikipedia.org/wiki/Round-robin_tournament), by drawing an edge from the winner to the loser of each game in the competition. A tournament is called [strongly connected](https://en.wikipedia.org/wiki/Strongly_connected_graph) or strong if and only if it cannot be partitioned into two nonempty subsets $L$ and $W$ of losers and winners, such that every competitor in $W$ beats every competitor in $L$.[^o17] Every strong tournament is pancyclic[^o18] and node-pancyclic.[^o19] If a tournament is [regular](wikipedia://en/85821) (each competitor has the same number of wins and losses as each other competitor) then it is also edge-pancyclic;[^o20] however, a strong tournament with four vertices cannot be edge-pancyclic.

## Graphs with many edges {#Graphs_with_many_edges}

[Mantel's theorem](https://en.wikipedia.org/wiki/Mantel's_theorem) states that any $n$-vertex undirected graph with at least $n^2/4$ edges, and no multiple edges or self-loops, either contains a triangle or it is the [complete bipartite graph](wikipedia://en/525320) $K_{n/2,n/2}$. This theorem can be strengthened: any undirected Hamiltonian graph with at least $n^2/4$ edges is either pancyclic or $K_{n/2,n/2}$.[^o2]

There exist $n$-vertex Hamiltonian directed graphs with $n(n+1)/2-3$ edges that are not pancyclic, but every Hamiltonian directed graph with at least $n(n+1)/2-1$ edges is pancyclic. Additionally, every $n$-vertex strongly connected directed graph in which each vertex has degree at least $n$ (counting incoming and outgoing edges together) is either pancyclic or it is a complete bipartite directed graph.[^o22]

## Graph powers {#Graph_powers}

For any graph $G$, its [$k$th power](https://en.wikipedia.org/wiki/Power_of_graph) $G^k$ is defined as the graph on the same vertex set that has an edge between every two vertices whose distance in $G$ is at most $k$. If $G$ is [2-vertex-connected](https://en.wikipedia.org/wiki/K-vertex-connected_graph), then by [Fleischner's theorem](https://en.wikipedia.org/wiki/Fleischner's_theorem) its square $G^2$ is Hamiltonian; this can be strengthened to show that it is necessarily vertex-pancyclic.[^n1] More strongly, whenever $G^2$ is Hamiltonian, it is also pancyclic.[^n2]

## Computational complexity {#Computational_complexity}

It is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) to test whether a graph is pancyclic, even for the special case of [3-connected](https://en.wikipedia.org/wiki/K-vertex-connected_graph) [cubic graphs](wikipedia://en/980508), and it is also NP-complete to test whether a graph is node-pancyclic, even for the special case of [polyhedral graphs](wikipedia://en/24656270).[^o27] It is also NP-complete to test whether the square of a graph is Hamiltonian, and therefore whether it is pancyclic.[^n3]

## History {#History}

Pancyclicity was first investigated in the context of tournaments by (Harary Moser 1966), (Moon 1966), and (Alspach 1967). The concept of pancyclicity was named and extended to undirected graphs by (Bondy 1971).
