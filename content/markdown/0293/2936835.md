# Trusted Platform Module

::: {#o2 .subject cue=lead name="Trusted Platform Module"}

A **Trusted Platform Module** (**TPM**) is a [secure cryptoprocessor](wikipedia://en/59865) that implements the **ISO/IEC 11889** standard. Common uses are verifying that the [boot process](https://en.wikipedia.org/wiki/Boot_process) starts from a trusted combination of hardware and software and storing [disk encryption](wikipedia://en/7066791) keys.

:::

A TPM 2.0 implementation is part of the [Windows 11](https://en.wikipedia.org/wiki/Windows_11) system requirements.[^o3]

## History {#History}

The first TPM version that was deployed was 1.1b in 2003.[^o5]

Trusted Platform Module (TPM) was conceived by a [computer industry](https://en.wikipedia.org/wiki/Computer_industry) consortium called [Trusted Computing Group](wikipedia://en/2792301) (TCG). It evolved into *TPM Main Specification Version 1.2* which was standardized by [International Organization for Standardization](https://en.wikipedia.org/wiki/International_Organization_for_Standardization) (ISO) and [International Electrotechnical Commission](https://en.wikipedia.org/wiki/International_Electrotechnical_Commission) (IEC) in 2009 as ISO/IEC 11889:2009.[^o6] *TPM Main Specification Version 1.2* was finalized on 3 March 2011 completing its revision.[^o7][^o8]

On April 9, 2014, the [Trusted Computing Group](wikipedia://en/2792301) announced a major upgrade to their specification entitled *TPM Library Specification 2.0*.[^o9] The group continues work on the standard incorporating errata, algorithmic additions and new commands. This version, first published in 2014, became ISO/IEC 11889:2015 and has been periodically reconfirmed by ISO since, most recently in 2021, while the underlying Trusted Computing Group specification has continued to be revised, reaching version 1.62 in 2020 and version 184 by March 2025.[^o10] A draft revision (ISO/IEC DIS 11889-1), intended to replace the 2015 edition, entered the ISO enquiry phase in 2026.[^o11]

When a new revision is released, it is divided into multiple parts by the Trusted Computing Group. Each part consists of a document that makes up the whole of the new TPM specification.

- Part 1 Architecture (renamed from Design Principles)
- Part 2 Structures of the TPM
- Part 3 Commands
- Part 4 Supporting Routines (added in TPM 2.0)

### Version differences {#Version_differences}

While TPM 2.0 addresses many of the same use cases and has similar features, the details are different. TPM 2.0 is not backward compatible with TPM 1.2.[^o13][^o14][^o15]

The TPM 2.0 policy authorization includes the 1.2 HMAC, locality, physical presence, and PCR. It adds authorization based on an asymmetric digital signature, indirection to another authorization secret, counters and time limits, NVRAM values, a particular command or command parameters, and physical presence. It permits the [ANDing and ORing](wikipedia://en/264399) of these authorization primitives to construct complex authorization policies.[^o30]

## Overview {#Overview}

*Image: TPM 1.2 diagram.svg.* Components of a Trusted Platform Module complying with the TPM version 1.2 standard

The Trusted Platform Module (TPM) provides:

- A [hardware random number generator](https://en.wikipedia.org/wiki/Hardware_random_number_generator)[^o32][^o33]
- Facilities for the secure generation of [cryptographic keys](https://en.wikipedia.org/wiki/Cryptographic_keys) for limited uses.
- [Remote attestation](https://en.wikipedia.org/wiki/Remote_attestation): Creates a nearly unforgeable [hash key](wikipedia://en/439526) summary of the hardware and software configuration. One could use the hash to verify that the hardware and software have not been changed. The software in charge of hashing the setup determines the extent of the summary.
- Binding: Data is encrypted using the TPM bind key, a unique [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) key descended from a storage key. Computers that incorporate a TPM can create cryptographic keys and encrypt them so that they can only be decrypted by the TPM. This process, often called wrapping or binding a key, can help protect the key from disclosure. Each TPM has a master wrapping key, called the storage root key, which is stored within the TPM itself. User-level RSA key containers are stored with the Windows user profile for a particular user and can be used to encrypt and decrypt information for applications that run under that specific user identity.[^o34][^o35]
- [Sealed storage](https://en.wikipedia.org/wiki/Sealed_storage): Specifies the TPM state[^o36] for the data to be decrypted (unsealed).[^o37]
- Other [Trusted Computing](wikipedia://en/58608) functions for the data to be decrypted (unsealed).[^o38]

Computer programs can use a TPM for the [authentication](wikipedia://en/47967) of hardware devices, since each TPM chip has a unique and secret Endorsement Key (EK) burned in as it is produced. Security embedded in hardware provides more protection than a software-only solution.[^o39] Its use is restricted in some countries.[^o40]

## Uses {#Uses}

### Platform integrity {#Platform_integrity}

*Image: TPM 2.0 implementation on Linux screenshot.png.* Screenshot of `tpm2-software` showing the reading of Platform Configuration Registers (PCRs), the getrandom result taken from TPM device, and TPM version (2.0)

The primary scope of TPM is to ensure the [integrity](https://en.wikipedia.org/wiki/Data_integrity) of a platform during boot time. In this context, "integrity" means "behaves as intended", and a "platform" is any computer device regardless of its [operating system](https://en.wikipedia.org/wiki/Operating_system). This is to ensure that the [boot process](https://en.wikipedia.org/wiki/Boot_process) starts from a trusted combination of hardware and software, and continues until the operating system has fully booted and [applications](https://en.wikipedia.org/wiki/Application_software) are running.

When TPM is used, the firmware and the operating system are responsible for ensuring integrity.

For example, the [Unified Extensible Firmware Interface](https://en.wikipedia.org/wiki/Unified_Extensible_Firmware_Interface) (UEFI) can use TPM to form a [root of trust](https://en.wikipedia.org/wiki/Root_of_Trust): The TPM contains several Platform Configuration Registers (PCRs) that allow secure storage and reporting of security-relevant metrics, such as [BIOS](https://en.wikipedia.org/wiki/BIOS), [Option ROMs](https://en.wikipedia.org/wiki/Option_ROM) and [boot managers](https://en.wikipedia.org/wiki/Boot_manager). These metrics can be used to detect changes to previous configurations and decide how to proceed. Examples of such use can be found in [Linux Unified Key Setup](https://en.wikipedia.org/wiki/Linux_Unified_Key_Setup) (LUKS),[^o44] [BitLocker](https://en.wikipedia.org/wiki/BitLocker) and [PrivateCore](https://en.wikipedia.org/wiki/PrivateCore) vCage memory encryption. (See below.)

Another example of platform integrity via TPM is in the use of [Microsoft Office 365](https://en.wikipedia.org/wiki/Microsoft_Office_365) licensing and Outlook Exchange.[^o45]

Another example of TPM use for platform integrity is the [Trusted Execution Technology](https://en.wikipedia.org/wiki/Trusted_Execution_Technology) (TXT), which creates a chain of trust. It could remotely attest that a computer is using the specified hardware and software.[^o46]

### Disk encryption {#Disk_encryption}

[Full disk encryption](https://en.wikipedia.org/wiki/Full_disk_encryption) utilities, such as [dm-crypt](wikipedia://en/10782256), can use this technology to protect the keys used to encrypt the computer's storage devices and provide integrity [authentication](wikipedia://en/47967) for a trusted boot pathway that includes firmware and the [boot sector](https://en.wikipedia.org/wiki/Boot_sector).[^o48]

## Implementations {#Implementations}

*Image: TPM Asus.jpg.* Trusted Platform Module installed on a mainboard

### Laptops and notebooks {#Laptops_and_notebooks}

In 2006, new [laptops](https://en.wikipedia.org/wiki/Laptop) began being sold with a built-in TPM chip. In the future, this concept could be co-located on an existing [motherboard](https://en.wikipedia.org/wiki/Motherboard) chip in computers, or any other device where the TPM facilities could be employed, such as a [cellphone](https://en.wikipedia.org/wiki/Cellphone). On a PC, either the [Low Pin Count](https://en.wikipedia.org/wiki/Low_Pin_Count) (LPC) bus or the [Serial Peripheral Interface](https://en.wikipedia.org/wiki/Serial_Peripheral_Interface) (SPI) bus is used to connect to the TPM chip.

The [Trusted Computing Group](wikipedia://en/2792301) (TCG) has certified TPM chips manufactured by [Infineon Technologies](https://en.wikipedia.org/wiki/Infineon_Technologies), [Nuvoton](https://en.wikipedia.org/wiki/Nuvoton), and [STMicroelectronics](https://en.wikipedia.org/wiki/STMicroelectronics),[^o52] having assigned TPM vendor [IDs](https://en.wikipedia.org/wiki/Identity_document) to [Advanced Micro Devices](https://en.wikipedia.org/wiki/Advanced_Micro_Devices), [Atmel](https://en.wikipedia.org/wiki/Atmel), [Broadcom](https://en.wikipedia.org/wiki/Broadcom), [IBM](https://en.wikipedia.org/wiki/IBM), Infineon, [Intel](https://en.wikipedia.org/wiki/Intel), [Lenovo](https://en.wikipedia.org/wiki/Lenovo), [National Semiconductor](https://en.wikipedia.org/wiki/National_Semiconductor), Nationz Technologies, Nuvoton, [Qualcomm](https://en.wikipedia.org/wiki/Qualcomm), [Rockchip](https://en.wikipedia.org/wiki/Rockchip), [Standard Microsystems Corporation](https://en.wikipedia.org/wiki/Microchip_Technology), STMicroelectronics, [Samsung](https://en.wikipedia.org/wiki/Samsung), Sinosun, [Texas Instruments](https://en.wikipedia.org/wiki/Texas_Instruments), and [Winbond](https://en.wikipedia.org/wiki/Winbond).[^o53]

### TPM 2.0 {#TPM_2.0}

There are five different types of TPM 2.0 implementations (listed in order from most to least secure):[^o55][^o56]

- Discrete TPMs (dTPMs) are dedicated chips that implement TPM functionality in their own tamper resistant semiconductor package. They are the most secure, certified to FIPS-140 with level 3 physical security[^o57] resistance to attack versus routines implemented in software, and their packages are required to implement some tamper resistance. For example, the TPM for the brake controller in a car is protected from hacking by sophisticated methods.[^o58]
- Integrated TPMs (iTPMs) are part of another chip. While they use hardware that resists software bugs, they are not required to implement tamper resistance. [Intel](https://en.wikipedia.org/wiki/Intel) has integrated TPMs in some of its [chipsets](https://en.wikipedia.org/wiki/Chipset).
- Firmware TPMs (fTPMs) are firmware-based (e.g. [UEFI](https://en.wikipedia.org/wiki/UEFI)) solutions that run in a CPU's [trusted execution environment](https://en.wikipedia.org/wiki/Trusted_execution_environment). Intel, AMD and Qualcomm have implemented firmware TPMs.
- Virtual TPMs (vTPMs) are provided by and rely on [hypervisors](https://en.wikipedia.org/wiki/Hypervisor) in isolated execution environments that are hidden from the software running inside [virtual machines](https://en.wikipedia.org/wiki/Virtual_machines) to secure their code from the software in the virtual machines. They can provide a security level comparable to a firmware TPM. [Google Cloud Platform](https://en.wikipedia.org/wiki/Google_Cloud_Platform) has implemented vTPM.[^o59]
- Software TPMs are software emulators of TPMs that run with no more protection than a regular program gets within an operating system. They depend entirely on the environment that they run in, so they provide no more security than what can be provided by the normal execution environment. They are useful for development purposes.

### Open source {#Open_source}

The official TCG reference implementation of the TPM 2.0 Specification has been developed by [Microsoft](https://en.wikipedia.org/wiki/Microsoft). It is licensed under [BSD License](https://en.wikipedia.org/wiki/BSD_License) and the [source code](https://en.wikipedia.org/wiki/Source_code) is available on [GitHub](https://en.wikipedia.org/wiki/GitHub).[^o62]

In 2018, [Intel](https://en.wikipedia.org/wiki/Intel) open-sourced its Trusted Platform Module 2.0 (TPM2) software stack with support for Linux and Microsoft Windows.[^o63] The source code is hosted on GitHub and licensed under [BSD License](https://en.wikipedia.org/wiki/BSD_License).[^o64][^o65]

[Infineon](https://en.wikipedia.org/wiki/Infineon) funded the development of an open source TPM middleware that complies with the Software Stack (TSS) Enhanced System API (ESAPI) specification of the TCG.[^o66] It was developed by [Fraunhofer Institute](https://en.wikipedia.org/wiki/Fraunhofer_Institute) for Secure Information Technology (SIT).[^o67]

[IBM](https://en.wikipedia.org/wiki/IBM)'s Software TPM 2.0 is an implementation of the TCG TPM 2.0 specification. It is based on the TPM specification Parts 3 and 4 and source code donated by Microsoft. It contains additional files to complete the implementation. The source code is hosted on [SourceForge](https://en.wikipedia.org/wiki/SourceForge)[^o68] and [GitHub](https://en.wikipedia.org/wiki/GitHub)[^o69] and licensed under BSD License.

In 2022, [AMD](https://en.wikipedia.org/wiki/Advanced_Micro_Devices) announced that under certain circumstances their fTPM implementation causes performance problems. A fix is available in form of a [BIOS](https://en.wikipedia.org/wiki/BIOS)-Update.[^o70][^o71]

## Criticism {#Criticism}

The [Trusted Computing Group](wikipedia://en/2792301) (TCG) has faced resistance to the deployment of this technology in some areas, where some authors see possible uses not specifically related to [Trusted Computing](wikipedia://en/58608), which may raise privacy concerns. The concerns include the abuse of remote validation of software to decide what software is allowed to run, and possible ways to follow actions taken by the user and record them in a database in a manner that is completely undetectable to the user.[^o73]

The [TrueCrypt](wikipedia://en/905962) disk encryption utility, as well as its derivative [VeraCrypt](wikipedia://en/45345491), do not support TPM. The original TrueCrypt developers were of the opinion that the exclusive purpose of the TPM is "to protect against attacks that require the attacker to have administrator privileges, or physical access to the computer". The attacker who has physical or administrative access to a computer can circumvent TPM, e.g., by installing a hardware [keystroke logger](https://en.wikipedia.org/wiki/Keystroke_logger), by resetting TPM, or by capturing memory contents and retrieving TPM-issued keys. The condemning text goes so far as to claim that TPM is entirely redundant.[^o74] The VeraCrypt publisher has reproduced the original allegation with no changes other than replacing "TrueCrypt" with "VeraCrypt".[^o75] The author is right that, after achieving either unrestricted physical access or administrative privileges, it is only a matter of time before other security measures in place are bypassed.[^o76][^o77] However, stopping an attacker in possession of administrative privileges has never been one of the goals of TPM (see for details), and TPM can [stop some physical tampering](wikipedia://en/15893148).[^o44][^o46][^o78][^o79][^o80]

In 2015, [Richard Stallman](https://en.wikipedia.org/wiki/Richard_Stallman) suggested replacing the term "trusted computing" with the term "treacherous computing" due to the danger that the computer can be made to systematically disobey its owner if the cryptographical keys are kept secret from them. He also considers that TPMs available for PCs in 2015 are not currently dangerous and that there is no reason not to include one in a computer or support it in software due to failed attempts from the industry to use that technology for [DRM](wikipedia://en/18938226), but that the TPM2 released in 2022 is precisely the "[treacherous computing](wikipedia://en/58608)" threat he had warned of.[^o81]

In August 2023, [Linus Torvalds](https://en.wikipedia.org/wiki/Linus_Torvalds), who was frustrated with AMD fTPM's stuttering bugs, opined, "Let's just disable the stupid fTPM `hwrnd` thing." He said the CPU-based random number generation, `[[RDRAND|rdrand]]`, was equally suitable, despite having its share of bugs.[^o82]

## Security issues {#Security_issues}

In 2010, [Christopher Tarnovsky](https://en.wikipedia.org/wiki/Christopher_Tarnovsky) presented an attack against TPMs at [Black Hat Briefings](https://en.wikipedia.org/wiki/Black_Hat_Briefings), where he claimed to be able to extract secrets from a single TPM. He was able to do this after 6 months of work by inserting a probe and spying on an [internal bus](https://en.wikipedia.org/wiki/Bus_%28computing%29) for the Infineon SLE 66 CL PC.[^o84][^o85]

In case of physical access, computers with TPM 1.2 are vulnerable to [cold boot attacks](wikipedia://en/15893148) as long as the system is on or can be booted without a passphrase from shutdown, [sleep](https://en.wikipedia.org/wiki/Sleep_%28computing%29) or [hibernation](https://en.wikipedia.org/wiki/Hibernation_%28computing%29), which is the default setup for Windows computers with BitLocker full disk encryption.[^o86] A fix was proposed, which has been adopted in the specifications for TPM 2.0.

In 2009, the concept of shared authorisation data in TPM 1.2 was found to be flawed. An adversary given access to the data could spoof responses from the TPM.[^o87] A fix was proposed, which has been adopted in the specifications for TPM 2.0.

In 2015, as part of the [Snowden revelations](https://en.wikipedia.org/wiki/Global_surveillance_disclosures_%282013–present%29), it was revealed that in 2010 a [US CIA](https://en.wikipedia.org/wiki/Central_Intelligence_Agency) team claimed at an internal conference to have carried out a [differential power analysis](wikipedia://en/754362) attack against TPMs that was able to extract secrets.[^o88][^o89]

Main [Trusted Boot (tboot)](https://en.wikipedia.org/wiki/Tboot) distributions before November 2017 are affected by a dynamic root of trust for measurement (DRTM) attack 2017-16837, which affects computers running on [Intel's Trusted eXecution Technology (TXT)](https://en.wikipedia.org/wiki/Trusted_Execution_Technology) for the boot-up routine.[^o94]

In October 2017, it was reported that a code library developed by [Infineon](https://en.wikipedia.org/wiki/Infineon_Technologies), which had been in widespread use in its TPMs, contained a vulnerability, known as [ROCA](wikipedia://en/55620314), which generated weak [RSA](https://en.wikipedia.org/wiki/RSA_%28cryptosystem%29) key pairs that allowed private keys to be inferred from [public keys](https://en.wikipedia.org/wiki/Public_key_cryptography). As a result, all systems depending upon the privacy of such weak keys are vulnerable to compromise, such as [identity theft](https://en.wikipedia.org/wiki/Identity_theft) or spoofing.[^o90] Cryptosystems that store encryption keys directly in the TPM without [blinding](wikipedia://en/490067) could be at particular risk to these types of attacks, as passwords and other factors would be meaningless if the attacks can extract encryption secrets.[^o91] Infineon has released firmware updates for its TPMs to manufacturers who have used them.[^o92]

In 2018, a design flaw in the TPM 2.0 specification for the static root of trust for measurement (SRTM) was reported (2018-6622). It allows an adversary to reset and forge platform configuration registers which are designed to securely hold measurements of software that are used for bootstrapping a computer.[^o93] Fixing it requires hardware-specific firmware patches.[^o93] An attacker abuses power interrupts and TPM state restores to trick TPM into thinking that it is running on non-tampered components.[^o94]

In 2021, the Dolos Group showed an attack on a discrete TPM, where the TPM chip itself had some tamper resistance, but the other endpoints of its communication bus did not. They read a full-disk-encryption key as it was transmitted across the motherboard, and used it to decrypt the laptop's SSD.[^o95]

## Availability {#Availability}

, a TPM is provided by nearly all PC and notebook manufacturers in their products.

Vendors include:

- [Infineon](https://en.wikipedia.org/wiki/Infineon) provides both TPM chips and TPM software, which are delivered as [OEM](https://en.wikipedia.org/wiki/Original_equipment_manufacturer) versions with new computers as well as separately by Infineon for products with TPM technology which comply with TCG standards. For example, Infineon licensed TPM management software to Broadcom Corp. in 2004.[^o97]
- [Microchip](https://en.wikipedia.org/wiki/Microchip_Technology) (formerly Atmel) manufactured TPM devices that it claims to be compliant to the Trusted Platform Module specification version 1.2 revision 116 and offered with several interfaces (LPC, SPI, and I<sup>2</sup>C), modes (FIPS 140-2 certified and standard mode), temperature grades (commercial and industrial), and packages (TSSOP and QFN).[^o98][^o99][^o100] Its TPMs support PCs and embedded devices.[^o98] It also provides TPM development kits to support integration of its TPM devices into various embedded designs.[^o101]
- [Nuvoton](https://en.wikipedia.org/wiki/Nuvoton) Technology Corporation provides TPM devices for PC applications. Nuvoton also provides TPM devices for embedded systems and Internet of Things (IoT) applications via I<sup>2</sup>C and SPI host interfaces. Nuvoton's TPM complies with [Common Criteria](https://en.wikipedia.org/wiki/Common_Criteria) (CC) with assurance level EAL 4 augmented with ALC\_FLR.1, AVA\_VAN.4 and ALC\_DVS.2, [FIPS 140-2](wikipedia://en/885948) level 2 with Physical Security and EMI/EMC level 3 and [Trusted Computing Group](wikipedia://en/2792301) Compliance requirements, all supported within a single device. TPMs produced by [Winbond](https://en.wikipedia.org/wiki/Winbond) are now part of Nuvoton.[^o102]
- [STMicroelectronics](https://en.wikipedia.org/wiki/STMicroelectronics) has provided TPMs for PC platforms and embedded systems since 2005. The product offering[^o103] includes discrete devices with several interfaces supporting [Serial Peripheral Interface](https://en.wikipedia.org/wiki/Serial_Peripheral_Interface) (SPI) and [I<sup>2</sup>C](https://en.wikipedia.org/wiki/I2C) and different qualification grades (consumer, industrial and automotive). The TPM products are [Common Criteria](https://en.wikipedia.org/wiki/Common_Criteria) (CC) certified EAL4+ augmented with ALC\_FLR.1 and AVA\_VAN.5, [FIPS 140-2](wikipedia://en/885948) level 2 certified with physical security level 3 and also [Trusted Computing Group](wikipedia://en/2792301) (TCG) certified.

There are also hybrid types; for example, TPM can be integrated into an [Ethernet](https://en.wikipedia.org/wiki/Ethernet) controller, thus eliminating the need for a separate motherboard component.[^o104][^o105]

### Field upgrade {#Field_upgrade}

Field upgrade is the TCG term for updating the TPM firmware. The update can be between TPM 1.2 and TPM 2.0, or between firmware versions. Some vendors limit the number of transitions between 1.2 and 2.0, and some restrict rollback to previous versions. Platform OEMs such as [HP](https://en.wikipedia.org/wiki/HP_Inc.)[^o107] supply an upgrade tool.

Since July 28, 2016, all new Microsoft device models, lines, or series (or updating the hardware configuration of an existing model, line, or series with a major update, such as CPU, graphic cards) implement, and enable by default TPM 2.0.

While TPM 1.2 parts are discrete silicon components, which are typically soldered on the motherboard, TPM 2.0 is available as a discrete (dTPM) silicon component in a single semiconductor package, an integrated component incorporated in one or more semiconductor packages - alongside other logic units in the same package(s), and as a firmware (fTPM) based component running in a trusted execution environment (TEE) on a general purpose System-on-a-chip (SoC).[^o108]

### Virtual TPM {#Virtual_TPM}

- [Google Compute Engine](https://en.wikipedia.org/wiki/Google_Compute_Engine) was the first major cloud provider offering virtualized TPMs (vTPMs) as part of [Google Cloud](https://en.wikipedia.org/wiki/Google_Cloud_Platform)'s Shielded VMs product.[^o110] [Amazon Web Services](https://en.wikipedia.org/wiki/Amazon_Web_Services) followed in 2022, naming its vTPM offering "Nitro TPM".[^o111]
- The libtpms library provides software emulation of a Trusted Platform Module (TPM 1.2 and TPM 2.0). It targets the integration of TPM functionality into hypervisors, primarily into Qemu.[^o112]

### Operating systems {#Operating_systems}

- [Windows 11](https://en.wikipedia.org/wiki/Windows_11) requires TPM 2.0 support as a minimum system requirement.[^o114][^o115] On many systems TPM is disabled by default which requires changing settings in the computer's UEFI to enable it.[^o116]
- [Windows 8](https://en.wikipedia.org/wiki/Windows_8) and later have native support for TPM 2.0.
- [Windows 7](https://en.wikipedia.org/wiki/Windows_7) can install an official patch to add TPM 2.0 support.[^o117]
- [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista) through [Windows 10](https://en.wikipedia.org/wiki/Windows_10) have native support for TPM 1.2.
- The [Linux kernel](https://en.wikipedia.org/wiki/Linux_kernel) supports the Trusted Platform Module 2.0 (TPM 2.0) since version 4.0 (2015).[^o118][^o119][^o120][^o121]

### Platforms {#Platforms}

- [Google](https://en.wikipedia.org/wiki/Google) includes TPMs in [Chromebooks](https://en.wikipedia.org/wiki/Chromebook) as part of their security model.[^o123]
- [Oracle](https://en.wikipedia.org/wiki/Oracle_Corporation) ships TPMs in their X- and T-Series Systems such as T3 or T4 series of servers.[^o124] Support is included in [Solaris 11](https://en.wikipedia.org/wiki/Solaris_%28operating_system%29).[^o125]
- In 2006, with the introduction of first Macintosh models with Intel processors, Apple started to ship Macs with TPM. Apple never provided an official driver, but there was a port under [GPL](https://en.wikipedia.org/wiki/GNU_General_Public_License) available.[^o126] Apple has not shipped a computer with TPM since 2006.[^o127] Starting in 2016, Apple products began adopting Apple's own trusted hardware component called "Secure Enclave", originally as a separate chip and later as an integrated part of Apple silicon CPUs. Apple Secure Enclave is not TPM-compatible.[^o128]
- In 2011, Taiwanese manufacturer [MSI](https://en.wikipedia.org/wiki/Micro-Star_International) launched its Windpad 110W tablet featuring an [AMD](https://en.wikipedia.org/wiki/Advanced_Micro_Devices) CPU and Infineon Security Platform TPM, which ships with controlling software version 3.7. The chip is disabled by default but can be enabled with the included, pre-installed software.[^o129]

### Virtualization {#Virtualization}

- [VMware ESXi](https://en.wikipedia.org/wiki/VMware_ESXi) hypervisor has supported TPM since 4.x, and from 5.0 it is enabled by default.[^o131][^o132]
- [Xen](https://en.wikipedia.org/wiki/Xen) hypervisor has support of virtualized TPMs. Each guest gets its own unique, emulated, software TPM.[^o133]
- [KVM](https://en.wikipedia.org/wiki/Kernel-based_Virtual_Machine), combined with [QEMU](https://en.wikipedia.org/wiki/QEMU), has support for virtualized TPMs. , it supports passing through the physical TPM chip to a single dedicated guest. QEMU 2.11 released in December 2017 also provides emulated TPMs to guests.[^o134]
- [VirtualBox](https://en.wikipedia.org/wiki/VirtualBox) has support for virtual TPM 1.2 and 2.0 devices starting with version 7.0 released in October 2022.[^o135]

### Software {#Software}

- [Microsoft](https://en.wikipedia.org/wiki/Microsoft) operating systems [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista) and later use the chip in conjunction with the included disk encryption component named [BitLocker](https://en.wikipedia.org/wiki/BitLocker). Microsoft had announced that from January 1, 2015, all computers will have to be equipped with a TPM 2.0 module in order to pass [Windows 8.1](https://en.wikipedia.org/wiki/Windows_8.1) [hardware certification](https://en.wikipedia.org/wiki/Hardware_certification).[^o138] However, in a December 2014 review of the Windows Certification Program this was instead made an optional requirement. However, TPM 2.0 is required for [connected standby](https://en.wikipedia.org/wiki/InstantGo) systems.[^o139] Virtual machines running on Hyper-V can have their own virtual TPM module starting with Windows 10 1511 and Windows Server 2016.[^o140] Microsoft Windows includes two TPM related [commands](https://en.wikipedia.org/wiki/Command_%28computing%29): tpmtool, a utility that can be used to retrieve information about the TPM, and tpmvscmgr, a [command-line](https://en.wikipedia.org/wiki/Command-line_interface) tool that allows creating and deleting TPM virtual [smart cards](https://en.wikipedia.org/wiki/Smart_card) on a computer.[^o141][^o142]

## Endorsement keys {#Endorsement_keys}

TPM endorsement keys (EKs) are asymmetric key pairs unique to each TPM. They use the [RSA](https://en.wikipedia.org/wiki/RSA_%28cryptosystem%29) and [ECC](wikipedia://en/9966) algorithms. The TPM manufacturer usually provisions endorsement key certificates in TPM [non-volatile memory](https://en.wikipedia.org/wiki/Non-volatile_memory). The certificates assert that the TPM is authentic. Starting with TPM 2.0, the certificates are in [X.509](https://en.wikipedia.org/wiki/X.509) [DER](https://en.wikipedia.org/wiki/Distinguished_Encoding_Rules) format. After the TPM was manufactured, the EKs cannot be changed. For fTPM, the EKs are stored on CPU / chipset when it was manufactured.

These manufacturers typically provide their [certificate authority](https://en.wikipedia.org/wiki/Certificate_Authority) root (and sometimes intermediate) certificates on their web sites.

## Software libraries {#Software_libraries}

To utilize a TPM, the user needs a software library that communicates with the TPM and provides a friendlier API than the raw TPM communication. Currently, there are several such open-source TPM 2.0 libraries. Some of them also support TPM 1.2, but mostly TPM 1.2 chips are now deprecated and modern development is focused on TPM 2.0.

Typically, a TPM library provides an API with one-to-one mappings to TPM commands. The TCG specification calls this layer the System API (SAPI). This way, the user has more control over the TPM operations, but the complexity is high. To hide some of the complexity, most libraries also offer simpler ways to invoke complex TPM operations. The TCG specification call these two layers Enhanced System API (ESAPI) and Feature API (FAPI).

There is currently only one stack that follows the TCG specification. All the other available open-source TPM libraries use their own form of richer API.

*Summary of the existing open-source TPM libraries*

::: {#o171 .table cue=table name="Summary of the existing open-source TPM libraries"}

| TPM Libraries | API | TPM 2.0 | TPM 1.2 | Attestation server or example | Microsoft Windows | Linux | Bare metal |
|---|---|---|---|---|---|---|---|
| tpm2-tss[^o172] | SAPI, ESAPI and FAPI from the TCG specification |  |  |  |  |  | Maybe |
| ibmtss[^o173][^o174] | 1:1 mapping to TPM commands + rich API (mild layer on top) |  |  |  |  |  |  |
| go-tpm[^o177] | 1:1 mapping to TPM commands + rich API (mild layer on top) |  |  |  |  |  |  |
| wolfTPM[^o179] | 1:1 mapping to TPM commands + rich API (wrappers) |  |  |  |  |  |  |
| TSS.MSR[^o180] | 1:1 mapping to TPM commands + rich API (wrappers) |  |  |  |  |  |  |

:::

These TPM libraries are sometimes also called TPM stacks, because they provide the interface for the developer or user to interact with the TPM. As seen from the table, the TPM stacks abstract the operating system and transport layer, so the user could migrate one application between platforms. For example, by using TPM stack API the user would interact the same way with a TPM, regardless if the physical chip is connected over SPI, I<sup>2</sup>C or LPC interface to the Host system.
