# Betweenness problem

::: {#o1 .subject cue=lead name="Betweenness problem"}

**Betweenness** is an [algorithmic problem](https://en.wikipedia.org/wiki/Algorithmic_problem) in [order theory](wikipedia://en/361924) about ordering a collection of items subject to constraints that some items must be placed between others.[^o2] It has applications in [bioinformatics](wikipedia://en/4214)[^o3] and was shown to be [NP-complete](https://en.wikipedia.org/wiki/NP-complete) by (Opatrný 1979).[^o10]

:::

## Problem statement {#Problem_statement}

The input to a betweenness problem is a collection of [ordered triples](https://en.wikipedia.org/wiki/Ordered_triple) of items. The items listed in these triples should be placed into a [total order](wikipedia://en/30330), with the property that for each of the given triples, the middle item in the triple appears in the output somewhere between the other two items. The items of each triple are not required to be consecutive in the output.[^o2][^o10]

::: {#o7 .example cue=heading name="Examples"}

## Examples {#Examples}

As an example, the collection of input triples

(2,1,3), (3,4,5), (1,4,5), (2,4,1), (5,2,3)

is satisfied by the output ordering

3, 1, 4, 2, 5

but not by

3, 1, 2, 4, 5.

In the first of these output orderings, for all five of the input triples, the middle item of the triple appears between the other two items However, for the second output ordering, item 4 is not between items 1 and 2, contradicting the requirement given by the triple (2,4,1).

If an input contains two triples like (1,2,3) and (2,3,1) with the same three items but a different choice of the middle item, then there is no valid solution. However, there are more complicated ways of forming a set of triples with no valid solution, that do not contain such a pair of contradictory triples.

:::

## Complexity {#Complexity}

(Opatrný 1979) showed that the [decision version](wikipedia://en/8336) of the betweenness problem (in which an algorithm must decide whether or not there exists a valid solution) is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) in two ways, by a [reduction](wikipedia://en/848067) from [3-satisfiability](https://en.wikipedia.org/wiki/3-satisfiability) and also by a different reduction from [hypergraph](wikipedia://en/232535) [2-coloring](wikipedia://en/426743).[^o10] However, it can easily be solved when all unordered triples of items are represented by an ordered triple of the input, by choosing one of the two items that are not between any others to be the start of the ordering and then using the triples involving this item to compare the relative positions of each pair of remaining items.

The related problem of finding an ordering that maximizes the number of satisfied triples is [MAXSNP-hard](https://en.wikipedia.org/wiki/SNP_%28complexity%29), implying that it is impossible to achieve an [approximation ratio](https://en.wikipedia.org/wiki/Approximation_ratio) arbitrarily close to 1 in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) unless [P = NP](https://en.wikipedia.org/wiki/P_=_NP).[^o2] It remains hard to solve or approximate even for dense instances that include an ordered triple for each possible unordered triple of items.[^o11] The minimum version of the problem restricted to the tournaments was proven to have polynomial time approximation schemes (PTAS).[^o12] One can achieve an approximation ratio of 1/3 (in expectation) by ordering the items randomly, and this simple strategy gives the best possible polynomial-time approximation if the [unique games conjecture](wikipedia://en/3000842) is true.[^o13] It is also possible to use [semidefinite programming](wikipedia://en/4993539) or combinatorial methods to find an ordering that satisfies at least half of the triples of any satisfiable instance, in polynomial time.[^o2][^o14]

In [parameterized complexity](wikipedia://en/603026), the problem of satisfying as many constraints as possible from a set *C* of constraints is [fixed-parameter tractable](https://en.wikipedia.org/wiki/Fixed-parameter_tractable) when parameterized by the difference *q* − |*C*|/3 between the solution quality *q* found by the parameterized algorithm and the |*C*|/3 quality guaranteed in expectation by a random ordering.[^o15]

Although not guaranteed to succeed, a [greedy heuristic](https://en.wikipedia.org/wiki/Greedy_heuristic) can find solutions to many instances of the betweenness problem arising in practice.[^o3]

::: {#o17 .application cue=heading name="Applications"}

## Applications {#Applications}

One application of betweenness arises in [bioinformatics](wikipedia://en/4214), as part of the process of [gene mapping](https://en.wikipedia.org/wiki/Gene_mapping). Certain types of genetic experiments can be used to determine the ordering of triples of genetic markers, but do not distinguish a genetic sequence from its reversal, so the information yielded from such an experiment determines only which one out of three markers is the middle one. The betweenness problem is an abstraction of the problem of assembling a collection of markers into a single sequence given experimental data of this type.[^o2][^o3]

The betweenness problem has also been used to model theories of [probability](wikipedia://en/22934), [causality](https://en.wikipedia.org/wiki/Causality), and [time](https://en.wikipedia.org/wiki/Time).[^o18]

:::
