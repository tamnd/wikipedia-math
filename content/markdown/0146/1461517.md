# Fixed-point space

::: {#o1 .subject cue=lead name="Fixed-point space"}

In [mathematics](wikipedia://en/18831), a [Hausdorff space](wikipedia://en/13637) *X* is called a **fixed-point space** if it obeys a [fixed-point theorem](wikipedia://en/1011848), according to which every [continuous function](wikipedia://en/6122) $f:X\rightarrow X$ has a [fixed point](wikipedia://en/449738), a point $x$ for which $f(x)=x$.

:::

For example, the [closed unit interval](https://en.wikipedia.org/wiki/Closed_unit_interval) is a fixed point space, as can be proved from the [intermediate value theorem](wikipedia://en/14884). The [real line](https://en.wikipedia.org/wiki/Real_line) is not a fixed-point space, because the continuous function that adds one to its argument does not have a fixed point. Generalizing the unit interval, by the [Brouwer fixed-point theorem](wikipedia://en/4101), every [compact](https://en.wikipedia.org/wiki/Compact_set) bounded [convex set](wikipedia://en/6292) in a [Euclidean space](wikipedia://en/9697) is a fixed-point space.

The definition of a fixed-point space can also be extended from continuous functions on topological spaces to other classes of maps on other types of space.
