# Progressive function

::: {#o1 .subject cue=lead name="Progressive function"}

In [mathematics](wikipedia://en/18831), a **progressive function** *ƒ* ∈ *L*<sup>2</sup>(**R**) is a function whose [Fourier transform](wikipedia://en/52247) is supported by positive frequencies only:[^o2]

:::

$$\mathop{\rm supp}\hat{f} \subseteq \mathbb{R}_+.$$

It is called **super regressive** if and only if the time reversed function *f*(−*t*) is progressive, or equivalently, if

$$\mathop{\rm supp}\hat{f} \subseteq \mathbb{R}_-.$$

The [complex conjugate](wikipedia://en/173918) of a progressive function is regressive, and vice versa.

The space of progressive functions is sometimes denoted $H^2_+(R)$, which is known as the [Hardy space](wikipedia://en/314780) of the upper half-plane. This is because a progressive function has the Fourier inversion formula

$$f(t) = \int_0^\infty e^{2\pi i st} \hat f(s)\, ds$$

and hence extends to a [holomorphic function](wikipedia://en/14110) on the [upper half-plane](wikipedia://en/287826) $\{ t + iu: t, u \in R, u \geq 0 \}$

by the formula

$$f(t+iu) = \int_0^\infty e^{2\pi i s(t+iu)} \hat f(s)\, ds = \int_0^\infty e^{2\pi i st} e^{-2\pi su} \hat f(s)\, ds.$$

Conversely, every holomorphic function on the upper half-plane which is uniformly square-integrable on every horizontal line will arise in this manner.

Regressive functions are similarly associated with the Hardy space on the lower half-plane $\{ t + iu: t, u \in R, u \leq 0 \}$.
