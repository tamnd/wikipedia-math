# Janiszewski's theorem

::: {#o1 .subject cue=lead name="Janiszewski's theorem"}

In [mathematics](wikipedia://en/18831), **Janiszewski's theorem**, named after the Polish mathematician [Zygmunt Janiszewski](wikipedia://en/362471), is a result concerning the [topology](wikipedia://en/29954) of the plane or extended plane. It states that if *A* and *B* are closed subsets of the extended plane with connected intersection, then any two points that can be connected by paths avoiding either *A* or *B* can be connected by a path avoiding both of them. The theorem has been used as a tool for proving the [Jordan curve theorem](wikipedia://en/267444)[^o2] and in [complex function theory](https://en.wikipedia.org/wiki/Complex_function_theory).

:::
