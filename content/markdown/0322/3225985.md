# Proth's theorem

::: {#o1 .subject cue=lead name="Proth's theorem"}

In [number theory](wikipedia://en/21527), **Proth's theorem** is a theorem which forms the basis of a [primality test](wikipedia://en/183751) for [Proth numbers](https://en.wikipedia.org/wiki/Proth_number) known as **Proth's test**. Proth numbers, sometimes called **Proth Numbers of the First Kind**, are those [integers](wikipedia://en/14563) *p* which take the form *p = k*2<sup>*n*</sup> + 1 with an odd *k* where *k* \< 2<sup>*n*</sup>. For *Proth Numbers of the Second Kind*, see related topic [Riesel numbers](wikipedia://en/321963). The theorem is also named after the French mathematician and original publisher of the theorem, **[François Proth](wikipedia://en/12423134)**.

:::

The theorem states[^o2][^o3] that for any **Proth number** (of the first kind), *p*, *p* is [prime](wikipedia://en/23666) if there exists an integer *a* for which [Euler's criterion](wikipedia://en/105622) yields –1, that is,

$$a^{\frac{p-1}{2}}\equiv -1 \pmod{p}.$$

In this case, *p* is called a **Proth prime**.

## Proth's Test {#Proth's_Test}

Only one such value of *a* need be found for the test to deterministically confirm primality, provided that *p* is a Proth number. Verifying that *p* is a Proth number is a triviality.

This is a practical test because, if *p* is prime, then any chosen *a* has about a 50 percent chance of working, and if *p* is not prime, then no chosen *a* will work. Furthermore, since the calculation is modulo *p*, only values of *a* smaller than *p* have to be considered.

### Systematic naïve variant {#Systematic_naïve_variant}

If *p* is Proth composite, then no base *a* will work to bear witness of primality. If any one base *a* bears witness, then primality is confirmed. If none do, then compositeness is confirmed. This is because the [inverse](wikipedia://en/155942) of Proth's theorem is also true:

If no *a* exists such that $a^{\frac{p-1}{2}}\equiv -1 \pmod{p}$, and *p* is a Proth number, then *p* is composite.

The contrapositive of *this* statement is that if *p* is a Proth prime, such an *a* value is guaranteed to exist.

Indeed, if *p* is a Proth prime then we expect roughly half of all *a*-values to satisfy the congruence, in the general case. On the other hand, if the second condition is not met - if *p* is not a Proth number - then compositeness cannot be guaranteed (the inverse is not generally true for non-Proth), even if the first condition of congruence is met.

As such, we may systematically check all base values \[2, *p* − 1\] to verify compositeness (note that *a* = 0 and *a* = 1 will never work), unless and until one is found to confirm primality. This process, as it is stated, though the most straightforward and trivial, can be made more efficient.

In principle, since if *p* is prime, there is roughly a 50% chance of a chosen *a* of proving primality, we may make the process slightly more efficient by checking about one-half of all possible *a*-values smaller than *p* - we expect half of said values to satisfy the congruence. Once more than *p*/2 distinct values of *a* have been tested, compositeness is deterministic. This is because, if *p* is prime then we expect half of all bases to bears witness; by the [pigeonhole principle](wikipedia://en/54217), once more than half have been checked, we can deduce that none will bear witness, and if no base value *a* will work, then *p* is composite. If on the other hand *p* is prime, then at least one of the values checked would inevitably have borne witness, as would all remaining unchecked values. This variation of the test is similar to the deterministic variant of the [Fermat primality test](wikipedia://en/157755).

Both of these naïve variants are grossly inefficient and never employed in practice. Note that both of these approaches represent significantly more computational work than simple brute force [trial division](wikipedia://en/557660) (Schoolhouse method) in the worst case scenario.

### Probabilistic Monte Carlo Variant {#Probabilistic_Monte_Carlo_Variant}

As 50% of bases *a* are expected to bear witness to primality, if *p* is indeed prime, then we may form a [Monte Carlo](https://en.wikipedia.org/wiki/Monte_Carlo_algorithm) probabilistic test thus: if the test is repeatedly performed *m* times, each iteration with a random *a*, each time failing to confirm primality, then we may infer that *p* is *probably composite* - this is in contrast to the *probably prime* results typical of other Monte Carlo algorithms such as the [Miller-Rabin test](https://en.wikipedia.org/wiki/Miller-Rabin_test). An approximate upper bound error probability $\varepsilon < 2^{-m}$ of a prime being falsely identified as composite can also be inferred. A composite will, however, never be falsely identified as prime.

This probabilistic implementation is not typically performed. Even though it is far more efficient than the deterministic naïve test, with computational efficiency on par with the Miller-Rabin test, it can still be improved both in performance runtime and in accuracy (or definitiveness).

### Las Vegas Variant {#Las_Vegas_Variant}

The Las Vegas formulation of Proth's test is by far the most efficient of the variants, and as definitive as the deterministic variant. This is the variant typically employed, though there are some nuances in implementation approach still.

In practice, a [quadratic nonresidue](https://en.wikipedia.org/wiki/Quadratic_nonresidue) of *p* is found and taken as the value of *a*. Since, if *a* is a quadratic nonresidue modulo *p* then the [converse](wikipedia://en/155941) of Proth's theorem is also true (if Euler's criterion does not yield –1 then *p* is composite) and the test becomes [conclusive](https://en.wikipedia.org/wiki/Iff) (bidirectional). The theorem may be restated:

For all Proth numbers *p*, and for any quadratic nonresidue *a* of *p*, *p* is prime if and only if $a^{\frac{p-1}{2}}\equiv -1 \pmod{p}$.

A quadratic nonresidue *a* of *p* may be identified when the [Legendre symbol](wikipedia://en/18567) is –1, thus for such an *a*-value:

$$\left(\frac{a}{p}\right)=-1 .$$

For such a value of *a*, the test is deterministic for both primality and compositeness; thus, for such an *a* the check against Proth's/Euler's criteria only requires only one iteration: congruence or non-congruence to -1 is wholly descriptive of primeness. The difficulty is in finding such of an *a*-value.

#### Determining the base {#Determining_the_base}

The value of *a* may be found either by systematically checking values in the interval \[2, *p* − 1\], through random selection and checking, or by a more direct computation (the more efficient option), against the Legendre symbol. In any case, when a value of *a* is verified against the Legendre symbol as a valid candidate, and therefore a quadratic nonresidual, it may be applied in Proth's / Euler's criterion to determine primality or compositeness conclusively.

A systematic check is not grossly inefficient in the general case; candidates are fairly common and one will likely be found in a handful of attempts, regardless of whether *p* is prime or composite. Though quadratic nonresidues are common whether or not *p* is prime, they can only be rare or non-existent, in the hypothetical, when *p* is composite. We may deduce conclusively that *p* is composite if no quadratic nonresidue can be found. Any exhaustive search is computationally expensive.

Random selection is also not grossly inefficient in the general case; the probability of finding a candidate is about 50% per iteration. Though finding *a* in this way is a probabilistic problem, once found the solution is deterministic. We may infer probabilistic compositeness (Monte Carlo) with a threshold of confidence if through random selection no nonresidue satisfying the Legendre symbol can be found in a reasonable number of attempts, though there is always a non-zero probability of a false result.

For the reasons outlined, a more direct calculation is typically employed via a [modified Euclidean algorithm](wikipedia://en/200091#Prime_or_prime_power_modulus).. This is done to guarantee a deterministic (and efficient) test. If direct computation of a quadratic nonresidue fails - due to non-existence - then compositeness can be deduced with absolute certainty.

Thus, in contrast to many Monte Carlo primality tests (randomized algorithms that can return a [false positive](https://en.wikipedia.org/wiki/False_positive) or [false negative](https://en.wikipedia.org/wiki/False_negative)), this deterministic variant of the primality testing algorithm is a [Las Vegas algorithm](wikipedia://en/537519), always returning the correct answer but with a randomly varying [runtime](https://en.wikipedia.org/wiki/Runtime_%28program_lifecycle_phase%29).

The check against Proth's criterion, a simple [modular exponentiation](wikipedia://en/903032) operation, once *a* has been determined, has a runtime on the order of the bit-length of *p*; the random variability in the overall test runtime, therefore, is primarily a result of the search for an appropriate *a* value, however that may be done.

#### Simplified forms {#Simplified_forms}

Given a Proth number *p* = *k*2<sup>*n*</sup> + 1, particular forms of *p*, *k*, and *n* have been identified that correspond to predetermined quadratic nonresidue values that are appropriate for use. It has been shown that:

- If $p > 3$ and $3 \nmid k$, then $a=3$ is always a quadratic nonresidue (candidate) and therefore a valid base to check, and so:

$3^{\frac{p-1}{2}} \equiv -1 \pmod{p}$ if and only if *p* is prime.

This is the basis of [Pépin's test](wikipedia://en/3266846) for [Fermat numbers](wikipedia://en/91127) and their corresponding primes, wherein *k* = 1 is indivisible by 3.

- If $p > 8$ and *p* is 3 or 5 modulo 8, then $a=2$ is always a quadratic nonresidue (candidate) and therefore a valid base to check, and so:

$2^{\frac{p-1}{2}} \equiv -1 \pmod{p}$ if and only if *p* is prime.

- If $p > 5$ and *p* is 2 or 3 modulo 5, then $a = 5$ is always a quadratic nonresidue (candidate) and therefore a valid base to check, and so:

$5^{\frac{p-1}{2}} \equiv -1 \pmod{p}$ if and only if *p* is prime.

Though no such simple rule exists for the case where *p* is 1 or 4 modulo 5, in the latter 4 mod 5 case, one can increase the chances of finding a quadratic nonresidue candidate systematically by checking values in the narrow vicinities of the two distinct square roots of 5 modulo *p*. If there are not precisely two distinct square roots (see the [Tonelli-Shanks algorithm](https://en.wikipedia.org/wiki/Tonelli-Shanks_algorithm)) then *p* is not prime. Direct computation of the nonresidue is still likely more efficient.

## Numerical examples {#Numerical_examples}

Examples of the theorem include:

- for *p* = 3 = 1(2<sup>1</sup>) + 1, we have that 2<sup>(3−1)/2</sup> + 1 = 3 is divisible by 3, so 3 is prime.
- for *p* = 5 = 1(2<sup>2</sup>) + 1, we have that 3<sup>(5−1)/2</sup> + 1 = 10 is divisible by 5, so 5 is prime.
- for *p* = 13 = 3(2<sup>2</sup>) + 1, we have that 5<sup>(13−1)/2</sup> + 1 = 15626 is divisible by 13, so 13 is prime.
- for *p* = 9, which is not prime, there is no *a* such that *a*<sup>(9−1)/2</sup> + 1 is divisible by 9.

The fact that *p* = 9 is not prime can be deterministically verified by checking that no such *a* (in mod 9) exists. This may be done by systematically checking each value of *a* from 2 to 8 (*a* = 0 and *a* = 1 will never work for any *p*). It is, however, sufficient to check values 2 to 5, or one-half of all possible values under 9. If 9 were a prime then by the pigeonhole principle, at lease one of these values of *a* will confirm primality, since it is expected that half of them would.

Alternatively, if we employ the deterministic variant wherein the quadratic nonresidue is directly computed, the work requires fewer iterations to confirm both compositeness and primality:

- for *p* = 97 = 3(2<sup>5</sup>) + 1, we have a quadratic nonresidue of *a* = 5, and 5<sup>(97−1)/2</sup> + 1 = 3552713678800500929355621337890626 is divisible by 97, so 97 is prime.
- for *p* = 1537 = 3(2<sup>9</sup>) + 1, we have a quadratic nonresidue of *a* = 5, and 5<sup>(1537−1)/2</sup> + 1 = 1052 (mod 1537) is not divisible by 1537, so 1537=29×53 is not prime.

In each of the previous two examples, an appropriate value of *a* was directly computed using a quadratic nonresidue computation such that the results of the test would be conclusive – a valid quadratic nonresidue in both the prime and composite cases. It was not necessarily to systematically search for an *a* to witness the prime case, or to reiterate the test a sufficient number of times for the composite. If a quadratic nonresidue cannot be found, or if one does not exist, then we may take this as confirmation of compositeness.

## Alternative Testing Results {#Alternative_Testing_Results}

Euler's criterion provides additional insights to a number *p*, which are not necessarily components of Proth's theorem. These are secondary facts largely attributed to other theorems, which are trivially evaluated during any implementation of Proth's test. The number *p* need not be a Proth number for the criterion to be useful. Given an integer *p*, let us choose an arbitrary *a* value. Evaluate Euler's criterion:

$$a^{\frac{p-1}{2}}\equiv b \pmod{p}.$$

There are generally five distinct outcomes. Some of these results do not rely on *p* being a Proth number, and are therefore valid for any form of prime candidate.

Primality of *p*:

- *b* = −1, in which case Proth's criterion is met and *p* is confirmed to be a Proth prime, as per Proth's theorem, if indeed *p* is a Proth number.

If *p* is not a Proth number yet *b* = −1, then this is indicative, but not conclusive, of primality. Refer to the probabilistic [Solovay–Strassen primality test](wikipedia://en/1013089) and the [Miller-Rabin test](https://en.wikipedia.org/wiki/Miller-Rabin_test).

Inconclusive result:

- *b* = 1, in which case the test is inconclusive and must be tried again with a new *a* value.

This condition is what requires reiteration and makes the test probabilistic, as if *p* were prime, then *b* = ±1 occurs with roughly equal probability, though the *b* = 1 condition may still be met with *p* either composite or non-Proth.

This is true unless *a* happens to also be a quadratic nonresidue of a Proth number *p*, in which case compositeness is indicated.

Compositeness of *p*, as per Euler's criterion and the [Legendre symbol](wikipedia://en/18567), which offer early exit conditions when *b* ≠ ±1. In each of these cases *p* is not prime and also need not be a Proth number:

- *b*<sup>2</sup> = 1, with nontrivial divisors of *p* being GCD(*b* ± 1, *p*).
- *b*<sup>2</sup> ≠ 1, where *p* is proven composite by Fermat's test, base *a*.
- *b* = 0, where *p* has a nontrivial divisor GCD(*a*, *p*).

## Proth Certificate {#Proth_Certificate}

A **Proth Certificate** is a [primality certificate](wikipedia://en/3691235) associated with Proth numbers and Proth's test, specifically. It is a document or digital proof of verification of any conditions proving primality (or compositeness). It typically contains the values *k* and *n* that comprises the Proth number, *p*, thus proving that it is a Proth number, as well as the *a*-value that proves primality. It may also prove compositeness, if appropriate. The certificate often shows the work of proof, including evidence that *a* is a quadratic nonresidue, etc., if necessary.

## Prime Search {#Prime_Search}

The first Proth primes are :

3, 5, 13, 17, [41](https://en.wikipedia.org/wiki/41_%28number%29), [97](https://en.wikipedia.org/wiki/97_%28number%29), [113](https://en.wikipedia.org/wiki/113_%28number%29), [193](https://en.wikipedia.org/wiki/193_%28number%29), 241, 257, 353, 449, 577, 641, 673, 769, 929, 1153 ....

The largest known Proth prime is 10223 × 2<sup>31172165</sup> + 1, and is 9,383,761 digits long.[^o14] It was found by Peter Szabolcs in the [PrimeGrid](wikipedia://en/3255603) [volunteer computing](https://en.wikipedia.org/wiki/Volunteer_computing) project, which announced it on 6 November 2016.[^o15] It is the 11th-largest known prime number as of January 2024, it was the largest known non-[Mersenne prime](wikipedia://en/18908) until being surpassed in 2023,[^o16] and is the largest [Colbert number](https://en.wikipedia.org/wiki/Colbert_number). The second-largest known Proth prime is 202705 × 2<sup>21320516</sup> + 1, found by PrimeGrid.[^o17]

## Generalization {#Generalization}

When *k* = *n*, the Proth number takes the form of *p = n*2<sup>*n*</sup> + 1. If we relax the condition requiring that *k* (or *n*) is odd, these are known as [Cullen numbers](wikipedia://en/321895), with corresponding [Cullen primes](https://en.wikipedia.org/wiki/Cullen_prime). Though Proth's test works when *n* is odd, Cullen numbers have their own primality tests for arbitrary *n*.

Furthermore, Cullen's primality tests may be generalized to numbers of the form *p = nc*<sup>*n*</sup> + 1, for arbitrary bases *c*.

:::
