# Symmetrically continuous function

::: {#o1 .subject cue=lead name="Symmetrically continuous function"}

In [mathematics](wikipedia://en/18831), a function $f: \mathbb{R} \to \mathbb{R}$ is **symmetrically continuous** at a point *x* if

$$\lim_{h\to 0} f(x+h)-f(x-h) = 0.$$

:::

The usual definition of [continuity](wikipedia://en/6122) implies symmetric continuity, but the converse is not true. For example, the function $x^{-2}$ is symmetrically continuous at $x=0$, but not continuous.

Also, [symmetric differentiability](wikipedia://en/3219921) implies symmetric continuity, but the converse is not true just like usual continuity does not imply differentiability.

The set of the symmetrically continuous functions, with the usual [scalar multiplication](wikipedia://en/244373) can be easily shown to have the structure of a [vector space](wikipedia://en/32370) over $\mathbb{R}$, similarly to the usually continuous functions, which form a [linear subspace](wikipedia://en/56357) within it.
