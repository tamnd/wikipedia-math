# Active shape model

::: {#o1 .subject cue=lead name="Active shape model"}

**Active shape models** (**ASMs**) are [statistical models](wikipedia://en/27576) of the [shape](wikipedia://en/169191) of objects which iteratively deform to fit to an example of the object in a new image, developed by Tim Cootes and [Chris J. Taylor](https://en.wikipedia.org/wiki/Chris_J._Taylor) in 1995. The shapes are constrained by the [point distribution model](wikipedia://en/12265304) (PDM) [statistical shape analysis](wikipedia://en/8707155) to vary only in ways seen in a training set of labelled examples. The shape of an object is represented by a set of points (controlled by the shape model). The ASM algorithm aims to match the model to a new image.[^o5][^o6][^o7][^o8][^o9]

:::

*Image: Operation Of Shape Model In Active Shape Model.jpg.* Operation of the shape model

The ASM works by alternating the following steps:

- Generate a suggested shape by looking in the image around each point for a better position for the point. This is commonly done using what is called a "profile model", which looks for strong edges or uses the [Mahalanobis distance](wikipedia://en/799760) to match a model template for the point.[^o2]
- Conform the suggested shape to the point distribution model, commonly called a "shape model" in this context. The figure to the right shows an example.

The technique has been widely used to analyse images of faces, mechanical assemblies and medical images (in 2D and 3D).

It is closely related to the [active appearance model](https://en.wikipedia.org/wiki/Active_appearance_model). It is also known as a "Smart Snakes"[^o2] method, since it is an analog to an [active contour model](https://en.wikipedia.org/wiki/Active_contour_model) which would respect explicit shape constraints.
