# Nonelementary problem

::: {#o1 .subject cue=lead name="Nonelementary problem"}

In [computational complexity theory](wikipedia://en/7543), a **nonelementary problem**[^o2] is a problem that is not a member of the class [ELEMENTARY](https://en.wikipedia.org/wiki/ELEMENTARY). As a class it is sometimes denoted as NONELEMENTARY. That is, it includes all decision problems that has no algorithmic solution with time bounded by an [elementary recursive function](wikipedia://en/665096). These functions grow no faster than a fixed-height tower of [exponentiation](wikipedia://en/99491) (for example, $O(2^{2^n})$). Not all primitive recursive functions are elementary; for example, [tetration](wikipedia://en/482379) grows too rapidly to be included in the elementary class.

:::

The hierarchy of decidable problems beyond the elementary is usually presented along the [fast-growing hierarchy](wikipedia://en/24947285).[^o3]

Let the functions of the hierarchy be $F_0, F_1, \dots, F_\omega, F_{\omega+1}, \dots$. For each [ordinal](wikipedia://en/26547932) $\alpha$, we define the class $\mathcal F_\alpha$ to be the class of functions computable in time $F_\alpha^{(k)}(n)$, for some positive constant $k$. Here, the notation $F^{(k)}$ indicates [function iteration](https://en.wikipedia.org/wiki/Function_iteration): it is the function obtained by applying $F$ repeatedly, $k$ times. That is,

$$\mathcal F_\alpha := \bigcup_{k = 1}^\infty \mathsf{FDTIME}(F_\alpha^{(k)}(n))$$

Now, define $\mathsf{F}_\alpha$ to be the complexity class $\bigcup_{\beta < \alpha, p \in \mathcal F_\beta} \mathsf{DTIME}(F_\alpha(p(n)))$.

With the definition, we have

- ELEMENTARY: the class of problems decidable in time $f(n)$, where $f(n)$ is a fixed-height exponential tower function. In other words, $\mathsf{ELEMENTARY} = \mathsf{DTIME}(n) \cup \mathsf{DTIME}(2^n) \cup \mathsf{DTIME}(2^{2^n}) \cup \cdots$.
- TOWER: $f(n) = {\;}^{p(n)}2$, where $p(n)$ is a fixed-height exponential tower function, and the superscript denotes [tetration](wikipedia://en/482379). In other words, $f(n) = F_3(p(n))$. In other words, $\mathsf{TOWER} = \mathsf{DTIME}({}^n2) \cup \mathsf{DTIME}({}^{2^n}2) \cup \mathsf{DTIME}({}^{2^{2^n}}2) \cup \cdots$. In other words, $\mathsf{TOWER} := \mathsf{F}_3$.
- PR: $f(n)$ is a [primitive recursive function](wikipedia://en/24829). In other words, $\mathsf{PR} = \mathsf{DTIME}(F_1) \cup \mathsf{DTIME}(F_2) \cup \mathsf{DTIME}(F_3) \cup \cdots$.
- ACK: $f(n) = A(n, n) = F_\omega(n)$, where $A$ is the [Ackermann function](wikipedia://en/2925). In other words, $\mathsf{ACK} := \mathsf{F}_\omega$

By the [time-hierarchy theorem](wikipedia://en/184120), ELEMENTARY and PR have no complete problems. However, TOWER and ACK do have complete problems.

**TOWER**-complete problems:

- Star-Free Expression Equivalence (SFEq)[^o3]
- Satisfiability of the [Weak Monadic Second-Order Logic of One Successor](wikipedia://en/14650395) (WS1S)[^o3]
- Satisfiability of [W. V. O. Quine](https://en.wikipedia.org/wiki/W._V._O._Quine)'s fluted fragment of [first-order logic](wikipedia://en/10983)[^o4]
- β-convertibility of two closed terms in [simply typed lambda calculus](wikipedia://en/1986011)[^o5][^o6]

**ACK**-complete problems:

- [reachability](https://en.wikipedia.org/wiki/Reachability_problem) in [vector addition systems](https://en.wikipedia.org/wiki/Vector_addition_system) (VAS).[^o7][^o8]
- reachability in labeled vector addition system with states (VASS)[^o9]
- [reachability](https://en.wikipedia.org/wiki/Reachability_problem) in [Petri nets](wikipedia://en/225192).[^o10][^o8]

Other nonelementary but decidable problems:

- the problem of [regular expression equivalence with complementation](wikipedia://en/25717#Deciding_equivalence_of_regular_expressions)[^o11]
- the [monadic second-order](https://en.wikipedia.org/wiki/Monadic_second-order) [theory](https://en.wikipedia.org/wiki/Theory_%28logic%29) with two successors (see [S2S](wikipedia://en/72252525))[^o12]
- the [first-order](wikipedia://en/10983) theory of any [term algebra](wikipedia://en/2216678) in a signature containing at least one binary function symbol[^o13]
- finite containment problem (FCP): Given two VAS with finite reachable sets $\operatorname{Reach}(V_1), \operatorname{Reach}(V_2)$, decide whether $\operatorname{Reach}(V_1) \subset \operatorname{Reach}(V_2)$. Its precise level of complexity is unknown. Note that deciding whether the reachable set is finite is EXPSPACE-complete.[^o3]
- The Coverability and Termination problems of certain classes of [well-structured transition systems](https://en.wikipedia.org/wiki/Well-structured_transition_system) are known to be $\mathsf{F}_\omega, \mathsf{F}_{\omega^\omega}, \mathsf{F}_{\omega^{\omega^\omega}},$ or $\mathsf{F}_{\epsilon_0}$-complete.[^o14]
