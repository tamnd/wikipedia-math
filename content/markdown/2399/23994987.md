# Kostant partition function

::: {#o1 .subject cue=lead name="Kostant partition function"}

In [representation theory](wikipedia://en/19378200), a branch of [mathematics](wikipedia://en/18831), the **Kostant partition function**, introduced by (txt), of a [root system](wikipedia://en/277087) $\Delta$ is the number of ways one can represent a vector ([weight](wikipedia://en/277179)) as a non-negative [integer](wikipedia://en/14563) combination of the [positive roots](https://en.wikipedia.org/wiki/Positive_root) $\Delta^+\subset\Delta$. Kostant used it to rewrite the [Weyl character formula](wikipedia://en/5011916) as a formula (the **Kostant multiplicity formula**) for the [multiplicity](wikipedia://en/19211790) of a weight of an [irreducible representation](wikipedia://en/385982) of a [semisimple Lie algebra](wikipedia://en/1337587). An alternative formula, that is more computationally efficient in some cases, is [Freudenthal's formula](wikipedia://en/5011916#Freudenthal.27s_formula).

:::

The Kostant partition function can also be defined for [Kac–Moody algebras](wikipedia://en/1146292) and has similar properties.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

### A<sub>2</sub> {#A2}

*Image: Kostant\_partition\_function\_for\_A2.png.* The Kostant partition function for the A2 root system

*Image: Kostant partition function for the root system B 2.png.* Values of the Kostant partition function for the root system $B_2$. The root system is given the Euclidean coordinates $\alpha_1 = (1,0), \alpha_2 = (-1, 1)$.

Consider the A2 root system, with positive roots $\alpha_1$, $\alpha_2$, and $\alpha_3:=\alpha_1+\alpha_2$. If an element $\mu$ can be expressed as a non-negative integer [linear combination](wikipedia://en/55632) of $\alpha_1$, $\alpha_2$, and $\alpha_3$, then since $\alpha_3=\alpha_1+\alpha_2$, it can also be expressed as a non-negative integer linear combination of the positive [simple roots](https://en.wikipedia.org/wiki/Simple_root) $\alpha_1$ and $\alpha_2$:

$$\mu=n_1\alpha_1+n_2\alpha_2$$

with $n_1$ and $n_2$ being non-negative integers. This expression gives *one* way to write $\mu$ as a non-negative integer combination of positive roots; other expressions can be obtained by replacing $\alpha_1+\alpha_2$ with $\alpha_3$ some number of times. We can do the replacement $k$ times, where $0\leq k\leq\mathrm{min}(n_1,n_2)$. Thus, if the Kostant partition function is denoted by $p$, we obtain the formula

$$p(n_1\alpha_1+n_2\alpha_2)=1+\mathrm{min}(n_1,n_2).$$

This result is shown graphically in the image at right. If an element $\mu$ is not of the form $\mu=n_1\alpha_1+n_2\alpha_2$, then $p(\mu)=0$.

### B<sub>2</sub> {#B2}

The partition function for the other rank 2 root systems are more complicated but are known explicitly.[^o7][^o8]

For B<sub>2</sub>, the positive simple roots are $\alpha_1 = (1, 0), \alpha_2 = (0,1)$, and the positive roots are the simple roots together with $\alpha_3 = (1,1)$ and $\alpha_4 = (2,1)$. The partition function can be viewed as a function of two non-negative integers $n_1$ and $n_2$, which represent the element $n_1 \alpha_1 + n_2 \alpha_2$. Then the partition function $P(n_1, n_2)$ can be defined piecewise with the help of two auxiliary functions.

If $n_1 \leq n_2$, then $P(n_1, n_2) = b(n_1)$. If $n_2 \leq n_1 \leq 2 n_2$, then $P(n_1, n_2) = q_2(n_2) - b(2n_2 - n_1 - 1) = b(n_1) - q_2(n_1 - n_2 - 1)$. If $2n_2 \leq n_1$, then $P(n_1, n_2) = q_2(n_2)$. The auxiliary functions are defined for $n \geq 1$ and are given by $q_2(n) = \frac{1}{2}(n + 1)(n + 2)$ and $b(n) = \frac{1}{4}(n+2)^2$ for $n$ even, $\frac{1}{4}(n+1)(n+3)$ for $n$ odd.

### G<sub>2</sub> {#G2}

For G<sub>2</sub>, the positive roots are $(1,0), (0,1), (1,1), (2,1), (3,1)$ and $(3,2)$, with $(1,0)$ denoting the short simple root and $(0,1)$ denoting the long simple root.

The partition function is defined piecewise with the domain divided into five regions, with the help of two auxiliary functions.

## Relation to the Weyl character formula {#Relation_to_the_Weyl_character_formula}

### Inverting the Weyl denominator {#Inverting_the_Weyl_denominator}

For each root $\alpha$ and each $H\in\mathfrak{h}$, we can *formally* apply the formula for the sum of a [geometric series](wikipedia://en/12630) to obtain

$$\frac{1}{1-e^{-\alpha(H)}}=1+e^{-\alpha(H)}+e^{-2\alpha(H)}+\cdots$$

where we do not worry about convergence—that is, the equality is understood at the level of [formal power series](wikipedia://en/60012). Using [Weyl's denominator formula](wikipedia://en/5011916#Weyl_denominator_formula)

$${\sum_{w\in W} (-1)^{\ell(w)}e^{w\cdot\rho(H)} = e^{\rho(H)}\prod_{\alpha>0}(1-e^{-\alpha(H)})},$$

we obtain a formal expression for the reciprocal of the Weyl denominator:[^o13]

$$\begin{aligned} \frac{1}{\sum_{w\in W} (-1)^{\ell(w)}e^{w\cdot\rho(H)}}&{}=e^{-\rho(H)}\prod_{\alpha>0}(1+e^{-\alpha(H)}+e^{-2\alpha(H)}+e^{-3\alpha(H)}+\cdots) \\ &{}=e^{-\rho(H)}\sum_{\mu}p(\mu)e^{-\mu(H)} \end{aligned}$$

Here, the first equality is by taking a product over the positive roots of the geometric series formula and the second equality is by counting all the ways a given exponential $e^{\mu(H)}$ can occur in the product. The function $\ell(w)$ is zero if the argument is a rotation and one if the argument is a reflection.

::: {#o15 .statement cue=named-heading name="Rewriting the character formula"}

### Rewriting the character formula {#Rewriting_the_character_formula}

This argument shows that we can convert the [Weyl character formula](wikipedia://en/5011916) for the irreducible representation with highest weight $\lambda$:

$$\operatorname{ch}V = {\sum_{w\in W} (-1)^{\ell(w)}e^{w\cdot(\lambda+\rho)(H)} \over \sum_{w\in W} (-1)^{\ell(w)}e^{w\cdot\rho(H)}}$$

from a quotient to a product:

$$\operatorname{ch}V = \left(\sum_{w\in W} (-1)^{\ell(w)}e^{w\cdot(\lambda+\rho)(H)}\right) \left(e^{-\rho(H)}\sum_{\mu}p(\mu)e^{-\mu(H)}\right) .$$

:::

::: {#o17 .statement cue=named-heading name="The multiplicity formula"}

### The multiplicity formula {#The_multiplicity_formula}

Using the preceding rewriting of the character formula, it is relatively easy to write the character as a sum of exponentials. The coefficients of these exponentials are the multiplicities of the corresponding weights. We thus obtain a formula for the multiplicity of a given weight $\mu$ in the irreducible representation with highest weight $\lambda$:[^o18]

$$\operatorname{mult} \mu = \sum_{w\in W}(-1)^{\ell(w)}p(w\cdot(\lambda+\rho)-(\mu+\rho)).$$

This result is the **Kostant multiplicity formula**.

The dominant term in this formula is the term $w=1$; the contribution of this term is $p(\lambda-\mu)$, which is just the multiplicity of $\mu$ in the [Verma module](wikipedia://en/2975234) with highest weight $\lambda$. If $\lambda$ is sufficiently far inside the fundamental Weyl chamber and $\mu$ is sufficiently close to $\lambda$, it may happen that all other terms in the formula are zero. Specifically, unless $w\cdot(\lambda+\rho)$ is higher than $\mu+\rho$, the value of the Kostant partition function on $w\cdot(\lambda+\rho)-(\mu+\rho)$ will be zero. Thus, although the sum is nominally over the whole Weyl group, in most cases, the number of nonzero terms is smaller than the order of the Weyl group.
