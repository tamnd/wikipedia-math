# Multiple edges

*Image: Multiple edges.png.* Multiple edges joining two vertices.

::: {#o1 .subject cue=lead name="Multiple edges"}

In [graph theory](wikipedia://en/12401), **multiple edges** (also called **parallel edges** or a **multi-edge**), are, in an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph), two or more [edges](https://en.wikipedia.org/wiki/Edge_%28graph_theory%29) that are [incident](https://en.wikipedia.org/wiki/Incident_%28graph_theory%29) to the same two [vertices](wikipedia://en/638899), or in a [directed graph](wikipedia://en/19721986), two or more edges with both the same tail vertex and the same head vertex. A [simple graph](https://en.wikipedia.org/wiki/Simple_graph) has no multiple edges and no [loops](wikipedia://en/1449083).

:::

Depending on the context, a [graph](wikipedia://en/325806) may be defined so as to either allow or disallow the presence of multiple edges (often in concert with allowing or disallowing loops):

- Where graphs are defined so as to *allow* multiple edges and loops, a graph without loops or multiple edges is often distinguished from other graphs by calling it a *simple graph.*[^o2]
- Where graphs are defined so as to *disallow* multiple edges and loops, a [multigraph](wikipedia://en/1774970) or a [pseudograph](https://en.wikipedia.org/wiki/Pseudograph) is often defined to mean a "graph" which *can* have multiple edges.[^o3]

Multiple edges are, for example, useful in the consideration of [electrical networks](wikipedia://en/9559), from a graph theoretical point of view.[^o4] Additionally, they constitute the core differentiating feature of [multidimensional networks](wikipedia://en/44342518).

A [planar graph](wikipedia://en/24314) remains planar if an edge is added between two vertices already joined by an edge; thus, adding multiple edges preserves planarity.[^o5]

A [dipole graph](wikipedia://en/6412575) is a graph with two vertices, in which all edges are parallel to each other.
