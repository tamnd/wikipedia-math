# Poisson wavelet

::: {#o1 .subject cue=lead name="Poisson wavelet"}

In mathematics, in functional analysis, several different [wavelets](wikipedia://en/50903) are known by the name **Poisson wavelet**. In one context, the term "Poisson wavelet" is used to denote a family of wavelets labeled by the set of [positive integers](https://en.wikipedia.org/wiki/Positive_integer), the members of which are associated with the [Poisson probability distribution](https://en.wikipedia.org/wiki/Poisson_probability_distribution). These wavelets were first defined and studied by Karlene A. Kosanovich, Allan R. Moser and Michael J. Piovoso in 1995–96.[^o2][^o3] In another context, the term refers to a certain wavelet which involves a form of the Poisson integral kernel.[^o4] In still another context, the terminology is used to describe a family of complex wavelets indexed by positive integers which are connected with the derivatives of the Poisson integral kernel.[^o5]

:::

## Wavelets associated with Poisson probability distribution {#Wavelets_associated_with_Poisson_probability_distribution}

::: {#o8 .definition cue=heading name="Definition"}

### Definition {#Definition}

*Image: PoissonWavelets.png.* Members of the family of Poisson wavelets corresponding to *n* = 1, 2, 3, 4.

For each positive integer *n* the Poisson wavelet $\psi_n(t)$ is defined by

$$\psi_n(t) = \begin{cases} \left(\frac{t-n}{n!}\right) t^{n-1}e^{-t} & \text{ for } t\ge 0 \\ 0 & \text{ for } t<0.\end{cases}$$

To see the relation between the Poisson wavelet and the Poisson distribution let *X* be a discrete [random variable](wikipedia://en/25685) having the Poisson distribution with parameter (mean) *t* and, for each non-negative integer *n*, let Prob(*X* = *n*) = *p*<sub>*n*</sub>(*t*). Then we have

$$p_n(t) = \frac{t^n}{n!}e^{-t}.$$

The Poisson wavelet $\psi_n(t)$ is now given by

$$\psi_n(t) = -\frac{d}{dt}p_n(t).$$

:::

::: {#o10 .statement kind=statement/fact cue=heading name="Basic properties"}

### Basic properties {#Basic_properties}

- $\psi_n(t)$ is the backward difference of the values of the Poisson distribution:

$$\psi_n(t)=p_n(t)-p_{n-1}(t).$$

- The "waviness" of the members of this wavelet family follows from

$$\int_{-\infty}^{\infty}\psi_n(t)\,dt =0.$$

- The [Fourier transform](wikipedia://en/52247) of $\psi_n(t)$ is given

$$\Psi(\omega)=\frac{-i\omega}{(1+i\omega)^{n+1}}.$$

- The admissibility constant associated with $\psi_n(t)$ is

$$C_{\psi_n} = \int_{-\infty}^{\infty}\frac{\left|\Psi_n(\omega)\right|^2}{|\omega|}\, d\omega =\frac{1}{n}.$$

- Poisson wavelet is not an orthogonal family of wavelets.

:::

### Poisson wavelet transform {#Poisson_wavelet_transform}

The Poisson wavelet family can be used to construct the family of Poisson wavelet transforms of functions defined the time domain. Since the Poisson wavelets satisfy the admissibility condition also, functions in the time domain can be reconstructed from their Poisson wavelet transforms using the formula for inverse continuous-time wavelet transforms.

If *f*(*t*) is a function in the time domain its *n*-th Poisson wavelet transform is given by

$$(W_nf)(a,b) = \frac{1}{\sqrt{|a|}}\int_{-\infty}^{\infty} f(t)\psi_n\left(\frac{t-b}{a}\right)\, dt$$

In the reverse direction, given the *n*-th Poisson wavelet transform $(W_nf)(a,b)$ of a function *f*(*t*) in the time domain, the function *f*(*t*) can be reconstructed as follows:

$$f(t)=\frac{1}{C_{\psi_n}} \int_{-\infty}^{\infty} \left[ \int_{-\infty}^{\infty} \, \left\{(W_nf)(a,b)\frac{1}{\sqrt{|a|}} \psi_n\left(\frac{t-b}{a}\right)\,\right\} db\right] \frac{da}{a^2}$$

::: {#o13 .application cue=heading name="Applications"}

### Applications {#Applications}

Poisson wavelet transforms have been applied in multi-resolution analysis, [system identification](wikipedia://en/552466), and parameter estimation. They are particularly useful in studying problems in which the functions in the time domain consist of linear combinations of decaying exponentials with time delay.

:::

## Wavelet associated with Poisson kernel {#Wavelet_associated_with_Poisson_kernel}

*Image: PoissonWaveletFromPoissonKernel.png.* Image of the wavelet associated with the Poisson kernel.

*Image: FourierTransformOfPoissonWaveletFromPoissonKernel.png.* Image of the Fourier transform of the wavelet associated with the Poisson kernel.

::: {#o16 .definition cue=heading name="Definition"}

### Definition {#Definition}

The Poisson wavelet is defined by the function[^o4]

$$\psi(t)=\frac{1}{\pi}\frac{1-t^2}{(1+t^2)^2}$$

This can be expressed in the form

$\psi(t)=P(t) + t\frac{d}{dt}P(t)$ where $P(t)=\frac{1}{\pi}\frac{1}{1+t^2}$.

:::

### Relation with Poisson kernel {#Relation_with_Poisson_kernel}

The function $P(t)$ appears as an [integral kernel](https://en.wikipedia.org/wiki/Integral_kernel) in the solution of a certain [initial value problem](wikipedia://en/498383) of the [Laplace operator](wikipedia://en/174706).

This is the initial value problem: Given any $s(x)$ in $L^p(\mathbb R)$, find a harmonic function $\phi(x,y)$ defined in the [upper half-plane](wikipedia://en/287826) satisfying the following conditions:

1. $\int_{-\infty}^\infty |\phi(x,y)|^p\, dx \le c < \infty$, and
1. $\phi(x,y)\rightarrow s(x)$ as $y\rightarrow 0$ in $L^p(\mathbb R)$.

The problem has the following solution: There is exactly one function $\phi(x,y)$ satisfying the two conditions and it is given by

$$\phi(t,y)= P_y(t)\star s(t)$$

where $P_y(t)=\frac{1}{y}P\left(\frac{t}{y}\right)=\frac{1}{\pi}\frac{y}{t^2+y^2}$ and where "$\star$" denotes the [convolution operation](https://en.wikipedia.org/wiki/Convolution_operation). The function $P_y(t)$ is the integral kernel for the function $\phi(x,y)$. The function $\phi(x,y)$ is the harmonic continuation of $s(x)$ into the upper half plane.

::: {#o19 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

- The "waviness" of the function follows from

$$\int_{-\infty}^\infty \psi(t)\, dt=0.$$

- The Fourier transform of $\psi(t)$ is given by

$$\Psi(\omega) = |\omega|e^{-|\omega|}.$$

- The admissibility constant is

$$C_{\psi} = \int_{-\infty}^{\infty}\frac{\left|\Psi(\omega)\right|^2}{|\omega|}\, d\omega =2.$$

:::

## A class of complex wavelets associated with the Poisson kernel {#A_class_of_complex_wavelets_associated_with_the_Poisson_kernel}

*Image: RealPartsOfPoissonWavelets.png.* The graphs of the real parts of the Poisson wavelet $\psi_n(t)$ for $n=1,2,3,4$.

*Image: ImaginaryPartsOfPoissonWavelets.png.* The graphs of the imaginary parts of the Poisson wavelet $\psi_n(t)$ for $n=1,2,3,4$.

::: {#o22 .definition cue=heading name="Definition"}

### Definition {#Definition}

The Poisson wavelet is a family of complex valued functions indexed by the set of positive integers and defined by[^o5][^o23]

$\psi_n(t)=\frac{1}{2\pi}(1-it)^{-(n+1)}$ where $n=1,2,3, \ldots$

:::

### Relation with Poisson kernel {#Relation_with_Poisson_kernel}

The function $\psi_n(t)$ can be expressed as an *n*-th derivative as follows:

$$\psi_n(t)= \frac{1}{2\pi}\frac{1}{n!\, i^n}\frac{d^n}{dt^n}\left((1-it)^{-1}\right)$$

Writing the function $(1-it)^{-1}$ in terms of the Poisson integral kernel $P(t)=\frac{1}{1+t^2}$ as

$$(1-it)^{-1}= P(t)+itP(t)$$

we have

$$\psi_n(t)=\frac{1}{2\pi}\frac{1}{n!\,i^n}\frac{d^n}{dt^n}P(t) + i \left(\frac{1}{2\pi}\frac{1}{n!\, i^n}\frac{d^n}{dt^n}\left(tP(t)\right)\right)$$

Thus $\psi_n(t)$ can be interpreted as a function proportional to the derivatives of the Poisson integral kernel.

::: {#o26 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

The Fourier transform of $\psi_n(t)$ is given by

$$\Psi_n(\omega) = \frac{1}{\Gamma(n+1)}\omega^n e^{-\omega}u(\omega)$$

where $u(\omega)$ is the [unit step function](https://en.wikipedia.org/wiki/Unit_step_function).

:::
