# List of computer algebra systems

::: {#o1 .subject cue=lead name="List of computer algebra systems"}

The following tables provide a **comparison of [computer algebra systems](wikipedia://en/54427)** (CAS).[^o2][^o3][^o4] A CAS is a package comprising a set of algorithms for performing symbolic manipulations on algebraic objects, a language to implement them, and an environment in which to use the language.[^o5][^o6] A CAS may include a user interface and graphics capability, and to be effective may require a large library of algorithms, efficient data structures, and a fast kernel.[^o7]

:::
