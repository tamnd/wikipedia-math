# Distribution ensemble

::: {#o1 .subject cue=lead name="Distribution ensemble"}

In [cryptography](wikipedia://en/18934432), a **distribution ensemble** or **probability ensemble** is a family of distributions or [random variables](wikipedia://en/25685) $X = \{X_i\}_{i \in I}$ where $I$ is a ([countable](https://en.wikipedia.org/wiki/Countable)) index set, and each $X_i$ is a random variable, or [probability distribution](wikipedia://en/23543). Often $I=\mathbb{N}$ and it is required that each $X_n$ have a certain property for *n* sufficiently large.

:::

For example, a **uniform ensemble** $U = \{U_n\}_{n \in \mathbb{N}}$ is a distribution ensemble where each $U_n$ is [uniformly distributed](https://en.wikipedia.org/wiki/Uniform_distribution_%28discrete%29) over strings of length *n*. In fact, many applications of probability ensembles implicitly assume that the probability spaces for the random variables all coincide in this way, so every probability ensemble is also a [stochastic process](wikipedia://en/47895#Definitions).
