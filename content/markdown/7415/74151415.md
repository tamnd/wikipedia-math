# Fresh variable

::: {#o1 .subject cue=lead name="Fresh variable"}

In formal reasoning, in particular in [mathematical logic](wikipedia://en/19636), [computer algebra](wikipedia://en/23659805), and [automated theorem proving](wikipedia://en/2546), a **fresh variable** is a variable that did not occur in the context considered so far.[^o2] The concept is often used without explanation.[^o3]

:::

Fresh variables may be used to replace other variables, to eliminate [variable shadowing](https://en.wikipedia.org/wiki/Variable_shadowing) or capture. For instance, in [alpha-conversion](https://en.wikipedia.org/wiki/Alpha-conversion), the processing of terms in the [lambda calculus](wikipedia://en/18203) into equivalent terms with renamed variables, replacing variables with fresh variables can be helpful as a way to avoid accidentally capturing variables that should be [free](https://en.wikipedia.org/wiki/Free_variable).[^o4] Another use for fresh variables involves the development of [loop invariants](https://en.wikipedia.org/wiki/Loop_invariant) in [formal program verification](https://en.wikipedia.org/wiki/Formal_verification), where it is sometimes useful to replace constants by newly introduced fresh variables.[^o5]

::: {#o7 .example cue=heading name="Example"}

## Example {#Example}

For example, in [term rewriting](https://en.wikipedia.org/wiki/Term_rewriting), before applying a rule $l \to r$ to a given term $t$, each variable in $l \to r$ should be replaced by a fresh one to avoid clashes with variables occurring in $t$. Given the rule

$$\operatorname{append}(\operatorname{cons}(x,y),z) \to \operatorname{cons}(x,\operatorname{append}(y,z))$$

and the term

$$\operatorname{append}(\operatorname{cons}(x,\operatorname{cons}(y,\mathrm{nil})),\operatorname{cons}(3,\mathrm{nil})),$$

attempting to find a matching substitution of the rule's left-hand side, $\operatorname{append}(\operatorname{cons}(x,y),z)$, within $\operatorname{append}(\operatorname{cons}(x,\operatorname{cons}(y,\mathrm{nil})),\operatorname{cons}(3,\mathrm{nil}))$ will fail, since $y$ cannot match $\operatorname{cons}(y,\mathrm{nil})$. However, if the rule is replaced by a *fresh copy*

$$\operatorname{append}(\operatorname{cons}(v_1,v_2),v_3) \to \operatorname{cons}(v_1,\operatorname{append}(v_2,v_3))$$

before, matching will succeed with the answer substitution

$$\{ v_1 \mapsto x, \; v_2 \mapsto \operatorname{cons}(y,\mathrm{nil}), \; v_3 \mapsto \operatorname{cons}(3,\mathrm{nil}) \}.$$

:::
