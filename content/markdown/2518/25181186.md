# SMASH (hash)

::: {#o4 .subject cue=lead name="SMASH"}

**SMASH** is a [cryptographic hash function](wikipedia://en/439526) which was created by [Lars R. Knudsen](https://en.wikipedia.org/wiki/Lars_R._Knudsen).[^o5] SMASH comes in two versions: 256-bit and 512-bit. Each version was supposed to rival [SHA-256](https://en.wikipedia.org/wiki/SHA-256) and [SHA-512](https://en.wikipedia.org/wiki/SHA-512), respectively, however, shortly after the SMASH presentation at [FSE 2005](https://en.wikipedia.org/wiki/FSE_2005), an attack vector against SMASH was discovered which left the hash broken.

:::

## Specifications {#Specifications}

The message length was limited to less than 2<sup>128</sup> for SMASH-256 and 2<sup>256</sup> for SMASH-512.

::: {#o8 .definition cue=heading name="Definition"}

## Definition {#Definition}

Input: 256/512-bit message blocks $m_1, m_2, ... ,m_t$ and $\theta \in GF(2^n)$

- $$h_0 = f(iv) \oplus iv$$
- $$h_i = h(h_{i-1},m_i) = f(h_{i_1}\oplus m_i) \oplus m_i \oplus \theta m_i$$
- $$h_{t+1} = f(h_t) \oplus h_t$$

The function f is a complex compression function consisting of H-Rounds and L-Rounds using [S-boxes](https://en.wikipedia.org/wiki/S-boxes), [linear diffusion](https://en.wikipedia.org/wiki/Linear_diffusion) and variable rotations, details can be found here [^o5]

:::

## Details {#Details}

The [S-boxes](https://en.wikipedia.org/wiki/S-boxes) in SMASH are derived versions from the [Serpent](wikipedia://en/385154) ones.
