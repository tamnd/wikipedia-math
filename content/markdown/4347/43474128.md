# 1-in-3-SAT

::: {#o1 .subject cue=lead name="1-in-3-SAT"}

In [computational complexity](wikipedia://en/6511), **one-in-three 3-SAT** (also known variously as **1-in-3-SAT** and **exactly-1 3-SAT**) is an [NP-complete](https://en.wikipedia.org/wiki/NP-complete) variant of the [Boolean satisfiability problem](wikipedia://en/4715).

:::

Given a [conjunctive normal form](wikipedia://en/73342) with three literals per clause, the problem is to determine whether there exists a truth assignment to the variables so that each clause has *exactly* one TRUE literal (and thus exactly two FALSE literals). In contrast, ordinary 3-SAT requires that every clause has *at least* one TRUE literal. Formally, a one-in-three 3-SAT problem is given as a generalized conjunctive normal form with all generalized clauses using a ternary operator *R* that is TRUE just if exactly one of its arguments is. When all the variables of a one-in-three 3-SAT formula have the same literal, the satisfiability problem is called **one-in-three monotone 3-SAT**.

One-in-three 3-SAT, together with its monotone case, is listed as NP-complete problem "LO4" in the standard reference *Computers and Intractability: A Guide to the Theory of NP-Completeness* by [Michael R. Garey](https://en.wikipedia.org/wiki/Michael_R._Garey) and [David S. Johnson](https://en.wikipedia.org/wiki/David_S._Johnson). One-in-three 3-SAT was proved to be NP-complete by [Thomas Jerome Schaefer](wikipedia://en/55872451) as a special case of [Schaefer's dichotomy theorem](wikipedia://en/4638322), which asserts that any problem generalizing Boolean satisfiability in a certain way is either in the class P or is NP-complete.[^o2]

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

Here is a satisfiable 1-in-3-SAT instance of 3 variables and 1 clause:

$$R(\neg a, b, c)$$

This instance admits 3 solutions:

- a=false, b=false, c=false
- a=true, b=true, c=false
- a=true, b=false, c=true

Here is a unique 1-in-3-SAT instance, that is to say a 1-in-3-SAT instance that admits exactly one solution:

$$R(a, b, c) \land R(g, h, i) \land R(a, d, h) \land R(b, d, g) \land R(b, e, h) \land R(c, f, i)$$

The unique solution is a=true, b=false, c=false, d=false, e=true, f=true, g=true, h=false, i=false

## Reduction from 3-SAT to 1-in-3-SAT {#Reduction_from_3-SAT_to_1-in-3-SAT}

Schaefer gives a construction allowing an easy polynomial-time [reduction](wikipedia://en/848067) from 3-SAT to one-in-three 3-SAT. Let "(*x* or *y* or *z*)" be a clause in a 3CNF formula. Add six fresh Boolean variables *a*, *b*, *c*, *d*, *e*, and *f*, to be used to simulate this clause and no other. Then the formula *R*(*x*,*a*,*d*) ∧ *R*(*y*,*b*,*d*) ∧ *R*(*a*,*b*,*e*) ∧ *R*(*c*,*d*,*f*) ∧ *R*(*z*,*c*,FALSE) is satisfiable by some setting of the fresh variables if and only if at least one of *x*, *y*, or *z* is TRUE, see table (below). Thus any 3-SAT instance with *m* clauses and *n* variables may be converted into an [equisatisfiable](https://en.wikipedia.org/wiki/Equisatisfiable) one-in-three 3-SAT instance with 5*m* clauses and *n* + 6*m* variables.[^n1]

## Positive 1-in-3-SAT {#Positive_1-in-3-SAT}

**Positive one-in-three 3-SAT** is a specific case where all the literals of the formula are positive. Positive 1-in-3-SAT is NP-complete. A 1-in-3-SAT formula can be reduced in polynomial time to positive 1-in-3-SAT formula by introducing hidden variables that are the negative of the variables appearing with a negative literal. Then some clauses have to be added to force those new variables to be the negative:

$$R(a \lor b \lor \neg c) => R(a \lor b \lor c') \land R(c \lor c' \lor \operatorname{alwaysZero}) \land R(c \lor c' \lor \operatorname{alwaysZeroToo}) \land R(\operatorname{alwaysZero} \lor \operatorname{alwaysZeroToo} \lor \operatorname{alwaysOne})$$

$c'$ is a new variable that is always the negative of $c$ and the new variables $\operatorname{alwaysZero}$, $\operatorname{alwaysZeroToo}$ and $\operatorname{alwaysOne}$ are constants and can be reused for the reductions of the other clauses. For a formula of $n$ variables and $m$ clauses, the reduced formula has at most $2n + 3$ variables and $7m + 1$ clauses but it can be less if we allow constants or the same variable twice in a clause.

## Simplification rules {#Simplification_rules}

Some rules allow to make the size of an instance smaller in polynomial time. Like other NP-complete problems, if a group of variables doesn't share any clause with the remaining group of variables, so the two groups represent two distinct 1-in-3-SAT instances that can be computed independently. The solutions of the original instance is the [cartesian product](wikipedia://en/24104095) of the solutions of the two instances and the original instance is unsolveable if at least one sub-instance is unsolveable.

Local analysis can simplify an instance:

- A clause including the $1$ constant can be safely removed and the remaining literals of the clause are set to $0$.
- A clause including twice $0$ constant can be safely removed and the remaining literal of the clause is set to $1$.
- A clause including one $0$ constant can be safely removed and one literal of the clause can be replaced by the opposite of the third literal of the clause.
- A clause including twice the same literal can be safely removed, the literal is set to $0$ and the third literal to $1$.
- A clause including a literal and its opposite can be safely removed and the third literal is set to $0$.

Some rules imply two clauses:

- When two clauses share two same variables with the same literals, only one clause is kept and the third literals in the both clauses are equal so one is replaced by the other in the entire instance.
- When two clauses share two same variables with opposite literals, we can safely remove the both clauses, replace one variable by the opposite of the other and set the third literals in the both clause to $0$.
- When two clauses share two same variables with one opposite and one same literals, we can safely remove the both clauses, set the variable with the same literal to $0$ and the third literals can be replaced by the opposite of the variable with the opposite literal.

The following rule is a pattern implying four clauses:

$$R(x_{1} \lor y_{1} \lor z_{1}) \land$$

$$R(x_{1} \lor y_{2} \lor z_{2}) \land$$

$$R(x_{2} \lor y_{1} \lor z_{3}) \land$$

$$R(x_{2} \lor y_{2} \lor z_{1})$$

At the first position (in real world, it may be at any position), two literals are present twice, at the second position, two literals are present twice, and at the third position, one literal is present twice but no clause share two identical literals. It can be simplified this way:

$$R(x_{1} \lor y_{1} \lor z_{1})$$

$$x_{1} = x_{2}$$

$$y_{1} = y_{2}$$

$$z_{1} = z_{2}= z_{3}$$

The following rule is a pattern implying a dynamic number of clauses:

$$R(x_{1} \lor y_{1} \lor z_{1}) \land$$

$$R(x_{2} \lor y_{1} \lor z_{2}) \land$$

$$R(x_{2} \lor y_{2} \lor z_{1}) \land$$

$$R(x_{3} \lor y_{3} \lor z_{2}) \land$$

$$R(x_{3} \lor y_{2} \lor z_{3}) \land$$

$$...$$

$$R(x_{n-1} \lor y_{n-1} \lor z_{n-2}) \land$$

$$R(x_{n-1} \lor y_{n-2} \lor z_{n-1}) \land$$

$$R(x_{n} \lor y_{n-1} \lor z_{n-1})$$

We can replace $x_{n}$ by $x_{1}$.

::: {#o12 .proof cue=inline-head name="Proof"}

***Proof***

- If x<sub>1</sub>=0, so y<sub>1</sub>=1 or z<sub>1</sub>=1 so x<sub>2</sub>=0 so y<sub>2</sub>=1 or z<sub>2</sub>=1 so x<sub>3</sub>=0 so y<sub>3</sub>=1 or z<sub>3</sub>=1 ... so x<sub>n−1</sub>=0 so y<sub>n−1</sub>=1 or z<sub>n−1</sub>=1 so x<sub>n</sub>=0
- If x<sub>1</sub>=1, so y<sub>1</sub>=z<sub>1</sub>=0 so y<sub>2</sub>=z<sub>2</sub> so y<sub>3</sub>=z<sub>3</sub> ... so y<sub>n−1</sub>=z<sub>n−1</sub> so y<sub>n−1</sub>=z<sub>n−1</sub>=0 and x<sub>n</sub>=1

:::
