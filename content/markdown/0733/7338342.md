# Homology manifold

::: {#o1 .subject cue=lead name="Homology manifold"}

In [mathematics](wikipedia://en/18831), a **homology manifold** (or **generalized manifold**) is a [locally compact topological space](https://en.wikipedia.org/wiki/Locally_compact_topological_space) *X* that looks locally like a [topological manifold](wikipedia://en/2119193) from the point of view of [homology theory](https://en.wikipedia.org/wiki/Homology_theory).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A **homology *G*-manifold** (without boundary) of dimension *n* over an abelian group *G* of coefficients is a locally compact topological space X with finite *G*-[cohomological dimension](wikipedia://en/9880197) such that for any *x*∈*X*, the [homology groups](wikipedia://en/142432#Construction_of_homology_groups)

$$H_p(X,X-x, G)$$

are trivial unless *p*=*n*, in which case they are isomorphic to *G*. Here *H* is some homology theory, usually [singular homology](wikipedia://en/431041). Homology manifolds are the same as homology **Z**-manifolds.

More generally, one can define homology manifolds with boundary, by allowing the local homology groups to vanish at some points, which are of course called the boundary of the homology manifold. The boundary of an *n*-dimensional [first-countable](https://en.wikipedia.org/wiki/First-countable) homology manifold is an *n*−1 dimensional homology manifold (without boundary).

:::

::: {#o5 .example cue=heading name="Examples"}

## Examples {#Examples}

- Any topological manifold is a homology manifold.
- An example of a homology manifold that is not a manifold is the suspension of a [homology sphere](wikipedia://en/585388) that is not a sphere.

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If *X*×*Y* is a topological manifold, then *X* and *Y* are homology manifolds.

:::
