# Indicator function (convex analysis)

::: {#o1 .subject cue=lead name="Indicator function"}

In the field of [mathematics](wikipedia://en/18831) known as [convex analysis](wikipedia://en/3237201), the **indicator function** of a set is a [convex function](wikipedia://en/245568) that indicates the membership (or non-membership) of a given element in that set. It is similar to the [indicator function](wikipedia://en/240790) used in probability, but assigns $+ \infty$ instead of $0$ to the outside elements.

:::

*Each field seems to have its own meaning of an "indicator function", as in [complex analysis](wikipedia://en/69319810) for instance.*

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $X$ be a [set](wikipedia://en/26691), and let $A$ be a [subset](wikipedia://en/27631) of $X$. The **indicator function** of $A$ is the function [^o4] [^o5] [^o6] [^o7]

$$\iota_{A} : X \to \mathbb{R} \cup \{ + \infty \}$$

taking values in the [extended real number line](wikipedia://en/51698) defined by

$$\iota_{A} (x) := \begin{cases} 0, & x \in A; \\ + \infty, & x \not \in A. \end{cases}$$

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

This function is convex if and only if the set $A$ is convex.[^o10]

This function is lower-semicontinuous if and only if the set $A$ is closed.[^o7]

For any arbitrary sets $A$ and $B$, it is that $\iota_A + \iota_B = \iota_{A\cap B}$.

For an arbitrary non-empty set its [Legendre transform](wikipedia://en/390273) is the [support function](wikipedia://en/9377661).[^o11]

The subgradient of $\iota_{A} (x)$ for a set $A$ and $x\in A$ is the [normal cone](wikipedia://en/3558266) of that set at $x$.[^o12]

Its [infimal convolution](https://en.wikipedia.org/wiki/Infimal_convolution) with the Euclidean norm $||\cdot||_2$ is the [Euclidean distance](wikipedia://en/53932) to that set.[^o13]

:::
