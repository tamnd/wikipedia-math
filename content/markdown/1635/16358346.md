# Muckenhoupt weights

::: {#o1 .subject cue=lead name="Muckenhoupt weights"}

In [mathematics](wikipedia://en/18831), the class of **Muckenhoupt weights** $A_{p}$ consists of those weights $\omega$ for which the [Hardy–Littlewood maximal operator](https://en.wikipedia.org/wiki/Hardy–Littlewood_maximal_operator) is bounded on $L^{p}(d\omega)$. Specifically, we consider functions $\,f\,$ on $\mathbf{R}^{n}$ and their associated [maximal functions](wikipedia://en/16358287) $M(\,f\,)$ defined as

:::

$$M(f)(x) = \sup_{r>0} \frac{1}{r^n} \int_{B_r(x)} |f|,$$

where $B_{r}(x)$ is the ball in $\mathbf{R}^{n}$ with radius $r$ and center at $x$. Let $1 \le p < \infty$, we wish to characterise the functions $\omega : \mathbf{R}^{n} \to [0, \infty)$ for which we have a bound

$$\int |M(f)(x)|^p \, \omega(x) dx \leq C \int |f|^p \, \omega(x)\, dx,$$

where $C$ depends only on $p$ and $\omega$. This was first done by [Benjamin Muckenhoupt](https://en.wikipedia.org/wiki/Benjamin_Muckenhoupt).[^o2]

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a fixed $1 < p < \infty$, we say that a weight $\omega : \mathbf{R}^{n} \to [0, \infty)$ belongs to $A_{p}$ if $\omega$ is locally integrable and there is a constant $C$ such that, for all balls $B$ in $\mathbf{R}^{n}$, we have

$$\left(\frac{1}{|B|} \int_B \omega(x) \, dx \right)\left(\frac{1}{|B|} \int_B \omega(x)^{-\frac{q}{p}} \, dx \right)^\frac{p}{q} \leq C < \infty,$$

where $|B|$ is the [Lebesgue measure](wikipedia://en/18198) of $B$, and $q$ is a [real number](wikipedia://en/20646438) such that: $\tfrac{1}{p} + \tfrac{1}{q} = 1$.

We say $\omega : \mathbf{R}^{n} \to [0, \infty)$ belongs to $A_{1}$ if there exists some $C$ such that

$$\frac{1}{|B|} \int_B \omega(y) \, dy \leq C\omega(x),$$

for almost every $x \in B$ and all balls $B$.[^o5]

:::

## Equivalent characterizations {#Equivalent_characterizations}

This following result is a fundamental result in the study of Muckenhoupt weights.

**Theorem.** Let $1 < p < \infty$. A weight $\omega$ is in $A_{p}$ [if and only if](wikipedia://en/14922) any one of the following hold.[^o5]

(a) The [Hardy–Littlewood maximal function](wikipedia://en/10094198) is bounded on $L^{p}(\omega(x)dx)$, that is

$$\int |M(f)(x)|^p \, \omega(x)\, dx \leq C \int |f|^p \, \omega(x)\, dx,$$

for some $C$ which only depends on $p$ and the constant $A$ in the above definition.

(b) There is a constant $c$ such that for any locally integrable function $\,f\,$ on $\mathbf{R}^{n}$, and all balls $B$:

$$(f_B)^p \leq \frac{c}{\omega(B)} \int_B f(x)^p \, \omega(x)\,dx,$$

where:

$$f_B = \frac{1}{|B|}\int_B f, \qquad \omega(B) = \int_B \omega(x)\,dx.$$

Equivalently:

**Theorem.** Let $1 < p < \infty$, then $w = e^{\varphi} \in A_{p}$ if and only if both of the following hold:

$$\sup_{B}\frac{1}{|B|}\int_{B}e^{\varphi-\varphi_B}dx<\infty$$

$$\sup_{B}\frac{1}{|B|}\int_{B}e^{-\frac{\varphi-\varphi_B}{p-1}}dx<\infty.$$

This equivalence can be verified by using [Jensen's Inequality](https://en.wikipedia.org/wiki/Jensen's_Inequality).

## Reverse Hölder inequalities and $A_{\infty}$ {#Reverse_Hölder_inequalities_and}

The main tool in the proof of the above equivalence is the following result.[^o5] The following statements are equivalent

1. $\omega \in A_{p}$ for some $1 \le p < \infty$.
1. There exist $0 < \delta, \gamma < 1$ such that for all balls $B$ and subsets $E \subset B$, $|E| \le \gamma\,|B|$ implies $\omega(E) \le \delta\,\omega(B)$.
1. There exist $1 < q$ and $c$ (both depending on $\omega$) such that for all balls $B$ we have:

$$\frac{1}{|B|} \int_{B} \omega^q \leq \left(\frac{c}{|B|} \int_{B} \omega \right)^q.$$

We call the inequality in the third formulation a reverse Hölder inequality as the reverse inequality follows for any non-negative function directly from [Hölder's inequality](wikipedia://en/191538). If any of the three equivalent conditions above hold we say $\omega$ belongs to $A_{\infty}$.

## Weights and BMO {#Weights_and_BMO}

The definition of an $A_{p}$ weight and the reverse Hölder inequality indicate that such a weight cannot degenerate or grow too quickly. This property can be phrased equivalently in terms of how much the logarithm of the weight oscillates:

(a) If $w \in A_{p}, (p \ge 1),$ then $\log(w) \in \operatorname{BMO}$ (i.e. $\log(w)$ has [bounded mean oscillation](wikipedia://en/4694026)).

(b) If $\,f\, \in \operatorname{BMO}$, then for sufficiently small $\delta > 0$, we have $e^{\delta f} \in A_{p}$ for some $p \ge 1$.

This equivalence can be established by using the exponential characterization of weights above, Jensen's inequality, and the [John–Nirenberg inequality](https://en.wikipedia.org/wiki/John–Nirenberg_inequality).

Note that the smallness assumption on $\delta > 0$ in part (b) is necessary for the result to be true, as $-\log|x| \in \operatorname{BMO}$, but:

$$e^{-\log|x|}=\frac{1}{e^{\log|x|}} = \frac{1}{|x|}$$

is not in any $A_{p}$.

## Further properties {#Further_properties}

Here we list a few miscellaneous properties about weights, some of which can be verified from using the definitions, others are nontrivial results:

$$A_1 \subseteq A_p \subseteq A_\infty, \qquad 1\leq p\leq\infty.$$

$$A_\infty = \bigcup_{p<\infty}A_p.$$

If $w \in A_{p}$, then $w\,dx$ defines a [doubling measure](https://en.wikipedia.org/wiki/Doubling_measure): for any ball $B$, if $2B$ is the ball of twice the radius, then $w(2B) \le Cw(B)$ where $C > 1$ is a constant depending on $w$.

If $w \in A_{p}$, then there is $\delta > 1$ such that $w^{\delta} \in A_{p}$.

If $w \in A_{\infty}$, then there is $\delta > 0$ and weights $w_1,w_2\in A_1$ such that $w=w_1 w_2^{-\delta}$.[^o10]

## Boundedness of singular integrals {#Boundedness_of_singular_integrals}

It is not only the Hardy–Littlewood maximal operator that is bounded on these weighted $L^{p}$ spaces. In fact, any [Calderón-Zygmund singular integral operator](https://en.wikipedia.org/wiki/Singular_integrals) is also bounded on these spaces.[^o12] Let us describe a simpler version of this here.[^o5] Suppose we have an operator $T$ which is bounded on $L^{2}(dx)$, so we have

$$\forall f \in C^{\infty}_c : \qquad \|T(f)\|_{L^2} \leq C\|f\|_{L^2}.$$

Suppose also that we can realise $T$ as convolution against a kernel $K$ in the following sense: if $\,f\,, g$ are smooth with disjoint support, then:

$$\int g(x) T(f)(x) \, dx = \iint g(x) K(x-y) f(y) \, dy\,dx.$$

Finally we assume a size and smoothness condition on the kernel $K$:

$$\forall x \neq 0, \forall |\alpha| \leq 1 : \qquad \left |\partial^{\alpha} K \right | \leq C |x|^{-n-\alpha}.$$

Then, for each $1 < p < \infty$ and $\omega \in A_{p}$, $T$ is a [bounded operator](wikipedia://en/455961) on $L^{p}(\omega(x)dx)$. That is, we have the estimate

$$\int |T(f)(x)|^p \, \omega(x)\,dx \leq C \int |f(x)|^p \, \omega(x)\, dx,$$

for all $\,f\,$ for which the right-hand side is finite.

### A converse result {#A_converse_result}

If, in addition to the three conditions above, we assume the non-degeneracy condition on the kernel $K$: For a fixed [unit vector](wikipedia://en/167053) $u_{0}$

$$|K(x)| \geq a |x|^{-n}$$

whenever $x = t \dot u_0$ with $-\infty < t < \infty$, then we have a converse. If we know

$$\int |T(f)(x)|^p \, \omega(x)\,dx \leq C \int |f(x)|^p \, \omega(x)\, dx,$$

for some fixed $1 < p < \infty$ and some $\omega$, then $\omega \in A_{p}$.[^o5]

## Weights and quasiconformal mappings {#Weights_and_quasiconformal_mappings}

For $K > 1$, a $K$-[quasiconformal mapping](wikipedia://en/2749226) is a [homeomorphism](wikipedia://en/13660) $\,f\, : \mathbf{R}^{n} \to\mathbf{R}^{n}$ such that

$$f\in W^{1,2}_{loc}(\mathbf{R}^n), \quad \text{ and } \quad \frac{\|Df(x)\|^n}{J(f,x)}\leq K,$$

where $Df\,(x)$ is the [derivative](wikipedia://en/7921) of $\,f\,$ at $x$ and $J(\,f\,, x) = \det(Df\,(x))$ is the [Jacobian](wikipedia://en/195351).

A theorem of Gehring[^o15] states that for all $K$-quasiconformal functions $\,f\, : \mathbf{R}^{n} \to\mathbf{R}^{n}$, we have $J(\,f\,, x) \in A_{p}$, where $p$ depends on $K$.

## Harmonic measure {#Harmonic_measure}

If you have a simply connected domain $\Omega \subseteq \mathbf{C}$, we say its boundary curve $\Gamma = \partial\Omega$ is $K$-chord-arc if for any two points $z, w$ in $\Gamma$ there is a curve $\gamma \subseteq \Gamma$ connecting $z$ and $w$ whose length is no more than $K|z - w|$. For a domain with such a boundary and for any $z_{0}$ in $\Omega$, the [harmonic measure](wikipedia://en/12141074) $w( \cdot ) = w(z_{0}, \Omega, \cdot)$ is absolutely continuous with respect to one-dimensional [Hausdorff measure](wikipedia://en/504109) and its [Radon–Nikodym derivative](https://en.wikipedia.org/wiki/Radon–Nikodym_derivative) is in $A_{\infty}$.[^o17] (Note that in this case, one needs to adapt the definition of weights to the case where the underlying measure is one-dimensional Hausdorff measure).
