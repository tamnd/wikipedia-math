# Weighted average

::: {#o1 .subject cue=lead name="Weighted average"}

**Weighted average** is a single number or value that best represents a set of data, when each data point is assigned different "weights" or importance. The most common weighted [average](wikipedia://en/60167) is the *[weighted arithmetic mean](wikipedia://en/33274)*, which is similar to an ordinary [arithmetic mean](wikipedia://en/612) except some data points contribute more than others. Other cases include the [weighted geometric mean](wikipedia://en/1232419) and [Weighted harmonic mean](wikipedia://en/14463#Weighted_harmonic_mean).

:::
