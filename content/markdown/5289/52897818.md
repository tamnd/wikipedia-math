# Univariate (statistics)

::: {#o1 .subject cue=lead name="Univariate"}

**Univariate** is a term commonly used in [statistics](wikipedia://en/26685) to describe a type of [data](https://en.wikipedia.org/wiki/Data) which consists of observations on only a single characteristic or attribute. A simple example of univariate data would be the salaries of workers in industry.[^o2] Similar to other data, univariate data can be visualized using graphs, images, or other analysis tools after the data is observed/collected, analyzed and reported with conclusions of the analysis**.** [^o3]

:::

## Data types {#Data_types}

Univariate data can either consist of non-numerical observations (such as eye colors like brown or blue) or numbers (such as height of 1.65 m, or mass of 70 kg). Generally, the terms [categorical](https://en.wikipedia.org/wiki/Categorical_data) univariate data and [numerical](https://en.wikipedia.org/wiki/Numerical_data) univariate data are used to distinguish between these types.

### Categorical univariate data {#Categorical_univariate_data}

Categorical univariate data consists of non-numerical [observations](https://en.wikipedia.org/wiki/Observation) that may be placed in categories. It includes labels or names used to identify an attribute of each element. Categorical univariate data usually use either [nominal](https://en.wikipedia.org/wiki/Nominal_number) or [ordinal](wikipedia://en/26547932) [scale of measurement](https://en.wikipedia.org/wiki/Scale_of_measurement).[^o6]

### Numerical univariate data {#Numerical_univariate_data}

Numerical univariate data consists of observations that are numbers. They are obtained using either [interval](wikipedia://en/49172) or [ratio](wikipedia://en/87837) scale of measurement. This type of univariate data can be classified even further into two subcategories: [discrete](https://en.wikipedia.org/wiki/Discrete_probability_distribution) and [continuous](https://en.wikipedia.org/wiki/Continuous_probability_distribution).[^o3] Numerical univariate data is discrete if the set of all possible values is [finite](wikipedia://en/11742) or countably [infinite](wikipedia://en/142679). Discrete univariate data is usually associated with counting (such as the number of books read by a person). Numerical univariate data is continuous if the set of all possible values is an interval of numbers. Continuous univariate data is typically associated with measuring (such as the weights of people).

## Data analysis and applications {#Data_analysis_and_applications}

Univariate analysis is the simplest form of analyzing data. *Uni* means "one", so the data has only one variable (*[univariate](wikipedia://en/2398982)*).[^o9] Univariate data requires analyzing each [variable](wikipedia://en/3728109) separately. Data is gathered for the purpose of answering a question, or more specifically, a research question. Univariate data does not answer research questions about relationships between variables. Instead, it is used to describe one characteristic or attribute that varies from observation to observation.[^o10] Typically, there are two purposes that a researcher can look for. The first one is to answer a research question with descriptive study and the second one is to get knowledge about how [attribute](wikipedia://en/30423282) varies with individual effect of a variable in [regression analysis](wikipedia://en/826997). There are some ways to describe patterns found in univariate data, which include graphical methods, measures of central tendency and measures of variability.[^o11]

Like other forms of statistics, it can be [inferential](https://en.wikipedia.org/wiki/Inferential_statistics) or [descriptive](wikipedia://en/8187). The key fact is that only one variable is involved.

Univariate analysis can yield misleading results in cases in which [multivariate analysis](https://en.wikipedia.org/wiki/Multivariate_analysis) is more appropriate.

### Measures of central tendency {#Measures_of_central_tendency}

Central tendency is one of the most common numerical descriptive measures. It is used to estimate the central location of the univariate data by the calculation of [mean](https://en.wikipedia.org/wiki/Mean), [median](wikipedia://en/18837) and [mode](wikipedia://en/1432127).[^o13] Each of these calculations has its own advantages and limitations. The mean has the advantage that its calculation includes each value of the data set, but it is particularly susceptible to the influence of [outliers](wikipedia://en/160951). The median is a better measure when the data set contains outliers. The mode is simple to locate.

One is not restricted to using only one of these measures of central tendency. If the data being analyzed are categorical, then the only measure of central tendency that can be used is the mode. However, if the data is numerical in nature ([ordinal](wikipedia://en/26547932) or [interval](wikipedia://en/49172)/[ratio](wikipedia://en/87837)) then the mode, median, or mean can all be used to describe the data. Using more than one of these measures provides a more accurate descriptive summary of central tendency for the univariate.[^o14]

### Measures of variability {#Measures_of_variability}

A measure of [variability](https://en.wikipedia.org/wiki/Statistical_variability) or [dispersion](wikipedia://en/23773247) (deviation from the mean) of a univariate data set can reveal the shape of a univariate data distribution more sufficiently. It will provide some information about the variation among data values. The measures of variability together with the measures of central tendency give a better understanding of the data than the measures of central tendency alone.[^o16] The three most frequently used measures of variability are [range](wikipedia://en/27588), [variance](wikipedia://en/32344) and [standard deviation](wikipedia://en/27590).[^o17] The appropriateness of each measure would depend on the type of data, the shape of the distribution of data and which measure of central tendency is being used. If the data is categorical, then there is no measure of variability to report. For data that is numerical, all three measures are possible. If the distribution of data is symmetrical, then the measures of variability are usually the variance and standard deviation. However, if the data are [skewed](wikipedia://en/28212), then the measure of variability that would be appropriate for that data set is the range.[^o6]

### Descriptive methods {#Descriptive_methods}

[Descriptive statistics](wikipedia://en/8187) describe a sample or population. They can be part of [exploratory data analysis](wikipedia://en/416589).[^o19]

The appropriate statistic depends on the [level of measurement](wikipedia://en/821148). For nominal variables, a [frequency table](https://en.wikipedia.org/wiki/Frequency_table) and a listing of the [mode(s)](wikipedia://en/1432127) are sufficient. For ordinal variables ([Ordinal data](wikipedia://en/52904244)), the [median](wikipedia://en/18837) can be calculated as a measure of [central tendency](https://en.wikipedia.org/wiki/Central_tendency) and the [range](wikipedia://en/27588) (and variations of it) as a measure of dispersion. For interval-level variables, the [arithmetic mean](wikipedia://en/612) (average) and [standard deviation](wikipedia://en/27590) are added to the toolbox and, for ratio-level variables, the [geometric mean](wikipedia://en/13046) and [harmonic mean](wikipedia://en/14463) are added, as measures of central tendency, and the [coefficient of variation](wikipedia://en/1012687) as a measure of dispersion.

For interval and ratio level data, further descriptors include the variable's [skewness](wikipedia://en/28212) and [kurtosis](wikipedia://en/16848).

### Inferential methods {#Inferential_methods}

Inferential methods allow us to infer from a sample to a population.[^o19] For a nominal variable a one-way [chi-square](wikipedia://en/226680) (goodness of fit) test can help determine if our sample matches that of some population.[^o21] For interval and ratio level data, a [one-sample t-test](https://en.wikipedia.org/wiki/T-test) can let us infer whether the mean in our sample matches some proposed number (typically 0). Other available tests of location include the one-sample [sign test](wikipedia://en/3319766) and [Wilcoxon signed rank test](https://en.wikipedia.org/wiki/Wilcoxon_signed_rank_test).

Frequently used graphical illustrations for univariate data include:

### Frequency distribution tables {#Frequency_distribution_tables}

Frequency is how many times a number occurs. The frequency of an observation in statistics indicates the number of times the observation occurs in the data. For example, in the following list of numbers {*1, 2, 3, 4, 6, 9, 9, 8, 5, 1, 1, 9, 9, 0, 6, 9*}, the frequency of the number 9 is 5 (because it occurs 5 times in this data set).

### Bar charts {#Bar_charts}

A [bar chart](wikipedia://en/393311) is a [graph](wikipedia://en/325806) consisting of [rectangular](https://en.wikipedia.org/wiki/Rectangular) bars. These bars actually represents [number](wikipedia://en/21690) or percentage of observations of existing categories in a variable. The [length](wikipedia://en/18542) or [height](wikipedia://en/239972) of bars gives a visual representation of the proportional differences among categories.

### Histograms {#Histograms}

[Histograms](https://en.wikipedia.org/wiki/Histograms) are used to estimate the distribution of the data, with the frequency of values assigned to a value range called a [bin](wikipedia://en/18614570).[^o26]

### Pie charts {#Pie_charts}

A [pie chart](wikipedia://en/728487) is a circle divided into portions that represent the relative frequencies or percentages of a population or a sample belonging to different categories.

## Distributions {#Distributions}

[Univariate distribution](wikipedia://en/9253219) is a dispersal type for a single random variable described either with a [probability mass function](wikipedia://en/154725) (pmf) for [discrete probability distribution](https://en.wikipedia.org/wiki/Discrete_probability_distribution), or [probability density function](wikipedia://en/43487) (pdf) for [continuous probability distribution](https://en.wikipedia.org/wiki/Continuous_probability_distribution).[^o29] It is not to be confused with [multivariate distribution](https://en.wikipedia.org/wiki/Multivariate_distribution).
