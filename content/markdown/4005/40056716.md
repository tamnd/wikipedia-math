# MatrixSSL

::: {#o2 .subject cue=lead name="MatrixSSL"}

**MatrixSSL** is an open-source [TLS/SSL](wikipedia://en/187813) implementation designed for custom applications in [embedded hardware](https://en.wikipedia.org/wiki/Embedded_hardware) environments.[^o3][^o4][^o5]

:::

The MatrixSSL library contains a full cryptographic software module that includes industry-standard [public key](wikipedia://en/24222) and [symmetric key](wikipedia://en/53042) algorithms. It is now called the Inside Secure TLS Toolkit.[^o6]

## Features {#Features}

Features:[^o8]

- Protocol versions
  - [SSL](https://en.wikipedia.org/wiki/Secure_Sockets_Layer) 3.0
  - [TLS](wikipedia://en/187813) 1.0
  - TLS 1.1
  - TLS 1.2
  - TLS 1.3
  - [DTLS](https://en.wikipedia.org/wiki/DTLS) 1.0
  - DTLS 1.2
- Public key algorithms
  - [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29)
  - [Elliptic curve cryptography](https://en.wikipedia.org/wiki/Elliptic_curve_cryptography)
  - [Diffie–Hellman](wikipedia://en/7903)
- Symmetric key algorithms
  - [AES](wikipedia://en/1260)
  - [AES-GCM](https://en.wikipedia.org/wiki/AES-GCM)
  - [Triple DES](wikipedia://en/48375)
  - [ChaCha](https://en.wikipedia.org/wiki/ChaCha_%28cipher%29)
  - [ARC4](https://en.wikipedia.org/wiki/ARC4)
  - [SEED](wikipedia://en/1063358)
- Supported [cipher suites](wikipedia://en/25149718)
  - TLS\_AES\_128\_GCM\_SHA256 (TLS 1.3)
  - TLS\_AES\_256\_GCM\_SHA384 (TLS 1.3)
  - TLS\_CHACHA20\_POLY1305\_SHA256 (TLS 1.3)
  - TLS\_DHE\_RSA\_WITH\_AES\_128\_CBC\_SHA
  - TLS\_DHE\_RSA\_WITH\_AES\_256\_CBC\_SHA
  - TLS\_DHE\_RSA\_WITH\_AES\_128\_CBC\_SHA256
  - TLS\_DHE\_RSA\_WITH\_AES\_256\_CBC\_SHA256
  - SSL\_DHE\_RSA\_WITH\_3DES\_EDE\_CBC\_SHA
  - TLS\_RSA\_WITH\_SEED\_CBC\_SHA
  - TLS\_DHE\_PSK\_WITH\_AES\_128\_CBC\_SHA
  - TLS\_DHE\_PSK\_WITH\_AES\_256\_CBC\_SHA
  - TLS\_PSK\_WITH\_AES\_128\_CBC\_SHA
  - TLS\_PSK\_WITH\_AES\_256\_CBC\_SHA
  - TLS\_ECDHE\_ECDSA\_WITH\_AES\_128\_CBC\_SHA
  - TLS\_ECDHE\_ECDSA\_WITH\_AES\_256\_CBC\_SHA
  - TLS\_ECDHE\_ECDSA\_WITH\_AES\_128\_GCM\_SHA256
  - TLS\_ECDHE\_ECDSA\_WITH\_AES\_256\_GCM\_SHA384
  - TLS\_ECDHE\_RSA\_WITH\_AES\_128\_CBC\_SHA
  - TLS\_ECDHE\_RSA\_WITH\_AES\_256\_CBC\_SHA
  - TLS\_ECDHE\_RSA\_WITH\_AES\_128\_CBC\_SHA256
  - TLS\_ECDHE\_RSA\_WITH\_AES\_256\_CBC\_SHA256
  - TLS\_ECDHE\_RSA\_WITH\_AES\_128\_GCM\_SHA256
  - TLS\_ECDHE\_RSA\_WITH\_AES\_256\_GCM\_SHA384
  - TLS\_ECDH\_ECDSA\_WITH\_AES\_128\_CBC\_SHA
  - TLS\_ECDH\_ECDSA\_WITH\_AES\_256\_CBC\_SHA
  - TLS\_ECDH\_RSA\_WITH\_AES\_128\_CBC\_SHA
  - TLS\_ECDH\_RSA\_WITH\_AES\_256\_CBC\_SHA
  - TLS\_ECDH\_ECDSA\_WITH\_AES\_128\_CBC\_SHA256
  - TLS\_ECDHE\_ECDSA\_WITH\_AES\_128\_CBC\_SHA256
  - TLS\_RSA\_WITH\_AES\_128\_CBC\_SHA
  - TLS\_RSA\_WITH\_AES\_256\_CBC\_SHA
  - TLS\_RSA\_WITH\_AES\_128\_CBC\_SHA256
  - TLS\_RSA\_WITH\_AES\_256\_CBC\_SHA256
  - TLS\_RSA\_WITH\_AES\_128\_GCM\_SHA256
  - TLS\_RSA\_WITH\_AES\_256\_GCM\_SHA384
  - SSL\_RSA\_WITH\_3DES\_EDE\_CBC\_SHA
  - SSL\_RSA\_WITH\_RC4\_128\_SHA
  - SSL\_RSA\_WITH\_RC4\_128\_MD5
  - TLS\_DH\_anon\_WITH\_AES\_128\_CBC\_SHA
  - TLS\_DH\_anon\_WITH\_AES\_256\_CBC\_SHA
  - SSL\_DH\_anon\_WITH\_3DES\_EDE\_CBC\_SHA
  - SSL\_DH\_anon\_WITH\_RC4\_128\_MD5
- [Client authentication](wikipedia://en/3064285)
- Secure Renegotiation
- Standard Session Resumption
- Stateless Session Resumption
- Transport independent
- [PKCS#1](wikipedia://en/16706008) and [PKCS#8](wikipedia://en/40387096) key parsing
- [False Start](https://en.wikipedia.org/wiki/Transmission_Control_Protocol)
- Max Fragment Length extension
- Optional PKCS#11 Crypto Interface
