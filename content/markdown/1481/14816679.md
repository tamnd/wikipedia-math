# Minlos's theorem

::: {#o1 .subject cue=lead name="Minlos's theorem"}

In the [mathematics](wikipedia://en/18831) of [topological vector spaces](wikipedia://en/45752), **Minlos's theorem** states that a [cylindrical measure](https://en.wikipedia.org/wiki/Cylindrical_measure) on the dual of a [nuclear space](wikipedia://en/2702957) is a [Radon measure](wikipedia://en/521933) if its [Fourier transform](wikipedia://en/52247) is continuous. It is named after [Robert Adol'fovich Minlos](https://en.wikipedia.org/wiki/Robert_Adol'fovich_Minlos) and can be proved using [Sazonov's theorem](wikipedia://en/9196302).

:::
