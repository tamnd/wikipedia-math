# Comparison of cryptographic hash functions

::: {#o1 .subject cue=lead name="Comparison of cryptographic hash functions"}

The following tables compare general and technical information for a number of cryptographic hash functions. See the individual functions' articles for further information. This article is not all-inclusive or necessarily up-to-date. An overview of hash function security/[cryptanalysis](wikipedia://en/5715) can be found at [hash function security summary](wikipedia://en/26774718).
