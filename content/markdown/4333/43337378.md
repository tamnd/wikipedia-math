# Augmentation (algebra)

::: {#o1 .subject cue=lead name="Augmentation"}

In [algebra](wikipedia://en/18716923), an **augmentation** of an [associative](wikipedia://en/2112) [algebra](https://en.wikipedia.org/wiki/Algebra_over_a_ring) *A* over a [commutative ring](wikipedia://en/61346) *k* is a *k*-[algebra homomorphism](https://en.wikipedia.org/wiki/Algebra_homomorphism) $A \to k$, typically denoted by ε. An algebra together with an augmentation is called an **augmented algebra**. The kernel of the augmentation is a two-sided [ideal](wikipedia://en/191788#Subalgebras_and_ideals) called the [augmentation ideal](wikipedia://en/2224774) of *A*.

:::

For example, if $A =k[G]$ is the [group algebra](wikipedia://en/349223) of a [finite group](wikipedia://en/323707) *G*, then

$$A \to k,\, \sum a_i x_i \mapsto \sum a_i$$

is an augmentation.

If *A* is a [graded algebra](https://en.wikipedia.org/wiki/Graded_algebra) which is connected, i.e. $A_0=k$, then the homomorphism $A\to k$ which maps an element to its homogeneous component of degree 0 is an augmentation. For example,

$$k[x]\to k, \sum a_ix^i \mapsto a_0$$

is an augmentation on the [polynomial ring](wikipedia://en/373065) $k[x]$.
