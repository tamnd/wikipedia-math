# Primitive element (co-algebra)

::: {#o1 .subject cue=lead name="Primitive element"}

In algebra, a **primitive element** of a [co-algebra](https://en.wikipedia.org/wiki/Co-algebra) *C* (over an element *g*) is an element *x* that satisfies

:::

$$\mu(x) = x \otimes g + g \otimes x$$

where $\mu$ is the [co-multiplication](https://en.wikipedia.org/wiki/Co-multiplication) and *g* is an element of *C* that maps to the [multiplicative identity](wikipedia://en/77591639#In_Mathematics) 1 of the [base field](wikipedia://en/27161748) under the [co-unit](https://en.wikipedia.org/wiki/Co-unit) (*g* is called *group-like*).

If *C* is a [bi-algebra](https://en.wikipedia.org/wiki/Bi-algebra), i.e., a co-algebra that is also an algebra (with certain compatibility conditions satisfied), then one usually takes *g* to be 1, the multiplicative identity of *C*. The bi-algebra *C* is said to be **primitively generated** if it is generated by primitive elements (as an algebra).

If *C* is a bi-algebra, then the set of primitive elements form a [Lie algebra](wikipedia://en/17944) with the usual commutator bracket $[x, y] = xy - yx$ ([graded commutator](https://en.wikipedia.org/wiki/Graded_commutator) if *C* is graded).

If *A* is a connected graded cocommutative [Hopf algebra](wikipedia://en/325714) over a field of characteristic zero, then the [Milnor–Moore theorem](wikipedia://en/43337028) states the [universal enveloping algebra](wikipedia://en/363551) of the graded Lie algebra of primitive elements of *A* is isomorphic to *A*. (This also holds under slightly weaker requirements.)
