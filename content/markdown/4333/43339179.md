# Primitive recursive set function

::: {#o1 .subject cue=lead name="Primitive recursive set function"}

In [mathematics](wikipedia://en/18831), **primitive recursive set functions** or **primitive recursive ordinal functions** are analogs of [primitive recursive functions](wikipedia://en/24829), defined for [sets](wikipedia://en/26691) or [ordinals](wikipedia://en/26547932) rather than [natural numbers](wikipedia://en/21474). They were introduced by (Jensen Karp 1971).

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A primitive recursive set function is a [function](wikipedia://en/185427) from sets to sets that can be obtained from the following basic functions by repeatedly applying the following rules of substitution and recursion:

The basic functions are:

- Projection: *P*<sub>*n*,*m*hair</sub>(*x*<sub>1</sub>, ..., *x*<sub>*n*</sub>) = *x*<sub>*m*</sub> for 0 ≤ *m* ≤ *n*
- Zero: *F*(*x*) = 0
- [Adjoining an element to a set](wikipedia://en/43548952): *F*(*x*, *y*) = *x* ∪ {*y*}
- Testing [membership](https://en.wikipedia.org/wiki/Element_%28mathematics%29): *C*(*x*, *y*, *u*, *v*) = *x* if *u* ∈ *v*, and *C*(*x*, *y*, *u*, *v*) = *y* otherwise.

The rules for generating new functions by substitution are

- *F*(**x**, **y**) = *G*(**x**, *H*(**x**), **y**)
- *F*(**x**, **y**) = *G*(*H*(**x**), **y**)

where **x** and **y** are finite sequences of variables.

The rule for generating new functions by recursion is

- *F*(*z*, **x**) = *G*(∪<sub>*u*hair∈hair*z*</sub> *F*(*u*, **x**), *z*, **x**)

A primitive recursive ordinal function is defined in the same way, except that the initial function *F*(*x*, *y*) = *x* ∪ {*y*} is replaced by *F*(*x*) = *x* ∪ {*x*} (the [successor](wikipedia://en/375256) of *x*). The primitive recursive ordinal functions are the same as the primitive recursive set functions that map ordinals to ordinals.

Examples of primitive recursive set functions:

- [TC](wikipedia://en/2462396#Transitive_closure), the function assigning to a set its transitive closure.[^o5]p. 26
- Given [hereditarily finite](wikipedia://en/332621) $c$, the constant function $f(x)=c$. [^o5]p. 28

:::

::: {#o7 .statement kind=statement/generalization cue=heading name="Extensions"}

## Extensions {#Extensions}

One can also add more initial functions to obtain a larger [class](wikipedia://en/20696) of functions. For example, the ordinal function $\alpha\mapsto\omega^\alpha$ is not primitive recursive, because the constant function with value ω (or any other [infinite set](wikipedia://en/142679)) is not primitive recursive, so one might want to add this constant function to the initial functions.

The notion of a set function being *primitive recursive in ω* has the same definition as that of primitive recursion, except with ω as a parameter kept fixed, not altered by the primitive recursion schemata.

Examples of functions primitive recursive in ω:[^o5] <sup>pp.28--29</sup>

- $$\mathbb P_\omega(x)=\bigcup_{n<\omega}x^n.$$
- The function assigning to $\alpha$ the $\alpha$th level $L_\alpha$ of [Godel's constructible hierarchy](wikipedia://en/343335).

:::

## Primitive recursive closure {#Primitive_recursive_closure}

Let $f_0:\textrm{Ord}^2\to\textrm{Ord}$ be the function $f(\alpha,\beta) =\alpha+\beta$, and for all $i<\omega$, $\tilde{f}_i(\alpha) = f_i(\alpha,\alpha)$ and $f_{i+1}(\alpha,\beta) = (\tilde{f}_i)^\beta(\alpha)$. Let L<sub>α</sub> denote the αth stage of [Godel's constructible universe](wikipedia://en/343335). L<sub>α</sub> is closed under primitive recursive set functions iff α is closed under each $f_i$ for all $i<\omega$. [^o5]p. 31
