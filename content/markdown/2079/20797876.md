# Edge cycle cover

*Image: Edge cycle cover.svg.* An **edge cycle cover** for each graph. The covering of the middle graph is *edge-disjoint*, while the one of the right graph is *vertex-disjoint*.

::: {#o1 .subject cue=lead name="Edge cycle cover"}

In [graph theory](wikipedia://en/12401), a branch of [mathematics](wikipedia://en/18831), an **edge cycle cover** (sometimes called simply **cycle cover**[^o2]) of a [graph](wikipedia://en/325806) is a family of [cycles](wikipedia://en/168609) which are [subgraphs](wikipedia://en/325802#Subgraphs) of *G* and contain all edges of *G*.

:::

If the cycles of the cover have no vertices in common, the cover is called **vertex-disjoint** or sometimes simply **disjoint cycle cover**. In this case, the set of the cycles constitutes a [spanning subgraph](https://en.wikipedia.org/wiki/Spanning_subgraph) of *G*.

If the cycles of the cover have no edges in common, the cover is called **edge-disjoint** or simply **disjoint cycle cover**.

::: {#o4 .statement kind=statement/fact cue=heading name="Properties and applications"}

## Properties and applications {#Properties_and_applications}

### Minimum-Weight Cycle Cover {#Minimum-Weight_Cycle_Cover}

For a [weighted graph](https://en.wikipedia.org/wiki/Weighted_graph), the Minimum-Weight Cycle Cover Problem (MWCCP) is the problem to find a cycle cover with minimal sum of weights of edges in all cycles of the cover.

For [bridgeless](wikipedia://en/1305071) [planar graphs](wikipedia://en/24314), the MWCCP can be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time).[^o6]

:::

## Cycle *k*-cover {#Cycle_k-cover}

A **cycle *k*-cover** of a graph is a family of cycles which cover every edge of *G* exactly *k* times. It has been [proven](wikipedia://en/82285) that every bridgeless graph has cycle *k*-cover for any even [integer](wikipedia://en/14563) *k*≥4. For *k*=2, it is the well-known [cycle double cover conjecture](https://en.wikipedia.org/wiki/Cycle_double_cover_conjecture) is an [open problem](wikipedia://en/1333335) in graph theory. The [cycle double cover conjecture](https://en.wikipedia.org/wiki/Cycle_double_cover_conjecture) states that in every bridgeless graph, there exists a set of cycles that together cover every edge of the graph twice.[^o8]
