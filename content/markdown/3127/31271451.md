# Completeness (logic)

::: {#o1 .subject cue=lead name="Completeness"}

In [mathematical logic](wikipedia://en/19636) and [metalogic](wikipedia://en/387934), a [formal system](wikipedia://en/396102) is called **complete** with respect to a particular [property](wikipedia://en/508057) if every [formula](wikipedia://en/404582) having the property can be [derived](wikipedia://en/1197184) using that system, i.e. is one of its [theorems](wikipedia://en/30977); otherwise the system is said to be **incomplete**. The term "complete" is also used without qualification, with differing meanings depending on the context, mostly referring to the property of semantic [validity](wikipedia://en/21304742). Intuitively, a system is called complete in this particular sense, if it can derive every formula that is true.

:::

## Other properties related to completeness {#Other_properties_related_to_completeness}

The property [converse](wikipedia://en/155941#Categorical_converse) to completeness is called [soundness](wikipedia://en/26819): a system is sound with respect to a property (mostly semantical validity) if each of its theorems has that property.

::: {#o4 .pointer-item cue=pointer name="Deductive completeness"}

## Forms of completeness {#Forms_of_completeness}

### Expressive completeness {#Expressive_completeness}

A [formal language](wikipedia://en/10939) is *expressively complete* if it can express the subject matter for which it is intended.

### Functional completeness {#Functional_completeness}

A set of [logical connectives](wikipedia://en/18153) associated with a formal system is *[functionally complete](wikipedia://en/5279259)* if it can express all [propositional functions](wikipedia://en/229146).

::: {#o8 .pointer-item cue=pointer name="Semantic completeness"}

### Semantic completeness {#Semantic_completeness}

**Semantic completeness** is the [converse](wikipedia://en/155941) of [soundness](wikipedia://en/26819) for formal systems. A formal system is complete with respect to tautologousness or "semantically complete" when all its [tautologies](wikipedia://en/4495335) are [theorems](wikipedia://en/30977), whereas a formal system is "sound" when all theorems are tautologies (that is, they are semantically valid formulas: formulas that are true under every [interpretation](wikipedia://en/14511671) of the language of the system that is consistent with the rules of the system). That is, a formal system is semantically complete if:

$$\models_{\mathcal S} \varphi\ \implies\ \vdash_{\mathcal S} \varphi.$$

For example, [Gödel's completeness theorem](wikipedia://en/12450) establishes semantic completeness for [first-order logic](wikipedia://en/10983).

:::

### Strong completeness {#Strong_completeness}

A formal system S is *strongly complete* or *complete in the strong sense* if for every set of premises Γ, any formula that semantically follows from Γ is derivable from Γ. That is:

$$\Gamma\models_{\mathcal S} \varphi \ \implies\ \Gamma \vdash_{\mathcal S} \varphi.$$

### Refutation completeness {#Refutation_completeness}

A formal system S is **refutation complete** if it is able to derive *[false](wikipedia://en/229823)* from every [unsatisfiable](wikipedia://en/23401166) set of formulas. That is:

$\Gamma \models_{\mathcal S} \bot\ \implies\ \Gamma \vdash_{\mathcal S} \bot.$[^o12]

Every strongly complete system is also refutation complete. Intuitively, strong completeness means that, given a formula set $\Gamma$, it is possible to *compute* every semantical consequence $\varphi$ of $\Gamma$, while refutation completeness means that, given a formula set $\Gamma$ and a formula $\varphi$, it is possible to *check* whether $\varphi$ is a semantical consequence of $\Gamma$.

Examples of refutation-complete systems include: [SLD resolution](https://en.wikipedia.org/wiki/SLD_resolution) on [Horn clauses](wikipedia://en/333824), [superposition](wikipedia://en/2648614) on equational [clausal](wikipedia://en/4638484) first-order logic, and [Robinson's resolution](wikipedia://en/2724082#Resolution_in_first_order_logic) on clause sets.[^o13] The latter is not strongly complete: e.g. $\{ a \} \models a \lor b$ holds even in the propositional subset of first-order logic, but $a \lor b$ cannot be derived from $\{ a \}$ by resolution. However, $\{ a, \lnot (a \lor b) \} \vdash \bot$ can be derived.

::: {#o15 .pointer-item cue=pointer name="Syntactic completeness"}

### Syntactical completeness {#Syntactical_completeness}

A formal system S is *syntactically complete* or *deductively complete* or *maximally complete* or *negation complete* if for each [sentence](wikipedia://en/2129527) (closed formula) *φ* of the language of the system either *φ* or ¬*φ* is a theorem of S. Syntactical completeness is a stronger property than semantic completeness. If a formal system is syntactically complete, a corresponding formal theory is called [complete](wikipedia://en/10086335) if it is a [consistent](wikipedia://en/75802) theory. [Gödel's incompleteness theorem](wikipedia://en/58863) shows that any [computable](https://en.wikipedia.org/wiki/Computable) system that is sufficiently powerful, such as [Peano arithmetic](https://en.wikipedia.org/wiki/Peano_arithmetic), cannot be both consistent and syntactically complete.

*Syntactical completeness* can also refer to another unrelated concept, also called *Post completeness* or *Hilbert–Post completeness*. In this sense, a formal system is *syntactically complete* if and only if no unprovable sentence can be added to it without introducing an [inconsistency](wikipedia://en/75802). [Truth-functional propositional logic](https://en.wikipedia.org/wiki/Propositional_calculus) and [first-order predicate logic](wikipedia://en/10983) are semantically complete, but not syntactically complete (for example, the propositional logic statement consisting of a single propositional variable **A** is not a theorem, and neither is its negation).

:::

### Structural completeness {#Structural_completeness}

In [superintuitionistic](https://en.wikipedia.org/wiki/Superintuitionistic_logic) and [modal logics](wikipedia://en/333365), a logic is *structurally complete* if every [admissible rule](wikipedia://en/1151794) is a derivable implication.

### Model completeness {#Model_completeness}

A theory is *model complete* if and only if every [embedding](wikipedia://en/52119) of its models is an [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding).

:::
