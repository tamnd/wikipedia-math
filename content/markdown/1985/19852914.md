# Manipulability ellipsoid

::: {#o1 .subject cue=lead name="Manipulability ellipsoid"}

In [robot kinematics](https://en.wikipedia.org/wiki/Robot_kinematics), the **manipulability ellipsoid** represents the manipulability of a robotic system in a graphical form. Here, the manipulability of a [robot arm](https://en.wikipedia.org/wiki/Robot_arm) refers to its ability to alter the position of the [end effector](https://en.wikipedia.org/wiki/End_effector) based on the joint configuration. A higher manipulability measure signifies a broader range of potential movements in that specific configuration. When the robot is in a [singular configuration](https://en.wikipedia.org/wiki/Singular_configuration) the manipulability measure diminishes to zero.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The manipulability ellipsoid is defined as the set[^o4]

$$\{ \xi : \xi^\operatorname{T} (J(q) J^\operatorname{T}(q))^{-1} \xi \le 1 \}$$

where *q* is the joint configuration of the robot and *J* is the [robot Jacobian](https://en.wikipedia.org/wiki/Robot_kinematics#Robot_Jacobian) relating the end-effector velocity with the joint rates.

:::

## Geometric Interpretation {#Geometric_Interpretation}

A geometric interpretation of the manipulability ellipsoid is that it includes all possible end-effector velocities normalized for a unit input at a given robot configuration. The axis of the ellipsoid can be computed by using the [singular value decomposition](wikipedia://en/142207) of the [robot Jacobian](https://en.wikipedia.org/wiki/Robot_kinematics#Robot_Jacobian).[^o4][^o6]
