# Nakano vanishing theorem

::: {#o1 .subject cue=lead name="Nakano vanishing theorem"}

In mathematics, specifically in the study of [vector bundles](wikipedia://en/276524) over [complex Kähler manifolds](wikipedia://en/390538), the **Nakano vanishing theorem**, sometimes called the **Akizuki–Nakano vanishing theorem**, generalizes the [Kodaira vanishing theorem](wikipedia://en/2988093).[^o2][^o3][^o4] Given a compact complex manifold *M* with a [holomorphic line bundle](https://en.wikipedia.org/wiki/Holomorphic_line_bundle) *F* over *M*, the Nakano vanishing theorem provides a condition on when the [cohomology groups](https://en.wikipedia.org/wiki/Cohomology_groups) $H^q(M; \Omega^p(F))$ equal zero. Here, $\Omega^p(F)$ denotes the [sheaf](wikipedia://en/245466) of holomorphic (*p*,0)-forms taking values on *F*. The theorem states that, if the first [Chern class](wikipedia://en/294349) of *F* is negative,

$$H^q(M; \Omega^p(F)) = 0 \text{ when } q + p < n.$$

Alternatively, if the first Chern class of *F* is positive,

$$H^q(M; \Omega^p(F)) = 0 \text{ when } q + p > n.$$

:::
