# Functionally graded element

::: {#o1 .subject cue=lead name="Functionally graded element"}

In materials science and mathematics, **functionally graded elements** are elements used in [finite element analysis](https://en.wikipedia.org/wiki/Finite_element_analysis).[^o2] They can be used to describe a [functionally graded material](https://en.wikipedia.org/wiki/Functionally_graded_material).[^o3]

:::
