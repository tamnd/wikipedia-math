# Moore determinant of a Hermitian matrix

::: {#o1 .subject cue=lead name="Moore determinant of a Hermitian matrix"}

In mathematics, the **Moore determinant** is a [determinant](wikipedia://en/8468) defined for [Hermitian matrices](wikipedia://en/189682) over a [quaternion algebra](wikipedia://en/2776890), introduced by (txt).

:::

Because quaternion multiplication does not [commute](https://en.wikipedia.org/wiki/Commutativity), it is necessary to specify the order in which multiplication occurs. The Moore determinant uses the formal classical determinant, which has $n!$ terms consisting of products of elements of the matrix, and for each term specifies an order for those elements to be multiplied. Specifically, it separates out cycles of factors $a_{f_1 f_2},a_{f_2 f_3},\dots,a_{f_k f_1}$. The shortest cycles are placed first, with the smallest index within the cycle occurring first. Ties in the length of the cycle are broken by listing the cycle with the smallest $f_1$ first.

This definition has the property that the Moore determinant of a matrix formed from a suitable collection of vectors of quaternions is zero if and only if the vectors are linearly dependent.
