# Voorhoeve index

::: {#o1 .subject cue=lead name="Voorhoeve index"}

In mathematics, the **Voorhoeve index** is a non-negative [real number](wikipedia://en/20646438) associated with certain [functions](wikipedia://en/185427) on the [complex numbers](wikipedia://en/5826), named after [Marc Voorhoeve](wikipedia://en/38508075). It may be used to extend [Rolle's theorem](wikipedia://en/200305) from real functions to complex functions, taking the role that for real functions is played by the number of zeros of the function in an [interval](wikipedia://en/49172).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The Voorhoeve index $V_I(f)$ of a complex-valued function *f* that is [analytic](wikipedia://en/61478) in a complex [neighbourhood](wikipedia://en/1529485) of the real interval $I$ = \[*a*, *b*\] is given by

$$V_I(f) = \frac{1}{2\pi}\int_a^b \! \left| \frac{d}{dt} {\rm Arg} \, f(t) \right| \,\, dt \, = \frac{1}{2\pi} \int_a^b \! \left| {\rm Im}\left(\frac{f'}{f}\right) \right| \, dt.$$

(Different authors use different normalization factors.)

:::

::: {#o5 .statement kind=statement/theorem cue=named-heading name="Rolle's theorem"}

## Rolle's theorem {#Rolle's_theorem}

[Rolle's theorem](wikipedia://en/200305) states that if $f$ is a [continuously differentiable](https://en.wikipedia.org/wiki/Continuously_differentiable_function) real-valued function on the [real line](https://en.wikipedia.org/wiki/Real_line), and $f(a)=$ $f(b)=0$, where $a<b$, then its derivative $f'$ has a zero strictly between $a$ and $b$. Or, more generally, if $N_I(f)$ denotes the number of zeros of the continuously differentiable function $f$ on the interval $I$, then $N_I(f) \le N_I(f')+1.$

Now one has the analogue of Rolle's theorem:

$$V_I(f) \le V_I (f') + \frac12.$$

This leads to bounds on the number of zeros of an analytic function in a complex region.

:::
