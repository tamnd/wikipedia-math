# Algebraic attack

::: {#o1 .subject cue=lead name="Algebraic attack"}

**Algebraic attack** is a method of algebraic [cryptanalysis](wikipedia://en/5715) by which a set of algebraic equations can be used to solve a cryptographic Boolean function that has a low degree or a high degree of [non linearity](https://en.wikipedia.org/wiki/Non-linear_equation). The main objective is to reduce the non linearity of the equations and then solve the cipher to decrypt into plaintext. It has been used for vulnerability testing for [encryption](wikipedia://en/10294) algorithms as well as hacking systems for malicious intent.

:::

## Theory {#Theory}

Algebraic attacks can be used for a variety of [cryptosystems](wikipedia://en/506383) which is the encryption scheme consisting of five tuples which are[^o3]

- Set of plaintext units denoted as $\mathcal{P}$
- Set of [ciphertext](wikipedia://en/175560) units denoted as $\mathcal{C}$
- Set called key space denoted as $\mathcal{K}$
- Encryption function for every $k \in K$ where $E_k : \mathcal{P} \rightarrow \mathcal{C}$
- Decryption function for every $k \in K$ where $D_k : \mathcal{C} \rightarrow \mathcal{P}$

A map between $E_{k(1)}$ and $D_{k(2)}$ exists such that $E_{k(1)} \circ D_{k(2)} = id_k$ for every $k \in K$. Thus the pair $(k(1), k(2))$ becomes [key pair](https://en.wikipedia.org/wiki/Key_pair).

The most basic process of describing encryption and [decryption](https://en.wikipedia.org/wiki/Decryption) in [cryptography](wikipedia://en/18934432) using [XOR cipher](wikipedia://en/939985) is as follows with an example :

- $\mathcal{P}$ (10011) [XOR](wikipedia://en/105979) $\mathcal{K}$ (10110) = $\mathcal{C}$ (00101)
- $\mathcal{C}$ (00101) XOR $\mathcal{K}$ (10110) = $\mathcal{P}$ (10011)

*Image: Public key encryption.svg.* Public key cryptosystem

The cryptosystem becomes [symmetric](wikipedia://en/53042) when $k(2)$ can be computed efficiently from $E_{k(1)}$ and $k$ else if not then it is a [public key](wikipedia://en/24222) cryptosystem. In [block cipher](wikipedia://en/4594), the plaintext is broken into plaintext units and encrypted by fixed key $k$ meanwhile in [stream cipher](wikipedia://en/49007), a Boolean function is used to generate a set of keys or keystream $k_1, k_2, \ldots$ from an initial key $k$ and then this keystream is used to encrypt the plaintext units individually.[^o3]

Assuming $\mathcal{P}$ and $\mathcal{C}$ as subsets of finite vector spaces of characteristic 2 where the field is $K = F_q$ and $q = 2^e$ or $p^e$ where $p$ is the characteristic and

every map $\phi : K^n \rightarrow K^m$ is a polynomial such that

$$\phi(a_1,\ldots, a_n) = (f_1(a_1,\ldots, a_n), \ldots, f_m(a_1,\ldots, a_n))$$

The main criteria for deciding to algebraic attack a [stream](wikipedia://en/49007) or a [block cipher](wikipedia://en/4594) is algebraic immunity $AI$.

For a set of all Boolean functions $B_n$ of n input variables with mapping of strings to values as $\{0, 1\}^n \rightarrow {0, 1}$ then each Boolean function $f$ can be represented as a multivariate polynomial over [GF(2)](wikipedia://en/11137263) which is called the [algebraic normal form](wikipedia://en/1048680) (ANF).[^o4]

$$f(x_1, \ldots, x_n) = a_0 + \sum_{1 \leqslant i \leqslant n} a_i x_i + \sum_{1 \leqslant i \leqslant j \leqslant n} a_{i,j} x_i x_j +\ldots + a_{1,2,\ldots,n} x_1 x_2 \ldots x_n ,$$

where the coefficients $a_0, a_i, a_{i, j} , \ldots, a_{1,2,\ldots,n} \in \{0, 1\}$ and $deg(f)$ is the algebraic degree or number of variables in highest order term with non zero coefficient.

Also $g \in B_n$ is [annihilator](wikipedia://en/3231096) of $f \in B_n$ if $f \cdot g = 0$

Given $f \in B_n$, algebraic immunity $AI(f)$ is defined as minimum degree of all annihilators of $f$ or $1 + f$.[^o4]

$$AI(f) = (f \oplus 1) \cdot g = 0$$

This annihilator is exactly located at $\left \lceil \frac{N}{2} \right \rceil$ therefore,[^o4]

$$AI(f) \leqslant \left \lceil \frac{N}{2} \right \rceil$$

## History of algorithms and preventive techniques {#History_of_algorithms_and_preventive_techniques}

### Early algorithms {#Early_algorithms}

Algebraic attack has many ways of decrypting an encrypted message using well developed cryptanalysis algorithms. The overall one-size-fits-all approach is breaking the stream or block cipher as a system of multivariate polynomial equations using a GF(2) binary field. The unknowns in the equations are what we need to solve for as they are the keys. If it is solved the key is recovered.[^o7]

*Image: Overview of LILI-128 keystream generators.png.* Overview of LILI-128 keystream generators

One of the approaches to achieve this is the attack on stream cipher done with the help of an over defined system of algebraic equations. Thus the $2^{92}$ toyocrypt (TOYOCRYPT-HRI) stream cipher[^o8] can be attacked in $2^{49}$ [CPU clocks](https://en.wikipedia.org/wiki/Clock_rate) with only 20 KB of keystream which is the fastest attack to break this encryption. [LILI-128](https://en.wikipedia.org/wiki/LILI-128) can be broken with an algebraic attack in $2^{57}$ CPU clocks. If the stream cipher will at most use 10 [Linear Feedback Shift Registers](wikipedia://en/58992) (LFSR) and a Boolean function $f$, the cipher can be broken with a general algebraic attack.[^o9]

If the cipher is having non linear equation system the attacker can try to replace the non linear terms with variables thus exceeding the variable count than in the original non linear equation. If the new equation system is solvable, they put the variable solution thus making the original equation linear. Common algebraic equation can be used then to solve the system.

To make good approximation for the key value pairs in the cipher sent using [linear cryptanalysis](wikipedia://en/59469) is another method of solving the cipher. One can use $2^{21}$ known plaintexts to break the 8 round [Data Encryption Standard](wikipedia://en/7978) (DES) and $2^{47}$ plaintexts to break the 16 round DES in this method which is also one of the first practically described use case of algebraic attack using linear cryptanalysis.[^o10]

[Cube attacks](wikipedia://en/18982200) later developed are one of the algebraic attack sub method by which the [Bluetooth](https://en.wikipedia.org/wiki/Bluetooth) E0 encryption can be converted into the plaintext in fraction of a second. This was further improvement from the precomputation algorithms that were the fastest known to break the Bluetooth cipher.[^o11]

### Modern algorithms {#Modern_algorithms}

SAT solvers are widely used standard of doing algebraic attacks.[^o7][^o13] It is similar to how we solve NP-complete problems which are the hardest problems to solve in the NP class and easy to verify in polynomial time. SAT solvers take up the logical formula and return the Boolean true or false value depending on whether the solution exists for the problem or not.

Gröbner basis attack uses [Gröbner basis of an ideal](wikipedia://en/357328) which is a polynomial equation system with same variety (or solutions) and is easier to solve but computationally expensive. The reduced Gröbner basis generating the zero dimensional ideal has a univariate form and can be solved with factorization. On a 3 round pure cipher, a 96 bit key is found under a second and uses very less (plaintext, ciphertext) pairs. Thus this is a lot faster than using exhaustive search of key space using Gröbner basis.[^o14] This algorithm is directly based from [Bruno Buchberger](wikipedia://en/1924233) as he had computed the Gröbner basis of an ideal.[^o15]

### Preventive techniques {#Preventive_techniques}

There has been research work for strengthening the [Crypto-1](wikipedia://en/16261979) stream cipher by causing the attackers to use too high CPU time and too high memory in the modified version of Crypto-1. This is one of the demonstrated ways to protect encryption from algebraic attack in RFID systems.[^o17]

[S-box](wikipedia://en/240991) technique[^o18] is used for securing image transfer so that the information enclosed within the image cannot be decrypted.[^o13] It has thus been used in satellite image encryption using [Fredkin logic](https://en.wikipedia.org/wiki/Fredkin_gate).[^o19]

## Notable examples {#Notable_examples}

[Keeloq](wikipedia://en/7494162) remote access to car and door alarms with an experimental attack was successfully broken in 2007. Given $2^{16}$ known plaintexts, a [slide](wikipedia://en/1821327)-algebraic attack that uses a SAT solver can break $2^{53}$ Keeloq encryptions in $2^{64}$ CPU clocks. It is also the first time that a real life full round cipher has been broken using an algebraic attack.[^o21]

Bluetooth stream cipher E0 is decoded easily by many attacks including algebraic and hence are removed from 4.0 versions which used the [AES-CCM](https://en.wikipedia.org/wiki/AES-CCMP) encryption standard. For E0's four LFSR system its initial value can be found using an algebraic attack that has a realistic space complexity of $2^{83}$ (84MB [RAM](https://en.wikipedia.org/wiki/Random-access_memory)) and time complexity of $2^{87}$ CPU clocks.[^o22]

Data Encryption Standard (DES) although robust from complete break was last widely used in 2001 for banking services and government websites as a result of vulnerability to algebraic attacks. One of the algebraic attacks on 6 round DES can be done with just a single plaintext.[^o23]

Reduced round version of [Data Encryption Standard](wikipedia://en/7978) (DES) and KeeLoq remote car locking ciphers were broken by [SAT solvers](https://en.wikipedia.org/wiki/SAT_solver) which outperformed the [Gröbner basis](wikipedia://en/357328) technique which is used when the keystream is extremely small. It was shown that the Hitag2 ciphers commonly used in automobiles can be broken in few hours using the same SAT solvers and algebraic attack with conversion.[^o24]

Modern cryptography algorithms such as [Post Quantum Cryptography](wikipedia://en/26605226) are trying to prevent algebraic attacks made by hackers using quantum computer in future. One such algorithm is Cryptographic Suite for Crystal Lattices (CRYSTALS). [^o25][^o26]
