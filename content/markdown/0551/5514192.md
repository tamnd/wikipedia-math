# Symmetric hypergraph theorem

::: {#o1 .subject cue=lead name="Symmetric hypergraph theorem"}

The **Symmetric hypergraph theorem** is a theorem in [combinatorics](wikipedia://en/5170) that puts an upper bound on the [chromatic number](wikipedia://en/426743#Chromatic_number) of a [graph](wikipedia://en/325806) (or [hypergraph](wikipedia://en/232535) in general). The original reference for this paper is unknown at the moment, and has been called [folklore](wikipedia://en/168905). [^o2]

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

A [group](wikipedia://en/19447) $G$ [acting on a set](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) $S$ is called *[transitive](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29#Types_of_actions)* if given any two elements $x$ and $y$ in $S$, there exists an element $f$ of $G$ such that $f(x) = y$. A graph (or hypergraph) is called *symmetric* if its [automorphism group](wikipedia://en/56661772) is transitive.

::: {#o5 .statement kind=statement/theorem cue=inline-head name="Theorem"}

**Theorem.** Let $H = (S, E)$ be a symmetric hypergraph. Let $m = |S|$, and let $\chi(H)$ denote the chromatic number of $H$, and let $\alpha(H)$ denote the [independence number](wikipedia://en/325802#Independence) of $H$. Then

$$\chi(H) \leq 1 + \frac{\ln{m}}{-\ln{(1-\alpha(H)/m)}}$$

:::

:::

::: {#o7 .application cue=heading name="Applications"}

## Applications {#Applications}

This theorem has applications to [Ramsey theory](wikipedia://en/157175), specifically [graph Ramsey theory](https://en.wikipedia.org/wiki/Graph_Ramsey_theory). Using this theorem, a relationship between the graph Ramsey numbers and the extremal numbers can be shown (see Graham-Rothschild-Spencer for the details).

The theorem has also been applied to problems involving arithmetic progressions. For instance, let $r_k(n)$ denote the minimum number of colors required so that there exists an $r_k(n)$-coloring of $[1,n]$ that avoids any monochromatic $k$-term [arithmetic progression](wikipedia://en/168389). The Symmetric Hypergraph Theorem can be used to show that[^o8]

$$r_k(n) < \frac{2n \log n}{\log \log n}(1 + o(1))$$

:::
