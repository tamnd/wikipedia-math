# GAUSS (software)

::: {#o2 .subject cue=lead name="GAUSS"}

**GAUSS** is a matrix [programming language](wikipedia://en/23015) for [mathematics](wikipedia://en/18831) and [statistics](wikipedia://en/26685), developed and marketed by Aptech Systems. Its primary purpose is the solution of numerical problems in statistics, [econometrics](wikipedia://en/10390), [time-series](https://en.wikipedia.org/wiki/Time-series), optimization and 2D- and 3D-[visualization](https://en.wikipedia.org/wiki/Visualization_%28computer_graphics%29).[^o3] It was first written in 1980[^o4] and was first published in 1984 for [MS-DOS](https://en.wikipedia.org/wiki/MS-DOS).[^o5] It has since become available for [Linux](https://en.wikipedia.org/wiki/Linux), [macOS](https://en.wikipedia.org/wiki/MacOS) and [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows).[^o6]

:::

## Examples {#Examples}

- GAUSS has several application modules as well as functions in its [runtime library](https://en.wikipedia.org/wiki/Runtime_library) (i.e., functions that come with GAUSS without extra cost):[^o9]
  - Qprog – [Quadratic programming](wikipedia://en/40324)
  - SqpSolvemt – [Sequential quadratic programming](wikipedia://en/7415899)
  - QNewton - [Quasi-Newton](wikipedia://en/7883127) unconstrained optimization
  - EQsolve - Nonlinear equations solver

## GAUSS Applications {#GAUSS_Applications}

A range of toolboxes are available for GAUSS at additional cost.[^o12]

*Toolboxes*

::: {#o13 .table cue=table name="Toolboxes"}

| Toolbox | Description |
|---|---|
| Algorithmic Derivatives | A program for generating GAUSS procedures for computing algorithmic derivatives. |
| Constrained Maximum Likelihood MT | Solves the general maximum likelihood problem subject to general constraints on the parameters. |
| Constrained Optimization | Solves the [nonlinear programming](wikipedia://en/679709) problem subject to general constraints on the parameters. |
| CurveFit | Nonlinear [curve fitting](wikipedia://en/555425). |
| Descriptive Statistics | Basic sample statistics including means, frequencies and [crosstabs](wikipedia://en/935515). This application is backwards compatible with programs written with Descriptive Statistics 3.1. |
| Descriptive Statistics MT | Basic sample statistics including means, frequencies and crosstabs. This application is thread-safe and takes advantage of structures. |
| Discrete Choice | A statistical package for estimating [discrete choice](wikipedia://en/4902101) and other models in which the dependent variable is qualitative in some way. |
| FANPAC MT | Comprehensive suite of [GARCH](wikipedia://en/610752#GARCH) (Generalized AutoRegressive Conditional Heteroskedastic) models for estimating volatility. |
| Linear Programming MT | Solves small and large scale [linear programming](wikipedia://en/43730) problems. |
| Linear Regression MT | [Least squares](wikipedia://en/82359) estimation. |
| Loglinear Analysis MT | Analysis of [categorical data](wikipedia://en/821165) using [log-linear analysis](wikipedia://en/35696836). |
| Maximum Likelihood MT | [Maximum likelihood estimation](wikipedia://en/140806) of the parameters of statistical models. |
| Nonlinear Equations MT | Solves [systems of nonlinear equations](wikipedia://en/27420015) having as many equations as unknowns. |
| Optimization | Unconstrained optimization. |
| Time Series MT | Exact ML estimation of VARMAX, VARMA, ARIMAX, [ARIMA](wikipedia://en/1510134), and [ECM](wikipedia://en/22309853) models subject to general constraints on the parameters. [Panel data](wikipedia://en/2499813) estimation. [Cointegration](wikipedia://en/1822603) and [unit root tests](wikipedia://en/2473482). |
