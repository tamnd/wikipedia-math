# Hoeffding's independence test

::: {#o1 .subject cue=lead name="Hoeffding's independence test"}

In [statistics](wikipedia://en/26685), **Hoeffding's test of independence**, named after [Wassily Hoeffding](wikipedia://en/2547060), is a test based on the population measure of deviation from independence

:::

$$H = \int (F_{12}-F_1F_2)^2 \, dF_{12}$$

where $F_{12}$ is the [joint distribution function](https://en.wikipedia.org/wiki/Joint_distribution_function) of two random variables, and $F_1$ and $F_2$ are their [marginal distribution](wikipedia://en/506077) functions. Hoeffding derived an [unbiased estimator](https://en.wikipedia.org/wiki/Unbiased_estimator) of $H$ that can be used to test for [independence](wikipedia://en/27593), and is [consistent](wikipedia://en/1497569) for any continuous [alternative](https://en.wikipedia.org/wiki/Alternative_hypothesis). The test should only be applied to data drawn from a [continuous distribution](https://en.wikipedia.org/wiki/Continuous_probability_distribution), since $H$ has a defect for discontinuous $F_{12}$, namely that it is not necessarily zero when $F_{12}=F_1F_2$. This drawback can be overcome by taking an [integration](wikipedia://en/15532) with respect to $dF_1F_2$. This modified measure is known as Blum–Kiefer–Rosenblatt coefficient.[^o2]

A paper published in 2008[^o3] describes both the calculation of a sample based version of this measure for use as a test statistic, and calculation of the null distribution of this test statistic.
