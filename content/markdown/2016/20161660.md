# ADE model

::: {#o1 .subject cue=lead name="ADE model"}

An **ADE model** is a genetic model for [twin studies](https://en.wikipedia.org/wiki/Twin_studies) which includes [dominance](https://en.wikipedia.org/wiki/Dominance_%28genetics%29) genetic effects.[^o2]

:::

*A* stands for [*additive* genetic effects](https://en.wikipedia.org/wiki/Additive_genetic_effects), *D* for non-additive genetic (or [*dominance*](https://en.wikipedia.org/wiki/Dominance_%28genetics%29)) effects, and *E* for nonshared *environment* effects.[^o3]
