# Boxcar function

*Image: Boxcar function.svg.* A graphical representation of a boxcar function

::: {#o1 .subject cue=lead name="Boxcar function"}

In [mathematics](wikipedia://en/18831), a **boxcar function** is any [function](wikipedia://en/185427) which is zero over the entire [real line](https://en.wikipedia.org/wiki/Real_line) except for a single [interval](wikipedia://en/49172) where it is equal to a constant $A$.[^o2] The function is named after its graph's resemblance to a [boxcar](https://en.wikipedia.org/wiki/Boxcar), a type of [railroad car](https://en.wikipedia.org/wiki/Railroad_car). The boxcar function can be expressed in terms of the [uniform distribution](https://en.wikipedia.org/wiki/Uniform_distribution_%28continuous%29) as

:::

$$\operatorname{boxcar}(x)= (b-a)A\,f(a,b;x) = A(H(x-a) - H(x-b)),$$

where $f(a,b;x)$ is the uniform distribution of $x$ for the interval $[a,b]$ and $H(x)$ is the [Heaviside step function](wikipedia://en/87299). As with most such [discontinuous functions](wikipedia://en/6122), there is a question of the value at the transition points, which are usually best chosen depending on the individual application.

When a boxcar function is selected as the [impulse response](wikipedia://en/545825) of a [filter](https://en.wikipedia.org/wiki/Digital_filter), the result is a [simple moving average](https://en.wikipedia.org/wiki/Simple_moving_average) filter, whose [frequency response](wikipedia://en/302033) is a [sinc-in-frequency](https://en.wikipedia.org/wiki/Sinc_filter#Frequency-domain_sinc), a type of [low-pass filter](https://en.wikipedia.org/wiki/Low-pass_filter).
