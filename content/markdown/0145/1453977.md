# Null vector

*Image: Conformalsphere.pdf.* A null cone where $q(x,y,z) = x^2 + y^2 - z^2 .$

::: {#o1 .subject cue=lead name="Null vector"}

In [mathematics](wikipedia://en/18831), given a [vector space](wikipedia://en/32370) *X* with an associated [quadratic form](wikipedia://en/251478) *q*, written (*X*, *q*), a **null vector** or **isotropic vector** is a non-zero element *x* of *X* for which *q*(*x*) = 0.

:::

In the theory of [real](wikipedia://en/20646438) [bilinear forms](wikipedia://en/449477), [definite quadratic forms](wikipedia://en/20437320) and [isotropic quadratic forms](wikipedia://en/10917170) are distinct. They are distinguished in that only for the latter does there exist a nonzero null vector.

A [quadratic space](https://en.wikipedia.org/wiki/Quadratic_space) (*X*, *q*) which has a null vector is called a [pseudo-Euclidean space](wikipedia://en/10962546). The term *isotropic vector v* when *q*(*v*) = 0 has been used in quadratic spaces,[^o2] and **anisotropic space** for a quadratic space without null vectors.

A pseudo-Euclidean vector space may be decomposed (non-uniquely) into [orthogonal subspaces](https://en.wikipedia.org/wiki/Orthogonal_subspaces) *A* and *B*, *X* = *A* + *B*, where *q* is positive-definite on *A* and negative-definite on *B*. The **null cone**, or **isotropic cone**, of *X* consists of the union of balanced spheres:

$$\bigcup_{r \geq 0} \{x = a + b : q(a) = -q(b) = r, \ \ a \in A, b \in B \}.$$

The null cone is also the union of the [isotropic lines](wikipedia://en/8088814) through the origin.

## Split algebras {#Split_algebras}

A composition algebra with a null vector is a **split algebra**.[^o5]

In a [composition algebra](wikipedia://en/3861635) (*A*, +, ×, \*), the quadratic form is q(*x*) = *x x*\*. When *x* is a null vector then there is no multiplicative inverse for *x*, and since *x* ≠ 0, *A* is not a [division algebra](wikipedia://en/26549625).

In the [Cayley–Dickson construction](wikipedia://en/175609), the split algebras arise in the series [bicomplex numbers](wikipedia://en/4802961), [biquaternions](wikipedia://en/1207070), and [bioctonions](wikipedia://en/51005149), which uses the [complex number](wikipedia://en/5826) field $\mathbb{C}$ as the foundation of this doubling construction due to [L. E. Dickson](https://en.wikipedia.org/wiki/L._E._Dickson) (1919). In particular, these algebras have two [imaginary units](wikipedia://en/52358), which commute so their product, when squared, yields +1:

$(hi)^2 = h^2 i^2 = (-1)(-1) = +1 .$ Then

$(1 + hi)(1 + hi)^* = (1 +hi)(1 - hi) = 1 - (hi)^2 = 0$ so 1 + hi is a null vector.

The real subalgebras, [split complex numbers](https://en.wikipedia.org/wiki/Split_complex_number), [split quaternions](https://en.wikipedia.org/wiki/Split_quaternion), and [split-octonions](wikipedia://en/3861649), with their null cones representing the light tracking into and out of 0 ∈ *A*, suggest [spacetime topology](https://en.wikipedia.org/wiki/Spacetime_topology).

:::

## Examples {#Examples}

The [light-like](https://en.wikipedia.org/wiki/Minkowski_space#Causal_structure) vectors of [Minkowski space](https://en.wikipedia.org/wiki/Minkowski_space) are null vectors.

The four [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent) [biquaternions](wikipedia://en/1207070) *l* = 1 + *hi*, *n* = 1 + *hj*, *m* = 1 + *hk*, and *m*<sup>∗</sup> = 1 – *hk* are null vectors and { *l*, *n*, *m*, *m*<sup>∗</sup> } can serve as a [basis](wikipedia://en/18420) for the subspace used to represent [spacetime](wikipedia://en/28758). Null vectors are also used in the [Newman–Penrose formalism](wikipedia://en/6176811) approach to spacetime manifolds.[^o8]

In the [Verma module](wikipedia://en/2975234) of a [Lie algebra](wikipedia://en/17944) there are null vectors.
