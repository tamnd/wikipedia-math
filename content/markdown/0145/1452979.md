# Znám's problem

::: {#o1 .subject cue=lead name="Znám's problem"}

*Image: Znam-2-3-11-23-31.svg.* Graphical demonstration that 1 = 1/2 + 1/3 + 1/11 + 1/23 + 1/31 + 1/(2×3×11×23×31). Each row of $k$ squares of side length 1/$k$ has total [area](wikipedia://en/1209) 1/$k$, and all the squares together exactly cover a larger square with area 1. The bottom row of 47058 squares with side length 1/47058 is too small to see in the figure and is not shown.

In [number theory](wikipedia://en/21527), **Znám's problem** asks which [sets](wikipedia://en/26691) of [integers](wikipedia://en/14563) have the property that each integer in the set is a [proper divisor](https://en.wikipedia.org/wiki/Proper_divisor) of the product of the other integers in the set, plus 1. Znám's problem is named after the Slovak mathematician [Štefan Znám](https://en.wikipedia.org/wiki/Štefan_Znám), who suggested it in 1972, although other mathematicians had considered similar problems around the same time.

:::

The initial terms of [Sylvester's sequence](wikipedia://en/4535485) almost solve this problem, except that the last chosen term equals one plus the product of the others, rather than being a proper divisor. Sun in 1983 showed that there is at least one solution to the (proper) Znám problem for each $k\ge 5$. Sun's solution is based on a [recurrence](wikipedia://en/146806) similar to that for Sylvester's sequence, but with a different set of initial values.[^n1]

The Znám problem is closely related to [Egyptian fractions](wikipedia://en/336349). It is known that there are only finitely many solutions for any fixed $k$. It is unknown whether there are any solutions to Znám's problem using only [odd numbers](https://en.wikipedia.org/wiki/Odd_number), and there remain several other [open questions](wikipedia://en/1333335).

## The problem {#The_problem}

Znám's problem asks which sets of integers have the property that each integer in the set is a [proper divisor](https://en.wikipedia.org/wiki/Proper_divisor) of the product of the other integers in the set, plus 1. That is, given $k$, what sets of integers

$$\{n_1, \ldots, n_k\}$$

are there such that, for each $i$, $n_i$ divides but is not equal to[^n2]

$$\Bigl(\prod_{j \ne i}^n n_j\Bigr) + 1 ?$$

A closely related problem concerns sets of integers in which each integer in the set is a divisor, but not necessarily a proper divisor, of one plus the product of the other integers in the set.[^n3] This problem does not seem to have been named in the literature, and is referred to here as the improper Znám problem. Any solution to Znám's problem is also a solution to the improper Znám problem, but not necessarily vice versa.[^n4]

## Origin {#Origin}

Znám's problem is named after the Slovak mathematician [Štefan Znám](https://en.wikipedia.org/wiki/Štefan_Znám), who suggested it in 1972.[^o8] Earlier, in 1971, Barbeau had posed the improper Znám problem for $k=3$,[^n3] and soon afterward Mordell, independently of Znám, found all solutions to the improper problem for $k\le 5$.[^o10] Then, in 1975, Skula showed that Znám's problem is unsolvable for $k<5$, and credited J. Janák with finding the solution $\{2, 3, 11, 23, 31\}$ for $k=5$.[^n2]

## Connection to Egyptian fractions {#Connection_to_Egyptian_fractions}

Any solution to the improper Znám problem is equivalent (via division by the product of the values $x_i$) to a solution to the equation

$$\sum\frac1{x_i} + \prod\frac1{x_i}=y,$$

where $y$ as well as each $x_i$ must be an integer, and [conversely](wikipedia://en/155941) any such solution corresponds to a solution to the improper Znám problem. However, all known solutions have $y=1$,[^n7] so they satisfy the equation

$$\sum\frac1{x_i} + \prod\frac1{x_i}=1.$$

This equation describes an [Egyptian fraction](wikipedia://en/336349) representation of the number one as a sum of [unit fractions](wikipedia://en/491316).[^n8] The solutions to this equation have been applied to the classification of [singularities](wikipedia://en/54240) on surfaces,[^n5] and to the theory of [nondeterministic finite automata](https://en.wikipedia.org/wiki/Nondeterministic_finite_automata).[^n9]

## Number of solutions {#Number_of_solutions}

The number of solutions to Znám's problem for any $k$ is finite, so it makes sense to count the total number of solutions for each $k$.[^n6] Sun showed in 1983 that there is at least one solution to the (proper) Znám problem for each $k\ge 5$. Sun's solution is based on a recurrence similar to that for Sylvester's sequence, but with a different set of initial values.[^n1] The number of solutions for small values of $k$, starting with $k=5$, forms the sequence:[^n7]

[2](https://en.wikipedia.org/wiki/2_%28number%29), [5](https://en.wikipedia.org/wiki/5_%28number%29), [18](wikipedia://en/208294), [96](https://en.wikipedia.org/wiki/96_%28number%29) .

Presently, a few solutions are known for $k=9$ and $k=10$, but it is unclear how many solutions remain undiscovered for those values of $k$. However, there are infinitely many solutions if $k$ is not fixed: Cao and Jing showed in 1998 showed that there are at least 39 solutions for each $k\ge 12$,[^n10] improving earlier results proving the existence of fewer solutions;[^o26] Sun and Cao [conjectured](wikipedia://en/6138) in 1988 that the number of solutions for each value of $k$ grows [monotonically](wikipedia://en/27838#Increasing_and_decreasing) with $k$.[^n11]

It is unknown whether there are any solutions to Znám's problem using only odd numbers. With one exception, all known solutions start with 2. If all numbers in a solution to Znám's problem or the improper Znám problem are [prime](wikipedia://en/23666), their product is a [primary pseudoperfect number](wikipedia://en/7184831).[^n12]
