# Hutchinson metric

*Image: Julia set (indigo).png.* A [Julia set](wikipedia://en/56434), a fractal related to the [Mandelbrot set](wikipedia://en/19562)

*Image: Animated fractal mountain.gif.* A fractal that models the surface of a mountain (animation)

::: {#o1 .subject cue=lead name="Hutchinson metric"}

In [mathematics](wikipedia://en/18831), the **Hutchinson metric**, otherwise known as the **Kantorovich metric**, is a [function](wikipedia://en/185427) which [measures](https://en.wikipedia.org/wiki/Metric_%28mathematics%29) "the discrepancy between two [images](wikipedia://en/71925) for use in [fractal](wikipedia://en/10913) [image processing](https://en.wikipedia.org/wiki/Image_processing)" and "can also be applied to describe the similarity between [DNA](https://en.wikipedia.org/wiki/DNA) sequences expressed as real or complex [genomic](https://en.wikipedia.org/wiki/Genomic) signals".[^o2][^o3]

:::

::: {#o5 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Consider only [nonempty](wikipedia://en/9566), [compact](wikipedia://en/6042), and finite [metric spaces](wikipedia://en/20018). For such a space $X$, let $P(X)$ denote the space of [Borel](wikipedia://en/4322) [probability measures](wikipedia://en/45437) on $X$, with

$$\delta : X \rightarrow P(X)$$

the embedding associating to $x \in X$ the point measure $\delta_x$. The support $|\mu|$ of a measure in $P(X)$ is the smallest [closed subset](https://en.wikipedia.org/wiki/Closed_subset) of measure 1.

If $f : X_1 \rightarrow X_2$ is [Borel measurable](wikipedia://en/4322) then the induced map

$$f_* : P(X_1) \rightarrow P(X_2)$$

associates to $\mu$ the measure $f_*(\mu)$ defined by

$$f_*(\mu)(B)= \mu(f^{-1}(B))$$

for all $B$ Borel in $X_2$.

Then the **Hutchinson metric** is given by

$$d(\mu_1,\mu_2) = \sup \left\lbrace \int u(x) \, \mu_1(dx) - \int u(x) \, \mu_2(dx) \right\rbrace$$

where the $\sup$ is taken over all [real](wikipedia://en/20646438)-valued functions $u$ with [Lipschitz constant](https://en.wikipedia.org/wiki/Lipschitz_constant) $\le\!1.$

Then $\delta$ is an [isometric embedding](https://en.wikipedia.org/wiki/Isometric_embedding) of $X$ into $P(X)$, and if $f : X_1 \rightarrow X_2$ is Lipschitz then $f_* : P(X_1) \rightarrow P(X_2)$ is Lipschitz with the same Lipschitz constant.[^o6]
