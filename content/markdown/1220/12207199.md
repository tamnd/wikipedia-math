# Either–or topology

::: {#o1 .subject cue=lead name="Either–or topology"}

In [mathematics](wikipedia://en/18831), the **either–or topology** is a [topological structure](wikipedia://en/30450) defined on the [closed interval](https://en.wikipedia.org/wiki/Closed_interval) \[−1, 1\] by declaring a set [open](wikipedia://en/39358) if it either does not contain {0} or does contain (−1, 1).

:::
