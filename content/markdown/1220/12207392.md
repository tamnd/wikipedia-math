# Compact complement topology

::: {#o1 .subject cue=lead name="Compact complement topology"}

In [mathematics](wikipedia://en/18831), the **compact complement topology** is a [topology](wikipedia://en/30450) defined on the set $\scriptstyle\mathbb{R}$ of [real numbers](https://en.wikipedia.org/wiki/Real_numbers), defined by declaring a [subset](wikipedia://en/27631) $\scriptstyle X \subseteq \mathbb{R}$ [open](wikipedia://en/39358) [if and only if](wikipedia://en/14922) it is either empty or its [complement](wikipedia://en/54347) $\scriptstyle\mathbb{R} \setminus X$ is compact in the standard [Euclidean topology](wikipedia://en/9697) on $\scriptstyle\mathbb{R}$.

:::
