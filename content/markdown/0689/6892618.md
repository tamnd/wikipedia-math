# Induced subgraph isomorphism problem

::: {#o1 .subject cue=lead name="Induced subgraph isomorphism problem"}

In [complexity theory](wikipedia://en/7543) and [graph theory](wikipedia://en/12401), **induced subgraph isomorphism** is an [NP-complete](https://en.wikipedia.org/wiki/NP-complete) [decision problem](wikipedia://en/8336) that involves finding a given graph as an [induced subgraph](wikipedia://en/1655188) of a larger graph.

:::

## Problem statement {#Problem_statement}

Formally, the problem takes as input two [graphs](wikipedia://en/12401) *G*<sub>1</sub>=(*V*<sub>1</sub>, *E*<sub>1</sub>) and *G*<sub>2</sub>=(*V*<sub>2</sub>, *E*<sub>2</sub>), where the number of vertices in *V*<sub>1</sub> can be assumed to be less than or equal to the number of vertices in *V*<sub>2</sub>. *G*<sub>1</sub> is [isomorphic](wikipedia://en/247577) to an induced subgraph of *G*<sub>2</sub> if there is an [injective function](wikipedia://en/45196) *f* which maps the vertices of *G*<sub>1</sub> to vertices of *G*<sub>2</sub> such that for all pairs of vertices *x*, *y* in *V*<sub>1</sub>, edge (*x*, *y*) is in *E*<sub>1</sub> if and only if the edge (*f*(*x*), *f*(*y*)) is in *E*<sub>2</sub>. The answer to the decision problem is yes if this function *f* exists, and no otherwise.

This is different from the [subgraph isomorphism problem](wikipedia://en/450062) in that the absence of an edge in *G*<sub>1</sub> implies that the corresponding edge in *G*<sub>2</sub> must also be absent. In subgraph isomorphism, these "extra" edges in *G*<sub>2</sub> may be present.

## Computational complexity {#Computational_complexity}

The complexity of induced subgraph isomorphism separates [outerplanar graphs](wikipedia://en/352343) from their generalization [series–parallel graphs](wikipedia://en/9938559): it may be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) for [2-connected](https://en.wikipedia.org/wiki/K-vertex-connected_graph) outerplanar graphs, but is NP-complete for 2-connected series–parallel graphs.[^o4][^o5]

::: {#o7 .statement kind=statement/generalization cue=heading name="Special cases"}

## Special cases {#Special_cases}

The special case of finding a long [path](wikipedia://en/638889) as an induced subgraph of a [hypercube](wikipedia://en/6706815) has been particularly well-studied, and is called the [snake-in-the-box](wikipedia://en/1850040) problem.[^o8] The [maximum independent set problem](https://en.wikipedia.org/wiki/Maximum_independent_set_problem) is also an induced subgraph isomorphism problem in which one seeks to find a large [independent set](wikipedia://en/524501) as an induced subgraph of a larger graph, and the [maximum clique problem](https://en.wikipedia.org/wiki/Maximum_clique_problem) is an induced subgraph isomorphism problem in which one seeks to find a large [clique graph](wikipedia://en/524466) as an induced subgraph of a larger graph.

:::

## Differences with the subgraph isomorphism problem {#Differences_with_the_subgraph_isomorphism_problem}

Although the induced subgraph isomorphism problem seems only slightly different from the subgraph isomorphism problem, the "induced" restriction introduces changes large enough that we can witness differences from a computational complexity point of view.

For example, the subgraph isomorphism problem is NP-complete on connected proper interval graphs and on connected bipartite permutation graphs,[^o10] but the **induced** subgraph isomorphism problem can be solved in polynomial time on these two classes.[^o11]

Moreover, the induced subtree isomorphism problem (i.e. the induced subgraph isomorphism problem where *G*<sub>1</sub> is restricted to be a tree) can be solved in polynomial time on interval graphs, while the subtree isomorphism problem is NP-complete on proper interval graphs.[^o12]
