# Tachytrope

::: {#o1 .subject cue=lead name="Tachytrope"}

A **tachytrope** is a [curve](wikipedia://en/89246) in which the law of the [velocity](wikipedia://en/20491903) is given. It was first used by [American](https://en.wikipedia.org/wiki/United_States) [mathematician](wikipedia://en/18902) [Benjamin Peirce](wikipedia://en/364270) in *A System of Analytic Mechanics*, first published in 1855.[^n1]

:::
