# Gowers' theorem

::: {#o1 .subject cue=lead name="Gowers' theorem"}

In [mathematics](wikipedia://en/18831), **Gowers' theorem**, also known as **Gowers' Ramsey theorem** and **Gowers' FIN**<sub>*k*</sub> **theorem**, is a theorem in [Ramsey theory](wikipedia://en/157175) and [combinatorics](wikipedia://en/5170). It is a Ramsey-theoretic result about functions with finite [support](wikipedia://en/381013). [Timothy Gowers](wikipedia://en/365715) originally [proved](wikipedia://en/82285) the result in 1992,[^o2] motivated by a problem regarding [Banach spaces](wikipedia://en/3989). The result was subsequently generalised by Bartošová, Kwiatkowska,[^o3] and Lupini.[^o4]

:::

::: {#o6 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

The presentation and notation is taken from [Todorčević](https://en.wikipedia.org/wiki/Stevo_Todorčević),[^o7] and is different to that originally given by Gowers.

For a function $f\colon \mathbb{N} \to \mathbb{N}$, the [support](wikipedia://en/381013) of $f$ is defined $\operatorname{supp}(f) = \{ n : f(n) \neq 0 \}$. Given $k \in \mathbb{N}$, let $\mathrm{FIN}_k$ be the set

$$\mathrm{FIN}_k = \big\{ f\colon \mathbb{N} \to \mathbb{N} \mid \operatorname{supp}(f) \text{ is finite and } \max(\operatorname{range}(f)) = k \big\}$$

If $f \in \mathrm{FIN}_n$, $g \in \mathrm{FIN}_m$ have [disjoint](wikipedia://en/39359) supports, we define $f+g \in \mathrm{FIN}_k$ to be their pointwise sum, where $k = \max\{n, m\}$. Each $\mathrm{FIN}_k$ is a [partial semigroup](wikipedia://en/43662522#Partial_semigroup) under $+$.

The *tetris operation* $T\colon \mathrm{FIN}_{k+1} \to \mathrm{FIN}_k$ is defined $T(f)(n) = \max \{ 0, f(n)-1 \}$. Intuitively, if $f$ is represented as a pile of square blocks, where the $n$th column has height $f(n)$, then $T(f)$ is the result of removing the bottom row. The name is in analogy with [the video game](https://en.wikipedia.org/wiki/Tetris). $T^{(k)}$ denotes the $k$th iterate of $T$.

A *block sequence* $(f_n)$ in $\mathrm{FIN}_k$ is one such that $\max(\operatorname{supp}(f_m)) < \min(\operatorname{supp}(f_{m+1}))$ for every $m$.

:::

::: {#o9 .statement cue=heading name="The theorem"}

## The theorem {#The_theorem}

Note that, for a block sequence $(f_n)$, numbers $k_1, \ldots, k_n$ and indices $m_1 < \cdots < m_n$, the sum $T^{(k_1)}(f_{m_1}) + \cdots + T^{(k_n)}(f_{m_n})$ is always defined. Gowers' original theorem states that, for any finite colouring of $\mathrm{FIN}_k$, there is a block sequence $(f_n)$ such that all elements of the form $T^{(k_1)}(f_{m_1}) + \cdots + T^{(k_n)}(f_{m_n})$ have the same colour.

The standard proof uses [ultrafilters](wikipedia://en/31911),[^o2][^o7] or equivalently, nonstandard arithmetic.[^o10]

:::

## Generalisation {#Generalisation}

Intuitively, the tetris operation can be seen as removing the bottom row of a pile of boxes. It is natural to ask what would happen if we tried removing different rows. Bartošová and Kwiatkowska[^o3] considered the wider class of *generalised tetris operations*, where we can remove any chosen subset of the rows.

Formally, let $F\colon \mathbb{N} \to \mathbb{N}$ be a [nondecreasing](wikipedia://en/48260) [surjection](wikipedia://en/27873). The induced tetris operation $\hat{F}\colon \mathrm{FIN}_k \to \mathrm{FIN}_{F(k)}$ is given by composition with $F$, i.e. $\hat{F}(f)(n) = F(f(n))$. The generalised tetris operations are the collection of $\hat{F}$ for all nondecreasing surjections $F\colon \mathbb{N} \to \mathbb{N}$. In this language, the original tetris operation is induced by the map $T\colon n \mapsto \max\{n-1, 0\}$.

Bartošová and Kwiatkowska[^o3] showed that the finite version of Gowers' theorem holds for the collection of generalised tetris operations. Lupini[^o4] later extended this result to the infinite case.
