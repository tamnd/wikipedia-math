# Problems involving arithmetic progressions

::: {#o1 .subject cue=lead name="Problems involving arithmetic progressions"}

**Problems involving [arithmetic progressions](wikipedia://en/168389)** are of interest in [number theory](wikipedia://en/21527),[^o2] [combinatorics](wikipedia://en/5170), and [computer science](https://en.wikipedia.org/wiki/Computer_science), both from theoretical and applied points of view.

:::

## Largest progression-free subsets {#Largest_progression-free_subsets}

Find the [cardinality](wikipedia://en/6174) (denoted by *A*<sub>*k*</sub>(*m*)) of the largest subset of {1, 2, ..., *m*} which contains no progression of *k* distinct terms. The elements of the forbidden progressions are not required to be consecutive. For example, *A*<sub>4</sub>(10) = 8, because {1, 2, 3, 5, 6, 8, 9, 10} has no arithmetic progressions of length 4, while all 9-element subsets of {1, 2, ..., 10} have one.

In 1936, [Paul Erdős](wikipedia://en/601284) and [Pál Turán](wikipedia://en/614998) posed a question related to this number[^o4] and Erdős set a \$1000 prize for an answer to it. The prize was collected by [Endre Szemerédi](wikipedia://en/663489) for a solution published in 1975, what has become known as [Szemerédi's theorem](wikipedia://en/591703).

## Arithmetic progressions from prime numbers {#Arithmetic_progressions_from_prime_numbers}

[Szemerédi's theorem](wikipedia://en/591703) states that a set of [natural numbers](wikipedia://en/21474) of non-zero [upper asymptotic density](https://en.wikipedia.org/wiki/Upper_asymptotic_density) contains finite arithmetic progressions, of any arbitrary length *k*.

Erdős made [a more general conjecture](wikipedia://en/4312009) from which it would follow that

*The sequence of primes numbers contains arithmetic progressions of any length.*

This result was proven by [Ben Green](wikipedia://en/1927952) and [Terence Tao](wikipedia://en/1118498) in 2004 and is now known as the [Green–Tao theorem](wikipedia://en/7006166).[^o6]

See also [Dirichlet's theorem on arithmetic progressions](wikipedia://en/101453).

, the longest known arithmetic progression of primes has length 27:[^o7]

224584605939537911 + 81292139·23#·*n*, for *n* = 0 to 26. ([23# = 223092870](wikipedia://en/422786))

As of 2011, the longest known arithmetic progression of *consecutive* primes has length 10. It was found in 1998.[^o8][^o9] The progression starts with a 93-digit number

100 99697 24697 14247 63778 66555 87969 84032 95093 24689

19004 18036 03417 75890 43417 03348 88215 90672 29719

and has the common difference 210.

## Primes in arithmetic progressions {#Primes_in_arithmetic_progressions}

[The prime number theorem for arithmetic progressions](wikipedia://en/23692#Prime_number_theorem_for_arithmetic_progressions) deals with the [asymptotic](wikipedia://en/641995) distribution of prime numbers in an arithmetic progression.

## Covering by and partitioning into arithmetic progressions {#Covering_by_and_partitioning_into_arithmetic_progressions}

- Find minimal *l<sub>n</sub>* such that any set of *n* residues modulo *p* can be covered by an arithmetic progression of the length *l<sub>n</sub>*.[^o12]
- For a given set *S* of integers find the minimal number of arithmetic progressions that cover *S*
- For a given set *S* of integers find the minimal number of nonoverlapping arithmetic progressions that cover *S*
- Find the number of ways to partition {1, ..., *n*} into arithmetic progressions.
- Find the number of ways to partition {1, ..., *n*} into arithmetic progressions of length at least 2 with the same period.
- See also [Covering system](wikipedia://en/2297820)
