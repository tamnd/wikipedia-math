# Piecewise linear function

::: {#o1 .subject cue=lead name="Piecewise linear function"}

In [mathematics](wikipedia://en/18831), a **piecewise linear** or **segmented function** is a [real-valued function](wikipedia://en/22284647) of a real variable, whose [graph](wikipedia://en/87352) is composed of straight-[line segments](wikipedia://en/22634860).[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

A piecewise linear function is a function defined on a (possibly unbounded) [interval](wikipedia://en/49172) of [real numbers](wikipedia://en/20646438), such that there is a collection of intervals on each of which the function is an [affine function](wikipedia://en/38449). (Thus "piecewise linear" is actually defined to mean "piecewise [affine](https://en.wikipedia.org/wiki/Affine_function)".) If the domain of the function is [compact](wikipedia://en/6042), there needs to be a finite collection of such intervals; if the domain is not compact, it may either be required to be finite or to be [locally finite](wikipedia://en/11611098) in the reals.

:::

::: {#o6 .example cue=heading name="Examples"}

## Examples {#Examples}

*Image: Piecewise linear function.svg.* A continuous piecewise linear function

The function defined by

$$f(x) = \begin{cases} -x - 3 & \text{if }x \leq -3 \\ x + 3 & \text{if }-3 < x < 0 \\ -2x + 3 & \text{if }0 \leq x < 3 \\ 0.5x - 4.5 & \text{if }x \geq 3 \end{cases}$$

is piecewise linear with four pieces. The graph of this function is shown to the right. Since the graph of an affine(\*) function is a [line](wikipedia://en/946975), the graph of a piecewise linear function consists of [line segments](wikipedia://en/22634860) and [rays](https://en.wikipedia.org/wiki/Ray_%28mathematics%29). The *x* values (in the above example −3, 0, and 3) where the slope changes are typically called breakpoints, changepoints, threshold values or knots. As in many applications, this function is also continuous. The graph of a continuous piecewise linear function on a compact interval is a [polygonal chain](wikipedia://en/12056032).

(\*) A [linear function](wikipedia://en/18102) satisfies by definition $f(\lambda x) = \lambda f(x)$ and therefore in particular $f(0) = 0$; functions whose graph is a straight line are *[affine](https://en.wikipedia.org/wiki/Affine_function)* rather than *linear*.

There are other examples of piecewise linear functions:

- [Absolute value](wikipedia://en/991)[^o7]
- [Sawtooth function](wikipedia://en/52147)
- [Floor function](https://en.wikipedia.org/wiki/Floor_function)
- [Step function](wikipedia://en/170939), a function composed of constant sub-functions, so also called a piecewise constant function
  - [Boxcar function](wikipedia://en/1454542),
  - [Heaviside step function](wikipedia://en/87299)[^o7]
  - [Sign function](wikipedia://en/505449)
- [Triangular function](wikipedia://en/3524992)

:::

## Fitting to a curve {#Fitting_to_a_curve}

*Image: Finite element method 1D illustration1.svg.* A function (blue) and a piecewise linear approximation to it (red)

An approximation to a known curve can be found by sampling the curve and interpolating linearly between the points. An algorithm for computing the most significant points subject to a given error tolerance has been published.[^o9]

## Fitting to data {#Fitting_to_data}

If partitions, and then breakpoints, are already known, [linear regression](wikipedia://en/48758386) can be performed independently on these partitions. However, continuity is not preserved in that case, and also there is no unique reference model underlying the observed data. A stable algorithm with this case has been derived.[^o11]

If partitions are not known, the [residual sum of squares](wikipedia://en/2473303) can be used to choose optimal separation points.[^o12] However efficient computation and joint estimation of all model parameters (including the breakpoints) may be obtained by an iterative procedure[^o13] currently implemented in the package `segmented`[^o14] for the [R language](wikipedia://en/376707).

A variant of [decision tree learning](wikipedia://en/577003) called [model trees](https://en.wikipedia.org/wiki/Model_tree) learns piecewise linear functions.[^o15]

## Generalizations {#Generalizations}

*Image: Piecewise linear function2D.svg.* A piecewise linear function of two arguments (top) and the convex polytopes on which it is linear (bottom)

The notion of a piecewise linear function makes sense in several different contexts. Piecewise linear functions may be defined on [*n*-dimensional](wikipedia://en/8398) [Euclidean space](wikipedia://en/9697), or more generally any [vector space](wikipedia://en/32370) or [affine space](wikipedia://en/298834), as well as on [piecewise linear manifolds](wikipedia://en/2174184) and [simplicial complexes](wikipedia://en/252686) (see [simplicial map](wikipedia://en/25738537)). In each case, the function may be [real](wikipedia://en/20646438)-valued, or it may take values from a vector space, an affine space, a piecewise linear manifold, or a simplicial complex. (In these contexts, the term “linear” does not refer solely to [linear transformations](wikipedia://en/18102), but to more general [affine linear](wikipedia://en/38449) functions.)

In dimensions higher than one, it is common to require the domain of each piece to be a [polygon](wikipedia://en/23621) or [polytope](wikipedia://en/23471). This guarantees that the graph of the function will be composed of polygonal or polytopal pieces.

[Splines](wikipedia://en/457680) generalize piecewise linear functions to higher-order polynomials, which are in turn generalized by piecewise-[smooth](wikipedia://en/1408000) and piecewise-differentiable functions.

:::

## Specializations {#Specializations}

Important sub-classes of piecewise linear functions include the [continuous](wikipedia://en/6122) piecewise linear functions and the [convex](wikipedia://en/245568) piecewise linear functions. In general, for every *n*-dimensional continuous piecewise linear function $f : \mathbb{R}^n \to \mathbb{R}$, there is a

$$\Pi \in \mathcal{P}(\mathcal{P}(\mathbb{R}^{n+1}))$$

such that

$f(\vec{x}) = \min_{\Sigma \in \Pi} \max_{(\vec{a}, b) \in \Sigma} \vec{a} \cdot \vec{x} + b.$[^o19]

If $f$ is convex and continuous, then there is a

$$\Sigma \in \mathcal{P}(\mathbb{R}^{n+1})$$

such that

$$f(\vec{x}) = \max_{(\vec{a},b) \in \Sigma} \vec{a} \cdot \vec{x} + b.$$

## Applications {#Applications}

*Image: R-3VAR1.JPG.* Crop response to depth of the watertable[^o22]

*Image: Mustard segm regr no effect.png.* Example of crop response to soil salinity[^o23]

In [agriculture](https://en.wikipedia.org/wiki/Agriculture) piecewise [regression analysis](wikipedia://en/826997) of measured data is used to detect the range over which growth factors affect the yield and the range over which the crop is not sensitive to changes in these factors.

The image on the left shows that at shallow [watertables](https://en.wikipedia.org/wiki/Watertable) the yield declines, whereas at deeper (> 7 dm) watertables the yield is unaffected. The graph is made using the method of [least squares](wikipedia://en/82359) to find the two segments with the [best fit](https://en.wikipedia.org/wiki/Best_fit).

The graph on the right reveals that crop yields [tolerate](https://en.wikipedia.org/wiki/Salt_tolerance_of_crops) a [soil salinity](https://en.wikipedia.org/wiki/Soil_salinity) up to ECe = 8 dS/m (ECe is the electric conductivity of an extract of a saturated soil sample), while beyond that value the crop production reduces. The graph is made with the method of partial regression to find the longest range of "no effect", i.e. where the line is horizontal. The two segments need not join at the same point. Only for the second segment method of least squares is used.
