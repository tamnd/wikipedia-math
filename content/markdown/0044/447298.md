# Graphical model

::: {#o1 .subject cue=lead name="Graphical model"}

Structured prediction

A **graphical model** or **probabilistic graphical model** (**PGM**) or **structured probabilistic model** is a [probabilistic model](https://en.wikipedia.org/wiki/Probabilistic_model) for which a [graph](wikipedia://en/325806) expresses the [conditional dependence](wikipedia://en/36805017) structure between [random variables](wikipedia://en/25685). Graphical models are commonly used in [probability theory](wikipedia://en/23542), [statistics](wikipedia://en/26685)—particularly [Bayesian statistics](wikipedia://en/404412)—and [machine learning](wikipedia://en/233488).

:::

## Types {#Types}

Generally, probabilistic graphical models use a graph-based representation as the foundation for encoding a distribution over a multi-dimensional space and a graph that is a compact or [factorized](wikipedia://en/2016186) representation of a set of independences that hold in the specific distribution. Two branches of graphical representations of distributions are commonly used, namely, [Bayesian networks](wikipedia://en/203996) and [Markov random fields](wikipedia://en/1323985). Both families encompass the properties of factorization and independences, but they differ in the set of independences they can encode and the factorization of the distribution that they induce.[^o3]

### Undirected Graphical Model {#Undirected_Graphical_Model}

*Image: Examples of an Undirected Graph.svg.* An undirected graph with four vertices

The undirected graph shown may have one of several interpretations; the common feature is that the presence of an edge implies some sort of dependence between the corresponding random variables. From this graph, we might deduce that B, C, and D are all [conditionally independent](wikipedia://en/801135) given A. This means that if the value of A is known, then the values of B, C, and D provide no further information about each other. Equivalently (in this case), the joint probability distribution can be factorized as:

$$P[A,B,C,D] = f_{AB}[A,B] \cdot f_{AC}[A,C] \cdot f_{AD}[A,D]$$

for some non-negative functions $f_{AB}, f_{AC}, f_{AD}$.

### Bayesian network {#Bayesian_network}

*Image: Example of a Directed Graph.svg.* Example of a directed acyclic graph on four vertices

If the network structure of the model is a [directed acyclic graph](wikipedia://en/204002), the model represents a factorization of the joint [probability](wikipedia://en/22934) of all random variables. More precisely, if the events are $X_1,\ldots,X_n$ then the joint probability satisfies

$$P[X_1,\ldots,X_n]=\prod_{i=1}^nP[X_i|\text{pa}(X_i)]$$

where $\text{pa}(X_i)$ is the set of parents of node $X_i$ (nodes with edges directed towards $X_i$). In other words, the [joint distribution](https://en.wikipedia.org/wiki/Joint_distribution) factors into a product of conditional distributions. For example, in the directed acyclic graph shown in the Figure this factorization would be

$$P[A,B,C,D] = P[A]\cdot P[B | A]\cdot P[C | A] \cdot P[D|A,C].$$

Any two nodes are [conditionally independent](wikipedia://en/801135) given the values of their parents. In general, any two sets of nodes are conditionally independent given a third set if a criterion called [*d*-separation](https://en.wikipedia.org/wiki/D-separation) holds in the graph. Local independences and global independences are equivalent in Bayesian networks.

This type of graphical model is known as a directed graphical model, [Bayesian network](wikipedia://en/203996), or belief network. Classic machine learning models like [hidden Markov models](https://en.wikipedia.org/wiki/Hidden_Markov_models), [neural networks](https://en.wikipedia.org/wiki/Artificial_neural_network) and newer models such as [variable-order Markov models](wikipedia://en/10770999) can be considered special cases of Bayesian networks.

One of the simplest Bayesian Networks is the [Naive Bayes classifier](wikipedia://en/87339).

### Cyclic Directed Graphical Models {#Cyclic_Directed_Graphical_Models}

*Image: Graph model.svg.* An example of a directed, cyclic graphical model. Each arrow indicates a dependency. In this example: D depends on A, B, and C; and C depends on B and D; whereas A and B are each independent.

The next figure depicts a graphical model with a cycle. This may be interpreted in terms of each variable 'depending' on the values of its parents in some manner. The particular graph shown suggests a joint probability density that factors as

$$P[A,B,C,D] = P[A]\cdot P[B]\cdot P[C,D|A,B],$$

but other interpretations are possible. [^o7]

### Other types {#Other_types}

- [Dependency network](https://en.wikipedia.org/wiki/Dependency_network_%28graphical_model%29) where cycles are allowed
- Tree-augmented classifier or **TAN model**

*Image: Tan corral.png.* TAN model for "corral dataset"

- Targeted Bayesian network learning (TBNL) *Image: Tbnl corral.jpg.* TBNL model for "corral dataset"
- A [factor graph](wikipedia://en/2016186) is an undirected [bipartite graph](wikipedia://en/244431) connecting variables and factors. Each factor represents a function over the variables it is connected to. This is a helpful representation for understanding and implementing [belief propagation](wikipedia://en/800010).
- A [clique tree](https://en.wikipedia.org/wiki/Clique_tree) or junction tree is a [tree](wikipedia://en/48560) of [cliques](wikipedia://en/524466), used in the [junction tree algorithm](wikipedia://en/4855682).
- A [chain graph](https://en.wikipedia.org/wiki/Chain_graph) is a graph which may have both directed and undirected edges, but without any directed cycles (i.e. if we start at any vertex and move along the graph respecting the directions of any arrows, we cannot return to the vertex we started from if we have passed an arrow). Both directed acyclic graphs and undirected graphs are special cases of chain graphs, which can therefore provide a way of unifying and generalizing Bayesian and Markov networks.[^o9]
- An [ancestral graph](wikipedia://en/2938319) is a further extension, having directed, bidirected and undirected edges.[^o10]
- [Random field](wikipedia://en/540838) techniques
  - A [Markov random field](wikipedia://en/1323985), also known as a Markov network, is a model over an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph). A graphical model with many repeated subunits can be represented with [plate notation](wikipedia://en/15882673).
  - A [conditional random field](wikipedia://en/4118276) is a [discriminative model](wikipedia://en/12155912) specified over an undirected graph.
- A [restricted Boltzmann machine](https://en.wikipedia.org/wiki/Restricted_Boltzmann_machine) is a [bipartite](wikipedia://en/244431) [generative model](wikipedia://en/1222578) specified over an undirected graph.
- A [staged tree](wikipedia://en/78352042) is an extension of a Bayesian network for sequences of discrete valued events. They allow for context specific independences and non-product sample spaces.

## Applications {#Applications}

The framework of the models, which provides algorithms for discovering and analyzing structure in complex distributions to describe them succinctly and extract the unstructured information, allows them to be constructed and utilized effectively.[^o3] Applications of graphical models include [causal inference](wikipedia://en/37103476), [information extraction](https://en.wikipedia.org/wiki/Information_extraction), [speech recognition](https://en.wikipedia.org/wiki/Speech_recognition), [computer vision](https://en.wikipedia.org/wiki/Computer_vision), decoding of [low-density parity-check codes](https://en.wikipedia.org/wiki/Low-density_parity-check_codes), modeling of [gene regulatory networks](wikipedia://en/356382), gene finding and diagnosis of diseases, and [graphical models for protein structure](wikipedia://en/27292230).

:::
