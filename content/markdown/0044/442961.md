# Cryptographic Message Syntax

::: {#o1 .subject cue=lead name="Cryptographic Message Syntax"}

The **Cryptographic Message Syntax** (**CMS**) is the [IETF](https://en.wikipedia.org/wiki/IETF)'s standard for [cryptographically](wikipedia://en/18934432) protected messages. It can be used by cryptographic schemes and protocols to [digitally sign](wikipedia://en/59644), [digest](wikipedia://en/439526), [authenticate](wikipedia://en/567523) or [encrypt](wikipedia://en/10294) any form of digital data.

:::

CMS is based on the syntax of [PKCS #7](wikipedia://en/64431194), which in turn is based on the [Privacy-Enhanced Mail](wikipedia://en/552878) standard. The newest version of CMS () is specified in 5652 (but also see 5911 for updated ASN.1 modules conforming to ASN.1 2002 and 8933 and 9629 for updates to the standard).

The architecture of CMS is built around [certificate-based](https://en.wikipedia.org/wiki/X.509) key management, such as the profile defined by the [PKIX](https://en.wikipedia.org/wiki/PKIX) [working group](https://en.wikipedia.org/wiki/Working_group). CMS is used as the key cryptographic component of many other cryptographic standards, such as [S/MIME](https://en.wikipedia.org/wiki/S/MIME), [PKCS #12](wikipedia://en/12545362) and the 3161 [digital timestamping](https://en.wikipedia.org/wiki/Digital_timestamping) protocol.

[OpenSSL](wikipedia://en/438819) is [open source](https://en.wikipedia.org/wiki/Open-source_software) software that can encrypt, decrypt, sign and verify, compress and uncompress CMS documents, using the `openssl-cms` command.

## Norms and Standards {#Norms_and_Standards}

Cryptographic Message Syntax (CMS) is regularly updated to address evolving security needs and emerging cryptographic algorithms.

- 8933 (Update to the Cryptographic Message Syntax (CMS) for Algorithm Identifier Protection)
- 5652 (Cryptographic Message Syntax (CMS), in use)
- 3852 (Cryptographic Message Syntax (CMS), obsolete)
- 3369 (Cryptographic Message Syntax (CMS), obsolete)
- 2630 (Cryptographic Message Syntax, obsolete)
- 6268 (New ASN.1 Modules for Cryptographic Message Syntax (CMS) and S/MIME, in use)
- 5911 (New ASN.1 Modules for Cryptographic Message Syntax (CMS) and S/MIME, updated)
- 5753 (Using Elliptic Curve Cryptography with CMS, in use)
- 3278 (Use of Elliptic Curve Cryptography (ECC) Algorithms in Cryptographic Message Syntax (CMS), obsolete)
- 5084 (Using AES-CCM and AES-GCM Authenticated Encryption in the Cryptographic Message Syntax (CMS), in use)
- 9629 (Using Key Encapsulation Mechanism (KEM) Algorithms in the Cryptographic Message Syntax (CMS), in use)
