# Book cipher

::: {#o1 .subject cue=lead name="Book cipher"}

*Image: Exodus 4 - reference to spiritual possession putting words in mouths.jpg.* The [King James Bible](https://en.wikipedia.org/wiki/King_James_Version), a highly available publication suitable for the book cipher.

A **book cipher** is a [cipher](wikipedia://en/5244) in which each word or letter in the [plaintext](wikipedia://en/157935) of a message is replaced by some code that locates it in another text, the [key](wikipedia://en/53039).

:::

A simple version of such a cipher would use a specific book as the key, and would replace each word of the plaintext by a number that gives the position where that word occurs in that book. For example, if the chosen key is [H. G. Wells](https://en.wikipedia.org/wiki/H._G._Wells)'s novel *[The War of the Worlds](https://en.wikipedia.org/wiki/The_War_of_the_Worlds)*, the plaintext "*all plans failed, coming back tomorrow*" could be encoded as "*335 219 881, 5600 853 9315*" — since the 335th word of the novel is "*all*", the 219th is "*plans*", etc.

Instead of the position of the word, sender can also use for each word a triplet indicating page number, line number in the page and word number in the line, avoiding error-prone counting of words from the start of the book. With the Bible, triplet can be chapter number, verse number, word number.

This method requires that the sender and receiver use exactly the same edition of the key book.[^o2]

This simple version fails if the message uses a word that does not appear in the text. A variant that avoids this problem works with individual letters rather than words. Namely each letter of the plaintext message would be replaced by a number that specifies where that letter occurs in the key book. For example, using the same *War of the Worlds* book as the key, the message "no ammo" could be encoded as "12 10 / 50 31 59 34" since the words with those positions in the novel are "***n****ineteenth*", "***o****f*", "***a****lmost*", "***m****ortal*", "***m****ight*", and "***o****wn*". This method was used in one of the [Beale ciphers](wikipedia://en/449424). This variant is more properly called a [substitution cipher](wikipedia://en/48356), specifically a [homophonic](wikipedia://en/48356#Homophonic_substitution) one.

Both methods, as described, are quite laborious. Therefore, in practice, the key has usually been a [codebook](wikipedia://en/530786) created for the purpose: a simple dictionary-like listing of all the words that might be needed to form a message, each with the respective code number(s). This version is called a [code](wikipedia://en/838989), and was extensively used from the 15th century up to [World War II](https://en.wikipedia.org/wiki/World_War_II).

## Choosing the key {#Choosing_the_key}

The main strength of a book cipher is the key. The sender and receiver of encoded messages can agree to use any book or other publication available to both of them as the key to their cipher. Someone intercepting the message and attempting to decode it, unless they are a skilled cryptographer (see: , below), must somehow identify the key from a huge number of possibilities available. In the context of [espionage](https://en.wikipedia.org/wiki/Espionage), a book cipher has a considerable advantage for a spy in enemy territory. A conventional codebook, if discovered by the local authorities, instantly incriminates the holder as a spy and gives the authorities the chance of deciphering the code and sending false messages impersonating the agent. On the other hand, a book, if chosen carefully to fit with the spy's cover story, would seem entirely innocuous. The drawback to a book cipher is that both parties have to possess an identical copy of the key. The book must not be of the sort that would look out of place in the possession of those using it, and it must be of a type likely to contain any words required. Thus, a spy wishing to send information about troop movements and numbers of armaments would be unlikely to find a cookbook or romance novel useful keys.

## Using widely available publications {#Using_widely_available_publications}

### Dictionary {#Dictionary}

Another approach is to use a dictionary as the codebook. This guarantees that nearly all words will be found, and also makes it much easier to find a word when encoding. This approach was used by [George Scovell](wikipedia://en/679423) for the [Duke of Wellington](https://en.wikipedia.org/wiki/Arthur_Wellesley,_1st_Duke_of_Wellington)'s army in some campaigns of the [Peninsular War](https://en.wikipedia.org/wiki/Peninsular_War). In Scovell's method, a codeword would consist of a number (indicating the page of the dictionary), a letter (indicating the column on the page), and finally a number indicating which entry of the column was meant. However, this approach also has a disadvantage: because entries are arranged in alphabetical order, so are the code numbers. This can give strong hints to the [cryptanalyst](wikipedia://en/5715) unless the message is [superenciphered](wikipedia://en/838989#Superencipherment). The wide distribution and availability of dictionaries also present a problem; it is likely that anyone trying to break such a code is also in possession of the dictionary which can be used to read the message.

### Bible cipher {#Bible_cipher}

The [Bible](https://en.wikipedia.org/wiki/Bible) is a widely available book that is almost always printed with chapter and verse markings making it easy to find a specific string of text within it, making it particularly useful for this purpose; the widespread availability of [concordances](https://en.wikipedia.org/wiki/Bible_concordance) can ease the encoding process as well.

## Security {#Security}

Essentially, the code version of a "book cipher" is just like any other code, but one in which the trouble of preparing and distributing the [codebook](wikipedia://en/530786) has been eliminated by using an existing text. However this means, as well as being attacked by all the usual means employed against other codes or ciphers, partial solutions may help the [cryptanalyst](wikipedia://en/5715) to guess other codewords, or even to break the code completely by identifying the key text. This is, however, not the only way a book cipher may be broken. It is still susceptible to other methods of cryptanalysis, and as such is quite easily broken, even without sophisticated means, without the cryptanalyst having any idea to what book the cipher is keyed.[^o8]

## Examples {#Examples}

- A famous use of a book cipher is in the [Beale ciphers](wikipedia://en/449424), of which Document No. 2 uses (a variant printing of) the [United States Declaration of Independence](https://en.wikipedia.org/wiki/United_States_Declaration_of_Independence) as the key text.
- In the [American Revolution](https://en.wikipedia.org/wiki/American_Revolution), [Benedict Arnold](https://en.wikipedia.org/wiki/Benedict_Arnold) used a book cipher, sometimes known as the [Arnold Cipher](wikipedia://en/2711669), which used Sir [William Blackstone](https://en.wikipedia.org/wiki/William_Blackstone)'s *[Commentaries on the Laws of England](https://en.wikipedia.org/wiki/Commentaries_on_the_Laws_of_England)* as a key text.
- Book ciphers have consistently been used throughout the [Cicada 3301](https://en.wikipedia.org/wiki/Cicada_3301) mystery.[^o11]
- [Eli Cohen](https://en.wikipedia.org/wiki/Eli_Cohen), the Israeli spy who for several years infiltrated the Syrian government until discovered by the Syrian intelligence and executed, used for his communications with Israel a book cypher based on a French-language copy of [Alexandre Dumas](https://en.wikipedia.org/wiki/Alexandre_Dumas)'s *[The Three Musketeers](https://en.wikipedia.org/wiki/The_Three_Musketeers)*.[^o12]

### In fiction {#In_fiction}

- In *[Colony](https://en.wikipedia.org/wiki/Colony_%28TV_series%29)*, a television series, the resistance movement uses a book cipher to communicate between members of the cells.
- In the novel *[Monsieur Lecoq](https://en.wikipedia.org/wiki/Monsieur_Lecoq)*, published in 1868, [Monsieur Lecoq](https://en.wikipedia.org/wiki/Monsieur_Lecoq) finds that a prisoner is communicating with his confederate using a double book cipher. Since the prisoner has only one book, *The songs of [Béranger](https://en.wikipedia.org/wiki/Pierre-Jean_de_Béranger)*, the solution is easily discovered.
- In *[The Valley of Fear](https://en.wikipedia.org/wiki/The_Valley_of_Fear)*, [Sherlock Holmes](https://en.wikipedia.org/wiki/Sherlock_Holmes) decrypts a message enciphered with a book cipher by deducing which book had been used as a key text.
- The name of [Ken Follett](https://en.wikipedia.org/wiki/Ken_Follett)'s World War II thriller *[The Key to Rebecca](https://en.wikipedia.org/wiki/The_Key_to_Rebecca)* refers to a [German spy](https://en.wikipedia.org/wiki/Abwehr) in [Cairo](https://en.wikipedia.org/wiki/Cairo) using [Daphne du Maurier](https://en.wikipedia.org/wiki/Daphne_du_Maurier)'s novel *[Rebecca](https://en.wikipedia.org/wiki/Rebecca_%28novel%29)* as the basis of a code.
- In *[A Presumption of Death](https://en.wikipedia.org/wiki/A_Presumption_of_Death)*, [Lord Peter Wimsey](https://en.wikipedia.org/wiki/Lord_Peter_Wimsey), on assignment for British Intelligence in World War II Nazi-occupied Europe, uses a code based on the works of [John Donne](https://en.wikipedia.org/wiki/John_Donne). The Germans break the code, coming near to catching Wimsey and Bunter. Wimsey then improvises a new code, based on an unpublished text known only to himself and his wife.
- [Graham Greene](https://en.wikipedia.org/wiki/Graham_Greene)'s protagonists often use book codes. In *[The Human Factor](https://en.wikipedia.org/wiki/The_Human_Factor_%28novel%29)*, several books are used, and an edition of [Charles Lamb](https://en.wikipedia.org/wiki/Charles_Lamb_%28writer%29)'s *[Tales from Shakespeare](https://en.wikipedia.org/wiki/Tales_from_Shakespeare)* is used in *[Our Man in Havana](https://en.wikipedia.org/wiki/Our_Man_in_Havana)*.
- A book cipher plays an important role in the TV version of *[Sharpe's Sword](https://en.wikipedia.org/wiki/Sharpe's_Sword_%28TV_programme%29)*. The key text is Voltaire's *[Candide](https://en.wikipedia.org/wiki/Candide)*.
- In the 2004 film *[National Treasure](https://en.wikipedia.org/wiki/National_Treasure_%28film%29)*, a book cipher (called an "Ottendorf cipher") is discovered on the back of the [U.S. Declaration of Independence](https://en.wikipedia.org/wiki/United_States_Declaration_of_Independence), using the "[Silence Dogood](https://en.wikipedia.org/wiki/Silence_Dogood)" letters as the key text.
- The protagonists of the [Matthew Reilly](https://en.wikipedia.org/wiki/Matthew_Reilly) novel *[The Six Sacred Stones](https://en.wikipedia.org/wiki/The_Six_Sacred_Stones)* used a book cipher to send confidential messages to each other. The key text was the [Harry Potter](https://en.wikipedia.org/wiki/Harry_Potter) books, but the messages were sent *via* a *[The Lord of the Rings](https://en.wikipedia.org/wiki/The_Lord_of_the_Rings)* forum to make the key text harder to identify.
- In *[Lost](https://en.wikipedia.org/wiki/Lost_%282004_TV_series%29): Mystery of the Island*, a series of four [jigsaw puzzles](https://en.wikipedia.org/wiki/Jigsaw_puzzle) released in 2007, a book cipher was used on each puzzle's box to hide spoilers and reveal information about the show to the fans.
- "The Fisher King", a two-part episode of *[Criminal Minds](https://en.wikipedia.org/wiki/Criminal_Minds)*, features a book cipher brought to the [Behavioral Analysis Unit](https://en.wikipedia.org/wiki/Behavioral_Analysis_Unit) by the UNSUB via Agent Hotchner's wife. The cypher was part of a larger puzzle to find a girl who had been missing for two years. The key text was *[The Collector](https://en.wikipedia.org/wiki/The_Collector)* by [John Fowles](https://en.wikipedia.org/wiki/John_Fowles).
- *[Burn Notice](https://en.wikipedia.org/wiki/Burn_Notice)* (episodes "Where There's Smoke" and "Center of the Storm", 2010): Michael Westen steals a Bible from a safe deposit box that is the code book of Simon. This becomes part of the season plot to track an organization starting wars for profit as Michael tries to arrange an interview with Simon.
- In the episode "[The Blind Banker](https://en.wikipedia.org/wiki/The_Blind_Banker)" of the BBC series *[Sherlock](https://en.wikipedia.org/wiki/Sherlock_%28TV_series%29)*, [Sherlock Holmes](https://en.wikipedia.org/wiki/Sherlock_Holmes) searches for a book that is the key to a cipher being used by [Chinese Tong](https://en.wikipedia.org/wiki/Tong_%28organization%29) smugglers to communicate with their agents and with each other through graffiti messages. He eventually finds it: the [London A-Z](https://en.wikipedia.org/wiki/Geographers'_A–Z_Street_Atlas).
- In the film *[Unknown](https://en.wikipedia.org/wiki/Unknown_%282011_film%29)* (2011), Prof. Bressler's passwords are obscured by a book cipher.
- In *[The Unit](https://en.wikipedia.org/wiki/The_Unit)* episode "[Paradise Lost](https://en.wikipedia.org/wiki/Paradise_Lost_%28The_Unit%29)", Jonas Blane (a.k.a. Snake Doctor) uses a book code from the poem *[Paradise Lost](https://en.wikipedia.org/wiki/Paradise_Lost)* to communicate to his wife, [Molly](https://en.wikipedia.org/wiki/Molly_Blane), that he has arrived safely in Panama.
- In *[The Good Soldier Švejk](https://en.wikipedia.org/wiki/The_Good_Soldier_Švejk)* by [Jaroslav Hašek](https://en.wikipedia.org/wiki/Jaroslav_Hašek), the officers in Švejk's [battalion](https://en.wikipedia.org/wiki/Battalion) attempt to use a book cipher. Their attempts are undone, however, when it is revealed that the novel in question is composed of two volumes, and Švejk has delivered the first volume to the officers, thinking that they intended to read the novel, rather than the second, which is used for the cipher. Furthermore, the key to the cipher is identical to an example given in a published military textbook.
- In *[An Instance of the Fingerpost](https://en.wikipedia.org/wiki/An_Instance_of_the_Fingerpost)*, a [historical mystery](https://en.wikipedia.org/wiki/Historical_fiction) by [Iain Pears](https://en.wikipedia.org/wiki/Iain_Pears), a book cipher conceals one character's family history and its relationship with the [English Civil War](https://en.wikipedia.org/wiki/English_Civil_War).
- In John Le Carre's *[A Perfect Spy](https://en.wikipedia.org/wiki/A_Perfect_Spy)*, the protagonist Magnus Pym uses a book cipher based on the German text Simplicissimus.
- In the book *[Red Dragon](https://en.wikipedia.org/wiki/Red_Dragon_%28novel%29)*, [Hannibal Lecter](https://en.wikipedia.org/wiki/Hannibal_Lecter) uses a book code to encrypt a message to the [Tooth Fairy](https://en.wikipedia.org/wiki/Francis_Dolarhyde) killer, with the message containing the home address of [Will Graham](https://en.wikipedia.org/wiki/Will_Graham_%28character%29), who is investigating the case, and the message, "Save yourself. Kill them all", with the intent of having Will and his family fall victim to the killer. In the 1986 film adaptation [Manhunter](https://en.wikipedia.org/wiki/Manhunter_%28film%29), the book used is mentioned to be a list of statutes of the state of [Maryland](https://en.wikipedia.org/wiki/Maryland). In the 2002 adaptation [Red Dragon](https://en.wikipedia.org/wiki/Red_Dragon_%282002_film%29), the book is changed to the French cooking encyclopedia [Larousse Gastronomique](https://en.wikipedia.org/wiki/Larousse_Gastronomique) to fit in with that movie's depiction of Lecter.
- In *The Darwin Code* by J D Welch, Jess uses a Shakespearean speech to construct a book cipher to communicate with an enemy who may or may not be an ally.
- In Bitterblue by Kristin Cashore, Bitterblue uses a book(?) code to unlock secrets of her father's reign as king.
- In the TV series *[Deutschland 83](https://en.wikipedia.org/wiki/Deutschland_83)*, protagonist Martin Rauch's [East German](https://en.wikipedia.org/wiki/East_German) handlers use a book cipher to communicate with him while he is undercover in [West Germany](https://en.wikipedia.org/wiki/West_Germany).
- In the series 2 finale of the BBC TV show *[Luther](https://en.wikipedia.org/wiki/Luther_%28TV_series%29)*, two brothers use a book cipher. Luther determines they must be using a book that is readily available in case the book is lost and/or so the users can always have it to hand. This leads him to discovering the book cipher is using Gideon's Bible.
