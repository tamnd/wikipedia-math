# Weierstrass function (nowhere-differentiable function)

*Image: WeierstrassFunction.svg.* Plot of Weierstrass function over the interval \[−2, 2\]. Like some other [fractals](wikipedia://en/10913), the function exhibits [self-similarity](wikipedia://en/28782): every zoom (red circle) is similar to the global plot.

::: {#o1 .subject cue=lead name="Weierstrass function"}

In [mathematics](wikipedia://en/18831), the **Weierstrass function**, named after its discoverer, [Karl Weierstrass](wikipedia://en/93459), is an example of a real-valued [function](wikipedia://en/185427) that is [continuous](wikipedia://en/6122) everywhere but [differentiable](wikipedia://en/330206) nowhere. It is also an example of a [fractal curve](wikipedia://en/4972605).

:::

The Weierstrass function has historically served the role of a [pathological](wikipedia://en/372742) function, being the first published example (1872) specifically concocted to challenge the notion that every continuous function is differentiable except on a set of isolated points. Weierstrass's demonstration that continuity did not imply almost-everywhere differentiability upended mathematics, overturning several proofs that relied on geometric intuition and vague definitions of [smoothness](wikipedia://en/1408000). These types of functions were disliked by contemporaries. For instance, [Charles Hermite](wikipedia://en/22870422), on finding that one class of function he was working on had such a property, described it as a "lamentable scourge".Accuracy of Poincaré quote in lead[^o2] The functions were difficult to visualize until the arrival of computers in the next century, and the results did not gain wide acceptance until practical applications such as models of [Brownian motion](wikipedia://en/4436) necessitated infinitely jagged functions (nowadays known as *[fractal curves](https://en.wikipedia.org/wiki/Fractal_curves)*).[^o3]

::: {#o5 .definition kind=definition/construction cue=heading name="Construction"}

## Construction {#Construction}

*Image: Weierstrass Animation.gif.* Animation based on the increasing of the $b$ value from 0.1 to 5.

In Weierstrass's original paper, the function was defined as a [Fourier series](wikipedia://en/59038):

$$\ f(x)=\sum_{n=0} ^\infty a^n \cos(b^n \pi x)\ ,$$

where $\ 0 < a < 1\ ,$ and $\ b\$ is a positive odd integer, and

$$\ a\ b > 1 + \tfrac{3}{2}\ \pi ~.$$

The minimum value of $\ b\$ for which there exists $\ 0 < a < 1\$ such that these constraints are satisfied is $\ b = 7 ~.$ This construction, along with the proof that the function is not differentiable at any point, was first delivered by Weierstrass in a paper presented to the [Königliche Akademie der Wissenschaften](https://en.wikipedia.org/wiki/Prussian_Academy_of_Sciences) on 18 July 1872.[^o6][^o7][^o8]

Despite being differentiable nowhere, the function is continuous: Since the terms of the infinite series which defines it are bounded by $\ \pm a^n\$ and this has finite sum for $\ 0 < a < 1\ ,$ convergence of the sum of the terms is [uniform](wikipedia://en/50652) by the [Weierstrass M-test](wikipedia://en/444456) with $\ M_n = a^n ~.$ Since each partial sum is continuous, by the [uniform limit theorem](wikipedia://en/29230765), it follows that $\ f\$ is continuous. Additionally, since each partial sum is [uniformly continuous](wikipedia://en/32337), it follows that $\ f\$ is also uniformly continuous.

It might be expected that a continuous function must have a derivative, or that the set of points where it is not differentiable should be countably infinite or finite. According to Weierstrass in his paper, earlier mathematicians including [Gauss](wikipedia://en/6125) had often assumed that this was true. This might be because it is difficult to draw or visualise a continuous function whose set of nondifferentiable points is something other than a countable set of points. Analogous results for better behaved classes of continuous functions do exist, for example the [Lipschitz functions](https://en.wikipedia.org/wiki/Lipschitz_functions), whose set of non-differentiability points must be a [Lebesgue null set](https://en.wikipedia.org/wiki/Lebesgue_null_set) ([Rademacher's theorem](wikipedia://en/7764195)). When we try to draw a general continuous function, we usually draw the graph of a function which is Lipschitz or otherwise well-behaved. Moreover, the fact that the set of non-differentiability points for a [monotone function](wikipedia://en/48260) is [measure-zero](https://en.wikipedia.org/wiki/Measure_zero) implies that the rapid oscillations of Weierstrass' function are necessary to ensure that it is nowhere-differentiable.

The Weierstrass function was one of the first [fractals](https://en.wikipedia.org/wiki/Fractals) studied, although this term was not used until much later. The function has detail at every level, so zooming in on a piece of the curve does not show it getting progressively closer and closer to a straight line. Rather between any two points no matter how close, the function will not be monotone.

The computation of the [Hausdorff dimension](wikipedia://en/14294) $\ D\$ of the graph of the classical Weierstrass function was an open problem until 2018, while it was generally believed that $\ D = 2 + \log_b(a) < 2 ~.$[^o9][^o10] That $D$ is strictly less than 2 follows from the conditions on $\ a\$ and $\ b\$ from above. Only after more than 30 years was this proved rigorously.[^o11]

The term Weierstrass function is often used in [real analysis](wikipedia://en/26478) to refer to any function with similar properties and construction to Weierstrass's original example. For example, the cosine function can be replaced in the infinite series by a [piecewise linear "zigzag" function](wikipedia://en/52151). [G. H. Hardy](wikipedia://en/87599) showed that the function of the above construction is nowhere differentiable with the assumptions $\ 0 < a < 1\ ,~ a\ b \geq 1 ~.$[^o12]

## Riemann function {#Riemann_function}

The Weierstrass function is based on the earlier Riemann function, claimed to be differentiable nowhere. Occasionally, this function

$$f(x) = \sum_{n = 1}^\infty \frac{\sin(n^2x)}{n^2}$$

has also been called "the" Weierstrass function or "a" Weierstrass function.[^o14]

While [Bernhard Riemann](wikipedia://en/41980) strongly claimed that the function is differentiable nowhere, no evidence of this was published by Riemann, and Weierstrass noted that he did not find any evidence of it surviving either in Riemann's papers or orally from his students.

In 1916, [G. H. Hardy](wikipedia://en/87599) confirmed that the function does not have a finite derivative in any value of $\pi x$ where $x$ is irrational or is rational with the form of either $\frac{2A}{4B+1}$ or $\ \frac{2A+1}{2B}\ ,$ where $A$ and $B$ are integers.[^o12] In 1969, [Joseph Gerver](https://en.wikipedia.org/wiki/Joseph_Gerver) found that the Riemann function has a defined differential on every value of $x$ that can be expressed in the form of $\ \frac{2A+1}{2B+1}\ \pi\$ with integer $A$ and $B$; that is, rational multipliers of $\ \pi\$ with an odd numerator and denominator. On these points, the function has a derivative of $\ -\frac{1}{2}\$.[^o15] In 1971, J. Gerver showed that the function has no finite differential at the values of $x$ that can be expressed in the form of $\ \frac{2A}{2B+1}\ \pi\ ,$ completing the problem of the differentiability of the Riemann function.[^o16]

As the Riemann function is differentiable only on a [null set](wikipedia://en/21520) of points, it is differentiable [almost nowhere](https://en.wikipedia.org/wiki/Almost_nowhere).

## Hölder continuity {#Hölder_continuity}

It is convenient to write the Weierstrass function equivalently as

$$\ W_\alpha(x) = \sum_{n=0}^\infty b^{-n\alpha}\ \cos(b^n \pi x)\$$

for $\ \alpha \equiv -\frac{\ln(a)}{\ln(b)} ~.$ Then $\ W_\alpha(x)\$ is [Hölder continuous](https://en.wikipedia.org/wiki/Hölder_continuous) of exponent $\alpha$, which is to say that there is a constant $K$ such that

$$\ \Bigl|\ W_\alpha(x) - W_\alpha(y)\ \Bigr|\ \le\ K\ \left|\ x - y\ \right|^\alpha\$$

for all $\ x\$ and $\ y ~.$[^o18] Moreover, $\ W_1\$ is Hölder continuous of all orders $\ \alpha < 1\$ but not [Lipschitz continuous](https://en.wikipedia.org/wiki/Lipschitz_continuous).

## Density of nowhere-differentiable functions {#Density_of_nowhere-differentiable_functions}

It turns out that the Weierstrass function is far from being an isolated example: although it is "pathological", it is also "typical" of continuous functions:

- In a [topological](wikipedia://en/29954) sense: the set of nowhere-differentiable real-valued functions on $[0, 1]$ is [comeager](https://en.wikipedia.org/wiki/Comeager_set) in the [vector space](wikipedia://en/32370) $C([0, 1]; \mathbb{R})$ of all continuous real-valued functions on $[0, 1]$ with the topology of [uniform convergence](wikipedia://en/50652).[^o20][^o21]
- In a [measure-theoretic](https://en.wikipedia.org/wiki/Measure_theory) sense: when the space $C([0, 1]; \mathbb{R})$ is equipped with [classical Wiener measure](https://en.wikipedia.org/wiki/Classical_Wiener_measure) $\gamma$, the collection of functions that are differentiable at even a single point of $[0, 1]$ has $\gamma$-[measure zero](https://en.wikipedia.org/wiki/Measure_zero). The same is true even if one takes finite-dimensional "slices" of $C([0, 1]; \mathbb{R})$ , in the sense that the nowhere-differentiable functions form a [prevalent subset](wikipedia://en/11649911) of $C([0, 1]; \mathbb{R})$ .
