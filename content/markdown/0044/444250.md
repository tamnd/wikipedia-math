- [Approximations of $\pi$](https://en.wikipedia.org/wiki/Approximations_of_π):

:::

  - [Liu Hui's π algorithm](wikipedia://en/17829294) — first algorithm that can compute π to arbitrary precision
  - [Leibniz formula for π](wikipedia://en/1301559) — alternating series with very slow convergence
  - [Wallis product](wikipedia://en/1301687) — infinite product converging slowly to π/2
  - [Viète's formula](wikipedia://en/1609504) — more complicated infinite product which converges faster
  - [Gauss–Legendre algorithm](wikipedia://en/12916) — iteration which converges quadratically to π, based on arithmetic–geometric mean
  - [Borwein's algorithm](wikipedia://en/233353) — iteration which converges quartically to 1/π, and other algorithms
  - [Chudnovsky algorithm](wikipedia://en/15893520) — fast algorithm that calculates a hypergeometric series
  - [Bailey–Borwein–Plouffe formula](wikipedia://en/22684956) — can be used to compute individual hexadecimal digits of π
  - [Bellard's formula](wikipedia://en/5957331) — faster version of Bailey–Borwein–Plouffe formula
  - [List of formulae involving π](wikipedia://en/4659082)

## Numerical linear algebra {#Numerical_linear_algebra}

[Numerical linear algebra](wikipedia://en/7330660) — study of numerical algorithms for linear algebra problems

### Basic concepts {#Basic_concepts}

- Types of matrices appearing in numerical analysis:
  - [Sparse matrix](wikipedia://en/341015)
    - [Band matrix](wikipedia://en/1451476)
    - [Bidiagonal matrix](wikipedia://en/1451250)
    - [Tridiagonal matrix](wikipedia://en/519218)
    - [Pentadiagonal matrix](https://en.wikipedia.org/wiki/Pentadiagonal_matrix)
    - [Skyline matrix](https://en.wikipedia.org/wiki/Skyline_matrix)
  - [Circulant matrix](wikipedia://en/889936)
  - [Triangular matrix](wikipedia://en/374222)
  - [Diagonally dominant matrix](wikipedia://en/5262748)
  - [Block matrix](wikipedia://en/457464) — matrix composed of smaller matrices
  - [Stieltjes matrix](wikipedia://en/8098498) — symmetric positive definite with non-positive off-diagonal entries
  - [Hilbert matrix](wikipedia://en/265000) — example of a matrix which is extremely ill-conditioned (and thus difficult to handle)
  - [Wilkinson matrix](wikipedia://en/21922476) — example of a symmetric tridiagonal matrix with pairs of nearly, but not exactly, equal eigenvalues
  - [Convergent matrix](wikipedia://en/37709899) — square matrix whose successive powers approach the zero matrix
- Algorithms for matrix multiplication:
  - [Strassen algorithm](wikipedia://en/771965)
  - [Coppersmith–Winograd algorithm](https://en.wikipedia.org/wiki/Coppersmith–Winograd_algorithm)
  - [Cannon's algorithm](wikipedia://en/12022054) — a distributed algorithm, especially suitable for processors laid out in a 2d grid
  - [Freivalds' algorithm](wikipedia://en/4767368) — a randomized algorithm for checking the result of a multiplication

::: {#o43 .entry cue=list-entry name="Matrix decomposition"}

- [Matrix decompositions](wikipedia://en/253873):

:::

  - [LU decomposition](wikipedia://en/6243993) — lower triangular times upper triangular
  - [QR decomposition](wikipedia://en/305223) — orthogonal matrix times triangular matrix
    - [RRQR factorization](wikipedia://en/31372766) — rank-revealing QR factorization, can be used to compute rank of a matrix
  - [Polar decomposition](wikipedia://en/1369241) — unitary matrix times positive-semidefinite Hermitian matrix
  - Decompositions by similarity:
    - [Eigendecomposition](wikipedia://en/13576645) — decomposition in terms of eigenvectors and eigenvalues
    - [Jordan normal form](wikipedia://en/312877) — bidiagonal matrix of a certain form; generalizes the eigendecomposition
      - [Weyr canonical form](wikipedia://en/41331720) — permutation of Jordan normal form
    - [Jordan–Chevalley decomposition](wikipedia://en/11578785) — sum of commuting nilpotent matrix and diagonalizable matrix
    - [Schur decomposition](wikipedia://en/372514) — similarity transform bringing the matrix to a triangular matrix
  - [Singular value decomposition](wikipedia://en/142207) — unitary matrix times diagonal matrix times unitary matrix

::: {#o44 .entry cue=list-entry name="Matrix splitting"}

- [Matrix splitting](wikipedia://en/36743227) — expressing a given matrix as a sum or difference of matrices

:::

  - [Frontal solver](wikipedia://en/8547005) — used in finite element methods
  - [Nested dissection](wikipedia://en/28070753) — for symmetric matrices, based on graph partitioning

- Iterative methods:
  - [Jacobi method](wikipedia://en/4047104)
  - [Gauss–Seidel method](wikipedia://en/4046824)
    - [Successive over-relaxation](wikipedia://en/4068447) (SOR) — a technique to accelerate the Gauss–Seidel method
      - [Symmetric successive over-relaxation](wikipedia://en/8517402) (SSOR) — variant of SOR for symmetric matrices
    - [Backfitting algorithm](wikipedia://en/25099295) — iterative procedure used to fit a generalized additive model, often equivalent to Gauss–Seidel
  - [Modified Richardson iteration](wikipedia://en/8518299)
  - [Conjugate gradient method](wikipedia://en/1448821) (CG) — assumes that the matrix is positive definite
    - [Derivation of the conjugate gradient method](wikipedia://en/26956978)
    - [Nonlinear conjugate gradient method](wikipedia://en/8980593) — generalization for nonlinear optimization problems
  - [Biconjugate gradient method](wikipedia://en/4289501) (BiCG)
    - [Biconjugate gradient stabilized method](wikipedia://en/25694537) (BiCGSTAB) — variant of BiCG with better convergence
  - [Conjugate residual method](wikipedia://en/29450651) — similar to CG but only assumed that the matrix is symmetric
  - [Generalized minimal residual method](wikipedia://en/4329521) (GMRES) — based on the Arnoldi iteration
  - [Chebyshev iteration](wikipedia://en/23263797) — avoids inner products but needs bounds on the spectrum
  - [Stone's method](wikipedia://en/4077966) (SIP — Strongly Implicit Procedure) — uses an incomplete LU decomposition
  - [Kaczmarz method](wikipedia://en/2407650)
  - [Preconditioner](wikipedia://en/5165246)
    - [Incomplete Cholesky factorization](wikipedia://en/8518192) — sparse approximation to the Cholesky factorization
    - [Incomplete LU factorization](wikipedia://en/8517337) — sparse approximation to the LU factorization
  - [Uzawa iteration](wikipedia://en/41225449) — for saddle node problems
- Underdetermined and overdetermined systems (systems that have no or more than one solution):
  - [Numerical computation of null space](https://en.wikipedia.org/wiki/Kernel_%28matrix%29#Numerical_computation_of_null_space) — find all solutions of an underdetermined system
  - [Moore–Penrose pseudoinverse](https://en.wikipedia.org/wiki/Moore–Penrose_pseudoinverse) — for finding solution with smallest 2-norm (for underdetermined systems) or smallest residual
  - [Sparse approximation](wikipedia://en/15951862) — for finding the sparsest solution (i.e., the solution with as many zeros as possible)

## Finding roots of nonlinear equations {#Finding_roots_of_nonlinear_equations}

*See #Numerical linear algebra for linear equations*

[Root-finding algorithm](wikipedia://en/153299) — algorithms for solving the equation *f*(*x*) = 0

- General methods:
  - [Bisection method](wikipedia://en/646651) — simple and robust; linear convergence
    - [Lehmer–Schur algorithm](wikipedia://en/2711954) — variant for complex functions
  - [Fixed-point iteration](wikipedia://en/7344320)
  - [Newton's method](wikipedia://en/22145) — based on linear approximation around the current iterate; quadratic convergence
    - [Kantorovich theorem](wikipedia://en/10349343) — gives a region around solution such that Newton's method converges
    - [Newton fractal](wikipedia://en/3918520) — indicates which initial condition converges to which root under Newton iteration
    - [Quasi-Newton method](wikipedia://en/7883127) — uses an approximation of the Jacobian:
      - [Broyden's method](wikipedia://en/10971756) — uses a rank-one update for the Jacobian
      - [Symmetric rank-one](wikipedia://en/11227519) — a symmetric (but not necessarily positive definite) rank-one update of the Jacobian
      - [Davidon–Fletcher–Powell formula](wikipedia://en/11231265) — update of the Jacobian in which the matrix remains positive definite
      - [Broyden–Fletcher–Goldfarb–Shanno algorithm](wikipedia://en/1926409) — rank-two update of the Jacobian in which the matrix remains positive definite
      - [Limited-memory BFGS](https://en.wikipedia.org/wiki/Limited-memory_BFGS) method — truncated, matrix-free variant of BFGS method suitable for large problems
    - [Steffensen's method](wikipedia://en/12180274) — uses divided differences instead of the derivative
  - [Secant method](wikipedia://en/640746) — based on linear interpolation at last two iterates
  - [False position method](https://en.wikipedia.org/wiki/False_position_method) — secant method with ideas from the bisection method
  - [Muller's method](wikipedia://en/1703991) — based on quadratic interpolation at last three iterates
  - [Sidi's generalized secant method](wikipedia://en/38824087) — higher-order variants of secant method
  - [Inverse quadratic interpolation](wikipedia://en/1313620) — similar to Muller's method, but interpolates the inverse
  - [Brent's method](wikipedia://en/1254323) — combines bisection method, secant method and inverse quadratic interpolation
  - [Ridders' method](wikipedia://en/17106226) — fits a linear function times an exponential to last two iterates and their midpoint
  - [Halley's method](wikipedia://en/9053035) — uses *f*, *f*' and *f*''; achieves the cubic convergence
  - [Householder's method](wikipedia://en/13075367) — uses first *d* derivatives to achieve order *d* + 1; generalizes Newton's and Halley's method
- Methods for polynomials:
  - [Aberth method](wikipedia://en/7378088)
  - [Bairstow's method](https://en.wikipedia.org/wiki/Bairstow's_method)
  - [Durand–Kerner method](wikipedia://en/3675893)
  - [Graeffe's method](wikipedia://en/6134192)
  - [Jenkins–Traub algorithm](wikipedia://en/12106314) — fast, reliable, and widely used
  - [Laguerre's method](wikipedia://en/1136614)
  - [Splitting circle method](wikipedia://en/3683888)
- Analysis:
  - [Wilkinson's polynomial](wikipedia://en/646974)

### Nonlinear programming {#Nonlinear_programming}

[Nonlinear programming](wikipedia://en/679709) — the most general optimization problem in the usual framework

- Special cases of nonlinear programming:
  - See *Linear programming* and *Convex optimization* above
  - [Geometric programming](wikipedia://en/9644681) — problems involving signomials or posynomials
    - [Signomial](wikipedia://en/18132644) — similar to polynomials, but exponents need not be integers
    - [Posynomial](wikipedia://en/9644721) — a signomial with positive coefficients
  - [Quadratically constrained quadratic program](wikipedia://en/9519121)
  - [Linear-fractional programming](wikipedia://en/22989094) — objective is ratio of linear functions, constraints are linear
    - [Fractional programming](wikipedia://en/31906989) — objective is ratio of nonlinear functions, constraints are linear
  - [Nonlinear complementarity problem](wikipedia://en/26548937) (NCP) — find *x* such that *x* ≥ 0, *f*(*x*) ≥ 0 and *x*<sup>T</sup> *f*(*x*) = 0
  - [Least squares](wikipedia://en/82359) — the objective function is a sum of squares
    - [Non-linear least squares](wikipedia://en/15652764)
    - [Gauss–Newton algorithm](wikipedia://en/1164753)
      - [BHHH algorithm](https://en.wikipedia.org/wiki/BHHH_algorithm) — variant of Gauss–Newton in econometrics
      - [Generalized Gauss–Newton method](wikipedia://en/17324351) — for constrained nonlinear least-squares problems
    - [Levenberg–Marquardt algorithm](wikipedia://en/892446)
    - [Iteratively reweighted least squares](wikipedia://en/11463665) (IRLS) — solves a weighted least-squares problem at every iteration
    - [Partial least squares](https://en.wikipedia.org/wiki/Partial_least_squares) — statistical techniques similar to principal components analysis
      - [Non-linear iterative partial least squares](https://en.wikipedia.org/wiki/Non-linear_iterative_partial_least_squares) (NIPLS)
  - [Mathematical programming with equilibrium constraints](wikipedia://en/18894568) — constraints include variational inequalities or complementarities
  - Univariate optimization:
    - [Golden section search](https://en.wikipedia.org/wiki/Golden_section_search)
    - [Successive parabolic interpolation](wikipedia://en/14680977) — based on quadratic interpolation through the last three iterates
- General algorithms:
  - Concepts:
    - [Descent direction](wikipedia://en/1537992)
    - [Guess value](wikipedia://en/2712653) — the initial guess for a solution with which an algorithm starts
    - [Line search](wikipedia://en/1537058)
      - [Backtracking line search](wikipedia://en/1670188)
      - [Wolfe conditions](wikipedia://en/1671343)
  - [Gradient method](wikipedia://en/15094152) — method that uses the gradient as the search direction
    - [Gradient descent](wikipedia://en/201489)
      - [Stochastic gradient descent](wikipedia://en/1180641)
    - [Landweber iteration](wikipedia://en/35717958) — mainly used for ill-posed problems
  - [Successive linear programming](https://en.wikipedia.org/wiki/Successive_linear_programming) (SLP) — replace problem by a linear programming problem, solve that, and repeat
  - [Sequential quadratic programming](wikipedia://en/7415899) (SQP) — replace problem by a quadratic programming problem, solve that, and repeat
  - [Newton's method in optimization](wikipedia://en/1244523)
    - See also under *Newton algorithm* in the section *Finding roots of nonlinear equations*
  - [Nonlinear conjugate gradient method](wikipedia://en/8980593)
  - Derivative-free methods
    - [Coordinate descent](wikipedia://en/33837524) — move in one of the coordinate directions
      - [Adaptive coordinate descent](https://en.wikipedia.org/wiki/Adaptive_coordinate_descent) — adapt coordinate directions to objective function
      - [Random coordinate descent](wikipedia://en/34432764) — randomized version
    - [Nelder–Mead method](wikipedia://en/2492629)
    - [Pattern search (optimization)](wikipedia://en/27328823)
    - [Powell's method](wikipedia://en/24106975) — based on conjugate gradient descent
    - [Rosenbrock methods](wikipedia://en/20353055) — derivative-free method, similar to Nelder–Mead but with guaranteed convergence
  - [Augmented Lagrangian method](wikipedia://en/30898832) — replaces constrained problems by unconstrained problems with a term added to the objective function
  - [Ternary search](https://en.wikipedia.org/wiki/Ternary_search)
  - [Tabu search](https://en.wikipedia.org/wiki/Tabu_search)
  - [Guided Local Search](https://en.wikipedia.org/wiki/Guided_Local_Search) — modification of search algorithms which builds up penalties during a search
  - Reactive search optimization (RSO) — the algorithm adapts its parameters automatically
  - [MM algorithm](wikipedia://en/34073448) — majorize-minimization, a wide framework of methods
  - [Least absolute deviations](wikipedia://en/19048902)
    - [Expectation–maximization algorithm](wikipedia://en/470752)
      - [Ordered subset expectation maximization](wikipedia://en/650972)
  - [Nearest neighbor search](https://en.wikipedia.org/wiki/Nearest_neighbor_search)
  - [Space mapping](https://en.wikipedia.org/wiki/Space_mapping) — uses "coarse" (ideal or low-fidelity) and "fine" (practical or high-fidelity) models

### Grids and meshes {#Grids_and_meshes}

::: {#o336 .entry cue=list-entry name="Grid classification"}

- [Grid classification](wikipedia://en/37792627) / [Types of mesh](wikipedia://en/37667343):

:::

  - [Polygon mesh](https://en.wikipedia.org/wiki/Polygon_mesh) — consists of polygons in 2D or 3D
  - [Triangle mesh](https://en.wikipedia.org/wiki/Triangle_mesh) — consists of triangles in 2D or 3D
    - [Triangulation (geometry)](wikipedia://en/1440970) — subdivision of given region in triangles, or higher-dimensional analogue
    - [Nonobtuse mesh](https://en.wikipedia.org/wiki/Nonobtuse_mesh) — mesh in which all angles are less than or equal to 90°
    - [Point-set triangulation](wikipedia://en/1081285) — triangle mesh such that given set of point are all a vertex of a triangle
    - [Polygon triangulation](wikipedia://en/679384) — triangle mesh inside a polygon
    - [Delaunay triangulation](wikipedia://en/8864) — triangulation such that no vertex is inside the circumcentre of a triangle
    - [Constrained Delaunay triangulation](https://en.wikipedia.org/wiki/Constrained_Delaunay_triangulation) — generalization of the Delaunay triangulation that forces certain required segments into the triangulation
    - [Pitteway triangulation](wikipedia://en/11252689) — for any point, triangle containing it has nearest neighbour of the point as a vertex
    - [Minimum-weight triangulation](wikipedia://en/22231180) — triangulation of minimum total edge length
    - [Kinetic triangulation](https://en.wikipedia.org/wiki/Kinetic_triangulation) — a triangulation that moves over time
    - [Triangulated irregular network](https://en.wikipedia.org/wiki/Triangulated_irregular_network)
    - [Quasi-triangulation](wikipedia://en/36587147) — subdivision into simplices, where vertices are not points but arbitrary sloped line segments
  - [Volume mesh](https://en.wikipedia.org/wiki/Volume_mesh) — consists of three-dimensional shapes
  - [Regular grid](wikipedia://en/3771917) — consists of congruent parallelograms, or higher-dimensional analogue
  - [Unstructured grid](wikipedia://en/3772072)
  - [Geodesic grid](https://en.wikipedia.org/wiki/Geodesic_grid) — isotropic grid on a sphere

::: {#o337 .entry cue=list-entry name="Mesh generation"}

- [Mesh generation](wikipedia://en/3050716)

:::

  - [Image-based meshing](https://en.wikipedia.org/wiki/Image-based_meshing) — automatic procedure of generating meshes from 3D image data
  - [Marching cubes](https://en.wikipedia.org/wiki/Marching_cubes) — extracts a polygon mesh from a scalar field
  - [Parallel mesh generation](wikipedia://en/13089880)
  - [Ruppert's algorithm](https://en.wikipedia.org/wiki/Ruppert's_algorithm) — creates quality Delauney triangularization from piecewise linear data

- Improving an existing mesh:
  - [Chew's second algorithm](https://en.wikipedia.org/wiki/Chew's_second_algorithm) — improves Delauney triangularization by refining poor-quality triangles
  - [Laplacian smoothing](wikipedia://en/8722051) — improves polynomial meshes by moving the vertices

::: {#o340 .entry cue=list-entry name="Jump-and-Walk algorithm"}

- [Jump-and-Walk algorithm](wikipedia://en/13830115) — for finding triangle in a mesh containing a given point
