# Kempner function

*Image: SmarandacheFunction.PNG.* Graph of the Kempner function

::: {#o1 .subject cue=lead name="Kempner function"}

In [number theory](wikipedia://en/21527), the **Kempner function** $S(n)$[^o2] is defined for a given [positive integer](https://en.wikipedia.org/wiki/Positive_integer) $n$ to be the smallest number $s$ such that $n$ [divides](https://en.wikipedia.org/wiki/Divides) the [factorial](wikipedia://en/10606) $s!$. For example, the number $8$ does not divide $1!$, $2!$, or $3!$, but does divide $4!$, so $S(8)=4$.

:::

This function has a highly irregular [growth rate](wikipedia://en/641995): it [grows linearly](wikipedia://en/152111) on the [prime numbers](wikipedia://en/23666) but only grows [sublogarithmically](wikipedia://en/4001300) at the factorial numbers.

## History {#History}

This function was first considered by [François Édouard Anatole Lucas](https://en.wikipedia.org/wiki/François_Édouard_Anatole_Lucas) in 1883,[^o4] followed by [Joseph Jean Baptiste Neuberg](wikipedia://en/19178914) in 1887.[^o5] In 1918, [A. J. Kempner](wikipedia://en/36825600) gave an algorithm for computing $S(n)$ without trials.[^o6]

The Kempner function is also sometimes called the **Smarandache function** following Florentin Smarandache's rediscovery of the function in 1980.[^o7]

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Since $n$ divides $n!$, $S(n)$ is always at most $n$. A number $n>4$ is [prime](wikipedia://en/23666) if and only if $S(n)=n$.[^o10] That is, the numbers $n$ for which $S(n)$ is as large as possible relative to $n$ are the primes. In the other direction, the numbers for which $S(n)$ is as small as possible are the factorials: $S(k!)=k$, for all $k\ge 1$.

$S(n)$ is the smallest possible [degree](wikipedia://en/5930652) of a [monic polynomial](wikipedia://en/314730) with integer coefficients, whose values over the integers are all divisible by $n$.[^o2] For instance, the fact that $S(6)=3$ means that there is a [cubic polynomial](https://en.wikipedia.org/wiki/Cubic_polynomial) whose values are all zero [modulo](wikipedia://en/20087) 6, for instance the polynomial

$$x(x-1)(x-2)=x^3-3x^2+2x,$$

but that all quadratic or linear polynomials (with leading coefficient one) are nonzero modulo 6 at some integers.

In one of the advanced problems in *[The American Mathematical Monthly](wikipedia://en/1179483)*, set in 1991 and solved in 1994, [Paul Erdős](wikipedia://en/601284) pointed out that the function $S(n)$ coincides with the largest [prime factor](https://en.wikipedia.org/wiki/Prime_factor) of $n$ for "almost all" $n$ (in the sense that the [asymptotic density](https://en.wikipedia.org/wiki/Asymptotic_density) of the set of exceptions is zero).[^o11]

:::

## Computational complexity {#Computational_complexity}

The Kempner function $S(n)$ of an arbitrary number $n$ is the maximum, over the [prime powers](wikipedia://en/1630483) $p^e$ dividing $n$, of $S(p^e)$.[^o6] When $n$ is itself a prime power $p^e$, its Kempner function may be found in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time) by sequentially scanning the multiples of $p$ until finding the first one whose factorial contains enough multiples of $p$. The same [algorithm](wikipedia://en/775) can be extended to any $n$ whose prime factorization is already known, by applying it separately to each prime power in the factorization and choosing the one that leads to the largest value.

For a number of the form $n=px$, where $p$ is prime and $x<p$, the Kempner function of $n$ is $p$.[^o6] It follows from this that computing the Kempner function of a [semiprime](wikipedia://en/339542) (a product of two primes) is computationally equivalent to finding its [prime factorization](https://en.wikipedia.org/wiki/Prime_factorization), believed to be a difficult problem. More generally, whenever $n$ is [composite](wikipedia://en/82289), the [greatest common divisor](wikipedia://en/12354) of $S(n)$ and $n$ will necessarily be a nontrivial [divisor](wikipedia://en/49492) of $n$, allowing $n$ to be factored by repeated evaluations of the Kempner function. Therefore, computing the Kempner function can in general be no easier than factoring composite numbers.
