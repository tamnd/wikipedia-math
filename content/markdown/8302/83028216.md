# Cubical type theory

::: {#o1 .subject cue=lead name="Cubical type theory"}

In [mathematical logic](wikipedia://en/19636) and [theoretical computer science](wikipedia://en/323392), **cubical type theory** is a flavor of [type theory](wikipedia://en/40282) which gives a computational interpretation to [univalent foundations](wikipedia://en/44554214) (also known as [homotopy type theory](wikipedia://en/33974223)).

:::

In cubical type theory, [function extensionality](wikipedia://en/294056#Extensionality_principles) and [univalence](https://en.wikipedia.org/wiki/Univalence_axiom) are not postulated as axioms, but rather can be proved as theorems. Unlike traditional homotopy type theory, where the postulate of univalence creates stuck closed terms, cubical type theory has the [canonicity](https://en.wikipedia.org/wiki/Canonicity_%28type_theory%29) property. It also enjoys [normalization](wikipedia://en/5085531#Definitions).

This is achieved by adding geometric primitives to the core rules of the type theory, including a formal interval object, interval variables, and operations for filling partial cubes.

The earliest cubical type theory is CCHM cubical type theory, named after its inventors Cohen, [Coquand](wikipedia://en/31842262), Huber and Mörtberg. Later variants include Cartesian cubical type theory.

Cubical type theories have semantics in various types of [cubical sets](wikipedia://en/46250924).

The [Agda](https://en.wikipedia.org/wiki/Agda_%28programming_language%29) proof assistant includes an implementation of cubical type theory.
