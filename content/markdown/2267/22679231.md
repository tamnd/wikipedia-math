# Semigroup with involution

::: {#o1 .subject cue=lead name="Semigroup with involution"}

In [mathematics](wikipedia://en/18831), particularly in [abstract algebra](wikipedia://en/19616384), a **semigroup with involution*,*** or a **\*-semigroup**, is a [semigroup](wikipedia://en/27799) equipped with an [involutive](wikipedia://en/293450) [anti-automorphism](https://en.wikipedia.org/wiki/Anti-automorphism), which—roughly speaking—brings it closer to a [group](wikipedia://en/19447) because this involution, considered as [unary operator](https://en.wikipedia.org/wiki/Unary_operator), exhibits certain fundamental properties of the operation of taking the inverse in a group:

:::

- [Uniqueness](https://en.wikipedia.org/wiki/Uniqueness_%28mathematics%29)
- Double application "cancelling itself out".
- The same interaction law with the binary operation as in the case of the group inverse.

It is thus not a surprise that any group is a semigroup with involution. However, there are significant natural examples of semigroups with involution that are not groups.

An example from [linear algebra](wikipedia://en/18422) is a set of real-valued n-by-n square matrices with the matrix-transpose as the involution. The [map](wikipedia://en/516931) which sends a matrix to its [transpose](wikipedia://en/173844) is an involution because the transpose is well defined for any matrix and obeys the law (*AB*)<sup>T</sup> = *B*<sup>T</sup>*A*<sup>T</sup>, which has the same form of interaction with multiplication as taking inverses has in the [general linear group](wikipedia://en/113564) (which is a subgroup of the full linear monoid). However, for an arbitrary matrix, *AA*<sup>T</sup> does not equal the identity element (namely the [diagonal matrix](wikipedia://en/174080)). Another example, coming from [formal language](wikipedia://en/10939) theory, is the [free semigroup](https://en.wikipedia.org/wiki/Free_semigroup) generated by a [nonempty set](https://en.wikipedia.org/wiki/Nonempty_set) (an [alphabet](https://en.wikipedia.org/wiki/Alphabet_%28computer_science%29)), with string [concatenation](wikipedia://en/64474) as the binary operation, and the involution being the map which [reverses](wikipedia://en/27701#Reversal) the [linear order](https://en.wikipedia.org/wiki/Linear_order) of the letters in a string. A third example, from basic [set theory](wikipedia://en/27553), is the set of all [binary relations](wikipedia://en/3931) between a set and itself, with the involution being the [converse relation](wikipedia://en/3941020), and the multiplication given by the usual [composition of relations](wikipedia://en/7472170).

Semigroups with involution appeared explicitly named in a 1953 paper of [Viktor Wagner](https://en.wikipedia.org/wiki/Viktor_Wagner) (in Russian) as result of his attempt to bridge the theory of semigroups with that of [semiheaps](https://en.wikipedia.org/wiki/Semiheap).[^o2]

::: {#o4 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Let *S* be a [semigroup](wikipedia://en/27799) with its binary operation written multiplicatively. An involution in *S* is a [unary operation](wikipedia://en/161006) \* on *S* (or, a transformation \* : *S* → *S*, *x* ↦ *x*\*) satisfying the following conditions:

1. For all *x* in *S*, (*x*\*)\* = *x*.
1. For all *x*, *y* in *S* we have (*xy*)\* = *y*\**x*\*.

The semigroup *S* with the involution \* is called a semigroup with involution.

Semigroups that satisfy only the first of these axioms belong to the larger class of [U-semigroups](https://en.wikipedia.org/wiki/U-semigroup).

In some applications, the second of these axioms has been called [antidistributive](https://en.wikipedia.org/wiki/Antidistributive).[^o5] Regarding the natural philosophy of this axiom, [H.S.M. Coxeter](https://en.wikipedia.org/wiki/Harold_Scott_MacDonald_Coxeter) remarked that it "becomes clear when we think of \[x\] and \[y\] as the operations of putting on our socks and shoes, respectively."[^o6]

:::

## Examples {#Examples}

1. If *S* is a [commutative](https://en.wikipedia.org/wiki/Commutative) semigroup then the [identity map](wikipedia://en/15069) of S is an involution.
1. If *S* is a [group](wikipedia://en/19447) then the inversion map \* : *S* → *S* defined by *x*\* = *x*<sup>−1</sup> is an involution. Furthermore, on an [abelian group](wikipedia://en/2974) both this map and the one from the previous example are involutions satisfying the axioms of semigroup with involution.[^o9]
1. If *S* is an [inverse semigroup](wikipedia://en/1757814) then the inversion map is an involution which leaves the [idempotents](https://en.wikipedia.org/wiki/Idempotent) [invariant](wikipedia://en/1126638). As noted in the previous example, the inversion map is not necessarily the only map with this property in an inverse semigroup. There may well be other involutions that leave all idempotents invariant; for example the identity map on a commutative regular, hence inverse, semigroup, in particular, an abelian group. A [regular semigroup](wikipedia://en/6797677) is an [inverse semigroup](wikipedia://en/1757814) [if and only if](wikipedia://en/14922) it admits an involution under which each idempotent is an invariant.[^o10]
1. Underlying every [C\*-algebra](wikipedia://en/7184) is a \*-semigroup. An important [instance](wikipedia://en/7184#Finite-dimensional_C*-algebras) is the algebra *M*<sub>*n*</sub>(**C**) of *n*-by-*n* [matrices](wikipedia://en/20556859) over **[C](wikipedia://en/5826)**, with the [conjugate transpose](wikipedia://en/217548) as involution.
1. If *X* is a set, the set of all [binary relations](wikipedia://en/3931) on *X* is a \*-semigroup with the \* given by the [converse relation](wikipedia://en/3941020), and the multiplication given by the usual [composition of relations](wikipedia://en/7472170). This is an example of a \*-semigroup which is not a regular semigroup.
1. If X is a set, then the set of all finite sequences (or [strings](wikipedia://en/27701)) of members of X forms a [free monoid](wikipedia://en/523166) under the operation of concatenation of sequences, with sequence reversal as an involution.
1. A [rectangular band](https://en.wikipedia.org/wiki/Rectangular_band) on a Cartesian product of a set *A* with itself, i.e. with elements from *A* × *A*, with the semigroup product defined as (*a*, *b*)(*c*, *d*) = (*a*, *d*), with the involution being the order reversal of the elements of a pair (*a*, *b*)\* = (*b*, *a*). This semigroup is also a [regular semigroup](wikipedia://en/6797677), as all bands are.[^o11]

:::

## Basic concepts and properties {#Basic_concepts_and_properties}

An element *x* of a semigroup with involution is sometimes called *hermitian* (by analogy with a [Hermitian matrix](wikipedia://en/189682)) when it is left invariant by the involution, meaning *x*\* = *x*. Elements of the form *xx*\* or *x*\**x* are always hermitian, and so are all powers of a hermitian element. As noted in the examples section, a semigroup *S* is an [inverse semigroup](wikipedia://en/1757814) if and only if *S* is a [regular semigroup](wikipedia://en/6797677) and admits an involution such that every idempotent is hermitian.[^o13]

Certain basic concepts may be defined on \*-semigroups in a way that parallels the notions stemming from a [regular element in a semigroup](wikipedia://en/6797677). A *partial isometry* is an element *s* such that *ss*\**s* = *s*; the set of partial isometries of a semigroup *S* is usually abbreviated PI(*S*).[^o14] A *projection* is an idempotent element *e* that is also hermitian, meaning that *ee* = *e* and *e*\* = *e*. Every projection is a partial isometry, and for every partial isometry *s*, *s*\**s* and *ss*\* are projections. If *e* and *f* are projections, then *e* = *ef* if and only if *e* = *fe*.[^o15]

Partial isometries can be [partially ordered](https://en.wikipedia.org/wiki/Partial_order) by *s* ≤ *t* defined as holding whenever *s* = *ss*\**t* and *ss*\* = *ss*\**tt*\*.[^o15] Equivalently, *s* ≤ *t* if and only if *s* = *et* and *e* = *ett*\* for some projection *e*.[^o15] In a \*-semigroup, PI(*S*) is an [ordered groupoid](https://en.wikipedia.org/wiki/Ordered_groupoid) with the [partial product](wikipedia://en/43662522) given by *s*⋅*t* = *st* if *s*\**s* = *tt*\*.[^o16]

::: {#o18 .example cue=heading name="Examples"}

### Examples {#Examples}

In terms of examples for these notions, in the \*-semigroup of binary relations on a set, the partial isometries are the relations that are [difunctional](https://en.wikipedia.org/wiki/Difunctional). The projections in this \*-semigroup are the [partial equivalence relations](wikipedia://en/3450320).[^o19][^o20]

The [partial isometries](wikipedia://en/1348079) in a C\*-algebra are exactly those defined in this section. In the case of *M*<sub>*n*</sub>(**C**) more can be said. If *E* and *F* are projections, then *E* ≤ *F* if and only if [im](wikipedia://en/579311)*E* ⊆ im*F*. For any two projection, if *E* ∩ *F* = *V*, then the unique projection *J* with image *V* and kernel the [orthogonal complement](wikipedia://en/1058833) of *V* is the meet of *E* and *F*. Since projections form a meet-[semilattice](wikipedia://en/755647), the partial isometries on *M*<sub>*n*</sub>(**C**) form an inverse semigroup with the product $A(A^*A\wedge BB^*)B$.[^o21]

Another simple example of these notions appears in the next section.

:::

## Notions of regularity {#Notions_of_regularity}

There are two related, but not identical notions of regularity in \*-semigroups. They were introduced nearly simultaneously by Nordahl & Scheiblich (1978) and respectively Drazin (1979).[^o23]

### Regular \*-semigroups (Nordahl & Scheiblich) {#Regular_*-semigroups_(Nordahl_&_Scheiblich)}

As mentioned in the previous examples, [inverse semigroups](wikipedia://en/1757814) are a subclass of \*-semigroups. It is also textbook knowledge that an inverse semigroup can be characterized as a regular semigroup in which any two idempotents commute. In 1963, [Boris M. Schein](https://en.wikipedia.org/wiki/Boris_M._Schein) showed that the following two axioms provide an analogous characterization of inverse semigroups as a [subvariety](wikipedia://en/1021753) of \*-semigroups:

- $$x = xx*x$$
- $$(xx*)(x*x) = (x*x)(xx*)$$

The first of these looks like the definition of a regular element, but is actually in terms of the involution. Likewise, the second axiom appears to be describing the commutation of two idempotents. It is known however that regular semigroups do not form a variety because their class does not contain [free objects](wikipedia://en/333835) (a result established by [D. B. McAlister](https://en.wikipedia.org/wiki/D._B._McAlister) in 1968). This line of reasoning motivated Nordahl and Scheiblich to begin in 1977 the study of the (variety of) \*-semigroups that satisfy only the first these two axioms; because of the similarity in form with the property defining regular semigroups, they named this variety regular \*-semigroups.

It is a simple calculation to establish that a regular \*-semigroup is also a regular semigroup because *x*\* turns out to be an inverse of *x*. The rectangular band from Example 7 is a regular \*-semigroup that is not an inverse semigroup.[^o11] It is also easy to verify that in a regular \*-semigroup the product of any two projections is an idempotent.[^o25] In the aforementioned rectangular band example, the projections are elements of the form $(x, x)$ and (like all elements of a band) are idempotent. However, two different projections in this band need not commute, nor is their product necessarily a projection since $(a, a)(b, b) = (a, b)$.

Semigroups that satisfy only $x** = x = xx*x$ (but not necessarily the antidistributivity of \* over multiplication) have also been studied under the name of [I-semigroups](https://en.wikipedia.org/wiki/I-semigroup).

#### P-systems {#P-systems}

The problem of characterizing when a regular semigroup is a regular \*-semigroup (in the sense of Nordahl & Scheiblich) can be addressed by defining a **P-system**. For the semigroup $S$, let $E(S)$ denote the set of idempotents, and let $V(a)$ denote the inverses of $a$. A P-system $F(S)$ is then a subset of $E(S)$ which satisfies the following axioms:

1. For any $a$ in $S$, there exists a unique $a^{\circ}$ in $V(a)$ such that $aa^{\circ}$ and $a^{\circ}a$ are in $F(S)$
1. For any $a$ in $S$, and $b$ in $F(S)$, *a°ba* is in F(S), where ° is the well-defined operation from the previous axiom
1. For any $a$, $b$ in $F(S)$, $ab$ is in $E(S)$; note: not necessarily in $F(S)$

A regular semigroup $S$ is a \*-regular semigroup, if and only if it has a p-system $F(S)$.[^o27] In this case $F(S)$ is the set of projections of $S$ with respect to the operation $^{\circ}$ defined by $F(S)$. In an [inverse semigroup](wikipedia://en/1757814) the entire semilattice of idempotents is a P-system. Also, if a regular semigroup $S$ has a P-system that is multiplicatively closed (i.e. subsemigroup), then $S$ is an inverse semigroup. Thus, a P-system may be regarded as a generalization of the semilattice of idempotents of an inverse semigroup.

::: {#o29 .pointer-item cue=pointer name="*-regular semigroup"}

### \*-regular semigroups (Drazin) {#*-regular_semigroups_(Drazin)}

A semigroup *S* with an involution \* is called a **\*-regular semigroup** (in the sense of Drazin) if for every *x* in *S*, *x*\* is *H*-equivalent to some inverse of *x*, where *H* is the [Green's relation](wikipedia://en/1192012) *H*. This defining property can be formulated in several equivalent ways. Another is to say that every [*L*-class](wikipedia://en/1192012#The_L.2C_R.2C_and_J_relations) contains a projection. An axiomatic definition is the condition that for every *x* in *S* there exists an element *x*′ such that *x*′*xx*′ = *x*′, *xx*′*x* = *x*, (*xx*′)\* = *xx*′, (*x*′*x*)\* = *x*′*x*. [Michael P. Drazin](wikipedia://en/13119440) first proved that given *x*, the element *x*′ satisfying these axioms is unique. It is called the Moore–Penrose inverse of *x*. This agrees with the classical definition of the [Moore–Penrose inverse](wikipedia://en/331258) of a square matrix.

One motivation for studying these semigroups is that they allow generalizing the Moore–Penrose inverse's properties from $\mathbb{R}$ and $\mathbb{C}$ to more general sets.

In the [multiplicative](wikipedia://en/125280) semigroup *M*<sub>*n*</sub>(*C*) of square matrices of order *n*, the map which assigns a matrix *A* to its [Hermitian conjugate](https://en.wikipedia.org/wiki/Hermitian_conjugate) *A*\* is an involution. The semigroup *M*<sub>*n*</sub>(*C*) is a \*-regular semigroup with this involution. The Moore–Penrose inverse of A in this \*-regular semigroup is the classical Moore–Penrose inverse of *A*.

## Free semigroup with involution {#Free_semigroup_with_involution}

As with all varieties, the [category](wikipedia://en/5869) of semigroups with involution admits [free objects](wikipedia://en/333835). The construction of a free semigroup (or monoid) with involution is based on that of a [free semigroup](https://en.wikipedia.org/wiki/Free_semigroup) (and respectively that of a free monoid). Moreover, the construction of a [free group](wikipedia://en/59735) can easily be derived by refining the construction of a free monoid with involution.[^o32]

The [generators](wikipedia://en/3171371) of a free semigroup with involution are the elements of the union of two ([equinumerous](https://en.wikipedia.org/wiki/Equinumerous)) [disjoint sets](wikipedia://en/39359) in [bijective correspondence](wikipedia://en/3942): $Y=X\sqcup X^\dagger$. (Here the notation $\sqcup$ emphasizes that the union is actually a [disjoint union](wikipedia://en/188946).) In the case were the two sets are finite, their union *Y* is sometimes called an *[alphabet](https://en.wikipedia.org/wiki/Alphabet_%28computer_science%29) with involution*[^o33] or a *symmetric alphabet*.[^o34] Let $\theta:X\rightarrow X^\dagger$ be a bijection; $\theta$ is naturally [extended](wikipedia://en/185427#Restrictions_and_extensions) to a bijection ${ }\dagger: Y \to Y$ essentially by taking the disjoint union of $\theta$ (as a set) with its [inverse](wikipedia://en/14907), or in [piecewise](https://en.wikipedia.org/wiki/Piecewise) notation:[^o35]

$$y^\dagger = \begin{cases} \theta(y) & \text{if } y \in X \\ \theta^{-1}(y) & \text{if } y \in X^\dagger \end{cases}$$

Now construct $Y^+\,$ as the [free semigroup](https://en.wikipedia.org/wiki/Free_semigroup) on $Y\,$ in the usual way with the binary (semigroup) operation on $Y^+\,$ being [concatenation](wikipedia://en/64474):

$$w = w_1w_2 \cdots w_k \in Y^+$$

for some letters $w_i\in Y.$

The bijection $\dagger$ on $Y$ is then extended as a bijection ${ }^\dagger:Y^+\rightarrow Y^+$ defined as the string reversal of the elements of $Y^+\,$ that consist of more than one letter:[^o33][^o35]

$$w^\dagger=w_k^\dagger w_{k-1}^\dagger \cdots w_{2}^\dagger w_{1}^\dagger.$$

This map is an involution on the semigroup $Y^+\,$. Thus, the semigroup $(X\sqcup X^\dagger)^+$ with the map ${ }^\dagger\,$ is a semigroup with involution, called a **free semigroup with involution** on *X*.[^o36] (The irrelevance of the concrete identity of $X^\dagger$ and of the bijection $\theta$ in this choice of terminology is explained below in terms of the universal property of the construction.) Note that unlike in Example 6, the involution *of every letter* is a distinct element in an alphabet with involution, and consequently the same observation extends to a free semigroup with involution.

If in the above construction instead of $Y^+\,$ we use the [free monoid](wikipedia://en/523166) $Y^*=Y^+\cup\{\varepsilon\}$, which is just the free semigroup extended with the [empty word](https://en.wikipedia.org/wiki/Empty_word) $\varepsilon\,$ (which is the [identity element](wikipedia://en/14962) of the [monoid](wikipedia://en/19652) $Y^*\,$), and suitably extend the involution with $\varepsilon^\dagger = \varepsilon$, we obtain a **free monoid with involution**.[^o35]

The construction above is actually the only way to extend a given map $\theta\,$ from $X\,$ to $X^\dagger\,$, to an involution on $Y^+$ (and likewise on $Y^*\,$). The qualifier "free" for these constructions is justified in the usual sense that they are [universal constructions](wikipedia://en/45200). In the case of the free semigroup with involution, given an arbitrary semigroup with involution $S\,$ and a map $\Phi:X\rightarrow S$, then a [semigroup homomorphism](https://en.wikipedia.org/wiki/Semigroup_homomorphism) $\overline\Phi:(X\sqcup X^\dagger)^+\rightarrow S$ exists such that $\Phi = \iota \circ \overline\Phi$, where $\iota : X \rightarrow (X\sqcup X^\dagger)^+$ is the [inclusion map](wikipedia://en/492516) and [composition of functions](https://en.wikipedia.org/wiki/Composition_of_functions) is taken in [diagram order](wikipedia://en/195947#Alternative_notations).[^o36] The construction of $(X\sqcup X^\dagger)^+$ as a semigroup with involution is unique up to [isomorphism](wikipedia://en/14828). An analogous argument holds for the free monoid with involution in terms of [monoid homomorphisms](https://en.wikipedia.org/wiki/Monoid_homomorphism) and the uniqueness up to isomorphism of the construction of $(X\sqcup X^\dagger)^*$ as a monoid with involution.

The construction of a [free group](wikipedia://en/59735) is not very far off from that of a free monoid with involution. The additional ingredient needed is to define a notion of [reduced word](https://en.wikipedia.org/wiki/Reduced_word) and a [rewriting](wikipedia://en/415847) rule for producing such words simply by deleting any adjacent pairs of letter of the form $xx^\dagger$ or $x^\dagger x$. It can be shown than the order of rewriting (deleting) such pairs does not matter, i.e. any order of deletions produces the same result.[^o32] (Otherwise put, these rules define a [confluent](wikipedia://en/3755377) rewriting system.) Equivalently, a free group is constructed from a free monoid with involution by taking the [quotient](wikipedia://en/310953) of the latter by the [congruence](wikipedia://en/48167) $\{ (yy^\dagger, \varepsilon) : y\in Y\}$, which is sometimes called the **Dyck congruence**—in a certain sense it generalizes [Dyck language](wikipedia://en/1852078) to multiple kinds of "parentheses" However simplification in the Dyck congruence takes place regardless of order. For example, if ")" is the inverse of "(", then $()=)(=\varepsilon$; the one-sided congruence that appears in the Dyck language proper $\{ (xx^\dagger, \varepsilon) : x\in X\}$, which instantiates only to $()=\varepsilon$ is (perhaps confusingly) called the **Shamir congruence**. The quotient of a free monoid with involution by the Shamir congruence is not a group, but a monoid ; nevertheless it has been called the **free half group** by its first discoverer—[Eli Shamir](https://en.wikipedia.org/wiki/Eli_Shamir)—although more recently it has been called the **involutive monoid** generated by *X*.[^o34][^o37] (This latter choice of terminology conflicts however with the use of "involutive" to denote any semigroup with involution—a practice also encountered in the literature.[^o38][^o39])

## Baer \*-semigroups {#Baer_*-semigroups}

A Baer \*-semigroup is a \*-semigroup with (two-sided) zero in which the right annihilator of every element coincides with the [right ideal](https://en.wikipedia.org/wiki/Semigroup_ideal) of some projection; this property is expressed formally as: for all *x* ∈ *S* there exists a projection *e* such that

{ *y* ∈ *S* | *xy* = 0 } = *eS*.[^o39]

The projection *e* is in fact uniquely determined by *x*.[^o39]

More recently, Baer \*-semigroups have been also called **Foulis semigroups**, after [David James Foulis](https://en.wikipedia.org/wiki/David_James_Foulis) who studied them in depth.[^o45][^o42]

### Examples and applications {#Examples_and_applications}

The set of all binary relations on a set (from example 5) is a Baer \*-semigroup.[^o44]

Baer \*-semigroups are also encountered in [quantum mechanics](wikipedia://en/25202),[^o39] in particular as the multiplicative semigroups of [Baer \*-rings](https://en.wikipedia.org/wiki/Baer_*-ring).

If *H* is a [Hilbert space](wikipedia://en/20598932), then the multiplicative semigroup of all [bounded operators](wikipedia://en/455961) on *H* is a Baer \*-semigroup. The involution in this case maps an operator to its [adjoint](https://en.wikipedia.org/wiki/Adjoint_operator).[^o44]

Baer \*-semigroup allow the [coordinatization](https://en.wikipedia.org/wiki/Coordinatization) of [orthomodular lattices](https://en.wikipedia.org/wiki/Orthomodular_lattice).[^o45]
