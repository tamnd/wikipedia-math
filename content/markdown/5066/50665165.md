# Dupin hypersurface

::: {#o1 .subject cue=lead name="Dupin hypersurface"}

In [differential geometry](wikipedia://en/8625), a **Dupin hypersurface** is a [submanifold](wikipedia://en/525095) in a [space form](wikipedia://en/1087009), whose [principal curvatures](wikipedia://en/2072472) have globally constant multiplicities.[^o2]

:::

::: {#o4 .application cue=heading name="Application"}

## Application {#Application}

A [hypersurface](wikipedia://en/525101) is called a Dupin hypersurface if the multiplicity of each principal curvature is constant on hypersurface and each principal curvature is constant along its associated principal directions.[^o5] All proper Dupin submanifolds arise as focal submanifolds of proper Dupin hypersurfaces.[^o6]

:::
