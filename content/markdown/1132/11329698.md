# Vitale's random Brunn–Minkowski inequality

::: {#o1 .subject cue=lead name="Vitale's random Brunn–Minkowski inequality"}

In [mathematics](wikipedia://en/18831), **Vitale's random Brunn–Minkowski inequality** is a [theorem](wikipedia://en/30977) due to [Richard Vitale](https://en.wikipedia.org/wiki/Richard_Vitale) that generalizes the classical [Brunn–Minkowski inequality](https://en.wikipedia.org/wiki/Brunn–Minkowski_inequality) for [compact subsets](wikipedia://en/6042) of *n*-[dimensional](wikipedia://en/8398) [Euclidean space](wikipedia://en/9697) **R**<sup>*n*</sup> to [random compact sets](wikipedia://en/5308916).

:::

::: {#o3 .statement cue=named-heading name="Statement of the inequality"}

## Statement of the inequality {#Statement_of_the_inequality}

Let *X* be a random compact set in **R**<sup>*n*</sup>; that is, a [Borel](https://en.wikipedia.org/wiki/Borel_sigma_algebra)–[measurable function](wikipedia://en/44055) from some [probability space](wikipedia://en/43325) (Ω, Σ, Pr) to the space of [non-empty](https://en.wikipedia.org/wiki/Non-empty), [compact](wikipedia://en/6042) [subsets](wikipedia://en/27631) of **R**<sup>*n*</sup> equipped with the [Hausdorff metric](https://en.wikipedia.org/wiki/Hausdorff_metric). A [random vector](https://en.wikipedia.org/wiki/Random_vector) *V* : Ω → **R**<sup>*n*</sup> is called a selection of *X* if Pr(*V* ∈ *X*) = 1. If *K* is a non-empty, compact subset of **R**<sup>*n*</sup>, let

$$\| K \| = \max \left\{ \left. \| v \|_{\mathbb{R}^{n}} \right| v \in K \right\}$$

and define the set-valued [expectation](wikipedia://en/9653) E\[*X*\] of *X* to be

$$\mathrm{E} [X] = \{ \mathrm{E} [V] | V \mbox{ is a selection of } X \mbox{ and } \mathrm{E} \| V \| < + \infty \}.$$

Note that E\[*X*\] is a subset of **R**<sup>*n*</sup>. In this notation, Vitale's random Brunn–Minkowski inequality is that, for any random compact set *X* with $E[\|X\|]<+\infty$,

$$\left( \mathrm{vol}_n \left( \mathrm{E} [X] \right) \right)^{1/n} \geq \mathrm{E} \left[ \mathrm{vol}_n (X)^{1/n} \right],$$

where "$vol_n$" denotes *n*-dimensional [Lebesgue measure](wikipedia://en/18198).

:::

::: {#o5 .statement cue=named-heading name="Relationship to the Brunn–Minkowski inequality"}

## Relationship to the Brunn–Minkowski inequality {#Relationship_to_the_Brunn–Minkowski_inequality}

If *X* takes the values (non-empty, compact sets) *K* and *L* with probabilities 1 − *λ* and *λ* respectively, then Vitale's random Brunn–Minkowski inequality is simply the original Brunn–Minkowski inequality for compact sets.

:::
