# Martin's axiom

::: {#o1 .subject cue=lead name="Martin's axiom"}

In the [mathematical](https://en.wikipedia.org/wiki/Mathematical) field of [set theory](wikipedia://en/27553), **Martin's axiom**, introduced by [Donald A. Martin](wikipedia://en/2270985) and [Robert M. Solovay](wikipedia://en/3160110), is a statement that is independent of the usual axioms of [ZFC set theory](https://en.wikipedia.org/wiki/ZFC_set_theory). It is implied by the [continuum hypothesis](wikipedia://en/5705), but it is consistent with ZFC and the negation of the continuum hypothesis.

:::

Informally, it says that all cardinals less than the [cardinality of the continuum](wikipedia://en/1574901), $\mathfrak{c}$, behave roughly like $\aleph_0$. The intuition behind this can be understood by studying the proof of the [Rasiowa–Sikorski lemma](wikipedia://en/30864999). It is a principle that is used to control certain [forcing](wikipedia://en/152205) arguments.

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

For a cardinal number $\kappa$, define the following statement:

**MA(*κ*)**

For any [partial order](https://en.wikipedia.org/wiki/Partial_order) *P* satisfying the [countable chain condition](wikipedia://en/1550771) (hereafter ccc) and any set *D* = {*D*<sub>*i*</sub>}<sub>*i*∈*I*</sub> of dense subsets of *P* such that *\|D|* ≤ *κ*, there is a [filter](wikipedia://en/19719) *F* on *P* such that *F* ∩ *D*<sub>*i*</sub> is non-[empty](wikipedia://en/9566) for every *D*<sub>*i*</sub> ∈ *D*.

In this context, a set *D* is called dense if every element of *P* has a lower bound in *D*. For application of ccc, an antichain is a subset *A* of *P* such that any two distinct members of *A* are incompatible (two elements are said to be compatible if there exists a common element below both of them in the partial order). This differs from, for example, the notion of antichain in the context of [trees](wikipedia://en/704160).

MA(ℵ<sub>0</sub>) is provable in ZFC and known as the [Rasiowa–Sikorski lemma](wikipedia://en/30864999).

MA(2<sup>ℵ<sub>0</sub></sup>) is false: \[0, 1\] is a [separable](wikipedia://en/27855) [compact](wikipedia://en/6042) [Hausdorff space](wikipedia://en/13637), and so (*P*, the poset of open subsets under inclusion, is) ccc. But now consider the following two 𝔠-size sets of dense sets in *P*: no *x* ∈ \[0, 1\] is [isolated](wikipedia://en/390557), and so each *x* defines the dense subset { *S* | *x* ∉ *S* }. And each *r* ∈ (0, 1\], defines the dense subset { *S* | diam(*S*) \< *r* }. The two sets combined are also of size 𝔠, and a filter meeting both must simultaneously avoid all points of \[0, 1\] while containing sets of arbitrarily small diameter. But a filter *F* containing sets of arbitrarily small diameter must contain a point in ⋂*F* by compactness. (See also .)

Martin's axiom is then that MA($\kappa$) holds for every $\kappa$ for which it could:

**Martin's axiom (MA)**

MA($\kappa$) holds for every $\kappa<\mathfrak{c}$.

:::

## Equivalent forms of MA(*κ*) {#Equivalent_forms_of_MA(κ)}

The following statements are equivalent to MA(*κ*):

- If *X* is a compact Hausdorff [topological space](wikipedia://en/30450) that satisfies the [ccc](wikipedia://en/1550771) then *X* is not the union of $\kappa$ or fewer [nowhere dense](https://en.wikipedia.org/wiki/Nowhere_dense) subsets.
- If *P* is a non-empty upwards ccc [poset](wikipedia://en/23572) and *Y* is a set of cofinal subsets of *P* with *\|Y|* ≤ *κ* then there is an upwards-directed set *A* such that *A* meets every element of *Y*.
- Let *A* be a non-zero ccc [Boolean algebra](wikipedia://en/3959) and *F* a set of subsets of *A* with *\|F|* ≤ *κ*. Then there is a Boolean homomorphism φ: *A* → **Z**/2**Z** such that for every *X* ∈ *F*, there is either an *a* ∈ *X* with φ(*a*) = 1 or there is an upper bound *b* ∈ *X* with φ(*b*) = 0.

## Consequences {#Consequences}

Martin's axiom has a number of other interesting [combinatorial](https://en.wikipedia.org/wiki/Combinatorial), [analytic](wikipedia://en/48396) and [topological](https://en.wikipedia.org/wiki/Topological) consequences:

- The union of *κ* or fewer [null sets](wikipedia://en/21520) in an atomless σ-finite [Borel measure](wikipedia://en/4322) on a [Polish space](wikipedia://en/396622) is null. In particular, the union of *κ* or fewer subsets of **R** of [Lebesgue measure](wikipedia://en/18198) 0 also has Lebesgue measure 0.
- A compact Hausdorff space *X* with *\|X|* \< 2<sup>*κ*</sup> is [sequentially compact](wikipedia://en/6042), i.e., every sequence has a convergent subsequence.
- No non-principal [ultrafilter](wikipedia://en/31911) on **N** has a base of cardinality less than *κ*.
- Equivalently for any *x* ∈ β**N**\\**N** we have 𝜒(*x*) ≥ *κ*, where 𝜒 is the [character](https://en.wikipedia.org/wiki/Character_%28topology%29) of *x*, and so 𝜒(β**N**) ≥ *κ*.
- MA(ℵ<sub>1</sub>) implies that a product of ccc topological spaces is ccc (this in turn implies there are no [Suslin lines](https://en.wikipedia.org/wiki/Suslin_line)).
- MA + ¬CH implies that there exists a Whitehead group that is not free; [Shelah](wikipedia://en/331211) used this to show that the [Whitehead problem](wikipedia://en/212619) is independent of ZFC.

## Further development {#Further_development}

Martin's axiom can be seen as a generalization of the [Baire category theorem](wikipedia://en/55227): if the continuum hypothesis holds, one of the equivalent forms of MA above is simply the Baire category theorem restricted to c.c.c. compact spaces (a topological space is *c.c.c.* if it has no uncountable, pairwise disjoint collection of open sets).[^o9]

Various other axioms modeled after Martin's axiom are known as *forcing axioms*. These include the [proper forcing axiom](wikipedia://en/6250799) and [Martin's maximum](wikipedia://en/15978374), both of which imply Martin's axiom.
