# Propositional variable

::: {#o1 .subject cue=lead name="Propositional variable"}

In [mathematical logic](wikipedia://en/19636), a **propositional variable** (also called a **sentence letter,[^o2]** **sentential variable,** or **sentential letter**) is an input [variable](wikipedia://en/3728109) (that can either be **true** or **false**) of a [truth function](wikipedia://en/604707). Propositional variables are the basic building-blocks of [propositional formulas](wikipedia://en/1557634), used in [propositional logic](wikipedia://en/18154) and [higher-order logics](wikipedia://en/562883).

:::

::: {#o4 .application cue=heading name="Uses"}

## Uses {#Uses}

Formulas in logic are typically built up recursively from some propositional variables, some number of [logical connectives](wikipedia://en/18153), and some [logical quantifiers](https://en.wikipedia.org/wiki/Logical_quantifier). Propositional variables are the [atomic formulas](wikipedia://en/4472066) of propositional logic, and are often denoted using capital [roman letters](https://en.wikipedia.org/wiki/Latin_script) such as $P$, $Q$ and $R$.[^o5]

::: {#o6 .example cue=inline-head name="Example"}

**Example**

In a given propositional logic, a formula can be defined as follows:

- Every propositional variable is a formula.
- Given a formula *X*, the [negation](wikipedia://en/161019) *¬X* is a formula.
- Given two formulas *X* and *Y*, and a [binary connective](https://en.wikipedia.org/wiki/Binary_connective) *b* (such as the [logical conjunction](wikipedia://en/18152) ∧), the expression *(X b Y)* is a formula. (Note the parentheses.)

Through this construction, all of the formulas of propositional logic can be built up from propositional variables as a basic unit. Propositional variables should not be confused with the [metavariables](wikipedia://en/29557417), which appear in the typical axioms of [propositional calculus](https://en.wikipedia.org/wiki/Propositional_calculus); the latter effectively range over well-formed formulae, and are often denoted using lower-case greek letters such as $\alpha$, $\beta$ and $\gamma$.

:::

## Predicate logic {#Predicate_logic}

Propositional variables with no object variables such as *x* and *y* attached to predicate letters such as P*x* and *x*R*y*, having instead individual constants *a*, *b*, ... attached to predicate letters are propositional constants P*a*, *a*R*b*. These propositional constants are atomic propositions, not containing propositional operators.

The internal structure of propositional variables contains [predicate letters](https://en.wikipedia.org/wiki/Predicate_symbol) such as P and Q, in association with [bound](https://en.wikipedia.org/wiki/Bound_variable) individual variables (e.g., x, *y*), individual constants such as *a* and *b* ([singular terms](wikipedia://en/246918) from a [domain of discourse](wikipedia://en/229180) D), ultimately taking a form such as P*a*, *a*R*b*.(or with parenthesis, $P(11)$ and $R(1, 3)$).[^o8]

Propositional logic is sometimes called [zeroth-order logic](https://en.wikipedia.org/wiki/Zeroth-order_logic) due to not considering the internal structure in contrast with [first-order logic](wikipedia://en/10983) which analyzes the internal structure of the atomic sentences.
