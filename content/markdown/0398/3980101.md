# N-monoid

::: {#o1 .subject cue=lead name="N-monoid"}

In [category theory](wikipedia://en/5869), a **(strict) *n*-monoid** is an [*n*-category](https://en.wikipedia.org/wiki/N-category) with only one 0-cell. In particular, a 1-monoid is a [monoid](wikipedia://en/19652) and a 2-monoid is a [strict monoidal category](wikipedia://en/330604).

:::
