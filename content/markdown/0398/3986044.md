# Cofunction

::: {#o1 .subject cue=lead name="Cofunction"}

*Image: Sine cosine one period.svg.* [Sine](https://en.wikipedia.org/wiki/Sine) and [cosine](https://en.wikipedia.org/wiki/Cosine) are each other's cofunctions.

In [mathematics](wikipedia://en/18831), a [function](wikipedia://en/185427) *f* is **cofunction** of a function *g* if *f*(*A*) = *g*(*B*) whenever *A* and *B* are [complementary angles](https://en.wikipedia.org/wiki/Complementary_angles) (pairs that sum to one right angle).[^o11] This definition typically applies to [trigonometric functions](wikipedia://en/30367).[^o7][^o10] The prefix "co-" can be found already in [Edmund Gunter](wikipedia://en/1399676)'s *Canon triangulorum* (1620).[^o8][^o9]

:::

For example, [sine](https://en.wikipedia.org/wiki/Sine) (Latin: *sinus*) and [cosine](https://en.wikipedia.org/wiki/Cosine) (Latin: *cosinus*,[^o8][^o9] *sinus complementi*[^o8][^o9]) are cofunctions of each other (hence the "co" in "cosine"):

::: {#o2 .table cue=table}

| $\sin\left(\frac{\pi}{2} - A\right) = \cos(A)$[^o11][^o10] | $\cos\left(\frac{\pi}{2} - A\right) = \sin(A)$[^o11][^o10] |
|---|---|

:::

The same is true of [secant](https://en.wikipedia.org/wiki/Secant_%28trigonometry%29) (Latin: *secans*) and [cosecant](https://en.wikipedia.org/wiki/Cosecant) (Latin: *cosecans*, *secans complementi*) as well as of [tangent](https://en.wikipedia.org/wiki/Tangent_%28trigonometry%29) (Latin: *tangens*) and [cotangent](https://en.wikipedia.org/wiki/Cotangent) (Latin: *cotangens*,[^o8][^o9] *tangens complementi*[^o8][^o9]):

::: {#o3 .table cue=table}

| $\sec\left(\frac{\pi}{2} - A\right) = \csc(A)$[^o11][^o10] | $\csc\left(\frac{\pi}{2} - A\right) = \sec(A)$[^o11][^o10] |
|---|---|
| $\tan\left(\frac{\pi}{2} - A\right) = \cot(A)$[^o11][^o10] | $\cot\left(\frac{\pi}{2} - A\right) = \tan(A)$[^o11][^o10] |

:::

These equations are also known as the **cofunction identities**.[^o7][^o10]

This also holds true for the [versine](wikipedia://en/555782) (versed sine, ver) and [coversine](https://en.wikipedia.org/wiki/Coversine) (coversed sine, cvs), the [vercosine](https://en.wikipedia.org/wiki/Vercosine) (versed cosine, vcs) and [covercosine](https://en.wikipedia.org/wiki/Covercosine) (coversed cosine, cvc), the [haversine](https://en.wikipedia.org/wiki/Haversine) (half-versed sine, hav) and [hacoversine](https://en.wikipedia.org/wiki/Hacoversine) (half-coversed sine, hcv), the [havercosine](https://en.wikipedia.org/wiki/Havercosine) (half-versed cosine, hvc) and [hacovercosine](https://en.wikipedia.org/wiki/Hacovercosine) (half-coversed cosine, hcc), as well as the [exsecant](wikipedia://en/1273836) (external secant, exs) and [excosecant](https://en.wikipedia.org/wiki/Excosecant) (external cosecant, exc):

::: {#o4 .table cue=table}

| $\operatorname{ver}\left(\frac{\pi}{2} - A\right) = \operatorname{cvs}(A)$[^o12] | $\operatorname{cvs}\left(\frac{\pi}{2} - A\right) = \operatorname{ver}(A)$ |
|---|---|
| $\operatorname{vcs}\left(\frac{\pi}{2} - A\right) = \operatorname{cvc}(A)$[^o13] | $\operatorname{cvc}\left(\frac{\pi}{2} - A\right) = \operatorname{vcs}(A)$ |
| $\operatorname{hav}\left(\frac{\pi}{2} - A\right) = \operatorname{hcv}(A)$ | $\operatorname{hcv}\left(\frac{\pi}{2} - A\right) = \operatorname{hav}(A)$ |
| $\operatorname{hvc}\left(\frac{\pi}{2} - A\right) = \operatorname{hcc}(A)$ | $\operatorname{hcc}\left(\frac{\pi}{2} - A\right) = \operatorname{hvc}(A)$ |
| $\operatorname{exs}\left(\frac{\pi}{2} - A\right) = \operatorname{exc}(A)$ | $\operatorname{exc}\left(\frac{\pi}{2} - A\right) = \operatorname{exs}(A)$ |

:::
