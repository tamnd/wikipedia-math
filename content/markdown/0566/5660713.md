# Signed distance function

*Image: Signed distance1.png.* The [graph](wikipedia://en/87352) (bottom, in red) of the signed distance between the points on the *xy* plane (in blue) and a fixed [disk](wikipedia://en/329542) (also represented on top, in gray)

*Image: Signed distance2.png.* A more complicated set (top) and the graph of its signed distance function (bottom, in red).

::: {#o1 .subject cue=lead name="Signed distance function"}

In [mathematics](wikipedia://en/18831) and its applications, the **signed distance function** or **signed distance field** (**SDF**) is the [orthogonal distance](https://en.wikipedia.org/wiki/Orthogonal_distance) of a given point *x* to the [boundary](wikipedia://en/72824) of a [set](wikipedia://en/26691) Ω in a [metric space](wikipedia://en/20018) (such as the surface of a geometric shape), with the [sign](wikipedia://en/7951270) determined by whether or not *x* is in the [interior](wikipedia://en/55610) of Ω. The [function](wikipedia://en/185427) has positive values at points *x* inside Ω, it decreases in value as *x* approaches the boundary of Ω where the signed distance function is zero, and it takes negative values outside of Ω.[^o2] However, the alternative convention is also sometimes taken instead (i.e., negative inside Ω and positive outside).[^o3] The concept also sometimes goes by the name **oriented distance function/field**.

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $\Omega$ be a [subset](wikipedia://en/27631) of a [metric space](wikipedia://en/20018) $X$ with [metric](https://en.wikipedia.org/wiki/Metric_%28mathematics%29) $d$, and $\partial\Omega$ be its [boundary](wikipedia://en/72824). The distance between a point $x$ of $X$ and the subset $\partial\Omega$ of $X$ is defined as usual as

$$d(x, \partial \Omega) = \inf_{y \in \partial \Omega}d(x, y),$$

where $\inf$ denotes the [infimum](https://en.wikipedia.org/wiki/Infimum).

The *signed distance function* from a point $x$ of $X$ to $\Omega$ is defined by

$$f(x) = \begin{cases} d(x, \partial \Omega) & \text{if } x \in \Omega \\ -d(x, \partial \Omega) & \text{if }\, x \notin \Omega\\ 0 & \text{if }\, x \in \partial \Omega. \end{cases}$$

:::

## Properties in Euclidean space {#Properties_in_Euclidean_space}

If Ω is a subset of the [Euclidean space](wikipedia://en/9697) **R**<sup>*n*</sup> with [piecewise](https://en.wikipedia.org/wiki/Piecewise) [smooth](https://en.wikipedia.org/wiki/Smooth_function) boundary, then the signed distance function is differentiable [almost everywhere](wikipedia://en/44688), and its [gradient](wikipedia://en/12461) satisfies the [eikonal equation](wikipedia://en/4557698)

$$|\nabla f|=1.$$

If the boundary of Ω is *C*<sup>*k*</sup> for *k* ≥ 2 (see [Differentiability classes](https://en.wikipedia.org/wiki/Differentiability_classes)) then *d* is *C*<sup>*k*</sup> on points sufficiently close to the boundary of Ω.[^n1] In particular, ***on*** the boundary *f* satisfies

$$\nabla f(x) = N(x),$$

where *N* is the inward [normal vector](https://en.wikipedia.org/wiki/Normal_vector) field. The signed distance function is thus a differentiable extension of the normal vector field. In particular, the [Hessian](wikipedia://en/412108) of the signed distance function on the boundary of Ω gives the [Weingarten map](wikipedia://en/15513875#Shape_operator).

If, further, Γ is a region sufficiently close to the boundary of Ω that *f* is twice continuously differentiable on it, then there is an explicit formula involving the Weingarten map *W*<sub>*x*</sub> for the Jacobian of changing variables in terms of the signed distance function and nearest boundary point. Specifically, if *T*(*∂*Ω, *μ*) is the set of points within distance *μ* of the boundary of Ω (i.e. the [tubular neighbourhood](https://en.wikipedia.org/wiki/Tubular_neighbourhood) of radius *μ*), and *g* is an [absolutely integrable function](https://en.wikipedia.org/wiki/Absolutely_integrable_function) on Γ, then

$$\int_{T(\partial\Omega,\mu)} g(x)\,dx = \int_{\partial\Omega}\int_{-\mu}^\mu g(u+\lambda N(u))\, \det(I-\lambda W_u) \,d\lambda \,dS_u,$$

where $\det$ denotes the [determinant](wikipedia://en/8468) and *dS*<sub>*u*</sub> indicates that we are taking the [surface integral](wikipedia://en/528867).[^n2]

## Algorithms {#Algorithms}

[Algorithms](wikipedia://en/775) for calculating the signed distance function include the efficient [fast marching method](wikipedia://en/8444826), [fast sweeping method](wikipedia://en/51959005)[^o11] and the more general [level-set method](wikipedia://en/1203063).

For [voxel](https://en.wikipedia.org/wiki/Voxel) rendering, a fast algorithm for calculating the SDF in [taxicab geometry](wikipedia://en/408354) uses [summed-area tables](https://en.wikipedia.org/wiki/Summed-area_table).[^o12]

:::

## Applications {#Applications}

*Image: Signed distance field duck.svg.* Signed distance fields stored as raster images can be used to represent shapes.

Signed distance functions are applied, for example, in [real-time rendering](https://en.wikipedia.org/wiki/Real-time_rendering),[^o15] for instance the method of [SDF ray marching](https://en.wikipedia.org/wiki/Ray_marching#Sphere_tracing), and [computer vision](https://en.wikipedia.org/wiki/Computer_vision).[^o16][^o17]

SDF has been used to describe object geometry in [real-time rendering](https://en.wikipedia.org/wiki/Real-time_rendering), usually in a raymarching context, starting in the mid 2000s. By 2007, [Valve](https://en.wikipedia.org/wiki/Valve_Corporation) was using SDFs to render large pixel-size (or [high DPI](https://en.wikipedia.org/wiki/Pixel_density#Named_pixel_densities)) [smooth fonts](https://en.wikipedia.org/wiki/Smooth_font) with [GPU](https://en.wikipedia.org/wiki/GPU) acceleration in its games.[^o18] Valve's method is not perfect as it runs in [raster space](https://en.wikipedia.org/wiki/Raster_graphics) in order to avoid the computational complexity of solving the problem in the (continuous) vector space. The rendered text often loses sharp corners. In 2014, an improved method was presented by [Behdad Esfahbod](https://en.wikipedia.org/wiki/Behdad_Esfahbod). Behdad's GLyphy approximates the font's [Bézier curves](wikipedia://en/4664) with arc splines, accelerated by grid-based [discretization](wikipedia://en/330017) techniques (which culls too-far-away points) to run in real time.[^o19]

A modified version of SDF was introduced as a [loss function](wikipedia://en/442137) to minimise the error in interpenetration of pixels while rendering multiple objects.[^o20] In particular, for any pixel that does not belong to an object, if it lies outside the object in rendition, no penalty is imposed; if it does, a positive value proportional to its distance inside the object is imposed.

$$f(x) = \begin{cases} 0 & \text{if }\, x \in \Omega^c\\ d(x, \partial\Omega) & \text{if }\, x \in \Omega \end{cases}$$

In 2020, the [FOSS](https://en.wikipedia.org/wiki/Free_and_open-source_software) game engine [Godot 4.0](https://en.wikipedia.org/wiki/Godot_%28game_engine%29) received SDF-based real-time [global illumination](https://en.wikipedia.org/wiki/Global_illumination) (SDFGI), that became a compromise between more realistic voxel-based GI and baked GI. Its core advantage is that it can be applied to infinite space, which allows developers to use it for open-world games.[^o21]

In 2023, the authors of the [Zed](https://en.wikipedia.org/wiki/Zed_%28text_editor%29) text editor announced a GPUI framework that draws all UI elements using the GPU at 120 fps. The work makes use of Inigo Quilez's list of geometric primitives in SDF, [Figma](https://en.wikipedia.org/wiki/Figma) co-founder Evan Wallace's [Gaussian blur](https://en.wikipedia.org/wiki/Gaussian_blur) in SDF, and a new rounded rectangle SDF.[^o22]
