# Quasi-open map

::: {#o1 .subject cue=lead name="Quasi-open map"}

In [topology](wikipedia://en/29954), a branch of mathematics, a **quasi-open map** (also called **quasi-interior map**) is a [function](wikipedia://en/185427) that generalizes the notion of [open map](https://en.wikipedia.org/wiki/Open_map).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A function $f:X\to Y$ between [topological spaces](wikipedia://en/30450) is called **quasi-open** if, for any nonempty [open set](wikipedia://en/39358) $U\subseteq X$, the [interior](wikipedia://en/55610) of $f(U)$ in $Y$ is nonempty.[^o4][^o5] Such a function has also been called a **quasi-interior map**.[^o6]

:::

::: {#o8 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Let $f:X\to Y$ be a map between [topological spaces](https://en.wikipedia.org/wiki/Topological_spaces).

- If $f$ is continuous, it need not be quasi-open. For example, the constant map $f:\mathbb{R}\to\mathbb{R}$ defined by $f(x)=0$ is continuous but not quasi-open.
- Conversely, if $f$ is quasi-open, it need not be continuous. For example, the map $f:\mathbb{R}\to\mathbb{R}$ defined by $f(x)=x$ if $x<0$ and $f(x)=x+1$ if $x\ge 0$ is quasi-open but not continuous.
- If $f$ is [open](https://en.wikipedia.org/wiki/Open_function), then $f$ is quasi-open.[^o5] The converse is not true in general. For example, the continuous function $f:\mathbb{R}\to\mathbb{R},x\mapsto\sin(x)$ is quasi-open but not open.
- If $f$ is a [local homeomorphism](wikipedia://en/248582), then $f$ is quasi-open.[^o9]
- The composition of two quasi-open maps is quasi-open.[^o10][^o5]

:::
