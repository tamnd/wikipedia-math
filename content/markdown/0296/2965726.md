# Markov number

::: {#o1 .subject cue=lead name="Markov number"}

A **Markov number** or **Markoff number** is a positive [integer](wikipedia://en/14563) *x*, *y* or *z* that is part of a solution to the **Markov [Diophantine equation](wikipedia://en/9109)**

:::

$$x^2 + y^2 + z^2 = 3xyz,\,$$

studied by (txt).

The first few Markov numbers are

[1](https://en.wikipedia.org/wiki/1_%28number%29), [2](https://en.wikipedia.org/wiki/2_%28number%29), [5](https://en.wikipedia.org/wiki/5_%28number%29), [13](wikipedia://en/37231), [29](wikipedia://en/362212), [34](https://en.wikipedia.org/wiki/34_%28number%29), [89](https://en.wikipedia.org/wiki/89_%28number%29), [169](https://en.wikipedia.org/wiki/169_%28number%29), [194](https://en.wikipedia.org/wiki/194_%28number%29), [233](https://en.wikipedia.org/wiki/233_%28number%29), 433, 610, 985, 1325, ...

appearing as coordinates of the Markov triples

(1, 1, 1), (1, 1, 2), (1, 2, 5), (1, 5, 13), (2, 5, 29), (1, 13, 34), (1, 34, 89), (2, 29, 169), (5, 13, 194), (1, 89, 233), (5, 29, 433), (1, 233, 610), (2, 169, 985), (13, 34, 1325), ...

There are infinitely many Markov numbers and Markov triples.

## Markov tree {#Markov_tree}

*Image: MarkoffNumberTree.png.* The first levels of the Markov number tree

There are two simple ways to obtain a new Markov triple from an old one (*x*, *y*, *z*). First, one may [permute](wikipedia://en/44027) the 3 numbers *x*,*y*,*z*, so in particular one can normalize the triples so that *x* ≤ *y* ≤ *z*. Second, if (*x*, *y*, *z*) is a Markov triple then so is (*x*, *y*, 3*xy* − *z*). Applying this operation twice returns the same triple one started with. Joining each normalized Markov triple to the 1, 2, or 3 normalized triples one can obtain from this gives a graph starting from (1,1,1) as in the diagram. This graph is [connected](wikipedia://en/1614492); in other words every Markov triple can be connected to (1,1,1) by a sequence of these operations.[^o4] If one starts, as an example, with (1, 5, 13) we get its three [neighbors](wikipedia://en/7309251) (5, 13, 194), (1, 13, 34) and (1, 2, 5) in the Markov tree if *z* is set to 1, 5 and 13, respectively. For instance, starting with (1, 1, 2) and trading *y* and *z* before each iteration of the transform lists Markov triples with [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number). Starting with that same triplet and trading *x* and *z* before each iteration gives the triples with [Pell numbers](wikipedia://en/1355482).

All the Markov numbers on the regions adjacent to 2's region are [odd](wikipedia://en/143135)-indexed Pell numbers (or numbers *n* such that 2*n*<sup>2</sup> − 1 is a [square](wikipedia://en/213919), ), and all the Markov numbers on the regions adjacent to 1's region are odd-indexed Fibonacci numbers (). Thus, there are infinitely many Markov triples of the form

$$(1, F_{2n-1}, F_{2n+1}),\,$$

where *F*<sub>*k*</sub> is the *k*th [Fibonacci number](https://en.wikipedia.org/wiki/Fibonacci_number). Likewise, there are infinitely many Markov triples of the form

$$(2, P_{2n-1}, P_{2n+1}),\,$$

where *P*<sub>*k*</sub> is the *k*th [Pell number](wikipedia://en/1355482).[^o5]

## Other properties {#Other_properties}

Aside from the two smallest *singular* triples (1, 1, 1) and (1, 1, 2), every Markov triple consists of three distinct integers.[^o7]

The *unicity conjecture*, as remarked by [Frobenius](wikipedia://en/341048) in 1913,[^o8] states that for a given Markov number *c*, there is exactly one normalized solution having *c* as its largest element: [proofs](wikipedia://en/82285) of this [conjecture](wikipedia://en/6138) have been claimed but none seems to be correct.[^o9] [Martin Aigner](wikipedia://en/24448177)[^o10] examines several weaker variants of the unicity conjecture. His fixed numerator conjecture was proved by Rabideau and Schiffler in 2020,[^o11] while the fixed denominator conjecture and fixed sum conjecture were proved by Lee, Li, Rabideau and Schiffler in 2023.[^o12]

None of the prime divisors of a Markov number is congruent to 3 modulo 4, which implies that an odd Markov number is 1 more than a multiple of 4.[^o13] Furthermore, if $m$ is a Markov number then none of the prime divisors of $9m^2-4$ is congruent to 3 modulo 4. An [even](wikipedia://en/143135) Markov number is 2 more than a multiple of 32.[^o14]

In his 1982 paper, [Don Zagier](wikipedia://en/1408557) conjectured that the *n*th Markov number is asymptotically given by

$$m_n = \tfrac13 e^{C\sqrt{n+o(1)}} \quad\text{with } C = 2.3523414972 \ldots\,.$$

The error $o(1) = (\log(3m_n)/C)^2 - n$ is plotted below.

*Image: MarkoffNumberAsymptotics.png.* Error in the approximation of large Markov numbers

Moreover, he pointed out that $x^2 + y^2 + z^2 = 3xyz + 4/9$, an approximation of the original Diophantine equation, is equivalent to $f(x)+f(y)=f(z)$ with $f(t) =$ arcosh$(3t/2).$[^o15] The conjecture was proved Status of the asymptotic formula by [Greg McShane](https://en.wikipedia.org/wiki/Greg_McShane) and [Igor Rivin](https://en.wikipedia.org/wiki/Igor_Rivin) in 1995 using techniques from [hyperbolic geometry](wikipedia://en/241291).[^o16]

The *n*th [Lagrange number](wikipedia://en/16075933) can be calculated from the *n*th Markov number with the formula

$$L_n = \sqrt{9 - {4 \over {m_n}^2}}.\,$$

The Markov numbers are sums of (non-unique) pairs of squares.

## Markov's theorem {#Markov's_theorem}

(txt) showed that if

$$f(x,y) = ax^2+bxy+cy^2$$

is an [indefinite](https://en.wikipedia.org/wiki/Indefinite_quadratic_form) [binary quadratic form](wikipedia://en/1867129) with [real](wikipedia://en/20646438) coefficients and [discriminant](https://en.wikipedia.org/wiki/Discriminant_of_a_quadratic_form) $D = b^2-4ac$, then there are integers *x*, *y* for which *f* takes a nonzero value of [absolute value](wikipedia://en/991) at most

$$\frac{\sqrt D}{3}$$

unless *f* is a *Markov form*:[^o20] a constant times a form

$$px^2+(3p-2a)xy+(b-3a)y^2$$

such that

$$\begin{cases} 0<a<p/2,\\ aq\equiv\pm r\pmod p,\\ bp-a^2=1, \end{cases}$$

where (*p*, *q*, *r*) is a Markov triple.

:::

## Matrices {#Matrices}

Let tr denote the [trace](wikipedia://en/43270) function over [matrices](wikipedia://en/20556859). If *X* and *Y* are in [SL](wikipedia://en/144823)<sub>2</sub>(**[$\mathbb{C}$](wikipedia://en/5826)**), then

$$\operatorname{tr}(X) \operatorname{tr}(Y) \operatorname{tr}(XY) + \operatorname{tr}(XYX^{-1}Y^{-1}) + 2 = \operatorname{tr}(X)^2 + \operatorname{tr}(Y)^2 + \operatorname{tr}(XY)^2$$

so that if $\operatorname{tr}(XYX^{-1}Y^{-1}) = -2$ then

$$\operatorname{tr}(X) \operatorname{tr}(Y) \operatorname{tr}(XY) = \operatorname{tr}(X)^2 + \operatorname{tr}(Y)^2 + \operatorname{tr}(XY)^2$$

In particular if *X* and *Y* also have integer entries then tr(*X*)/3, tr(*Y*)/3, and tr(*XY*)/3 are a Markov triple. If *X*⋅*Y*⋅*Z* = [I](wikipedia://en/59718) then tr(*XtY*) = tr(*Z*), so more symmetrically if *X*, *Y*, and *Z* are in SL<sub>2</sub>([$\mathbb{Z}$](wikipedia://en/14563)) with *X*⋅*Y*⋅*Z* = I and the [commutator](wikipedia://en/7193#Group_theory) of two of them has trace −2, then their traces/3 are a Markov triple.[^o22]
