# Disorder problem

::: {#o1 .subject cue=lead name="Disorder problem"}

In the study of [stochastic processes](https://en.wikipedia.org/wiki/Stochastic_processes) in [mathematics](wikipedia://en/18831), a **disorder problem** or **quickest detection problem** (formulated by [Kolmogorov](https://en.wikipedia.org/wiki/Kolmogorov)) is the problem of using ongoing observations of a stochastic process to detect as soon as possible when the probabilistic properties of the process have changed. This is a type of [change detection](wikipedia://en/10543268) problem.

:::

An example case is to detect the change in the drift parameter of a [Wiener process](wikipedia://en/149984).[^o2]
