# Gold code

::: {#o1 .subject cue=lead name="Gold code"}

A **Gold code**, also known as **Gold sequence**, is a type of binary [sequence](wikipedia://en/27838) used in [telecommunications](https://en.wikipedia.org/wiki/Telecommunications) ([CDMA](https://en.wikipedia.org/wiki/CDMA))[^o4] and satellite navigation ([GPS](https://en.wikipedia.org/wiki/GPS)).[^o5] Gold codes are named after Robert Gold.[^o6][^o7] Gold codes have bounded small [cross-correlations](wikipedia://en/714163) within a set, which is useful when multiple devices are broadcasting in the same frequency range. A set of Gold code sequences consists of 2<sup>*n*</sup> + 1 sequences each one with a period of 2<sup>*n*</sup> − 1.

:::

A set of Gold codes can be generated with the following steps. Pick two [maximum-length sequences](wikipedia://en/1495467) of the same length 2<sup>*n*</sup> − 1 such that their absolute [cross-correlation](wikipedia://en/714163) is less than or equal to 2<sup>(*n*+2)/2</sup>, where *n* is the size of the [linear-feedback shift register](wikipedia://en/58992) used to generate the maximum-length sequence.[^o7] The set of the 2<sup>*n*</sup> − 1 [exclusive-ors](https://en.wikipedia.org/wiki/Exclusive-or) of the two sequences in their various phases (i.e. translated into all relative positions) together with the two maximum-length sequences form a set of 2<sup>*n*</sup> + 1 Gold code sequences. The highest absolute cross-correlation in this set of codes is 2<sup>(*n*+2)/2</sup> + 1 for even *n* and 2<sup>(*n*+1)/2</sup> + 1 for odd *n*.

The [exclusive or](wikipedia://en/105979) of two different Gold codes from the same set is another Gold code in some phase.

Within a set of Gold codes about half of the codes are balanced – the number of ones and zeros differs by only one.[^o8]

Gold codes are used in [GPS](https://en.wikipedia.org/wiki/GPS). The [GPS C/A](https://en.wikipedia.org/wiki/GPS_signals#Coarse/acquisition_code) ranging codes are Gold codes of period 1,023.
