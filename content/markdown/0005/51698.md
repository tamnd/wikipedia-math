# Extended real number line

::: {#o1 .subject cue=lead name="Extended real number line"}

*Image: Extended\_Real\_Numbers.svg.* Extended real numbers (top) vs [projectively extended real numbers](https://en.wikipedia.org/wiki/Projectively_extended_real_numbers) (bottom)

In [mathematics](wikipedia://en/18831), the **extended real number system** is obtained from the [real number](wikipedia://en/20646438) system $\mathbb{R}$ by adding two elements denoted $+\infty$ and $-\infty$ that are respectively greater and lower than every real number. This allows for treating the [potential infinities](https://en.wikipedia.org/wiki/Potential_infinity) of infinitely increasing sequences and infinitely decreasing series as [actual infinities](https://en.wikipedia.org/wiki/Actual_infinity). For example, the [infinite sequence](https://en.wikipedia.org/wiki/Infinite_sequence) $(1,2,\ldots)$ of the [natural numbers](wikipedia://en/21474) increases *infinitively* and has no [upper bound](https://en.wikipedia.org/wiki/Upper_bound) in the real number system (a potential infinity); in the extended real number line, the sequence has $+\infty$ as its [least upper bound](https://en.wikipedia.org/wiki/Least_upper_bound) and as its [limit](wikipedia://en/26551602) (an actual infinity). In [calculus](wikipedia://en/5176) and [mathematical analysis](wikipedia://en/48396), the use of $+\infty$ and $-\infty$ as actual limits extends significantly the possible computations.[^o2] It is the [Dedekind–MacNeille completion](wikipedia://en/16667323) of the real numbers.

:::

The extended real number system is denoted $\overline{\mathbb{R}}$, $[-\infty,+\infty]$, or $\mathbb{R}\cup\left\{-\infty,+\infty\right\}$.[^o7] When the meaning is clear from context, the symbol $+\infty$ is often written simply as $\infty$.[^o7]

There is also a distinct [projectively extended real line](wikipedia://en/1014534) where $+\infty$ and $-\infty$ are not distinguished, i.e., there is a single actual infinity for both infinitely increasing sequences and infinitely decreasing sequences that is denoted as just $\infty$ or as $\pm\infty$.

## Motivation {#Motivation}

### Limits {#Limits}

The extended number line is often useful to describe the behavior of a [function](wikipedia://en/185427) $f$ when either the [argument](wikipedia://en/32842052) $x$ or the function value $f$ gets "infinitely large" in some sense. For example, consider the function $f$ defined by

$$f(x)=\frac{1}{x^{2}}.$$

The [graph](wikipedia://en/87352) of this function has a horizontal [asymptote](wikipedia://en/3107) at $y=0$. Geometrically, when moving increasingly farther to the right along the $x$-axis, the value of ${1}/{x^2}$ [approaches](wikipedia://en/285759) 0. This limiting behavior is similar to the [limit of a function](wikipedia://en/285759) $\lim_{x\to x_0}f(x)$ in which the [real number](wikipedia://en/20646438) $x$ approaches $x_0,$ except that there is no real number that $x$ approaches when $x$ increases infinitely. Adjoining the elements $+\infty$ and $-\infty$ to $\mathbb{R}$ enables a definition of "limits at infinity" which is very similar to the usual definition of limits, except that $|x-x_0|<\varepsilon$ is replaced by $x>N$ (for $+\infty$) or $x<-N$ (for $-\infty$). This allows proving and writing

$$\begin{aligned}\lim_{x\to+\infty}\frac1{x^2}&=0,\\\lim_{x\to-\infty}\frac1{x^2}&=0,\\\lim_{x\to0}\frac1{x^2}&=+\infty.\end{aligned}$$

### Measure and integration {#Measure_and_integration}

In [measure theory](https://en.wikipedia.org/wiki/Measure_theory), it is often useful to allow sets that have infinite [measure](wikipedia://en/19873) and integrals whose value may be infinite.

Such measures arise naturally out of calculus. For example, in assigning a measure to $\mathbb{R}$ that agrees with the usual length of [intervals](wikipedia://en/49172), this measure must be larger than any finite real number. Also, when considering [improper integrals](wikipedia://en/346030), such as

$$\int_1^{\infty}\frac{dx}{x}$$

the value "infinity" arises. Finally, it is often useful to consider the limit of a sequence of functions, such as

$$f_n(x)=\begin{cases}2n(1-nx),&\mbox{if }0\leq x\leq\frac{1}{n}\\0,&\mbox{if }\frac{1}{n}<x\leq1\end{cases}.$$

Without allowing functions to take on infinite values, such essential results as the [monotone convergence theorem](wikipedia://en/146263) and the [dominated convergence theorem](wikipedia://en/351853) would not make sense.

## Order and topological properties {#Order_and_topological_properties}

The extended real number system $\overline{\mathbb{R}}$, defined as $[-\infty,+\infty]$ or $\mathbb{R}\cup\left\{-\infty,+\infty\right\}$, can be turned into a [totally ordered set](https://en.wikipedia.org/wiki/Totally_ordered_set) by defining $-\infty\leq a\leq+\infty$ for all $a\in\overline{\mathbb{R}}$. With this [order topology](wikipedia://en/213650), $\overline{\mathbb{R}}$ has the desirable property of [compactness](wikipedia://en/6042): Every [subset](wikipedia://en/27631) of $\overline\mathbb{R}$ has a [supremum](https://en.wikipedia.org/wiki/Supremum) and an [infimum](https://en.wikipedia.org/wiki/Infimum)[^o7] (the infimum of the [empty set](wikipedia://en/9566) is $+\infty$, and its supremum is $-\infty$). Moreover, with this [topology](wikipedia://en/30450), $\overline\mathbb{R}$ is [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic) to the [unit interval](wikipedia://en/49324) $[0,1]$. Thus the topology is [metrizable](https://en.wikipedia.org/wiki/Metrizable), corresponding (for a given homeomorphism) to the ordinary [metric](https://en.wikipedia.org/wiki/Metric_%28mathematics%29) on this interval. There is no metric, however, that is an extension of the ordinary metric on $\mathbb{R}$.

In this topology, a set $U$ is a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28mathematics%29) of $+\infty$ if and only if it contains a set $\{x:x>a\}$ for some real number $a$. The notion of the neighborhood of $-\infty$ can be defined similarly. Using this characterization of extended-real neighborhoods, [limits](wikipedia://en/285759) with $x$ tending to $+\infty$ or $-\infty$, and limits "equal" to $+\infty$ and $-\infty$, reduce to the general topological definition of limits—instead of having a special definition in the real number system.

## Arithmetic operations {#Arithmetic_operations}

The arithmetic operations of $\mathbb{R}$ can be partially extended to $\overline\mathbb{R}$ as follows:[^o9]

$$\begin{aligned}a\pm\infty=\pm\infty+a&=\pm\infty,&a&\neq\mp\infty\\a\cdot(\pm\infty)=\pm\infty\cdot a&=\pm\infty,&a&\in(0,+\infty]\\a\cdot(\pm\infty)=\pm\infty\cdot a&=\mp\infty,&a&\in[-\infty,0)\\\frac{a}{\pm\infty}&=0,&a&\in\mathbb{R}\\\frac{\pm\infty}{a}&=\pm\infty,&a&\in(0,+\infty)\\\frac{\pm\infty}{a}&=\mp\infty,&a&\in(-\infty,0)\end{aligned}$$

For exponentiation, see Exponentiation. Here, $a+\infty$ means both $a+(+\infty)$ and $a-(-\infty)$, while $a-\infty$ means both $a-(+\infty)$ and $a+(-\infty)$.

The expressions $\infty-\infty$, $0\times(\pm\infty)$, and $\pm\infty/\pm\infty$ (called [indeterminate forms](wikipedia://en/366723)) are usually left [undefined](https://en.wikipedia.org/wiki/Defined_and_undefined). These rules are modeled on the laws for [infinite limits](wikipedia://en/285759#Limits_involving_infinity). However, in the context of [probability](wikipedia://en/23542) or measure theory, $0\times\pm\infty$ is often defined as 0.[^o13]

When dealing with both positive and negative extended real numbers, the expression $1/0$ is usually left undefined, because, although it is true that for every real nonzero sequence $f$ that [converges](wikipedia://en/285773) to 0, the [reciprocal](wikipedia://en/229940) sequence $1/f$ is eventually contained in every neighborhood of $\{\infty,-\infty\}$, it is *not* true that the sequence $1/f$ must itself converge to either $-\infty$ or $\infty.$ Said another way, if a [continuous function](wikipedia://en/6122) $f$ achieves a zero at a certain value $x_0,$ then it need not be the case that $1/f$ tends to either $-\infty$ or $\infty$ in the limit as $x$ tends to $x_0$. This is the case for the limits of the [identity function](wikipedia://en/15069) $f(x)=x$ when $x$ tends to 0, and of $f(x)=x^2\sin\left(1/x\right)$ (for the latter function, neither $-\infty$ nor $\infty$ is a limit of $1/f(x)$, even if only positive values of $x$ are considered).

However, in contexts where only non-negative values are considered, it is often convenient to define $1/0=+\infty$. For example, when working with [power series](wikipedia://en/59958), the [radius of convergence](wikipedia://en/61476) of a power series with [coefficients](wikipedia://en/51203) $a_n$ is often defined as the reciprocal of the [limit-supremum](wikipedia://en/44837) of the sequence $\left(|a_n|^{1/n}\right)$. Thus, if one allows $1/0$ to take the value $+\infty$, then one can use this formula regardless of whether the limit-supremum is 0 or not.

## Algebraic properties {#Algebraic_properties}

With the arithmetic operations defined above, $\overline\mathbb{R}$ is not even a [semigroup](wikipedia://en/27799), let alone a [group](wikipedia://en/19447), a [ring](wikipedia://en/48404) or a [field](wikipedia://en/10603) as in the case of $\mathbb{R}$. However, it has several convenient properties:

- $a+(b+c)$ and $(a+b)+c$ are either equal or both undefined.
- $a+b$ and $b+a$ are either equal or both undefined.
- $a\cdot(b\cdot c)$ and $(a\cdot b)\cdot c$ are either equal or both undefined.
- $a\cdot b$ and $b\cdot a$ are either equal or both undefined
- $a\cdot(b+c)$ and $(a\cdot b)+(a\cdot c)$ are equal if both are defined.
- If $a\leq b$ and if both $a+c$ and $b+c$ are defined, then $a+c\leq b+c$.
- If $a\leq b$ and $c>0$ and if both $a\cdot c$ and $b\cdot c$ are defined, then $a\cdot c\leq b\cdot c$.

In general, all laws of arithmetic are valid in $\overline\mathbb{R}$ as long as all occurring expressions are defined.

:::

## Miscellaneous {#Miscellaneous}

Several functions can be [continuously](https://en.wikipedia.org/wiki/Continuity_%28topology%29) [extended](wikipedia://en/1589032) to $\overline\mathbb{R}$ by taking limits. For instance, one may define the extremal points of the following functions as:

$$\exp(-\infty)=0,$$

$$\ln(0)=-\infty,$$

$$\tanh(\pm\infty)=\pm1,$$

$$\arctan(\pm\infty)= \pm\frac{\pi}{2}.$$

Some [singularities](wikipedia://en/54240) may additionally be removed. For example, the function $1/x^2$ can be continuously extended to $\overline\mathbb{R}$ (under *some* definitions of continuity), by setting the value to $+\infty$ for $x=0$, and 0 for $x=+\infty$ and $x=-\infty$. On the other hand, the function $1/x$ can*not* be continuously extended, because the function approaches $-\infty$ as $x$ approaches 0 [from below](wikipedia://en/379840), and $+\infty$ as $x$ approaches 0 from above, i.e., the function not converging to the same value as its independent variable approaching to the same domain element from both the positive and negative value sides.

A similar but different real-line system, the [projectively extended real line](wikipedia://en/1014534), does not distinguish between $+\infty$ and $-\infty$ (i.e. infinity is unsigned).[^o13] As a result, a function may have limit $\infty$ on the projectively extended real line, while in the extended real number system only the [absolute value](wikipedia://en/991) of the function has a limit, e.g. in the case of the function $1/x$ at $x=0$. On the other hand, on the projectively extended real line, $\lim_{x\to-\infty}{f(x)}$ and $\lim_{x\to+\infty}{f(x)}$ correspond to only a limit from the right and one from the left, respectively, with the full limit only existing when the two are equal. Thus, the functions $e^x$ and $\arctan(x)$ cannot be made continuous at $x=\infty$ on the projectively extended real line.
