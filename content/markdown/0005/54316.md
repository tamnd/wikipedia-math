# List of mathematical functions

::: {#o1 .subject cue=lead name="List of mathematical functions"}

In [mathematics](wikipedia://en/18831), some functions or groups of functions are important enough to deserve their own names. This is a listing of articles which explain some of these functions in more detail. There is a large theory of [special functions](wikipedia://en/23709110) which developed out of [statistics](wikipedia://en/26685) and [mathematical physics](wikipedia://en/173416). A modern, abstract point of view contrasts large [function spaces](wikipedia://en/340630), which are infinite-dimensional and within which most functions are "anonymous", with special functions picked out by properties such as [symmetry](wikipedia://en/53741), or relationship to [harmonic analysis](wikipedia://en/14147) and [group representations](wikipedia://en/12695).

:::

See also [List of types of functions](wikipedia://en/16868392)

## Elementary functions {#Elementary_functions}

[Elementary functions](https://en.wikipedia.org/wiki/Elementary_functions) are functions built from basic operations (e.g. addition, exponentials, logarithms...)

### Algebraic functions {#Algebraic_functions}

[Algebraic functions](wikipedia://en/974169) are functions that can be expressed as the solution of a polynomial equation with integer (or equivalently rational) coefficients.

::: {#o4 .entry cue=list-entry name="Polynomial"}

- [Polynomials](wikipedia://en/23000): Can be generated solely by addition, multiplication, and raising to the power of a positive integer.

:::

  - [Constant function](wikipedia://en/320861): polynomial of degree zero, graph is a horizontal straight line
  - [Linear function](wikipedia://en/152111): First degree polynomial, graph is a straight line.
  - [Quadratic function](wikipedia://en/187240): Second degree polynomial, graph is a [parabola](wikipedia://en/23231).
  - [Cubic function](wikipedia://en/243709): Third degree polynomial.
  - [Quartic function](wikipedia://en/308152): Fourth degree polynomial.
  - [Quintic function](https://en.wikipedia.org/wiki/Quintic_function): Fifth degree polynomial.

::: {#o5 .entry cue=list-entry name="Rational function"}

- [Rational functions](wikipedia://en/361210): A ratio of two polynomials.

:::

::: {#o6 .entry cue=list-entry name="nth root"}

- [*n*th root](wikipedia://en/235029)

:::

  - [Square root](wikipedia://en/29208): Yields a number whose square is the given one.
  - [Cube root](wikipedia://en/292506): Yields a number whose cube is the given one.

### Elementary transcendental functions {#Elementary_transcendental_functions}

[Transcendental functions](wikipedia://en/297021) are functions that are not algebraic.

::: {#o8 .entry cue=list-entry name="Exponential function"}

- [Exponential function](wikipedia://en/9678): raises a fixed number to a variable power.

:::

::: {#o9 .entry cue=list-entry name="Hyperbolic function"}

- [Hyperbolic functions](https://en.wikipedia.org/wiki/Hyperbolic_function): formally similar to the [trigonometric functions](wikipedia://en/30367).

:::

  - [Inverse hyperbolic functions](wikipedia://en/3804557): [inverses](wikipedia://en/14907) of the [hyperbolic functions](wikipedia://en/56567), analogous to the [inverse circular functions](wikipedia://en/374220).

::: {#o10 .entry cue=list-entry name="Logarithm"}

- [Logarithms](wikipedia://en/17860): the inverses of exponential functions; useful to solve equations involving exponentials.

:::

  - [Natural logarithm](wikipedia://en/21476)
  - [Common logarithm](wikipedia://en/174482)
  - [Binary logarithm](wikipedia://en/249992)

::: {#o11 .entry cue=list-entry name="Periodic function"}

- [Periodic functions](wikipedia://en/76848)

:::

  - [Trigonometric functions](https://en.wikipedia.org/wiki/Trigonometric_function): [sine](https://en.wikipedia.org/wiki/Sine), [cosine](https://en.wikipedia.org/wiki/Cosine), [tangent](https://en.wikipedia.org/wiki/Tangent_%28trigonometry%29), [cotangent](https://en.wikipedia.org/wiki/Cotangent), [secant](https://en.wikipedia.org/wiki/Secant_%28trigonometry%29), [cosecant](https://en.wikipedia.org/wiki/Cosecant), [exsecant](wikipedia://en/1273836), [excosecant](https://en.wikipedia.org/wiki/Excosecant), [versine](wikipedia://en/555782), [coversine](https://en.wikipedia.org/wiki/Coversine), [vercosine](https://en.wikipedia.org/wiki/Vercosine), [covercosine](https://en.wikipedia.org/wiki/Covercosine), [haversine](https://en.wikipedia.org/wiki/Haversine), [hacoversine](https://en.wikipedia.org/wiki/Hacoversine), [havercosine](https://en.wikipedia.org/wiki/Havercosine), [hacovercosine](https://en.wikipedia.org/wiki/Hacovercosine); used in [geometry](wikipedia://en/18973446) and to describe periodic phenomena.
    - [Inverse trigonometric functions](wikipedia://en/374220).
    - See also [Gudermannian function](wikipedia://en/303274).

Most special functions are transcendental.

::: {#o22 .entry cue=list-entry name="Liouville function"}

- [Liouville function](wikipedia://en/104463): $\Lambda(n)=(-1)^{\Omega(n)}$

:::

::: {#o23 .entry cue=list-entry name="Von Mangoldt function"}

- [Von Mangoldt function](wikipedia://en/1928862), Λ(*n*) = log *p* if *n* is a positive power of the prime *p*

:::

::: {#o24 .entry cue=list-entry name="Carmichael function"}

- [Carmichael function](wikipedia://en/1181756): $\lambda(n)=$ The smallest integer $m$ such that $a^m\equiv 1\pmod{n}$ for all $a$ coprime to $n$

::: {#o25 .entry cue=list-entry name="Radical function"}

- [Radical function](wikipedia://en/1634886): The product of the distinct prime factors of a positive integer input.

### Miscellaneous functions {#Miscellaneous_functions}

::: {#o66 .entry cue=list-entry name="Ackermann function"}

- [Ackermann function](wikipedia://en/2925): in the [theory of computation](wikipedia://en/30402), a [computable function](wikipedia://en/1139338) that is not [primitive recursive](wikipedia://en/24829).

:::

::: {#o67 .entry cue=list-entry name="Dirac delta function"}

- [Dirac delta function](wikipedia://en/37021): everywhere zero except for *x* = 0; total integral is 1. Not a function but a [distribution](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29), but sometimes informally referred to as a function, particularly by physicists and engineers.

:::

::: {#o68 .entry cue=list-entry name="Dirichlet function"}

- [Dirichlet function](wikipedia://en/630005): is an [indicator function](wikipedia://en/240790) that matches 1 to [rational numbers](wikipedia://en/19727024) and 0 to [irrationals](wikipedia://en/20647689). It is [nowhere continuous](https://en.wikipedia.org/wiki/Nowhere_continuous).

:::

::: {#o69 .entry cue=list-entry name="Thomae's function"}

- [Thomae's function](wikipedia://en/3397404): is a function that is continuous at all irrational numbers and discontinuous at all rational numbers. It is also a modification of Dirichlet function and sometimes called Riemann function.

:::

::: {#o70 .entry cue=list-entry name="Kronecker delta function"}

- [Kronecker delta function](https://en.wikipedia.org/wiki/Kronecker_delta_function): is a function of two variables, usually integers, which is 1 if they are equal, and 0 otherwise.

:::

::: {#o71 .entry cue=list-entry name="Minkowski's question mark function"}

- [Minkowski's question mark function](https://en.wikipedia.org/wiki/Minkowski's_question_mark_function): Derivatives vanish on the rationals.

:::

::: {#o72 .entry cue=list-entry name="Weierstrass function"}

- [Weierstrass function](https://en.wikipedia.org/wiki/Weierstrass_function): is an example of [continuous function](wikipedia://en/6122) that is nowhere [differentiable](wikipedia://en/330206)

:::
