# Semi-continuity

*Image: Upper semi.svg.* An upper semicontinuous function that is not lower semicontinuous at $x_0$. The solid blue dot indicates $f\left(x_0\right).$

*Image: Lower semi.svg.* A lower semicontinuous function that is not upper semicontinuous at $x_0$. The solid blue dot indicates $f\left(x_0\right).$

::: {#o1 .subject cue=lead name="Semi-continuity"}

In [mathematical analysis](wikipedia://en/48396), **semicontinuity** (or **semi-continuity**) is a property of [extended real](https://en.wikipedia.org/wiki/Extended_real_number)-valued [functions](wikipedia://en/185427) that is weaker than [continuity](wikipedia://en/6122). An extended real-valued function $f$ is **upper** (respectively, **lower**) **semicontinuous** at a point $x_0$ if, roughly speaking, the function values for arguments near $x_0$ are not much higher (respectively, lower) than $f\left(x_0\right).$ Briefly, a function on a domain $X$ is lower semi-continuous if its [epigraph](wikipedia://en/5744061) $\{(x,t)\in X\times\mathbb{R} : t\ge f(x)\}$ is closed in $X\times\mathbb{R}$, and upper semi-continuous if $-f$ is lower semi-continuous.

:::

A function is continuous if and only if it is both upper and lower semicontinuous. If we take a continuous function and increase its value at a certain point $x_0$ to $f\left(x_0\right) + c$ for some $c>0$, then the result is upper semicontinuous; if we decrease its value to $f\left(x_0\right) - c$ then the result is lower semicontinuous.

The notion of upper and lower semicontinuous function was first introduced and studied by [René Baire](https://en.wikipedia.org/wiki/René_Baire) in his thesis in 1899.[^o2]

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

Assume throughout that $X$ is a [topological space](wikipedia://en/30450) and $f:X\to\overline{\mathbb{R}}$ is a function with values in the [extended real numbers](https://en.wikipedia.org/wiki/Extended_real_number) $\overline{\mathbb{R}}=\mathbb{R} \cup \{-\infty,\infty\} = [-\infty,\infty]$.

### Upper semicontinuity {#Upper_semicontinuity}

A function $f:X\to\overline{\mathbb{R}}$ is called **upper semicontinuous at a point** $x_0 \in X$ if for every real $y > f\left(x_0\right)$ there exists a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) $U$ of $x_0$ such that $f(x)<y$ for all $x\in U$.[^o6] Equivalently, $f$ is upper semicontinuous at $x_0$ if and only if

$$\limsup_{x \to x_0} f(x) \leq f(x_0)$$

where lim sup is the [limit superior](https://en.wikipedia.org/wiki/Limit_superior_%28topological_space%29) of the function $f$ at the point $x_0$, defined as

$$\limsup_{x\to x_0}f(x) = \inf_{x_0 \in U}\sup_{x\in U} f(x)$$

where the [infimum](https://en.wikipedia.org/wiki/Infimum) is over all neighborhoods of the point $x_0$.[^n1][^n2][^n3]

If $X$ is a [metric space](wikipedia://en/20018) with [distance function](https://en.wikipedia.org/wiki/Distance_function) $d$ and $f(x_0)\in\mathbb{R},$ this can also be restated using an $\varepsilon$-$\delta$ formulation, similar to the definition of [continuous function](wikipedia://en/6122). Namely, for each $\varepsilon>0$ there is a $\delta>0$ such that $f(x)<f(x_0)+\varepsilon$ whenever $d(x,x_0)<\delta.$

A function $f:X\to\overline{\mathbb{R}}$ is called **upper semicontinuous** if it satisfies any of the following equivalent conditions:[^o6]

(1) The function is upper semicontinuous at every point of its [domain](https://en.wikipedia.org/wiki/Domain_%28function%29).

(2) For each $y\in\mathbb{R}$, the set $f^{-1}([ -\infty ,y))=\{x\in X : f(x)<y\}$ is [open](https://en.wikipedia.org/wiki/Open_%28topology%29) in $X$, where $[ -\infty ,y)=\{t\in\overline{\mathbb{R}}:t<y\}$.

(3) For each $y\in\mathbb{R}$, the $y$-[superlevel set](https://en.wikipedia.org/wiki/Superlevel_set) $f^{-1}([y, \infty)) = \{x\in X : f(x)\ge y\}$ is [closed](https://en.wikipedia.org/wiki/Closed_%28topology%29) in $X$.

(4) The [hypograph](wikipedia://en/18048054) $\{(x,t)\in X\times\mathbb{R} : t\le f(x)\}$ is closed in $X\times\mathbb{R}$.

(5) The function $f$ is continuous when the [codomain](wikipedia://en/50264) $\overline{\mathbb{R}}$ is given the [left order topology](https://en.wikipedia.org/wiki/Left_order_topology). This is just a restatement of condition (2) since the left order topology is generated by all the intervals $[ -\infty,y)$.

::: {#o11 .pointer-item cue=pointer name="Lower semicontinuous function"}

### Lower semicontinuity {#Lower_semicontinuity}

A function $f:X\to\overline{\mathbb{R}}$ is called **lower semicontinuous at a point** $x_0\in X$ if for every real $y < f\left(x_0\right)$ there exists a [neighborhood](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) $U$ of $x_0$ such that $f(x)>y$ for all $x\in U$. Equivalently, $f$ is lower semicontinuous at $x_0$ if and only if

$$\liminf_{x \to x_0} f(x) \ge f(x_0)$$

where $\liminf$ is the [limit inferior](https://en.wikipedia.org/wiki/Limit_inferior_%28topological_space%29) of the function $f$ at point $x_0.$

If $X$ is a [metric space](wikipedia://en/20018) with [distance function](https://en.wikipedia.org/wiki/Distance_function) $d$ and $f(x_0)\in\mathbb{R},$ this can also be restated as follows: For each $\varepsilon>0$ there is a $\delta>0$ such that $f(x)>f(x_0)-\varepsilon$ whenever $d(x,x_0)<\delta.$

A function $f:X\to\overline{\mathbb{R}}$ is called **lower semicontinuous** if it satisfies any of the following equivalent conditions:

(1) The function is lower semicontinuous at every point of its [domain](https://en.wikipedia.org/wiki/Domain_%28function%29).

(2) For each $y\in\mathbb{R}$, the set $f^{-1}((y,\infty ])=\{x\in X : f(x)>y\}$ is [open](https://en.wikipedia.org/wiki/Open_%28topology%29) in $X$, where $(y,\infty ]=\{t\in\overline{\mathbb{R}}:t>y\}$.

(3) For each $y\in\mathbb{R}$, the $y$-[sublevel set](https://en.wikipedia.org/wiki/Sublevel_set) $f^{-1}((-\infty, y]) = \{x\in X : f(x)\le y\}$ is [closed](https://en.wikipedia.org/wiki/Closed_%28topology%29) in $X$.

(4) The [epigraph](wikipedia://en/5744061) $\{(x,t)\in X\times\mathbb{R} : t\ge f(x)\}$ is closed in $X\times\mathbb{R}$.[^o12]

(5) The function $f$ is continuous when the [codomain](wikipedia://en/50264) $\overline{\mathbb{R}}$ is given the [right order topology](https://en.wikipedia.org/wiki/Right_order_topology). This is just a restatement of condition (2) since the right order topology is generated by all the intervals $(y,\infty ]$.

## Examples {#Examples}

Consider the function $f,$ [piecewise](https://en.wikipedia.org/wiki/Piecewise) defined by:

$$f(x) = \begin{cases} -1 & \mbox{if } x < 0,\\ 1 & \mbox{if } x \geq 0 \end{cases}$$

This function is upper semicontinuous at $x_0 = 0,$ but not lower semicontinuous.

The [floor function](https://en.wikipedia.org/wiki/Floor_function) $f(x) = \lfloor x \rfloor,$ which returns the greatest integer less than or equal to a given real number $x,$ is everywhere upper semicontinuous. Similarly, the [ceiling function](https://en.wikipedia.org/wiki/Ceiling_function) $f(x) = \lceil x \rceil$ is lower semicontinuous.

Upper and lower semicontinuity bear no relation to [continuity from the left or from the right](wikipedia://en/6122#Directional_and_semi-continuity) for functions of a real variable. Semicontinuity is defined in terms of an ordering in the range of the functions, not in the domain.[^o15] For example the function

$$f(x) = \begin{cases} \sin(1/x) & \mbox{if } x \neq 0,\\ 1 & \mbox{if } x = 0, \end{cases}$$

is upper semicontinuous at $x = 0$ while the function limits from the left or right at zero do not even exist.

If $X = \mathbb{R}^n$ is a Euclidean space (or more generally, a metric space) and $\Gamma = C([0,1], X)$ is the space of [curves](wikipedia://en/89246) in $X$ (with the [supremum distance](https://en.wikipedia.org/wiki/Supremum_norm) $d_\Gamma(\alpha,\beta) = \sup\{d_X(\alpha(t),\beta(t)):t\in[0,1]\}$), then the length functional $L : \Gamma \to [0, +\infty],$ which assigns to each curve $\alpha$ its [length](wikipedia://en/89246#Length_of_curves) $L(\alpha),$ is lower semicontinuous.[^o16] As an example, consider approximating the unit square diagonal by a staircase from below. The staircase always has length 2, while the diagonal line has only length $\sqrt 2$.

A fundamental example in [real analysis](wikipedia://en/26478) is [Fatou's lemma](wikipedia://en/291614). It asserts that if $f_n$ is a sequence of non-negative [measurable functions](wikipedia://en/44055), then

$$\int\liminf f_n \le \liminf\int f_n$$

where $\liminf$ denotes the ([pointwise](wikipedia://en/4786797)) [limit inferior](https://en.wikipedia.org/wiki/Limit_inferior). What this means, in full generality, is that if $(X,\mu)$ be a measure space and $L^+(X,\mu)$ denotes the set of positive measurable functions endowed with the topology of [convergence in measure](wikipedia://en/7996261) with respect to $\mu,$ then the integral, seen as an operator from $L^+(X,\mu)$ to $[-\infty, +\infty]$ is lower semicontinuous.

## Properties {#Properties}

Unless specified otherwise, all functions below are from a [topological space](wikipedia://en/30450) $X$ to the [extended real numbers](https://en.wikipedia.org/wiki/Extended_real_number) $\overline{\mathbb{R}}= [-\infty,\infty].$ *Several of the results hold for semicontinuity at a specific point, but for brevity they are only stated for semicontinuity over the whole domain.*

- A function $f:X\to\overline{\mathbb{R}}$ is [continuous](wikipedia://en/6122) if and only if it is both upper and lower semicontinuous.
- The [characteristic function](wikipedia://en/240790) or [indicator function](wikipedia://en/240790) of a set $A\subset X$ (defined by $\mathbf{1}_A(x)=1$ if $x\in A$ and $0$ if $x\notin A$) is upper semicontinuous if and only if $A$ is a [closed set](wikipedia://en/47279). It is lower semicontinuous if and only if $A$ is an [open set](wikipedia://en/39358).
- In the field of [convex analysis](wikipedia://en/3237201), the [characteristic function](https://en.wikipedia.org/wiki/Characteristic_function_%28convex_analysis%29) of a set $A \subset X$ is defined differently, as $\chi_{A}(x)=0$ if $x\in A$ and $\chi_A(x) = \infty$ if $x\notin A$. With that definition, the characteristic function of any closed set is lower semicontinuous, and the characteristic function of any open set is upper semicontinuous.

### Binary operations on semicontinuous functions {#Binary_operations_on_semicontinuous_functions}

Let $f,g : X \to \overline{\mathbb{R}}$.

- If $f$ and $g$ are lower semicontinuous, then the sum $f+g$ is lower semicontinuous[^o20] (provided the sum is well-defined, i.e., $f(x)+g(x)$ is not the [indeterminate form](wikipedia://en/366723) $-\infty+\infty$). The same holds for upper semicontinuous functions.
- If $f$ and $g$ are lower semicontinuous and non-negative, then the product function $f g$ is lower semicontinuous. The corresponding result holds for upper semicontinuous functions.
- The function $f$ is lower semicontinuous if and only if $-f$ is upper semicontinuous.
- If $f$ and $g$ are upper semicontinuous and $f$ is [non-decreasing](wikipedia://en/48260), then the [composition](wikipedia://en/195947) $f \circ g$ is upper semicontinuous. On the other hand, if $f$ is not non-decreasing, then $f \circ g$ may not be upper semicontinuous. For example take $f : \mathbb{R} \to \mathbb{R}$ defined as $f(x)=-x$. Then $f$ is continuous and $f \circ g = -g$, which is not upper semicontinuous unless $g$ is continuous.
- If $f$ and $g$ are lower semicontinuous, their (pointwise) maximum and minimum (defined by $x \mapsto \max\{f(x), g(x)\}$ and $x \mapsto \min\{f(x), g(x)\}$) are also lower semicontinuous. Consequently, the set of all lower semicontinuous functions from $X$ to $\overline{\mathbb{R}}$ (or to $\mathbb{R}$) forms a [lattice](wikipedia://en/469304). The corresponding statements also hold for upper semicontinuous functions.

### Optimization of semicontinuous functions {#Optimization_of_semicontinuous_functions}

- The (pointwise) [supremum](https://en.wikipedia.org/wiki/Supremum) of an arbitrary family $(f_i)_{i\in I}$ of lower semicontinuous functions $f_i:X\to\overline{\mathbb{R}}$ (defined by $f(x)=\sup\{f_i(x):i\in I\}$) is lower semicontinuous.[^o22]

In particular, the limit of a [monotone increasing](https://en.wikipedia.org/wiki/Monotone_increasing) sequence $f_1\le f_2\le f_3\le\cdots$ of continuous functions is lower semicontinuous. (The Theorem of Baire below provides a partial converse.) The limit function will only be lower semicontinuous in general, not continuous. An example is given by the functions $f_n(x)=1-(1-x)^n$ defined for $x\in[0,1]$ for $n=1,2,\ldots.$

Likewise, the [infimum](https://en.wikipedia.org/wiki/Infimum) of an arbitrary family of upper semicontinuous functions is upper semicontinuous. And the limit of a [monotone decreasing](https://en.wikipedia.org/wiki/Monotone_decreasing) sequence of continuous functions is upper semicontinuous.

- If $C$ is a [compact space](wikipedia://en/6042) (for instance a closed bounded interval $[a, b]$) and $f : C \to \overline{\mathbb{R}}$ is upper semicontinuous, then $f$ attains a maximum on $C.$ If $f$ is lower semicontinuous on $C,$ it attains a minimum on $C.$

(*Proof for the upper semicontinuous case*: By condition (5) in the definition, $f$ is continuous when $\overline{\mathbb{R}}$ is given the left order topology. So its image $f(C)$ is compact in that topology. And the compact sets in that topology are exactly the sets with a maximum. For an alternative proof, see the article on the [extreme value theorem](wikipedia://en/276881).)

### Other properties {#Other_properties}

- (**Theorem of Baire**)[^o24] Let $X$ be a [metric space](wikipedia://en/20018). Every lower semicontinuous function $f:X\to\overline{\mathbb{R}}$ is the limit of a point-wise [increasing](https://en.wikipedia.org/wiki/Monotone_increasing) sequence of extended real-valued continuous functions on $X.$ In particular, there exists a sequence $\{f_i\}$ of continuous functions $f_i : X \to \overline\mathbb{R}$ such that

$$f_i(x) \leq f_{i+1}(x) \quad \forall x \in X,\ \forall i = 0, 1, 2, \dots$$

and

$$\lim_{i \to \infty} f_i(x) = f(x) \quad \forall x \in X.$$

If $f$ does not take the value $-\infty$, the continuous functions can be taken to be real-valued.[^o25][^o26]

Additionally, every upper semicontinuous function $f:X\to\overline{\mathbb{R}}$ is the limit of a [monotone decreasing](https://en.wikipedia.org/wiki/Monotone_decreasing) sequence of extended real-valued continuous functions on $X;$ if $f$ does not take the value $\infty,$ the continuous functions can be taken to be real-valued.

- Any upper semicontinuous function $f : X \to \mathbb{N}$ on an arbitrary topological space $X$ is locally constant on some [dense open subset](wikipedia://en/23523594) of $X.$
- If the topological space $X$ is [sequential](wikipedia://en/4668395), then $f : X \to \mathbb{R}$ is upper semi-continuous if and only if it is sequentially upper semi-continuous, that is, if for any $x \in X$ and any sequence $(x_n)_n \subset X$ that converges towards $x$, there holds $\limsup_{n \to \infty} f(x_n) \leqslant f(x)$. Equivalently, in a sequential space, $f$ is upper semicontinuous if and only if its superlevel sets $\{\, x \in X \,|\, f(x) \geqslant y \,\}$ are [sequentially closed](wikipedia://en/28480560#Sequentially_open%2Fclosed_sets) for all $y \in \mathbb{R}$. In general, upper semicontinuous functions are sequentially upper semicontinuous, but the converse may be false.

:::

## Semicontinuity of set-valued functions {#Semicontinuity_of_set-valued_functions}

For [set-valued functions](wikipedia://en/12506030), several concepts of semicontinuity have been defined, namely *upper*, *lower*, *outer*, and *inner* semicontinuity, as well as *upper* and *lower [hemicontinuity](wikipedia://en/2945778)*. A set-valued function $F$ from a set $A$ to a set $B$ is written $F : A \rightrightarrows B.$ For each $x \in A,$ the function $F$ defines a set $F(x) \subset B.$ The [preimage](https://en.wikipedia.org/wiki/Preimage) of a set $S \subset B$ under $F$ is defined as

$$F^{-1}(S) :=\{x \in A: F(x) \cap S \neq \varnothing\}.$$

That is, $F^{-1}(S)$ is the set that contains every point $x$ in $A$ such that $F(x)$ is not [disjoint](wikipedia://en/39359) from $S$.[^o62]

### Upper and lower semicontinuity {#Upper_and_lower_semicontinuity}

A set-valued map $F: \mathbb{R}^m \rightrightarrows \mathbb{R}^n$ is *upper semicontinuous* at $x \in \mathbb{R}^m$ if for every open set $U \subset \mathbb{R}^n$ such that $F(x) \subset U$, there exists a neighborhood $V$ of $x$ such that $F(V) \subset U.$[^o62]

A set-valued map $F: \mathbb{R}^m \rightrightarrows \mathbb{R}^n$ is *lower semicontinuous* at $x \in \mathbb{R}^m$ if for every open set $U \subset \mathbb{R}^n$ such that $x \in F^{-1}(U),$ there exists a neighborhood $V$ of $x$ such that $V \subset F^{-1}(U).$[^o62]

Upper and lower set-valued semicontinuity are also defined more generally for a set-valued maps between topological spaces by replacing $\mathbb{R}^m$ and $\mathbb{R}^n$ in the above definitions with arbitrary topological spaces.[^o62]

Note, that there is not a direct correspondence between single-valued lower and upper semicontinuity and set-valued lower and upper semicontinuouty. An upper semicontinuous single-valued function is not necessarily upper semicontinuous when considered as a set-valued map.[^o62] For example, the function $f : \mathbb{R} \to \mathbb{R}$ defined by

$$f(x) = \begin{cases} -1 & \mbox{if } x < 0,\\ 1 & \mbox{if } x \geq 0 \end{cases}$$

is upper semicontinuous in the single-valued sense but the set-valued map $x \mapsto F(x) := \{f(x)\}$ is not upper semicontinuous in the set-valued sense.

### Inner and outer semicontinuity {#Inner_and_outer_semicontinuity}

A set-valued function $F: \mathbb{R}^m \rightrightarrows \mathbb{R}^n$ is called *inner semicontinuous* at $x$ if for every $y \in F(x)$ and every convergent sequence $(x_i)$ in $\mathbb{R}^m$ such that $x_i \to x$, there exists a sequence $(y_i)$ in $\mathbb{R}^n$ such that $y_i \to y$ and $y_i \in F\left(x_i\right)$ for all sufficiently large $i \in \mathbb{N}.$[^o63][^o30]

A set-valued function $F: \mathbb{R}^m \rightrightarrows \mathbb{R}^n$ is called *outer semicontinuous* at $x$ if for every convergence sequence $(x_i)$ in $\mathbb{R}^m$ such that $x_i \to x$ and every convergent sequence $(y_i)$ in $\mathbb{R}^n$ such that $y_i \in F(x_i)$ for each $i\in\mathbb{N},$ the sequence $(y_i)$ converges to a point in $F(x)$ (that is, $\lim _{i \to \infty} y_i \in F(x)$).[^o63]

## Hulls {#Hulls}

Because the supremum of a family of lower semicontinuous functions is lower semicontinuous, if $f$ is an arbitrary extended-real valued function on a topological space $X$, the supremum of the set of lower semicontinuous functions majorized by $f$ is lower semicontinuous. This greatest lower semicontinuous function majorized by $f$ is the lower semicontinuous *hull* of $f$.[^n4] The hull $H_f$ is defined pointwise by the relation[^n5]

$$H_f(x) = \liminf_{y\to x} f(y).$$

The hull $H_f$ has the property that its epigraph is the closure of the epigraph of $f$.

The lower semicontinuous hull plays a role in [convex analysis](wikipedia://en/3237201). Given a convex (extended real) function, the epigraph might not be closed. But the lower semicontinuous hull of a convex function is convex, and is known as the closure of the original convex function.

Some operations in convex analysis, such as the [Legendre transform](https://en.wikipedia.org/wiki/Legendre_transform) automatically produce closed convex functions. The Legendre transform applied twice to a convex function gives the closure of the original function, rather than the original function. Thus the lower semicontinuous hull is a way of regularizing convex functions, by modifying it at boundary points of its effective domain.

In [categorical terms](wikipedia://en/5869), the lower semicontinuous hull of a function $f$ is the (left) [Kan extension](wikipedia://en/2502518) of $f$ along the inclusion of the poset of open neighborhoods (ordered by reverse inclusion) into the topological space $X$. Explicitly, the value of the hull $H_f$ at a point $x \in X$ is given by the [colimit](https://en.wikipedia.org/wiki/Colimit):

$$(\mathrm{Lan}_\iota f)(x) = \inf_{U \ni x} \sup_{y \in U} f(y),$$

which coincides with $\liminf_{y \to x} f(y)$, the left Kan extension under the inclusion functor $\iota$. The upper semicontinuous hull is a right Kan extension.[^o34]

Other types of hulls are often considered in applications. For example, the infimum of the set of continuous [affine functions](https://en.wikipedia.org/wiki/Affine_function) that majorize a given function on a convex subset of a topological vector space is upper semicontinuous. This fact is used in the proof of the [Choquet theorem](https://en.wikipedia.org/wiki/Choquet_theorem).[^n6] Similar ideas applied to [subharmonic functions](wikipedia://en/3237359) are used in the [Perron method](wikipedia://en/26444076) for solving the [Dirichlet problem](wikipedia://en/571109) for the [Laplace operator](wikipedia://en/174706) in a domain. The key condition for the class of subharmonic solutions is upper semicontinuity, particularly near the boundary where the boundary conditions are applied.

## Applications {#Applications}

### Calculus of variations {#Calculus_of_variations}

An important application of semicontinuity is to the [calculus of variations](wikipedia://en/171882). It derives its significance in this context due to the following theorem.[^n7] Let $X$ be a topological space, and $F:X\to(-\infty,+\infty]$. A minimizing sequence is a sequence $x_k$ in $X$ such that

$$\lim_{k\to\infty}F(x_k) = \inf_X F.$$

The theorem is that if $F$ is sequentially lower semicontinuous and $x_k$ is a minimizing sequence that converges to $x_0$, then

$$F(x_0)= \inf_X F.$$

That is, $x_0$ is an absolute minimum of $F$.

This is often combined with results such as [Tonelli's theorem](wikipedia://en/11905171) in [functional analysis](wikipedia://en/11180), which characterizes the [weak](wikipedia://en/33662) lower semicontinuity of [nonlinear](https://en.wikipedia.org/wiki/Nonlinearity) [functionals](wikipedia://en/1374948) on [*L*<sup>*p*</sup> spaces](wikipedia://en/45194) in terms of the convexity of another function. More specialized results of this kind are useful in variational formulations of problems in [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations), which relate semicontinuity of functionals given by integration to the convexity properties of the integrand, often defined on some [Sobolev space](wikipedia://en/611964). The prototypical example is the [Dirichlet problem](wikipedia://en/571109) for the [Laplace operator](wikipedia://en/174706), which can be formulated as a minimization problem of the [energy](https://en.wikipedia.org/wiki/Energy), subject to [boundary conditions](https://en.wikipedia.org/wiki/Boundary_conditions),

$$F(u) = \int_\Omega |\nabla u|^2,$$

i.e., the integral of the squared norm of the gradient of a function over a bounded domain in Euclidean space. The integrand is convex in an appropriate Sobolev space, so the limit of a minimizing sequence is a solution of the Dirichlet problem. This has implications, for instance, for [finite element](https://en.wikipedia.org/wiki/Finite_element) solutions, which gives a way to construct a minimizing sequence.

### Existence of saddle points {#Existence_of_saddle_points}

Together with convexity assumptions, both upper and lower semicontinuity play a role in theorems guaranteeing the existence of [saddle points](wikipedia://en/640249) of functions, on [locally convex topological vector spaces](wikipedia://en/518844). One such result is the [minimax theorem of Fan and Sion](wikipedia://en/645602#Sion's_minimax_theorem).[^n8] It states that if $f:X\times Y\to\mathbb R$ is a function from a pair of non-empty closed, convex sets $X,Y$ belonging to [reflexive Banach spaces](https://en.wikipedia.org/wiki/Reflexive_Banach_space), such that

- $f(x,\cdot)$ is concave and upper semicontinuous for each $x\in X$ and
- $f(\cdot,y)$ is convex and lower semicontinuous for each $y\in Y$,

then the set of saddle points of $f$ is convex. If both convexity and concavity are strict, then there is at most one saddle point. If the sets $X$ and $Y$ are bounded, then the set of saddle points is non-empty. A saddle point is by definition a point $(x_0,y_0)$ at which

$$f(x_0,y_0) = \inf_{x\in X}\sup_{y\in Y}f(x,y) = \sup_{y\in Y}\inf_{x\in X}f(x,y).$$

### Dimension {#Dimension}

*Image: Hexagon dimension semicontinuous.svg.* Illustration of the face-dimension function $f$ on a [hexagon](wikipedia://en/59733) in the plane

Many integer-valued functions of importance are also semicontinuous. For a simple example, suppose one has a [polyhedron](wikipedia://en/23470) $K$ (or, more generally, a closed convex set) in an $n$-dimensional vector space. A face of $K$ is by definition the set of maxima of some linear functional on $K$. Define the function

$$f(x) = \inf\{\dim F| F \text{ is a face of }K\text{ and }x\in F\}.$$

Then $f$ is lower semicontinuous. This is intuitively because under any small perturbations, you can move from a face of lower dimension, such as an edge or vertex, to one of higher dimension, but any point of a higher dimensional face cannot be moved to one of lower dimension if the perturbation is small enough.

Another example of a similar character is that [matrix rank](https://en.wikipedia.org/wiki/Matrix_rank) is a lower semicontinuous function on the space of $n\times m$ matrices. This is because the rank can go up at matrices which are nearby, but not down. As a result of this, together with the [implicit function theorem](wikipedia://en/581005), when a [Lie group](wikipedia://en/17945) acts smoothly on a [smooth manifold](https://en.wikipedia.org/wiki/Smooth_manifold), the dimension of the orbit through a point is lower semicontinuous (i.e., the function $f(x)=\dim(G\cdot x)$).[^o43]

### Algebraic geometry {#Algebraic_geometry}

Semicontinuity theorem More sophisticated versions of this same idea play a fundamental role in [algebraic geometry](wikipedia://en/1997), where many dimension maps with codomain in the integers are known to be semicontinuous. (For example as applied to a [Newton–Okounkov body](https://en.wikipedia.org/wiki/Newton–Okounkov_body).)

In general, let $X$ and $S$ be [schemes](wikipedia://en/364754) and $f:X\to S$ a flat and proper morphism of finite presentation. Let $\mathcal{F}$ be an $\mathcal{O}_X$-module flat and of finite presentation over $S$. Then for any $i\in\mathbb{Z}$ the function

$$h^i:S\to\mathbb{Z}_{\geq 0}, s\mapsto\text{dim}_{\kappa(s)}H^i(X_s,\mathcal{F}_s)$$

is upper semicontinuous.[^o45] An important special case of this theorem when additionally $X, S$ are noetherian, $f$ is projective and $\mathcal{F}$ is coherent can be found in the standard textbook of [Hartshorne](wikipedia://en/5693379).[^o46] Original work in the language of hypercohomology can be found in [EGA III](wikipedia://en/471387) Théorème (7.7.5), citing also previous work, in particular [Grauert](wikipedia://en/2979031) for the complex-analytic setting.

Let $X, Y$ be schemes and $f:X\to Y$ a morphism of finite type. The function

$$n_{X/Y}:Y\to\mathbb{Z}_{\geq 0}\cup\{\infty\}, y\mapsto\text{dim}_{\text{top}}X_y$$

associates to any $y\in Y$ the dimension of the fiber $X_y$. If $f$ is a flat morphism of schemes of finite presentation, then $n_{X/Y}$ is lower semicontinuous.[^o48] If $f$ is a proper morphism of schemes, then $n_{X/Y}$ is upper semicontinuous.[^o49]

[Vakil](wikipedia://en/5981037) collected a list of further semicontinuity results in algebraic geometry.[^o50]

### Descriptive set theory {#Descriptive_set_theory}

Semicontinuous functions are used in [descriptive set theory](wikipedia://en/396619) to define stratifications of topological spaces by complexity measures such as *dimension*, *rank*, or *ordinal height*.[^o52][^o53][^o54] Such functions often take values in an [ordinal](wikipedia://en/26547932), and their semicontinuity ensures that the sets $\{x : f(x) \ge \alpha\}$ are closed (and hence [Borel](wikipedia://en/43327) in a [Polish space](wikipedia://en/396622)).

A central example is the rank function on well-founded trees. Let $\mathcal{T} \subseteq \omega^{<\omega}$ be a tree coded by a point in [Baire space](wikipedia://en/200550) $\omega^\omega$. The *rank* $\rho(\mathcal{T}) \in \omega_1 \cup \{\infty\}$ is defined as the supremum of the lengths of descending sequences in $\mathcal{T}$. The function assigning the rank $\rho(\mathcal{T})$ to each tree is *lower semicontinuous* with respect to the natural topology on tree codes. This rank stratifies the space of trees into closed sets $\{\mathcal{T} : \rho(\mathcal{T}) \ge \alpha\}$, analogous to how [matrix rank](https://en.wikipedia.org/wiki/Matrix_rank) stratifies $\mathbb{R}^{n \times m}$.

More generally, *ordinal-valued lower semicontinuous functions* are used to measure the complexity of points or structures in a [Polish space](wikipedia://en/396622)—such as [Scott ranks](https://en.wikipedia.org/wiki/Scott_rank) of countable structures, projective ranks of sets, or Lusin–Novikov complexities of equivalence relations. These functions enable fine classification and are crucial in defining [universal sets](https://en.wikipedia.org/wiki/Universal_set_%28descriptive_set_theory%29) and effective parametrizations in higher levels of the [projective hierarchy](wikipedia://en/1236542).

Because the preimage of an interval $[\alpha, \infty]$ under a lower semicontinuous function is closed, such functions yield *canonical stratifications* of topological spaces into closed (thus Borel) pieces of increasing complexity. This property is often used in proofs of [reflection principles](wikipedia://en/3225574), [separation theorems](wikipedia://en/6629185), and in the effective classification of [Borel equivalence relations](wikipedia://en/2123692).

### Dynamical systems {#Dynamical_systems}

In [ergodic theory](wikipedia://en/258986) and [topological dynamics](wikipedia://en/16379713), semicontinuity arises naturally when studying functionals on the space of [invariant measures](wikipedia://en/7635201) of a [dynamical system](wikipedia://en/9087). The most important example is the *entropy function*, which assigns to each invariant measure its [measure-theoretic entropy](https://en.wikipedia.org/wiki/Measure-theoretic_entropy).[^o56][^o57][^o58]

Let $(X, T)$ be a topological dynamical system with $X$ compact and $T : X \to X$ continuous. The space $\mathcal{M}_T(X)$ of $T$-invariant Borel probability measures is a compact convex subset of the dual of $C(X)$ under the weak-\* topology. The *entropy map* $\mu \mapsto h_\mu(T)$ is an *upper semicontinuous function* on $\mathcal{M}_T(X)$:

$$\limsup_{\mu_n \to \mu} h_{\mu_n}(T) \le h_\mu(T).$$

This property plays a key role in the [variational principle](wikipedia://en/491097), which asserts that the topological entropy $h_{\mathrm{top}}(T)$ is the supremum of $h_\mu(T)$ over all invariant measures. Upper semicontinuity guarantees that this supremum is attained when the space of measures is compact.

More generally, many functionals of interest—such as [Lyapunov exponents](wikipedia://en/166441), dimension spectra, or [return time](https://en.wikipedia.org/wiki/Return_time) statistics—are semicontinuous on the space of invariant measures. In some cases, these semicontinuity properties are used to prove existence of measures maximizing or minimizing a given quantity, or to establish structural properties of the [simplex](wikipedia://en/3655598) $\mathcal{M}_T(X)$ (e.g., that ergodic measures form a residual—dense $G_\delta$—set).

Similar ideas appear in the theory of [joinings](https://en.wikipedia.org/wiki/Joining_%28dynamical_systems%29), where one studies invariant couplings between systems. The set of joinings is compact in the weak-\* topology, and semicontinuity is used to analyze disjointness and uniqueness of invariant couplings.
