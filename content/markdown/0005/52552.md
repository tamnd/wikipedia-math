# Axiom of power set

*Image: Hasse diagram of powerset of 3.svg.* The elements of the power set of the set $\{x, y, z\}$ [ordered](wikipedia://en/361924) with respect to [inclusion](https://en.wikipedia.org/wiki/Inclusion_%28set_theory%29).

::: {#o1 .subject cue=lead name="Axiom of power set"}

In [mathematics](wikipedia://en/18831), the **axiom of power set**[^o2] is one of the [Zermelo–Fraenkel axioms](https://en.wikipedia.org/wiki/Zermelo–Fraenkel_axioms) of [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory). It guarantees for every set $x$ the existence of a set $\mathcal{P}(x)$, the [power set](wikipedia://en/23799) of $x$, consisting precisely of the [subsets](wikipedia://en/27631) of $x$. By the [axiom of extensionality](wikipedia://en/52376), the set $\mathcal{P}(x)$ is unique.

:::

The axiom of power set appears in most axiomatizations of set theory. It is generally considered uncontroversial, although [constructive set theory](wikipedia://en/5042360) prefers a weaker version to resolve concerns about [predicativity](https://en.wikipedia.org/wiki/Predicativity).

::: {#o4 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

The subset relation $\subseteq$ is not a [primitive notion](wikipedia://en/23706) in [formal set theory](https://en.wikipedia.org/wiki/Formal_set_theory) and is not used in the formal language of the Zermelo–Fraenkel axioms. Rather, the subset relation $\subseteq$ is defined in terms of [set membership](https://en.wikipedia.org/wiki/Set_membership), $\in$. Given this, in the [formal language](wikipedia://en/10939) of the Zermelo–Fraenkel axioms, the axiom of power set reads:

$$\forall x \, \exists y \, \forall z \, [z \in y \iff \forall w \, (w \in z \Rightarrow w \in x)]$$

where *y* is the power set of *x*, *z* is any element of *y*, *w* is any member of *z*.

In English, this says:

[Given any](https://en.wikipedia.org/wiki/Given_any) [set](wikipedia://en/26691) *x*, [there is](wikipedia://en/91420) a set *y* [such that](https://en.wikipedia.org/wiki/Such_that), given any set *z*, this set *z* is a member of *y* [if and only if](wikipedia://en/14922) every element of *z* is also an element of *x*.

:::

## Consequences {#Consequences}

The power set axiom allows a simple definition of the [Cartesian product](wikipedia://en/24104095) of two sets $X$ and $Y$:

$$X \times Y = \{ (x, y) : x \in X \land y \in Y \}.$$

Notice that

$$x, y \in X \cup Y$$

$$\{ x \}, \{ x, y \} \in \mathcal{P}(X \cup Y)$$

and, for example, considering a model using the [Kuratowski ordered pair](wikipedia://en/22362#Defining_the_ordered_pair_using_set_theory),

$$(x, y) = \{ \{ x \}, \{ x, y \} \} \in \mathcal{P}(\mathcal{P}(X \cup Y))$$

and thus the Cartesian product is a set since

$$X \times Y \subseteq \mathcal{P}(\mathcal{P}(X \cup Y)).$$

One may define the Cartesian product of any [finite](wikipedia://en/11742) [collection](wikipedia://en/20696) of sets recursively:

$$X_1 \times \cdots \times X_n = (X_1 \times \cdots \times X_{n-1}) \times X_n.$$

The existence of the Cartesian product can be proved without using the power set axiom, as in the case of the [Kripke–Platek set theory](wikipedia://en/1124695).

## Limitations {#Limitations}

The power set axiom does not specify what subsets of a set exist, only that there is a set containing all those that do.[^o7] Not all conceivable subsets are guaranteed to exist. In particular, the power set of an infinite set would contain only "constructible sets" if the universe is the [constructible universe](wikipedia://en/343335). But in other models of ZF, the universe could contain sets that are not constructible.[^o8]
