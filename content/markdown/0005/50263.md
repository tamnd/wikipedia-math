# Domain of a function

*Image: Codomain2.SVG.* A function $f$ from $X$ to $Y$. The set of points in the red oval $X$ is the domain of $f$. The set of points in the blue oval $Y$ is the codomain of $f$. The set of points in the yellow oval is the range of $f$.

*Image: Arcsine Arccosine.svg.* Graph of the arcsine and arccosine functions, *f*(*x*) = arcsin(*x*) and *f*(*x*) = arccos(*x*), each of whose domain consists of the set of real numbers \[–1,1\] inclusively

::: {#o1 .subject cue=lead name="Domain of a function"}

In [mathematics](wikipedia://en/18831), the **domain of a function** is the [set](wikipedia://en/26691) of inputs accepted by the [function](wikipedia://en/185427). It is sometimes denoted by $\operatorname{dom}(f)$ or $\operatorname{dom }f$, where $f$ is the function. In layman's terms, the domain of a function can generally be thought of as "what x can be".[^o2]

:::

More precisely, given a function $f\colon X\to Y$, the domain of $f$ is $X$. In modern mathematical language, the domain is part of the definition of a function rather than a property of it.

In the special case that $X$ and $Y$ are both sets of [real numbers](wikipedia://en/20646438), the function $f$ can be graphed in the [Cartesian coordinate system](wikipedia://en/7706). In this case, the domain is represented on the $x$-axis of the graph, as the projection of the graph of the function onto the $x$-axis.

For a function $f\colon X\to Y$, the set $Y$ is called the *[codomain](wikipedia://en/50264)*: the set to which all outputs must belong. The set of specific outputs the function assigns to elements of $X$ is called its *[range](wikipedia://en/275991)* or *[image](wikipedia://en/579311)*. The image of $f$ is a subset of $Y$, shown as the yellow oval in the accompanying diagram.

Any function can be restricted to a subset of its domain. The [restriction](wikipedia://en/1589032) of $f \colon X \to Y$ to $A$, where $A\subseteq X$, is written as $\left. f \right|_A \colon A \to Y$.

## Natural domain {#Natural_domain}

If a [real function](https://en.wikipedia.org/wiki/Real_function) $f$ is given by a formula, it may be not defined for some values of the variable. In this case, it is a *[partial function](wikipedia://en/23577)*, and the set of real numbers on which the formula can be evaluated to a real number is called the *natural domain* or *domain of definition* of $f$. In many contexts, a partial function is called simply a *function*, and its natural domain is called simply its *domain*.

::: {#o5 .example cue=heading name="Examples"}

### Examples {#Examples}

- The function $f$ defined by $f(x)=\frac{1}{x}$ cannot be evaluated at 0. Therefore, the natural domain of $f$ is the set of real numbers excluding 0, which can be denoted by $\mathbb{R} \setminus \{ 0 \}$ or $\{x\in\mathbb R:x\ne 0\}$.
- The [piecewise](https://en.wikipedia.org/wiki/Piecewise) function $f$ defined by $f(x) = \begin{cases} 1/x&x\not=0\\ 0&x=0 \end{cases},$ has as its natural domain the set $\mathbb{R}$ of real numbers.
- The [square root](wikipedia://en/29208) function $f(x)=\sqrt x$ has as its natural domain the set of non-negative real numbers, which can be denoted by $\mathbb R_{\geq 0}$, the interval $[0,\infty)$, or $\{x\in\mathbb R:x\geq 0\}$.
- The [tangent function](https://en.wikipedia.org/wiki/Tangent_function), denoted $\tan$, has as its natural domain the set of all real numbers which are not of the form $\tfrac{\pi}{2} + k \pi$ for some [integer](wikipedia://en/14563) $k$, which can be written as $\mathbb R \setminus \{\tfrac{\pi}{2}+k\pi: k\in\mathbb Z\}$.

:::

## Other uses {#Other_uses}

The term *domain* is also commonly used in a different sense in [mathematical analysis](wikipedia://en/48396): a *[domain](wikipedia://en/16796643)* is a [non-empty](wikipedia://en/9566) [connected](https://en.wikipedia.org/wiki/Connected_%28topology%29) [open set](wikipedia://en/39358) in a [topological space](wikipedia://en/30450). In particular, in [real](wikipedia://en/26478) and [complex analysis](wikipedia://en/5759), a *domain* is a non-empty connected open subset of the [real coordinate space](wikipedia://en/1482083) $\mathbb{R}^n$ or the [complex coordinate space](wikipedia://en/39125683) $\mathbb{C}^n.$

Sometimes such a domain is used as the domain of a function, although functions may be defined on more general sets. The two concepts are sometimes conflated as in, for example, the study of [partial differential equations](wikipedia://en/52564): in that case, a *domain* is the open connected subset of $\mathbb{R}^{n}$ where a problem is posed, making it both an analysis-style domain and also the domain of the unknown function(s) sought.

## Set theoretical notions {#Set_theoretical_notions}

For example, it is sometimes convenient in [set theory](wikipedia://en/27553) to permit the domain of a function to be a [proper class](wikipedia://en/20696) $X$, in which case there is formally no such thing as a triple $(X, Y, G)$. With such a definition, functions do not have a domain, although some authors still use it informally after introducing a function in the form $f: X \to Y$.[^o8]
