# Complement (set theory)

::: {#o1 .subject cue=lead name="Complement"}

In [set theory](wikipedia://en/27553), the **complement** of a [set](wikipedia://en/26691) $A$, often denoted by $A^c$ (or $A'$),[^o2] is the set of [elements](https://en.wikipedia.org/wiki/Element_%28mathematics%29) not in $A$.[^o3]

:::

When all elements in the [universe](https://en.wikipedia.org/wiki/Universe_%28set_theory%29), i.e. all elements under consideration, are considered to be [members](https://en.wikipedia.org/wiki/Element_%28mathematics%29) of a given set $U$, the **absolute complement** of $A$ is the set of elements in $U$ that are not in $A$.

The **relative complement** of $A$ with respect to a set $B$, also termed the **set difference** of $B$ and $A$, written $B \setminus A,$ is the set of elements in $B$ that are not in $A$.

## Absolute complement {#Absolute_complement}

*Image: Venn10.svg.* The **absolute complement** of the white disc is the red region

::: {#o6 .definition cue=heading name="Definition"}

### Definition {#Definition}

If $A$ is a set, then the **absolute complement** of $A$ (or simply the **complement** of $A$) is the set of elements not in $A$ (within a larger set that is implicitly defined). In other words, let $U$ be a set that contains all the elements under study; if there is no need to mention $U$, either because it has been previously specified, or it is obvious and unique, then the absolute complement of $A$ is the relative complement of $A$ in $U$:[^n1]

$$A^c= U \setminus A = \{ x \in U : x \notin A \}.$$

The absolute complement of $A$ is usually denoted by $A^c$.[^n1] Other notations include $\overline A$,[^n2] $A',$[^o3] $\complement_U A, \text{ and } \complement A.$[^o10]

:::

::: {#o12 .example cue=heading name="Examples"}

### Examples {#Examples}

- Assume that the universe is the set of [integers](wikipedia://en/14563). If $A$ is the set of odd numbers, then the complement of $A$ is the set of even numbers. If $B$ is the set of [multiples](wikipedia://en/3912709) of 3, then the complement of $B$ is the set of numbers [congruent](wikipedia://en/20087) to 1 or 2 modulo 3 (or, in simpler terms, the integers that are not multiples of 3).
- Assume that the universe is the [standard 52-card deck](https://en.wikipedia.org/wiki/Standard_52-card_deck). If the set $A$ is the suit of spades, then the complement of $A$ is the [union](wikipedia://en/47949) of the suits of clubs, diamonds, and hearts. If the set $B$ is the union of the suits of clubs and diamonds, then the complement of $B$ is the union of the suits of hearts and spades.
- When the universe is the [universe of sets](wikipedia://en/296838) described in formalized [set theory](wikipedia://en/27553), the absolute complement of a set is generally not itself a set, but rather a [proper class](https://en.wikipedia.org/wiki/Proper_class). For more info, see [universal set](wikipedia://en/303405).

:::

::: {#o14 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

Let $A$ and $B$ be two sets in a universe $U$. The following identities capture important properties of absolute complements:

[De Morgan's laws](wikipedia://en/64669):[^n1]

- $$\left(A \cup B \right)^c= A^c \cap B^c.$$
- $$\left(A \cap B \right)^c = A^c \cup B^c.$$

Complement laws:[^n1]

- $$A \cup A^c = U.$$
- $$A \cap A^c = \emptyset .$$
- $$\emptyset^c = U.$$
- $$U^c = \emptyset.$$
- $$\text{If }A\subseteq B\text{, then }B^c \subseteq A^c.$$

(this follows from the equivalence of a conditional with its [contrapositive](https://en.wikipedia.org/wiki/Contrapositive)).

[Involution](wikipedia://en/293450) or double complement law:

- $$\left(A^c\right)^c = A.$$

Relationships between relative and absolute complements:

- $$A \setminus B = A \cap B^c.$$
- $$(A \setminus B)^c = A^c \cup B = A^c \cup (B \cap A).$$

Relationship with a set difference:

- $$A^c \setminus B^c = B \setminus A.$$

The first two complement laws above show that if $A$ is a non-empty, [proper subset](https://en.wikipedia.org/wiki/Proper_subset) of $U$, then $\{A, A^{\text{∁}}\}$ is a [partition](wikipedia://en/340240) of $U$.

:::

## Relative complement {#Relative_complement}

::: {#o19 .definition cue=heading name="Definition"}

### Definition {#Definition}

If $A$ and $B$ are sets, then the **relative complement** of $A$ in $B$,[^n1] also termed the **set difference** of $B$ and $A$,[^n3] is the set of elements in $B$ but not in $A$.

*Image: Relative compliment.svg.* The **relative complement** of $A$ in $B$: $B \cap A^c = B \setminus A$

The relative complement of $A$ in $B$ is denoted $B \setminus A$ according to the [ISO 31-11 standard](wikipedia://en/3371683#Sets). It is sometimes written $B - A,$ but this notation can be ambiguous, as in some contexts (for example, [Minkowski set operations](wikipedia://en/504105) in [functional analysis](wikipedia://en/11180)) it can be interpreted as the set of all elements $b - a,$ where $b$ is taken from $B$ and $a$ from $A$.

Formally:

$$B \setminus A = \{ x\in B : x \notin A \}.$$

:::

::: {#o23 .example cue=heading name="Examples"}

### Examples {#Examples}

- $$\{ 1, 2, 3\} \setminus \{ 2,3,4\} = \{ 1 \}.$$
- $$\{ 2, 3, 4 \} \setminus \{ 1,2,3 \} = \{ 4 \} .$$
- If $\mathbb{R}$ is the set of [real numbers](wikipedia://en/20646438) and $\mathbb{Q}$ is the set of [rational numbers](wikipedia://en/19727024), then $\mathbb{R}\setminus\mathbb{Q}$ is the set of [irrational numbers](wikipedia://en/20647689).

:::

::: {#o25 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

Let $A$, $B$, and $C$ be three sets in a universe $U$. The following [identities](wikipedia://en/298428) capture notable properties of relative complements:

- $$C \setminus (A \cap B) = (C \setminus A) \cup (C \setminus B).$$
- $$C \setminus (A \cup B) = (C \setminus A) \cap (C \setminus B).$$
- $$C \setminus (B \setminus A) = (C \cap A) \cup (C \setminus B),$$

with the important special case $C \setminus (C \setminus A) = (C \cap A)$ demonstrating that intersection can be expressed using only the relative complement operation.

- $$(B \setminus A) \cap C = (B \cap C) \setminus A = B \cap (C \setminus A).$$
- $$(B \setminus A) \cup C = (B \cup C) \setminus (A \setminus C).$$
- $$A \setminus A = \emptyset.$$
- $$\emptyset \setminus A = \emptyset.$$
- $$A \setminus \emptyset = A.$$
- $$A \setminus U = \emptyset.$$
- If $A\subset B$, then $C\setminus A\supset C\setminus B$.
- $A \supseteq B \setminus C$ is equivalent to $C \supseteq B \setminus A$.

:::

::: {#o27 .pointer-item cue=pointer name="Complementary relation"}

## Complementary relation {#Complementary_relation}

A [binary relation](wikipedia://en/3931) $R$ is defined as a subset of a [product of sets](https://en.wikipedia.org/wiki/Product_of_sets) $X \times Y.$ The **complementary relation** $\bar{R}$ is the set complement of $R$ in $X \times Y.$ The complement of relation $R$ can be written

$$\bar{R} \ = \ (X \times Y) \setminus R.$$

Here, $R$ is often viewed as a [logical matrix](wikipedia://en/4109196) with rows representing the elements of $X,$ and columns elements of $Y.$ The truth of $aRb$ corresponds to 1 in row $a,$ column $b.$ Producing the complementary relation to $R$ then corresponds to switching all 1s to 0s, and 0s to 1s for the logical matrix of the complement.

Together with [composition of relations](wikipedia://en/7472170) and [converse relations](wikipedia://en/3941020), complementary relations and the [algebra of sets](wikipedia://en/961805) are the elementary [operations](wikipedia://en/4140245) of the [calculus of relations](https://en.wikipedia.org/wiki/Calculus_of_relations).

:::

## LaTeX notation {#LaTeX_notation}

In the [LaTeX](https://en.wikipedia.org/wiki/LaTeX) typesetting language, the command `\setminus`[^o29] is usually used for rendering a set difference symbol, which is similar to a [backslash](https://en.wikipedia.org/wiki/Backslash) symbol. When rendered, the `\setminus` command looks identical to `\backslash`, except that it has a little more space in front and behind the slash, akin to the LaTeX sequence `\mathbin{\backslash}`. A variant `\smallsetminus` is available in the amssymb package, but this symbol is not included separately in Unicode. The symbol $\complement$ (as opposed to $C$) is produced by `\complement`. (It corresponds to the Unicode symbol 2201.)
