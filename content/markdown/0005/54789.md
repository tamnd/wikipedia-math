# Recursively enumerable language

::: {#o1 .subject cue=lead name="Recursively enumerable language"}

In [mathematics](wikipedia://en/18831), [logic](wikipedia://en/46426065) and [computer science](https://en.wikipedia.org/wiki/Computer_science), a [formal language](wikipedia://en/10939) is called **recursively enumerable** (also **recognizable**, **partially decidable**, **semidecidable**, **Turing-acceptable** or **Turing-recognizable**) if it is a [recursively enumerable subset](https://en.wikipedia.org/wiki/Recursively_enumerable_set) in the [set](wikipedia://en/26691) of all possible words over the [alphabet](https://en.wikipedia.org/wiki/Alphabet_%28computer_science%29) of the language, i.e., if there exists a [Turing machine](wikipedia://en/30403) which will enumerate all valid strings of the language. These are generated by [unrestricted grammars](wikipedia://en/4906174).

:::

Recursively enumerable languages are known as **type-0** languages in the [Chomsky hierarchy](wikipedia://en/6011) of formal languages. All [regular](wikipedia://en/25723), [context-free](wikipedia://en/6759), [context-sensitive](wikipedia://en/6212) and [recursive](wikipedia://en/23290990) languages are recursively enumerable.

The class of all recursively enumerable languages is called **[RE](wikipedia://en/3106703)**.

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

There are three equivalent definitions of a recursively enumerable language:

1. A recursively enumerable language is a [recursively enumerable](https://en.wikipedia.org/wiki/Recursively_enumerable_set) [subset](wikipedia://en/27631) in the [set](wikipedia://en/26691) of all possible words over the [alphabet](https://en.wikipedia.org/wiki/Alphabet_%28computer_science%29) of the [language](wikipedia://en/10939).
1. A recursively enumerable language is a formal language for which there exists a [Turing machine](wikipedia://en/30403) (or other [computable function](wikipedia://en/1139338)) which will enumerate all valid strings of the language. Note that if the language is [infinite](wikipedia://en/20110824), the enumerating algorithm provided can be chosen so that it avoids repetitions, since we can test whether the string produced for number *n* is "already" produced for a number which is less than *n*. If it already is produced, use the output for input *n*+1 instead (recursively), but again, test whether it is "new".
1. A recursively enumerable language is a formal language for which there exists a Turing machine (or other computable function) that will halt and accept when presented with any [string](https://en.wikipedia.org/wiki/Literal_string) in the language as input but may either halt and reject or loop forever when presented with a string not in the language. Contrast this to [recursive languages](wikipedia://en/23290990), which require that the Turing machine halts in all cases.

All [regular](wikipedia://en/25723), [context-free](wikipedia://en/6867), [context-sensitive](wikipedia://en/6212) and [recursive](wikipedia://en/23290990) languages are recursively enumerable.

[Post's theorem](wikipedia://en/764468) shows that **[RE](wikipedia://en/3106703)**, together with its [complement](wikipedia://en/1929955) [co-RE](https://en.wikipedia.org/wiki/Co-RE), correspond to the first level of the [arithmetical hierarchy](wikipedia://en/186475).

:::

::: {#o5 .example cue=heading name="Example"}

## Example {#Example}

The set of [halting Turing machines](https://en.wikipedia.org/wiki/Halting_Problem) is recursively enumerable but not recursive. Indeed, one can run the Turing machine and accept if the machine halts, hence it is recursively enumerable. On the other hand, the problem is undecidable.

Some other recursively enumerable languages that are not recursive include:

- [Post correspondence problem](wikipedia://en/64685)
- [Mortality (computability theory)](https://en.wikipedia.org/wiki/Mortality_%28computability_theory%29)
- [Entscheidungsproblem](wikipedia://en/9672)

:::

## Closure properties {#Closure_properties}

Recursively enumerable languages (REL) are [closed](wikipedia://en/293802) under the following operations. That is, if *L* and *P* are two recursively enumerable languages, then the following languages are recursively enumerable as well:

- the [Kleene star](wikipedia://en/16750) $L^*$ of *L*
- the [concatenation](wikipedia://en/64474#Concatenation_of_sets_of_strings) $L \circ P$ of *L* and *P*
- the [union](wikipedia://en/47949) $L \cup P$
- the [intersection](wikipedia://en/23476429) $L \cap P$.

Recursively enumerable languages are not closed under [set difference](https://en.wikipedia.org/wiki/Set_difference) or complementation. The set difference $L - P$ is recursively enumerable if $P$ is recursive. If $L$ is recursively enumerable, then the complement of $L$ is recursively enumerable [if and only if](wikipedia://en/14922) $L$ is also recursive.
