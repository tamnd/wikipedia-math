# Monomorphism

*Image: Monomorphism scenarios.svg.* When $f$ is a monomorphism, the morphisms $g_1$ and $g_2$ are equal if and only if their compositions with $f$ are.

::: {#o1 .subject cue=lead name="Monomorphism"}

In the context of [abstract algebra](wikipedia://en/19616384) or [universal algebra](wikipedia://en/45200), a **monomorphism** is an [injective](wikipedia://en/45196) [homomorphism](wikipedia://en/13564). A monomorphism from $X$ to $Y$ is often denoted with the notation $X\hookrightarrow Y$.

:::

In the more general setting of [category theory](wikipedia://en/5869), a **monomorphism** (also called a **monic morphism** or a **mono**) is a [left-cancellative](https://en.wikipedia.org/wiki/Left-cancellative) [morphism](wikipedia://en/27716891). That is, an arrow $f : X \to Y$ such that for all objects $Z$ and all morphisms $g_{1}, g_{2}: Z \to X$,

$$f \circ g_1 = f \circ g_2 \implies g_1 = g_2.$$

*Image: Monomorphism\_pullback\_square.png.* The pullback of a monomorphism $f$ with itself is trivial.

Monomorphisms are a categorical generalization of [injective functions](wikipedia://en/45196) (also called "one-to-one functions"); in some categories the notions coincide, but monomorphisms are more general, as in the examples below.

In the setting of [posets](wikipedia://en/23572) intersections are [idempotent](wikipedia://en/14972): the intersection of anything with itself is itself. Monomorphisms generalize this property to arbitrary categories. A morphism is a monomorphism if it is idempotent with respect to [pullbacks](wikipedia://en/841689).

The [categorical dual](https://en.wikipedia.org/wiki/Categorical_dual) of a monomorphism is an [epimorphism](wikipedia://en/59539), that is, a monomorphism in a category *C* is an epimorphism in the [dual category](https://en.wikipedia.org/wiki/Dual_category) *C*<sup>op</sup>. Every [section](wikipedia://en/10630303) is a monomorphism, and every [retraction](https://en.wikipedia.org/wiki/Retract_%28category_theory%29) is an epimorphism.

## Relation to invertibility {#Relation_to_invertibility}

Left-invertible morphisms are necessarily monic: if *l* is a left inverse for *f* (meaning *l* is a morphism and $l \circ f = \operatorname{id}_{X}$), then *f* is monic, as

$$f \circ g_1 = f \circ g_2 \Rightarrow l\circ f\circ g_1 = l\circ f\circ g_2 \Rightarrow g_1 = g_2.$$

A left-invertible morphism is called a [section](wikipedia://en/10630303) or a split monomorphism.

However, a monomorphism need not be left-invertible. For example, in the category **Group** of all [groups](wikipedia://en/19447) and [group homomorphisms](wikipedia://en/12396) among them, if *H* is a subgroup of *G* then the inclusion *f* : *H* → *G* is always a monomorphism; but *f* has a left inverse in the category if and only if *H* has a [normal complement](wikipedia://en/11436087) in *G*.

A morphism *f* : *X* → *Y* is monic if and only if the induced map *f*<sub>∗</sub> : Hom(*Z*, *X*) → Hom(*Z*, *Y*), defined by *f*<sub>∗</sub>(*h*) = *f* ∘ *h* for all morphisms *h* : *Z* → *X*, is [injective](https://en.wikipedia.org/wiki/Injective) for all objects *Z*.

::: {#o4 .example cue=heading name="Examples"}

## Examples {#Examples}

Every morphism in a [concrete category](wikipedia://en/167001) whose underlying [function](wikipedia://en/185427) is injective is a monomorphism; in other words, if morphisms are actually functions between sets, then any morphism which is a one-to-one function will necessarily be a monomorphism in the categorical sense. In the [category of sets](wikipedia://en/26829) the converse also holds, so the monomorphisms are exactly the [injective](https://en.wikipedia.org/wiki/Injective) morphisms. The converse also holds in most naturally occurring categories of algebras because of the existence of a [free object](wikipedia://en/333835) on one generator. In particular, it is true in the categories of all groups, of all [rings](wikipedia://en/48404), and in any [abelian category](wikipedia://en/45063).

It is not true in general, however, that all monomorphisms must be injective in other categories; that is, there are settings in which the morphisms are functions between sets, but one can have a function that is not injective and yet is a monomorphism in the categorical sense. For example, in the category **Div** of [divisible](wikipedia://en/472147) [(abelian) groups](wikipedia://en/2974) and [group homomorphisms](wikipedia://en/12396) between them there are monomorphisms that are not injective: consider, for example, the quotient map *q* : **Q** → **Q**/**Z**, where **Q** is the rationals under addition, **Z** the integers (also considered a group under addition), and **Q**/**Z** is the corresponding [quotient group](wikipedia://en/11526). This is not an injective map, as for example every integer is mapped to 0. Nevertheless, it is a monomorphism in this category. This follows from the implication *q* ∘ *h* = 0 ⇒ *h* = 0, which we will now prove. If *h* : *G* → **Q**, where *G* is some divisible group, and *q* ∘ *h* = 0, then *h*(*x*) ∈ **Z**, ∀ *x* ∈ *G*. Now fix some *x* ∈ *G*. Without loss of generality, we may assume that *h*(*x*) ≥ 0 (otherwise, choose −*x* instead). Then, letting *n* = *h*(*x*) + 1, since *G* is a divisible group, there exists some *y* ∈ *G* such that *x* = *ny*, so *h*(*x*) = *n* *h*(*y*). From this, and 0 ≤ *h*(*x*) \< *h*(*x*) + 1 = *n*, it follows that

$$0 \leq \frac{h(x)}{h(x) + 1} = h(y) < 1$$

Since *h*(*y*) ∈ **Z**, it follows that *h*(*y*) = 0, and thus *h*(*x*) = 0 = *h*(−*x*), ∀ *x* ∈ *G*. This says that *h* = 0, as desired.

To go from that implication to the fact that *q* is a monomorphism, assume that *q* ∘ *f* = *q* ∘ *g* for some morphisms *f*, *g* : *G* → **Q**, where *G* is some divisible group. Then *q* ∘ (*f* − *g*) = 0, where (*f* − *g*) : *x* ↦ *f*(*x*) − *g*(*x*). (Since (*f* − *g*)(0) = 0, and (*f* − *g*)(*x* + *y*) = (*f* − *g*)(*x*) + (*f* − *g*)(*y*), it follows that (*f* − *g*) ∈ Hom(*G*, **Q**)). From the implication just proved, *q* ∘ (*f* − *g*) = 0 ⇒ *f* − *g* = 0 ⇔ ∀ *x* ∈ *G*, *f*(*x*) = *g*(*x*) ⇔ *f* = *g*. Hence *q* is a monomorphism, as claimed.

## Properties {#Properties}

- In an [elementary topos](wikipedia://en/815802), every mono is an equalizer, and any map that is both monic and [epic](https://en.wikipedia.org/wiki/Epic_morphism) is an [isomorphism](https://en.wikipedia.org/wiki/Isomorphism_%28category_theory%29).
- Every isomorphism is monic.

## Related concepts {#Related_concepts}

*Image: Diagram-orthogonality-2.svg.* Diagram visualizing a strong monomorphism $\mu$.

There are also useful concepts of *regular monomorphism*, *extremal monomorphism*, *immediate monomorphism*, *strong monomorphism*, and *split monomorphism*.

- A monomorphism is said to be **regular** if it is an [equalizer](wikipedia://en/310767) of some pair of parallel morphisms.
- A monomorphism $\mu$ is said to be **extremal**[^n1] if in each representation $\mu=\varphi\circ\varepsilon$, where $\varepsilon$ is an epimorphism, the morphism $\varepsilon$ is automatically an [isomorphism](wikipedia://en/14828).
- A monomorphism $\mu$ is said to be **immediate** if in each representation $\mu=\mu'\circ\varepsilon$, where $\mu'$ is a monomorphism and $\varepsilon$ is an epimorphism, the morphism $\varepsilon$ is automatically an [isomorphism](wikipedia://en/14828).
- A monomorphism $\mu:C\to D$ is said to be **strong**[^n1][^n2] if for any epimorphism $\varepsilon:A\to B$ and any morphisms $\alpha:A\to C$ and $\beta:B\to D$ such that $\beta\circ\varepsilon=\mu\circ\alpha$, there exists a morphism $\delta:B\to C$ such that $\delta\circ\varepsilon=\alpha$ and $\mu\circ\delta=\beta$.
- A monomorphism $\mu$ is said to be **split** if there exists a morphism $\varepsilon$ such that $\varepsilon\circ\mu=1$ (in this case $\varepsilon$ is called a left-sided inverse for $\mu$).

:::

## Terminology {#Terminology}

The companion terms *monomorphism* and *epimorphism* were originally introduced by [Nicolas Bourbaki](wikipedia://en/167394); Bourbaki uses *monomorphism* as shorthand for an injective function. Early category theorists believed that the correct generalization of injectivity to the context of categories was the cancellation property given above. While this is not exactly true for monic maps, it is very close, so this has caused little trouble, unlike the case of epimorphisms. [Saunders Mac Lane](wikipedia://en/336574) attempted to make a distinction between what he called *monomorphisms*, which were maps in a concrete category whose underlying maps of sets were injective, and *monic maps*, which are monomorphisms in the categorical sense of the word. This distinction never came into general use.

In adjectival form, a monomorphism is said to be monic; in common shorthand, it is also called a mono.
