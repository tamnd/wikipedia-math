# Horizontal line test

::: {#o1 .subject cue=lead name="Horizontal line test"}

In [mathematics](wikipedia://en/18831), the **horizontal line test** is a test used to determine whether a [function](wikipedia://en/185427) is [injective](https://en.wikipedia.org/wiki/Injective) (i.e., one-to-one).[^o2]

:::

## In calculus {#In_calculus}

A *horizontal line* is a straight, flat line that goes from left to right. Given a function $f \colon \mathbb{R} \to \mathbb{R}$ (i.e. from the [real numbers](https://en.wikipedia.org/wiki/Real_numbers) to the real numbers), we can decide if it is [injective](https://en.wikipedia.org/wiki/Injective) by looking at horizontal lines that intersect the function's [graph](wikipedia://en/87352). If any horizontal line $y=c$ intersects the graph in more than one point, the function is not injective. To see this, note that the points of intersection have the same y-value (because they lie on the line $y=c$) but different x values, which by definition means the function cannot be injective.[^o2]

| *Image: Horizontal-test-ok.png.* Passes the test (injective) | *Image: Horizontal-test-fail.png.* Fails the test (not injective) |
|---|---|

Variations of the horizontal line test can be used to determine whether a function is [surjective](https://en.wikipedia.org/wiki/Surjective) or [bijective](https://en.wikipedia.org/wiki/Bijective):

- The function *f* is surjective (i.e., onto) [if and only if](wikipedia://en/14922) its graph intersects any horizontal line at **least** once.
- *f* is bijective if and only if any horizontal line will intersect the graph **exactly** once.

## In set theory {#In_set_theory}

Consider a function $f \colon X \to Y$ with its corresponding [graph](wikipedia://en/87352) as a subset of the [Cartesian product](wikipedia://en/24104095) $X \times Y$. Consider the horizontal lines in $X \times Y$ :$\{(x,y_0) \in X \times Y: y_0 \text{ is constant}\} = X \times \{y_0\}$. The function *f* is [injective](https://en.wikipedia.org/wiki/Injective) [if and only if](wikipedia://en/14922) each horizontal line intersects the graph at most once. In this case the graph is said to pass the horizontal line test. If any horizontal line intersects the graph more than once, the function fails the horizontal line test and is not injective.[^o5]
