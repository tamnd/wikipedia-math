# Axiom of union

::: {#o1 .subject cue=lead name="Axiom of union"}

In [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), the **axiom of union** is one of the [axioms](wikipedia://en/928) of [Zermelo–Fraenkel set theory](wikipedia://en/152214). This axiom was introduced by [Ernst Zermelo](wikipedia://en/178655).

:::

Informally, the axiom states that if $X$ is a [set](wikipedia://en/26691) of sets, then the [union](wikipedia://en/47949#Arbitrary_union) of all sets in $X$ is still a set. In more basic terms, for each set $X$ there is a set $Y$ whose elements are precisely the elements of the elements of $X$.

::: {#o3 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

In the [formal language](wikipedia://en/10939) of the Zermelo–Fraenkel axioms, the axiom reads:[^o4]

$$\forall X\, \exists Y\, \forall u\, (u \in Y \leftrightarrow \exists z\, (u \in z \land z \in X))$$

or in words:

[Given any](https://en.wikipedia.org/wiki/Given_any) [set](wikipedia://en/26691) *X*, [there is](wikipedia://en/91420) a set *Y* such that, for any element *u*, *u* [is a member of](https://en.wikipedia.org/wiki/Element_%28set_theory%29) *Y* [if and only if](wikipedia://en/14922) there is a set *z* such that *u* is a member of *z* [and](wikipedia://en/18152) *z* is a member of *X*.

or, more simply:

For any set $X$, there is a set $\bigcup X$ which consists of just the elements of the elements of that set $X$.

:::

## Consequences {#Consequences}

The axiom of union allows one to unpack a set of sets and thus create a flatter set. Together with the [axiom of pairing](wikipedia://en/52385), it implies that for any two sets $A$ and $B$, their [binary union](wikipedia://en/47949#Union_of_two_sets) $A \cup B$ is also a set.

Together with the [axiom schema of replacement](wikipedia://en/52387), the axiom of union implies that one can form the union of a [family](wikipedia://en/23624339) of sets indexed by a set.

The axiom of union is often used to construct the [limit](wikipedia://en/343663) of an infinite sequence of sets $X_0 \subseteq X_1 \subseteq X_2 \subseteq \cdots$. For example, it can be used to construct the [supremum](https://en.wikipedia.org/wiki/Supremum) of any set of [ordinal numbers](wikipedia://en/26547932).[^o8]

## Weaker form {#Weaker_form}

In the context of set theories which include the [axiom schema of separation](https://en.wikipedia.org/wiki/Axiom_schema_of_separation), the axiom of union is sometimes stated in a weaker form which only produces a [superset](https://en.wikipedia.org/wiki/Superset) of the union of a set. For example, Kunen states the axiom as

$$\forall \mathcal{F} \,\exists A \, \forall Y\, \forall x [(x \in Y \land Y \in \mathcal{F}) \Rightarrow x \in A]$$

to facilitate its verification in various [models](https://en.wikipedia.org/wiki/Model_%28mathematical_logic%29). This form is logically equivalent to

$$\forall \mathcal{F} \,\exists A \forall x [ [\exists Y (x \in Y \land Y \in \mathcal{F}) ] \Rightarrow x \in A].$$

Compared to the axiom stated at the top of this section, this variation asserts only one direction of the implication, rather than both directions.

## Independence {#Independence}

In its full generality, the axiom of union is [independent](wikipedia://en/1141208) from the rest of the ZFC-axioms. It is the only axiom that asserts the existence of [singular](https://en.wikipedia.org/wiki/Singular_cardinal) [strong limit cardinals](https://en.wikipedia.org/wiki/Strong_limit_cardinal) such as $\beth_\omega$ ([beth-omega](wikipedia://en/393359), the limit of the sequence $\aleph_0, 2^{\aleph_0}, 2^{2^{\aleph_0} }, \ldots$). Concretely, if $\kappa$ is a singular strong limit cardinal, then the set of sets $X$ such that $\vert X \vert < \kappa$ and $\vert y \vert < \kappa$ for all $y$ in the [transitive closure](wikipedia://en/292239) of $X$ forms a [model](https://en.wikipedia.org/wiki/Model_%28mathematical_logic%29) of $\text{ZFC} - \text{Union}$ (the ZFC axioms minus the axiom of union).[^o8]

However, many results in ZF(C) remain valid even without the axiom of union. The [axiom schema of replacement](wikipedia://en/52387) allows one to form a union if one can construct a set of the same or larger [cardinality](wikipedia://en/6174), together with a definable surjection from it onto that union, which can often be achieved with the [axiom of power set](wikipedia://en/52552). For example, the binary union $A \cup B$ can be constructed when the cardinalities $\vert A \vert$ and $\vert B \vert$ are [comparable](wikipedia://en/3834818), since without loss of generality one can assume that $\vert A \vert \le \vert B \vert$ and $2 \le \vert B \vert$, and then

$$|A \cup B| \le |A| + |B| \le 2 \cdot |B| \le |B| \cdot |B| = |B \times B| \le |\mathcal{P}(\mathcal{P}(B))|$$

where the final inequality follows from the [definition of the Cartesian product](wikipedia://en/24104095#Set-theoretic_definition) using the [Kuratowski ordered pair](https://en.wikipedia.org/wiki/Kuratowski_ordered_pair).

Assuming the [axiom of choice](wikipedia://en/840), the [well-ordering theorem](wikipedia://en/33458) can be proved without the axiom of union, which can be used to show that $\bigcup X$ exists *as long as the cardinalities of all sets in $X$ are bounded*. This condition is always true for finite unions, or more generally when $X$ only contains sets with a finite number of infinite cardinalities. Conversely, assuming the consistency of ZF, there exists a model of $\text{ZFC} - \text{Union}$ such that $\bigcup X$ *never* exists when $X$ contains sets with an infinite number of infinite cardinalities.[^o8]

## Relation to Intersection {#Relation_to_Intersection}

There is no corresponding axiom of [intersection](wikipedia://en/23476429). If $A$ is a *nonempty* set containing $E$, it is possible to form the intersection $\bigcap A$ using the [axiom schema of specification](wikipedia://en/52386) as

$$\bigcap A = \{c\in E:\forall D(D\in A\Rightarrow c\in D)\},$$

so no separate axiom of intersection is necessary. (If *A* is the [empty set](wikipedia://en/9566), then trying to form the intersection of *A* as

{*c*: for all *D* in *A*, *c* is in *D*}

is not permitted by the axioms. Moreover, if such a set existed, then it would contain every set in the "universe", but the notion of a [universal set](wikipedia://en/303405) is antithetical to Zermelo–Fraenkel set theory.)
