# Linear span

*Image: Basis for a plane.svg.* The cross-hatched plane is the linear span of **u** and **v** in both **R**<sup>2</sup> and **R**<sup>3</sup>, here shown in [perspective](wikipedia://en/380405).

::: {#o1 .subject cue=lead name="Linear span"}

In [mathematics](wikipedia://en/18831), the **linear span** (also called the **linear hull**[^o2] or just **span**) of a [set](wikipedia://en/26691) $S$ of elements of a [vector space](wikipedia://en/32370) $V$ is the smallest [linear subspace](wikipedia://en/56357) of $V$ that contains $S.$ It is the set of all finite [linear combinations](wikipedia://en/55632) of the elements of $S$,[^o3] and the intersection of all linear subspaces that contain $S.$ It is often denoted $\operatorname{span}(S)$[^o4] or $\langle S \rangle.$

:::

For example, in [geometry](wikipedia://en/18973446), two [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent) [vectors](https://en.wikipedia.org/wiki/Vector_%28geometry%29) span a [plane](https://en.wikipedia.org/wiki/Plane_%28geometry%29).

To express that a vector space $V$ is a linear span of a subset $S$, one commonly uses one of the following phrases: $S$ spans $V$; $S$ is a **spanning set** of $V$; $V$ is spanned or [generated](wikipedia://en/3171371) by $S$; $S$ is a generator set or a generating set of $V$.

Spans can be generalized to many [mathematical structures](wikipedia://en/1809181), in which case, the smallest substructure containing $S$ is generally called the substructure *generated* by $S.$

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a [vector space](wikipedia://en/32370) $V$ over a [field](wikipedia://en/10603) $K$, the span of a [set](wikipedia://en/26691) $S$ of vectors (not necessarily finite) is defined to be the intersection $W$ of all [subspaces](wikipedia://en/56357) of $V$ that contain $S$. It is thus the smallest (for [set inclusion](https://en.wikipedia.org/wiki/Set_inclusion)) subspace containing $S$. It is referred to as the subspace *spanned by* $S$, or by the vectors in $S$. Conversely, $S$ is called a *spanning set* of $W$, and we say that $S$ *spans* $W$.

It follows from this definition that the span of $S$ is the set of all finite [linear combinations](https://en.wikipedia.org/wiki/Linear_combinations) of elements (vectors) of $S$, and can be defined as such.[^o7][^o8][^o9] That is,

$$\operatorname{span}(S) = \biggl \{ \lambda_1 \mathbf v_1 + \lambda_2 \mathbf v_2 + \cdots + \lambda_n \mathbf v_n \mid n \in \mathbb{N},\; \mathbf v_1,...,\mathbf v_n \in S, \; \lambda_1,...,\lambda_n \in K \biggr \}$$

When $S$ is [empty](wikipedia://en/9566), the only possibility is $n = 0$, and the previous expression for $\operatorname{span}(S)$ reduces to the [empty sum](wikipedia://en/209748). The standard convention for the empty sum implies thus $\text{span}(\emptyset) = \{\mathbf 0\},$ a property that is immediate with the other definitions. However, many introductory textbooks simply include this fact as part of the definition.

When $S=\{\mathbf v_1,\ldots, \mathbf v_n\}$ is [finite](wikipedia://en/11742), one has

$$\operatorname{span}(S) = \{ \lambda_1 \mathbf v_1 + \lambda_2 \mathbf v_2 + \cdots + \lambda_n \mathbf v_n \mid \lambda_1,...,\lambda_n \in K \}$$

:::

::: {#o11 .example cue=heading name="Examples"}

## Examples {#Examples}

The [real](wikipedia://en/20646438) vector space $\mathbb R^3$ has {(−1, 0, 0), (0, 1, 0), (0, 0, 1)} as a spanning set. This particular spanning set is also a [basis](wikipedia://en/18420). If (−1, 0, 0) were replaced by (1, 0, 0), it would also form the [canonical basis](wikipedia://en/462005) of $\mathbb R^3$.

Another spanning set for the same space is given by {(1, 2, 3), (0, 1, 2), (−1, $\tfrac{1}{2}$, 3), (1, 1, 1)}, but this set is not a basis, because it is [linearly dependent](https://en.wikipedia.org/wiki/Linear_dependency).

The set $\{(1, 0, 0), (0, 1, 0), (1, 1, 0)$} is not a spanning set of $\mathbb R^3$, since its span is the space of all vectors in $\mathbb R^3$ whose last component is zero. That space is also spanned by the set {(1, 0, 0), (0, 1, 0)}, as (1, 1, 0) is a linear combination of (1, 0, 0) and (0, 1, 0). Thus, the spanned space is not $\mathbb R^3.$ It can be identified with $\mathbb R^2$ by removing the third components equal to zero.

The empty set is a spanning set of {(0, 0, 0)}, since the empty set is a subset of all possible vector spaces in $\mathbb R^3$, and {(0, 0, 0)} is the intersection of all of these vector spaces.

The set of [monomials](wikipedia://en/357416) $x^{n}$, where $n$ is a non-negative integer, spans the space of [polynomials](wikipedia://en/23000).

:::

## Theorems {#Theorems}

### Equivalence of definitions {#Equivalence_of_definitions}

The set of all linear combinations of a subset $S$ of $V$, a vector space over $K$, is the smallest linear subspace of $V$ containing $S$.

*Proof.* We first prove that $\operatorname{span} S$ is a subspace of $V$. Since $S$ is a subset of $V$, we only need to prove the existence of a zero vector $\mathbf{0}$ in $\operatorname{span} S$, that $\operatorname{span} S$ is closed under addition, and that $\operatorname{span} S$ is closed under scalar multiplication. Letting $S = \{ \mathbf v_1, \mathbf v_2, \ldots, \mathbf v_n \}$, it is trivial that the zero vector of $V$ exists in $\operatorname{span} S$, since $\mathbf 0 = 0 \mathbf v_1 + 0 \mathbf v_2 + \cdots + 0 \mathbf v_n$. Adding together two linear combinations of $S$ also produces a linear combination of $S$: $(\lambda_1 \mathbf v_1 + \cdots + \lambda_n \mathbf v_n) + (\mu_1 \mathbf v_1 + \cdots + \mu_n \mathbf v_n) = (\lambda_1 + \mu_1) \mathbf v_1 + \cdots + (\lambda_n + \mu_n) \mathbf v_n$, where all $\lambda_i, \mu_i \in K$, and multiplying a linear combination of $S$ by a scalar $c \in K$ will produce another linear combination of $S$: $c(\lambda_1 \mathbf v_1 + \cdots + \lambda_n \mathbf v_n) = c\lambda_1 \mathbf v_1 + \cdots + c\lambda_n \mathbf v_n$. Thus $\operatorname{span} S$ is a subspace of $V$.

It follows that $S \subseteq \operatorname{span} S$, since every $\mathbf{v}_{i}$ is a linear combination of $S$ (trivially). Suppose that $W$ is a linear subspace of $V$ containing $S$. Since $W$ is closed under addition and scalar multiplication, then every linear combination $\lambda_1 \mathbf v_1 + \cdots + \lambda_n \mathbf v_n$ must be contained in $W$. Thus, $\operatorname{span} S$ is contained in every subspace of $V$ containing $S$, and the intersection of all such subspaces, or the smallest such subspace, is equal to the set of all linear combinations of $S$.

### Size of spanning set is at least size of linearly independent set {#Size_of_spanning_set_is_at_least_size_of_linearly_independent_set}

Every spanning set $S$ of a vector space $V$ must contain at least as many elements as any [linearly independent](wikipedia://en/101863) set of vectors from $V$.

*Proof.* Let $S = \{ \mathbf v_1, \ldots, \mathbf v_m \}$ be a spanning set and $W = \{ \mathbf w_1, \ldots, \mathbf w_n \}$ be a linearly independent set of vectors from $V$. We want to show that $m \geq n$.

Since $S$ spans $V$, then $S \cup \{ \mathbf w_1 \}$ must also span $V$, and $\mathbf w_1$ must be a linear combination of $S$. Thus $S \cup \{ \mathbf w_1 \}$ is linearly dependent, and we can remove one vector from $S$ that is a linear combination of the other elements. This vector cannot be any of the $\mathbf{w}_{i}$, since $W$ is linearly independent. The resulting set is $\{ \mathbf w_1, \mathbf v_1, \ldots, \mathbf v_{i-1}, \mathbf v_{i+1}, \ldots, \mathbf v_m \}$, which is a spanning set of $V$. We repeat this step $n$ times, where the resulting set after the $p$th step is the union of $\{ \mathbf w_1, \ldots, \mathbf w_p \}$ and $m - p$ vectors of $S$.

It is ensured until the $n$th step that there will always be some $\mathbf{v}_{i}$ to remove out of $S$ for every adjoint of $\mathbf{v}$, and thus there are at least as many $\mathbf{v}_{i}$'s as there are $\mathbf{w}_{i}$'s—i.e. $m \geq n$. To verify this, we assume by way of contradiction that $m < n$. Then, at the $m$th step, we have the set $\{ \mathbf w_1, \ldots, \mathbf w_m \}$ and we can adjoin another vector $\mathbf w_{m+1}$. But, since $\{ \mathbf w_1, \ldots, \mathbf w_m \}$ is a spanning set of $V$, $\mathbf w_{m+1}$ is a linear combination of $\{ \mathbf w_1, \ldots, \mathbf w_m \}$. This is a contradiction, since $W$ is linearly independent.

### Spanning set can be reduced to a basis {#Spanning_set_can_be_reduced_to_a_basis}

Let $V$ be a finite-dimensional vector space. Any set of vectors that spans $V$ can be reduced to a [basis](wikipedia://en/18420) for $V$, by discarding vectors if necessary (i.e. if there are linearly dependent vectors in the set). If the [axiom of choice](wikipedia://en/840) holds, this is true without the assumption that $V$ has finite dimension. This also indicates that a basis is a minimal spanning set when $V$ is finite-dimensional.

## Generalizations {#Generalizations}

Generalizing the definition of the span of points in space, a subset $X$ of the ground set of a [matroid](wikipedia://en/244321) is called a spanning set if the rank of $X$ equals the rank of the entire ground set[^n1]

The vector space definition can also be generalized to modules.[^o20][^o21] Given an $R$-module $A$ and a collection of elements $a_{1}$, ..., $a_{n}$ of $A$, the [submodule](https://en.wikipedia.org/wiki/Submodule) of $A$ spanned by $a_{1}$, ..., $a_{n}$ is the sum of [cyclic modules](wikipedia://en/4128720)

$$Ra_1 + \cdots + Ra_n = \left\{ \sum_{k=1}^n r_k a_k \bigg| r_k \in R \right\}$$

consisting of all *R*-linear combinations of the elements $a_{i}$. As with the case of vector spaces, the submodule of *A* spanned by any subset of *A* is the intersection of all submodules containing that subset.

:::

## Closed linear span (functional analysis) {#Closed_linear_span_(functional_analysis)}

In [functional analysis](wikipedia://en/11180), a closed linear span of a [set](wikipedia://en/26691) of [vectors](wikipedia://en/32370) is the minimal closed set which contains the linear span of that set.

Suppose that $X$ is a normed vector space and let $E$ be any non-empty subset of $X$. The **closed linear span** of $E$, denoted by $\overline{\operatorname{Sp}}(E)$ or $\overline{\operatorname{Span}}(E)$, is the intersection of all the closed linear subspaces of $X$ which contain $E$.

One mathematical formulation of this is

$$\overline{\operatorname{Sp}}(E) = \{u\in X | \forall\varepsilon > 0\,\exists x\in\operatorname{Sp}(E) : \|x - u\|<\varepsilon\}.$$

The closed linear span of the set of functions *x<sup>n</sup>* on the interval \[0, 1\], where *n* is a non-negative integer, depends on the norm used. If the [*L*<sup>2</sup> norm](wikipedia://en/45194#Lp_spaces_and_Lebesgue_integrals) is used, then the closed linear span is the [Hilbert space](wikipedia://en/20598932) of [square-integrable functions](wikipedia://en/28680558) on the interval. But if the [maximum norm](https://en.wikipedia.org/wiki/Maximum_norm) is used, the closed linear span will be the space of continuous functions on the interval. In either case, the closed linear span contains functions that are not polynomials, and so are not in the linear span itself. However, the [cardinality](wikipedia://en/6174) of the set of functions in the closed linear span is the [cardinality of the continuum](wikipedia://en/1574901), which is the same cardinality as for the set of polynomials.

### Notes {#Notes}

The linear span of a set is dense in the closed linear span. Moreover, as stated in the lemma below, the closed linear span is indeed the [closure](wikipedia://en/293802) of the linear span.

Closed linear spans are important when dealing with closed linear subspaces (which are themselves highly important, see [Riesz's lemma](wikipedia://en/5584743)).

::: {#o25 .statement kind=statement/lemma cue=named-heading name="A useful lemma"}

### A useful lemma {#A_useful_lemma}

Let $X$ be a normed space and let $E$ be any non-empty subset of $X$. Then $\overline{\operatorname{Sp}}(E)$ is a closed linear subspace of *X* which contains *E*,; $\overline{\operatorname{Sp}}(E) = \overline{\operatorname{Sp}(E)}$, viz. $\overline{\operatorname{Sp}}(E)$ is the closure of $\operatorname{Sp}(E)$,; $E^\perp = (\operatorname{Sp}(E))^\perp = \left(\overline{\operatorname{Sp}(E)}\right)^\perp.$; $(E^\perp)^\perp = ((\operatorname{Sp}(E))^\perp)^\perp = \overline{\operatorname{Sp}(E)}.$

(So the usual way to find the closed linear span is to find the linear span first, and then the closure of that linear span.)

:::
