# Embedding

::: {#o1 .subject cue=lead name="Embedding"}

In [mathematics](wikipedia://en/18831), an **embedding** (or **imbedding**[^o2]) is one instance of some [mathematical structure](wikipedia://en/1809181) contained within another instance, such as a [group](wikipedia://en/19447) that is a [subgroup](wikipedia://en/28011).

:::

When some object $X$ is said to be embedded in another object $Y$, the embedding is given by some [injective](wikipedia://en/45196) and structure-preserving map $f:X\rightarrow Y$. The precise meaning of "structure-preserving" depends on the kind of mathematical structure of which $X$ and $Y$ are instances. In the terminology of [category theory](wikipedia://en/5869), a structure-preserving map is called a [morphism](wikipedia://en/27716891).

The fact that a map $f:X\rightarrow Y$ is an embedding is often indicated by the use of a "hooked arrow" (21AA);[^o3] thus: $f : X \hookrightarrow Y.$ (On the other hand, this notation is sometimes reserved for [inclusion maps](wikipedia://en/492516).)

Given $X$ and $Y$, several different embeddings of $X$ in $Y$ may be possible. In many cases of interest there is a standard (or "canonical") embedding, like those of the [natural numbers](wikipedia://en/21474) in the [integers](wikipedia://en/14563), the integers in the [rational numbers](wikipedia://en/19727024), the rational numbers in the [real numbers](wikipedia://en/20646438), and the real numbers in the [complex numbers](wikipedia://en/5826). In such cases it is common to identify the [domain](wikipedia://en/50263) $X$ with its [image](wikipedia://en/579311) $f(X)$ contained in $Y$, so that $X\subseteq Y$.

## Topology and geometry {#Topology_and_geometry}

### General topology {#General_topology}

In [general topology](wikipedia://en/178649), an embedding is a [homeomorphism](wikipedia://en/13660) onto its image.[^o6] More explicitly, an injective [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29) map $f : X \to Y$ between [topological spaces](wikipedia://en/30450) $X$ and $Y$ is a **topological embedding** if $f$ yields a homeomorphism between $X$ and $f(X)$ (where $f(X)$ carries the [subspace topology](wikipedia://en/910926) inherited from $Y$). Intuitively then, the embedding $f : X \to Y$ lets us treat $X$ as a [subspace](wikipedia://en/910926) of $Y$. Every embedding is injective and [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29). Every map that is injective, continuous and either [open](https://en.wikipedia.org/wiki/Open_map) or [closed](https://en.wikipedia.org/wiki/Closed_map) is an embedding; however there are also embeddings that are neither open nor closed. The latter happens if the image $f(X)$ is neither an [open set](wikipedia://en/39358) nor a [closed set](wikipedia://en/47279) in $Y$.

For a given space $Y$, the existence of an embedding $X \to Y$ is a [topological invariant](https://en.wikipedia.org/wiki/Topological_invariant) of $X$. This allows two spaces to be distinguished if one is able to be embedded in a space while the other is not.

#### Related definitions {#Related_definitions}

If the domain of a function $f : X \to Y$ is a [topological space](wikipedia://en/30450) then the function is said to be *locally injective at a point* if there exists some [neighborhood](wikipedia://en/1529485) $U$ of this point such that the restriction $f\big\vert_U : U \to Y$ is injective. It is called *locally injective* if it is locally injective around every point of its domain. Similarly, a *local topological embedding* is a function for which every point in its domain has some neighborhood to which its restriction is a (topological, resp. smooth) embedding.

Every injective function is locally injective but not conversely. [Local diffeomorphisms](wikipedia://en/1728483), [local homeomorphisms](wikipedia://en/248582), and smooth [immersions](wikipedia://en/6993953) are all locally injective functions that are not necessarily injective. The [inverse function theorem](wikipedia://en/287229) gives a sufficient condition for a continuously differentiable function to be (among other things) locally injective. Every [fiber](wikipedia://en/6603892) of a locally injective function $f : X \to Y$ is necessarily a [discrete subspace](wikipedia://en/56061) of its [domain](wikipedia://en/50263) $X.$

### Differential topology {#Differential_topology}

In [differential topology](wikipedia://en/8562): Let $M$ and $N$ be smooth [manifolds](wikipedia://en/2073470) and $f:M\to N$ be a smooth map. Then $f$ is called an [immersion](wikipedia://en/6993953) if its [derivative](wikipedia://en/1558510) is everywhere injective. An **embedding**, or a **smooth embedding**, is defined to be an immersion that is an embedding in the topological sense mentioned above (i.e. [homeomorphism](wikipedia://en/13660) onto its image).[^o9]

In other words, the domain of an embedding is [diffeomorphic](wikipedia://en/8564) to its image, and in particular the image of an embedding must be a [submanifold](wikipedia://en/525095). An immersion is precisely a **local embedding**, i.e. for any point $x\in M$ there is a neighborhood $x\in U\subset M$ such that $f:U\to N$ is an embedding.

When the domain manifold is compact, the notion of a smooth embedding is equivalent to that of an injective immersion.

An important case is $N = \mathbb{R}^n$. The interest here is in how large $n$ must be for an embedding, in terms of the dimension $m$ of $M$. The [Whitney embedding theorem](wikipedia://en/477578)[^o10] states that $n = 2m$ is enough, and is the best possible linear bound. For example, the [real projective space](wikipedia://en/1014694) $\mathbb{R}\mathrm{P}^m$ of dimension $m$, where $m$ is a power of two, requires $n = 2m$ for an embedding. However, this does not apply to immersions; for instance, $\mathbb{R}\mathrm{P}^2$ can be immersed in $\mathbb{R}^3$ as is explicitly shown by [Boy's surface](wikipedia://en/61361)—which has self-intersections. The [Roman surface](wikipedia://en/59979) fails to be an immersion as it contains [cross-caps](https://en.wikipedia.org/wiki/Cross-cap).

An embedding is **proper** if it behaves well with respect to [boundaries](wikipedia://en/2119193#Manifolds_with_boundary): one requires the map $f: X \rightarrow Y$ to be such that

- $f(\partial X) = f(X) \cap \partial Y$, and
- $f(X)$ is [transverse](https://en.wikipedia.org/wiki/Transversality_%28mathematics%29) to $\partial Y$ in any point of $f(\partial X)$.

The first condition is equivalent to having $f(\partial X) \subseteq \partial Y$ and $f(X \setminus \partial X) \subseteq Y \setminus \partial Y$. The second condition, roughly speaking, says that $f(X)$ is not tangent to the boundary of $Y$.

### Riemannian and pseudo-Riemannian geometry {#Riemannian_and_pseudo-Riemannian_geometry}

In [Riemannian geometry](wikipedia://en/195243) and pseudo-Riemannian geometry: Let $(M,g)$ and $(N,h)$ be [Riemannian manifolds](wikipedia://en/144652) or more generally [pseudo-Riemannian manifolds](wikipedia://en/287555). An **isometric embedding** is a smooth embedding $f:M\rightarrow N$ that preserves the (pseudo-)[metric](https://en.wikipedia.org/wiki/Riemannian_metric) in the sense that $g$ is equal to the [pullback](wikipedia://en/494995) of $h$ by $f$, i.e. $g=f^{*}h$. Explicitly, for any two tangent vectors $v,w\in T_x(M)$ we have

$$g(v,w)=h(df(v),df(w)).$$

Analogously, **isometric immersion** is an immersion between (pseudo)-Riemannian manifolds that preserves the (pseudo)-Riemannian metrics.

Equivalently, in Riemannian geometry, an isometric embedding (immersion) is a smooth embedding (immersion) that preserves length of [curves](wikipedia://en/89246) (cf. [Nash embedding theorem](https://en.wikipedia.org/wiki/Nash_embedding_theorem)).[^o13]

:::

## Algebra {#Algebra}

In general, for an [algebraic category](wikipedia://en/1021753) $C$, an embedding between two $C$-algebraic structures $X$ and $Y$ is a $C$-morphism $e:X\rightarrow Y$ that is injective.

::: {#o16 .pointer-item cue=pointer name="Embedding (field theory)"}

### Field theory {#Field_theory}

In [field theory](https://en.wikipedia.org/wiki/Field_theory_%28mathematics%29), an **embedding** of a [field](wikipedia://en/10603) $E$ in a field $F$ is a [ring homomorphism](wikipedia://en/26411) $\sigma:E\rightarrow F$.

The [kernel](wikipedia://en/45240) of $\sigma$ is an [ideal](wikipedia://en/25977) of $E$, which cannot be the whole field $E$, because of the condition $1=\sigma(1)=1$. Furthermore, any field has as ideals only the zero ideal and the whole field itself (because if there is any non-zero field element in an ideal, it is invertible, showing the ideal is the whole field). Therefore, the kernel is $0$, so any embedding of fields is a [monomorphism](wikipedia://en/59538). Hence, $E$ is [isomorphic](https://en.wikipedia.org/wiki/Isomorphic) to the [subfield](wikipedia://en/11634) $\sigma(E)$ of $F$. This justifies the name *embedding* for an arbitrary homomorphism of fields.

:::

### Universal algebra and model theory {#Universal_algebra_and_model_theory}

If $\sigma$ is a [signature](wikipedia://en/7788156) and $A,B$ are $\sigma$-[structures](wikipedia://en/4055928) (also called $\sigma$-algebras in [universal algebra](wikipedia://en/45200) or models in [model theory](wikipedia://en/19858)), then a map $h:A \to B$ is a $\sigma$-embedding exactly if all of the following hold:

- $h$ is injective,
- for every $n$-ary function symbol $f \in\sigma$ and $a_1,\ldots,a_n \in A^n,$ we have $h(f^A(a_1,\ldots,a_n))=f^B(h(a_1),\ldots,h(a_n))$,
- for every $n$-ary relation symbol $R \in\sigma$ and $a_1,\ldots,a_n \in A^n,$ we have $A \models R(a_1,\ldots,a_n)$ iff $B \models R(h(a_1),\ldots,h(a_n)).$

Here $A\models R (a_1,\ldots,a_n)$ is a model theoretical notation equivalent to $(a_1,\ldots,a_n)\in R^A$. In model theory there is also a stronger notion of [elementary embedding](https://en.wikipedia.org/wiki/Elementary_embedding).

## Order theory and domain theory {#Order_theory_and_domain_theory}

In [order theory](wikipedia://en/361924), an embedding of [partially ordered sets](wikipedia://en/23572) is a function $F$ between partially ordered sets $X$ and $Y$ such that

$$\forall x_1,x_2\in X: x_1\leq x_2 \iff F(x_1)\leq F(x_2).$$

Injectivity of $F$ follows quickly from this definition. In [domain theory](wikipedia://en/325077), an additional requirement is that

$\forall y\in Y:\{x \mid F(x) \leq y\}$ is [directed](wikipedia://en/9165).

::: {#o20 .pointer-item cue=pointer name="Metric embedding"}

## Metric spaces {#Metric_spaces}

A mapping $\phi: X \to Y$ of [metric spaces](https://en.wikipedia.org/wiki/Metric_spaces) is called an *embedding* (with [distortion](https://en.wikipedia.org/wiki/Stretch_factor) $C>0$) if

$$L d_X(x, y) \leq d_Y(\phi(x), \phi(y)) \leq CLd_X(x,y)$$

for every $x,y\in X$ and some constant $L>0$.

### Normed spaces {#Normed_spaces}

An important special case is that of [normed spaces](https://en.wikipedia.org/wiki/Normed_spaces); in this case it is natural to consider linear embeddings.

One of the basic questions that can be asked about a finite-dimensional [normed space](https://en.wikipedia.org/wiki/Normed_space) $(X, \| \cdot \|)$ is, *what is the maximal dimension $k$ such that the [Hilbert space](wikipedia://en/20598932) $\ell_2^k$ can be linearly embedded into $X$ with constant distortion?*

The answer is given by [Dvoretzky's theorem](wikipedia://en/9118440).

:::

## Category theory {#Category_theory}

In [category theory](wikipedia://en/5869), there is no satisfactory and generally accepted definition of embeddings that is applicable in all categories. One would expect that all isomorphisms and all compositions of embeddings are embeddings, and that all embeddings are monomorphisms. Other typical requirements are: any [extremal monomorphism](wikipedia://en/59538#Related_concepts) is an embedding and embeddings are stable under [pullbacks](wikipedia://en/841689).

Ideally the class of all embedded [subobjects](wikipedia://en/540476) of a given object, up to isomorphism, should also be [small](https://en.wikipedia.org/wiki/Small_class), and thus an [ordered set](https://en.wikipedia.org/wiki/Ordered_set). In this case, the category is said to be well powered with respect to the class of embeddings. This allows defining new local structures in the category (such as a [closure operator](wikipedia://en/483120)).

In a [concrete category](wikipedia://en/167001), an **embedding** is a morphism $f:A\rightarrow B$ that is an injective function from the underlying set of $A$ to the underlying set of $B$ and is also an **initial morphism** in the following sense: If $g$ is a function from the underlying set of an object $C$ to the underlying set of $A$, and if its composition with $f$ is a morphism $fg:C\rightarrow B$, then $g$ itself is a morphism.

A [factorization system](wikipedia://en/7149012) for a category also gives rise to a notion of embedding. If $(E,M)$ is a factorization system, then the morphisms in $M$ may be regarded as the embeddings, especially when the category is well powered with respect to $M$. Concrete theories often have a factorization system in which $M$ consists of the embeddings in the previous sense. This is the case of the majority of the examples given in this article.

As usual in category theory, there is a [dual](wikipedia://en/310885) concept, known as quotient. All the preceding properties can be dualized.

An embedding can also refer to an [embedding functor](wikipedia://en/310959#Embeddings).
