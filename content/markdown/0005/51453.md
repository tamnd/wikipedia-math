# Singular function

::: {#o1 .subject cue=lead name="Singular function"}

*Image: Devils-staircase.svg.* The graph of the winding number of the [circle map](https://en.wikipedia.org/wiki/Circle_map) is an example of a singular function.

In [mathematics](wikipedia://en/18831), a [real-valued function](wikipedia://en/22284647) *f* on the [interval](wikipedia://en/49172) \[*a*, *b*\] is said to be **singular** if it has the following properties:

:::

- *f* is [continuous](wikipedia://en/6122) on \[*a*, *b*\]. (\*\*)
- there exists a set *N* of [measure](wikipedia://en/19873) 0 such that for all *x* outside of *N,* the [derivative](wikipedia://en/7921) *f* (*x*) exists and is zero; that is, the derivative of *f* vanishes [almost everywhere](wikipedia://en/44688).
- *f* is non-constant on \[*a*, *b*\].

A standard example of a singular function is the [Cantor function](wikipedia://en/320819), which is sometimes called the devil's staircase (a term also used for singular functions in general). There are, however, other functions that have been given that name. One is defined in terms of the [circle map](https://en.wikipedia.org/wiki/Circle_map).

If *f*(*x*) = 0 for all *x* ≤ *a* and *f*(*x*) = 1 for all *x* ≥ *b*, then the function can be taken to represent a [cumulative distribution function](wikipedia://en/5793) for a [random variable](wikipedia://en/25685) which is neither a [discrete random variable](https://en.wikipedia.org/wiki/Discrete_random_variable) (since the [probability](wikipedia://en/22934) is zero for each point) nor an absolutely [continuous random variable](https://en.wikipedia.org/wiki/Continuous_random_variable) (since the [probability density](wikipedia://en/43487) is zero everywhere it exists).

Singular functions occur, for instance, as sequences of spatially modulated phases or structures in [solids](https://en.wikipedia.org/wiki/Solid) and [magnets](https://en.wikipedia.org/wiki/Magnet), described in a prototypical fashion by the [Frenkel–Kontorova model](https://en.wikipedia.org/wiki/Frenkel–Kontorova_model) and by the [ANNNI model](wikipedia://en/6898571), as well as in some [dynamical systems](wikipedia://en/9087). Most famously, perhaps, they lie at the center of the [fractional quantum Hall effect](https://en.wikipedia.org/wiki/Fractional_quantum_Hall_effect).

## When referring to functions with a singularity {#When_referring_to_functions_with_a_singularity}

When discussing [mathematical analysis](wikipedia://en/48396) in general, or more specifically [real analysis](wikipedia://en/26478) or [complex analysis](wikipedia://en/5759) or [differential equations](wikipedia://en/1424309), it is common for a function which contains a [mathematical singularity](https://en.wikipedia.org/wiki/Mathematical_singularity) to be referred to as a 'singular function'. This is especially true when referring to functions which diverge to infinity at a point or on a boundary. For example, one might say, "*1/x* becomes singular at the origin, so *1/x* is a singular function."

Advanced techniques for working with functions that contain singularities have been developed in the subject called [distributional](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) or [generalized function](wikipedia://en/1580246) analysis. A [weak derivative](wikipedia://en/1411087) is defined that allows singular functions to be used in [partial differential equations](wikipedia://en/52564), etc.
