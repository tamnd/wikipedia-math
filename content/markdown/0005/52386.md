# Axiom schema of specification

::: {#o1 .subject cue=lead name="Axiom schema of specification"}

In many popular versions of [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), the **axiom schema of specification**,[^o2] also known as the **axiom schema of separation** (Aussonderungsaxiom)[^o3][^o4], **subset axiom[^o5]**, **axiom of class construction**,[^o6] or **axiom schema of restricted comprehension**[^o7] is an [axiom schema](wikipedia://en/764613). Essentially, it says that any definable [subclass](wikipedia://en/1828474) of a set is a set.

:::

Some mathematicians refer to this axiom as the **axiom schema of comprehension**, although others reserve that term only for *unrestricted* comprehension; this axiom is a "restricted" version of unrestricted comprehension. Because restricting comprehension avoids [Russell's paradox](wikipedia://en/46095), several mathematicians including [Zermelo](wikipedia://en/178655), [Fraenkel](wikipedia://en/528451), and [Gödel](https://en.wikipedia.org/wiki/Gödel) considered it the most important axiom of set theory.[^o8]

::: {#o10 .statement cue=heading name="Statement"}

## Statement {#Statement}

One instance of the schema is included for each [formula](wikipedia://en/404582) $\varphi$ in the language of set theory with [free variables](https://en.wikipedia.org/wiki/Free_variables) among $x,w_1,w_2,\ldots,w_n,A$. So the set $B$, whose existence is asserted by the axiom, does not occur free in $\varphi$. In the formal language of set theory, the axiom schema is:

$$\forall w_1,\ldots,w_n \, \forall A \, \exists B \, \forall x \, ( x \in B \Leftrightarrow [ x \in A \land \varphi(x, w_1, \ldots, w_n , A) ] )$$

or in words:

Given any [set](wikipedia://en/26691) *A*, [there is](wikipedia://en/91420) a set *B* (a subset of *A*) such that, given any set *x*, *x* is a member of *B* [if and only if](wikipedia://en/14922) *x* is a member of *A* [and](wikipedia://en/18152) $\varphi$ holds for *x*.

Note that there is one axiom for every such [predicate](https://en.wikipedia.org/wiki/Predicate_%28mathematics%29) $\varphi$; thus, this is an [axiom schema](wikipedia://en/764613).

To understand this axiom schema, note that the set *B* must be a [subset](wikipedia://en/27631) of *A*. Thus, what the axiom schema is really saying is that, given a set *A* and a predicate $\varphi$, we can find a subset *B* of *A* whose members are precisely the members of *A* that satisfy $\varphi$. By the [axiom of extensionality](wikipedia://en/52376) this set is unique. We usually denote this set using [set-builder notation](wikipedia://en/220089) as $B = \{x\in A \mid \varphi(x) \}$. Thus the essence of the axiom is:

Every [subclass](wikipedia://en/1828474) of a set that is defined by a predicate is itself a set.

The preceding form of separation was introduced in 1930 by [Thoralf Skolem](wikipedia://en/453765) as a refinement of a previous, non-first-order[^o11] form by Zermelo.[^o12] The axiom schema of specification is characteristic of systems of [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory) related to the usual set theory [ZFC](https://en.wikipedia.org/wiki/ZFC), but does not usually appear in radically different systems of [alternative set theory](https://en.wikipedia.org/wiki/Alternative_set_theory). For example, [New Foundations](wikipedia://en/945957) and [positive set theory](wikipedia://en/1023857) use different restrictions of the axiom of comprehension of [naive set theory](wikipedia://en/4944). The [Alternative Set Theory](https://en.wikipedia.org/wiki/Alternative_Set_Theory) of Vopenka makes a specific point of allowing proper subclasses of sets, called [semisets](wikipedia://en/1634884). Even in systems related to ZFC, this scheme is sometimes restricted to formulas with bounded quantifiers, as in [Kripke–Platek set theory with urelements](wikipedia://en/1572078).

:::

::: {#o14 .statement kind=statement/axiom cue=named-heading name="Relation to the axiom schema of replacement"}

## Relation to the axiom schema of replacement {#Relation_to_the_axiom_schema_of_replacement}

The axiom schema of specification is implied by the [axiom schema of replacement](wikipedia://en/52387) together with the [axiom of empty set](wikipedia://en/52534).[^o15]

The *axiom schema of replacement* says that, if a function $f$ is definable by a formula $\varphi(x, y, p_1, \ldots, p_n)$, then for any set $A$, there exists a set $B = f(A) = \{ f(x) \mid x \in A \}$:

$\begin{aligned} &\forall x \, \forall y \, \forall z \, \forall p_1 \ldots \forall p_n [ \varphi(x, y, p_1, \ldots, p_n) \wedge \varphi(x, z, p_1, \ldots, p_n) \implies y = z ] \implies \\ &\forall A \, \exists B \, \forall y ( y \in B \iff \exists x ( x \in A \wedge \varphi(x, y, p_1, \ldots, p_n) ) ) \end{aligned}$.[^o15]

To derive the axiom schema of specification, let $\varphi(x, p_1, \ldots, p_n)$ be a formula and $z$ a set, and define the function $f$ such that $f(x) = x$ if $\varphi(x, p_1, \ldots, p_n)$ is true and $f(x) = u$ if $\varphi(x, p_1, \ldots, p_n)$ is false, where $u \in z$ such that $\varphi(u, p_1, \ldots, p_n)$ is true. Then the set $y$ guaranteed by the axiom schema of replacement is precisely the set $y$ required in the axiom schema of specification. If $u$ does not exist, then $f(x)$ in the axiom schema of specification is the empty set, whose existence (i.e., the axiom of empty set) is then needed.[^o15]

For this reason, the axiom schema of specification is left out of some axiomatizations of **ZF** ([Zermelo–Fraenkel set theory](wikipedia://en/152214)),[^o16] although some authors, despite the redundancy, include both.[^o17] Regardless, the axiom schema of specification is notable because it was in [Zermelo](wikipedia://en/178655)'s original 1908 list of axioms, before [Fraenkel](wikipedia://en/528451) invented the axiom of replacement in 1922.[^o16] Additionally, if one takes [**ZFC** set theory](https://en.wikipedia.org/wiki/ZFC_set_theory) (i.e., **ZF** with the axiom of choice), removes the axiom of replacement and the [axiom of collection](https://en.wikipedia.org/wiki/Axiom_of_collection), but keeps the axiom schema of specification, one gets the weaker system of axioms called **ZC** (i.e., Zermelo's axioms, plus the axiom of choice).[^o18]

:::

## Unrestricted comprehension {#Unrestricted_comprehension}

The **axiom schema of unrestricted comprehension** reads:

$$\forall w_1,\ldots,w_n \, \exists B \, \forall x \, ( x \in B \Leftrightarrow \varphi(x, w_1, \ldots, w_n) )$$

that is: There exists a set $B$ whose members are precisely those objects that satisfy the predicate $\varphi$.

This set $B$ is again unique, and is usually denoted as $\{\{\operatorname{math}|x$ : $\varphi$($x$, $w$${}_{1}$, ..., $w$${}_{b}$)}.}}

At an informal level, this axiom schema can be described as saying for any property or condition $\varphi$ (the set's [predicate](wikipedia://en/285109)), there exists a set $\{x | \varphi(x)\}$ composed of all and only the objects which satisfy $\varphi$.[^o21][^o22] For example, when $\varphi$ is a [tautology](wikipedia://en/4495335), the resulting set $B$ is the [universal set](wikipedia://en/303405).

This axiom schema was tacitly used in the early days of [naive set theory](wikipedia://en/4944), before a strict axiomatization was adopted. However, it was later discovered to lead directly to [Russell's paradox](wikipedia://en/46095), by taking $\varphi(x)$ to be $\neg(x \in x)$ (i.e., the property that set $x$ is not a member of itself). Therefore, no useful [axiomatization](https://en.wikipedia.org/wiki/Axiomatization) of set theory can use unrestricted comprehension. Passing from [classical logic](wikipedia://en/55868) to [intuitionistic logic](wikipedia://en/169262) does not help, as the proof of Russell's paradox is intuitionistically valid.

The axiom schema of specification can be viewed as a "restricted" version of this axiom schema, where $\varphi$ can only be true for elements of another set $A$, thus forbidding the construction of sets that are "too large" such as the universal set. Accepting only the axiom schema of specification was the beginning of axiomatic set theory. Most of the other Zermelo–Fraenkel axioms (but not the [axiom of extensionality](wikipedia://en/52376), the [axiom of regularity](wikipedia://en/2113), or the [axiom of choice](wikipedia://en/840)) then became necessary to make up for some of what was lost by changing the axiom schema of comprehension to the axiom schema of specification—each of these axioms states that a certain set exists, and defines that set by giving a predicate for its members to satisfy, i.e. it is a special case of the axiom schema of comprehension.

It is also possible to prevent the schema from being inconsistent by restricting which formulae it can be applied to, such as only [stratified](wikipedia://en/571280) formulae in [New Foundations](wikipedia://en/945957) (see below) or only positive formulae (formulae with only conjunction, disjunction, quantification and atomic formulae) in [positive set theory](wikipedia://en/1023857). Positive formulae, however, typically are unable to express certain things that most theories can; for instance, there is no [complement](wikipedia://en/54347) or [relative complement](https://en.wikipedia.org/wiki/Relative_complement) in positive set theory.

:::

## In NBG set theory {#In_NBG_set_theory}

In [von Neumann–Bernays–Gödel set theory](wikipedia://en/528491), a distinction is made between sets and [classes](wikipedia://en/20696). A class $C$ is a set if and only if it belongs to some class $E$. In this theory, there is a [theorem](wikipedia://en/30977) schema that reads

$$\exists D \forall C \, ( [ C \in D ] \iff [ P (C) \land \exists E \, ( C \in E ) ] ) \,,$$

that is, There is a class $D$ such that any class $C$ is a member of $D$ if and only if $C$ is a set that satisfies $P$.

provided that the quantifiers in the predicate $P$ are restricted to sets.

This theorem schema is itself a restricted form of comprehension, which avoids Russell's paradox because of the requirement that $C$ be a set. Then specification for sets themselves can be written as a single axiom

$$\forall D \forall A \, ( \exists E \, [ A \in E ] \implies \exists B \, [ \exists E \, ( B \in E ) \land \forall C \, ( C \in B \iff [ C \in A \land C \in D ] ) ] ) \,,$$

that is, Given any class $D$ and any set $A$, there is a set $B$ whose members are precisely those classes that are members of both $A$ and $D$.

or even more simply The [intersection](wikipedia://en/23476429) of a class $D$ and a set $A$ is itself a set $B$.

In this axiom, the predicate $P$ is replaced by the class $D$, which can be quantified over. Another simpler axiom which achieves the same effect is

$$\forall A \forall B \, ( [ \exists E \, ( A \in E ) \land \forall C \, ( C \in B \implies C \in A ) ] \implies \exists E \, [ B \in E ] ) \,,$$

that is, A subclass of a set is a set.

## In higher-order settings {#In_higher-order_settings}

In a [typed](wikipedia://en/40282) language where we can quantify over predicates, the axiom schema of specification becomes a simple axiom. This is much the same trick as was used in the NBG axioms of the previous section, where the predicate was replaced by a class that was then quantified over.

In [second-order logic](wikipedia://en/341428) and [higher-order logic](wikipedia://en/562883) with higher-order semantics, the axiom of specification is a logical validity and does not need to be explicitly included in a theory.

## In Quine's New Foundations {#In_Quine's_New_Foundations}

In the [New Foundations](wikipedia://en/945957) approach to set theory pioneered by [W. V. O. Quine](https://en.wikipedia.org/wiki/W._V._O._Quine), the axiom of comprehension for a given predicate takes the unrestricted form, but the predicates that may be used in the schema are themselves restricted. The predicate ($C$ is not in $C$) is forbidden, because the same symbol $C$ appears on both sides of the membership symbol (and so at different "relative types"); thus, Russell's paradox is avoided. However, by taking $P(C)$ to be $(C = C)$, which is allowed, we can form a set of all sets. For details, see [stratification](wikipedia://en/571280).[^o26]
