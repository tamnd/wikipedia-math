# Axiom of pairing

::: {#o1 .subject cue=lead name="Axiom of pairing"}

In [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory) and the branches of [logic](wikipedia://en/46426065), [mathematics](wikipedia://en/18831), and [computer science](https://en.wikipedia.org/wiki/Computer_science) that use it, the **axiom of pairing** is one of the [axioms](wikipedia://en/928) of [Zermelo–Fraenkel set theory](wikipedia://en/152214). It was introduced by (Zermelo 1908) as a special case of his [axiom of elementary sets](https://en.wikipedia.org/wiki/Axiom_of_elementary_sets).

:::

::: {#o4 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

In the [formal language](wikipedia://en/10939) of the Zermelo–Fraenkel axioms, the axiom reads:

$$\forall A \, \forall B \, \exists C \, \forall D \, [D \in C \iff (D = A \lor D = B)]$$

In words:

[Given any](https://en.wikipedia.org/wiki/Given_any) object *A* and any object *B*, [there is](wikipedia://en/91420) a set *C* such that, given any object *D*, *D* is a member of *C* [if and only if](wikipedia://en/14922) *D* is [equal](https://en.wikipedia.org/wiki/Equal_%28math%29) to *A* [or](wikipedia://en/7962) *D* is equal to *B*.

:::

## Consequences {#Consequences}

As noted, what the axiom is saying is that, given two objects *A* and *B*, we can find a set *C* whose members are exactly *A* and *B*.

We can use the [axiom of extensionality](wikipedia://en/52376) to show that this set *C* is unique. We call the set *C* the *pair* of *A* and *B*, and denote it {*A*,*B*}. Thus the essence of the axiom is:

Any two objects have a pair.

The set {*A*,*A*} is abbreviated {*A*}, called the *[singleton](wikipedia://en/381798)* containing *A*. Note that a singleton is a special case of a pair. Being able to construct a singleton is necessary, for example, to show the non-existence of the infinitely descending chains $x=\{x\}$ from the [axiom of regularity](wikipedia://en/2113).

The axiom of pairing also allows for the definition of [ordered pairs](https://en.wikipedia.org/wiki/Ordered_pairs). For any objects $a$ and $b$, the [ordered pair](wikipedia://en/22362) is defined by the following:

$$(a, b) = \{ \{ a \}, \{ a, b \} \}.\,$$

Note that this definition satisfies the condition

$$(a, b) = (c, d) \iff a = c \land b = d.$$

Ordered [*n*-tuples](wikipedia://en/132729) can be defined recursively as follows:

$$(a_1, \ldots, a_n) = ((a_1, \ldots, a_{n-1}), a_n).\!$$

## Alternatives {#Alternatives}

### Non-independence {#Non-independence}

The axiom of pairing is generally considered uncontroversial, and it or an equivalent appears in just about any [axiomatization](https://en.wikipedia.org/wiki/Axiomatization) of set theory. Nevertheless, in the standard formulation of the [Zermelo–Fraenkel set theory](wikipedia://en/152214), the axiom of pairing follows from the [axiom schema of replacement](wikipedia://en/52387) applied to any given set with two or more elements,[^o8][^o9] and thus it is sometimes omitted. The existence of such a set with two elements, such as { {}, { {} } }, can be deduced either from the [axiom of empty set](wikipedia://en/52534) and the [axiom of power set](wikipedia://en/52552) or from the [axiom of infinity](wikipedia://en/246449).

In the absence of some of the stronger ZFC axioms, the axiom of pairing can still, without loss, be introduced in weaker forms.

### Weaker {#Weaker}

In the presence of standard forms of the [axiom schema of separation](https://en.wikipedia.org/wiki/Axiom_schema_of_separation) we can replace the axiom of pairing by its weaker version:

$$\forall A\forall B\exists C\forall D((D=A\lor D=B)\Rightarrow D\in C).$$

This weak axiom of pairing implies that any given objects $A$ and $B$ are members of some set $C$. Using the axiom schema of separation we can construct the set whose members are exactly $A$ and $B$.

Another axiom which implies the axiom of pairing in the presence of the [axiom of empty set](wikipedia://en/52534) is the [axiom of adjunction](wikipedia://en/43548952)

$$\forall A \, \forall B \, \exists C \, \forall D \, [D \in C \iff (D \in A \lor D = B)].$$

It differs from the standard one by use of $D \in A$ instead of $D=A$. Using {} for *A* and *x* for B, we get {*x*} for C. Then use {*x*} for *A* and *y* for *B*, getting {*x,y*} for C. One may continue in this fashion to build up any finite set. And this could be used to generate all [hereditarily finite sets](wikipedia://en/332621) without using the [axiom of union](wikipedia://en/52553).

### Stronger {#Stronger}

Together with the [axiom of empty set](wikipedia://en/52534) and the [axiom of union](wikipedia://en/52553), the axiom of pairing can be generalised to the following schema:

$$\forall A_1 \, \ldots \, \forall A_n \, \exists C \, \forall D \, [D \in C \iff (D = A_1 \lor \cdots \lor D = A_n)]$$

that is:

Given any [finite](wikipedia://en/11742) number of objects *A*<sub>1</sub> through *A*<sub>*n*</sub>, there is a set *C* whose members are precisely *A*<sub>1</sub> through *A*<sub>*n*</sub>.

This set *C* is again unique by the [axiom of extensionality](wikipedia://en/52376), and is denoted {*A*<sub>1</sub>,...,*A*<sub>*n*</sub>}.

Of course, we can't refer to a *finite* number of objects rigorously without already having in our hands a (finite) set to which the objects in question belong. Thus, this is not a single statement but instead a [schema](https://en.wikipedia.org/wiki/Schema_%28logic%29), with a separate statement for each [natural number](wikipedia://en/21474) *n*.

- The case *n* = 1 is the axiom of pairing with *A* = *A*<sub>1</sub> and *B* = *A*<sub>1</sub>.
- The case *n* = 2 is the axiom of pairing with *A* = *A*<sub>1</sub> and *B* = *A*<sub>2</sub>.
- The cases *n* > 2 can be proved using the axiom of pairing and the [axiom of union](wikipedia://en/52553) multiple times.

For example, to prove the case *n* = 3, use the axiom of pairing three times, to produce the pair {*A*<sub>1</sub>,*A*<sub>2</sub>}, the singleton {*A*<sub>3</sub>}, and then the pair {{*A*<sub>1</sub>,*A*<sub>2</sub>},{*A*<sub>3</sub>}}. The [axiom of union](wikipedia://en/52553) then produces the desired result, {*A*<sub>1</sub>,*A*<sub>2</sub>,*A*<sub>3</sub>}. We can extend this schema to include *n*=0 if we interpret that case as the [axiom of empty set](wikipedia://en/52534).

Thus, one may use this as an [axiom schema](wikipedia://en/764613) in the place of the axioms of empty set and pairing. Normally, however, one uses the axioms of empty set and pairing separately, and then proves this as a [theorem](wikipedia://en/30977) schema. Note that adopting this as an axiom schema will not replace the [axiom of union](wikipedia://en/52553), which is still needed for other situations.
