# Boolean ring

::: {#o1 .subject cue=lead name="Boolean ring"}

In [mathematics](wikipedia://en/18831), a **Boolean ring** $R$ is a [ring](wikipedia://en/48404) for which $x^{2} = x$ for all $x$ in $R$, that is, a ring that consists of only [idempotent elements](https://en.wikipedia.org/wiki/Idempotent_element_%28ring_theory%29).[^n1][^n2][^n3] An example is the ring of [integers modulo 2](wikipedia://en/20087#Integers_modulo_m).

:::

Every Boolean ring gives rise to a [Boolean algebra](wikipedia://en/3959), with ring multiplication corresponding to [conjunction](wikipedia://en/18152) or [meet](https://en.wikipedia.org/wiki/Meet_%28mathematics%29) $\land$, and ring addition to [exclusive disjunction](wikipedia://en/105979) or [symmetric difference](wikipedia://en/262288) (not [disjunction](wikipedia://en/7962) $\lor$, which would constitute a [semiring](wikipedia://en/371468)). Conversely, every Boolean algebra gives rise to a Boolean ring. Boolean rings are named after the founder of Boolean algebra, [George Boole](wikipedia://en/38298).

::: {#o6 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

There are at least four different and incompatible systems of notation for Boolean rings and algebras:

- In [commutative algebra](wikipedia://en/245990) the standard notation is to use $x + y = (x \land \neg y) \lor (\neg x \land y)$ for the ring sum of $x$ and $y$, and use $xy = x \land y$ for their product.
- In [logic](wikipedia://en/19636), a common notation is to use $x \land y$ for the meet (same as the ring product) and use $x \lor y$ for the join, given in terms of ring notation (given just above) by $x + y + xy$.
- In [set theory](wikipedia://en/27553) and logic it is also common to use $x \cdot y$ for the meet, and $x + y$ for the join $x \lor y$.[^n4] This use of $+$ is different from the use in ring theory.
- A rare convention is to use $xy$ for the product and $x \oplus y$ for the ring sum, in an effort to avoid the ambiguity of $+$.

Historically, the term "Boolean ring" has been used to mean a "Boolean ring possibly without an identity", and "Boolean algebra" has been used to mean a Boolean ring with an identity. The existence of the identity is necessary to consider the ring as an algebra over the [field of two elements](wikipedia://en/11137263): otherwise there cannot be a (unital) ring homomorphism of the field of two elements into the Boolean ring. (This is the same as the old use of the terms "ring" and "algebra" in [measure theory](https://en.wikipedia.org/wiki/Measure_theory).)

:::

## Examples {#Examples}

One example of a Boolean ring is the [power set](wikipedia://en/23799) of any set $X$, where the addition in the ring is [symmetric difference](wikipedia://en/262288), and the multiplication is [intersection](wikipedia://en/23476429). As another example, we can also consider the set of all [finite](wikipedia://en/11742) or cofinite subsets of $X$, again with symmetric difference and intersection as operations. More generally with these operations any [field of sets](wikipedia://en/1018676) is a Boolean ring. By [Stone's representation theorem](wikipedia://en/604111) every Boolean ring is isomorphic to a [field of sets](wikipedia://en/1018676) (treated as a ring with these operations).

:::

## Relation to Boolean algebras {#Relation_to_Boolean_algebras}

*Image: Vennandornot.svg.* [Venn diagrams](wikipedia://en/61701) for the Boolean operations of conjunction, disjunction, and complement

Since the join operation $\lor$ in a Boolean algebra is often written additively, it makes sense in this context to denote ring addition by $\oplus$, a symbol that is often used to denote [exclusive or](wikipedia://en/105979).

Given a Boolean ring $R$, for $x$ and $y$ in $R$ we can define

$$x \land y = xy,$$

$$x \lor y = x \oplus y \oplus xy,$$

$$\neg x = 1 \oplus x.$$

These operations then satisfy all of the axioms for meets, joins, and complements in a [Boolean algebra](wikipedia://en/3959). Thus every Boolean ring becomes a Boolean algebra. Similarly, every Boolean algebra becomes a Boolean ring thus:

$$xy = x \land y,$$

$$x \oplus y = (x \lor y) \land \neg(x \land y).$$

If a Boolean ring is translated into a Boolean algebra in this way, and then the Boolean algebra is translated into a ring, the result is the original ring. The analogous result holds beginning with a Boolean algebra.

A map between two Boolean rings is a [ring homomorphism](wikipedia://en/26411) [if and only if](wikipedia://en/14922) it is a homomorphism of the corresponding Boolean algebras. Furthermore, a subset of a Boolean ring is a [ring ideal](https://en.wikipedia.org/wiki/Ring_ideal) (prime ring ideal, maximal ring ideal) if and only if it is an [order ideal](https://en.wikipedia.org/wiki/Order_ideal) (prime order ideal, maximal order ideal) of the Boolean algebra. The [quotient ring](wikipedia://en/184635) of a Boolean ring modulo a ring ideal corresponds to the factor algebra of the corresponding Boolean algebra modulo the corresponding order ideal.

## Properties of Boolean rings {#Properties_of_Boolean_rings}

Every Boolean ring $R$ satisfies $x \oplus x = 0$ for all $x$ in $R$, because we know

$$x \oplus x = (x \oplus x)^{2} = x^{2} \oplus x^{2} \oplus x^{2} \oplus x^{2} = x \oplus x \oplus x \oplus x$$

and since $(R, \oplus)$ is an abelian group, we can subtract $x \oplus x$ from both sides of this equation, which gives $x \oplus x = 0$. A similar proof shows that every Boolean ring is [commutative](https://en.wikipedia.org/wiki/Commutative):

$x \oplus y = (x \oplus y)^{2} = x^{2} \oplus xy \oplus yx \oplus y^{2} = x \oplus xy \oplus yx \oplus y$ and this yields $xy \oplus yx = 0$, which means $xy = yx$ (using the first property above).

The property $x \oplus x = 0$ shows that any Boolean ring is an [associative algebra](wikipedia://en/2112) over the [field](wikipedia://en/10603) $\mathbf{F}_{2}$ with two elements, in precisely one way. In particular, any finite Boolean ring has as [cardinality](wikipedia://en/6174) a [power of two](wikipedia://en/376948). Not every unital associative algebra over $\mathbf{F}_{2}$ is a Boolean ring: consider for instance the [polynomial ring](wikipedia://en/373065) $\mathbf{F}_{2}[X]$.

The quotient ring $R / I$ of any Boolean ring $R$ modulo any ideal $I$ is again a Boolean ring. Likewise, any [subring](wikipedia://en/24873145) of a Boolean ring is a Boolean ring.

Any [localization](https://en.wikipedia.org/wiki/Localization_of_a_ring) $RS^{-1}$ of a Boolean ring $R$ by a set $S \subseteq R$ is a Boolean ring, since every element in the localization is idempotent.

The maximal ring of quotients $Q(R)$ (in the sense of Utumi and [Lambek](wikipedia://en/1250498)) of a Boolean ring $R$ is a Boolean ring, since every partial endomorphism is idempotent.[^n5]

Every [prime ideal](wikipedia://en/24928) $P$ in a Boolean ring $R$ is [maximal](wikipedia://en/48164): the [quotient ring](wikipedia://en/184635) $R / P$ is an [integral domain](wikipedia://en/15462) and also a Boolean ring, so it is isomorphic to the [field](wikipedia://en/10603) $\mathbf{F}_{2}$, which shows the maximality of $P$. Since maximal ideals are always prime, prime ideals and maximal ideals coincide in Boolean rings.

Every finitely generated ideal of a Boolean ring is [principal](wikipedia://en/145126) (indeed, $(x,y) = (x + y + xy))$. Furthermore, as all elements are idempotents, Boolean rings are commutative [von Neumann regular rings](wikipedia://en/907524) and hence absolutely flat, which means that every module over them is [flat](wikipedia://en/492616).

## Unification {#Unification}

[Unification](https://en.wikipedia.org/wiki/Unification_%28logic%29) in Boolean rings is [decidable](wikipedia://en/913118),[^n6] that is, algorithms exist to solve arbitrary equations over Boolean rings. Both unification and matching in [finitely generated](wikipedia://en/11985661) free Boolean rings are [NP-complete](https://en.wikipedia.org/wiki/NP-complete), and both are [NP-hard](https://en.wikipedia.org/wiki/NP-hard) in [finitely presented](https://en.wikipedia.org/wiki/Finitely_presented_algebra) Boolean rings.[^n7] (In fact, as any unification problem $f(X) = g(X)$ in a Boolean ring can be rewritten as the matching problem $f(X) + g(X) = 0$, the problems are equivalent.)

Unification in Boolean rings is unitary if all the uninterpreted function symbols are nullary and finitary otherwise (i.e. if the function symbols not occurring in the signature of Boolean rings are all constants then there exists a [most general unifier](https://en.wikipedia.org/wiki/Most_general_unifier), and otherwise the [minimal complete set of unifiers](wikipedia://en/54432#Unification_problem,_solution_set) is finite).[^n8]
