# EXPSPACE

::: {#o1 .subject cue=lead name="EXPSPACE"}

In [computational complexity theory](wikipedia://en/7543), **EXPSPACE** is the [set](wikipedia://en/26691) of all [decision problems](wikipedia://en/8336) solvable by a deterministic [Turing machine](wikipedia://en/30403) in [exponential](wikipedia://en/9678) [space](wikipedia://en/338946), i.e., in $O(2^{p(n)})$ space, where $p(n)$ is a polynomial function of $n$. Some authors restrict $p(n)$ to be a [linear function](wikipedia://en/152111), but most authors instead call the resulting class [ESPACE](wikipedia://en/663649). If we use a nondeterministic machine instead, we get the class NEXPSPACE, which is equal to EXPSPACE by [Savitch's theorem](wikipedia://en/658501).

:::

A decision problem is EXPSPACE-complete if it is in EXPSPACE, and every problem in EXPSPACE has a [polynomial-time many-one reduction](https://en.wikipedia.org/wiki/Polynomial-time_many-one_reduction) to it. In other words, there is a polynomial-time [algorithm](wikipedia://en/775) that transforms instances of one to instances of the other with the same answer. EXPSPACE-complete problems might be thought of as the hardest problems in EXPSPACE.

EXPSPACE is a strict superset of [PSPACE](wikipedia://en/39351), [NP](wikipedia://en/21562), and [P](wikipedia://en/658550). It contains [EXPTIME](wikipedia://en/54694) and is believed to strictly contain it, but this is unproven.

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

In terms of [DSPACE](wikipedia://en/658520) and [NSPACE](wikipedia://en/658518),

$$\mathsf{EXPSPACE} = \bigcup_{k\in\mathbb{N}} \mathsf{DSPACE}\left(2^{n^k}\right) = \bigcup_{k\in\mathbb{N}} \mathsf{NSPACE}\left(2^{n^k}\right)$$

:::

## Examples of problems {#Examples_of_problems}

### Formal languages {#Formal_languages}

An example of an EXPSPACE-complete problem is the problem of recognizing whether two [regular expressions](wikipedia://en/25717) represent different languages, where the expressions are limited to four operators: union, [concatenation](wikipedia://en/64474), the [Kleene star](wikipedia://en/16750) (zero or more copies of an expression), and squaring (two copies of an expression).[^o6]

### Logic {#Logic}

Alur and Henzinger extended [linear temporal logic](wikipedia://en/710307) with times (integer) and prove that the validity problem of their logic is EXPSPACE-complete.[^o8]

Reasoning in the first-order theory of the real numbers with +, ×, = is in EXPSPACE and was conjectured to be EXPSPACE-complete in 1986.[^o9]

### Petri nets {#Petri_nets}

The coverability problem for [Petri Nets](https://en.wikipedia.org/wiki/Petri_Nets) is EXPSPACE-complete.[^o11]

The [reachability problem](https://en.wikipedia.org/wiki/Reachability_problem) for Petri nets was known to be EXPSPACE-hard for a long time,[^o12] but shown to be [nonelementary](wikipedia://en/2284654),[^o13] so probably not in EXPSPACE. In 2022 it was shown to be [Ackermann](wikipedia://en/2925)-complete.[^o14][^o15]

It is EXPSPACE-complete to decide whether the reachability of a given [vector addition system](https://en.wikipedia.org/wiki/Vector_addition_system) is finite.[^o16]
