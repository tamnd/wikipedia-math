# Axiom of empty set

::: {#o1 .subject cue=lead name="Axiom of empty set"}

In [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), the **axiom of empty set**,[^o2][^o3] also called the **axiom of null set**[^o4] and the **axiom of existence**,[^o5][^o12] is a statement that asserts the existence of a set with no elements.[^o4] Although [Zermelo](wikipedia://en/178655) originally stipulated the existence of a set with no elements as an axiom[^o6][^o7] , it can be treated as either an axiom or a derivable truth depending on the specific set-theoretic context. It is an [axiom](wikipedia://en/928) of [Kripke–Platek set theory](wikipedia://en/1124695) and the variant of [general set theory](wikipedia://en/9373204) that Burgess (2005) calls "ST,"[^o8] and a demonstrable truth in [Zermelo–Fraenkel set theory](wikipedia://en/152214), with or without the [axiom of choice](wikipedia://en/840).[^o9]

:::

::: {#o11 .statement cue=heading name="Formal statement"}

## Formal statement {#Formal_statement}

In the [formal language](wikipedia://en/10939) of the [Zermelo–Fraenkel axioms](https://en.wikipedia.org/wiki/Zermelo–Fraenkel_axioms), the axiom reads:

$\exists A\, \forall x\, (x \notin A)$.[^o2][^o3][^o12]

Or, [alternatively](wikipedia://en/64669#Extension_to_predicate_and_modal_logic), $\exists A\, \lnot \exists y\, (y \in A)$.[^o13]

In words:

[There is](wikipedia://en/91420) a [set](wikipedia://en/26691) such that no element is a member of it.

:::

## Interpretation {#Interpretation}

It follows from the [axiom of extensionality](wikipedia://en/52376) that there is only one set with no elements. Since this set is unique, we can name it. It is called the *[empty set](wikipedia://en/9566)* (denoted by { } or ∅). The axiom, stated in natural language, is:

*An empty set exists*.

This formula is a theorem[^o15], and considered true in every version of set theory. The only controversy is over how it should be justified: by making it an axiom; by deriving it from a set-existence axiom (or logic) and the [axiom schema of separation](wikipedia://en/52386); by deriving it from the axiom of infinity; or some other method.

In some formulations of ZF, the axiom of empty set is actually repeated in the [axiom of infinity](wikipedia://en/246449). However, there are other formulations of that axiom that do not presuppose the existence of an empty set. The ZF axioms can also be written using a [constant symbol](wikipedia://en/10983#Non-logical_symbols) representing the empty set; then the axiom of infinity uses this symbol without requiring it to be empty, while the axiom of empty set is needed to state that it is in fact empty.

Furthermore, one sometimes considers set theories in which there are no infinite sets, and then the axiom of empty set may still be required. However, any axiom of set theory or logic that implies the existence of any set will imply the existence of the empty set, if one has the [axiom schema of separation](https://en.wikipedia.org/wiki/Axiom_schema_of_separation). This is true, since the empty set is that subset of any set consisting of those elements that satisfy a contradictory formula, for example $\varnothing = \{u \in w \mid u \neq u \}$.

In many formulations of first-order predicate logic, the existence of at least one object is always guaranteed. If the axiomatization of set theory is formulated in such a [logical system](https://en.wikipedia.org/wiki/Logical_system) with the [axiom schema of separation](https://en.wikipedia.org/wiki/Axiom_schema_of_separation) as axioms, and if the theory makes no distinction between sets and other kinds of objects (which holds for ZF, KP, and similar theories), then the existence of the empty set is a theorem.

If separation is not postulated as an axiom schema but derived as a theorem schema from the schema of replacement (as is sometimes done), the situation is more complicated and depends on the exact formulation of the replacement schema. The formulation used in the [axiom schema of replacement](wikipedia://en/52387) article only allows to construct the image *F*\[*a*\] when *a* is contained in the domain of the class function *F*; then the derivation of separation requires the axiom of empty set. On the other hand, the constraint of totality of *F* is often dropped from the replacement schema, in which case it implies the separation schema without using the axiom of empty set (or any other axiom for that matter).
