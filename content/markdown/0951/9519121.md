# Quadratically constrained quadratic program

::: {#o1 .subject cue=lead name="Quadratically constrained quadratic program"}

In [mathematical optimization](wikipedia://en/52033), a **quadratically constrained quadratic program** (**QCQP**) is an [optimization problem](wikipedia://en/1126536) in which both the [objective function](https://en.wikipedia.org/wiki/Objective_function) and the [constraints](wikipedia://en/4171950) are [quadratic functions](wikipedia://en/187240). It has the form

:::

$$\begin{aligned} & \text{minimize} && \tfrac12 x^\mathrm{T} P_0 x + q_0^\mathrm{T} x \\ & \text{subject to} && \tfrac12 x^\mathrm{T} P_i x + q_i^\mathrm{T} x + r_i \leq 0 \quad \text{for } i = 1,\dots,m , \\ &&& Ax = b, \end{aligned}$$

where *P*<sub>0</sub>, ..., *P*<sub>*m*</sub> are *n*-by-*n* matrices and *x* ∈ **R**<sup>*n*</sup> is the optimization variable.

If *P*<sub>0</sub>, ..., *P*<sub>*m*</sub> are all [positive semidefinite](https://en.wikipedia.org/wiki/Positive-definite_matrix), then the problem is [convex](wikipedia://en/6292). If these matrices are neither positive nor negative semidefinite, the problem is non-convex. If *P*<sub>1</sub>, ... ,*P*<sub>*m*</sub> are all zero, then the constraints are in fact [linear](wikipedia://en/18102) and the problem is a [quadratic program](https://en.wikipedia.org/wiki/Quadratic_program).

## Hardness {#Hardness}

A convex QCQP problem can be efficiently solved using an interior point method (in a polynomial time), typically requiring around 30-60 iterations to converge. Solving the general non-convex case is an [NP-hard](https://en.wikipedia.org/wiki/NP-hard) problem.

To see this, note that the two constraints *x*<sub>1</sub>(*x*<sub>1</sub> − 1) ≤ 0 and *x*<sub>1</sub>(*x*<sub>1</sub> − 1) ≥ 0 are equivalent to the constraint *x*<sub>1</sub>(*x*<sub>1</sub> − 1) = 0, which is in turn equivalent to the constraint *x*<sub>1</sub> ∈ {0, 1}. Hence, any [0–1 integer program](https://en.wikipedia.org/wiki/0–1_integer_program) (in which all variables have to be either 0 or 1) can be formulated as a quadratically constrained quadratic program. Since 0–1 [integer programming](wikipedia://en/411215) is NP-hard in general, QCQP is also NP-hard.

However, even for a nonconvex QCQP problem a local solution can generally be found with a nonconvex variant of the interior point method. In some cases (such as when solving [nonlinear programming](wikipedia://en/679709) problems with a sequential QCQP approach) these local solutions are sufficiently good to be accepted.

## Relaxation {#Relaxation}

There are two main relaxations of QCQP: using [semidefinite programming](wikipedia://en/4993539) (SDP), and using the [reformulation-linearization technique](https://en.wikipedia.org/wiki/Reformulation-linearization_technique) (RLT). For some classes of QCQP problems (precisely, QCQPs with zero diagonal elements in the data matrices), [second-order cone programming](wikipedia://en/7500026) (SOCP) and [linear programming](wikipedia://en/43730) (LP) relaxations providing the same objective value as the SDP relaxation are available.[^o4]

Nonconvex QCQPs with non-positive off-diagonal elements can be exactly solved by the SDP or SOCP relaxations,[^o5] and there are polynomial-time-checkable sufficient conditions for SDP relaxations of general QCQPs to be exact.[^o6] Moreover, it was shown that a class of random general QCQPs has exact semidefinite relaxations [with high probability](https://en.wikipedia.org/wiki/With_high_probability) as long as the number of constraints grows no faster than a fixed polynomial in the number of variables.[^o6]

### Semidefinite programming {#Semidefinite_programming}

When *P*<sub>0</sub>, ..., *P*<sub>*m*</sub> are all [positive-definite matrices](https://en.wikipedia.org/wiki/Positive-definite_matrix), the problem is [convex](wikipedia://en/1674411) and can be readily solved using [interior point methods](https://en.wikipedia.org/wiki/Interior_point_method), as done with [semidefinite programming](wikipedia://en/4993539).

## Example {#Example}

- [Max Cut](wikipedia://en/2180494) is a problem in graph theory, which is NP-hard. Given a graph, the problem is to divide the vertices in two sets, so that as many edges as possible go from one set to the other. Max Cut can be formulated as a QCQP, and SDP relaxation of the dual provides good lower bounds.
- QCQP is used to finely tune machine setting in high-precision applications such as [photolithography](https://en.wikipedia.org/wiki/Photolithography).
