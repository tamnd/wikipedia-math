# List of interactive geometry software

::: {#o1 .subject cue=lead name="List of interactive geometry software"}

**Interactive geometry software** (**IGS**) or **dynamic geometry environments** (**DGEs**) are [computer programs](https://en.wikipedia.org/wiki/Computer_program) which allow one to create and then manipulate [geometric](wikipedia://en/18973446) constructions, primarily in [plane geometry](https://en.wikipedia.org/wiki/Euclidean_plane_geometry). In most IGS, one starts construction by putting a few points and using them to define new objects such as [lines](https://en.wikipedia.org/wiki/Line_%28mathematics%29), [circles](wikipedia://en/6220) or other points. After some construction is done, one can move the points one started with and see how the construction changes.

:::

## History {#History}

The earliest IGS was the Geometric Supposer, which was developed in the early 1980s.[^o3] This was soon followed by Cabri in 1986 and The Geometer's Sketchpad.

## Comparison {#Comparison}

There are three main types of computer environments for studying school geometry: supposers, dynamic geometry environments (DGEs) and [Logo](https://en.wikipedia.org/wiki/Logo_%28programming_language%29)-based programs.[^o5] Most are DGEs: software that allows the user to manipulate ("drag") the geometric object into different shapes or positions. The main example of a supposer is the Geometric Supposer, which does not have draggable objects, but allows students to study pre-defined shapes. Nearly all of the following programs are DGEs. For a related, comparative physical example of these algorithms, see [Lenart Sphere](https://en.wikipedia.org/wiki/Lenart_Sphere).

## 2D programs {#2D_programs}

### C.a.R. {#C.a.R.}

[C.a.R.](https://en.wikipedia.org/wiki/C.a.R.) is a free [GPL](https://en.wikipedia.org/wiki/GNU_General_Public_License) analog of The Geometer's Sketchpad (GSP), written in [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29).

### Cabri {#Cabri}

[Cabri](https://en.wikipedia.org/wiki/Cabri_Geometry) Cabri was developed by the French school of mathematics education in Grenoble (Laborde, 1993)

### CaRMetal {#CaRMetal}

[CaRMetal](https://en.wikipedia.org/wiki/CaRMetal) is a free [GPL](https://en.wikipedia.org/wiki/GNU_General_Public_License) software written in [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29). Derived from C.a.R., it provides a different user interface.

### Cinderella {#Cinderella}

[Cinderella](https://en.wikipedia.org/wiki/Cinderella_%28software%29), written in [Java](https://en.wikipedia.org/wiki/Java_%28programming_language%29), is very different from The Geometer's Sketchpad. The later version Cinderella.2 also includes a physics simulation engine and a scripting language. Also, it now supports macros, line segments, calculations, arbitrary functions, plots, etc. Full documentation is available online.

### Dr Genius {#Dr_Genius}

Dr Genius was an attempt to merge [Dr. Geo](https://en.wikipedia.org/wiki/Dr._Geo) and the [Genius calculator](https://en.wikipedia.org/wiki/Genius_%28software%29).

### Dr. Geo {#Dr._Geo}

[Dr. Geo](https://en.wikipedia.org/wiki/Dr._Geo) is a GPL interactive software intended for younger students (7-15). The later version, Dr. Geo II,[^o50] is a complete rewrite of Dr. Geo, for the [Squeak](https://en.wikipedia.org/wiki/Squeak_%28programming_language%29)/[Smalltalk](https://en.wikipedia.org/wiki/Smalltalk) environment.

### GCLC {#GCLC}

**GCLC**[^o52] is a dynamic geometry tool for visualizing and teaching geometry, and for producing mathematical illustrations. In GCLC, figures are described rather than drawn. This approach stresses the fact that geometrical constructions are abstract, formal procedures and not figures. A concrete figure can be generated on the basis of the abstract description. There are several output formats, including [LaTeX](https://en.wikipedia.org/wiki/LaTeX), LaTeX/PStricks, LaTeX/Tikz, [SVG](https://en.wikipedia.org/wiki/Scalable_Vector_Graphics) and [PostScript](https://en.wikipedia.org/wiki/PostScript). There is a built-in geometry theorem prover (based on the area method). GCLC is available for [Windows](https://en.wikipedia.org/wiki/Windows) and [Linux](https://en.wikipedia.org/wiki/Linux). WinGCLC is a Windows version of GCLC with a graphical interface that provides a range of additional functionalities. GCLC is open source software (licence CC BY-ND).

### GeoGebra {#GeoGebra}

[GeoGebra](https://en.wikipedia.org/wiki/GeoGebra) is software that combines geometry, algebra and calculus for mathematics education in schools and universities. It is available free of charge for non-commercial users.[^o54]

::: {#o55 .entry cue=list-entry name="GPL license"}

- **License**: open source under [GPL license](https://en.wikipedia.org/wiki/GNU_General_Public_License) (free of charge)

:::

- **Languages**: 55
- **Geometry**: points, lines, all conic sections, vectors, parametric curves, locus lines
- **Algebra**: direct input of inequalities, implicit polynomials, linear and quadratic equations; calculations with numbers, points and vectors
- **Calculus**: direct input of functions (including piecewise-defined); intersections and roots of functions; symbolic derivatives and integrals (built-in CAS); sliders as parameters
- **Parametric graphs**: Yes
- **Implicit polynomials**: Yes

::: {#o56 .entry cue=list-entry name="Java applet"}

- **Web export**: all constructions exportable as web pages as a [Java applet](https://en.wikipedia.org/wiki/Java_applet)

:::

- **Macros**: usable both as tools with the mouse and as commands in the input field
- **Animation**: Yes
- **Spreadsheet**: Yes, the cells can contain any GeoGebra object (numbers, points, functions etc.)
- **Dynamic text**: Yes (including LaTeX)
- **Platforms**: Mac OS, Unix/Linux, Windows (any platform that supports Java 1.5 or later)
- **Continuity**: uses a heuristic 'near-to-approach' to avoid jumping objects

### GeoKone.NET {#GeoKone.NET}

**GeoKone.NET**[^o58] is an interactive recursive natural geometry (or "sacred geometry") generator that runs in a web browser. GeoKone allows the user to create geometric figures using naturalistic rules of recursive copying, such as the [golden ratio](wikipedia://en/12386).

### Geolog {#Geolog}

**Geolog**[^o60] is a logic programming language for finitary geometric logic.

### Geometry Expressions {#Geometry_Expressions}

Geometry Expressions[^o62] does symbolic geometry. It uses real symbolic inputs and returns real and symbolic outputs. It emphasises use with a [computer algebra system](wikipedia://en/54427) (CAS), and exporting and sharing via interactive [HTML5](https://en.wikipedia.org/wiki/HTML5), [Lua](https://en.wikipedia.org/wiki/Lua), and [macOS](https://en.wikipedia.org/wiki/MacOS) dashboard widget apps.

### Jeometry {#Jeometry}

**Jeometry** is a dynamic geometry applet.

### Kig {#Kig}

[Kig](https://en.wikipedia.org/wiki/Kig_%28software%29) is a free ([GPL](https://en.wikipedia.org/wiki/GNU_General_Public_License)) analog of The Geometer's Sketchpad (GSP) for [KDE](https://en.wikipedia.org/wiki/KDE), but more calculus-oriented. It is a part of the [KDE Edutainment Project](https://en.wikipedia.org/wiki/KDE_Edutainment_Project).

### KmPlot {#KmPlot}

[KmPlot](https://en.wikipedia.org/wiki/KmPlot) is a mathematical function plotter released under the free [GPL license](https://en.wikipedia.org/wiki/GNU_General_Public_License). Includes a powerful parser and precision printing in correct scale. Simultaneously plot multiple functions and combine function terms to build new functions. Supports functions with parameters and functions in polar coordinates. Several grid modes are available. Features include:

- powerful mathematical parser
- precise metric printing
- different plot types (functions, parametric, polar)
- highly configurable visual settings (plot line, axes, grid)

::: {#o76 .entry cue=list-entry name="BMP"}

- export to bitmap format ([BMP](https://en.wikipedia.org/wiki/BMP_file_format) and [PNG](https://en.wikipedia.org/wiki/Portable_Network_Graphics)) and to [Scalable Vector Graphics](https://en.wikipedia.org/wiki/Scalable_Vector_Graphics) (SVG)

:::

::: {#o77 .entry cue=list-entry name="XML"}

- save/load complete session in readable [XML](https://en.wikipedia.org/wiki/XML) format

:::

- trace mode: cross-hair following plot, coordinates shown in the status bar
- zooming support
- ability to draw the 1st and 2nd derivative and the integral of a plot function
- support user-defined constants and parameter values
- various tools for plot functions: find minimum/maximum point, get y-value and draw the area between the function and the y-axis

### KSEG {#KSEG}

[KSEG](wikipedia://en/1055128) is a free ([GPL](https://en.wikipedia.org/wiki/GNU_General_Public_License)) analog of The Geometer's Sketchpad (GSP) with some unique features. This software can handle heavy, complex constructions in Euclidean geometry.

- **Deterministic**
- **Languages:** Dutch, English, French, Chinese, German, Hungarian, Italian, Japanese, Norwegian Bokmål, Portuguese, Russian, Spanish, Turkish, Welsh
- **Macros:** Yes. Editable and with support for recursion
- **Java-applet:** No
- **Animation:** No
- **Locus:** Yes, but no direct way to place a point on a locus.
- **Assignments:** No
- **Measurement/calculations:** Yes (the calculator is a bit strange)

::: {#o79 .entry cue=list-entry name="Qt"}

- **Platform:** Unix/Linux, Windows, Mac OS (any platform that supports [Qt](https://en.wikipedia.org/wiki/Qt_%28software%29))

:::

- **Proofs:** No
- **Extra:** Editable

### Live Geometry {#Live_Geometry}

Live Geometry is a free [CodePlex](https://en.wikipedia.org/wiki/CodePlex) project that lets you create interactive ruler and compass constructions and experiment with them. It is written in [Silverlight](https://en.wikipedia.org/wiki/Silverlight) 4 and C# 4.0 (Visual Studio 2010). The core engine is a flexible and extensible framework that allows easy addition of new figure types and features. The project has two front-ends: WPF and Silverlight, which both share the common *DynamicGeometry* library.

### TracenPoche {#TracenPoche}

[TracenPoche](https://en.wikipedia.org/wiki/TracenPoche) is a completely [Adobe Flash](https://en.wikipedia.org/wiki/Adobe_Flash) program. It is available in English, Spanish, and French.

### Archimedes Geo3D {#Archimedes_Geo3D}

[Archimedes Geo3D](https://en.wikipedia.org/wiki/Archimedes_Geo3D) is a shareware program designed for 3D geometric constructions. It extends traditional ruler and compass constructions into 3D space, allowing users to work with elements such as points, lines, circles, planes, spheres, vectors, and loci. ## Continuity versus determinism {#Continuity_versus_determinism}

All these programs can be divided into two category: deterministic and continuous. GeoGebra can be deterministic or continuous (one can change it in preferences).

All constructions in the deterministic programs (GSP, Cabri, Kseg and most of others) are completely determined by the given points but the result of some constructions can jump or behave unexpectedly when a given point is moved.

On the contrary, some constructions in continuous programs (so far only Cinderella and GeoGebra), depend on the number of hidden parameters and in such a way that moving a given point produces a continuous motion of the construction, as a result, if the point is moved back to the original position the result of construction might be different.

Here is a test to check whether a particular program is continuous:

Construct the [orthocenter](wikipedia://en/161244) of triangle and three midpoints (say *A', B' C**) between vertices and orthocenter.***

Construct a [circumcircle](wikipedia://en/1926432) of *A'B'C'*.

This is the [nine-point circle](wikipedia://en/161243), it intersects each side of the original triangle at two points: the base of altitude and midpoint. Construct an intersection of one side with the circle at midpoint now move opposite vertex of the original triangle, if the constructed point does not move when base of altitude moves through it that probably means that your program is continuous.

Although it is possible to make a deterministic program which behaves continuously in this and similar simple examples, in general it can be proved that no program can be continuous and deterministic at the same time.[^o90]
