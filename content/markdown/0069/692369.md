# Fractional coloring

*Image: Graph fractional coloring.svg.* 5:2-coloring of [Dodecahedral graph](wikipedia://en/8407). A 4:2-coloring of this graph does not exist.

::: {#o1 .subject cue=lead name="Fractional coloring"}

**Fractional coloring** is a topic in a branch of [graph theory](wikipedia://en/12401) known as [fractional graph theory](https://en.wikipedia.org/wiki/Fractional_graph_theory). It is a generalization of ordinary [graph coloring](wikipedia://en/426743). In a traditional graph coloring, each vertex in a graph is assigned some color, and adjacent vertices — those connected by edges — must be assigned different colors. In a fractional coloring however, a *set* of colors is assigned to each vertex of a graph. The requirement about adjacent vertices still holds, so if two vertices are joined by an edge, they must have no colors in common.

:::

Fractional graph coloring can be viewed as the [linear programming relaxation](wikipedia://en/6368430) of traditional graph coloring. Indeed, fractional coloring problems are much more amenable to a linear programming approach than traditional coloring problems.

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

*Image: Fractional coloring of C5.png.* Above: A 3:1-coloring of the cycle on 5 vertices, and the corresponding 6:2-coloring.Below: A 5:2 coloring of the same graph.

A ***b*-fold coloring** of a graph *G* is an assignment of sets of size *b* to vertices of a graph such that adjacent vertices receive [disjoint sets](wikipedia://en/39359). An ***a*:*b*-coloring** is a *b*-fold coloring out of *a* available colors. Equivalently, it can be defined as a homomorphism to the [Kneser graph](wikipedia://en/2724154) $KG_{a,b}$. The ***b*-fold chromatic number** $\chi_b(G)$ is the least *a* such that an *a*:*b*-coloring exists. Note that the regular [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number) $\chi(G)$ is exactly $\chi_1(G)$.

The **fractional chromatic number** $\chi_f(G)$ is defined to be:

$$\chi_{f}(G) = \lim_{b \to \infty}\frac{\chi_{b}(G)}{b} = \inf_{b}\frac{\chi_{b}(G)}{b}$$

Note that the limit exists because $\chi_b(G)$ is *[subadditive](https://en.wikipedia.org/wiki/Subadditive_function)*, meaning: $\chi_{a+b}(G) \le \chi_a(G) + \chi_b(G).$

The fractional chromatic number can equivalently be defined in probabilistic terms. $\chi_f(G)$ is the smallest *k* for which there exists a [probability distribution](wikipedia://en/23543) over the [independent sets](wikipedia://en/524501) of *G* such that for each vertex *v*, given an independent set *S* drawn from the distribution:

$$\Pr(v\in S) \geq \frac{1}{k}.$$

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

We have:

$$\chi_f(G)\ge \frac{n(G)}{\alpha(G)},$$

with equality for [vertex-transitive graphs](wikipedia://en/581175), where *n*(*G*) is the [order](wikipedia://en/325802#Basics) of *G*, α(*G*) is the [independence number](https://en.wikipedia.org/wiki/Independence_number).[^o6]

Moreover:

$$\omega(G) \le \chi_f(G) \le \chi(G),$$

where ω(*G*) is the [clique number](https://en.wikipedia.org/wiki/Clique_number), and $\chi(G)$ is the [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number).

Furthermore, the fractional chromatic number approximates the chromatic number within a logarithmic factor,[^o7] in fact:

$$\frac{\chi(G)}{1+\ln \alpha(G)} \le \chi_f(G) \le \frac{\chi_b(G)}{b} \le \chi(G).$$

Kneser graphs give examples where: $\chi(G) /\chi_f(G)$ is arbitrarily large, since: $\chi(KG_{m,n}) =m-2n+2,$ while $\chi_f(KG_{m,n}) = \tfrac{m}{n}.$

:::

## Linear programming (LP) formulation {#Linear_programming_(LP)_formulation}

The fractional chromatic number $\chi_f(G)$ of a graph *G* can be obtained as a solution to a [linear program](wikipedia://en/43730). Let $\mathcal{I}(G)$ be the set of all independent sets of *G*, and let $\mathcal{I}(G,x)$ be the set of all those independent sets which include vertex *x*. For each independent set *I*, define a nonnegative real variable *x<sub>I</sub>*. Then $\chi_f(G)$ is the minimum value of:

$$\sum_{I\in\mathcal{I}(G)} x_I,$$

subject to:

$$\sum_{I\in\mathcal{I}(G,x)} x_I \ge 1$$

for each vertex $x$.

The [dual](https://en.wikipedia.org/wiki/Dual_problem) of this linear program computes the "fractional clique number", a relaxation to the rationals of the integer concept of [clique number](https://en.wikipedia.org/wiki/Clique_number). That is, a weighting of the vertices of *G* such that the total weight assigned to any independent set is at most *1*. The [strong duality](wikipedia://en/34390810) theorem of linear programming guarantees that the optimal solutions to both linear programs have the same value. Note however that each linear program may have size that is exponential in the number of vertices of *G*, and that computing the fractional chromatic number of a graph is [NP-hard](https://en.wikipedia.org/wiki/NP-hard).[^o9] This stands in contrast to the problem of fractionally coloring the edges of a graph, which can be solved in polynomial time. This is a straightforward consequence of Edmonds' [matching polytope](wikipedia://en/64572404) theorem.[^o10][^o11]

## Applications {#Applications}

Applications of fractional graph coloring include *activity scheduling*. In this case, the graph *G* is a *conflict graph*: an edge in *G* between the nodes *u* and *v* denotes that *u* and *v* cannot be active simultaneously. Put otherwise, the set of nodes that are active simultaneously must be an independent set in graph *G*.

An optimal fractional graph coloring in *G* then provides a shortest possible schedule, such that each node is active for (at least) 1 time unit in total, and at any point in time the set of active nodes is an independent set. If we have a solution *x* to the above linear program, we simply traverse all independent sets *I* in an arbitrary order. For each *I*, we let the nodes in *I* be active for $x_I$ time units; meanwhile, each node not in *I* is inactive.

In more concrete terms, each node of *G* might represent a *radio transmission* in a wireless communication network; the edges of *G* represent *interference* between radio transmissions. Each radio transmission needs to be active for 1 time unit in total; an optimal fractional graph coloring provides a minimum-length schedule (or, equivalently, a maximum-bandwidth schedule) that is conflict-free.

### Comparison with traditional graph coloring {#Comparison_with_traditional_graph_coloring}

If one further required that each node must be active *continuously* for 1 time unit (without switching it off and on every now and then), then traditional graph [vertex coloring](https://en.wikipedia.org/wiki/Vertex_coloring) would provide an optimal schedule: first the nodes of color 1 are active for 1 time unit, then the nodes of color 2 are active for 1 time unit, and so on. Again, at any point in time, the set of active nodes is an independent set.

In general, fractional graph coloring provides a shorter schedule than non-fractional graph coloring; there is an [integrality gap](https://en.wikipedia.org/wiki/Integrality_gap). It may be possible to find a shorter schedule, at the cost of switching devices (such as radio transmitters) on and off more than once.

:::
