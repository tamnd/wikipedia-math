# Affine logic

::: {#o1 .subject cue=lead name="Affine logic"}

**Affine logic** is a [substructural logic](wikipedia://en/412909) whose proof theory rejects the [structural rule](wikipedia://en/697666) of [contraction](https://en.wikipedia.org/wiki/Idempotency_of_entailment). It can also be characterized as [linear logic](wikipedia://en/579675) with [weakening](wikipedia://en/693185).

:::

The name "affine logic" is associated with [linear logic](wikipedia://en/579675), to which it differs by allowing the weakening rule. [Jean-Yves Girard](wikipedia://en/579673) introduced the name as part of the [geometry of interaction](wikipedia://en/8561592) semantics of linear logic, which characterizes linear logic in terms of [linear algebra](wikipedia://en/18422); here he alludes to [affine transformations](wikipedia://en/38449) on [vector spaces](wikipedia://en/32370).[^o2]

Affine logic predated linear logic. V. N. Grishin used this logic in 1974,[^o3] after observing that [Russell's paradox](wikipedia://en/46095) cannot be derived in a [set theory](wikipedia://en/27553) without contraction, even with an [unbounded comprehension axiom](https://en.wikipedia.org/wiki/Unrestricted_comprehension).[^o4] Likewise, the logic formed the basis of a [decidable](wikipedia://en/913118) sub-theory of [predicate logic](https://en.wikipedia.org/wiki/Predicate_logic), called 'Direct logic' (Ketonen & Wehrauch, 1984; Ketonen & Bellin, 1989).

Affine logic can be embedded into linear logic by rewriting the affine arrow $A \rightarrow B$ as the linear arrow$A \multimap B \otimes \top$.

Whereas full linear logic (i.e. propositional linear logic with multiplicatives, additives, and exponentials) is undecidable, full affine logic is decidable.

Affine logic forms the foundation of [ludics](wikipedia://en/902801).
