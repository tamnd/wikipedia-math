# Nemeth Braille

::: {#o1 .subject cue=lead name="Nemeth Braille"}

The **Nemeth Braille Code for Mathematics and Science Notation** is a [Braille code](https://en.wikipedia.org/wiki/Braille_code) for encoding mathematical and scientific notation linearly using standard six-dot [Braille cells](https://en.wikipedia.org/wiki/Braille_cell) for tactile reading by the visually impaired. The code was developed by [Abraham Nemeth](wikipedia://en/2046064). The Nemeth Code was first written up in 1952. It was revised in 1956, 1965, and 1972.[^o3] It is an example of a compact human-readable [markup language](https://en.wikipedia.org/wiki/Markup_language).

:::

Nemeth Braille is one code used to write mathematics in braille. There are many systems in use around the world.[^o4]

::: {#o6 .statement cue=named-heading name="Principles of the Nemeth Code"}

## Principles of the Nemeth Code {#Principles_of_the_Nemeth_Code}

The Nemeth Code Book (1972) opens with the following words:

One consequence is that the braille transcriber does not need to know the underlying mathematics. The braille transcriber needs to identify the inkprint symbols and know how to render them in Nemeth Code braille. For example, if the same math symbol might have two different meanings, this would not matter; both instances would be brailled the same. This is in contrast to the International [Braille Music](https://en.wikipedia.org/wiki/Braille_music) Code, where the braille depends on the meaning of the inkprint music. Thus a knowledge of music is required to produce braille music.

:::
