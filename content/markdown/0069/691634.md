# Club principle

::: {#o1 .subject cue=lead name="Club principle"}

In [mathematics](wikipedia://en/18831), and particularly in [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory), the **club principles** ♣<sub>*S*</sub> are a family of [combinatorial principles](wikipedia://en/5170) that are a weaker version of the corresponding [◊<sub>*S*</sub>](https://en.wikipedia.org/wiki/Diamondsuit); it was introduced in 1975 by Adam Ostaszewski.[^o2]

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a given [cardinal number](wikipedia://en/6173) $\kappa$ and a [stationary set](wikipedia://en/1679067) $S \subseteq \kappa$, $\clubsuit_{S}$ is the statement that there is a [sequence](wikipedia://en/27838) $\left\langle A_\delta: \delta \in S\right\rangle$ such that

- every *A*<sub>*δ*</sub> is a cofinal [subset](wikipedia://en/27631) of *δ*
- for every [unbounded subset](wikipedia://en/26547932#Closed_unbounded_sets_and_classes) $A \subseteq \kappa$, there is a $\delta$ so that $A_{\delta} \subseteq A$

$\clubsuit_{\omega_1}$ is usually written as just $\clubsuit$.

:::

## ♣ and ◊ {#♣_and_◊}

It is clear that [◊](wikipedia://en/691736) ⇒ ♣, and it was shown in 1975 that ♣ + [CH](wikipedia://en/5705) ⇒ ◊; however, [Saharon Shelah](wikipedia://en/331211) gave a proof in 1980 that there exists a model of ♣ in which CH does not hold, so ♣ and ◊ are not equivalent (since ◊ ⇒ CH).[^o6]
