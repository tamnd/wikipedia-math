# Buchberger's algorithm

::: {#o1 .subject cue=lead name="Buchberger's algorithm"}

In the theory of [multivariate polynomials](https://en.wikipedia.org/wiki/Multivariate_polynomial), **Buchberger's algorithm** is a method for transforming a given set of polynomials into a [Gröbner basis](wikipedia://en/357328), which is another set of polynomials that have the same common zeros and are more convenient for extracting information on these common zeros. It was introduced by [Bruno Buchberger](wikipedia://en/1924233) simultaneously with the definition of Gröbner bases.

:::

The [Euclidean algorithm](wikipedia://en/10377) for computing the polynomial [greatest common divisor](wikipedia://en/12354) is a special case of Buchberger's algorithm restricted to polynomials of a single variable. [Gaussian elimination](wikipedia://en/13035) of a [system of linear equations](wikipedia://en/113087) is another special case where the degree of all polynomials equals one.

For other Gröbner basis algorithms, see Gröbner basis#Algorithms and implementations.

::: {#o3 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

A crude version of this algorithm to find a basis for an ideal $I$ of a polynomial ring *R* proceeds as follows:

**Input** A set of polynomials *F* that generates $I$

**Output** A [Gröbner basis](wikipedia://en/357328) *G* for $I$

1. *G* := *F*
1. For every *f<sub>i</sub>*, *f<sub>j</sub>* in *G*, denote by *g<sub>i</sub>* the leading term of *f<sub>i</sub>* with respect to the given [monomial ordering](https://en.wikipedia.org/wiki/Monomial_ordering), and by *a<sub>ij</sub>* the [least common multiple](wikipedia://en/17961) of *g<sub>i</sub>* and *g<sub>j</sub>*.
1. Choose two polynomials in *G* and let $S_{ij} = \tfrac{a_{ij}}{g_{i}} f_{i} - \tfrac{a_{ij}}{g_{j}} f_{j}$ *(The leading terms here will cancel by construction)*.
1. Reduce *S*<sub>*ij*</sub>, with the [multivariate division algorithm](https://en.wikipedia.org/wiki/Multivariate_division_algorithm) relative to the set *G* until the result is not further reducible. If the result is non-zero, add it to *G*.
1. Repeat steps 2–4 until all possible pairs are considered, including those involving the new polynomials added in step 4.
1. Output *G*

The polynomial *S*<sub>*ij*</sub> is commonly referred to as the *S*-polynomial, where *S* refers to *subtraction* (Buchberger) or *[syzygy](https://en.wikipedia.org/wiki/Syzygy_%28mathematics%29)* (others). The pair of polynomials with which it is associated is commonly referred to as [critical pair](https://en.wikipedia.org/wiki/Critical_pair_%28logic%29).

There are many ways to improve this algorithm beyond what has been stated above. For example, all the new elements of *F* can be reduced relative to each other before adding them. If the leading terms of *f<sub>i</sub>* and *f<sub>j</sub>* share no variables in common, then *S<sub>ij</sub>* will *always* reduce to 0 (if using only $f_{i}$ and $f_{j}$ for reduction), so it needn't be calculated at all.

The algorithm terminates because it is consistently increasing the size of the monomial ideal generated by the leading terms of our set *F*, and [Dickson's lemma](wikipedia://en/357371) (or the [Hilbert basis theorem](https://en.wikipedia.org/wiki/Hilbert_basis_theorem)) guarantees that any such ascending chain must eventually become constant.

:::

## Complexity {#Complexity}

The [computational complexity](wikipedia://en/405944) of Buchberger's algorithm is very difficult to estimate, because of the number of choices that may dramatically change the computation time. Nevertheless, T. W. Dubé has proved[^o5] that the degrees of the elements of a reduced Gröbner basis are always bounded by

$$2\left(\frac{d^2}{2} +d\right)^{2^{n-1}},$$

where $n$ is the number of variables, and $d$ the maximal [total degree](https://en.wikipedia.org/wiki/Total_degree) of the input polynomials. This allows, in theory, to use [linear algebra](wikipedia://en/18422) over the [vector space](wikipedia://en/32370) of the polynomials of degree bounded by this value, for getting an algorithm of complexity $d^{2^{n+o(1)}}$.

On the other hand, there are examples[^o6] where the Gröbner basis contains elements of degree

$$d^{2^{\Omega(n)}},$$

and the above upper bound of complexity is optimal. Nevertheless, such examples are extremely rare.

Since its discovery, many variants of Buchberger's have been introduced to improve its efficiency. [Faugère's F4 and F5 algorithms](https://en.wikipedia.org/wiki/Faugère's_F4_and_F5_algorithms) are presently the most efficient algorithms for computing Gröbner bases, and allow to compute routinely Gröbner bases consisting of several hundreds of polynomials, having each several hundreds of terms and coefficients of several hundreds of digits.

## Implementations {#Implementations}

At least one implementation of Buchberger’s algorithm has been [proved](wikipedia://en/1197184) correct within the [proof assistant](wikipedia://en/1258607) [Rocq](wikipedia://en/581974) (formerly named Coq).[^o9]

In the [SymPy](https://en.wikipedia.org/wiki/SymPy) library for [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29), the (improved) Buchberger algorithm is implemented as `sympy.polys.polytools.groebner()`.[^o10]

:::
