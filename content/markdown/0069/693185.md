# Monotonicity of entailment

::: {#o1 .subject cue=lead name="Monotonicity of entailment"}

**Monotonicity of entailment** is a property of many [logical systems](https://en.wikipedia.org/wiki/Logical_system) such that if a sentence follows deductively from a given set of sentences then it also follows deductively from any superset of those sentences. A corollary is that if a given argument is deductively [valid](wikipedia://en/21304742), it cannot become invalid by the addition of extra premises.[^n1][^n2]

:::

Logical systems with this property are called monotonic logics in order to differentiate them from [non-monotonic logics](wikipedia://en/341086). [Classical logic](wikipedia://en/55868) and [intuitionistic logic](wikipedia://en/169262) are examples of monotonic logics.

## Weakening rule {#Weakening_rule}

Monotonicity may be stated formally as a rule called **weakening**, or sometimes **thinning**. A system is monotonic if and only if the rule is [admissible](wikipedia://en/1151794). The weakening rule may be expressed as a natural deduction sequent:

$$\frac{\Gamma \vdash C}{\Gamma, A \vdash C }$$

This can be read as saying that if, on the basis of a set of assumptions $\Gamma$, one can prove C, then by adding an assumption A, one can still prove C.

::: {#o6 .example cue=heading name="Example"}

## Example {#Example}

The following argument is valid: "All men are mortal. Socrates is a man. Therefore Socrates is mortal." This can be weakened by adding a premise: "All men are mortal. Socrates is a man. Cows produce milk. Therefore Socrates is mortal." By the property of monotonicity, the argument remains valid with the additional premise, even though the premise is irrelevant to the conclusion.

:::

## Non-monotonic logics {#Non-monotonic_logics}

In most logics, weakening is either an inference rule or a [metatheorem](wikipedia://en/5106151) if the logic doesn't have an explicit rule. Notable exceptions are:

- [Relevance logic](wikipedia://en/185076), where every premise is necessary for the conclusion.
- [Linear logic](wikipedia://en/579675), which lacks monotonicity and [idempotency of entailment](https://en.wikipedia.org/wiki/Idempotency_of_entailment).
