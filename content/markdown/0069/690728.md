# Harmonious coloring

*Image: Harmonious coloring tree.svg.* Harmonious coloring of the complete 7-ary [tree](wikipedia://en/48560) with 3 levels using 12 colors. The harmonious chromatic number of this graph is 12. Any fewer colors will result in a color pair appearing on more than one pair of adjacent vertices. Moreover, by Mitchem's Formula, $\chi_{H}(T_{7,3}) = \lceil(3/2)(7+1)\rceil = 12$.

::: {#o1 .subject cue=lead name="Harmonious coloring"}

In [graph theory](wikipedia://en/12401), a **harmonious coloring** is a (proper) [vertex coloring](https://en.wikipedia.org/wiki/Vertex_coloring) in which every pair of colors appears on *at most* one pair of adjacent [vertices](wikipedia://en/638899). It is the opposite of the [complete coloring](wikipedia://en/690736), which instead requires every color pairing to occur *at least* once. The **harmonious chromatic number** $\chi_{H}(G)$ of a [graph](wikipedia://en/325806) $G$ is the minimum number of colors needed for any harmonious coloring of $G$.

:::

Every graph has a harmonious coloring, since it suffices to assign every vertex a distinct color; thus $\chi_{H}(G) \le \lvert V(G)\rvert$. There trivially exist graphs $G$ with $\chi_{H}(G) > \chi(G)$ (where $\chi$ is the [chromatic number](https://en.wikipedia.org/wiki/Chromatic_number)); one example is any path of length > 2, which can be 2-colored but has no harmonious coloring with 2 colors.

Some properties of $\chi_{H}(G)$:

$$\chi_{H}(T_{k,3}) = \left\lceil\frac{3(k+1)}{2}\right\rceil,$$

where $T_{k,3}$ is the complete [$k$-ary](wikipedia://en/325802#k-ary) tree with 3 levels. (Mitchem 1989)

Harmonious coloring was first proposed by Harary and Plantholt (1982). Still very little is known about it.
