# Akaike information criterion

::: {#o1 .subject cue=lead name="Akaike information criterion"}

The **Akaike information criterion** (**AIC**) is an [estimator](wikipedia://en/10043) of [prediction error](https://en.wikipedia.org/wiki/Prediction_error) and thereby relative quality of [statistical models](wikipedia://en/27576) for a given set of data.[^o2][^o3][^o4] Given a collection of models for the data, AIC estimates the quality of each model, relative to each of the other models. Thus, AIC provides a means for [model selection](wikipedia://en/3664073).

:::

AIC is founded on [information theory](wikipedia://en/14773). When a statistical model is used to represent the process that generated the data, the representation will almost never be exact; so some information will be lost by using the model to represent the process. AIC estimates the relative amount of information lost by a given model: the less information a model loses, the higher the quality of that model.

In estimating the amount of information lost by a model, AIC deals with the trade-off between the [goodness of fit](wikipedia://en/2474821) of the model and the simplicity of the model, balancing the risk of [overfitting](wikipedia://en/173332) with the risk of underfitting.

The Akaike information criterion is named after the Japanese statistician [Hirotugu Akaike](https://en.wikipedia.org/wiki/Hirotugu_Akaike), who formulated it. It now forms the basis of a paradigm for the [foundations of statistics](wikipedia://en/15515301) and is also widely used for [statistical inference](wikipedia://en/27577).

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

Suppose that we have a [statistical model](wikipedia://en/27576) of some data. Let $k$ be the number of estimated [parameters](wikipedia://en/413291) in the model. Let $\hat L$ be the maximized value of the [likelihood function](wikipedia://en/44968) for the model. Then the AIC value of the model is the following.[^o7][^o74]

$$\mathrm{AIC} \, = \, 2k - 2\ln(\hat L)$$

Given a set of candidate models for the data, the preferred model is the one with the minimum AIC value. Thus, AIC rewards [goodness of fit](wikipedia://en/2474821) (as assessed by the likelihood function), but it also includes a penalty that is an increasing function of the number of estimated parameters. The penalty discourages [overfitting](wikipedia://en/173332), which is desired because increasing the number of parameters in the model almost always improves the goodness of the fit.

Suppose that the data is generated by some unknown process *f*. We consider two candidate models to represent *f*: *g*<sub>1</sub> and *g*<sub>2</sub>. If we knew *f*, then we could find the information lost from using *g*<sub>1</sub> to represent *f* by calculating the [Kullback–Leibler divergence](wikipedia://en/1115052), *D*<sub>KL</sub>(*f* ‖ *g*<sub>1</sub>); similarly, the information lost from using *g*<sub>2</sub> to represent *f* could be found by calculating *D*<sub>KL</sub>(*f* ‖ *g*<sub>2</sub>). We would then, generally, choose the candidate model that minimized the information loss.

We cannot choose with certainty, because we do not know *f*. (Akaike 1974) showed, however, that we can estimate, via AIC, how much more (or less) information is lost by *g*<sub>1</sub> than by *g*<sub>2</sub>. The estimate, though, is only valid [asymptotically](wikipedia://en/26024794); if the number of data points is small, then some correction is often necessary (see AICc, below).

Note that AIC tells nothing about the absolute quality of a model, only the quality relative to other models. Thus, if all the candidate models fit poorly, AIC will not give any warning of that. Hence, after selecting a model via AIC, it is usually good practice to validate the absolute quality of the model. Such validation commonly includes checks of the model's [residuals](wikipedia://en/461509) (to determine whether the residuals seem random) and tests of the model's predictions. For more on this topic, see *[statistical model validation](wikipedia://en/26502065)*.

:::

## How to use AIC in practice {#How_to_use_AIC_in_practice}

To apply AIC in practice, we start with a set of candidate models, and then find the models' corresponding AIC values. There will almost always be information lost due to using a candidate model to represent the "true model," i.e. the process that generated the data. We wish to select, from among the candidate models, the model that minimizes the information loss. We cannot choose with certainty, but we can minimize the estimated information loss.

Suppose that there are *R* candidate models. Denote the AIC values of those models by AIC<sub>1</sub>, AIC<sub>2</sub>, AIC<sub>3</sub>, ..., AIC<sub>*R*</sub>. Let AIC<sub>min</sub> be the minimum of those values. Then the quantity exp((AIC<sub>min</sub> − AIC<sub>*i*</sub>)/2) can be interpreted as being proportional to the probability that the *i*th model minimizes the (estimated) information loss.[^o10]

As an example, suppose that there are three candidate models, whose AIC values are 100, 102, and 110. Then the second model is $\exp((100 - 102)/2) = 0.368$ times as probable as the first model to minimize the information loss. Similarly, the third model is $\exp((100 - 110)/2) = 0.007$ times as probable as the first model to minimize the information loss.

In this example, we would omit the third model from further consideration. We then have three options: (1) gather more data, in the hope that this will allow clearly distinguishing between the first two models; (2) simply conclude that the data is insufficient to support selecting one model from among the first two; (3) take a weighted average of the first two models, with weights proportional to 1 and 0.368, respectively, and then do [statistical inference](wikipedia://en/27577) based on the weighted [multimodel](wikipedia://en/22212276).[^o11]

The quantity $\exp((\operatorname{AIC}_{\min} - \operatorname{AIC}_{i})/2)$ is known as the *[relative likelihood](wikipedia://en/55754796)* of model *i*. It is closely related to the likelihood ratio used in the [likelihood-ratio test](wikipedia://en/45035). Indeed, if all the models in the candidate set have the same number of parameters, then using AIC might at first appear to be very similar to using the likelihood-ratio test. There are, however, important distinctions. In particular, the likelihood-ratio test is valid only for [nested models](wikipedia://en/27576#Nested_models), whereas AIC (and AICc) has no such restriction.[^o12][^o13]

## Hypothesis testing {#Hypothesis_testing}

Every [statistical hypothesis test](wikipedia://en/30284) can be formulated as a comparison of statistical models. Hence, every statistical hypothesis test can be replicated via AIC. Two examples are briefly described in the subsections below. Details for those examples, and many more examples, are given by (Sakamoto Ishiguro Kitagawa 1986, Part II) and (Konishi Kitagawa 2008, ch. 4).

### Replicating Student's *t*-test {#Replicating_Student's_t-test}

As an example of a hypothesis test, consider the [*t*-test](wikipedia://en/536080) to compare the means of two [normally-distributed](wikipedia://en/21462) populations. The input to the *t*-test comprises a random sample from each of the two populations.

To formulate the test as a comparison of models, we construct two different models. The first model models the two populations as having potentially different means and standard deviations. The likelihood function for the first model is thus the product of the likelihoods for two distinct normal distributions; so it has four parameters: $\mu_{1}, \sigma_{1}, \mu_{2}, \sigma_{2}$. To be explicit, the [likelihood function](wikipedia://en/44968) is as follows (denoting the sample sizes by $n_{1}$ and $n_{2}$).

$$\mathcal{L}(\mu_1,\sigma_1,\mu_2,\sigma_2) \, = \,$$

$$\; \; \; \; \; \; \; \; \prod_{i=1}^{n_1} \frac{1}{\sqrt{2 \pi}\sigma_1} \exp\left( -\frac{(x_i-\mu_1)^2}{2\sigma_1^2}\right) \; \, \boldsymbol\cdot \, \prod_{i=n_1+1}^{n_1+n_2} \frac{1}{\sqrt{2 \pi}\sigma_2} \exp\left( -\frac{(x_i-\mu_2)^2}{2\sigma_2^2}\right)$$

The second model models the two populations as having the same means and the same standard deviations. The likelihood function for the second model thus sets $\mu_{1} = \mu_{2}$ and $\sigma_{1} = \sigma_{2}$ in the above equation; so it only has two parameters.

We then maximize the likelihood functions for the two models (in practice, we maximize the log-likelihood functions); after that, it is easy to calculate the AIC values of the models. We next calculate the relative likelihood. For instance, if the second model was only 0.01 times as likely as the first model, then we would omit the second model from further consideration: so we would conclude that the two populations have different means.

The *t*-test assumes that the two populations have identical standard deviations; the test tends to be unreliable if the assumption is false and the sizes of the two samples are very different ([Welch's *t*-test](wikipedia://en/7849883) would be better). Comparing the means of the populations via AIC, as in the example above, has the same disadvantage. However, one could create a third model that allows different standard deviations. This third model would have the advantage of not making such assumptions at the cost of an additional parameter and thus degree of freedom.

### Comparing categorical data sets {#Comparing_categorical_data_sets}

For another example of a hypothesis test, suppose that we have two populations, and each member of each population is in one of two [categories](wikipedia://en/821165)—category #1 or category #2. Each population is [binomially distributed](https://en.wikipedia.org/wiki/Binomially_distributed). We want to know whether the distributions of the two populations are the same. We are given a random sample from each of the two populations.

Let $m$ be the size of the sample from the first population. Let $m_{1}$ be the number of observations (in the sample) in category #1; so the number of observations in category #2 is $m - m_{1}$. Similarly, let $n$ be the size of the sample from the second population. Let $n_{1}$ be the number of observations (in the sample) in category #1.

Let $p$ be the probability that a randomly-chosen member of the first population is in category #1. Hence, the probability that a randomly-chosen member of the first population is in category #2 is $1 - p$. Note that the distribution of the first population has one parameter. Let $q$ be the probability that a randomly-chosen member of the second population is in category #1. Note that the distribution of the second population also has one parameter.

To compare the distributions of the two populations, we construct two different models. The first model models the two populations as having potentially different distributions. The likelihood function for the first model is thus the product of the likelihoods for two distinct binomial distributions; so it has two parameters: $p$, $q$. To be explicit, the likelihood function is as follows.

$$\mathcal{L}(p,q) \, = \, \frac{m!}{m_1! (m-m_1)!} p^{m_1} (1-p)^{m-m_1} \; \, \boldsymbol\cdot \; \; \frac{n!}{n_1! (n-n_1)!} q^{n_1} (1-q)^{n-n_1}$$

The second model models the two populations as having the same distribution. The likelihood function for the second model thus sets $p = q$ in the above equation; so the second model has one parameter.

We then maximize the likelihood functions for the two models (in practice, we maximize the log-likelihood functions); after that, it is easy to calculate the AIC values of the models. We next calculate the relative likelihood. For instance, if the second model was only 0.01 times as likely as the first model, then we would omit the second model from further consideration: so we would conclude that the two populations have different distributions.

:::

## Foundations of statistics {#Foundations_of_statistics}

[Statistical inference](wikipedia://en/27577) is generally regarded as comprising hypothesis testing and [estimation](wikipedia://en/10043). Hypothesis testing can be done via AIC, as discussed above. Regarding estimation, there are two types: [point estimation](wikipedia://en/160379) and [interval estimation](wikipedia://en/160381). Point estimation can be done within the AIC paradigm: it is provided by [maximum likelihood estimation](wikipedia://en/140806). Interval estimation can also be done within the AIC paradigm: it is provided by [likelihood intervals](https://en.wikipedia.org/wiki/Likelihood_interval). Hence, statistical inference generally can be done within the AIC paradigm.

The most commonly used paradigms for statistical inference are [frequentist inference](wikipedia://en/15537745) and [Bayesian inference](wikipedia://en/49571). AIC, though, can be used to do statistical inference without relying on either the frequentist paradigm or the Bayesian paradigm: because AIC can be interpreted without the aid of [significance levels](wikipedia://en/160995) or [Bayesian priors](https://en.wikipedia.org/wiki/Bayesian_prior).[^o21] In other words, AIC can be used to form a [foundation of statistics](wikipedia://en/15515301) that is distinct from both frequentism and Bayesianism.[^o22][^o23]

## Modification for small sample size {#Modification_for_small_sample_size}

When the [sample](https://en.wikipedia.org/wiki/Sample_%28statistics%29) size is small, there is a substantial probability that AIC will select models that have too many parameters, i.e. that AIC will overfit.[^o25][^o26][^o27] To address such potential overfitting, AICc was developed: AICc is AIC with a correction for small sample sizes.

The formula for AICc depends upon the statistical model. Assuming that the model is [univariate](wikipedia://en/2398982), is linear in its parameters, and has normally-distributed [residuals](wikipedia://en/461509) (conditional upon regressors), then the formula for AICc is as follows.[^o28][^o29][^o30][^o31]

$$\mathrm{AICc} \, = \, \mathrm{AIC} + \frac{2k^2 + 2k}{n - k - 1}$$

—where $n$ denotes the sample size and $k$ denotes the number of parameters. Thus, AICc is essentially AIC with an extra penalty term for the number of parameters. Note that as $n \to \infty$, the extra penalty term converges to 0, and thus AICc converges to AIC.[^o32]

If the assumption that the model is univariate and linear with normal residuals does not hold, then the formula for AICc will generally be different from the formula above. For some models, the formula can be difficult to determine. For every model that has AICc available, though, the formula for AICc is given by AIC plus terms that includes both $k$ and $k$<sup>2</sup>. In comparison, the formula for AIC includes $k$ but not $k$<sup>2</sup>. In other words, AIC is a [first-order estimate](https://en.wikipedia.org/wiki/First_order_approximation) (of the information loss), whereas AICc is a [second-order estimate](https://en.wikipedia.org/wiki/Second_order_approximation).[^o33]

Further discussion of the formula, with examples of other assumptions, is given by (Burnham Anderson 2002, ch. 7) and by (Konishi Kitagawa 2008, ch. 7–8). In particular, with other assumptions, [bootstrap estimation](wikipedia://en/6885770) of the formula is often feasible.

To summarize, AICc has the advantage of tending to be more accurate than AIC (especially for small samples), but AICc also has the disadvantage of sometimes being much more difficult to compute than AIC. Note that if all the candidate models have the same $k$ and the same formula for AICc, then AICc and AIC will give identical (relative) valuations; hence, there will be no disadvantage in using AIC, instead of AICc. Furthermore, if $n$ is many times larger than $k$<sup>2</sup>, then the extra penalty term will be negligible; hence, the disadvantage in using AIC, instead of AICc, will be negligible.

## History {#History}

*Image: Akaike.jpg.* [Hirotugu Akaike](https://en.wikipedia.org/wiki/Hirotugu_Akaike)

The Akaike information criterion was formulated by the statistician [Hirotugu Akaike](https://en.wikipedia.org/wiki/Hirotugu_Akaike). It was originally named "an information criterion".[^o37] It was first announced in English by Akaike at a 1971 symposium; the proceedings of the symposium were published in 1973.[^o37][^o38] The 1973 publication, though, was only an informal presentation of the concepts.[^o39] The first formal publication was a 1974 paper by Akaike.[^o40]

The initial derivation of AIC relied upon some strong assumptions. (Takeuchi 1976) showed that the assumptions could be made much weaker. Takeuchi's work, however, was in Japanese and was not widely known outside Japan for many years. (Translated in [^o42])

AIC was originally proposed for [linear regression](wikipedia://en/48758386) (only) by (Sugiura 1978). That instigated the work of (Hurvich Tsai 1989), and several further papers by the same authors, which extended the situations in which AICc could be applied.

The first general exposition of the information-theoretic approach was the volume by (Burnham Anderson 2002). It includes an English presentation of the work of Takeuchi. The volume led to far greater use of AIC, and it now has more than 64,000 citations on [Google Scholar](https://en.wikipedia.org/wiki/Google_Scholar).

Akaike called his approach an "entropy maximization principle", because the approach is founded on the concept of [entropy in information theory](wikipedia://en/15445). Indeed, minimizing AIC in a statistical model is effectively equivalent to maximizing entropy in a thermodynamic system; in other words, the information-theoretic approach in statistics is essentially applying the [second law of thermodynamics](wikipedia://en/133017). As such, AIC has roots in the work of [Ludwig Boltzmann](wikipedia://en/544255) on [entropy](wikipedia://en/9891). For more on these issues, see (Akaike 1985) and (Burnham Anderson 2002, ch. 2).

## Usage tips {#Usage_tips}

### Counting parameters {#Counting_parameters}

A [statistical model](wikipedia://en/27576) must account for [random errors](https://en.wikipedia.org/wiki/Random_error). A straight line model might be formally described as *y*<sub>*i*</sub> = *b*<sub>0</sub> + *b*<sub>1</sub>*x*<sub>*i*</sub> + *ε*<sub>*i*</sub>. Here, the *ε*<sub>*i*</sub> are the [residuals](https://en.wikipedia.org/wiki/Errors_and_residuals_in_statistics) from the straight line fit. If the *ε*<sub>*i*</sub> are assumed to be [i.i.d.](https://en.wikipedia.org/wiki/I.i.d.) [Gaussian](wikipedia://en/21462) (with zero mean), then the model has three parameters: *b*<sub>0</sub>, *b*<sub>1</sub>, and the variance of the Gaussian distributions. Thus, when calculating the AIC value of this model, we should use *k*=3. More generally, for any [least squares](wikipedia://en/82359) model with i.i.d. Gaussian residuals, the variance of the residuals' distributions should be counted as one of the parameters.[^o50]

As another example, consider a first-order [autoregressive model](wikipedia://en/1434444), defined by *x*<sub>*i*</sub> = *c* + *φx*<sub>*i*−1</sub> + *ε*<sub>*i*</sub>, with the *ε*<sub>*i*</sub> being i.i.d. Gaussian (with zero mean). For this model, there are three parameters: *c*, *φ*, and the variance of the *ε*<sub>*i*</sub>. More generally, a *p*th-order autoregressive model has $p + 2$ parameters. (If, however, *c* is not estimated from the data, but instead given in advance, then there are only $p + 1$ parameters.)

### Transforming data {#Transforming_data}

The AIC values of the candidate models must all be computed with the same data set. Sometimes, though, we might want to compare a model of the [response variable](wikipedia://en/437701), $y$, with a model of the logarithm of the response variable, $\log(y)$. More generally, we might want to compare a model of the data with a model of [transformed data](wikipedia://en/10056274). Following is an illustration of how to deal with data transforms (adapted from (Burnham Anderson 2002, §2.11.3): "Investigators should be sure that all hypotheses are modeled using the same response variable").

Suppose that we want to compare two models: one with a [normal distribution](wikipedia://en/21462) of $y$ and one with a normal distribution of $\log(y)$. We should *not* directly compare the AIC values of the two models. Instead, we should transform the normal [cumulative distribution function](wikipedia://en/5793) to first take the logarithm of $y$. To do that, we need to perform the relevant [integration by substitution](wikipedia://en/193748): thus, we need to multiply by the derivative of the [(natural) logarithm](wikipedia://en/21476) function, which is $1/y$. Hence, the transformed distribution has the following [probability density function](wikipedia://en/43487):

$$y \mapsto \, \frac{1}{y} \frac{1}{\sqrt{2\pi\sigma^2}}\,\exp \left(-\frac{\left(\ln y-\mu\right)^2}{2\sigma^2}\right)$$

—which is the probability density function for the [log-normal distribution](wikipedia://en/102476). We then compare the AIC value of the normal model against the AIC value of the log-normal model.

For misspecified model, Takeuchi's Information Criterion (TIC) might be more appropriate. However, TIC often suffers from instability caused by estimation errors.[^o53]

## Comparisons with other model selection methods {#Comparisons_with_other_model_selection_methods}

Several alternative model selection criteria have been proposed and studied in statistical literature. These include the [Bayesian information criterion (BIC)](wikipedia://en/2473272), cross-validation methods, [least squares](wikipedia://en/82359) fitting, [Mallows's Cp](wikipedia://en/8284591), and other information-theoretic approaches such as [Widely Applicable Information Criterion (WAIC)](https://en.wikipedia.org/wiki/Watanabe–Akaike_information_criterion), [Deviance information criterion (DIC)](wikipedia://en/3103500), and [Hannan–Quinn information criterion (HQC)](wikipedia://en/12583075). These methods differ in their assumptions, asymptotic behavior, and suitability depending on the goals of the analysis — such as prediction, inference, or model interpretation. A comprehensive overview of AIC and other model selection methods is given by Ding et al. (2018).[^o55]

### Comparison with BIC {#Comparison_with_BIC}

A critical difference between AIC and BIC (and their variants) lies in their asymptotic behavior under well-specified and misspecified model classes.[^o57] Their fundamental differences have been well-studied in regression variable selection and autoregression order selection[^o58] problems. In general, if the goal is prediction, AIC and leave-one-out cross-validations are preferred.

The formula for the [Bayesian information criterion](wikipedia://en/2473272) (BIC) is similar to the formula for AIC, but with a different penalty for the number of parameters. With AIC the penalty is $2k$, whereas with BIC the penalty is $\ln(n)k$.

A comparison of AIC/AICc and BIC is given by (Burnham Anderson 2002, §6.3-6.4), with follow-up remarks by (Burnham Anderson 2004). The authors show that AIC/AICc can be derived in the same Bayesian framework as BIC, just by using different [prior probabilities](wikipedia://en/472877). In the Bayesian derivation of BIC, though, each candidate model has a prior probability of 1/*R* (where *R* is the number of candidate models). Additionally, the authors present a few simulation studies that suggest AICc tends to have practical/performance advantages over BIC.

A point made by several researchers is that AIC and BIC are appropriate for different tasks. In particular, BIC is argued to be appropriate for selecting the "true model" (i.e. the process that generated the data) from the set of candidate models, whereas AIC is not appropriate. To be specific, if the "true model" is in the set of candidates, then BIC will select the "true model" with probability 1, as $n \to \infty$; in contrast, when selection is done via AIC, the probability can be less than 1.[^o61][^o62][^o63] Proponents of AIC argue that this issue is negligible, because the "true model" is virtually never in the candidate set. Indeed, it is a common aphorism in statistics that "[all models are wrong](wikipedia://en/44732699)"; hence the "true model" (i.e. reality) cannot be in the candidate set.

Another comparison of AIC and BIC is given by (Vrieze 2012). Vrieze presents a simulation study—which allows the "true model" to be in the candidate set (unlike with virtually all real data). The simulation study demonstrates, in particular, that AIC sometimes selects a much better model than BIC even when the "true model" is in the candidate set. The reason is that, for finite $n$, BIC can have a substantial risk of selecting a very bad model from the candidate set. This reason can arise even when $n$ is much larger than $k$<sup>2</sup>. With AIC, the risk of selecting a very bad model is minimized.

If the "true model" is not in the candidate set, then the most that we can hope to do is select the model that best approximates the "true model". AIC is appropriate for finding the best approximating model, under certain assumptions.[^o61][^o62][^o63] (Those assumptions include, in particular, that the approximating is done with regard to information loss.)

Comparison of AIC and BIC in the context of [regression](wikipedia://en/826997) is given by (Yang 2005). In regression, AIC is asymptotically optimal for selecting the model with the least [mean squared error](wikipedia://en/201816), under the assumption that the "true model" is not in the candidate set. BIC is not asymptotically optimal under the assumption. Yang additionally shows that the rate at which AIC converges to the optimum is, in a certain sense, the best possible.

### Comparison with least squares {#Comparison_with_least_squares}

Sometimes, each candidate model assumes that the residuals are distributed according to independent identical normal distributions (with zero mean). That gives rise to [least squares](wikipedia://en/82359) model fitting.

With least squares fitting, the [maximum likelihood estimate](wikipedia://en/140806) for the variance of a model's residuals distributions is

$$\hat\sigma^2 = \mathrm{RSS}/n,$$

where the [residual sum of squares](wikipedia://en/2473303) is

$$\textstyle \mathrm{RSS} = \sum_{i=1}^n (y_i-f(x_i;\hat{\theta}))^2$$

Then, the maximum value of a model's log-likelihood function is (see [Normal distribution#Log-likelihood](wikipedia://en/21462#Log-likelihood)):

$$\ln(\hat L)= -\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln(\hat\sigma^2) - \frac{1}{2\hat\sigma^2}\mathrm{RSS} \, = \, - \frac{n}{2}\ln(\hat\sigma^2) + C$$

where $C$ is a constant independent of the model, and dependent only on the particular data points, i.e. it does not change if the data does not change.

That gives:[^o67]

$$\mathrm{AIC} = 2k - 2\ln(\hat L) = 2k + n\ln(\hat\sigma^2) - 2C$$

Because only differences in AIC are meaningful, the constant $C$ can be ignored, which allows us to conveniently take the following for model comparisons:

$$\Delta \mathrm{AIC} = 2k + n\ln(\hat\sigma^2)$$

Note that if all the models have the same $k$, then selecting the model with minimum AIC is equivalent to selecting the model with minimum $\operatorname{RSS}$—which is the usual objective of model selection based on least squares.

### Comparison with cross-validation {#Comparison_with_cross-validation}

Leave-one-out [cross-validation](wikipedia://en/416612) is asymptotically equivalent to AIC, for ordinary linear regression models.[^o69] Asymptotic equivalence to AIC also holds for [mixed-effects models](wikipedia://en/5431921).[^o70]

### Comparison with Mallows's *C<sub>p</sub>* {#Comparison_with_Mallows's_Cp}

Akaike stated, 'It is interesting to note that the use of a statistic proposed by [Mallows](wikipedia://en/56679601) is essentially equivalent to our present approach'.[^o72] However, the precise relation between AIC and [*C<sub>p</sub>*](wikipedia://en/8284591) requires some nuance.

Under a normal regression model with unknown error variance $\sigma^2$, the AIC statistic, as noted above, is

$$\mbox{AIC} = n \ln(\mbox{RSS}/n) + 2k$$

(I deliberately stop using $\hat\sigma^2$ here to avoid confusion below). For large samples, if this model is correct, then $\mbox{RSS}/n$ should be close to the true error variance $\sigma^2$, and using a one-term Taylor series for the logarithm,

::: {#o73 .equation cue=numblk name="1"}

$$\mbox{AIC} \approx n \ln \sigma^2 + n \left ( \frac{\mbox{RSS}}{n\sigma^2} - 1 \right ) + 2k = n \ln \sigma^2 - n + \frac{\mbox{RSS}}{\sigma^2} + 2k \tag{1}$$

:::

This final expression (neglecting terms with *n*) is Mallows' *C<sub>p</sub>* when $\sigma^2$ happens to be known. In the more usual situation where this is unknown, an estimate $\hat\sigma^2$, typically derived from a model using all possible predictors, must be substituted. This leads to an asymptotic equivalence between AIC and *C<sub>p</sub>*. However, Akaike noted that 'unfortunately some subjective judgement is required for the choice of $\hat\sigma^2$ in the definition of *C<sub>p</sub>*'.[^o74]

In the unusual case that $\sigma^2$ is known, AIC is exactly equal to ((1)). As a result, ((1)) is sometimes considered to be AIC, and AIC and *C<sub>p</sub>* are claimed to be equivalent.[^o75] Such statements should be considered incorrect; when AIC is correctly implemented, the equivalence is only asymptotic.

### Other information criteria {#Other_information_criteria}

Other model selection criteria include the [Widely Applicable Information Criterion (WAIC)](https://en.wikipedia.org/wiki/Watanabe–Akaike_information_criterion) and the [Deviance Information Criterion (DIC)](https://en.wikipedia.org/wiki/Deviance_Information_Criterion), both of which are widely used in Bayesian model selection. WAIC, in particular, is asymptotically equivalent to leave-one-out cross-validation and applies even in complex or singular models. The [Hannan–Quinn criterion (HQC)](wikipedia://en/12583075) offers a middle ground between AIC and BIC by applying a lighter penalty than BIC but a heavier one than AIC. The [Minimum Description Length (MDL)](wikipedia://en/331325) principle, closely related to BIC, approaches model selection from an information-theoretic perspective, treating it as a compression problem. Each of these methods has advantages depending on model complexity, sample size, and the goal of analysis.
