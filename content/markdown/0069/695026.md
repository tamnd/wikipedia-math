# Noncrossing partition

*Image: Noncrossing partitions 5.svg.* There are 42 noncrossing and 10 crossing partitions of a 5-element set

*Image: Noncrossing partitions 4; Hasse.svg.* The 14 noncrossing partitions of a 4-element set ordered by [refinement](wikipedia://en/340240#Refinement_of_partitions) in a [Hasse diagram](wikipedia://en/338199)

::: {#o1 .subject cue=lead name="Noncrossing partition"}

In [combinatorics](wikipedia://en/5170), the topic of **noncrossing partitions** has assumed some importance because of (among other things) its application to the theory of [free probability](wikipedia://en/679696). The number of noncrossing partitions of a set of *n* elements is the *n*th [Catalan number](wikipedia://en/216488). The number of noncrossing partitions of an *n*-element set with *k* blocks is found in the [Narayana number](wikipedia://en/12267066) triangle.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [partition of a set](wikipedia://en/340240) *S* is a set of non-empty, pairwise disjoint subsets of *S*, called "parts" or "blocks", whose union is all of *S*. Consider a [finite set](wikipedia://en/11742) that is linearly ordered, or (equivalently, for purposes of this definition) arranged in a [cyclic order](wikipedia://en/434673) like the vertices of a regular *n*-gon. No generality is lost by taking this set to be *S* = { 1, ..., *n* }. A **noncrossing partition** of *S* is a partition in which no two blocks "cross" each other, i.e., if *a* and *b* belong to one block and *x* and *y* to another, they are not arranged in the order *a x b y*. If one draws an arch based at *a* and *b*, and another arch based at *x* and *y*, then the two arches cross each other if the order is *a x b y* but not if it is *a x y b* or *a b x y*. In the latter two orders the partition { { *a*, *b* }, { *x*, *y* } } is noncrossing.

| Crossing: | *a x b y* |
|---|---|
| Noncrossing: | *a x y b* |
| Noncrossing: | *a b x y* |

Equivalently, if we label the vertices of a regular *n*-gon with the numbers 1 through *n*, the [convex hulls](wikipedia://en/40634) of different blocks of the partition are disjoint from each other, i.e., they also do not "cross" each other. The set of all non-crossing partitions of *S* is denoted $\text{NC}(S)$. There is an obvious [order isomorphism](wikipedia://en/23916899) between $\text{NC}(S_1)$ and $\text{NC}(S_2)$ for two finite sets $S_1,S_2$ with the same size. That is, $\text{NC}(S)$ depends essentially only on the size of $S$ and we denote by $\text{NC}(n)$ the non-crossing partitions on *any* set of size *n*.

:::

## Lattice structure {#Lattice_structure}

Like the set of all [partitions of the set](wikipedia://en/340240) { 1, ..., *n* }, the set of all noncrossing partitions is a [lattice](wikipedia://en/469304) when [partially ordered](wikipedia://en/23572) by saying that a finer partition is "less than" a coarser partition. However, although it is a subset of the lattice of all set partitions, it is *not* a sublattice, because the subset is not closed under the join operation in the larger lattice. In other words, the finest partition that is coarser than both of two noncrossing partitions is not always the finest *noncrossing* partition that is coarser than both of them.

Unlike the lattice of all partitions of the set, the lattice of all noncrossing partitions is self-dual, i.e., it is order-isomorphic to the lattice that results from inverting the partial order ("turning it upside-down"). This can be seen by observing that each noncrossing partition has a non-crossing complement, called the Kreweras complement. Indeed, every interval within this lattice is self-dual.

## Role in free probability theory {#Role_in_free_probability_theory}

The lattice of noncrossing partitions plays the same role in defining [free cumulants](wikipedia://en/359684#Free_cumulants) in [free probability](wikipedia://en/679696) theory that is played by the lattice of *all* partitions in defining joint cumulants in classical [probability theory](wikipedia://en/23542). To be more precise, let $(\mathcal{A},\phi)$ be a [non-commutative probability space](https://en.wikipedia.org/wiki/Non-commutative_probability_space) (See [free probability](wikipedia://en/679696) for terminology.), $a\in\mathcal{A}$ a [non-commutative random variable](https://en.wikipedia.org/wiki/Non-commutative_random_variable) with free cumulants $(k_n)_{n\in\mathbb{N}}$. Then

$$\phi(a^n) = \sum_{\pi\in\text{NC}(n)} \prod_{j} k_j^{N_j(\pi)}$$

where $N_j(\pi)$ denotes the number of blocks of length $j$ in the non-crossing partition $\pi$. That is, the moments of a non-commutative [random variable](wikipedia://en/25685) can be expressed as a sum of free cumulants over the sum non-crossing partitions. This is the free analogue of the [moment-cumulant formula](wikipedia://en/359684#Cumulants_and_set-partitions) in classical probability. See also [Wigner semicircle distribution](wikipedia://en/1028321).
