# Bing–Borsuk conjecture

::: {#o1 .subject cue=lead name="Bing–Borsuk conjecture"}

In [mathematics](wikipedia://en/18831), the **Bing–Borsuk conjecture** states that every $n$-dimensional [homogeneous](wikipedia://en/363325) [absolute neighborhood retract](wikipedia://en/81809195) space is a [topological manifold](wikipedia://en/2119193). The conjecture has been proved for dimensions 1 and 2, and it is known that the 3-dimensional version of the conjecture implies the [Poincaré conjecture](wikipedia://en/23798).

:::

::: {#o3 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A [topological space](wikipedia://en/30450) is *homogeneous* if, for any two points $m_1, m_2 \in M$, there is a [homeomorphism](wikipedia://en/13660) of $M$ which takes $m_1$ to $m_2$.

A [metric space](wikipedia://en/20018) $M$ is an [absolute neighborhood retract](wikipedia://en/81809195) (ANR) if, for every closed embedding $f: M \rightarrow N$ (where $N$ is a metric space), there exists an [open neighbourhood](https://en.wikipedia.org/wiki/Open_neighbourhood) $U$ of the image $f(M)$ which [retracts](wikipedia://en/2120001) to $f(M)$.[^o4]

There is an alternate statement of the Bing–Borsuk conjecture: suppose $M$ is [embedded](wikipedia://en/52119) in $\mathbb{R}^{m+n}$ for some $m \geq 3$ and this embedding can be extended to an embedding of $M \times (-\varepsilon, \varepsilon)$. If $M$ has a mapping cylinder neighbourhood $N=C_\varphi$ of some map $\varphi: \partial N \rightarrow M$ with mapping cylinder projection $\pi: N \rightarrow M$, then $\pi$ is an [approximate fibration](wikipedia://en/71514588).[^o5]

:::

## History {#History}

The conjecture was first made in a paper by [R. H. Bing](wikipedia://en/967353) and [Karol Borsuk](https://en.wikipedia.org/wiki/Karol_Borsuk) in 1965, who proved it for $n=1$ and 2.[^o7][^o8]

Włodzimierz Jakobsche showed in 1978 that, if the Bing–Borsuk conjecture is true in dimension 3, then the Poincaré conjecture must also be true.[^o9]

The [Busemann conjecture](https://en.wikipedia.org/wiki/Busemann_conjecture) states that every [Busemann $G$-space](wikipedia://en/57172319) is a topological manifold. It is a special case of the Bing–Borsuk conjecture. The Busemann conjecture is known to be true for dimensions 1 to 4.
