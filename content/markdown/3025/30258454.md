# Skolem–Mahler–Lech theorem

::: {#o1 .subject cue=lead name="Skolem–Mahler–Lech theorem"}

In [algebraic number theory](wikipedia://en/174705), the **Skolem–Mahler–Lech theorem** states that if a sequence of numbers satisfies a [linear recurrence with constant coefficients](wikipedia://en/50700194), then with finitely many exceptions the positions at which the sequence is zero form a regularly repeating pattern. This result is named after [Thoralf Skolem](wikipedia://en/453765) (who proved the theorem for sequences of [rational numbers](wikipedia://en/19727024)), [Kurt Mahler](wikipedia://en/4421496) (who proved it for sequences of [algebraic numbers](wikipedia://en/1158)), and [Christer Lech](https://en.wikipedia.org/wiki/Christer_Lech) (who proved it for sequences with values in any [field of characteristic zero](https://en.wikipedia.org/wiki/Field_of_characteristic_zero). Its known proofs use [$p$-adic analysis](wikipedia://en/291327) and are [non-constructive](wikipedia://en/360113).

:::

::: {#o3 .statement kind=statement/theorem cue=named-heading name="Theorem statement"}

## Theorem statement {#Theorem_statement}

Let $K$ be a [field of characteristic zero](https://en.wikipedia.org/wiki/Field_of_characteristic_zero), such as the field of [complex numbers](wikipedia://en/5826) $\mathbb{C}$. Let $(u_n)$ be a [constant-recursive sequence](wikipedia://en/49700795) with values in $K$, i.e., a sequence satisfying a recurrence relation of the form

$$u_{n+d} = c_{d-1} u_{n+d-1} + \cdots + c_0 u_n$$

where $c_0, \dots, c_{d-1} \in K$. Then the zero set $\{n \in \mathbb{N} \mid u_n = 0\}$ is equal to the union of finitely many [arithmetic progressions](wikipedia://en/168389) and a finite set.

If $c_0 \ne 0$ (excluding sequences such as 1, 0, 0, 0, …), then the set of zeros is in fact equal to the union of a finite set and finitely many *full* arithmetic progressions, where an infinite arithmetic progression is full if there exist integers *a* and *b* such that the progression consists of all positive integers equal to *b* modulo *a*.

:::

::: {#o5 .example cue=heading name="Example"}

## Example {#Example}

Consider the sequence

that alternates between zeros and the [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number). This sequence can be generated by the linear recurrence relation

$$F(i) = F(i-2) + F(i-4)$$

(a modified form of the Fibonacci recurrence), starting from the base cases *F*(1) = *F*(2) = *F*(4) = 0 and *F*(3) = 1. For this sequence, *F*(*i*) = 0 if and only if *i* is either one or even. Thus, the positions at which the sequence is zero can be partitioned into a finite set (the [singleton set](https://en.wikipedia.org/wiki/Singleton_set) {1}) and a full arithmetic progression (the positive [even numbers](https://en.wikipedia.org/wiki/Even_number)).

In this example, only one arithmetic progression was needed, but other recurrence sequences may have zeros at positions forming multiple arithmetic progressions.

:::

::: {#o7 .statement kind=statement/generalization cue=heading name="Related results"}

## Related results {#Related_results}

The [Skolem problem](wikipedia://en/48160075) is the problem of determining whether a given recurrence sequence has a zero. There exist an algorithm to test whether there are infinitely many zeros,[^o8] and if so to find the decomposition of these zeros into periodic sets guaranteed to exist by the Skolem–Mahler–Lech theorem. However, it is unknown whether there exists an algorithm to determine whether a recurrence sequence has any non-periodic zeros.[^o9]

:::
