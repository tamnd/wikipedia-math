# Hooley's delta function

::: {#o1 .subject cue=lead name="Hooley's delta function"}

In [mathematics](wikipedia://en/18831), **Hooley's delta function**, also called **Erdős--Hooley delta-function**, defines the maximum number of divisors of $n$ in $[u, eu]$ for all $u$, where $e$ is [Euler's number](https://en.wikipedia.org/wiki/Euler's_number). It is usually denoted $\Delta(n)$. The first few terms of this sequence are

:::

$$1, 2, 1, 2, 1, 2, 1, 2, 1, 2, 1, 3, 1, 2, 2, 2, 1, 2, 1, 3, 2, 2, 1, 4, \dots$$

.

## History {#History}

The sequence was first introduced by [Paul Erdős](wikipedia://en/601284) in 1974,[^o4] then studied by [Christopher Hooley](wikipedia://en/5380265) in 1979.[^o5]

In 2023, [Dimitris Koukoulopoulos](wikipedia://en/69797343) and [Terence Tao](wikipedia://en/1118498) proved that

$$\sum_{k=1}^n \Delta(k) \ll n (\log \log n)^{11/4}$$

for $n \ge 100$.[^o6] In particular, the [average order](wikipedia://en/18760872) of $\Delta(n)$ to $k$ is $O((\log n)^k)$ for any $k > 0$.

In 2024, [Kevin Ford](wikipedia://en/55700462) along with Koukoulopoulos and Tao proved the lower bound

$$\sum_{k=1}^n \Delta(k) \gg n (\log \log n)^{1+\eta-\epsilon},$$

where $\epsilon$ is fixed, $\eta=0.3533227\ldots$, and $n \geq 100$.[^o7]

## Usage {#Usage}

This function measures the tendency of [divisors](wikipedia://en/49492) of a number to cluster.

The growth of this sequence is limited by $\Delta(mn) \leq \Delta(n) d(m)$, where $d(n)$ is the [number of divisors](wikipedia://en/407249) of $n$.[^o9]
