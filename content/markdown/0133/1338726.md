# Delegated Path Discovery

::: {#o1 .subject cue=lead name="Delegated Path Discovery"}

**Delegated Path Discovery** (**DPD**) is a method for querying a trusted server for information about a [public key certificate](wikipedia://en/223796).

:::

DPD allows [clients](https://en.wikipedia.org/wiki/Client_%28computing%29) to obtain collated certificate information from a trusted DPD [server](https://en.wikipedia.org/wiki/Server_%28computing%29). This information may then be used by the client to validate the subject certificate.

The requirements for DPD are described in RFC 3379. [^o2]
