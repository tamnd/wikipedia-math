# Continued fraction factorization

::: {#o1 .subject cue=lead name="Continued fraction factorization"}

In [number theory](wikipedia://en/21527), the **continued fraction factorization method** (**CFRAC**) is an [integer factorization](wikipedia://en/15491) [algorithm](wikipedia://en/775). It is a general-purpose algorithm, meaning that it is suitable for factoring any integer *n*, not depending on special form or properties. It was described by [D. H. Lehmer](https://en.wikipedia.org/wiki/Derrick_Henry_Lehmer) and [R. E. Powers](https://en.wikipedia.org/wiki/R._E._Powers) in 1931,[^o2] and developed as a computer algorithm by Michael A. Morrison and [John Brillhart](wikipedia://en/11176492) in 1975.[^o3]

:::

The continued fraction method is based on [Dixon's factorization method](wikipedia://en/1033877). It uses [convergents](https://en.wikipedia.org/wiki/Convergent_%28continued_fraction%29) in the [regular continued fraction expansion](wikipedia://en/739199) of

$$\sqrt{kn},\qquad k\in\mathbb{Z^+}.$$

Since this is a [quadratic irrational](https://en.wikipedia.org/wiki/Quadratic_irrational), the continued fraction must be [periodic](wikipedia://en/10875031) (unless *n* is square, in which case the factorization is obvious).

It has a time complexity of $O\left(e^{\sqrt{2\log n \log\log n}}\right)=L_n\left[1/2,\sqrt{2}\right]$, in the [O](wikipedia://en/44578) and [L](wikipedia://en/2811119) notations.[^o4]
