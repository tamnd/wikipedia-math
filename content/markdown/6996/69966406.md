# Open set condition

::: {#o1 .subject cue=lead name="Open set condition"}

*Image: Open set condition.png.* an open set covering of the [sierpinski triangle](https://en.wikipedia.org/wiki/Sierpinski_triangle) along with one of its mappings ψ<sub>*i*</sub>.

In [fractal geometry](https://en.wikipedia.org/wiki/Fractal_geometry), the **open set condition** (**OSC**) is a commonly imposed condition on self-similar fractals. In some sense, the condition imposes restrictions on the overlap in a fractal construction.[^o2] Specifically, given an [iterated function system](wikipedia://en/505225) of [contractive mappings](wikipedia://en/6239) $\psi_1, \ldots, \psi_m$, the open set condition requires that there exists a nonempty, open set V satisfying two conditions:

:::

1. $$\bigcup_{i=1}^m\psi_i (V) \subseteq V,$$
1. The sets $\psi_1(V), \ldots, \psi_m(V)$ are pairwise disjoint.

Introduced in 1946 by P.A.P Moran,[^o3] the open set condition is used to compute the dimensions of certain self-similar fractals, notably the Sierpinski Gasket. It is also used to simplify computation of the packing measure.[^o4]

An equivalent statement of the open set condition is to require that the s-dimensional [Hausdorff measure](wikipedia://en/504109) of the set is greater than zero.[^o5]

## Computing Hausdorff dimension {#Computing_Hausdorff_dimension}

When the open set condition holds and each $\psi_i$ is a similitude (that is, a composition of an [isometry](wikipedia://en/254777) and a [dilation](wikipedia://en/1591770) around some point), then the unique fixed point of $\psi$ is a set whose [Hausdorff dimension](wikipedia://en/14294) is the unique solution for *s* of the following:[^o7]

$$\sum_{i=1}^m r_i^s = 1.$$

where r<sub>i</sub> is the magnitude of the dilation of the similitude.

With this theorem, the Hausdorff dimension of the Sierpinski gasket can be calculated. Consider three [non-collinear points](https://en.wikipedia.org/wiki/Non-collinear_points) *a*<sub>1</sub>, *a*<sub>2</sub>, *a*<sub>3</sub> in the plane **R**<sup>2</sup> and let $\psi_i$ be the dilation of ratio 1/2 around *a<sub>i</sub>*. The unique non-empty fixed point of the corresponding mapping $\psi$ is a Sierpinski gasket, and the dimension *s* is the unique solution of

$$\left(\frac{1}{2}\right)^s+\left(\frac{1}{2}\right)^s+\left(\frac{1}{2}\right)^s = 3 \left(\frac{1}{2}\right)^s =1.$$

Taking [natural logarithms](wikipedia://en/21476) of both sides of the above equation, we can solve for *s*, that is: *s* = ln(3)/ln(2). The Sierpinski gasket is self-similar and satisfies the OSC.

## Strong open set condition {#Strong_open_set_condition}

The strong open set condition (SOSC) is an extension of the open set condition. A fractal F satisfies the SOSC if, in addition to satisfying the OSC, the intersection between F and the open set V is nonempty.[^o9] The two conditions are equivalent for self-similar and self-conformal sets, but not for certain classes of other sets, such as function systems with infinite mappings and in non-euclidean metric spaces.[^o10][^o11] In these cases, SOCS is indeed a stronger condition.
