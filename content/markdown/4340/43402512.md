# Bondage number

::: {#o1 .subject cue=lead name="Bondage number"}

*Image: Bondage number.svg.* The [domination number](https://en.wikipedia.org/wiki/Domination_number) of the graph on the left can be strictly increased by 1 when removing a minimum of 2 edges, shown on the right. The highlighted vertices show a minimum dominating set for each graph.

In the [mathematical](https://en.wikipedia.org/wiki/Mathematical) field of [graph theory](wikipedia://en/12401), the **bondage number** of a nonempty [graph](wikipedia://en/325806) $G$ is the [cardinality](wikipedia://en/6174) of the smallest set of edges whose removal results in a [domination number](https://en.wikipedia.org/wiki/Domination_number) strictly greater than the domination number $\gamma(G)$ of $G$. The bondage number is denoted $b(G)$.[^o2][^o3]

:::

The concept was introduced by Fink et al. in 1990 and measures the [vulnerability](https://en.wikipedia.org/wiki/Graph_connectivity) of a graph's domination structure to edge removal.[^o4]

## Examples and specific values {#Examples_and_specific_values}

For several standard families of graphs, exact values of the bondage number are known:[^o2]

- For the [complete graph](wikipedia://en/85816) $K_{n}$ with $n \ge 2$ vertices, $b(K_{n}) = \lceil n/2\rceil$.
- For the [cycle graph](wikipedia://en/878962) $C_{n}$ with $n \ge 3$ vertices, $b(C_{n}) = 3$ if $n \equiv 1\pmod{3}$, and $b(C_{n}) = 2$ otherwise.
- For the [path graph](wikipedia://en/4587190) $P_{n}$ with $n \ge 2$ vertices, $b(P_{n}) = 2$.
- For nontrivial [trees](wikipedia://en/48560), the bondage number is at most 2. A tree has bondage number 1 if any vertex is adjacent to two or more [leaves](https://en.wikipedia.org/wiki/Leaf_vertex).

## Bounds {#Bounds}

Several general bounds on the bondage number have been established. For a connected graph $G$ of order $p$ with maximum degree $\Delta(G)$ and minimum degree $\delta(G)$, the following inequalities hold:[^o2][^o3]

- $$b(G) \le \min_{\{u,v\} \in E(G)} (\deg(u) + \deg(v) - 1)$$
- $$b(G) \le \Delta(G) + \delta(G) - 1$$
- $$b(G) \le p - 1$$
- $b(G) \le (\gamma(G) - 1)\Delta(G) + 1$ if $\gamma(G) \ge 2$
- $b(G) \le p - \gamma(G) + 1$, where $\gamma(G)$ is the domination number
- $b(G) \le \lambda(G) + \Delta(G) - 1$, where $\lambda(G)$ is the edge connectivity

## Computational complexity {#Computational_complexity}

Determining the bondage number of a general graph is [NP-hard](https://en.wikipedia.org/wiki/NP-hard), as shown by Hu and Xu in 2012.[^o4] This hardness result has been strengthened to show that the bondage problem remains NP-hard even when restricted to [bipartite graphs](wikipedia://en/244431) and even when asking whether $b(G) \le 1$.[^o8] This is because if a polynomial time algorithm existed for computing bondage numbers, it could be used to compute domination numbers in polynomial time, which is known to be [NP-complete](https://en.wikipedia.org/wiki/NP-complete).

However, for special classes of graphs, efficient algorithms exist. In particular, the bondage number of any tree can be determined in [O(*n*)](wikipedia://en/44578) time using a linear algorithm developed by Hartnell et al.[^o4]

## Conjectures {#Conjectures}

::: {#o11 .problem cue=unsolved}

For the bondage number $b(G)$ and maximum degree $\Delta(G)$ of a graph $G$, is $b(G) \le (3/2)\Delta(G)$ for all graphs?

:::

A conjecture by Fink et al. from 1990 stated that for any nonempty graph $G$,

$$b(G) \le \Delta(G) + 1.$$

However, this was disproved by Teschner in 1993, who showed that the [Cartesian product](wikipedia://en/2856852) $K_{3} \square K_{3}$ has $b(K_{3} \square K_{3}) = \Delta(K_{3} \square K_{3}) + 2$. More generally, Hartnell-Rall and Teschner independently showed that $b(K_{n} \square K_{n}) = (3/2)\Delta(K_{n} \square K_{n})$ for $n \ge 3$.[^o3][^o4] They also provided a 4-regular [bipartite graph](wikipedia://en/244431) with bondage number 6 as another counterexample.

Teschner then proposed the following weaker conjecture:[^o12]

For any graph $G$, $b(G) \le (3/2)\Delta(G)$.

This conjecture remains open.[^o4]

### Planar graphs {#Planar_graphs}

For [planar graphs](wikipedia://en/24314), Dunbar et al. conjectured in 1998:

If $G$ is a planar graph, then $b(G) \le \Delta(G) + 1$.

This conjecture has been verified for planar graphs with $\Delta(G) \ge 7$ and for various other special cases, but remains open in general. It is known that $b(G) \le \min(8, \Delta(G) + 2)$ for any connected planar graph $G$.[^o4]

:::

## Variations {#Variations}

Several variations of the bondage number have been studied based on different types of domination. The **total bondage number** considers [total dominating sets](wikipedia://en/1747972#Variants) (where every vertex in the dominating set must also be adjacent to another vertex in the dominating set).[^o8] The **Roman bondage number** is based on [Roman domination](https://en.wikipedia.org/wiki/Roman_dominating_set), where vertices are assigned values 0, 1, or 2 subject to certain constraints.[^o16] Further generalizations include the **double Roman bondage number**,[^o17] the **independent Roman bondage number**,[^o18] and the **quasi-total Roman bondage number**.[^o19] Other variations include the **k-power bondage number**,[^o20] the **cobondage number**,[^o21] and the **lower bondage number**.[^o22]

:::

## Motivation {#Motivation}

The bondage number has applications in analyzing the vulnerability of communication networks. In a network modeled as a graph where vertices represent sites and edges represent direct communication links, a minimum dominating set corresponds to an optimal placement of transmitters so that every site either has a transmitter or is directly connected to a site with a transmitter. The bondage number represents the minimum number of communication links that must fail before an additional transmitter is required to maintain communication with all sites.[^o2]

## Related problems {#Related_problems}

The **reinforcement number** $r(G)$ is the minimum number of edges that must be added to $G$ to decrease its domination number. Like the bondage number, determining the reinforcement number is NP-hard even for bipartite graphs.[^o8]
