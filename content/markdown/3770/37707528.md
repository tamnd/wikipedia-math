# Osgood's lemma

::: {#o1 .subject cue=lead name="Osgood's lemma"}

In [mathematics](wikipedia://en/18831), specifically [complex analysis](wikipedia://en/5759), **Osgood's lemma** states that a [continuous function](wikipedia://en/6122) of several [complex variables](https://en.wikipedia.org/wiki/Complex_variable) that is [holomorphic](wikipedia://en/14110) in each variable separately is itself holomorphic. It was introduced by [William Fogg Osgood](https://en.wikipedia.org/wiki/William_Fogg_Osgood) in 1899.[^n1]

:::

The assumption that the function is continuous can be dropped, but that form of the lemma is much harder to prove and is known as [Hartogs' theorem](https://en.wikipedia.org/wiki/Hartogs'_theorem).

There is no analogue of this result for real variables. If it is assumed that a function $f:\mathbb{R}^n\to\mathbb{R}$ is globally continuous and separately differentiable on each variable (all partial derivatives exist everywhere), it is not true that $f$ will necessarily be differentiable. A counterexample in two dimensions is given by

$$f(x,y)=\dfrac{2x^2y+y^3}{x^2+y^2}.$$

If in addition it is defined that $f(0,0)=0$, this function is everywhere continuous and has well-defined partial derivatives in $x$ and $y$ everywhere (also at the origin), but is not differentiable at the origin.
