# Convergent matrix

::: {#o1 .subject cue=lead name="Convergent matrix"}

In [linear algebra](wikipedia://en/18422), a **convergent matrix** is a matrix that converges to the [zero matrix](wikipedia://en/1168888) under [matrix exponentiation](wikipedia://en/125280#Powers_of_a_matrix).

:::

## Background {#Background}

When successive powers of a [matrix](wikipedia://en/20556859) **T** become small (that is, when all of the entries of **T** approach zero, upon raising **T** to successive powers), the matrix **T** converges to the zero matrix. A [regular splitting](wikipedia://en/36743227) of a [non-singular](wikipedia://en/217122) matrix **A** results in a convergent matrix **T**. A semi-convergent splitting of a matrix **A** results in a semi-convergent matrix **T**. A general [iterative method](wikipedia://en/15237) converges for every initial vector if **T** is convergent, and under certain conditions if **T** is semi-convergent.

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

We call an *n* × *n* matrix **T** a **convergent matrix** if

::: {#o5 .equation cue=numblk name="1"}

$$\lim_{k \to \infty}( \mathbf T^k)_{ij} = 0, \tag{1}$$

:::

for each *i* = 1, 2, ..., *n* and *j* = 1, 2, ..., *n*.[^o6][^o7][^o8]

:::

::: {#o10 .example cue=heading name="Example"}

## Example {#Example}

Let

$$\begin{aligned} & \mathbf{T} = \begin{pmatrix} \frac{1}{4} & \frac{1}{2} \\[4pt] 0 & \frac{1}{4} \end{pmatrix}. \end{aligned}$$

Computing successive powers of **T**, we obtain

$$\begin{aligned} & \mathbf{T}^2 = \begin{pmatrix} \frac{1}{16} & \frac{1}{4} \\[4pt] 0 & \frac{1}{16} \end{pmatrix}, \quad \mathbf{T}^3 = \begin{pmatrix} \frac{1}{64} & \frac{3}{32} \\[4pt] 0 & \frac{1}{64} \end{pmatrix}, \quad \mathbf{T}^4 = \begin{pmatrix} \frac{1}{256} & \frac{1}{32} \\[4pt] 0 & \frac{1}{256} \end{pmatrix}, \quad \mathbf{T}^5 = \begin{pmatrix} \frac{1}{1024} & \frac{5}{512} \\[4pt] 0 & \frac{1}{1024} \end{pmatrix}, \end{aligned}$$

$$\begin{aligned} \mathbf{T}^6 = \begin{pmatrix} \frac{1}{4096} & \frac{3}{1024} \\[4pt] 0 & \frac{1}{4096} \end{pmatrix}, \end{aligned}$$

and, in general,

$$\begin{aligned} \mathbf{T}^k = \begin{pmatrix} (\frac{1}{4})^k & \frac{k}{2^{2k - 1}} \\[4pt] 0 & (\frac{1}{4})^k \end{pmatrix}. \end{aligned}$$

Since

$$\lim_{k \to \infty} \left( \frac{1}{4} \right)^k = 0$$

and

$$\lim_{k \to \infty} \frac{k}{2^{2k - 1}} = 0,$$

**T** is a convergent matrix. Note that *ρ*(**T**) = $\tfrac{1}{4}$, where *ρ*(**T**) represents the [spectral radius](wikipedia://en/386169) of **T**, since $\tfrac{1}{4}$ is the only [eigenvalue](https://en.wikipedia.org/wiki/Eigenvalue) of **T**.

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Characterizations"}

## Characterizations {#Characterizations}

Let **T** be an *n* × *n* matrix. The following properties are equivalent to **T** being a convergent matrix:

1. $\lim_{k \to \infty} \| \mathbf T^k \| = 0,$ for some natural norm;
1. $\lim_{k \to \infty} \| \mathbf T^k \| = 0,$ for all natural norms;
1. $$\rho( \mathbf T ) < 1;$$
1. $\lim_{k \to \infty} \mathbf T^k \mathbf x = \mathbf 0,$ for every **x**.[^o13][^o14][^o15][^o16]

:::

## Iterative methods {#Iterative_methods}

A general **iterative method** involves a process that converts the [system of linear equations](wikipedia://en/113087)

::: {#o18 .equation cue=numblk name="2"}

$$\mathbf{Ax} = \mathbf{b} \tag{2}$$

:::

into an equivalent system of the form

::: {#o19 .equation cue=numblk name="3"}

$$\mathbf{x} = \mathbf{Tx} + \mathbf{c} \tag{3}$$

:::

for some matrix **T** and vector **c**. After the initial vector **x**<sup>(0)</sup> is selected, the sequence of approximate solution vectors is generated by computing

::: {#o20 .equation cue=numblk name="4"}

$$\mathbf{x}^{(k + 1)} = \mathbf{Tx}^{(k)} + \mathbf{c} \tag{4}$$

:::

for each *k* ≥ 0.[^o21][^o22] For any initial vector **x**<sup>(0)</sup> ∈ $\mathbb{R}^n$, the sequence $\lbrace \mathbf{x}^{ \left( k \right) } \rbrace _{k = 0}^{\infty}$ defined by ((4)), for each *k* ≥ 0 and **c** ≠ 0, converges to the unique solution of ((3)) if and only if *ρ*(**T**) \< 1, that is, **T** is a convergent matrix.[^o23][^o24]

### Regular splitting {#Regular_splitting}

A **matrix splitting** is an expression which represents a given matrix as a sum or difference of matrices. In the system of linear equations ((2)) above, with **A** non-singular, the matrix **A** can be split, that is, written as a difference

::: {#o26 .equation cue=numblk name="5"}

$$\mathbf{A} = \mathbf{B} - \mathbf{C} \tag{5}$$

:::

so that ((2)) can be re-written as ((4)) above. The expression ((5)) is a **regular splitting of A** if and only if **B**<sup>−1</sup> ≥ **0** and **C** ≥ **0**, that is, **B**<sup>−1</sup> and **C** have only nonnegative entries. If the splitting ((5)) is a regular splitting of the matrix **A** and **A**<sup>−1</sup> ≥ **0**, then *ρ*(**T**) \< 1 and **T** is a convergent matrix. Hence the method ((4)) converges.[^o27][^o28]

## Semi-convergent matrix {#Semi-convergent_matrix}

We call an *n* × *n* matrix **T** a **semi-convergent matrix** if the limit

::: {#o30 .equation cue=numblk name="6"}

$$\lim_{k \to \infty} \mathbf T^k \tag{6}$$

:::

exists.[^o31] If **A** is possibly singular but ((2)) is consistent, that is, **b** is in the range of **A**, then the sequence defined by ((4)) converges to a solution to ((2)) for every **x**<sup>(0)</sup> ∈ $\mathbb{R}^n$ if and only if **T** is semi-convergent. In this case, the splitting ((5)) is called a **semi-convergent splitting** of **A**.[^o32]
