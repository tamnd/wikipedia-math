# Kempf–Ness theorem

::: {#o1 .subject cue=lead name="Kempf–Ness theorem"}

In [algebraic geometry](wikipedia://en/1997), the **Kempf–Ness theorem**, introduced by (txt), gives a criterion for the [stability](wikipedia://en/1639003#Stability) of a vector in a [representation](wikipedia://en/12695) of a complex [reductive group](wikipedia://en/1088386). If the [complex](wikipedia://en/5826) [vector space](wikipedia://en/32370) is given a [norm](wikipedia://en/990534) that is [invariant](wikipedia://en/1126638) under a [maximal compact subgroup](wikipedia://en/1496726) of the reductive group, then the Kempf–Ness theorem states that a vector is stable if and only if the norm attains a minimum value on the [orbit](https://en.wikipedia.org/wiki/Group_action_%28mathematics%29) of the vector.

:::

The theorem has the following consequence: If *X* is a complex [smooth](https://en.wikipedia.org/wiki/Smooth_variety) [projective variety](wikipedia://en/320469) and if *G* is a reductive [complex Lie group](wikipedia://en/2187847), then $X /\!/ G$ (the [GIT quotient](wikipedia://en/41139312) of *X* by *G*) is [homeomorphic](wikipedia://en/13660) to the [symplectic quotient](https://en.wikipedia.org/wiki/Symplectic_quotient) of *X* by a [maximal compact subgroup](wikipedia://en/1496726) of *G*.
