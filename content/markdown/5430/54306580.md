# Line perfect graph

*Image: Line perfect graph.svg.* A line perfect graph. The edges in each biconnected component are colored black if the component is bipartite, blue if the component is a tetrahedron, and red if the component is a book of triangles.

::: {#o1 .subject cue=lead name="Line perfect graph"}

In [graph theory](wikipedia://en/12401), a **line perfect graph** is a [graph](wikipedia://en/325806) whose [line graph](wikipedia://en/675231) is a [perfect graph](wikipedia://en/670531). Equivalently, these are the graphs in which every odd-length [simple cycle](https://en.wikipedia.org/wiki/Simple_cycle) is a triangle.

:::

A graph is line perfect if and only if each of its [biconnected components](wikipedia://en/4842394) is a [bipartite graph](wikipedia://en/244431), the [complete graph](wikipedia://en/85816) $K_{4}$, or a [triangular book](wikipedia://en/2597784) $K_{1,1,n}$. Because these three types of biconnected component are all perfect graphs themselves, every line perfect graph is itself perfect. By similar reasoning, every line perfect graph is a [parity graph](wikipedia://en/51745979), a [Meyniel graph](wikipedia://en/744167), and a [perfectly orderable graph](wikipedia://en/21051205).

Line perfect graphs generalize the bipartite graphs, and share with them the properties that the [maximum matching](https://en.wikipedia.org/wiki/Maximum_matching) and [minimum vertex cover](https://en.wikipedia.org/wiki/Minimum_vertex_cover) have the same size, and that the [chromatic index](https://en.wikipedia.org/wiki/Chromatic_index) equals the [maximum degree](https://en.wikipedia.org/wiki/Maximum_degree).
