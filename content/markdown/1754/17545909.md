# Coates graph

*Image: Coates graph.svg.* The Coates graph of matrix A

::: {#o1 .subject cue=lead name="Coates graph"}

In [mathematics](wikipedia://en/18831), the **Coates graph** or **Coates flow graph**, named after C.L. Coates, is a [graph](wikipedia://en/325806) associated with the Coates' method for the solution of a [system of linear equations](wikipedia://en/113087).[^o6][^o5]

:::

The Coates graph *G*<sub>*c*</sub>(**A**) associated with an *n* × *n* [matrix](wikipedia://en/20556859) **A** is an *n*-node, weighted, labeled, [directed graph](wikipedia://en/19721986). The nodes, labeled 1 through *n*, are each associated with the corresponding row/column of **A**. If entry *a*<sub>*ji*</sub> ≠ 0 then there is a directed edge from node *i* to node *j* with weight *a*<sub>*ji*</sub>.[^o4] In other words, the Coates graph for matrix **A** is the one whose [adjacency matrix](wikipedia://en/244463) is the [transpose](wikipedia://en/173844) of **A**.
