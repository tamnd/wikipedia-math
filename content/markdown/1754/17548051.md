# Fast Walsh–Hadamard transform

*Image: Fast walsh hadamard transform 8.svg.* The fast Walsh–Hadamard transform applied to a vector of length 8

*Image: 1010 0110 Walsh spectrum (fast WHT).svg.* Example for the input vector (1, 0, 1, 0, 0, 1, 1, 0)

::: {#o1 .subject cue=lead name="Fast Walsh–Hadamard transform"}

In computational mathematics, the Hadamard ordered **fast Walsh–Hadamard transform** (**FWHT<sub>*h*</sub>**) is an efficient [algorithm](wikipedia://en/775) to compute the [Walsh–Hadamard transform](https://en.wikipedia.org/wiki/Walsh–Hadamard_transform) (WHT). A naive implementation of the WHT of order $n = 2^m$ would have a [computational complexity](wikipedia://en/7543) of [O($n^2$)](wikipedia://en/44578). The FWHT<sub>*h*</sub> requires only $n \log n$ additions or subtractions.

:::

The FWHT<sub>*h*</sub> is a [divide-and-conquer algorithm](wikipedia://en/201154) that [recursively](wikipedia://en/25407) breaks down a WHT of size $n$ into two smaller WHTs of size $n/2$. [^o2] This implementation follows the recursive definition of the $2^m \times 2^m$ [Hadamard matrix](wikipedia://en/507553) $H_m$:

$$H_m = \frac{1}{\sqrt 2} \begin{pmatrix} H_{m-1} & H_{m-1} \\ H_{m-1} & -H_{m-1} \end{pmatrix}.$$

The $1/\sqrt2$ normalization factors for each stage may be grouped together or even omitted.

The [sequency-ordered](wikipedia://en/1291534), also known as Walsh-ordered, fast Walsh–Hadamard transform, FWHT<sub>*w*</sub>, is obtained by computing the FWHT<sub>*h*</sub> as above, and then rearranging the outputs.

A simple fast nonrecursive implementation of the Walsh–Hadamard transform follows from decomposition of the Hadamard transform matrix as $H_m = A^m$, where *A* is *m*-th root of $H_m$. [^o3]

## Python example code {#Python_example_code}

```python
import math
def fwht(a) -> None:
    """In-place Fast Walsh–Hadamard Transform of array a."""
    assert math.log2(len(a)).is_integer(), "length of a is a power of 2"
    h = 1
    while h < len(a):
        # perform FWHT
        for i in range(0, len(a), h * 2):
            for j in range(i, i + h):
                x = a[j]
                y = a[j + h]
                a[j] = x + y
                a[j + h] = x - y
        # normalize and increment
        a /= math.sqrt(2)
        h *= 2
```
