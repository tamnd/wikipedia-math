# Gain scheduling

::: {#o1 .subject cue=lead name="Gain scheduling"}

In [control theory](wikipedia://en/7039), **gain scheduling** is an approach to control of [nonlinear systems](wikipedia://en/146103) that uses a family of linear [controllers](https://en.wikipedia.org/wiki/Controller_%28control_theory%29), each of which provides satisfactory control for a different [operating point](https://en.wikipedia.org/wiki/Operating_point) of the system.

:::

One or more [observable](wikipedia://en/871280) variables, called the *scheduling variables*, are used to determine what operating region the system is currently in and to enable the appropriate linear controller. For example, in an aircraft [flight control system](https://en.wikipedia.org/wiki/Flight_control_system), the [altitude](https://en.wikipedia.org/wiki/Altitude) and [Mach number](wikipedia://en/20051) might be the scheduling variables, with different linear controller parameters available (and automatically plugged into the controller) for various combinations of these two variables. In brief, gain scheduling is a control design approach that constructs a nonlinear controller for a nonlinear plant by patching together a collection of linear controllers.

A relatively large scope state of the art about gain scheduling has been published in (Survey of Gain-Scheduling Analysis & Design, D.J.Leith, WE.Leithead).[^o2]

Recently, new methodologies using Machine learning, such as Adaptive control based on [Artificial Neural Networks](https://en.wikipedia.org/wiki/Artificial_neural_networks) (ANN) and [Reinforcement Learning](wikipedia://en/66294),[^o3][^o4][^o5] have been studied.
