# Cylinder set measure

::: {#o1 .subject cue=lead name="Cylinder set measure"}

In [mathematics](wikipedia://en/18831), **cylinder set measure** (or **promeasure**, or **premeasure**, or **quasi-measure**, or **CSM**) is a kind of prototype for a [measure](wikipedia://en/19873) on an infinite-dimensional [vector space](wikipedia://en/32370). An example is the [Gaussian](https://en.wikipedia.org/wiki/Gauss) cylinder set measure on [Hilbert space](wikipedia://en/20598932).

:::

Cylinder set measures are in general **not** measures (and in particular need not be [countably additive](https://en.wikipedia.org/wiki/Sigma_additivity) but only [finitely additive](https://en.wikipedia.org/wiki/Sigma_additivity)), but can be used to define measures, such as the [classical Wiener measure](wikipedia://en/6810363#Classical_Wiener_measure) on the set of continuous paths starting at the origin in [Euclidean space](wikipedia://en/9697). This is done in the construction of the [abstract Wiener space](wikipedia://en/6592746) where one defines a cylinder set Gaussian measure on a separable Hilbert space and chooses a Banach space in such a way that the cylindrical measure becomes σ-additive on the cylindrical algebra.

The terminology is not always consistent in the literature. Some authors call cylinder set measures just **cylinder measure** or **cylindrical measures** (see e.g.[^o2][^o3][^o4]), while some reserve this word only for σ-additive measures.

::: {#o6 .definition cue=heading name="Definition"}

## Definition {#Definition}

There are two equivalent ways to define a cylinder set measure.

One way is to define it directly as a set function on the [cylindrical algebra](wikipedia://en/21236657) such that certain restrictions on smaller σ-algebras are σ-additive measure. This can also be expressed in terms of a finite-dimensional linear operator.

Denote by $\mathcal{Cyl}(N,M)$ the cylindrical algebra defined for two spaces with [dual pairing](wikipedia://en/63735167) $\langle,\rangle:=\langle,\rangle_{N,M}$, i.e. the set of all cylindrical sets

$$C_{f_1,\dots,f_m,B}=\{x\in N\colon (\langle x,f_1\rangle,\dots,\langle x,f_m\rangle)\in B\}$$

for some $f_1,\dots,f_m\in M$ and $B\in \mathcal{B}(\mathbb{R}^m)$.[^o7][^o8] This is an algebra which can also be written as the union of smaller σ-algebras.

### Definition on the cylindrical algebra {#Definition_on_the_cylindrical_algebra}

Let $X$ be a [topological vector space](wikipedia://en/45752) over $\mathbb{R}$, denote its algebraic dual as $X^*$ and let $G\subseteq X^*$ be a subspace. Then the set function $\mu:\mathcal{Cyl}(X,G)\to \mathbb{R}_{+}$ is a **cylinder set measure** (or **cylinderical measure**) if for any finite set $F=\{f_1,\dots,f_n\}\subset G$ the restriction to

$$\mu:\sigma(\mathcal{Cyl}(X,F))\to \mathbb{R}_{+}$$

is a σ-additive measure. Notice that $\sigma(\mathcal{Cyl}(X,F))$ is a σ-algebra while $\mathcal{Cyl}(X,G)$ is not.[^o2][^o3][^o10]

As usual if $\mu(X)=1$ we call it a **cylindrical probability measure**.

### Operatic definition {#Operatic_definition}

Let $E$ be a [real](wikipedia://en/20646438) [topological vector space](wikipedia://en/45752). Let $\mathcal{A} (E)$ denote the collection of all [surjective](https://en.wikipedia.org/wiki/Surjection) [continuous linear maps](https://en.wikipedia.org/wiki/Continuous_linear_map) $T : E \to F_T$ defined on $E$ whose image is some finite-dimensional real vector space $F_T$:

$$\mathcal{A} (E) := \left\{ T \in \mathrm{Lin} (E; F_{T}) : T \mbox{ surjective and } \dim_{\mathbb{R}} F_{T} < + \infty\right\}.$$

A **cylinder set measure** on $E$ is a collection of [measures](wikipedia://en/19873)

$$\left\{\mu_{T} : T \in \mathcal{A} (E)\right\}.$$

where $\mu_T$ is a measure on $F_T.$ These measures are required to satisfy the following consistency condition: if $\pi_{ST} : F_S \to F_T$ is a surjective [projection](wikipedia://en/3909097), then the [push forward](wikipedia://en/9412979) of the measure is as follows:

$$\mu_{T} = \left(\pi_{ST}\right)_{*} \left(\mu_{S}\right).$$

If $\mu(E)=1$ then it's a **cylindrical probability measure**. Some authors define cylindrical measures explicitly as probability measures, however they don't need to be.

:::

## Connection to the abstract Wiener spaces {#Connection_to_the_abstract_Wiener_spaces}

Let $(H,B,i)$ be an [abstract Wiener space](wikipedia://en/6592746) in its classical definition by [Leonard Gross](wikipedia://en/64592988). This is a separable [Hilbert space](wikipedia://en/20598932) $H$, a separable Banach space $B$ that is the completion under a *measurable norm* or *Gross-measurable norm* $\|\cdot\|_1$ and a continuous linear embedding $i:H\to B$ with dense range. Gross then showed that this construction allows to continue a cylindrical Gaussian measure as a σ-additive measure on the Banach space. More precisely let $H'$ be the topological dual space of $H$, he showed that a cylindrical Gaussian measure on $H$ defined on the cylindrical algebra $\mathcal{Cyl}(H,H')$ will be σ-additive on the cylindrical algebra $\mathcal{Cyl}(B,B')$ of the Banach space. Hence the measure is also σ-additive on the cylindrical σ-algebra $\mathcal{E}(B,B'):=\sigma(\mathcal{Cyl}(B,B')).$ This follows from the [Carathéodory's extension theorem](wikipedia://en/4026968), and is therefore also a measure in the classical sense.[^o13]

## Remarks {#Remarks}

The consistency condition

$$\mu_{T} = \left(\pi_{ST}\right)_{*} (\mu_{S})$$

is modelled on the way that true measures push forward (see the section cylinder set measures versus true measures). However, it is important to understand that in the case of cylinder set measures, this is a requirement that is part of the definition, not a result.

A cylinder set measure can be intuitively understood as defining a finitely additive function on the [cylinder sets](wikipedia://en/2613658) of the topological vector space $E.$ The **cylinder sets** are the [pre-images](https://en.wikipedia.org/wiki/Pre-image) in $E$ of measurable sets in $F_T$: if $\mathcal{B}_{T}$ denotes the [$\sigma$-algebra](wikipedia://en/29586) on $F_T$ on which $\mu_T$ is defined, then

$$\mathrm{Cyl} (E) := \left\{T^{-1} (B) : B \in \mathcal{B}_{T}, T \in \mathcal{A} (E)\right\}.$$

In practice, one often takes $\mathcal{B}_{T}$ to be the [Borel $\sigma$-algebra](https://en.wikipedia.org/wiki/Borel_sigma_algebra) on $F_T.$ In this case, one can show that when $E$ is a [separable](wikipedia://en/27855) [Banach space](wikipedia://en/3989), the σ-algebra generated by the cylinder sets is precisely the Borel $\sigma$-algebra of $E$:

$$\mathrm{Borel} (E) = \sigma \left(\mathrm{Cyl} (E)\right).$$

## Cylinder set measures versus true measures {#Cylinder_set_measures_versus_true_measures}

A cylinder set measure on $E$ is not actually a true measure on $E$: it is a collection of measures defined on all finite-dimensional images of $E.$ If $E$ has a probability measure $\mu$ already defined on it, then $\mu$ gives rise to a cylinder set measure on $E$ using the push forward: set $\mu_T = T_{*}(\mu)$on $F_T.$

When there is a measure $\mu$ on $E$ such that $\mu_T = T_{*}(\mu)$ in this way, it is customary to [abuse notation](wikipedia://en/1698066) slightly and say that the cylinder set measure $\left\{\mu_{T} : T \in \mathcal{A} (E)\right\}$ "is" the measure $\mu.$

## Cylinder set measures on Hilbert spaces {#Cylinder_set_measures_on_Hilbert_spaces}

When the Banach space $E$ is also a [Hilbert space](wikipedia://en/20598932) $H,$ there is a **canonical Gaussian cylinder set measure** $\gamma^H$ arising from the [inner product](https://en.wikipedia.org/wiki/Inner_product) structure on $H.$ Specifically, if $\langle \cdot, \cdot \rangle$ denotes the inner product on $H,$ let $\langle \cdot, \cdot \rangle_T$ denote the [quotient inner product](https://en.wikipedia.org/wiki/Quotient_inner_product) on $F_T.$ The measure $\gamma_T^H$ on $F_T$ is then defined to be the canonical [Gaussian measure](wikipedia://en/6572909) on $F_T$:

$$\gamma_{T}^{H} := i_{*} \left(\gamma^{\dim F_{T}}\right),$$

where $i : \mathbb{R}^{\dim(F_T)} \to F_T$ is an [isometry](wikipedia://en/254777) of Hilbert spaces taking the [Euclidean](wikipedia://en/9417) inner product on $\mathbb{R}^{\dim(F_T)}$ to the inner product $\langle \cdot, \cdot \rangle_T$ on $F_T,$ and $\gamma^n$ is the standard [Gaussian measure](wikipedia://en/6572909) on $\mathbb{R}^n.$

The canonical Gaussian cylinder set measure on an infinite-dimensional separable Hilbert space $H$ does not correspond to a true measure on $H.$ The proof is quite simple: the ball of radius $r$ (and center 0) has measure at most equal to that of the ball of radius $r$ in an $n$-dimensional Hilbert space, and this tends to 0 as $n$ tends to infinity. So the ball of radius $r$ has measure 0; as the Hilbert space is a countable union of such balls it also has measure 0, which is a contradiction. (See [infinite dimensional Lebesgue measure](wikipedia://en/6607484).)

An alternative proof that the Gaussian cylinder set measure is not a measure uses the [Cameron–Martin theorem](wikipedia://en/6573013) and a result on the [quasi-invariance of measures](wikipedia://en/2749048). If $\gamma^H = \gamma$ really were a measure, then the [identity function](wikipedia://en/15069) on $H$ would [radonify](https://en.wikipedia.org/wiki/Radonify) that measure, thus making $\operatorname{id} : H \to H$ into an [abstract Wiener space](wikipedia://en/6592746). By the Cameron–Martin theorem, $\gamma$ would then be quasi-invariant under translation by any element of $H,$ which implies that either $H$ is finite-dimensional or that $\gamma$ is the zero measure. In either case, we have a contradiction.

[Sazonov's theorem](wikipedia://en/9196302) gives conditions under which the [push forward](wikipedia://en/9412979) of a canonical Gaussian cylinder set measure can be turned into a true measure.

## Nuclear spaces and cylinder set measures {#Nuclear_spaces_and_cylinder_set_measures}

A cylinder set measure on the dual of a [nuclear](wikipedia://en/2702957) [Fréchet space](wikipedia://en/233801) automatically extends to a measure if its Fourier transform is continuous.

::: {#o18 .example cue=inline-head name="Example"}

**Example**: Let $S$ be the space of [Schwartz functions](https://en.wikipedia.org/wiki/Distribution_%28mathematics%29) on a finite dimensional vector space; it is nuclear. It is contained in the Hilbert space $H$ of [$L^2$ functions](wikipedia://en/45194), which is in turn contained in the space of [tempered distributions](wikipedia://en/10995628) $S^\prime,$ the dual of the [nuclear](wikipedia://en/2702957) [Fréchet space](wikipedia://en/233801) $S$:

$$S \subseteq H \subseteq S^\prime.$$

The Gaussian cylinder set measure on $H$ gives a cylinder set measure on the space of tempered distributions, which extends to a measure on the space of tempered distributions, $S^\prime.$

The Hilbert space $H$ has measure 0 in $S^\prime,$ by the first argument used above to show that the canonical Gaussian cylinder set measure on $H$ does not extend to a measure on $H.$

:::
