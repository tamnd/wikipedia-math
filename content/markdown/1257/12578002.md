# AsciiMath

::: {#o1 .subject cue=lead name="AsciiMath"}

**AsciiMath** is a client-side [mathematical markup language](wikipedia://en/10636131) for displaying mathematical expressions in [web browsers](https://en.wikipedia.org/wiki/Web_browser).[^o2][^o3]

:::

## Details {#Details}

Using the [JavaScript](https://en.wikipedia.org/wiki/JavaScript) script ASCIIMathML.js, AsciiMath notation is converted to [MathML](wikipedia://en/52313) at the time the page is loaded by the browser, natively in [Mozilla Firefox](https://en.wikipedia.org/wiki/Mozilla_Firefox), [Safari](https://en.wikipedia.org/wiki/Safari_%28web_browser%29), and via a plug-in in [IE7](https://en.wikipedia.org/wiki/IE7). The simplified markup language supports a subset of the [LaTeX](https://en.wikipedia.org/wiki/LaTeX) language instructions, as well as a less verbose syntax (which, for example, replaces "\\times" with "xx" or "times" to produce the "×" symbol). The resulting MathML mathematics can be styled by applying [CSS](https://en.wikipedia.org/wiki/CSS) to class "mstyle".[^o5]

The script ASCIIMathML.js is freely available under the [MIT License](https://en.wikipedia.org/wiki/MIT_License).[^o6] The latest version also includes support for [SVG](https://en.wikipedia.org/wiki/Scalable_Vector_Graphics) graphics, natively in [Mozilla Firefox](https://en.wikipedia.org/wiki/Mozilla_Firefox) and via a plug-in in [IE7](https://en.wikipedia.org/wiki/IE7).

Per May 2009 there is a new version available. This new version still contains the original ASCIIMathML and LaTeXMathML as developed by Peter Jipsen, but the ASCIIsvg part has been extended with linear-logarithmic, logarithmic-linear, logarithmic-logarithmic, polar graphs and pie charts, normal and stacked bar charts, different functions like integration and differentiation and a series of event trapping functions, buttons and sliders, in order to create interactive lecture material and exams online in web pages.

ASCIIMathML.js has been integrated into [MathJax](https://en.wikipedia.org/wiki/MathJax), starting with MathJax v2.0.[^o7][^o8]

::: {#o10 .example cue=heading name="Example"}

## Example {#Example}

The well-known [quadratic formula](wikipedia://en/59217)

$$x=\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

looks like this in AsciiMath: x=(-b +- sqrt(b^2 – 4ac))/(2a)

:::
