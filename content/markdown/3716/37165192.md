# Algebraic matroid

::: {#o1 .subject cue=lead name="Algebraic matroid"}

In [mathematics](wikipedia://en/18831), an **algebraic matroid** is a [matroid](wikipedia://en/244321), a [combinatorial](wikipedia://en/5170) structure, that expresses an abstraction of the relation of [algebraic independence](wikipedia://en/287808).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Given a [field extension](wikipedia://en/11634) *L*/*K*, [Zorn's lemma](wikipedia://en/51442) can be used to show that there always exists a maximal algebraically independent subset of *L* over *K*. Further, all the maximal algebraically independent subsets have the same [cardinality](wikipedia://en/6174), known as the [transcendence degree](https://en.wikipedia.org/wiki/Transcendence_degree) of the extension.

For every finite set *S* of elements of *L*, the algebraically independent subsets of *S* satisfy the axioms that define the independent sets of a [matroid](wikipedia://en/244321). In this matroid, the rank of a set of elements is its transcendence degree, and the flat generated by a set *T* of elements is the intersection of *L* with the field *K*\[*T*\].[^o4] A matroid that can be generated in this way is called *algebraic* or *algebraically representable*.[^o5] No good characterization of algebraic matroids is known,[^o6] but certain matroids are known to be non-algebraic; the smallest is the [Vámos matroid](wikipedia://en/36886801).[^o7][^o13]

:::

## Relation to linear matroids {#Relation_to_linear_matroids}

Many finite matroids may be [represented](wikipedia://en/37165960) by a [matrix](wikipedia://en/20556859) over a field *K*, in which the matroid elements correspond to matrix columns, and a set of elements is independent if the corresponding set of columns is [linearly independent](wikipedia://en/101863). Every matroid with a linear representation of this type over a field *F* may also be represented as an algebraic matroid over *F*,[^o9][^o10] by choosing an [indeterminate](https://en.wikipedia.org/wiki/Indeterminate_%28variable%29) for each row of the matrix, and by using the matrix coefficients within each column to assign each matroid element a linear combination of these transcendentals. For fields of characteristic zero (such as the real numbers) linear and algebraic matroids coincide, but for other fields there may exist algebraic matroids that are not linear;[^o11][^o12] indeed the non-Pappus matroid is algebraic over any finite field, but not linear and not algebraic over any field of characteristic zero.[^o10] However, if a matroid is algebraic over a field *F* of characteristic zero then it is linear over *F*(*T*) for some finite set of transcendentals *T* over *F*[^o13] and over the [algebraic closure](wikipedia://en/3129) of *F*.[^o10]

## Closure properties {#Closure_properties}

If a matroid is algebraic over a [simple extension](wikipedia://en/4771726) *F*(*t*) then it is algebraic over *F*. It follows that the class of algebraic matroids is closed under [contraction](wikipedia://en/36749660),[^o15] and that a matroid algebraic over *F* is algebraic over the [prime field](https://en.wikipedia.org/wiki/Prime_field) of *F*.[^o16]

The class of algebraic matroids is closed under truncation and matroid union.[^o20] It is not known whether the [dual](https://en.wikipedia.org/wiki/Matroid_dual) of an algebraic matroid is always algebraic[^o17] and there is no excluded minor characterisation of the class.[^o20]

## Characteristic set {#Characteristic_set}

The **(algebraic) characteristic set** *K*(*M*) of a matroid *M* is the set of possible [characteristics](wikipedia://en/1066621) of fields over which *M* is algebraically representable.[^o10]

- If 0 is in *K*(*M*) then all sufficiently large primes are in *K*(*M*).[^o10]
- Every prime occurs as the unique characteristic for some matroid.[^o10][^o19]
- If *M* is algebraic over *F* then any contraction of *M* is algebraic over *F* and hence so is any minor of *M*.[^o20]
