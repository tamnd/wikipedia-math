# Metrizable topological vector space

::: {#o1 .subject cue=lead name="Metrizable topological vector space"}

In [functional analysis](wikipedia://en/11180) and related areas of [mathematics](wikipedia://en/18831), a **metrizable** (resp. **pseudometrizable**) [topological vector space](wikipedia://en/45752) (TVS) is a TVS whose topology is induced by a metric (resp. [pseudometric](wikipedia://en/68503)). An **LM-space** is an [inductive limit](https://en.wikipedia.org/wiki/Inductive_limit) of a sequence of [locally convex](https://en.wikipedia.org/wiki/Locally_convex) metrizable TVS.

:::

## Pseudometrics and metrics {#Pseudometrics_and_metrics}

A **[pseudometric](wikipedia://en/68503)** on a set $X$ is a map $d : X \times X \rightarrow \mathbb{R}$ satisfying the following properties:

$d(x, x) = 0 \text{ for all } x \in X$; **Symmetry**: $d(x, y) = d(y, x) \text{ for all } x, y \in X$; **[Subadditivity](https://en.wikipedia.org/wiki/Subadditive)**: $d(x, z) \leq d(x, y) + d(y, z) \text{ for all } x, y, z \in X.$

A pseudometric is called a **[metric](https://en.wikipedia.org/wiki/Metric_%28mathematics%29)** if it satisfies:

**[Identity of indiscernibles](wikipedia://en/630398)**: for all $x, y \in X,$ if $d(x, y) = 0$ then $x = y.$

**Ultrapseudometric**

A pseudometric $d$ on $X$ is called a **[ultrapseudometric](https://en.wikipedia.org/wiki/Ultrametric)** or a **strong pseudometric** if it satisfies:

**Strong**/**Ultrametric triangle inequality**: $d(x, z) \leq \max \{ d(x, y), d(y, z) \} \text{ for all } x, y, z \in X.$

**Pseudometric space**

A **[pseudometric space](wikipedia://en/68503)** is a pair $(X, d)$ consisting of a set $X$ and a pseudometric $d$ on $X$ such that $X$'s topology is identical to the topology on $X$ induced by $d.$ We call a pseudometric space $(X, d)$ a **[metric space](wikipedia://en/20018)** (resp. **ultrapseudometric space**) when $d$ is a metric (resp. ultrapseudometric).

### Topology induced by a pseudometric {#Topology_induced_by_a_pseudometric}

If $d$ is a pseudometric on a set $X$ then collection of **open balls**:

$$B_r(z) := \{ x \in X : d(x, z) < r \}$$

as $z$ ranges over $X$ and $r > 0$ ranges over the positive real numbers, forms a basis for a topology on $X$ that is called the $d$**\-topology** or the **pseudometric topology** on $X$ induced by $d.$

Convention: If $(X, d)$ is a pseudometric space and $X$ is treated as a [topological space](wikipedia://en/30450), then unless indicated otherwise, it should be assumed that $X$ is endowed with the topology induced by $d.$

**Pseudometrizable space**

A topological space $(X, \tau)$ is called **pseudometrizable** (resp. **metrizable**, **ultrapseudometrizable**) if there exists a pseudometric (resp. metric, ultrapseudometric) $d$ on $X$ such that $\tau$ is equal to the topology induced by $d.$[^n1]

## Pseudometrics and values on topological groups {#Pseudometrics_and_values_on_topological_groups}

An additive [topological group](wikipedia://en/42315) is an additive group endowed with a topology, called a **group topology**, under which addition and negation become continuous operators.

A topology $\tau$ on a real or complex vector space $X$ is called a **vector topology** or a **TVS topology** if it makes the operations of vector addition and [scalar multiplication](wikipedia://en/244373) continuous (that is, if it makes $X$ into a [topological vector space](wikipedia://en/45752)).

Every [topological vector space](wikipedia://en/45752) (TVS) $X$ is an additive commutative topological group but not all group topologies on $X$ are vector topologies. This is because despite it making addition and negation continuous, a group topology on a vector space $X$ may fail to make scalar multiplication continuous. For instance, the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology) on any non-trivial vector space makes addition and negation continuous but do not make scalar multiplication continuous.

### Translation invariant pseudometrics {#Translation_invariant_pseudometrics}

If $X$ is an additive group then we say that a pseudometric $d$ on $X$ is **translation invariant** or just **invariant** if it satisfies any of the following equivalent conditions:

**[Translation invariance](https://en.wikipedia.org/wiki/Translation_invariance)**: $d(x + z, y + z) = d(x, y) \text{ for all } x, y, z \in X$; $d(x, y) = d(x - y, 0) \text{ for all } x, y \in X.$

### Value/G-seminorm {#Value/G-seminorm}

If $X$ is a [topological group](wikipedia://en/42315) the a **value** or **G-seminorm** on $X$ (the *G* stands for Group) is a real-valued map $p : X \rightarrow \mathbb{R}$ with the following properties:[^n2]

**Non-negative**: $p \geq 0.$ **Subadditive**: $p(x + y) \leq p(x) + p(y) \text{ for all } x, y \in X$; $p(0) = 0..$ **Symmetric**: $p(-x) = p(x) \text{ for all } x \in X.$

where we call a G-seminorm a **G-norm** if it satisfies the additional condition:

**Total**/**Positive definite**: If $p(x) = 0$ then $x = 0.$

#### Properties of values {#Properties_of_values}

If $p$ is a value on a vector space $X$ then:

$|p(x) - p(y)| \leq p(x - y) \text{ for all } x, y \in X.$[^n3] $p(n x) \leq n p(x)$ and $\frac{1}{n} p(x) \leq p(x / n)$ for all $x \in X$ and positive integers $n.$[^n4] The set $\{ x \in X : p(x) = 0 \}$ is an additive subgroup of $X.$[^n3]

### Equivalence on topological groups {#Equivalence_on_topological_groups}

::: {#o15 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^n2].**

Suppose that $X$ is an additive commutative group. If $d$ is a translation invariant pseudometric on $X$ then the map $p(x) := d(x, 0)$ is a value on $X$ called **the value associated with $d$**, and moreover, $d$ generates a group topology on $X$ (i.e. the $d$-topology on $X$ makes $X$ into a topological group). Conversely, if $p$ is a value on $X$ then the map $d(x, y) := p(x - y)$ is a translation-invariant pseudometric on $X$ and the value associated with $d$ is just $p.$

:::

### Pseudometrizable topological groups {#Pseudometrizable_topological_groups}

::: {#o18 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^n2].**

If $(X, \tau)$ is an additive commutative [topological group](wikipedia://en/42315) then the following are equivalent:

$\tau$ is induced by a pseudometric; (i.e. $(X, \tau)$ is pseudometrizable); $\tau$ is induced by a translation-invariant pseudometric; the identity element in $(X, \tau)$ has a countable neighborhood basis.

If $(X, \tau)$ is Hausdorff then the word "pseudometric" in the above statement may be replaced by the word "metric." A commutative topological group is metrizable if and only if it is Hausdorff and pseudometrizable.

:::

### An invariant pseudometric that doesn't induce a vector topology {#An_invariant_pseudometric_that_doesn't_induce_a_vector_topology}

Let $X$ be a non-trivial (i.e. $X \neq \{ 0 \}$) real or complex vector space and let $d$ be the translation-invariant **trivial metric** on $X$ defined by $d(x, x) = 0$ and $d(x, y) = 1 \text{ for all } x, y \in X$ such that $x \neq y.$ The topology $\tau$ that $d$ induces on $X$ is the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology), which makes $(X, \tau)$ into a commutative topological group under addition but does not form a vector topology on $X$ because $(X, \tau)$ is [disconnected](wikipedia://en/6233) but every vector topology is connected. What fails is that scalar multiplication isn't continuous on $(X, \tau).$

This example shows that a translation-invariant (pseudo)metric is not enough to guarantee a vector topology, which leads us to define paranorms and *F*-seminorms.

## Additive sequences {#Additive_sequences}

A collection $\mathcal{N}$ of subsets of a vector space is called **additive**[^n5] if for every $N \in \mathcal{N},$ there exists some $U \in \mathcal{N}$ such that $U + U \subseteq N.$

::: {#o22 .statement kind=statement/theorem cue=math-theorem name="Continuity of addition at 0"}

**Continuity of addition at 0.**

If $(X, +)$ is a [group](wikipedia://en/19447) (as all vector spaces are), $\tau$ is a topology on $X,$ and $X \times X$ is endowed with the [product topology](wikipedia://en/24910), then the addition map $X \times X \to X$ (i.e. the map $(x, y) \mapsto x + y$) is continuous at the origin of $X \times X$ if and only if the set of [neighborhoods](https://en.wikipedia.org/wiki/Neighborhood_%28topology%29) of the origin in $(X, \tau)$ is additive. This statement remains true if the word "neighborhood" is replaced by "open neighborhood."[^n5]

:::

All of the above conditions are consequently a necessary for a topology to form a vector topology. Additive sequences of sets have the particularly nice property that they define non-negative continuous real-valued [subadditive](https://en.wikipedia.org/wiki/Subadditive) functions. These functions can then be used to prove many of the basic properties of topological vector spaces and also show that a Hausdorff TVS with a countable basis of neighborhoods is metrizable. The following theorem is true more generally for commutative additive [topological groups](wikipedia://en/42315).

::: {#o24 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

Let $U_{\bullet} = \left(U_i\right)_{i=0}^{\infty}$ be a collection of subsets of a vector space such that $0 \in U_i$ and $U_{i+1} + U_{i+1} \subseteq U_i$ for all $i \geq 0.$ For all $u \in U_0,$ let

$$\mathbb{S}(u) := \left\{ n_{\bullet} = \left(n_1, \ldots, n_k\right) ~:~ k \geq 1, n_i \geq 0 \text{ for all } i, \text{ and } u \in U_{n_1} + \cdots + U_{n_k}\right\}.$$

Define $f : X \to [0, 1]$ by $f(x) = 1$ if $x \not\in U_0$ and otherwise let

$$f(x) := \inf_{} \left\{ 2^{- n_1} + \cdots 2^{- n_k} ~:~ n_{\bullet} = \left(n_1, \ldots, n_k\right) \in \mathbb{S}(x)\right\}.$$

Then $f$ is [subadditive](wikipedia://en/745789) (meaning $f(x + y) \leq f(x) + f(y) \text{ for all } x, y \in X$) and $f = 0$ on $\bigcap_{i \geq 0} U_i,$ so in particular $f(0) = 0.$ If all $U_i$ are [symmetric sets](wikipedia://en/22260858) then $f(-x) = f(x)$ and if all $U_i$ are balanced then $f(s x) \leq f(x)$ for all scalars $s$ such that $|s| \leq 1$ and all $x \in X.$ If $X$ is a topological vector space and if all $U_i$ are neighborhoods of the origin then $f$ is continuous, where if in addition $X$ is Hausdorff and $U_{\bullet}$ forms a basis of balanced neighborhoods of the origin in $X$ then $d(x, y) := f(x - y)$ is a metric defining the vector topology on $X.$

:::

::: {#o25 .proof cue=collapse name="Proof"}

Assume that $n_{\bullet} = \left(n_1, \ldots, n_k\right)$ always denotes a finite sequence of non-negative integers and use the notation:

$$\sum 2^{- n_{\bullet}} := 2^{- n_1} + \cdots + 2^{- n_k} \quad \text{ and } \quad \sum U_{n_{\bullet}} := U_{n_1} + \cdots + U_{n_k}.$$

For any integers $n \geq 0$ and $d > 2,$

$$U_n \supseteq U_{n+1} + U_{n+1} \supseteq U_{n+1} + U_{n+2} + U_{n+2} \supseteq U_{n+1} + U_{n+2} + \cdots + U_{n+d} + U_{n+d+1} + U_{n+d+1}.$$

From this it follows that if $n_{\bullet} = \left(n_1, \ldots, n_k\right)$ consists of distinct positive integers then $\sum U_{n_{\bullet}} \subseteq U_{-1 + \min \left(n_{\bullet}\right)}.$

It will now be shown by induction on $k$ that if $n_{\bullet} = \left(n_1, \ldots, n_k\right)$ consists of non-negative integers such that $\sum 2^{- n_{\bullet}} \leq 2^{- M}$ for some integer $M \geq 0$ then $\sum U_{n_{\bullet}} \subseteq U_M.$ This is clearly true for $k = 1$ and $k = 2$ so assume that $k > 2,$ which implies that all $n_i$ are positive. If all $n_i$ are distinct then this step is done, and otherwise pick distinct indices $i < j$ such that $n_i = n_j$ and construct $m_{\bullet} = \left(m_1, \ldots, m_{k-1}\right)$ from $n_{\bullet}$ by replacing each $n_i$ with $n_i - 1$ and deleting the $j^{\text{th}}$ element of $n_{\bullet}$ (all other elements of $n_{\bullet}$ are transferred to $m_{\bullet}$ unchanged). Observe that $\sum 2^{- n_{\bullet}} = \sum 2^{- m_{\bullet}}$ and $\sum U_{n_{\bullet}} \subseteq \sum U_{m_{\bullet}}$ (because $U_{n_i} + U_{n_j} \subseteq U_{n_i - 1}$) so by appealing to the inductive hypothesis we conclude that $\sum U_{n_{\bullet}} \subseteq \sum U_{m_{\bullet}} \subseteq U_M,$ as desired.

It is clear that $f(0) = 0$ and that $0 \leq f \leq 1$ so to prove that $f$ is subadditive, it suffices to prove that $f(x + y) \leq f(x) + f(y)$ when $x, y \in X$ are such that $f(x) + f(y) < 1,$ which implies that $x, y \in U_0.$ This is an exercise. If all $U_i$ are symmetric then $x \in \sum U_{n_{\bullet}}$ if and only if $- x \in \sum U_{n_{\bullet}}$ from which it follows that $f(-x) \leq f(x)$ and $f(-x) \geq f(x).$ If all $U_i$ are balanced then the inequality $f(s x) \leq f(x)$ for all unit scalars $s$ such that $|s| \leq 1$ is proved similarly. Because $f$ is a nonnegative subadditive function satisfying $f(0) = 0,$ as described in the article on [sublinear functionals](https://en.wikipedia.org/wiki/Sublinear_functional), $f$ is uniformly continuous on $X$ if and only if $f$ is continuous at the origin. If all $U_i$ are neighborhoods of the origin then for any real $r > 0,$ pick an integer $M > 1$ such that $2^{-M} < r$ so that $x \in U_M$ implies $f(x) \leq 2^{-M} < r.$ If the set of all $U_i$ form basis of balanced neighborhoods of the origin then it may be shown that for any $n > 1,$ there exists some $0 < r \leq 2^{-n}$ such that $f(x) < r$ implies $x \in U_n.$ $\blacksquare$

:::

## Paranorms {#Paranorms}

If $X$ is a vector space over the real or complex numbers then a **paranorm** on $X$ is a G-seminorm (defined above) $p : X \rightarrow \mathbb{R}$ on $X$ that satisfies any of the following additional conditions, each of which begins with "for all sequences $x_{\bullet} = \left(x_i\right)_{i=1}^{\infty}$ in $X$ and all convergent sequences of scalars $s_{\bullet} = \left(s_i\right)_{i=1}^{\infty}$":[^n6]

**Continuity of multiplication**: if $s$ is a scalar and $x \in X$ are such that $p\left(x_i - x\right) \to 0$ and $s_{\bullet} \to s,$ then $p\left(s_i x_i - s x\right) \to 0.$ Both of the conditions:

if $s_{\bullet} \to 0$ and if $x \in X$ is such that $p\left(x_i - x\right) \to 0$ then $p\left(s_i x_i\right) \to 0$;

if $p\left(x_{\bullet}\right) \to 0$ then $p\left(s x_i\right) \to 0$ for every scalar $s.$ Both of the conditions:

if $p\left(x_{\bullet}\right) \to 0$ and $s_{\bullet} \to s$ for some scalar $s$ then $p\left(s_i x_i\right) \to 0$;

if $s_{\bullet} \to 0$ then $p\left(s_i x\right) \to 0 \text{ for all } x \in X.$ **Separate continuity**:[^n7]

if $s_{\bullet} \to s$ for some scalar $s$ then $p\left(s x_i - s x\right) \to 0$ for every $x \in X$;

if $s$ is a scalar, $x \in X,$ and $p\left(x_i - x\right) \to 0$ then $p\left(s x_i - s x\right) \to 0$ .

A paranorm is called **total** if in addition it satisfies:

**Total**/**Positive definite**: $p(x) = 0$ implies $x = 0.$

### Properties of paranorms {#Properties_of_paranorms}

If $p$ is a paranorm on a vector space $X$ then the map $d : X \times X \rightarrow \mathbb{R}$ defined by $d(x, y) := p(x - y)$ is a translation-invariant pseudometric on $X$ that defines a vector topology on $X.$[^n8]

If $p$ is a paranorm on a vector space $X$ then:

the set $\{ x \in X : p(x) = 0 \}$ is a vector subspace of $X.$[^n8] $p(x + n) = p(x) \text{ for all } x, n \in X$ with $p(n) = 0.$[^n8] If a paranorm $p$ satisfies $p(s x) \leq |s| p(x) \text{ for all } x \in X$ and scalars $s,$ then $p$ is absolutely homogeneity (i.e. equality holds)[^n8] and thus $p$ is a [seminorm](wikipedia://en/292067).

### Examples of paranorms {#Examples_of_paranorms}

If $d$ is a translation-invariant pseudometric on a vector space $X$ that induces a vector topology $\tau$ on $X$ (i.e. $(X, \tau)$ is a TVS) then the map $p(x) := d(x - y, 0)$ defines a continuous paranorm on $(X, \tau)$; moreover, the topology that this paranorm $p$ defines in $X$ is $\tau.$[^n8] If $p$ is a paranorm on $X$ then so is the map $q(x) := p(x) / [1 + p(x)].$[^n8] Every positive scalar multiple of a paranorm (resp. total paranorm) is again such a paranorm (resp. total paranorm). Every [seminorm](wikipedia://en/292067) is a paranorm.[^n8] The restriction of an paranorm (resp. total paranorm) to a vector subspace is an paranorm (resp. total paranorm).[^n9] The sum of two paranorms is a paranorm.[^n8] If $p$ and $q$ are paranorms on $X$ then so is $(p \wedge q)(x) := \inf_{} \{ p(y) + q(z) : x = y + z \text{ with } y, z \in X \}.$ Moreover, $(p \wedge q) \leq p$ and $(p \wedge q) \leq q.$ This makes the set of paranorms on $X$ into a [conditionally complete lattice](wikipedia://en/469304#Conditional_completeness).[^n8] Each of the following real-valued maps are paranorms on $X := \mathbb{R}^2$:

$$(x, y) \mapsto |x|$$

$(x, y) \mapsto |x| + |y|$ The real-valued maps $(x, y) \mapsto \sqrt{\left|x^2 - y^2\right|}$ and $(x, y) \mapsto \left|x^2 - y^2\right|^{3/2}$ are not paranorms on $X := \mathbb{R}^2.$[^n8] If $x_{\bullet} = \left(x_i\right)_{i \in I}$ is a [Hamel basis](https://en.wikipedia.org/wiki/Hamel_basis) on a vector space $X$ then the real-valued map that sends $x = \sum_{i \in I} s_i x_i \in X$ (where all but finitely many of the scalars $s_i$ are 0) to $\sum_{i \in I} \sqrt{\left|s_i\right|}$ is a paranorm on $X,$ which satisfies $p(sx) = \sqrt{|s|} p(x)$ for all $x \in X$ and scalars $s.$[^n8] The function $p(x) := |\sin (\pi x)| + \min \{ 2, |x| \}$ is a paranorm on $\mathbb{R}$ that is not balanced but nevertheless equivalent to the usual norm on $R.$ Note that the function $x \mapsto |\sin (\pi x)|$ is subadditive.[^n10] Let $X_{\mathbb{C}}$ be a complex vector space and let $X_{\mathbb{R}}$ denote $X_{\mathbb{C}}$ considered as a vector space over $\mathbb{R}.$ Any paranorm on $X_{\mathbb{C}}$ is also a paranorm on $X_{\mathbb{R}}.$[^n9]

:::

## *F*-seminorms {#F-seminorms}

If $X$ is a vector space over the real or complex numbers then an ***F*-seminorm** on $X$ (the $F$ stands for [Fréchet](https://en.wikipedia.org/wiki/Maurice_René_Fréchet)) is a real-valued map $p : X \to \mathbb{R}$ with the following four properties: [^n11]

**Non-negative**: $p \geq 0.$ **Subadditive**: $p(x + y) \leq p(x) + p(y)$ for all $x, y \in X$ **[Balanced](https://en.wikipedia.org/wiki/Balanced_function)**: $p(a x) \leq p(x)$ for $x \in X$ all scalars $a$ satisfying $|a| \leq 1;$

This condition guarantees that each set of the form $\{z \in X : p(z) \leq r\}$ or $\{z \in X : p(z) < r\}$ for some $r \geq 0$ is a [balanced set](wikipedia://en/1734238). For every $x \in X,$ $p\left(\tfrac{1}{n} x\right) \to 0$ as $n \to \infty$

The sequence $\left(\tfrac{1}{n}\right)_{n=1}^\infty$ can be replaced by any positive sequence converging to the zero.[^n12]

An *F*-seminorm is called an ***F*-norm** if in addition it satisfies:

**Total**/**Positive definite**: $p(x) = 0$ implies $x = 0.$

An *F*-seminorm is called **monotone** if it satisfies:

**Monotone**: $p(r x) < p(s x)$ for all non-zero $x \in X$ and all real $s$ and $t$ such that $s < t.$[^n12]

### *F*-seminormed spaces {#F-seminormed_spaces}

An ***F*-seminormed space** (resp. ***F*-normed space**)[^n12] is a pair $(X, p)$ consisting of a vector space $X$ and an *F*-seminorm (resp. *F*-norm) $p$ on $X.$

If $(X, p)$ and $(Z, q)$ are *F*-seminormed spaces then a map $f : X \to Z$ is called an **isometric embedding**[^n12] if $q(f(x) - f(y)) = p(x, y) \text{ for all } x, y \in X.$

Every isometric embedding of one *F*-seminormed space into another is a [topological embedding](https://en.wikipedia.org/wiki/Topological_embedding), but the converse is not true in general.[^n12]

### Examples of *F*-seminorms {#Examples_of_F-seminorms}

Every positive scalar multiple of an *F*-seminorm (resp. *F*-norm, seminorm) is again an *F*-seminorm (resp. *F*-norm, seminorm). The sum of finitely many *F*-seminorms (resp. *F*-norms) is an *F*-seminorm (resp. *F*-norm). If $p$ and $q$ are *F*-seminorms on $X$ then so is their pointwise supremum $x \mapsto \sup \{p(x), q(x)\}.$ The same is true of the supremum of any non-empty finite family of *F*-seminorms on $X.$[^n12] The restriction of an *F*-seminorm (resp. *F*-norm) to a vector subspace is an *F*-seminorm (resp. *F*-norm).[^n9] A non-negative real-valued function on $X$ is a seminorm if and only if it is a [convex](wikipedia://en/245568) *F*-seminorm, or equivalently, if and only if it is a convex balanced *G*-seminorm.[^n10] In particular, every [seminorm](wikipedia://en/292067) is an *F*-seminorm. For any $0 < p < 1,$ the map $f$ on $\mathbb{R}^n$ defined by

$$[f\left(x_1, \ldots, x_n\right)]^p = \left|x_1\right|^p + \cdots \left|x_n\right|^p$$

is an *F*-norm that is not a norm. If $L : X \to Y$ is a linear map and if $q$ is an *F*-seminorm on $Y,$ then $q \circ L$ is an *F*-seminorm on $X.$[^n12] Let $X_\mathbb{C}$ be a complex vector space and let $X_\mathbb{R}$ denote $X_\mathbb{C}$ considered as a vector space over $\mathbb{R}.$ Any *F*-seminorm on $X_\mathbb{C}$ is also an *F*-seminorm on $X_\mathbb{R}.$[^n9]

### Properties of *F*-seminorms {#Properties_of_F-seminorms}

Every *F*-seminorm is a paranorm and every paranorm is equivalent to some *F*-seminorm.[^n7] Every *F*-seminorm on a vector space $X$ is a value on $X.$ In particular, $p(x) = 0,$ and $p(x) = p(-x)$ for all $x \in X.$

### Topology induced by a single *F*-seminorm {#Topology_induced_by_a_single_F-seminorm}

::: {#o64 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^n11].**

Let $p$ be an *F*-seminorm on a vector space $X.$ Then the map $d : X \times X \to \mathbb{R}$ defined by $d(x, y) := p(x - y)$ is a translation invariant pseudometric on $X$ that defines a vector topology $\tau$ on $X.$ If $p$ is an *F*-norm then $d$ is a metric. When $X$ is endowed with this topology then $p$ is a continuous map on $X.$

The balanced sets $\{x \in X ~:~ p(x) \leq r\},$ as $r$ ranges over the positive reals, form a neighborhood basis at the origin for this topology consisting of closed set. Similarly, the balanced sets $\{x \in X ~:~ p(x) < r\},$ as $r$ ranges over the positive reals, form a neighborhood basis at the origin for this topology consisting of open sets.

:::

### Topology induced by a family of *F*-seminorms {#Topology_induced_by_a_family_of_F-seminorms}

Suppose that $\mathcal{L}$ is a non-empty collection of *F*-seminorms on a vector space $X$ and for any finite subset $\mathcal{F} \subseteq \mathcal{L}$ and any $r > 0,$ let

$$U_{\mathcal{F}, r} := \bigcap_{p \in \mathcal{F}} \{x \in X : p(x) < r\}.$$

The set $\left\{U_{\mathcal{F}, r} ~:~ r > 0, \mathcal{F} \subseteq \mathcal{L}, \mathcal{F} \text{ finite }\right\}$ forms a filter base on $X$ that also forms a neighborhood basis at the origin for a vector topology on $X$ denoted by $\tau_{\mathcal{L}}.$[^n12] Each $U_{\mathcal{F}, r}$ is a [balanced](wikipedia://en/1734238) and [absorbing](wikipedia://en/1728179) subset of $X.$[^n12] These sets satisfy[^n12]

$$U_{\mathcal{F}, r/2} + U_{\mathcal{F}, r/2} \subseteq U_{\mathcal{F}, r}.$$

$\tau_{\mathcal{L}}$ is the coarsest vector topology on $X$ making each $p \in \mathcal{L}$ continuous.[^n12] $\tau_{\mathcal{L}}$ is Hausdorff [if and only if](wikipedia://en/14922) for every non-zero $x \in X,$ there exists some $p \in \mathcal{L}$ such that $p(x) > 0.$[^n12] If $\mathcal{F}$ is the set of all continuous *F*-seminorms on $\left(X, \tau_{\mathcal{L}}\right)$ then $\tau_{\mathcal{L}} = \tau_{\mathcal{F}}.$[^n12] If $\mathcal{F}$ is the set of all pointwise suprema of non-empty finite subsets of $\mathcal{F}$ of $\mathcal{L}$ then $\mathcal{F}$ is a directed family of *F*-seminorms and $\tau_{\mathcal{L}} = \tau_{\mathcal{F}}.$[^n12]

## Fréchet combination {#Fréchet_combination}

Suppose that $p_{\bullet} = \left(p_i\right)_{i=1}^{\infty}$ is a family of non-negative subadditive functions on a vector space $X.$

The **Fréchet combination**[^n8] of $p_{\bullet}$ is defined to be the real-valued map

$$p(x) := \sum_{i=1}^{\infty} \frac{p_i(x)}{2^{i} \left[ 1 + p_i(x)\right]}.$$

### As an *F*-seminorm {#As_an_F-seminorm}

Assume that $p_{\bullet} = \left(p_i\right)_{i=1}^{\infty}$ is an increasing sequence of seminorms on $X$ and let $p$ be the Fréchet combination of $p_{\bullet}.$ Then $p$ is an *F*-seminorm on $X$ that induces the same locally convex topology as the family $p_{\bullet}$ of seminorms.[^n13]

Since $p_{\bullet} = \left(p_i\right)_{i=1}^{\infty}$ is increasing, a basis of open neighborhoods of the origin consists of all sets of the form $\left\{ x \in X ~:~ p_i(x) < r\right\}$ as $i$ ranges over all positive integers and $r > 0$ ranges over all positive real numbers.

The [translation invariant](https://en.wikipedia.org/wiki/Translation_invariant) [pseudometric](wikipedia://en/68503) on $X$ induced by this *F*-seminorm $p$ is

$$d(x, y) = \sum^{\infty}_{i=1} \frac{1}{2^i} \frac{p_i( x - y )}{1 + p_i( x - y )}.$$

This metric was discovered by [Fréchet](https://en.wikipedia.org/wiki/Fréchet) in his 1906 thesis for the spaces of real and complex sequences with pointwise operations.[^n14]

### As a paranorm {#As_a_paranorm}

If each $p_i$ is a paranorm then so is $p$ and moreover, $p$ induces the same topology on $X$ as the family $p_{\bullet}$ of paranorms.[^n8] This is also true of the following paranorms on $X$:

$q(x) := \inf_{} \left\{ \sum_{i=1}^n p_i(x) + \frac{1}{n} ~:~ n > 0 \text{ is an integer }\right\}.$[^n8] $r(x) := \sum_{n=1}^{\infty} \min \left\{ \frac{1}{2^n}, p_n(x)\right\}.$[^n8]

::: {#o83 .statement kind=statement/generalization cue=heading name="Generalization"}

### Generalization {#Generalization}

The Fréchet combination can be generalized by use of a bounded remetrization function.

A bounded remetrization function[^n15] is a continuous non-negative non-decreasing map $R : [0, \infty) \to [0, \infty)$ that has a bounded range, is [subadditive](wikipedia://en/745789) (meaning that $R(s + t) \leq R(s) + R(t)$ for all $s, t \geq 0$), and satisfies $R(s) = 0$ if and only if $s = 0.$

Examples of bounded remetrization functions include $\arctan t,$ $\tanh t,$ $t \mapsto \min \{t, 1\},$ and $t \mapsto \frac{t}{1 + t}.$[^n15] If $d$ is a pseudometric (respectively, metric) on $X$ and $R$ is a bounded remetrization function then $R \circ d$ is a bounded pseudometric (respectively, bounded metric) on $X$ that is uniformly equivalent to $d.$[^n15]

Suppose that $p_\bullet = \left(p_i\right)_{i=1}^\infty$ is a family of non-negative *F*-seminorm on a vector space $X,$ $R$ is a bounded remetrization function, and $r_\bullet = \left(r_i\right)_{i=1}^\infty$ is a sequence of positive real numbers whose sum is finite. Then

$$p(x) := \sum_{i=1}^\infty r_i R\left(p_i(x)\right)$$

defines a bounded *F*-seminorm that is uniformly equivalent to the $p_\bullet.$[^n16] It has the property that for any net $x_\bullet = \left(x_a\right)_{a \in A}$ in $X,$ $p\left(x_\bullet\right) \to 0$ if and only if $p_i\left(x_\bullet\right) \to 0$ for all $i.$[^n16] $p$ is an *F*-norm if and only if the $p_\bullet$ separate points on $X.$[^n16]

:::

## Characterizations {#Characterizations}

### Of (pseudo)metrics induced by (semi)norms {#Of_(pseudo)metrics_induced_by_(semi)norms}

A pseudometric (resp. metric) $d$ is induced by a seminorm (resp. norm) on a vector space $X$ if and only if $d$ is translation invariant and **absolutely homogeneous**, which means that for all scalars $s$ and all $x, y \in X,$ in which case the function defined by $p(x) := d(x, 0)$ is a seminorm (resp. norm) and the pseudometric (resp. metric) induced by $p$ is equal to $d.$

### Of pseudometrizable TVS {#Of_pseudometrizable_TVS}

If $(X, \tau)$ is a [topological vector space](wikipedia://en/45752) (TVS) (where note in particular that $\tau$ is assumed to be a vector topology) then the following are equivalent:[^n11]

$X$ is pseudometrizable (i.e. the vector topology $\tau$ is induced by a pseudometric on $X$). $X$ has a countable neighborhood base at the origin. The topology on $X$ is induced by a translation-invariant pseudometric on $X.$ The topology on $X$ is induced by an *F*-seminorm. The topology on $X$ is induced by a paranorm.

### Of metrizable TVS {#Of_metrizable_TVS}

If $(X, \tau)$ is a TVS then the following are equivalent:

$X$ is metrizable. $X$ is [Hausdorff](wikipedia://en/13637) and pseudometrizable. $X$ is Hausdorff and has a countable neighborhood base at the origin.[^n11][^n12] The topology on $X$ is induced by a translation-invariant metric on $X.$[^n11] The topology on $X$ is induced by an *F*-norm.[^n11][^n12] The topology on $X$ is induced by a monotone *F*-norm.[^n12] The topology on $X$ is induced by a total paranorm.

::: {#o102 .statement kind=statement/theorem cue=math-theorem name="Birkhoff–Kakutani theorem"}

**[Birkhoff–Kakutani theorem](https://en.wikipedia.org/wiki/Birkhoff–Kakutani_theorem).**

If $(X, \tau)$ is a topological vector space then the following three conditions are equivalent:[^o103][^o104]

The origin $\{ 0 \}$ is closed in $X,$ and there is a [countable](https://en.wikipedia.org/wiki/Countable) [basis of neighborhoods](https://en.wikipedia.org/wiki/Neighborhood_basis) for $0$ in $X.$ $(X, \tau)$ is [metrizable](wikipedia://en/19738) (as a topological space). There is a [translation-invariant metric](https://en.wikipedia.org/wiki/Translation-invariant_metric) on $X$ that induces on $X$ the topology $\tau,$ which is the given topology on $X.$

By the Birkhoff–Kakutani theorem, it follows that there is an [equivalent metric](wikipedia://en/6811610) that is translation-invariant.

:::

### Of locally convex pseudometrizable TVS {#Of_locally_convex_pseudometrizable_TVS}

If $(X, \tau)$ is TVS then the following are equivalent:[^n13]

$X$ is [locally convex](https://en.wikipedia.org/wiki/Locally_convex) and pseudometrizable. $X$ has a countable neighborhood base at the origin consisting of convex sets. The topology of $X$ is induced by a countable family of (continuous) seminorms. The topology of $X$ is induced by a countable increasing sequence of (continuous) seminorms $\left(p_i\right)_{i=1}^{\infty}$ (increasing means that for all $i,$ $p_i \geq p_{i+1}.$ The topology of $X$ is induced by an *F*-seminorm of the form:

$$p(x) = \sum_{n=1}^{\infty} 2^{-n} \operatorname{arctan} p_n(x)$$

where $\left(p_i\right)_{i=1}^{\infty}$ are (continuous) seminorms on $X.$[^n17]

:::

## Quotients {#Quotients}

Let $M$ be a vector subspace of a topological vector space $(X, \tau).$

If $X$ is a pseudometrizable TVS then so is $X / M.$[^n11] If $X$ is a complete pseudometrizable TVS and $M$ is a closed vector subspace of $X$ then $X / M$ is complete.[^n11] If $X$ is metrizable TVS and $M$ is a closed vector subspace of $X$ then $X / M$ is metrizable.[^n11] If $p$ is an *F*-seminorm on $X,$ then the map $P : X / M \to \mathbb{R}$ defined by

$$P(x + M) := \inf_{} \{ p(x + m) : m \in M \}$$

is an *F*-seminorm on $X / M$ that induces the usual [quotient topology](https://en.wikipedia.org/wiki/Quotient_topology) on $X / M.$[^n11] If in addition $p$ is an *F*-norm on $X$ and if $M$ is a closed vector subspace of $X$ then $P$ is an *F*-norm on $X.$[^n11]

## Examples and sufficient conditions {#Examples_and_sufficient_conditions}

Every [seminormed space](https://en.wikipedia.org/wiki/Seminormed_space) $(X, p)$ is pseudometrizable with a canonical pseudometric given by $d(x, y) := p(x - y)$ for all $x, y \in X.$[^n18]. If $(X, d)$ is pseudometric *TVS* with a translation invariant pseudometric $d,$ then $p(x) := d(x, 0)$ defines a paranorm.[^n19] However, if $d$ is a translation invariant pseudometric on the vector space $X$ (without the addition condition that $(X, d)$ is pseudometric TVS), then $d$ need not be either an *F*-seminorm[^n20] nor a paranorm. If a TVS has a bounded neighborhood of the origin then it is pseudometrizable; the converse is in general false.[^n14] If a Hausdorff TVS has a bounded neighborhood of the origin then it is metrizable.[^n14] Suppose $X$ is either a [DF-space](wikipedia://en/63703274) or an [LM-space](https://en.wikipedia.org/wiki/LM-space). If $X$ is a [sequential space](wikipedia://en/4668395) then it is either metrizable or else a [Montel](wikipedia://en/1796319) DF-space.

If $X$ is Hausdorff locally convex TVS then $X$ with the [strong topology](wikipedia://en/63951372), $\left(X, b\left(X, X^{\prime}\right)\right),$ is metrizable if and only if there exists a countable set $\mathcal{B}$ of bounded subsets of $X$ such that every bounded subset of $X$ is contained in some element of $\mathcal{B}.$[^n21]

The [strong dual space](wikipedia://en/63951372) $X_b^{\prime}$ of a metrizable locally convex space (such as a [Fréchet space](wikipedia://en/233801)[^o121]) $X$ is a [DF-space](wikipedia://en/63703274).[^n22] The strong dual of a DF-space is a [Fréchet space](wikipedia://en/233801).[^n23] The strong dual of a [reflexive](wikipedia://en/210091) Fréchet space is a [bornological space](wikipedia://en/1804457).[^n22] The strong bidual (that is, the [strong dual space](wikipedia://en/63951372) of the strong dual space) of a metrizable locally convex space is a Fréchet space.[^n24] If $X$ is a metrizable locally convex space then its strong dual $X_b^{\prime}$ has one of the following properties, if and only if it has all of these properties: (1) [bornological](wikipedia://en/1804457), (2) [infrabarreled](wikipedia://en/63950387), (3) [barreled](wikipedia://en/1733592).[^n24]

### Normability {#Normability}

A topological vector space is [seminormable](https://en.wikipedia.org/wiki/Seminormed_space) if and only if it has a [convex](wikipedia://en/6292) bounded neighborhood of the origin. Moreover, a TVS is [normable](https://en.wikipedia.org/wiki/Normable_space) if and only if it is [Hausdorff](wikipedia://en/13637) and seminormable.[^n14] Every metrizable TVS on a finite-[dimensional](https://en.wikipedia.org/wiki/Hamel_basis) vector space is a normable [locally convex](https://en.wikipedia.org/wiki/Locally_convex) [complete TVS](wikipedia://en/53695856), being [TVS-isomorphic](https://en.wikipedia.org/wiki/TVS_isomorphism) to [Euclidean space](wikipedia://en/9697). Consequently, any metrizable TVS that is not normable must be infinite dimensional.

If $M$ is a metrizable [locally convex TVS](wikipedia://en/518844) that possess a [countable](wikipedia://en/6026) fundamental system of bounded sets, then $M$ is normable.[^n25]

If $X$ is a Hausdorff [locally convex space](wikipedia://en/518844) then the following are equivalent:

$X$ is [normable](https://en.wikipedia.org/wiki/Normable_space). $X$ has a [(von Neumann) bounded](wikipedia://en/1789812) neighborhood of the origin. the [strong dual space](wikipedia://en/63951372) $X^{\prime}_b$ of $X$ is normable.[^n26]

and if this locally convex space $X$ is also metrizable, then the following may be appended to this list:

the strong dual space of $X$ is metrizable.[^n26] the strong dual space of $X$ is a [Fréchet–Urysohn](wikipedia://en/28480560) locally convex space.[^o121]

In particular, if a metrizable locally convex space $X$ (such as a [Fréchet space](wikipedia://en/233801)) is not normable then its [strong dual space](wikipedia://en/63951372) $X^{\prime}_b$ is not a [Fréchet–Urysohn space](wikipedia://en/28480560) and consequently, this [complete](wikipedia://en/53695856) Hausdorff locally convex space $X^{\prime}_b$ is also neither metrizable nor normable.

Another consequence of this is that if $X$ is a [reflexive](wikipedia://en/210091) [locally convex](https://en.wikipedia.org/wiki/Locally_convex) TVS whose strong dual $X^{\prime}_b$ is metrizable then $X^{\prime}_b$ is necessarily a reflexive Fréchet space, $X$ is a [DF-space](wikipedia://en/63703274), both $X$ and $X^{\prime}_b$ are necessarily [complete](wikipedia://en/53695856) Hausdorff [ultrabornological](wikipedia://en/63904912) [distinguished](wikipedia://en/64266856) [webbed spaces](wikipedia://en/41717785), and moreover, $X^{\prime}_b$ is normable if and only if $X$ is normable if and only if $X$ is Fréchet–Urysohn if and only if $X$ is metrizable. In particular, such a space $X$ is either a [Banach space](wikipedia://en/3989) or else it is not even a Fréchet–Urysohn space.

## Metrically bounded sets and bounded sets {#Metrically_bounded_sets_and_bounded_sets}

Suppose that $(X, d)$ is a pseudometric space and $B \subseteq X.$ The set $B$ is **metrically bounded** or **$d$-bounded** if there exists a real number $R > 0$ such that $d(x, y) \leq R$ for all $x, y \in B$; the smallest such $R$ is then called the **diameter** or **$d$-diameter** of $B.$[^n14] If $B$ is [bounded](https://en.wikipedia.org/wiki/Bounded_set_%28functional_analysis%29) in a pseudometrizable TVS $X$ then it is metrically bounded; the converse is in general false but it is true for [locally convex](https://en.wikipedia.org/wiki/Locally_convex) metrizable TVSs.[^n14]

## Properties of pseudometrizable TVS {#Properties_of_pseudometrizable_TVS}

::: {#o137 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem[^n27].**

All infinite-dimensional [separable](wikipedia://en/27855) complete metrizable TVS are [homeomorphic](https://en.wikipedia.org/wiki/Homeomorphic).

:::

Every metrizable [locally convex](https://en.wikipedia.org/wiki/Locally_convex) TVS is a [quasibarrelled space](https://en.wikipedia.org/wiki/Quasibarrelled_space),[^n28] [bornological space](wikipedia://en/1804457), and a [Mackey space](wikipedia://en/1804899). Every complete pseudometrizable TVS is a [barrelled space](wikipedia://en/1733592) and a [Baire space](wikipedia://en/200550) (and hence non-meager).[^n29] However, there exist metrizable Baire spaces that are not [complete](wikipedia://en/53695856).[^n29] If $X$ is a metrizable locally convex space, then the strong dual of $X$ is [bornological](wikipedia://en/1804457) if and only if it is [barreled](https://en.wikipedia.org/wiki/Barreled_space), if and only if it is [infrabarreled](https://en.wikipedia.org/wiki/Infrabarreled_space).[^n24] If $X$ is a complete pseudometrizable TVS and $M$ is a closed vector subspace of $X,$ then $X / M$ is complete.[^n11] The [strong dual](wikipedia://en/63951372) of a locally convex metrizable TVS is a [webbed space](wikipedia://en/41717785).[^n30] If $(X, \tau)$ and $(X, \nu)$ are complete metrizable TVSs (i.e. [F-spaces](wikipedia://en/200440)) and if $\nu$ is coarser than $\tau$ then $\tau = \nu$;[^n31] this is no longer guaranteed to be true if any one of these metrizable TVSs is not complete.[^n32] Said differently, if $(X, \tau)$ and $(X, \nu)$ are both [F-spaces](wikipedia://en/200440) but with different topologies, then neither one of $\tau$ and $\nu$ contains the other as a subset. One particular consequence of this is, for example, that if $(X, p)$ is a [Banach space](wikipedia://en/3989) and $(X, q)$ is some other normed space whose norm-induced topology is finer than (or alternatively, is coarser than) that of $(X, p)$ (i.e. if $p \leq C q$ or if $q \leq C p$ for some constant $C > 0$), then the only way that $(X, q)$ can be a Banach space (i.e. also be complete) is if these two norms $p$ and $q$ are [equivalent](https://en.wikipedia.org/wiki/Equivalent_norms); if they are not equivalent, then $(X, q)$ can not be a Banach space. As another consequence, if $(X, p)$ is a Banach space and $(X, \nu)$ is a [Fréchet space](wikipedia://en/233801), then the map $p : (X, \nu) \to \mathbb{R}$ is continuous if and only if the Fréchet space $(X, \nu)$ is the TVS $(X, p)$ (here, the Banach space $(X, p)$ is being considered as a TVS, which means that its norm is "[forgetten](wikipedia://en/844783)" but its topology is remembered).

A metrizable [locally convex](https://en.wikipedia.org/wiki/Locally_convex) space is [normable](https://en.wikipedia.org/wiki/Normable_space) if and only if its [strong dual space](wikipedia://en/63951372) is a [Fréchet–Urysohn](wikipedia://en/28480560) locally convex space.[^o121] Any product of complete metrizable TVSs is a [Baire space](wikipedia://en/200550).[^n29] A product of metrizable TVSs is metrizable if and only if it all but at most countably many of these TVSs have dimension $0.$[^n33] A product of pseudometrizable TVSs is pseudometrizable if and only if it all but at most countably many of these TVSs have the trivial topology. Every complete pseudometrizable TVS is a [barrelled space](wikipedia://en/1733592) and a [Baire space](wikipedia://en/200550) (and thus non-meager).[^n29] The dimension of a complete metrizable TVS is either finite or uncountable.[^n33]

### Completeness {#Completeness}

Every [topological vector space](wikipedia://en/45752) (and more generally, a [topological group](wikipedia://en/42315)) has a canonical [uniform structure](https://en.wikipedia.org/wiki/Uniform_structure), induced by its topology, which allows the notions of completeness and [uniform continuity](wikipedia://en/32337) to be applied to it. If $X$ is a metrizable TVS and $d$ is a metric that defines $X$'s topology, then its possible that $X$ is complete as a TVS (i.e. relative to its uniformity) but the metric $d$ is not a [complete metric](https://en.wikipedia.org/wiki/Complete_metric) (such metrics exist even for $X = \mathbb{R}$). Thus, if $X$ is a TVS whose topology is induced by a pseudometric $d,$ then the notion of completeness of $X$ (as a TVS) and the notion of completeness of the pseudometric space $(X, d)$ are not always equivalent. The next theorem gives a condition for when they are equivalent:

::: {#o151 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

If $X$ is a pseudometrizable TVS whose topology is induced by a translation invariant pseudometric $d,$ then $d$ is a complete pseudometric on $X$ if and only if $X$ is complete as a TVS.[^n34]

:::

::: {#o155 .statement kind=statement/theorem cue=math-theorem name="Theorem (Klee)"}

**Theorem[^n35][^o154] (Klee).**

Let $d$ be any[^o156] metric on a vector space $X$ such that the topology $\tau$ induced by $d$ on $X$ makes $(X, \tau)$ into a topological vector space. If $(X, d)$ is a complete metric space then $(X, \tau)$ is a complete-TVS.

:::

::: {#o157 .statement kind=statement/theorem cue=math-theorem name="Theorem"}

**Theorem.**

If $X$ is a TVS whose topology is induced by a paranorm $p,$ then $X$ is complete if and only if for every sequence $\left(x_i\right)_{i=1}^{\infty}$ in $X,$ if $\sum_{i=1}^{\infty} p\left(x_i\right) < \infty$ then $\sum_{i=1}^{\infty} x_i$ converges in $X.$[^n36]

:::

If $M$ is a closed vector subspace of a complete pseudometrizable TVS $X,$ then the quotient space $X / M$ is complete.[^n37] If $M$ is a complete vector subspace of a metrizable TVS $X$ and if the quotient space $X / M$ is complete then so is $X.$[^n37] If $X$ is not complete then $M := X,$ but not complete, vector subspace of $X.$

A [Baire](wikipedia://en/200550) [separable](wikipedia://en/27855) [topological group](wikipedia://en/42315) is metrizable if and only if it is cosmic.[^o161]

### Subsets and subsequences {#Subsets_and_subsequences}

Let $M$ be a [separable](wikipedia://en/27855) locally convex metrizable topological vector space and let $C$ be its completion. If $S$ is a bounded subset of $C$ then there exists a bounded subset $R$ of $X$ such that $S \subseteq \operatorname{cl}_C R.$[^n38] Every [totally bounded](https://en.wikipedia.org/wiki/Totally_bounded_set) subset of a locally convex metrizable TVS $X$ is contained in the closed [convex balanced hull](wikipedia://en/1734292) of some sequence in $X$ that converges to $0.$ In a pseudometrizable TVS, every [bornivore](https://en.wikipedia.org/wiki/Bornivore) is a neighborhood of the origin.[^n39] If $d$ is a translation invariant metric on a vector space $X,$ then $d(n x, 0) \leq n d(x, 0)$ for all $x \in X$ and every positive integer $n.$[^n40] If $\left(x_i\right)_{i=1}^{\infty}$ is a null sequence (that is, it converges to the origin) in a metrizable TVS then there exists a sequence $\left(r_i\right)_{i=1}^{\infty}$ of positive real numbers diverging to $\infty$ such that $\left(r_i x_i\right)_{i=1}^{\infty} \to 0.$[^n40] A subset of a complete metric space is closed if and only if it is complete. If a space $X$ is not complete, then $X$ is a closed subset of $X$ that is not complete. If $X$ is a metrizable [locally convex](wikipedia://en/518844) TVS then for every [bounded](wikipedia://en/1789812) subset $B$ of $X,$ there exists a bounded [disk](wikipedia://en/1734292) $D$ in $X$ such that $B \subseteq X_D,$ and both $X$ and the [auxiliary normed space](wikipedia://en/63622954) $X_D$ induce the same [subspace topology](wikipedia://en/910926) on $B.$[^n41]

::: {#o169 .statement kind=statement/theorem cue=math-theorem name="Banach-Saks theorem"}

**[Banach-Saks theorem](https://en.wikipedia.org/wiki/Banach-Saks_theorem)[^n42].**

If $\left(x_n\right)_{n=1}^{\infty}$ is a sequence in a [locally convex](https://en.wikipedia.org/wiki/Locally_convex) metrizable TVS $(X, \tau)$ that converges weakly to some $x \in X,$ then there exists a sequence $y_{\bullet} = \left(y_i\right)_{i=1}^{\infty}$ in $X$ such that $y_{\bullet} \to x$ in $(X, \tau)$ and each $y_i$ is a convex combination of finitely many $x_n.$

:::

::: {#o171 .statement kind=statement/theorem cue=math-theorem name="Mackey's countability condition"}

**Mackey's countability condition[^n14].**

Suppose that $X$ is a locally convex metrizable TVS and that $\left(B_i\right)_{i=1}^{\infty}$ is a countable sequence of bounded subsets of $X.$ Then there exists a bounded subset $B$ of $X$ and a sequence $\left(r_i\right)_{i=1}^{\infty}$ of positive real numbers such that $B_i \subseteq r_i B$ for all $i.$

:::

**Generalized series**

As described [in this article's section on generalized series](wikipedia://en/15287#Summations_over_arbitrary_index_sets), for any $I$-[indexed family](https://en.wikipedia.org/wiki/Indexing_set) family $\left(r_i\right)_{i \in I}$ of vectors from a TVS $X,$ it is possible to define their sum $\textstyle\sum\limits_{i \in I} r_i$ as the limit of the [net](wikipedia://en/22170) of finite partial sums $F \in \operatorname{FiniteSubsets}(I) \mapsto \textstyle\sum\limits_{i \in F} r_i$ where the domain $\operatorname{FiniteSubsets}(I)$ is [directed](wikipedia://en/9165) by $\,\subseteq.\,$ If $I = \mathbb{N}$ and $X = \mathbb{R},$ for instance, then the generalized series $\textstyle\sum\limits_{i \in \mathbb{N}} r_i$ converges if and only if $\textstyle\sum\limits_{i=1}^\infty r_i$ [converges unconditionally](wikipedia://en/2620508) in the usual sense (which for real numbers, [is equivalent](wikipedia://en/1895800) to [absolute convergence](wikipedia://en/61532)). If a generalized series $\textstyle\sum\limits_{i \in I} r_i$ converges in a metrizable TVS, then the set $\left\{i \in I : r_i \neq 0\right\}$ is necessarily [countable](wikipedia://en/6026) (that is, either finite or [countably infinite](https://en.wikipedia.org/wiki/Countably_infinite));[^o191] in other words, all but at most countably many $r_i$ will be zero and so this generalized series $\textstyle\sum\limits_{i \in I} r_i ~=~ \textstyle\sum\limits_{\stackrel{i \in I}{r_i \neq 0}} r_i$ is actually a sum of at most countably many non-zero terms.

### Linear maps {#Linear_maps}

If $X$ is a pseudometrizable TVS and $A$ maps bounded subsets of $X$ to bounded subsets of $Y,$ then $A$ is continuous.[^n14] Discontinuous linear functionals exist on any infinite-dimensional pseudometrizable TVS.[^n43] Thus, a pseudometrizable TVS is finite-dimensional if and only if its continuous dual space is equal to its [algebraic dual space](https://en.wikipedia.org/wiki/Algebraic_dual_space).[^n43]

If $F : X \to Y$ is a linear map between TVSs and $X$ is metrizable then the following are equivalent:

$F$ is continuous; $F$ is a (locally) bounded map (that is, $F$ maps [(von Neumann) bounded subsets](wikipedia://en/1789812) of $X$ to bounded subsets of $Y$);[^n12] $F$ is [sequentially continuous](https://en.wikipedia.org/wiki/Sequentially_continuous);[^n12] the image under $F$ of every null sequence in $X$ is a bounded set[^n12] where by definition, a **null sequence** is a sequence that converges to the origin. $F$ maps null sequences to null sequences;

**Open and almost open maps**

**Theorem**: If $X$ is a complete pseudometrizable TVS, $Y$ is a Hausdorff TVS, and $T : X \to Y$ is a closed and [almost](https://en.wikipedia.org/wiki/Almost_open_linear_map) open linear surjection, then $T$ is an open map.[^n44]

**Theorem**: If $T : X \to Y$ is a surjective linear operator from a [locally convex](https://en.wikipedia.org/wiki/Locally_convex) space $X$ onto a [barrelled space](wikipedia://en/1733592) $Y$ (e.g. every complete pseudometrizable space is barrelled) then $T$ is [almost open](https://en.wikipedia.org/wiki/Almost_open_linear_map).[^n44]

**Theorem**: If $T : X \to Y$ is a surjective linear operator from a TVS $X$ onto a [Baire space](wikipedia://en/200550) $Y$ then $T$ is almost open.[^n44]

**Theorem**: Suppose $T : X \to Y$ is a continuous linear operator from a complete pseudometrizable TVS $X$ into a Hausdorff TVS $Y.$ If the image of $T$ is non-[meager](https://en.wikipedia.org/wiki/Meager_set) in $Y$ then $T : X \to Y$ is a surjective open map and $Y$ is a [complete](wikipedia://en/53695856) metrizable space.[^n44]

### Hahn-Banach extension property {#Hahn-Banach_extension_property}

A vector subspace $M$ of a TVS $X$ has **the extension property** if any continuous linear functional on $M$ can be extended to a continuous linear functional on $X.$[^n21] Say that a TVS $X$ has the **[Hahn-Banach](https://en.wikipedia.org/wiki/Hahn-Banach_theorem) extension property** (**HBEP**) if every vector subspace of $X$ has the extension property.[^n21]

The [Hahn-Banach theorem](https://en.wikipedia.org/wiki/Hahn-Banach_theorem) guarantees that every Hausdorff locally convex space has the HBEP. For complete metrizable TVSs there is a converse:

::: {#o186 .statement kind=statement/theorem cue=math-theorem name="Theorem (Kalton)"}

**Theorem (Kalton).**

Every complete metrizable TVS with the Hahn-Banach extension property is locally convex.[^n21]

:::

If a vector space $X$ has uncountable dimension and if we endow it with the [finest vector topology](https://en.wikipedia.org/wiki/Finest_vector_topology) then this is a TVS with the HBEP that is neither locally convex or metrizable.[^n21]
