# Weak convergence (Hilbert space)

::: {#o1 .subject cue=lead name="Weak convergence"}

In [mathematics](wikipedia://en/18831), **weak convergence** in a [Hilbert space](wikipedia://en/20598932) is [the convergence](wikipedia://en/285773) of a [sequence](wikipedia://en/27838) of points in the [weak topology](wikipedia://en/33662).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A [sequence](https://en.wikipedia.org/wiki/Sequence_%28mathematics%29) of points $(x_n)$ in a Hilbert space $H$ is said to **converge weakly** to a point $x$ in $H$ if

$$\lim_{n\to\infty}\langle x_n,y \rangle = \langle x,y \rangle$$

for all $y$ in $H$. Here, $\langle \cdot, \cdot \rangle$ is understood to be the [inner product](https://en.wikipedia.org/wiki/Inner_product) on the Hilbert space. The notation

$$x_n \rightharpoonup x$$

is sometimes used to denote this kind of convergence.[^o4]

:::

::: {#o6 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If a sequence converges strongly (that is, if it converges in norm), then it converges weakly as well.
- Since every closed and bounded set is weakly [relatively compact](wikipedia://en/596600) (its closure in the weak topology is compact), every [bounded sequence](https://en.wikipedia.org/wiki/Bounded_sequence) $x_n$ in a Hilbert space *H* contains a weakly convergent subsequence. Note that closed and bounded sets are not in general weakly compact in Hilbert spaces (consider the set consisting of an [orthonormal basis](wikipedia://en/195063) in an infinite-dimensional Hilbert space which is closed and bounded but not weakly compact since it doesn't contain 0). However, bounded and weakly closed sets are weakly compact so as a consequence every convex bounded closed set is weakly compact.
- As a consequence of the [principle of uniform boundedness](https://en.wikipedia.org/wiki/Banach-Steinhaus_Theorem), every weakly convergent sequence is bounded.
- The norm is (sequentially) weakly [lower-semicontinuous](https://en.wikipedia.org/wiki/Lower_semicontinuous): if $x_n$ converges weakly to *x*, then

$$\Vert x\Vert \le \liminf_{n\to\infty} \Vert x_n \Vert,$$

and this inequality is strict whenever the convergence is not strong. For example, infinite orthonormal sequences converge weakly to zero, as demonstrated below.

- If $x_n \to x$ weakly and $\lVert x_n \rVert \to \lVert x \rVert$, then $x_n \to x$ strongly:

$$\langle x - x_n, x - x_n \rangle = \langle x, x \rangle + \langle x_n, x_n \rangle - \langle x_n, x \rangle - \langle x, x_n \rangle \rightarrow 0.$$

- If the Hilbert space is finite-dimensional, i.e. a [Euclidean space](wikipedia://en/9697), then weak and strong convergence are equivalent.

::: {#o8 .example cue=heading name="Example"}

### Example {#Example}

*Image: Sinfrequency.jpg.* The first three functions in the sequence $f_n(x) = \sin(n x)$ on $[0, 2 \pi]$. As $n \rightarrow \infty$ $f_n$ converges weakly to $f =0$.

The Hilbert space $L^2[0, 2\pi]$ is the space of the [square-integrable functions](wikipedia://en/28680558) on the interval $[0, 2\pi]$ equipped with the inner product defined by

$$\langle f,g \rangle = \int_0^{2\pi} f(x)\cdot g(x)\,dx,$$

(see [L<sup>*p*</sup> space](wikipedia://en/45194)). The sequence of functions $f_1, f_2, \ldots$ defined by

$$f_n(x) = \sin(n x)$$

converges weakly to the zero function in $L^2[0, 2\pi]$, as the integral

$$\int_0^{2\pi} \sin(n x)\cdot g(x)\,dx.$$

tends to zero for any square-integrable function $g$ on $[0, 2\pi]$ when $n$ goes to infinity, which is by [Riemann–Lebesgue lemma](wikipedia://en/1461209), i.e.

$$\langle f_n,g \rangle \to \langle 0,g \rangle = 0.$$

Although $f_n$ has an increasing number of 0's in $[0,2 \pi]$ as $n$ goes to infinity, it is of course not equal to the zero function for any $n$. Note that $f_n$ does not converge to 0 in the $L_\infty$ or $L_2$ norms. This dissimilarity is one of the reasons why this type of convergence is considered to be "weak."

:::

### Weak convergence of orthonormal sequences {#Weak_convergence_of_orthonormal_sequences}

Consider a sequence $e_n$ which was constructed to be orthonormal, that is,

$$\langle e_n, e_m \rangle = \delta_{mn}$$

where $\delta_{mn}$ equals one if *m* = *n* and zero otherwise. We claim that if the sequence is infinite, then it converges weakly to zero. A simple proof is as follows. For *x* ∈ *H*, we have

$\sum_n | \langle e_n, x \rangle |^2 \leq \| x \|^2$ ([Bessel's inequality](wikipedia://en/1446277))

where equality holds when {*e*<sub>*n*</sub>} is a Hilbert space basis. Therefore

$| \langle e_n, x \rangle |^2 \rightarrow 0$ (since the series above converges, its corresponding sequence must go to zero)

i.e.

$$\langle e_n, x \rangle \rightarrow 0 .$$

:::

::: {#o11 .statement kind=statement/theorem cue=named-heading name="Banach–Saks theorem"}

## Banach–Saks theorem {#Banach–Saks_theorem}

The **Banach–Saks theorem** states that every bounded sequence $x_n$ contains a subsequence $x_{n_k}$ and a point *x* such that

$$\frac{1}{N}\sum_{k=1}^N x_{n_k}$$

converges strongly to *x* as *N* goes to infinity.

:::

::: {#o13 .statement kind=statement/generalization cue=heading name="Generalizations"}

## Generalizations {#Generalizations}

The definition of weak convergence can be extended to [Banach spaces](wikipedia://en/3989). A sequence of points $(x_n)$ in a Banach space *B* is said to **converge weakly** to a point *x* in *B* if

$$f(x_n) \to f(x)$$

for any bounded linear [functional](wikipedia://en/1374948) $f$ defined on $B$, that is, for any $f$ in the [dual space](wikipedia://en/7988) $B'$. If $B$ is an [Lp space](wikipedia://en/45194) on $\Omega$ and $p<+\infty$, then any such $f$ has the form

$$f(x) = \int_{\Omega} x\,y\,d\mu$$

for some $y\in\,L^q(\Omega)$, where $\mu$ is the [measure](wikipedia://en/19873) on $\Omega$ and $\frac{1}{p}+\frac{1}{q}=1$ are [conjugate indices](https://en.wikipedia.org/wiki/Conjugate_indices).

In the case where $B$ is a Hilbert space, then, by the [Riesz representation theorem](wikipedia://en/26452),

$$f(\cdot) = \langle \cdot,y \rangle$$

for some $y$ in $B$, so one obtains the Hilbert space definition of weak convergence.

:::
