# Campbell's theorem (geometry)

::: {#o1 .subject cue=lead name="Campbell's theorem"}

**Campbell's theorem**, named after [John Edward Campbell](wikipedia://en/8963216), also known as **Campbell’s embedding theorem** and the **Campbell-Magaard theorem**, is a [mathematical theorem](https://en.wikipedia.org/wiki/Mathematical_theorem) guaranteeing that any n-dimensional [Riemannian manifold](wikipedia://en/144652) can be locally embedded in an (*n* + 1)-dimensional Ricci-flat Riemannian manifold.[^o2]

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

Campbell's theorem states that any [*n*-dimensional](https://en.wikipedia.org/wiki/N-dimensional) [Riemannian manifold](wikipedia://en/144652) can be [embedded](wikipedia://en/52119) locally in an (*n* + 1)-manifold with a [Ricci curvature](wikipedia://en/276582) of *R*<sub>**ab**</sub> = 0. The theorem also states, in similar form, that an *n*-dimensional [pseudo-Riemannian manifold](wikipedia://en/287555) can be both locally and isometrically embedded in an *n*(*n* + 1)/2-[pseudo-Euclidean space](wikipedia://en/10962546).

:::

::: {#o6 .application cue=heading name="Applications"}

## Applications {#Applications}

Campbell’s theorem can be used to produce the embedding of numerous [4-dimensional spacetimes](https://en.wikipedia.org/wiki/Spacetime_symmetries) in [5-dimensional](wikipedia://en/2851410) [Ricci-flat spaces](wikipedia://en/644797). It is also used to embed a class of [*n*-dimensional Einstein spaces](https://en.wikipedia.org/wiki/N-dimensional_space).[^o7]

:::
