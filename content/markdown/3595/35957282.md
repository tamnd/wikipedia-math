# Mori domain

::: {#o1 .subject cue=lead name="Mori domain"}

In algebra, a **Mori domain**, named after [Yoshiro Mori](wikipedia://en/35983170) by (txt), is an [integral domain](wikipedia://en/15462) satisfying the [ascending chain condition](wikipedia://en/3189) on integral [divisorial ideals](https://en.wikipedia.org/wiki/Divisorial_ideal). [Noetherian domains](https://en.wikipedia.org/wiki/Noetherian_domain) and [Krull domains](https://en.wikipedia.org/wiki/Krull_domain) both have this property. A commutative ring is a Krull domain if and only if it is a Mori domain and [completely integrally closed](https://en.wikipedia.org/wiki/Completely_integrally_closed).[^o3] A polynomial ring over a Mori domain need not be a Mori domain. Also, the [complete integral closure](https://en.wikipedia.org/wiki/Complete_integral_closure) of a Mori domain need not be a Mori (or, equivalently, Krull) domain.

:::
