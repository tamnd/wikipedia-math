# Tarski–Grothendieck set theory

::: {#o1 .subject cue=lead name="Tarski–Grothendieck set theory"}

**Tarski–Grothendieck set theory** (**TG**, named after mathematicians [Alfred Tarski](wikipedia://en/59920) and [Alexander Grothendieck](wikipedia://en/2042)) is an [axiomatic set theory](https://en.wikipedia.org/wiki/Axiomatic_set_theory). It is a [non-conservative extension](https://en.wikipedia.org/wiki/Non-conservative_extension) of [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZFC) and is distinguished from other axiomatic set theories by the inclusion of **Tarski's axiom**, which states that for each set there is a "Tarski universe" it belongs to (see below). Tarski's axiom implies the existence of [inaccessible cardinals](wikipedia://en/248076), providing a richer [ontology](https://en.wikipedia.org/wiki/Ontology) than ZFC. For example, adding this axiom supports [category theory](wikipedia://en/5869).

:::

The [Mizar system](wikipedia://en/209074) and [Metamath](wikipedia://en/6023946) use Tarski–Grothendieck set theory for [formal verification of proofs](https://en.wikipedia.org/wiki/Proof_verification).

::: {#o3 .statement kind=statement/axiom cue=named-heading name="Axioms"}

## Axioms {#Axioms}

Tarski–Grothendieck set theory starts with conventional [Zermelo–Fraenkel set theory](wikipedia://en/152214) and then adds “Tarski's axiom”. We will use the [axioms](wikipedia://en/928), [definitions](wikipedia://en/7964), and notation of Mizar to describe it. Mizar's basic objects and processes are fully [formal](wikipedia://en/396102); they are described informally below. First, let us assume that:

- Given any set $A$, the singleton $\{A\}$ exists.
- Given any two sets, their unordered and ordered pairs exist.
- Given any set of sets, its union exists.

**TG** includes the following axioms, which are conventional because they are also part of [ZFC](https://en.wikipedia.org/wiki/ZFC):

- Set axiom: Quantified variables range over sets alone; everything is a set (the same [ontology](https://en.wikipedia.org/wiki/Ontology) as [ZFC](https://en.wikipedia.org/wiki/ZFC)).
- [Axiom of extensionality](wikipedia://en/52376): Two sets are identical if they have the same members.
- [Axiom of regularity](wikipedia://en/2113): No set is a member of itself, and circular chains of membership are impossible.
- [Axiom schema of replacement](wikipedia://en/52387): Let the [domain](wikipedia://en/50263) of the [class function](wikipedia://en/20696#Classes_in_formal_set_theories) $F$ be the set $A$. Then the [range](wikipedia://en/275991) of $F$ (the values of $F(x)$ for all members $x$ of $A$) is also a set.

It is Tarski's axiom that distinguishes **TG** from other axiomatic set theories. Tarski's axiom also implies the axioms of [infinity](wikipedia://en/246449), [choice](wikipedia://en/840),[^o4][^o5][^o6] and [power set](wikipedia://en/52552).[^o7][^o8] It also implies the existence of [inaccessible cardinals](wikipedia://en/248076), thanks to which the [ontology](https://en.wikipedia.org/wiki/Ontology) of **TG** is much richer than that of conventional set theories such as [ZFC](https://en.wikipedia.org/wiki/ZFC).

- **Tarski's axiom** (adapted from Tarski 1939[^o9]). For every set $s$, there exists a set $u$ (a "universe") such that

<!-- -->

1. $s \in u$: it contains $s$
1. $(\forall x \in u) (\forall y \subseteq x) (y \in u)$: it contains every [subset](wikipedia://en/27631) of every member
1. $(\forall x \in u) (\mathcal{P}(x) \in u)$: it contains the [powerset](https://en.wikipedia.org/wiki/Powerset) of every member
1. $(\forall x \subseteq u) (|x| < |u| \to x \in u)$: it contains every subset of itself that has smaller [cardinality](wikipedia://en/6174)

More formally:

$$\forall s \exists u [s \in u \land (\forall x \in u) (\mathcal{P}(x) \subseteq u \land \mathcal{P}(x) \in u) \land (\forall x \subseteq u) (|x| < |u| \to x \in u)]$$

where $|\cdot|$ denotes the [cardinality](wikipedia://en/6174) of a set. In short, Tarski's axiom states that every set belongs to a Tarski universe. If a Tarski universe is [transitive](wikipedia://en/2462396), it is also a [Grothendieck universe](wikipedia://en/1072144).[^o10] Conversely, assuming the [axiom of choice](wikipedia://en/840), every Grothendieck universe is a Tarski universe (i.e. satisfies Tarski's axiom).[^o11]

The set $u$ looks much like a “universal set” for $s$—it not only has as members the powerset of $s$, and all subsets of $s$, it also has the powerset of that powerset and so on—its members are closed under the operations of taking powerset or taking a subset. It's like a “universal set” except that of course it is not a member of itself and is not a set of all sets. That's the guaranteed universe $s$ belongs to. And then any such $u$ is itself a member of an even larger “almost universal set” and so on. Tarski's axiom is an axiom that guarantees vastly more sets than ZFC does.

:::

## Implementation in the Mizar system {#Implementation_in_the_Mizar_system}

The Mizar language, underlying the Mizar system's implementation of **TG** and providing its logical syntax, is typed and the types are assumed to be non-empty. Hence, the theory is implicitly taken to be [non-empty](wikipedia://en/52534). The existence axioms, e.g. the existence of the unordered pair, is also implemented indirectly by the definition of term constructors.

The system includes equality, the membership predicate and the following standard definitions:

- [Singleton](wikipedia://en/381798): A set with one member;
- [Unordered pair](wikipedia://en/1112432): A set with two distinct members. $\{a,b\} = \{b,a\}$;
- [Ordered pair](wikipedia://en/22362): The set $\{\{a,b\},\{a\}\} = (a,b) \neq (b,a)$;
- [Subset](wikipedia://en/27631): A set all of whose members are members of another given set;
- The [union](wikipedia://en/47949) of a set of sets $Y$: The set of all members of any member of $Y$.

## Implementation in Metamath {#Implementation_in_Metamath}

The Metamath system supports arbitrary [higher-order logics](wikipedia://en/562883), but it is typically used with the "set.mm" definitions of axioms. The [ax-groth axiom](http://us.metamath.org/mpeuni/ax-groth.html) adds Tarski's axiom, which in Metamath is defined as follows:

$$\vdash \exists y (x \in y \land \forall z \in y (\forall w (w \subseteq z \rightarrow w \in y) \land \exists w \in y \forall v (v \subseteq z \rightarrow v \in w)) \land \forall z (z \subseteq y \rightarrow (z \approx y \lor z \in y)))$$
