# Ordinal notation

::: {#o1 .subject cue=lead name="Ordinal notation"}

In [mathematical logic](wikipedia://en/19636) and [set theory](wikipedia://en/27553), an **ordinal notation** is a [partial function](wikipedia://en/23577) mapping the set of all finite sequences of symbols, themselves members of a finite alphabet, to a [countable set](wikipedia://en/6026) of [ordinals](wikipedia://en/26547932). A [Gödel numbering](wikipedia://en/207790) is an injective function mapping the set of [well-formed formula](wikipedia://en/404582)e (a finite sequence of symbols on which the ordinal notation function is defined) of some formal language to the natural numbers. This associates each well-formed formula with a unique natural number, called its Gödel number. If a Gödel numbering is fixed, then the subset relation on the ordinals induces an ordering on well-formed formulae, which in turn induces a well-ordering on the subset of natural numbers. A **recursive ordinal notation** must satisfy the following two additional properties:

:::

1. the subset of natural numbers is a [recursive set](https://en.wikipedia.org/wiki/Recursive_set)
1. the induced well-ordering on the subset of natural numbers is a recursive relation

There are many such schemes of ordinal notations, including schemes by [Wilhelm Ackermann](wikipedia://en/62727), [Heinz Bachmann](wikipedia://en/47768191), Wilfried Buchholz, [Georg Cantor](wikipedia://en/12216), [Solomon Feferman](wikipedia://en/355401), Gerhard Jäger, Isles, Pfeiffer, Wolfram Pohlers, [Kurt Schütte](wikipedia://en/16184365), [Gaisi Takeuti](wikipedia://en/2593847) (called **ordinal diagrams**), [Oswald Veblen](https://en.wikipedia.org/wiki/Oswald_Veblen). [Stephen Cole Kleene](wikipedia://en/28805) has a system of notations, called [Kleene's O](wikipedia://en/16105044), which includes ordinal notations but it is not as well behaved as the other systems described here.

Usually one proceeds by defining several functions from ordinals to ordinals and representing each such function by a symbol. In many systems, such as [Veblen's well known system](wikipedia://en/16124925), the functions are [normal functions](wikipedia://en/404306), that is, they are strictly increasing and [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28set_theory%29) in at least one of their arguments, and increasing in other arguments. Another desirable property for such functions is that the value of the function is greater than each of its arguments, so that an ordinal is always being described in terms of smaller ordinals. There are several such desirable properties. Unfortunately, no one system can have all of them since they conflict with each other.

## A simplified example using a pairing function {#A_simplified_example_using_a_pairing_function}

As usual, we must start off with a constant symbol for zero, "$0$", which we may consider to be a function of [arity](wikipedia://en/42301) zero. This is necessary because there are no smaller ordinals in terms of which zero can be described.

The most obvious next step would be to define a unary function, "S" that takes an ordinal to the smallest ordinal greater than it; in other words, S is the [successor function](wikipedia://en/325637). In combination with zero, successor allows one to name any natural number.

The third function might be defined as one that maps each ordinal to the smallest ordinal that cannot yet be described with the above two functions and previous values of this function. This would map $\beta$ to $\omega\cdot\beta$, except when $\beta$ is a fixed point of that function plus a finite number, in which case one maps $\beta$ to $\omega\cdot(\beta+1)$.

The fourth function would map $\alpha$ to $\omega^\omega\cdot\alpha$, except when $\alpha$ is a fixed point of that function plus a finite number, in which case one maps $\alpha$ to $\omega^\omega\cdot(\alpha+1)$.

### ξ-notation {#&xi;-notation}

One could continue in this way, but it would give us an infinite number of functions. So instead, let us merge the unary functions into a binary function. By [transfinite recursion](https://en.wikipedia.org/wiki/Transfinite_recursion) on $\alpha$, we can use transfinite recursion on $\beta$ to define $\xi(\alpha,\beta)$ to be the smallest ordinal $\gamma$ such that $\alpha<\gamma$ and $\beta<\gamma$ and $\gamma$ is not the value of $\xi$ for any smaller $\alpha$ or for the same $\alpha$ with a smaller $\beta$.

Thus, define $\xi$-notations as follows:

- "$0$" is a $\xi$-notation for zero.
- If "A" and "B" are replaced by $\xi$-notations for $\alpha$ and $\beta$ in "ξAB", then the result is a $\xi$-notation for $\xi(\alpha,\beta)$.
- There are no other $\xi$-notations.

The function $\xi$ is defined for all pairs of ordinals and is one-to-one. It always gives values larger than its arguments and its [range](wikipedia://en/275991) is all ordinals other than 0 and the [epsilon numbers](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29).

One has $\xi(\alpha,\beta)<\xi(\gamma,\delta)$ when either

- $\alpha=\gamma$ and $\beta<\delta$, or
- $\alpha<\gamma$ and $\beta<\xi(\gamma,\delta)$, or
- $\alpha>\gamma$ and $\xi(\alpha,\beta)\leq\delta$.

With this definition, the first few ξ-notations are:

"0" for 0. "ξ00" for 1. "ξ0ξ00" for ξ(0,1)=2. "ξξ000" for ξ(1,0)=ω. "ξ0ξ0ξ00" for 3. "ξ0ξξ000" for ω+1. "ξξ00ξ00" for ω·2. "ξξ0ξ000" for ω<sup>ω</sup>. "ξξξ0000" for $\omega^{\omega^{\omega}}.$

In general, $\xi(0,\beta)=\beta+1$. While ξ(1+α,β) = ω<sup>ω<sup>α</sup></sup>·(β+k) for k = 0 or 1 or 2 depending on special situations: k = 2 if α is an epsilon number and β is finite. Otherwise, k = 1 if β is a multiple of ω<sup>ω<sup>α+1</sup></sup> plus a finite number. Otherwise, k = 0.

That is:

$$\alpha + 1 = \xi (0, \alpha) .$$

$$1 \leq \gamma < \omega^{\omega^{\beta + 1}} \land n < \omega \implies \omega^{\omega^{\beta + 1}} \cdot \alpha + \omega^{\omega^\beta} \cdot (\omega \cdot \gamma + n) = \xi (1 + \beta, \omega^{\omega^{\beta + 1}} \cdot \alpha + (\omega \cdot \gamma + n)) .$$

$$(0 < \alpha \lor \beta < \omega^\beta) \land n < \omega \implies \omega^{\omega^{\beta + 1}} \cdot \alpha + \omega^{\omega^\beta} \cdot (n + 1) = \xi (1 + \beta, \omega^{\omega^{\beta + 1}} \cdot \alpha + n) .$$

$$\beta = \omega^\beta \land n < \omega \implies \omega^{\omega^\beta} \cdot (n + 2) = \xi (\beta, n) .$$

The ξ-notations can be used to name any ordinal less than ε<sub>0</sub> with an alphabet of only two symbols ("0" and "ξ"). If these notations are extended by adding functions that enumerate epsilon numbers, then they will be able to name any ordinal less than the first epsilon number that cannot be named by the added functions. This last property, adding symbols within an initial segment of the ordinals gives names within that segment, is called repleteness (after [Solomon Feferman](wikipedia://en/355401)).

## Examples of Ordinal Notations {#Examples_of_Ordinal_Notations}

There are many different systems for ordinal notation introduced by various authors. It is often quite hard to convert between the different systems.

### Cantor {#Cantor}

"Exponential polynomials" in 0 and ω gives a system of ordinal notation for ordinals less than [ε<sub>0</sub>](https://en.wikipedia.org/wiki/Epsilon_numbers_%28mathematics%29). There are many equivalent ways to write these; instead of exponential polynomials, one can use rooted trees, or nested parentheses, or the system described above.

### Veblen {#Veblen}

The 2-variable Veblen functions (Veblen 1908) can be used to give a system of ordinal notation for ordinals less than the [Feferman–Schütte ordinal](wikipedia://en/16084455). The Veblen functions in a finite or transfinite number of variables give systems of ordinal notations for ordinals less than the small and large [Veblen ordinals](https://en.wikipedia.org/wiki/Veblen_ordinal_%28disambiguation%29).

### Ackermann {#Ackermann}

(Ackermann 1951) described a system of ordinal notation rather weaker than the system described earlier by Veblen. The limit of his system is sometimes called the [Ackermann ordinal](wikipedia://en/16137162).

### Bachmann {#Bachmann}

(Bachmann 1950) introduced the key idea of using uncountable ordinals to produce new countable ordinals. His original system was rather cumbersome to use as it required choosing a special sequence converging to each ordinal. Later systems of notation introduced by Feferman and others avoided this complication.

### Takeuti (ordinal diagrams) {#Takeuti_(ordinal_diagrams)}

(Takeuti 1987) described a system of ordinal notation known as "ordinal diagrams", whose limit is the [Takeuti–Feferman–Buchholz ordinal](wikipedia://en/68444579).[^o14] The system was later simplified by Feferman.

### Feferman's θ functions {#Feferman's_&theta;_functions}

Feferman introduced theta functions, described in (Buchholz 1986) as follows. For an ordinal *α*, θ<sub>*α*</sub> is a function mapping ordinals to ordinals. Often θ<sub>*α*</sub>(*β*) is written as θ*αβ*. The set *C*(*α*, *β*) is defined by induction on *α* to be the set of ordinals that can be generated from 0, [ω<sub>1</sub>](wikipedia://en/20860540), ω<sub>2</sub>, ..., ω<sub>ω</sub>, together with the ordinals less than β by the operations of ordinal addition and the functions θ<sub>ξ</sub> for ξ\<α. And the function θ<sub>γ</sub> is defined to be the function enumerating the ordinals δ with δ∉*C*(γ,δ). The problem with this system is that ordinal notations and [collapsing functions](https://en.wikipedia.org/wiki/Collapsing_function) are not identical, and therefore this function does not qualify as an ordinal notation. An associated ordinal notation is not known.

::: {#o18 .pointer-item cue=pointer name="Buchholz's notation"}

### Buchholz {#Buchholz}

(Buchholz 1986) described the following system of ordinal notation as a simplification of Feferman's theta functions. Define:

- Ω<sub>ξ</sub> = ω<sub>ξ</sub> if ξ > 0, Ω<sub>0</sub> = 1

The functions ψ<sub>*v*</sub>(α) for α an ordinal, *v* an ordinal at most ω, are defined by induction on α as follows:

- ψ<sub>*v*</sub>(α) is the smallest ordinal not in *C*<sub>*v*</sub>(α)

where *C*<sub>*v*</sub>(α) is the smallest set such that

- *C*<sub>*v*</sub>(α) contains all ordinals less than Ω<sub>*v*</sub>
- *C*<sub>*v*</sub>(α) is closed under ordinal addition
- *C*<sub>*v*</sub>(α) is closed under the functions ψ<sub>*u*</sub> (for *u*≤ω) applied to arguments less than α.

This system has about the same strength as Fefermans system, as $\theta\varepsilon_{\Omega_v+1}0 = \psi_0(\varepsilon_{\Omega_v+1})$ for *v* ≤ ω. Yet, while this system is powerful, it does not qualify as an ordinal notation. Buchholz did create an associated ordinal notation, yet it is complicated: the definition is in the main article.

:::

### Kleene's O {#Kleene's_O}

(Kleene 1938) described a system of notation for all recursive ordinals (those less than the [Church–Kleene ordinal](https://en.wikipedia.org/wiki/Church–Kleene_ordinal)). Unfortunately, unlike the other systems described above there is in general no [effective](wikipedia://en/1139338) way to tell whether some natural number represents an ordinal, or whether two numbers represent the same ordinal. However, one can effectively find notations that represent the ordinal sum, product, and power (see [ordinal arithmetic](wikipedia://en/2139226)) of any two given notations in Kleene's $\mathcal{O}$; and given any notation for an ordinal, there is a [recursively enumerable set](https://en.wikipedia.org/wiki/Recursively_enumerable_set) of notations that contains one element for each smaller ordinal and is effectively ordered. Kleene's $\mathcal{O}$ denotes a canonical (and very non-computable) set of notations. It uses a subset of the [natural numbers](wikipedia://en/21474) instead of finite strings of symbols, and is not recursive, therefore, once again, not qualifying as a recursive ordinal notation.
