# Stably free module

::: {#o1 .subject cue=lead name="Stably free module"}

In [mathematics](wikipedia://en/18831), a **stably free module** is a [module](wikipedia://en/276410) which is close to being [free](wikipedia://en/326454).

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A module *M* over a ring *R* is *stably free* if there exists a free [finitely generated module](wikipedia://en/326430) *F* over *R* such that $M \oplus F$ is a free module.

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- A [projective module](wikipedia://en/364488) is stably free if and only if it possesses a finite [free resolution](https://en.wikipedia.org/wiki/Free_resolution).
- An [infinitely generated module](https://en.wikipedia.org/wiki/Infinitely_generated_module) is stably free if and only if it is free.[^o7]

:::
