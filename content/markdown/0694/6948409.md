# Binary erasure channel

*Image: Binaryerasurechannel.png.* The channel model for the binary erasure channel showing a mapping from channel input X to channel output Y (with known erasure symbol *?*). The probability of erasure is $p_e$

::: {#o1 .subject cue=lead name="Binary erasure channel"}

In [coding theory](wikipedia://en/321869) and [information theory](wikipedia://en/14773), a **binary erasure channel** (**BEC**) is a [communications channel](https://en.wikipedia.org/wiki/Communications_channel) model. A transmitter sends a [bit](https://en.wikipedia.org/wiki/Bit) (a zero or a one), and the receiver either receives the bit correctly, or with some probability $P_e$ receives a message that the bit was not received ("erased") .

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

A binary erasure channel with erasure probability $P_e$ is a channel with binary input, ternary output, and probability of erasure $P_e$. That is, let $X$ be the transmitted [random variable](wikipedia://en/25685) with alphabet $\{0,1\}$. Let $Y$ be the received variable with alphabet $\{0,1,\text{e} \}$, where $\text{e}$ is the erasure symbol. Then, the channel is characterized by the [conditional probabilities](wikipedia://en/24104134):[^n1]

$$\begin{aligned} \operatorname {Pr} [ Y = 0 | X = 0 ] &= 1 - P_e \\ \operatorname {Pr} [ Y = 0 | X = 1 ] &= 0 \\ \operatorname {Pr} [ Y = 1 | X = 0 ] &= 0 \\ \operatorname {Pr} [ Y = 1 | X = 1 ] &= 1 - P_e \\ \operatorname {Pr} [ Y = e | X = 0 ] &= P_e \\ \operatorname {Pr} [ Y = e | X = 1 ] &= P_e \end{aligned}$$

:::

## Capacity {#Capacity}

The [channel capacity](wikipedia://en/231204) of a BEC is $1-P_e$, attained with a uniform distribution for $X$ (i.e. half of the inputs should be 0 and half should be 1).[^n2]

{| class="toccolours collapsible collapsed" width="80%" style="text-align:left"

!Proof[^n2] |- |By symmetry of the input values, the optimal input distribution is $X \sim \mathrm{Bernoulli}\left(\frac{1}{2}\right)$. The channel capacity is:

$$\operatorname{I}(X;Y) = \operatorname{H}(X)-\operatorname{H}(X|Y)$$

Observe that, for the [binary entropy function](wikipedia://en/5275277) $\operatorname{H}_\text{b}$ (which has value 1 for input $\frac{1}{2}$),

$$\operatorname{H}(X|Y)=\sum_y P(y)\operatorname{H}(X|y)=P_e \operatorname{H}_{\text{b}}\left(\frac{1}{2}\right) = P_e$$

as $X$ is known from (and equal to) y unless $y=e$, which has probability $P_e$.

By definition $\operatorname{H}(X)=\operatorname{H}_{\text{b}}\left(\frac{1}{2}\right)=1$, so

$$\operatorname{I}(X;Y) = 1-P_e.$$

\|}

If the sender is notified when a bit is erased, they can repeatedly transmit each bit until it is correctly received, attaining the capacity $1-P_e$. However, by the [noisy-channel coding theorem](wikipedia://en/3474289), the capacity of $1-P_e$ can be obtained even without such feedback.[^n3]

## Related channels {#Related_channels}

If bits are flipped rather than erased, the channel is a [binary symmetric channel](wikipedia://en/74361) (BSC), which has capacity $1 - \operatorname H_\text{b}(P_e)$ (for the [binary entropy function](wikipedia://en/5275277) $\operatorname{H}_\text{b}$), which is less than the capacity of the BEC for $0<P_e<1/2$.[^n4][^n5] If bits are erased but the receiver is not notified (i.e. does not receive the output $e$) then the channel is a [deletion channel](https://en.wikipedia.org/wiki/Deletion_channel), and its capacity is an open problem.[^n6]

## History {#History}

The BEC was introduced by [Peter Elias](https://en.wikipedia.org/wiki/Peter_Elias) of MIT in 1955 as a toy example.
