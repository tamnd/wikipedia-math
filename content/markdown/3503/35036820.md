# Frequency domain decomposition

::: {#o1 .subject cue=lead name="Frequency domain decomposition"}

The **frequency domain decomposition** (**FDD**) is an output-only [system identification](wikipedia://en/552466) technique popular in [civil engineering](https://en.wikipedia.org/wiki/Civil_engineering), in particular in [structural health monitoring](https://en.wikipedia.org/wiki/Structural_health_monitoring). As an output-only algorithm, it is useful when the input data is unknown. FDD is a [modal analysis](wikipedia://en/7542417) technique which generates a [system realization](https://en.wikipedia.org/wiki/System_realization) using the frequency response given (multi-)output data.[^o2][^o3]

:::

::: {#o5 .definition kind=definition/construction cue=heading name="Algorithm"}

## Algorithm {#Algorithm}

1. Estimate the [power spectral density](https://en.wikipedia.org/wiki/Power_spectral_density) matrix $\hat{G}_{yy}(j\omega)$ at discrete frequencies $\omega = \omega_i$.
1. Do a [singular value decomposition](wikipedia://en/142207) of the power spectral density, i.e. $\hat{G}_{yy}(j \omega_i) = U_i S_i U_i^H$ where $U_i = [u_{i1},u_{i2},...,u_{im}]$ is a [unitary matrix](wikipedia://en/129222) holding the [singular vectors](https://en.wikipedia.org/wiki/Singular_vector) $u_{ij}$, $S_i$ is the diagonal matrix holding the singular values $s_{ij}$.
1. For an $n$ degree of freedom system, then pick the $n$ dominating peaks in the power spectral density using whichever technique you wish (or manually). These peaks correspond to the [mode shapes](https://en.wikipedia.org/wiki/Mode_shape).[^o2]
   1. Using the mode shapes, an input-output system realization can be written.

:::
