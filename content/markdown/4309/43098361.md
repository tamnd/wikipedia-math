# Gödel operation

::: {#o1 .subject cue=lead name="Gödel operation"}

In mathematical [set theory](wikipedia://en/27553), a set of **Gödel operations** is a finite collection of operations on sets that can be used to construct the [constructible sets](wikipedia://en/343335) from [ordinals](wikipedia://en/26547932). (txt, 35) introduced the original set of 8 Gödel operations 𝔉<sub>1</sub>,...,𝔉<sub>8</sub> under the name **fundamental operations**. Other authors sometimes use a slightly different set of about 8 to 10 operations, usually denoted *G*<sub>1</sub>, *G*<sub>2</sub>,...

:::

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

(Gödel 1940) used the following eight operations as a set of Gödel operations (which he called fundamental operations):

1. $$\mathfrak{F}_1(X,Y) = \{X,Y\}$$
1. $$\mathfrak{F}_2(X,Y) = E\cdot X = \{(a,b)\in X\mid a\in b\}$$
1. $$\mathfrak{F}_3(X,Y) = X-Y$$
1. $$\mathfrak{F}_4(X,Y) = X\upharpoonright Y= X\cdot (V\times Y) = \{(a,b)\in X\mid b\in Y\}$$
1. $$\mathfrak{F}_5(X,Y) = X\cdot \mathfrak{D}(Y) = \{b\in X\mid\exists a (a,b)\in Y\}$$
1. $$\mathfrak{F}_6(X,Y) = X\cdot Y^{-1}= \{(a,b)\in X\mid(b,a)\in Y\}$$
1. $$\mathfrak{F}_7(X,Y) = X\cdot \mathfrak{Cnv}_2(Y) = \{(a,b,c)\in X\mid(b,c,a)\in Y\}$$
1. $$\mathfrak{F}_8(X,Y) = X\cdot \mathfrak{Cnv}_3(Y)= \{(a,b,c)\in X\mid(a,c,b)\in Y\}$$

The second expression in each line gives Gödel's definition in his original notation, where the dot means intersection, $V$ is the universe, $E$ is the membership relation, $\mathfrak{D}$ denotes domain and so on. Note that the convention here is that a function from $X$ to $Y$ is encoded as a subset of $Y\times X$, not $X\times Y$.

(Jech 2003) uses the following set of 10 Gödel operations.

1. $$G_1(X,Y) = \{X,Y\}$$
1. $$G_2(X,Y) = X\times Y$$
1. $$G_3(X,Y) = \{(x,y)\mid x\in X, y\in Y, x\in y\}$$
1. $$G_4(X,Y) = X-Y$$
1. $$G_5(X,Y) = X\cap Y$$
1. $$G_6(X) = \cup X$$
1. $$G_7(X) = \text{dom}(X)$$
1. $$G_8(X) = \{(x,y)\mid(y,x)\in X\}$$
1. $$G_9(X) = \{(x,y,z)\mid(x,z,y)\in X\}$$
1. $$G_{10}(X) = \{(x,y,z)\mid(y,z,x)\in X\}$$

The reason for including the functions $\{(x,y,z)\mid(x,z,y)\in X\}$ and $\{(x,y,z)\mid(y,z,x)\in X\}$ which permute the entries of an ordered [tuple](wikipedia://en/132729) is that, for example, the tuple $(x_1,x_2,x_3,x_4)$ can be formed easily from $x_1$ and $(x_2,x_3,x_4)$ since it equals $(x_1,(x_2,x_3,x_4))$, but it is more difficult to form when the entries are given in a different order, such as from $x_4$ and $(x_1,x_2,x_3)$.[^o7]<sup>p. 63</sup>

:::

::: {#o9 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

Gödel's normal form theorem states that if $\phi(x_1,\ldots,x_n)$ is a formula in the language of set theory with all quantifiers bounded, then the function $\{ (x_1, \ldots, x_n) \in (X_1\times\ldots\times X_n) \mid \phi(x_1, \ldots, x_n)\}$ of $X_1$, $\ldots$, $X_n$ is given by a composition of some Gödel operations. This result is closely related to Jensen's [rudimentary functions](https://en.wikipedia.org/wiki/Jensen_hierarchy#Rudimentary_functions).[^o10]

[Jon Barwise](wikipedia://en/912858) showed that a version of Gödel's normal form theorem with his own set of 12 Gödel operations is provable in $\mathrm{KPU}$, a variant of [Kripke–Platek set theory](wikipedia://en/1124695) admitting [urelements](https://en.wikipedia.org/wiki/Urelements).[^o7]<sup>p. 64</sup>

:::
