# Key checksum value

::: {#o1 .subject cue=lead name="Key checksum value"}

In [cryptography](wikipedia://en/18934432), a **Key Checksum Value** (KCV) is the [checksum](https://en.wikipedia.org/wiki/Checksum) of a [cryptographic key](wikipedia://en/53039).[^o2] It is used to validate the integrity of the key or compare keys without knowing their actual values. The KCV is computed by encrypting a block of bytes, each with value '00' or '01', with the cryptographic key and retaining the first 6 hexadecimal characters of the encrypted result. It is used in [key management](wikipedia://en/631063) in different ciphering devices, such as [SIM-cards](https://en.wikipedia.org/wiki/SIM_card) or [Hardware Security Modules (HSM)](https://en.wikipedia.org/wiki/Hardware_security_module).

:::

## KCV for symmetric key management in retail financial services {#KCV_for_symmetric_key_management_in_retail_financial_services}

The payments cards industry uses the following definition, as documented in requirement 15-1 of [PCI](https://en.wikipedia.org/wiki/Payment_card_industry) PIN Security standard.[^o6] The same definitions can also be found in the [ASC X9](https://en.wikipedia.org/wiki/ASC_X9) standards under [ANSI x9.24-1-2017](https://x9.org/standard-release-ansi-x9-24-1-2017/) Retail Financial Services Symmetric [Key Management](wikipedia://en/631063) Part 1[^o7]

> Check values may be computed by two methods. [TDEA](https://en.wikipedia.org/wiki/TDEA) may use either method. [AES](wikipedia://en/1260) must only use the [CMAC](https://en.wikipedia.org/wiki/Cmac) method. In the first method, check values are computed by encrypting an all binary zeros block using the [key](wikipedia://en/53039) or component as the encryption key, using the leftmost n-bits of the result; where n is at most 24 bits (6 hexadecimal digits/3 bytes). In the second method the KCV is calculated by [MACing](wikipedia://en/567523) an all binary zeros block using the [CMAC](https://en.wikipedia.org/wiki/Cmac) algorithm as specified in [ISO 9797-1](https://en.wikipedia.org/wiki/ISO/IEC_9797-1) (see also [NIST SP 800-38B](https://csrc.nist.gov/pubs/sp/800/38/b/upd1/final)). The check value will be the leftmost n-bits of the result, where n is at most 40 bits (10 hexadecimal digits). The [block cipher](wikipedia://en/4594) used in the [CMAC](https://en.wikipedia.org/wiki/Cmac) function is the same as the [block cipher](wikipedia://en/4594) of the key itself. A [TDEA](https://en.wikipedia.org/wiki/TDEA) key or a component of a [TDEA](https://en.wikipedia.org/wiki/TDEA) key will be [MACed](wikipedia://en/567523) using the [TDEA](https://en.wikipedia.org/wiki/TDEA) block cipher, while a 128-bit [AES](wikipedia://en/1260) key or component will be [MACed](wikipedia://en/567523) using the [AES](wikipedia://en/1260)-128 [block cipher](wikipedia://en/4594).
