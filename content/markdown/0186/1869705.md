# Cobweb plot

::: {#o1 .subject cue=lead name="Cobweb plot"}

*Image: CobwebConstruction.gif.* Construction of a cobweb plot of the logistic map $y = 2.8 x (1-x)$, showing an [attracting fixed point](https://en.wikipedia.org/wiki/Attracting_fixed_point).

*Image: LogisticCobwebChaos.gif.* An animated cobweb diagram of the [logistic map](wikipedia://en/18137) $y = r x (1-x)$, showing [chaotic behaviour](wikipedia://en/6295) for most values of $r > 3.57$.

In [mathematics](wikipedia://en/18831), specifically [dynamical systems](https://en.wikipedia.org/wiki/Dynamical_systems), a **cobweb plot**, known also as **Lémeray diagram** or **Verhulst diagram**, is a visual tool used to investigate the qualitative behaviour of one-dimensional [iterated functions](wikipedia://en/1448702), such as the [logistic map](wikipedia://en/18137). The technique was introduced in 1822 by [Adrien-Marie Legendre](wikipedia://en/49695).[^n1] Using a cobweb plot, it is possible to infer the long-term status of an [initial condition](wikipedia://en/1186804) under [repeated application](wikipedia://en/146806) of a map.[^n2]

:::

::: {#o5 .definition kind=definition/construction cue=heading name="Method"}

## Method {#Method}

For a given iterated function $f:\mathbb{R}\rightarrow\mathbb{R}$, the plot consists of a diagonal ($x=y$) line and a curve representing $y = f(x)$. To plot the behaviour of a value $x_0$, apply the following steps.

1. Find the point on the function curve with an $x$-coordinate of $x_0$. This has the coordinates ($x_0, f(x_0)$).
1. Plot horizontally across from this point to the diagonal line. This has the coordinates ($f(x_0), f(x_0)$).
1. Plot vertically from the point on the diagonal to the function curve. This has the coordinates ($f(x_0), f(f(x_0))$).
1. Repeat from step 2 as required.

:::

## Interpretation {#Interpretation}

On a cobweb plot, a stable [fixed point](wikipedia://en/449738) corresponds to the segment of the staircase with progressively decreasing stair lengths or to an inward [spiral](wikipedia://en/61563), while an unstable fixed point is the segment of the staircase with growing stairs or an outward spiral. It follows from the definition of a fixed point that the staircases [converge](https://en.wikipedia.org/wiki/Converge_%28mathematics%29) whereas spirals center at a point where the [diagonal](wikipedia://en/15069) $y=x$ line crosses the function graph. A period-2 [orbit](wikipedia://en/252250) is represented by a [rectangle](wikipedia://en/70048), while greater period cycles produce further, more complex closed loops. A [chaotic](wikipedia://en/6295) orbit would show a "filled-out" area, indicating an infinite number of non-repeating values.[^n2]
