# Feedback vertex set

::: {#o1 .subject cue=lead name="Feedback vertex set"}

*Image: Feedback vertex set.svg.* Removing the red vertices and all edges connected to them leaves the graph with no cycles. Thus, the set of vertices is a feedback vertex set (FVS) of the graph. There is no smaller FVS, so it is a minimum FVS and the FVS number is its size, 3.

In the [mathematical](wikipedia://en/18831) discipline of [graph theory](wikipedia://en/12401), a **feedback vertex set** (FVS) of a [graph](wikipedia://en/325806) is a set of vertices whose removal leaves a graph without [cycles](wikipedia://en/168609) ("removal" means deleting the vertex and all edges adjacent to it). Equivalently, each FVS contains at least one vertex of any cycle in the graph. The **feedback vertex set number** of a graph is the size of a smallest FVS. Whether there exists a **feedback vertex set of size at most k** is an [NP-complete](https://en.wikipedia.org/wiki/NP-complete) problem; it was among the [first problems shown to be NP-complete](wikipedia://en/2012564). It has wide applications in [operating systems](https://en.wikipedia.org/wiki/Operating_system), [database systems](https://en.wikipedia.org/wiki/Database_system), and [VLSI](https://en.wikipedia.org/wiki/VLSI) chip design.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

The FVS [decision problem](wikipedia://en/8336) is as follows:

INSTANCE: An (undirected or directed) [graph](wikipedia://en/325806) $G = (V, E)$ and a positive integer $k$.

QUESTION: Is there a subset $X \subseteq V$ with $|X| \leq k$ such that, when all vertices of $X$ and their adjacent edges are deleted from $G$, the remainder is [cycle-free](wikipedia://en/168609)?

The graph $G[V \setminus X]$ that remains after removing $X$ from $G$ is an induced [forest](https://en.wikipedia.org/wiki/Forest_%28graph_theory%29) (resp. an induced [directed acyclic graph](wikipedia://en/204002) in the case of [directed graphs](wikipedia://en/19721986)). Thus, finding a minimum FVS in a graph is equivalent to finding a maximum induced forest (resp. maximum induced directed acyclic graph in the case of [directed graphs](wikipedia://en/19721986)).

:::

## NP-completeness {#NP-completeness}

(Karp 1972) showed that finding a feedback vertex set of size $\le k$ in [*directed* graphs](wikipedia://en/19721986) is [NP-complete](https://en.wikipedia.org/wiki/NP-complete). The problem remains NP-complete on directed graphs with maximum in-degree and out-degree two, and on directed planar graphs with maximum in-degree and out-degree three.[^o6]

Karp's reduction also implies the NP-completeness of the feedback vertex set problem on *undirected* graphs, where the problem stays NP-complete on graphs of [maximum degree](wikipedia://en/1374448) four. The feedback vertex set problem can be solved in polynomial time on graphs of [maximum degree](wikipedia://en/1374448) at most three, using an algorithm based on the [matroid parity problem](wikipedia://en/56069479).[^o7]

## Exact algorithms {#Exact_algorithms}

The corresponding [NP optimization problem](https://en.wikipedia.org/wiki/NP_optimization_problem) of finding the size of a minimum feedback vertex set can be solved in time *O*(1.7347<sup>*n*</sup>), where *n* is the number of vertices in the graph.[^o9] This algorithm actually computes a maximum induced forest, and when such a forest is obtained, its complement is a minimum feedback vertex set. The number of minimal feedback vertex sets in a graph is bounded by *O*(1.8638<sup>*n*</sup>).[^n1] The directed feedback vertex set problem can still be solved in time *O\**(1.9977<sup>*n*</sup>), where *n* is the number of vertices in the given directed graph.[^n2] The parameterized versions of the directed and undirected problems are both [fixed-parameter tractable](https://en.wikipedia.org/wiki/Fixed-parameter_tractable).[^n3]

In undirected graphs of maximum [degree](wikipedia://en/1374448) three, the feedback vertex set problem can be solved in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time), by transforming it into an instance of the [matroid parity problem](wikipedia://en/56069479) for [linear matroids](https://en.wikipedia.org/wiki/Linear_matroid).[^n4]

The special case of finding all feedback vertices in a directed graph (vertices that lie on every directed cycle) can be solved in linear time using a DFS-based algorithm by Garey and Tarjan.[^o14]

## Approximation {#Approximation}

The undirected problem is [APX-complete](wikipedia://en/2018925). This follows from the following facts.

- The APX-completeness of the [vertex cover problem](wikipedia://en/562782);[^o16]
- The existence of an approximation preserving [L-reduction](wikipedia://en/4073116) from the vertex cover problem to it;
- Existing constant-factor approximation algorithms.[^o17]

The best known approximation algorithm on undirected graphs is by a factor of two.[^o18]

By contrast, the directed version of the problem appears to be much harder to approximate. Under the [unique games conjecture](wikipedia://en/3000842), an unproven but commonly used [computational hardness assumption](wikipedia://en/6158383), it is NP-hard to approximate the problem to within any constant factor in polynomial time. The same hardness result was originally proven for the closely related [feedback arc set](wikipedia://en/1860374) problem,[^o19] but since the feedback arc set problem and feedback vertex set problem in directed graphs are reducible to one another while preserving solution sizes,[^o20] it also holds for the latter.

## Bounds {#Bounds}

According to the [Erdős–Pósa theorem](wikipedia://en/22211457), the size of a minimum feedback vertex set is within a logarithmic factor of the maximum number of vertex-disjoint cycles in the given graph.[^n5]

## Related concepts {#Related_concepts}

- Instead of vertices, one can consider a *feedback edge set* - a set of edges in an undirected graph, whose removal makes the graph acyclic. The size of a smallest feedback edge set in a graph is called the **[circuit rank](https://en.wikipedia.org/wiki/Circuit_rank)** of the graph. In contrast to the FVS number, the circuit rank can be easily computed: it is $|E|-|V|+|C|$, where C is the set of [connected components](wikipedia://en/246223) of the graph. The problem of finding a smallest feedback edge set is equivalent to finding a [spanning forest](wikipedia://en/455770), which can be done in [polynomial time](https://en.wikipedia.org/wiki/Polynomial_time).
- The analogous concept in a [directed graph](wikipedia://en/19721986) is the **[feedback arc set](wikipedia://en/1860374)** (FAS) - a set of directed arcs whose removal makes the graph acyclic. Finding a smallest FAS is an NP-hard problem.[^o17]

::: {#o25 .application cue=heading name="Applications"}

## Applications {#Applications}

- In [operating systems](https://en.wikipedia.org/wiki/Operating_system), feedback vertex sets play a prominent role in the study of [deadlock](https://en.wikipedia.org/wiki/Deadlock_%28computer_science%29) recovery. In the [wait-for graph](https://en.wikipedia.org/wiki/Wait-for_graph) of an operating system, each directed cycle corresponds to a deadlock situation. In order to resolve all deadlocks, some blocked processes have to be aborted. A minimum feedback vertex set in this graph corresponds to a minimum number of processes that one needs to abort.[^n6]
- The feedback vertex set problem has applications in [VLSI](https://en.wikipedia.org/wiki/VLSI) chip design.[^n7]
- Another application is in complexity theory. Some computational problems on graphs are NP-hard in general, but can be solved in polynomial time for graphs with bounded FVS number. Some examples are graph isomorphism[^o28] and the path reconfiguration problem.[^o29]

:::
