# Monochromatic triangle

::: {#o1 .subject cue=lead name="Monochromatic triangle"}

*Image: RamseyTheory K5 no mono K3.svg.* A partition of the edges of the [complete graph](wikipedia://en/85816) *K*<sub>5</sub> into two triangle-free subsets

In [graph theory](wikipedia://en/12401) and [theoretical computer science](wikipedia://en/323392), the **monochromatic triangle problem** is an algorithmic problem on graphs, in which the goal is to partition the edges of a given graph into two [triangle-free](wikipedia://en/7667996) subgraphs. It is [NP-complete](https://en.wikipedia.org/wiki/NP-complete) but [fixed-parameter tractable](https://en.wikipedia.org/wiki/Fixed-parameter_tractable) on graphs of bounded [treewidth](wikipedia://en/3987086).

:::

## Problem statement {#Problem_statement}

The monochromatic triangle problem takes as input an n-node undirected graph G(V,E) with node set V and edge set E. The output is a Boolean value, true if the edge set E of G can be partitioned into two [disjoint sets](wikipedia://en/39359) E1 and E2, such that both of the two subgraphs G1(V,E1) and G2(V,E2) are [triangle-free graphs](wikipedia://en/7667996), and false otherwise. This [decision problem](wikipedia://en/8336) is [NP-complete](https://en.wikipedia.org/wiki/NP-complete).[^o3]

## Generalization to multiple colors {#Generalization_to_multiple_colors}

The problem may be generalized to **triangle-free edge coloring**, finding an assignment of colors to the edges of a graph so that no triangle has all three edges given the same color. The monochromatic triangle problem is the special case of triangle-free edge-coloring when there are exactly two colors available. If there exists a two-color triangle-free [edge coloring](wikipedia://en/690647), then the edges of each color form the two sets E1 and E2 of the monochromatic triangle problem. Conversely, if the monochromatic triangle problem has a solution, we can use one color for E1 and a second color for E2 to obtain a triangle-free edge coloring.

::: {#o6 .statement kind=statement/theorem cue=named-heading name="Connection to Ramsey's theorem"}

## Connection to Ramsey's theorem {#Connection_to_Ramsey's_theorem}

By [Ramsey's theorem](wikipedia://en/184898), for any finite number *k* of colors, there exists a number *n* such that complete graphs of *n* or more vertices do not have triangle-free edge colorings with *k* colors. For *k* = 2, the corresponding value of *n* is 6. That is, the answer to the monochromatic triangle problem on the complete graph *K*<sub>6</sub> is no.

:::

## Parameterized complexity {#Parameterized_complexity}

It is straightforward to express the monochromatic triangle problem in the [monadic second-order](wikipedia://en/14650395) [logic of graphs](wikipedia://en/47857242) (MSO<sub>2</sub>), by a logical formula that asserts the existence of a partition of the edges into two subsets such that there do not exist three mutually adjacent vertices whose edges all belong to the same side of the partition. It follows from [Courcelle's theorem](wikipedia://en/35810608) that the monochromatic triangle problem is [fixed-parameter tractable](https://en.wikipedia.org/wiki/Fixed-parameter_tractable) on graphs of bounded [treewidth](wikipedia://en/3987086). More precisely, there is an algorithm for solving the problem whose running time is the number of vertices of the input graph multiplied by a quickly-growing but [computable function](wikipedia://en/1139338) of the treewidth.[^o8]
