# Dual code

::: {#o1 .subject cue=lead name="Dual code"}

In [coding theory](wikipedia://en/321869), the **dual code** of a [linear code](wikipedia://en/1866743)

:::

$$C\subset\mathbb{F}_q^n$$

is the linear code defined by

$$C^\perp = \{x \in \mathbb{F}_q^n \mid \langle x,c\rangle = 0\;\forall c \in C \}$$

where

$$\langle x, c \rangle = \sum_{i=1}^n x_i c_i$$

is a scalar product. In [linear algebra](wikipedia://en/18422) terms, the dual code is the [annihilator](wikipedia://en/328684) of *C* with respect to the [bilinear form](wikipedia://en/449477) $\langle\cdot\rangle$. The [dimension](wikipedia://en/38267) of *C* and its dual always add up to the length *n*:

$$\dim C + \dim C^\perp = n.$$

A [generator matrix](wikipedia://en/6133005) for the dual code is the [parity-check matrix](wikipedia://en/10557570) for the original code and vice versa. The dual of the dual code is always the original code.

::: {#o3 .pointer-item cue=pointer name="Self-dual code"}

## Self-dual codes {#Self-dual_codes}

A **self-dual code** is one which is its own dual. This implies that *n* is even and dim *C* = *n*/2. If a self-dual code is such that each codeword's weight is a multiple of some constant $c > 1$, then it is of one of the following four types:[^o4]

- **Type I** codes are binary self-dual codes which are not [doubly even](https://en.wikipedia.org/wiki/Doubly_even_code). Type I codes are always [even](wikipedia://en/4706915) (every codeword has even [Hamming weight](wikipedia://en/1127884)).
- **Type II** codes are binary self-dual codes which are doubly even.
- **Type III** codes are ternary self-dual codes. Every codeword in a Type III code has Hamming weight divisible by 3.
- **Type IV** codes are self-dual codes over **F**<sub>4</sub>. These are again even.

Codes of types I, II, III, or IV exist only if the length *n* is a multiple of 2, 8, 4, or 2 respectively.

If a self-dual code has a generator matrix of the form $G=[I_k|A]$, then the dual code $C^\perp$ has [generator matrix](wikipedia://en/6133005) $[-\bar{A}^T|I_k]$, where $I_k$ is the $(n/2)\times (n/2)$ identity matrix and $\bar{a}=a^q\in\mathbb{F}_q$.

:::
