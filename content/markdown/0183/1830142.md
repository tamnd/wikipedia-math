# Bijection, injection and surjection

::: {#o2 .subject cue=lead name="Bijection, injection and surjection"}

In [mathematics](wikipedia://en/18831), **injections**, **surjections**, and **bijections** are classes of [functions](wikipedia://en/185427) distinguished by the manner in which *[arguments](wikipedia://en/25065)* (input [expressions](wikipedia://en/609125) from the [domain](wikipedia://en/50263)) and *[images](wikipedia://en/579311)* (output expressions from the [codomain](wikipedia://en/50264)) are related or *mapped to* each other.

:::

A function [maps](wikipedia://en/516931) elements from its domain to elements in its codomain. Given a function $f \colon X \to Y$:

- The function is **[injective](wikipedia://en/45196)**, or **one-to-one**, if each element of the codomain is mapped to by *at most* one element of the domain, or equivalently, if distinct elements of the domain map to distinct elements in the codomain. An injective function is also called an **injection**.[^o3] Notationally:

$$\forall x, x' \in X, f(x) = f(x') \implies x = x',$$

or, equivalently (using [logical transposition](https://en.wikipedia.org/wiki/Transposition_%28logic%29)),

$\forall x,x' \in X, x \neq x' \implies f(x) \neq f(x').$[^o4][^o5][^o6]

- The function is **[surjective](wikipedia://en/27873)**, or **onto**, if each element of the codomain is mapped to by *at least* one element of the domain; that is, if the image and the codomain of the function are equal. A surjective function is a **surjection**.[^o3] Notationally:

$\forall y \in Y, \exists x \in X, y = f(x).$[^o4][^o5][^o6]

- The function is **[bijective](https://en.wikipedia.org/wiki/Bijective_function)** (**one-to-one and onto**, **one-to-one correspondence**, or **invertible**) if each element of the codomain is mapped to by *exactly* one element of the domain; that is, if the function is *both* injective and surjective. A bijective function is also called a **bijection**.[^o3][^o4][^o5][^o6] That is, combining the definitions of injective and surjective,

$$\forall y\in Y, \exists! x\in X, y=f(x),$$

where $\exists! x$ means "there [exists exactly one](wikipedia://en/276894) $x$".

- In any case (for any function), the following holds:

$$\forall x\in X, \exists! y\in Y, y=f(x).$$

An injective function need not be surjective (not all elements of the codomain may be associated with arguments), and a surjective function need not be injective (some images may be associated with *more than one* argument). The four possible combinations of injective and surjective features are illustrated in the adjacent diagrams.

## Injection {#Injection}

*Image: Injective composition.svg.* Injective composition: the second function need not be injective.

A function is **injective** (**one-to-one**) if each possible element of the codomain is mapped to by at most one argument. Equivalently, a function is injective if it maps distinct arguments to distinct images. An injective function is an **injection**.[^o3] The formal definition is the following.

The function $f \colon X \to Y$ is injective, if for all $x,x' \in X$, $f(x) = f(x') \Rightarrow x = x'.$[^o4][^o5][^o6]

The following are some facts related to injections:

- A function $f \colon X \to Y$ is injective [if and only if](wikipedia://en/14922) $X$ is empty or $f$ is left-[invertible](wikipedia://en/14907); that is, there is a function $g \colon f(X) \to X$ such that $g\circ f=$ [identity function](wikipedia://en/15069) on *X*. Here, $f(X)$ is the image of $f$.
- Since every function is surjective when its [codomain](wikipedia://en/50264) is restricted to its [image](wikipedia://en/579311), every injection induces a bijection onto its image. More precisely, every injection $f \colon X \to Y$ can be factored as a bijection followed by an inclusion as follows. Let $f_{R}\colon X\rightarrow f(X)$ be $f$ with codomain restricted to its image, and let $i \colon f(X) \to Y$ be the [inclusion map](wikipedia://en/492516) from $f(X)$ into $Y$. Then $f=i\circ f_{R}$. A dual factorization is given for surjections below.
- The composition of two injections is again an injection, but if $g\circ f$ is injective, then it can only be concluded that $f$ is injective (see figure).
- Every [embedding](wikipedia://en/52119) is injective.

## Surjection {#Surjection}

*Image: Surjective composition.svg.* Surjective composition: the first function need not be surjective.

A function is *surjective* or *onto* if each element of the [codomain](wikipedia://en/50264) is mapped to by at least one element of the [domain](wikipedia://en/50263). In other words, each element of the codomain has a non-empty [preimage](https://en.wikipedia.org/wiki/Preimage). Equivalently, a function is surjective if its image is equal to its codomain. A surjective function is a *surjection*.[^o3] The formal definition is the following.

The function $f \colon X \to Y$ is surjective, if for all $y \in Y$, there is $x \in X$ such that $f(x) = y.$[^o4][^o5][^o6]

The following are some facts related to surjections:

- A function $f \colon X \to Y$ is surjective if and only if it is right-invertible; that is, if and only if there is a function $g \colon Y \to X$ such that $f\circ g=$ identity function on $Y$. (This statement is equivalent to the [axiom of choice](wikipedia://en/840).)
- By collapsing all arguments mapping to a given fixed image, every surjection induces a bijection from a [quotient set](https://en.wikipedia.org/wiki/Quotient_set) of its domain to its codomain. More precisely, given a function $f$, define an [equivalence relation](wikipedia://en/9259) on the domain of $f$, such that *x* and *y* are equivalent if and only if they have the same image under $f$; then the [equivalence classes](https://en.wikipedia.org/wiki/Equivalence_classes) of this relation are the preimages under $f$ of the elements of the image of $f$. As all elements of any one of these equivalence classes are mapped by $f$ on the same element of the codomain, this induces a bijection between the [quotient set](https://en.wikipedia.org/wiki/Quotient_set) by this equivalence relation (the set of the equivalence classes) and the image of $f$ (which is its codomain when $f$ is surjective). Moreover, $f$ is the [composition](wikipedia://en/195947) of the [canonical projection](https://en.wikipedia.org/wiki/Canonical_projection) from $f$ to the quotient set, and the bijection between the quotient set and the codomain of $f$.
- The composition of two surjections is again a surjection, but if $g\circ f$ is surjective, then it can only be concluded that $g$ is surjective (see figure).

## Bijection {#Bijection}

*Image: Bijective composition.svg.* Bijective composition: the first function need not be surjective and the second function need not be injective.

A function is *bijective* if it is both injective and surjective. A bijective function is also called a *bijection* or a *one-to-one correspondence* (not to be confused with *one-to-one function*, which refers to injection). A function is bijective if and only if every possible image is mapped to by exactly one argument.[^o3] This equivalent condition is formally expressed as follows:

The function $f \colon X \to Y$ is bijective, if for all $y \in Y$, there is a unique $x \in X$ such that $f(x) = y.$[^o4][^o5][^o6]

The following are some facts related to bijections:

- A function $f \colon X \to Y$ is bijective if and only if it is invertible; that is, there is a function $g \colon Y \to X$ such that $g\circ f=$ identity function on $X$ and $f\circ g=$ identity function on $Y$. This function maps each image to its unique preimage.
- The composition of two bijections is again a bijection, but if $g\circ f$ is a bijection, then it can only be concluded that $f$ is injective and $g$ is surjective (see the figure at right and the remarks above regarding injections and surjections).
- The bijections from a set to itself form a [group](wikipedia://en/19447) under composition, called the [symmetric group](wikipedia://en/28901).

### Cardinality {#Cardinality}

Suppose that one wants to define what it means for two sets to "have the same number of elements". One way to do this is to say that two sets "have the same number of elements", if and only if all the elements of one set can be paired with the elements of the other, in such a way that each element is paired with exactly one element. Accordingly, one can define two sets to "have the same number of elements"—if there is a bijection between them. In which case, the two sets are said to have the same [cardinality](wikipedia://en/6174).

Likewise, one can say that set $X$ "has fewer than or the same number of elements" as set $Y$, if there is an injection from $X$ to $Y$; one can also say that set $X$ "has fewer than the number of elements" in set $Y$, if there is an injection from $X$ to $Y$, but not a bijection between $X$ and $Y$.

## Examples {#Examples}

It is important to specify the domain and codomain of each function, since by changing these, functions which appear to be the same may have different properties.

**Injective and surjective (bijective)**

- The identity function id<sub>*X*</sub> for every non-empty set *X*, and thus specifically $\mathbf{R} \to \mathbf{R} : x \mapsto x.$
- $\mathbf{R}^+ \to \mathbf{R}^+ : x \mapsto x^2$, and thus also its inverse $\mathbf{R}^+ \to \mathbf{R}^+ : x \mapsto \sqrt{x}.$
- The [exponential function](wikipedia://en/9678) $\exp \colon \mathbf{R} \to \mathbf{R}^+ : x \mapsto \mathrm{e}^x$ (that is, the exponential function with its codomain restricted to its image), and thus also its inverse the [natural logarithm](wikipedia://en/21476) $\ln \colon \mathbf{R}^+ \to \mathbf{R} : x \mapsto \ln{x}.$ Here, $\mathbf{R}^+$ denotes the [positive real numbers](wikipedia://en/47172571).
- $$\mathbf{R} \to \mathbf{R} : x \mapsto x^3$$

**Injective and non-surjective**

- The exponential function $\exp \colon \mathbf{R} \to \mathbf{R} : x \mapsto \mathrm{e}^x.$

**Non-injective and surjective**

- $$\mathbf{R} \to \mathbf{R} : x \mapsto (x-1)x(x+1) = x^3 - x .$$
- $$\mathbf{R} \to [-1,1] : x \mapsto \sin(x).$$

**Non-injective and non-surjective**

- $$\mathbf{R} \to \mathbf{R}: x \mapsto \sin(x).$$
- $$\mathbf{R} \to \mathbf{R} : x \mapsto x^2$$

## Properties {#Properties}

- For every function $f$, let $X$ be a subset of the domain and $Y$ a subset of the codomain. One has always $X \subset f^{-1}(f(X))$ and $f(f^{-1}(Y)) \subset Y$, where $f(X)$ is the [image](wikipedia://en/71925) of $X$ and $f^{-1}(Y)$ is the [preimage](https://en.wikipedia.org/wiki/Preimage) of $Y$ under $f$. If $f$ is injective, then $X = f^{-1}(f(X))$, and if $f$ is surjective, then $f(f^{-1}(Y)) = Y$.
- For every function $h: X \to Y$, one can define a surjection $H : X \to h(X) : x \mapsto h(x)$ and an injection $I : h(X) \to Y : y \mapsto y$. It follows that $h = I \circ H$. This decomposition as the [composition](wikipedia://en/195947) of a surjection and an injection is unique [up to](wikipedia://en/44787) an isomorphism, in the sense that, given such a decomposition, there is a unique bijection $\varphi:h(X)\to H(X)$ such that $H(x)=\varphi(h(x))$ and $I(\varphi(h(x)))=h(x)$ for every $x\in X.$

:::

## Category theory {#Category_theory}

In the [category](wikipedia://en/53759) of [sets](wikipedia://en/26691), injections, surjections, and bijections correspond precisely to [monomorphisms](wikipedia://en/59538), [epimorphisms](wikipedia://en/59539), and [isomorphisms](wikipedia://en/14828), respectively.[^o16]

## History {#History}

The [Oxford English Dictionary](https://en.wikipedia.org/wiki/Oxford_English_Dictionary) records the use of the word *injection* as a noun by [S. Mac Lane](wikipedia://en/336574) in *[Bulletin of the American Mathematical Society](wikipedia://en/2668304)* (1950), and *injective* as an adjective by [Eilenberg](wikipedia://en/362501) and [Steenrod](https://en.wikipedia.org/wiki/Norman_Steenrod) in *Foundations of Algebraic Topology* (1952).[^o18]

However, it was not until the French [Bourbaki group](https://en.wikipedia.org/wiki/Bourbaki_group) coined the injective-surjective-bijective terminology in 1954 in *Théorie des ensembles* (both as nouns and adjectives) that they achieved widespread adoption.[^o19]
