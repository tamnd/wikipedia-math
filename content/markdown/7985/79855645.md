# Twisted diagonal (simplicial sets)

::: {#o1 .subject cue=lead name="Twisted diagonal"}

In [higher category theory](wikipedia://en/5274013) in [mathematics](wikipedia://en/18831), the **twisted diagonal** of a [simplicial set](wikipedia://en/1027784) (for [∞-categories](https://en.wikipedia.org/wiki/∞-category) also called the **twisted arrow ∞-category**) is a construction, which generalizes the [twisted diagonal of a category](wikipedia://en/79855641) to which it corresponds under the [nerve](wikipedia://en/5127933) construction. Since the twisted diagonal of a category is the [category of elements](wikipedia://en/4877413) of the [Hom functor](wikipedia://en/2741037), the twisted diagonal of an ∞-category can be used to define the [Hom functor of an ∞-category](https://en.wikipedia.org/wiki/Hom_functor_of_an_∞-category).

:::

## Twisted diagonal with the join operation {#Twisted_diagonal_with_the_join_operation}

For a simplicial set $A$ define a [bisimplicial set](wikipedia://en/79855594) and a simplicial set with the [opposite simplicial set](wikipedia://en/79855588) and the [join of simplicial sets](https://en.wikipedia.org/wiki/Join_%28simplicial_sets%29) by:[^o3]

$$\mathbf{Tw}(A)_{m,n} =\operatorname{Hom}((\Delta^m)^\mathrm{op}*\Delta^n,A),$$

$$\operatorname{Tw}(A) =\delta^*(\mathbf{Tw}(A)).$$

($\delta^*\colon \mathbf{bisSet}\rightarrow\mathbf{sSet}$ is the functor obtained by precomposition with the diagonal $\delta\colon\Delta\rightarrow\Delta\times\Delta$, hence $\delta^*(A)_n=A_{n,n}$.) The canonical morphisms $(\Delta^m)^\mathrm{op}\rightarrow(\Delta^m)^\mathrm{op}*\Delta^n\leftarrow\Delta^n$ induce canonical morphisms $\mathbf{Tw}(A)\rightarrow A^\mathrm{op}\boxtimes A$ and $\operatorname{Tw}(A)\rightarrow A^\mathrm{op}\times A$.[^o3]

## Twisted diagonal with the diamond operation {#Twisted_diagonal_with_the_diamond_operation}

For a simplicial set $A$ define a bisimplicial set and a simplicial set with the opposite simplicial set and the [diamond operation](wikipedia://en/79855628) by:[^o5]

$$\mathbf{Tw}_\diamond(A)_{m,n} =\operatorname{Hom}((\Delta^m)^\mathrm{op}\diamond\Delta^n,A),$$

$$\operatorname{Tw}_\diamond(A) =\delta^*(\mathbf{Tw}_\diamond(A)).$$

The canonical morphisms $(\Delta^m)^\mathrm{op}\rightarrow(\Delta^m)^\mathrm{op}\diamond\Delta^n\leftarrow\Delta^n$ induce canonical morphisms $\mathbf{Tw}_\diamond(A)\rightarrow A^\mathrm{op}\boxtimes A$ and $\operatorname{Tw}_\diamond(A)\rightarrow A^\mathrm{op}\times A$. The weak categorical equivalence $\gamma_{(\Delta^m)^\mathrm{op},\Delta^n}\colon (\Delta^m)^\mathrm{op}\diamond\Delta^n\rightarrow(\Delta^m)^\mathrm{op}*\Delta^n$ induces canonical morphisms $\mathbf{Tw}(A)\rightarrow\mathbf{Tw}_\diamond(A)$ and $\operatorname{Tw}(A)\rightarrow\operatorname{Tw}_\diamond(A)$.

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- Under the [nerve](wikipedia://en/5127933), the twisted diagonal of categories corresponds to the twisted diagonal of simplicial sets. Let $\mathcal{C}$ be a small category, then:[^o8]

$$N\operatorname{Tw}(\mathcal{C}) =\operatorname{Tw}(N\mathcal{C}).$$

- For an ∞-category $A$, the canonical map $\operatorname{Tw}(A)\rightarrow A^\mathrm{op}\times A$ is a [left fibration](https://en.wikipedia.org/wiki/Left_fibration). Therefore, the twisted diagonal $\operatorname{Tw}(A)$ is also an ∞-category.[^o9][^o10][^o11]
- For a Kan complex $A$, the canonical map $\operatorname{Tw}(A)\rightarrow A^\mathrm{op}\times A$ is a [Kan fibration](wikipedia://en/8992759). Therefore, the twisted diagonal $\operatorname{Tw}(A)$ is also a Kan complex.[^o12]
- For an ∞-category $A$, the canonical map $\mathbf{Tw}_\diamond(A)\rightarrow A^\mathrm{op}\boxtimes A$ is a left bifibration and the canonical map $\operatorname{Tw}_\diamond(A)\rightarrow A^\mathrm{op}\times A$ is a left fibration. Therefore, the simplicial set $\operatorname{Tw}_\diamond(A)$ is also an ∞-category.[^o13]
- For an ∞-category $A$, the canonical morphism $\operatorname{Tw}(A)\rightarrow\operatorname{Tw}_\diamond(A)$ is a fiberwise equivalence of left fibrations over $A^\mathrm{op}\times A$.[^o14]
- A functor $u\colon A\rightarrow B$ between ∞-categories $A$ and $B$ is [fully faithful](wikipedia://en/876534) if and only if the induced map:

$$\operatorname{Tw}(A)\rightarrow(A^\mathrm{op}\times A)\times_{B^\mathrm{op}\times B}\operatorname{Tw}(B)$$

is a fiberwise equivalence over $A^\mathrm{op}\times A$.[^o15]

- For a functor $u\colon A\rightarrow B$ between ∞-categories $A$ and $B$, the induced maps:

$$\operatorname{Tw}(A)\rightarrow(A^\mathrm{op}\times B)\times_{B^\mathrm{op}\times B}\operatorname{Tw}(B),$$

$$\operatorname{Tw}(A)\rightarrow(B^\mathrm{op}\times A)\times_{B^\mathrm{op}\times B}\operatorname{Tw}(B),$$

are cofinal.[^o16]
