# Machine learning in biology

::: {#o1 .subject cue=lead name="Machine learning in biology"}

**Machine learning in bioinformatics** is the application of [machine learning](wikipedia://en/233488) algorithms to [bioinformatics](wikipedia://en/4214), including [genomics](https://en.wikipedia.org/wiki/Genomics), [proteomics](https://en.wikipedia.org/wiki/Proteomics), [microarrays](https://en.wikipedia.org/wiki/Microarrays), [systems biology](https://en.wikipedia.org/wiki/Systems_biology), [evolution](https://en.wikipedia.org/wiki/Evolution), and [text mining](wikipedia://en/318439).

:::

Prior to the emergence of machine learning, bioinformatics algorithms had to be programmed by hand; for problems such as [protein structure prediction](wikipedia://en/306769), this proved difficult.[^o2] Machine learning techniques such as [deep learning](https://en.wikipedia.org/wiki/Deep_learning) can [learn features](https://en.wikipedia.org/wiki/Feature_learning) of data sets rather than requiring the programmer to define them individually. The algorithm can further learn how to combine low-level [features](https://en.wikipedia.org/wiki/Feature_%28machine_learning%29) into more abstract features, and so on. This multi-layered approach allows such systems to make sophisticated predictions when appropriately trained. These methods contrast with other [computational biology](https://en.wikipedia.org/wiki/Computational_biology) approaches which, while exploiting existing datasets, do not allow the data to be interpreted and analyzed in unanticipated ways.

## Tasks {#Tasks}

Machine learning algorithms in bioinformatics can be used for prediction, classification, and feature detection and selection. Classification or recognition algorithms output a categorical class, while prediction algorithms output a numerical valued feature.

Algorithms differ in the type of process used to build the predictive models from data using analogies, rules, neural networks, probabilities, and/or statistics.

Advances in information technologies, artificial intelligence, and data mining, together with the growing availability of [open data sets](https://en.wikipedia.org/wiki/Open_data), have enabled the development of methods that can identify patterns and learn from data.

## Approaches {#Approaches}

### Artificial neural networks {#Artificial_neural_networks}

[Artificial neural networks](https://en.wikipedia.org/wiki/Artificial_neural_network) in bioinformatics have been used for:[^o6]

- Comparing and aligning RNA, protein, and DNA sequences.
- Identification of promoters and finding genes from sequences related to DNA.
- Interpreting the expression-gene and micro-array data.
- Identifying the network (regulatory) of genes.
- Learning evolutionary relationships by constructing [phylogenetic trees](wikipedia://en/149326).
- Classifying and predicting [protein structure](https://en.wikipedia.org/wiki/Protein_structure).
- [Molecular design](https://en.wikipedia.org/wiki/Molecular_modelling) and [docking](https://en.wikipedia.org/wiki/Docking_%28molecular%29)

### Feature engineering {#Feature_engineering}

The way that features, often vectors in a many-dimensional space, are extracted from the domain data is an important component of learning systems.[^o8] In genomics, a typical representation of a sequence is a vector of [k-mers](wikipedia://en/10573305) frequencies, which is a vector of dimension $4^k$ whose entries count the appearance of each subsequence of length $k$ in a given sequence. Since for a value as small as $k=12$ the dimensionality of these vectors is huge (e.g. in this case the dimension is $4^{12} \approx 16\times 10^6$), techniques such as [principal component analysis](wikipedia://en/76340) are used to project the data to a lower dimensional space, thus selecting a smaller set of features from the sequences.[^o8][^o9]

### Classification {#Classification}

In this type of machine learning task, the output is a discrete variable. One example of this type of task in bioinformatics is labeling new genomic data (such as genomes of unculturable bacteria) based on a model of already labeled data.[^o8]

#### Hidden Markov models {#Hidden_Markov_models}

[Hidden Markov models](https://en.wikipedia.org/wiki/Hidden_Markov_models) (HMMs) are a class of [statistical models](https://en.wikipedia.org/wiki/Statistical_models) for sequential data (often related to systems evolving over time). An HMM is composed of two mathematical objects: an observed state‐dependent process $X_1,X_2,\ldots ,X_M$, and an unobserved (hidden) state process $S_1,S_2,\ldots ,S_T$. In an HMM, the state process is not directly observed – it is a 'hidden' (or 'latent') variable – but observations are made of a state‐dependent process (or observation process) that is driven by the underlying state process (and which can thus be regarded as a noisy measurement of the system states of interest).[^o12] HMMs can be formulated in continuous time.[^o13][^o14]

HMMs can be used to profile and convert a multiple sequence alignment into a position-specific scoring system suitable for searching databases for homologous sequences remotely.[^o15] Additionally, ecological phenomena can be described by HMMs.[^o16]

#### Convolutional neural networks {#Convolutional_neural_networks}

[Convolutional neural networks](https://en.wikipedia.org/wiki/Convolutional_neural_network) (CNN) are a class of [deep neural network](https://en.wikipedia.org/wiki/Deep_neural_network) whose architecture is based on shared weights of convolution kernels or filters that slide along input features, providing translation-equivariant responses known as feature maps.[^o18][^o19] CNNs take advantage of the hierarchical pattern in data and assemble patterns of increasing complexity using smaller and simpler patterns discovered via their filters.[^o20]

Convolutional networks were [inspired](https://en.wikipedia.org/wiki/Mathematical_biology) by [biological](https://en.wikipedia.org/wiki/Biological) processes[^o21][^o22][^o23][^o24] in that the connectivity pattern between [neurons](wikipedia://en/349771) resembles the organization of the animal [visual cortex](https://en.wikipedia.org/wiki/Visual_cortex). Individual [cortical neurons](https://en.wikipedia.org/wiki/Cortical_neuron) respond to stimuli only in a restricted region of the [visual field](https://en.wikipedia.org/wiki/Visual_field) known as the [receptive field](https://en.wikipedia.org/wiki/Receptive_field). The receptive fields of different neurons partially overlap such that they cover the entire visual field.

CNN uses relatively little pre-processing compared to other [image classification algorithms](https://en.wikipedia.org/wiki/Image_classification). This means that the network learns to optimize the [filters](https://en.wikipedia.org/wiki/Filter_%28signal_processing%29) (or kernels) through automated learning, whereas in traditional algorithms these filters are [hand-engineered](wikipedia://en/46207323). This reduced reliance on prior knowledge of the analyst and on human intervention in manual feature extraction makes CNNs a desirable model.[^o20]

A phylogenetic convolutional neural network (Ph-CNN) is a [convolutional neural network](https://en.wikipedia.org/wiki/Convolutional_neural_network) architecture proposed by Fioranti et al. in 2018 to classify [metagenomics](https://en.wikipedia.org/wiki/Metagenomics) data.[^o25] In this approach, phylogenetic data is endowed with patristic distance (the sum of the lengths of all branches connecting two [operational taxonomic units](https://en.wikipedia.org/wiki/Operational_taxonomic_unit) \[OTU\]) to select k-neighborhoods for each OTU, and each OTU and its neighbors are processed with convolutional filters.

#### Self-supervised learning (Attention and Transformer Models) {#Self-supervised_learning_(Attention_and_Transformer_Models)}

*Image: Models for Biological Sequence Representation.jpg.* A comparison of three machine learning models used to generate vector representations (embeddings) from biological sequences, including the transformer architecture

Unlike supervised methods, [self-supervised learning](wikipedia://en/67902375) methods learn representations without relying on annotated data. That is well-suited for genomics, where [high throughput sequencing](https://en.wikipedia.org/wiki/High_throughput_sequencing) techniques can create potentially large amounts of unlabeled data. Some examples of self-supervised learning methods applied on genomics include DNABERT and Self-GenomeNet.[^o27][^o28]

Because of their parallelism and the ability to extract correlation across the whole sequences, [transformer-based models](https://en.wikipedia.org/wiki/Transformer-based_models) achieve [state-of-the-art](https://en.wikipedia.org/wiki/State-of-the-art) performance in a variety of important tasks such as machine translation and [question answering](https://en.wikipedia.org/wiki/Question_answering). The vanilla transformer model can be divided into two parts: [encoder](https://en.wikipedia.org/wiki/Encoder) and [decoder](https://en.wikipedia.org/wiki/Decoder), which have similar basic architectures composed of a stack of identical blocks. Each block consists of two kinds of sub-layers: the multi-head attention sub-layer and the position-wise feed-forward sub-layer. Both kinds of sublayers are followed by layer normalization. A residual connection around every sub-layer will be applied in each block to speed up the training process.[^o29]

##### Attention modules {#Attention_modules}

*Image: Process of a Single Attention Head in a Transformer Model.jpg.* Visual representation of the self-attention mechanism within a single transformer attention head, showing the transformation into query, key, and value vectors and the weighted scoring process

The key innovation in the [Transformer architecture](https://en.wikipedia.org/wiki/Transformer_%28deep_learning%29) is the multi-head self-attention layer, which can relate all relevant tokens to better encode every word or residue in the input sequence. The self-attention layer takes a sequence of tokens as input (tokens equivalent to words in a language or [amino acids](https://en.wikipedia.org/wiki/Amino_acid)/[nucleotides](https://en.wikipedia.org/wiki/Nucleotide) in a sequence) and learns sequence-wide context information. Multi-head attention represents multiple simultaneous attention heads. Before calculating the attention function, each token embedding is transformed into three corresponding vectors: the $Query (Q)$, the $Key (K)$, and the $Value (V)$ vectors. This transformation is achieved by multiplying the token embedding with three randomly initialized, learnable parameter matrices, $W_Q$, $W_K$, and $W_V$.

The core attention function is computed by three steps:

1. *Scoring*: The attention head computes the dot products of the Query vector with all Key vectors.
1. *Scaling and Weighting*: Each dot product is divided by $\sqrt{d_k}$ (where $d_k$ is the dimension of the key vector) and a [Softmax function](wikipedia://en/6152185) is applied to obtain the weights on the Value vectors.
1. *Output*: The output of the attention function is the weighted sum of these Value vectors, which contains information for the entire sequence. The weight assigned to each value is computed by a compatibility function of the Query with the corresponding Key.

In the parallel computation of the attention function, a set of query, key, and value vectors are packed into matrices $Q$, $K$, and $V$. The attention function is computed as follows: ${Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$ When generalized to multi-head attention with $h$ heads, the results of the multiple heads (each assigned different parameters $W_Q$, $W_K$, $W_V$) are concatenated and once again projected with a parameter matrix $W^O$, resulting in the final output:$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) W^O \text{where } \text{head}_i = \text{Attention}(Q W^Q_i, K W^K_i, V W^V_i)$[^o29]

##### Position-wise feed-forward networks {#Position-wise_feed-forward_networks}

Except for the attention sub-layer, each block of the encoder and decoder contains a fully connected [feed-forward network](https://en.wikipedia.org/wiki/Feedforward_neural_network) (FFN), which is applied identically and independently to each token (position-wise). This layer consists of two linear transformations with a [Rectified Linear Unit](wikipedia://en/37862937) (ReLU) activation function in the middle. The FFN is computed as follows:${FFN}(x) = \text{max}(0, xW_1 + b_1)W_2 + b_2$ Here, $W_1, b_1, W_2,$ and $b_2$ are the learnable parameters of the network. This layer is responsible for translating the output of the attention mechanism into a form suitable for the next layer.[^o29]

##### Residual connection and layer normalization {#Residual_connection_and_layer_normalization}

Each encoder and decoder block contains two residual connections and two layer normalization layers. These are applied to both the multi-head self-attention output and the feed-forward network (FFN) output. Layer normalization can accelerate the training process of the model by normalizing the output of the former layers to make it converge faster. The formulas are as follows: $\begin{aligned} \text{LayerNorm}(X + \text{MultiHeadAttention}(X)) \text{LayerNorm}(X + \text{FeedForward}(X)) \end{aligned}$ The variable $X$ represents the input of the multi-head self-attention or FFN. This original input is added to the sub-layer's output, forming a residual connection. For deep networks, the residual connection helps defend against vanishing and exploding gradients by keeping the original input signal, which stabilizes the training process.[^o29]

#### Random forest {#Random_forest}

*Image: Some bioinformatic applications of Random Forest.jpg.* Some bioinformatic applications of random forest

[Random forests](wikipedia://en/1363880) (RF) classify by constructing an ensemble of [decision trees](https://en.wikipedia.org/wiki/Decision_trees), and outputting the average prediction of the individual trees.[^o34] This is a modification of [bootstrap aggregating](wikipedia://en/1307911) (which aggregates a large collection of decision trees) and can be used for [classification](wikipedia://en/232426) or [regression](wikipedia://en/826997).[^o35][^o36]

As random forests give an internal estimate of generalization error, cross-validation is unnecessary. In addition, they produce proximities, which can be used to impute missing values, and which enable novel data visualizations.[^o37]

Computationally, random forests are appealing because they naturally handle both regression and (multiclass) classification, are relatively fast to train and to predict, depend only on one or two tuning parameters, have a built-in estimate of the generalization error, can be used directly for high-dimensional problems, and can easily be implemented in parallel. Statistically, random forests are appealing for additional features, such as measures of variable importance, differential class weighting, missing value imputation, visualization, outlier detection, and unsupervised learning.[^o37]

### Clustering {#Clustering}

[Clustering](wikipedia://en/669675) - the partitioning of a data set into disjoint subsets, so that the data in each subset are as close as possible to each other and as distant as possible from data in any other subset, according to some defined [distance](https://en.wikipedia.org/wiki/Metric_%28mathematics%29) or [similarity](wikipedia://en/1004743) function - is a common technique for statistical data analysis.

Clustering is central to much data-driven bioinformatics research and serves as a powerful computational method whereby means of hierarchical, centroid-based, distribution-based, density-based, and self-organizing maps classification, has long been studied and used in classical machine learning settings. Particularly, clustering helps to analyze unstructured and high-dimensional data in the form of sequences, expressions, texts, images, and so on. Clustering is also used to gain insights into biological processes at the [genomic](https://en.wikipedia.org/wiki/Genomic) level, e.g. gene functions, cellular processes, subtypes of cells, [gene regulation](https://en.wikipedia.org/wiki/Gene_regulation), and metabolic processes.[^o39]

#### Clustering algorithms used in bioinformatics {#Clustering_algorithms_used_in_bioinformatics}

Data clustering algorithms can be hierarchical or partitional. Hierarchical algorithms find successive clusters using previously established clusters, whereas partitional algorithms determine all clusters at once. Hierarchical algorithms can be agglomerative (bottom-up) or divisive (top-down).

Agglomerative algorithms begin with each element as a separate cluster and merge them in successively larger clusters. Divisive algorithms begin with the whole set and proceed to divide it into successively smaller clusters. [Hierarchical clustering](wikipedia://en/477573) is calculated using metrics on [Euclidean spaces](https://en.wikipedia.org/wiki/Euclidean_spaces), the most commonly used is the [Euclidean distance](wikipedia://en/53932) computed by finding the square of the difference between each variable, adding all the squares, and finding the square root of the said sum. An example of a [hierarchical clustering](wikipedia://en/477573) algorithm is [BIRCH](https://en.wikipedia.org/wiki/BIRCH), which is particularly good on bioinformatics for its nearly linear [time complexity](wikipedia://en/405944) given generally large datasets.[^o41] Partitioning algorithms are based on specifying an initial number of groups, and iteratively reallocating objects among groups to convergence. This algorithm typically determines all clusters at once. Most applications adopt one of two popular heuristic methods: [k-means](https://en.wikipedia.org/wiki/K-means) algorithm or [k-medoids](wikipedia://en/6406095). Other algorithms do not require an initial number of groups, such as [affinity propagation](https://en.wikipedia.org/wiki/Affinity_propagation). In a genomic setting this algorithm has been used both to cluster biosynthetic gene clusters in gene cluster families(GCF) and to cluster said GCFs.[^o42]

### Workflow {#Workflow}

Typically, a workflow for applying machine learning to biological data goes through four steps:[^o44]

- *Recording,* including capture and storage. In this step, different information sources may be merged into a single set.
- *Preprocessing,* including cleaning and restructuring into a ready-to-analyze form. In this step, uncorrected data are eliminated or corrected, while missing data maybe imputed and relevant variables chosen.
- *Analysis,* evaluating data using either supervised or unsupervised algorithms. The algorithm is typically trained on a subset of data, optimizing parameters, and evaluated on a separate test subset.
- *Visualization and interpretation,* where knowledge is represented effectively using different methods to assess the significance and importance of the findings.

### Data errors {#Data_errors}

- Duplicate data is a significant issue in bioinformatics. Publicly available data may be of uncertain quality.[^o46]
- Errors during experimentation.[^o46]
- Erroneous interpretation.[^o46]
- Typing mistakes.[^o46]
- Non-standardized methods (3D structure in PDB from multiple sources, X-ray diffraction, theoretical modeling, nuclear magnetic resonance, etc.) are used in experiments.[^o46]

## Applications {#Applications}

In general, a machine learning system can usually be trained to recognize elements of a certain class given sufficient samples.[^o49] For example, machine learning methods can be trained to identify specific visual features such as splice sites.[^o50]

[Support vector machines](https://en.wikipedia.org/wiki/Support-vector_machine) have been extensively used in cancer genomic studies.[^o51] In addition, [deep learning](https://en.wikipedia.org/wiki/Deep_learning) has been incorporated into bioinformatic algorithms. Deep learning applications have been used for regulatory genomics and cellular imaging.[^o52] Other applications include medical image classification, genomic sequence analysis, as well as protein structure classification and prediction.[^o53] Deep learning has been applied to regulatory genomics, variant calling and pathogenicity scores.[^o54] [Natural language processing](https://en.wikipedia.org/wiki/Natural_language_processing) and [text mining](wikipedia://en/318439) have helped to understand phenomena including protein-protein interaction, gene-disease relation as well as predicting biomolecule structures and functions.[^o55]

### Precision/personalized medicine {#Precision/personalized_medicine}

[Natural language processing](https://en.wikipedia.org/wiki/Natural_Language_Processing) algorithms [personalized medicine](https://en.wikipedia.org/wiki/Personalized_medicine) for patients who suffer genetic diseases, by combining the extraction of clinical information and genomic data available from the patients. Institutes such as Health-funded Pharmacogenomics Research Network focus on finding breast cancer treatments.[^o55]

[Precision medicine](https://en.wikipedia.org/wiki/Precision_medicine) considers individual genomic variability, enabled by large-scale biological databases. Machine learning can be applied to perform the matching function between (groups of patients) and specific treatment modalities.[^o55]

Computational techniques are used to solve other problems, such as efficient primer design for [PCR](https://en.wikipedia.org/wiki/Polymerase_chain_reaction), biological-image analysis and back translation of proteins (which is, given the degeneration of the genetic code, a complex combinatorial problem).[^o44]

### Genomics {#Genomics}

*Image: Growth of GenBank.png.* The growth of GenBank, a genomic sequence database provided by the [National Center for Biotechnology Information](https://en.wikipedia.org/wiki/National_Center_for_Biotechnology_Information) (NCBI)

While genomic sequence data has historically been sparse due to the technical difficulty of sequencing a piece of DNA, the number of available sequences is growing. On average, the number of [bases](https://en.wikipedia.org/wiki/Base_%28genetics%29) available in the [GenBank](https://en.wikipedia.org/wiki/GenBank) public repository has doubled every 18 months since 1982.[^o58] However, while [raw data](wikipedia://en/6895400) was becoming increasingly available and accessible, , biological interpretation of this data was occurring at a much slower pace.[^o59] This made for an increasing need for developing [computational genomics](https://en.wikipedia.org/wiki/Computational_genomics) tools, including machine learning systems, that can automatically determine the location of protein-encoding genes within a given DNA sequence (i.e. [gene prediction](https://en.wikipedia.org/wiki/Gene_prediction)).[^o59]

Gene prediction is commonly performed through both *extrinsic searches* and *intrinsic searches*.[^o59] For the extrinsic search, the input DNA sequence is run through a large database of sequences whose genes have been previously discovered and their locations annotated and identifying the target sequence's genes by determining which strings of bases within the sequence are [homologous](https://en.wikipedia.org/wiki/Homology_%28biology%29) to known gene sequences. However, not all the genes in a given input sequence can be identified through homology alone, due to limits in the size of the database of known and annotated gene sequences. Therefore, an intrinsic search is needed where a gene prediction program attempts to identify the remaining genes from the DNA sequence alone.[^o59]

Machine learning has also been used for the problem of [multiple sequence alignment](wikipedia://en/4066308) which involves aligning many DNA or amino acid sequences in order to determine regions of similarity that could indicate a shared evolutionary history.[^o44] It can also be used to detect and visualize genome rearrangements.[^o60]

### Proteomics {#Proteomics}

*Image: C16orf95 protein secondary structure prediction.png.* A protein's amino acid sequence annotated with the protein secondary structure. Each amino acid is labeled as either an alpha helix, a beta-sheet, or a coil.

[Proteins](https://en.wikipedia.org/wiki/Protein), strings of [amino acids](https://en.wikipedia.org/wiki/Amino_acid), gain much of their function from [protein folding](https://en.wikipedia.org/wiki/Protein_folding), where they conform into a three-dimensional structure, including the [primary structure](https://en.wikipedia.org/wiki/Protein_primary_structure), the [secondary structure](https://en.wikipedia.org/wiki/Protein_secondary_structure) ([alpha helices](https://en.wikipedia.org/wiki/Alpha_helix) and [beta sheets](https://en.wikipedia.org/wiki/Beta_sheet)), the [tertiary structure](https://en.wikipedia.org/wiki/Protein_tertiary_structure), and the [quaternary structure](https://en.wikipedia.org/wiki/Protein_quaternary_structure).

Protein secondary structure prediction is a main focus of this subfield as tertiary and quaternary structures are determined based on the secondary structure.[^o2] Solving the true structure of a protein is expensive and time-intensive, furthering the need for systems that can accurately predict the structure of a protein by analyzing the amino acid sequence directly.[^o2][^o44] Prior to machine learning, researchers needed to conduct this prediction manually. This trend began in 1951 when Pauling and Corey released their work on predicting the hydrogen bond configurations of a protein from a polypeptide chain.[^o62] Automatic feature learning reaches an accuracy of 82-84%.[^o2][^o63] Recent approaches have utilized deep learning techniques for state-of-the-art secondary structure predictions. For example, DeepCNF (deep convolutional neural fields) achieved an accuracy of approximately 84% when tasked to classify the amino acids of a protein sequence into one of three structural classes (helix, sheet, or coil).[^o63] The theoretical limit for three-state protein secondary structure is 88–90%.[^o2] In 2018, [AlphaFold](https://en.wikipedia.org/wiki/AlphaFold), an [artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence) (AI) program developed by [DeepMind](https://en.wikipedia.org/wiki/DeepMind), placed first in the overall rankings of the 13th [Critical Assessment of Structure Prediction](https://en.wikipedia.org/wiki/Critical_Assessment_of_Structure_Prediction) (CASP). It was particularly successful at predicting the most accurate structures for targets rated as most difficult by the competition organizers, where no existing [template structures](https://en.wikipedia.org/wiki/Threading_%28protein_sequence%29) were available from [proteins](https://en.wikipedia.org/wiki/Proteins) with partially similar sequences. AlphaFold 2 (2020) repeated this placement in the CASP14 competition and achieved a level of accuracy much higher than any other entry.[^o64][^o65][^o66]

Machine learning has also been applied to proteomics problems such as [protein side-chain](https://en.wikipedia.org/wiki/Side_chain) prediction, [protein loop](https://en.wikipedia.org/wiki/Turn_%28biochemistry%29) modeling, and [protein contact map](https://en.wikipedia.org/wiki/Protein_contact_map) prediction.[^o44]

### Metagenomics {#Metagenomics}

[Metagenomics](https://en.wikipedia.org/wiki/Metagenomics) is the study of microbial communities from environmental DNA samples.[^o68] Currently, limitations and challenges predominate in the implementation of machine learning tools due to the amount of data in environmental samples.[^o69] Supercomputers and web servers have made access to these tools easier.[^o70] The high dimensionality of microbiome datasets is a major challenge in studying the microbiome; this significantly limits the power of current approaches for identifying true differences and increases the chance of false discoveries.[^o71]

Despite their importance, machine learning tools related to metagenomics have focused on the study of gut microbiota and the relationship with digestive diseases, such as [inflammatory bowel disease](https://en.wikipedia.org/wiki/Inflammatory_bowel_disease) (IBD), *[Clostridioides difficile](https://en.wikipedia.org/wiki/Clostridioides_difficile)* infection (CDI), [colorectal cancer](https://en.wikipedia.org/wiki/Colorectal_cancer) and [diabetes](https://en.wikipedia.org/wiki/Diabetes), seeking better diagnosis and treatments.[^o70] Many algorithms were developed to classify microbial communities according to the health condition of the host, regardless of the type of sequence data, e.g. [16S rRNA](https://en.wikipedia.org/wiki/16S_rRNA) or [whole-genome sequencing](https://en.wikipedia.org/wiki/Whole-genome_sequencing) (WGS), using methods such as least absolute shrinkage and selection operator classifier, [random forest](wikipedia://en/1363880), supervised classification model, and gradient boosted tree model. [Neural networks](https://en.wikipedia.org/wiki/Neural_networks), such as [recurrent neural networks](wikipedia://en/1706303) (RNN), [convolutional neural networks](https://en.wikipedia.org/wiki/Convolutional_neural_network) (CNN), and [Hopfield neural networks](https://en.wikipedia.org/wiki/Hopfield_neural_network) have been added.[^o70] For example, in 2018, Fioravanti et al. developed an algorithm called Ph-CNN to classify data samples from healthy patients and patients with IBD symptoms (to distinguish healthy and sick patients) by using phylogenetic trees and convolutional neural networks.[^o72]

In addition, [random forest](wikipedia://en/1363880) (RF) methods and implemented importance measures help in the identification of microbiome species that can be used to distinguish diseased and non-diseased samples. However, the performance of a decision tree and the diversity of decision trees in the ensemble significantly influence the performance of RF algorithms. The generalization error for RF measures how accurate the individual classifiers are and their interdependence. Therefore, the high dimensionality problems of microbiome datasets pose challenges. Effective approaches require many possible variable combinations, which exponentially increases the computational burden as the number of features increases.[^o71]

For microbiome analysis in 2020 Dang & Kishino[^o71] developed a novel analysis pipeline. The core of the pipeline is an RF classifier coupled with forwarding [variable selection](https://en.wikipedia.org/wiki/Variable_selection) (RF-FVS), which selects a minimum-size core set of microbial species or functional signatures that maximize the predictive classifier performance. The framework combines:

- identifying a few significant features by a massively parallel forward [variable selection](https://en.wikipedia.org/wiki/Variable_selection) procedure
- mapping the selected species on a [phylogenetic tree](wikipedia://en/149326), and
- predicting functional profiles by functional gene enrichment analysis from metagenomic [16S rRNA](https://en.wikipedia.org/wiki/16S_rRNA) data.

They demonstrated performance by analyzing two published datasets from large-scale case-control studies:

- 16S rRNA gene amplicon data for *C. difficile* infection (CDI) and
- shotgun metagenomics data for human colorectal cancer (CRC).

The proposed approach improved the accuracy from 81% to 99.01% for CDI and from 75.14% to 90.17% for CRC.

The use of machine learning in environmental samples has been less explored, maybe because of data complexity, especially from WGS. Some works show that it is possible to apply these tools in environmental samples. In 2021 Dhungel et al.,[^o73] designed an R package called MegaR. This package allows working with 16S rRNA and whole metagenomic sequences to make taxonomic profiles and classification models by machine learning models. MegaR includes a comfortable visualization environment to improve the user experience. Machine learning in environmental metagenomics can help to answer questions related to the interactions between microbial communities and ecosystems, e.g. the work of Xun et al., in 2021[^o74] where the use of different machine learning methods offered insights on the relationship among the soil, microbiome biodiversity, and ecosystem stability.

### Microarrays {#Microarrays}

[Microarrays](https://en.wikipedia.org/wiki/Microarray), a type of [lab-on-a-chip](https://en.wikipedia.org/wiki/Lab-on-a-chip), are used for automatically collecting data about large amounts of biological material. Machine learning can aid in analysis, and has been applied to expression pattern identification, classification, and genetic network induction.[^o44]

*Image: DNA-microarray analysis.jpg.* A DNA-microarray analysis of Burkitt's lymphoma and diffuse large B-cell lymphoma (DLBCL), which differences in gene expression patterns

This technology is especially useful for monitoring gene expression, aiding in diagnosing cancer by examining which genes are expressed.[^o76] One of the main tasks is identifying which genes are expressed based on the collected data.[^o44] In addition, due to the huge number of genes on which data is collected by the microarray, winnowing the large amount of irrelevant data to the task of expressed gene identification is challenging. Machine learning presents a potential solution as various classification methods can be used to perform this identification. The most commonly used methods are [radial basis function networks](wikipedia://en/9651443), [deep learning](https://en.wikipedia.org/wiki/Deep_learning), [Bayesian classification](wikipedia://en/87339), [decision trees](wikipedia://en/232602), and [random forest](wikipedia://en/1363880).[^o76]

### Systems biology {#Systems_biology}

Systems biology focuses on the study of emergent behaviors from complex interactions of simple biological components in a system. Such components can include DNA, RNA, proteins, and metabolites.[^o78]

Machine learning has been used to aid in modeling these interactions in domains such as genetic networks, signal transduction networks, and metabolic pathways.[^o44] [Probabilistic graphical models](wikipedia://en/447298), a machine learning technique for determining the relationship between different variables, are one of the most commonly used methods for modeling genetic networks.[^o44] In addition, machine learning has been applied to systems biology problems such as identifying [transcription factor binding sites](https://en.wikipedia.org/wiki/DNA_binding_site) using [Markov chain optimization](wikipedia://en/60876).[^o44] [Genetic algorithms](https://en.wikipedia.org/wiki/Genetic_algorithm), machine learning techniques which are based on the natural process of evolution, have been used to model genetic networks and regulatory structures.[^o44]

Other systems biology applications of machine learning include the task of enzyme function prediction, high throughput microarray data analysis, analysis of genome-wide association studies to better understand markers of disease, protein function prediction.[^o79]

### Evolution {#Evolution}

This domain, particularly [phylogenetic tree](wikipedia://en/149326) reconstruction, uses the features of machine learning techniques. Phylogenetic trees are schematic representations of the evolution of organisms. Initially, they were constructed using features such as morphological and metabolic features. Later, due to the availability of genome sequences, the construction of the phylogenetic tree algorithm used the concept based on genome comparison. With the help of optimization techniques, a comparison was done by means of multiple sequence alignment.[^o81]

### Stroke diagnosis {#Stroke_diagnosis}

Machine learning methods for the analysis of [neuroimaging](https://en.wikipedia.org/wiki/Neuroimaging) data are used to help diagnose [stroke](https://en.wikipedia.org/wiki/Stroke). Historically multiple approaches to this problem involved neural networks.[^o83][^o84]

Multiple approaches to detect strokes used machine learning. As proposed by Mirtskhulava,[^o85] feed-forward networks were tested to detect strokes using neural imaging. As proposed by Titano[^o86] 3D-CNN techniques were tested in supervised classification to screen head CT images for acute neurologic events. Three-dimensional [CNN](https://en.wikipedia.org/wiki/Convolutional_neural_network) and [SVM](https://en.wikipedia.org/wiki/Support-vector_machine) methods are often used.[^o84]

### Text mining {#Text_mining}

The increase in biological publications increased the difficulty in searching and compiling relevant available information on a given topic. This task is known as [knowledge extraction](https://en.wikipedia.org/wiki/Knowledge_extraction). It is necessary for biological data collection which can then in turn be fed into machine learning algorithms to generate new biological knowledge.[^o44][^o88] Machine learning can be used for this knowledge extraction task using techniques such as [natural language processing](https://en.wikipedia.org/wiki/Natural_language_processing) to extract the useful information from human-generated reports in a database. [Text Nailing](https://en.wikipedia.org/wiki/Text_Nailing), an alternative approach to machine learning, capable of extracting features from clinical narrative notes was introduced in 2017.

This technique has been applied to the search for novel drug targets, as this task requires the examination of information stored in biological databases and journals.[^o88] Annotations of proteins in protein databases often do not reflect the complete known set of knowledge of each protein, so additional information must be extracted from biomedical literature. Machine learning has been applied to the automatic annotation of gene and protein function, determination of the [protein subcellular localization](https://en.wikipedia.org/wiki/Protein_targeting), [DNA-expression array](https://en.wikipedia.org/wiki/Gene_expression) analysis, large-scale [protein interaction](https://en.wikipedia.org/wiki/List_of_protein_interactions) analysis, and molecule interaction analysis.[^o88]

Another application of text mining is the detection and visualization of distinct DNA regions given sufficient reference data.[^o89]

### Clustering and abundance profiling of biosynthetic gene clusters {#Clustering_and_abundance_profiling_of_biosynthetic_gene_clusters}

Microbial communities are complex assembles of diverse microorganisms,[^o91] where symbiont partners constantly produce diverse metabolites derived from the primary and secondary (specialized) metabolism, from which metabolism plays an important role in microbial interaction.[^o92] Metagenomic and metatranscriptomic data are an important source for deciphering communications signals.

Molecular mechanisms produce specialized metabolites in various ways. [Biosynthetic Gene Clusters](https://en.wikipedia.org/wiki/Metabolic_gene_cluster) (BGCs) attract attention, since several metabolites are clinically valuable, anti-microbial, anti-fungal, anti-parasitic, anti-tumor and immunosuppressive agents produced by the modular action of multi-enzymatic, multi-domains gene clusters, such as [Nonribosomal peptide](https://en.wikipedia.org/wiki/Nonribosomal_peptide) synthetases (NRPSs) and [polyketide synthases](https://en.wikipedia.org/wiki/Polyketide_synthase) (PKSs).[^o93] Diverse studies[^o94][^o95][^o96][^o97][^o98][^o99][^o100][^o101] show that grouping BGCs that share homologous core genes into gene cluster families (GCFs) can yield useful insights into the chemical diversity of the analyzed strains, and can support linking BGCs to their secondary metabolites.[^o95][^o97] GCFs have been used as functional markers in human health studies[^o102][^o103] and to study the ability of soil to suppress fungal pathogens.[^o104] Given their direct relationship to catalytic enzymes, and compounds produced from their encoded pathways, BGCs/GCFs can serve as a proxy to explore the chemical space of microbial secondary metabolism. Cataloging GCFs in sequenced microbial genomes yields an overview of the existing chemical diversity and offers insights into future priorities.[^o94][^o96] Tools such as BiG-SLiCE and BIG-MAP[^o105] have emerged with the sole purpose of unveiling the importance of BGCs in natural environments.

### Decodification of RiPPs chemical structures {#Decodification_of_RiPPs_chemical_structures}

The increase of experimentally characterized [ribosomally synthesized and post-translationally modified peptides](https://en.wikipedia.org/wiki/Ribosomally_synthesized_and_post-translationally_modified_peptides) (RiPPs), together with the availability of information on their sequence and chemical structure, selected from databases such as BAGEL, BACTIBASE, MIBIG, and THIOBASE, provide the opportunity to develop machine learning tools to decode the chemical structure and classify them.

In 2017, researchers at the National Institute of Immunology of New Delhi, India, developed RiPPMiner[^o107] software, a bioinformatics resource for decoding RiPP chemical structures by genome mining. The RiPPMiner web server consists of a query interface and the RiPPDB database. RiPPMiner defines 12 subclasses of RiPPs, predicting the cleavage site of the leader peptide and the final cross-link of the RiPP chemical structure.

### Mass spectral similarity scoring {#Mass_spectral_similarity_scoring}

Many tandem mass spectrometry **(**MS/MS**)** based metabolomics studies, such as library matching and molecular networking, use spectral similarity as a proxy for structural similarity. Spec2vec[^o109] algorithm provides a new way of spectral similarity score, based on [Word2Vec](https://en.wikipedia.org/wiki/Word2vec). Spec2Vec learns fragmental relationships within a large set of spectral data, in order to assess spectral similarities between molecules and to classify unknown molecules through these comparisons.

For systemic annotation, some metabolomics studies rely on fitting measured fragmentation mass spectra to library spectra or contrasting spectra via network analysis. Scoring functions are used to determine the similarity between pairs of fragment spectra as part of these processes. So far, no research has suggested scores that are significantly different from the commonly utilized [cosine-based similarity](https://en.wikipedia.org/wiki/Cosine_similarity).[^o110]

## Databases {#Databases}

An important part of bioinformatics is the management of big datasets, known as databases of reference. Databases exist for each type of biological data, for example for biosynthetic gene clusters and metagenomes.

### General databases by bioinformatics {#General_databases_by_bioinformatics}

#### National Center for Biotechnology Information {#National_Center_for_Biotechnology_Information}

The National Center for Biotechnology Information (NCBI)[^o114] provides a large suite of online resources for biological information and data, including the [GenBank](https://en.wikipedia.org/wiki/GenBank) nucleic acid sequence database and the [PubMed](https://en.wikipedia.org/wiki/PubMed) database of citations and abstracts for published life science journals. Augmenting many of the Web applications are custom implementations of the BLAST program optimized to search specialized data sets. Resources include PubMed Data Management, RefSeq Functional Elements, genome data download, variation services API, Magic-BLAST, QuickBLASTp, and Identical Protein Groups. All of these resources can be accessed through NCBI.[^o115]

### Bioinformatics analysis for biosynthetic gene clusters {#Bioinformatics_analysis_for_biosynthetic_gene_clusters}

#### antiSMASH {#antiSMASH}

antiSMASH allows the rapid genome-wide identification, annotation and analysis of secondary metabolite biosynthesis gene clusters in bacterial and fungal genomes. It integrates and cross-links with a large number of in silico [secondary metabolite](https://en.wikipedia.org/wiki/Secondary_metabolite) analysis tools.[^o118]

#### gutSMASH {#gutSMASH}

gutSMASH is a tool that systematically evaluates bacterial metabolic potential by predicting both known and novel [anaerobic](https://en.wikipedia.org/wiki/Anaerobic_organism) metabolic gene clusters (MGCs) from the gut [microbiome](https://en.wikipedia.org/wiki/Microbiome).

#### MIBiG {#MIBiG}

MIBiG,[^o121] the minimum information about a biosynthetic gene cluster specification, provides a standard for annotations and [metadata](https://en.wikipedia.org/wiki/Metadata) on biosynthetic gene clusters and their molecular products. MIBiG is a Genomic Standards Consortium project that builds on the minimum information about any sequence (MIxS) framework.[^o122]

MIBiG facilitates the standardized deposition and retrieval of biosynthetic gene cluster data as well as the development of comprehensive comparative analysis tools. It assists next-generation research on the biosynthesis, chemistry and ecology of broad classes of societally relevant bioactive [secondary metabolites](https://en.wikipedia.org/wiki/Secondary_metabolites), guided by experimental evidence and metadata components.[^o123]

#### SILVA {#SILVA}

SILVA[^o125] is an interdisciplinary project among biologists and computers scientists assembling a complete database of RNA ribosomal (rRNA) sequences of genes, both small ([16S](https://en.wikipedia.org/wiki/16S_ribosomal_RNA), [18S](https://en.wikipedia.org/wiki/18S_ribosomal_RNA), SSU) and large ([23S](https://en.wikipedia.org/wiki/23S), [28S](https://en.wikipedia.org/wiki/28S), LSU) subunits, which belong to the bacteria, archaea and eukarya domains. These data are freely available for academic and commercial use.[^o126]

#### Greengenes {#Greengenes}

Greengenes[^o128] is a full-length [16S rRNA](https://en.wikipedia.org/wiki/16S_rRNA) gene database that provides chimera screening, standard alignment and a curated taxonomy based on de novo tree inference.[^o129][^o130] Overview:

- 1,012,863 RNA sequences from 92,684 organisms contributed to RNAcentral.
- The shortest sequence has 1,253 nucleotides, the longest 2,368.
- The average length is 1,402 nucleotides.
- Database version: 13.5.

#### Open Tree of Life Taxonomy {#Open_Tree_of_Life_Taxonomy}

Open Tree of Life Taxonomy (OTT)[^o132] aims to build a complete, dynamic, and digitally available Tree of Life by synthesizing published phylogenetic trees along with taxonomic data. Phylogenetic trees have been classified, aligned, and merged. Taxonomies have been used to fill in sparse regions and gaps left by phylogenies. OTT is a base that has been little used for sequencing analyzes of the 16S region, however, it has a greater number of sequences classified taxonomically down to the genus level compared to SILVA and Greengenes. However, in terms of classification at the edge level, it contains a lesser amount of information[^o133]

#### Ribosomal Database Project {#Ribosomal_Database_Project}

Ribosomal Database Project (RDP)[^o135] is a database that provides RNA ribosomal (rRNA) sequences of small subunits of domain bacterial and archaeal ([16S](https://en.wikipedia.org/wiki/16S_ribosomal_RNA)); and fungal rRNA sequences of large subunits ([28S](https://en.wikipedia.org/wiki/28S)).[^o136]
