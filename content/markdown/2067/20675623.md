# SANDstorm hash

::: {#o1 .subject cue=lead name="SANDstorm hash"}

The **SANDstorm hash**[^o3] is a [cryptographic hash function](wikipedia://en/439526) designed in 2008 by Mark Torgerson, [Richard Schroeppel](wikipedia://en/1649527), Tim Draelos, Nathan Dautenhahn, Sean Malone, Andrea Walker, Michael Collins, and Hilarie Orman for the [NIST SHA-3 competition](https://en.wikipedia.org/wiki/NIST_SHA-3_competition).

:::

The SANDstorm hash was accepted into the first round of the NIST hash function competition, but was not accepted into the second round.[^o4]

## Architecture {#Architecture}

The hash function has an explicit key schedule.[^o6] It uses an 8-bit by 8-bit [S-box](wikipedia://en/240991).[^o6] The hash function can be parallelized on a large range of platforms using [multi-core processing](https://en.wikipedia.org/wiki/Multi-core_processor).[^o7]

Both SANDstorm-256 and SANDstorm-512 run more than twice as slowly as [SHA-2](wikipedia://en/1638777) as measured by cpb.[^o6]

As of 2009, no [collision attack](wikipedia://en/969624) or [preimage attack](wikipedia://en/969477) against SANDstorm is known which is better than the trivial [birthday attack](wikipedia://en/189369) or long second preimage attack.[^o6]
