# Full reptend prime

::: {#o1 .subject cue=lead name="Full reptend prime"}

In [number theory](wikipedia://en/21527), a **full reptend prime**, **full repetend prime**, **proper prime**[^o2] or **long prime** in [base](wikipedia://en/701207) *b* is an [odd](wikipedia://en/143135) [prime number](wikipedia://en/23666) *p* such that the [Fermat quotient](wikipedia://en/22834255)

:::

$$q_p(b) = \frac{b^{p - 1} - 1}{p}$$

(where *p* does not [divide](wikipedia://en/49492) *b*) gives a [cyclic number](wikipedia://en/1672489). Therefore, the base *b* expansion of $1/p$ repeats the digits of the corresponding cyclic number infinitely, as does that of $a/p$ with rotation of the digits for any *a* between 1 and *p* − 1. The cyclic number corresponding to prime *p* will possess *p* − 1 digits [if and only if](wikipedia://en/14922) *p* is a full reptend prime. That is, the [multiplicative order](wikipedia://en/344542) ord<sub>*p*</sub> *b* = *p* − 1, which is equivalent to *b* being a [primitive root](wikipedia://en/186864) modulo *p*.

The term "long prime" was used by [John Conway](wikipedia://en/15807) and [Richard Guy](wikipedia://en/816308) in their *Book of Numbers*.

## Base 10 {#Base_10}

[Base 10](wikipedia://en/8214) may be assumed if no base is specified, in which case the expansion of the number is called a [repeating decimal](wikipedia://en/13612447). In base 10, if a full reptend prime ends in the digit 1, then each digit 0, 1, ..., 9 appears in the reptend the same number of times as each other digit.[^o2] (For such primes in base 10, see .) In fact, in base *b*, if a full reptend prime ends in the digit 1, then each digit 0, 1, ..., *b* − 1 appears in the repetend the same number of times as each other digit, but no such prime exists when *b* = 12, since every full reptend prime in [base 12](wikipedia://en/8400) ends in the digit 5 or 7 in the same base. Generally, no such prime exists when *b* is [congruent](wikipedia://en/20087) to 0 or 1 modulo 4.

The values of *p* for which this formula produces cyclic numbers in decimal are:

[7](https://en.wikipedia.org/wiki/7_%28number%29), [17](wikipedia://en/208288), [19](wikipedia://en/208292), [23](wikipedia://en/362203), [29](wikipedia://en/362212), [47](https://en.wikipedia.org/wiki/47_%28number%29), [59](https://en.wikipedia.org/wiki/59_%28number%29), [61](https://en.wikipedia.org/wiki/61_%28number%29), [97](https://en.wikipedia.org/wiki/97_%28number%29), [109](https://en.wikipedia.org/wiki/109_%28number%29), [113](https://en.wikipedia.org/wiki/113_%28number%29), [131](https://en.wikipedia.org/wiki/131_%28number%29), [149](https://en.wikipedia.org/wiki/149_%28number%29), [167](https://en.wikipedia.org/wiki/167_%28number%29), [179](https://en.wikipedia.org/wiki/179_%28number%29), [181](https://en.wikipedia.org/wiki/181_%28number%29), [193](https://en.wikipedia.org/wiki/193_%28number%29), [223](https://en.wikipedia.org/wiki/223_%28number%29), [229](https://en.wikipedia.org/wiki/229_%28number%29), [233](https://en.wikipedia.org/wiki/233_%28number%29), [257](https://en.wikipedia.org/wiki/257_%28number%29), [263](https://en.wikipedia.org/wiki/263_%28number%29), [269](https://en.wikipedia.org/wiki/269_%28number%29), [313](https://en.wikipedia.org/wiki/313_%28number%29), 337, 367, 379, 383, 389, 419, 433, 461, 487, 491, 499, 503, 509, 541, 571, 577, 593, 619, 647, 659, 701, 709, 727, 743, 811, 821, 823, 857, 863, 887, 937, 941, 953, 971, 977, 983, 1019, 1021, 1033, 1051...

This sequence is the set of primes *p* such that 10 is a [primitive root](wikipedia://en/186864) modulo *p*. [Artin's conjecture on primitive roots](wikipedia://en/2085185) is that this sequence contains 37.395...% of the primes.

## Binary full reptend primes {#Binary_full_reptend_primes}

In [base 2](https://en.wikipedia.org/wiki/Base_2), the full reptend primes are: (less than 1000)

3, 5, 11, 13, 19, 29, 37, 53, 59, 61, 67, 83, 101, 107, 131, 139, 149, 163, 173, 179, 181, 197, 211, 227, 269, 293, 317, 347, 349, 373, 379, 389, 419, 421, 443, 461, 467, 491, 509, 523, 541, 547, 557, 563, 587, 613, 619, 653, 659, 661, 677, 701, 709, 757, 773, 787, 797, 821, 827, 829, 853, 859, 877, 883, 907, 941, 947, ...

For these primes, 2 is a [primitive root](wikipedia://en/186864) modulo *p*, so 2<sup>*n*</sup> [modulo](https://en.wikipedia.org/wiki/Modulo_operation) *p* can be any [natural number](wikipedia://en/21474) between 1 and *p* − 1.

$$a(i) = 2^i \bmod p \bmod 2.$$

These sequences of period *p* − 1 have an autocorrelation function that has a negative peak of −1 for shift of $(p-1)/2$. The randomness of these sequences has been examined by [diehard tests](wikipedia://en/2167005).[^o5]

Binary full reptend prime sequences (also called maximum-length decimal sequences) have found [cryptographic](https://en.wikipedia.org/wiki/Cryptographic) and [error-correction coding](https://en.wikipedia.org/wiki/Error-correction_code) applications.[^o6] In these applications, repeating decimals to base 2 are generally used which gives rise to binary sequences. The maximum length binary sequence for $1/p$ (when 2 is a primitive root of *p*) is given by Kak.[^o7]
