# Set Theory: An Introduction to Independence Proofs

::: {#o1 .subject cue=lead name="Set Theory: An Introduction to Independence Proofs"}

***Set Theory: An Introduction to Independence Proofs*** is a textbook and reference work in [set theory](wikipedia://en/27553) by [Kenneth Kunen](https://en.wikipedia.org/wiki/Kenneth_Kunen). It starts from basic notions, including the [ZFC](https://en.wikipedia.org/wiki/ZFC) axioms, and quickly develops combinatorial notions such as [trees](wikipedia://en/704160), [Suslin's problem](wikipedia://en/228668), the [diamond principle](wikipedia://en/691736), and [Martin's axiom](wikipedia://en/1550783). It develops some basic [model theory](wikipedia://en/19858) (rather specifically aimed at models of set theory) and the theory of [Gödel's constructible universe](https://en.wikipedia.org/wiki/Gödel's_constructible_universe), *L*. The book then proceeds to describe the method of [forcing](wikipedia://en/152205).

:::

Kunen completely rewrote the book for the 2011 edition (under the title *Set Theory*), including more model theory.
