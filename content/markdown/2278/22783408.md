# Light's associativity test

::: {#o1 .subject cue=lead name="Light's associativity test"}

In [mathematics](wikipedia://en/18831), **Light's associativity test** is a procedure invented by F. W. Light for testing whether a [binary operation](wikipedia://en/3948) defined in a [finite set](wikipedia://en/11742) by a [Cayley multiplication table](wikipedia://en/1802723) is [associative](https://en.wikipedia.org/wiki/Associative). The naive procedure for verification of the associativity of a binary operation specified by a Cayley table, which compares the two products that can be formed from each triple of elements, is cumbersome. Light's associativity test simplifies the task in some instances (although it does not improve the worst-case runtime of the naive algorithm, namely $\mathcal{O} \left( n^{3} \right)$ for sets of size $n$).

:::

## Description of the procedure {#Description_of_the_procedure}

Let a binary operation ' · ' be defined in a finite set *A* by a Cayley table. Choosing some element *a* in *A*, two new binary operations are defined in *A* as follows:

$$x \star y = x \cdot ( a \cdot y )$$

$$x \circ y = (x \cdot a) \cdot y$$

The Cayley tables of these operations are constructed and compared. If the tables coincide then $x \cdot ( a \cdot y ) = ( x \cdot a ) \cdot y$ for all *x* and *y*. This is repeated for every element of the set *A*.

The example below illustrates a further simplification in the procedure for the construction and comparison of the Cayley tables of the operations ' $\star$ ' and ' $\circ$ '.

It is not even necessary to construct the Cayley tables of ' $\star$ ' and ' $\circ$ ' for *all* elements of *A*. It is enough to compare Cayley tables of ' $\star$ ' and ' $\circ$ ' corresponding to the elements in a proper generating subset of *A*.

When the operation ' · ' is [commutative](wikipedia://en/294390), then x $\star$ y = y $\circ$ x. As a result, only part of each Cayley table must be computed, because x $\star$ x = x $\circ$ x always holds, and x $\star$ y = x $\circ$ y implies y $\star$ x = y $\circ$ x.

When there is an [identity element](wikipedia://en/14962) e, it does not need to be included in the Cayley tables because x $\star$ y = x $\circ$ y always holds if at least one of x and y are equal to e.

### A further simplification {#A_further_simplification}

It is not necessary to construct the Cayley tables (Table 6 and table 11) of the binary operations ' $\star$ ' and ' $\circ$ '. It is enough to copy the column corresponding to the header ***c*** in Table 1 to the index column in Table 5 and form the following table (Table 14) and verify that the ***a***-row of Table 14 is identical with the ***a***-row of Table 1, the ***b***-row of Table 14 is identical with the ***b***-row of Table 1, etc. This is to be repeated *mutatis mutandis* for all the elements of the generating set of *A*.

*Table 14*

::: {#o19 .table cue=table name="Table 14"}

|  | *a* | *c* | *b* | *d* | *d* |
|---|---|---|---|---|---|
| ***a*** | *a* | *a* | *a* | *d* | *d* |
| ***c*** | *a* | *c* | *b* | *d* | *d* |
| ***b*** | *a* | *b* | *c* | *d* | *d* |
| ***d*** | *d* | *d* | *d* | *a* | *a* |
| ***e*** | *d* | *e* | *e* | *a* | *a* |

## Extension {#Extension}

Light's associativity test can be extended to test associativity in a more general context.[^o24][^o25]

Let *T* = { *t*<sub>1</sub>, *t*<sub>2</sub>, $\ldots$, *t*<sub>*m*</sub> } be a [magma](wikipedia://en/141916) in which the operation is denoted by [juxtaposition](https://en.wikipedia.org/wiki/Juxtaposition_%28literary%29). Let *X* = { *x*<sub>1</sub>, *x*<sub>2</sub>, $\ldots$, *x*<sub>*n*</sub> } be a set. Let there be a mapping from the [Cartesian product](wikipedia://en/24104095) *T* × *X* to *X* denoted by (*t*, *x*) *tx* and let it be required to test whether this map has the property

(*st*)*x* = *s*(*tx*) for all *s*, *t* in *T* and all *x* in *X*.

A generalization of Light's associativity test can be applied to verify whether the above property holds or not. In mathematical notations, the generalization runs as follows: For each *t* in *T*, let *L*(*t*) be the *m* × *n* matrix of elements of *X* whose *i* - th row is

( (*t*<sub>*i*</sub>*t*)*x*<sub>1</sub>, (*t*<sub>*i*</sub>*t*)*x*<sub>2</sub>, $\ldots$ , (*t*<sub>*i*</sub>*t*)*x*<sub>n</sub> ) for *i* = 1, $\ldots$, *m*

and let *R*(*t*) be the *m* × *n* matrix of elements of *X*, the elements of whose *j* - th column are

( *t*<sub>1</sub>(*tx*<sub>*j*</sub>), *t*<sub>2</sub>(*tx*<sub>*j*</sub>), $\ldots$ , *t*<sub>*m*</sub>(*tx*<sub>j</sub>) ) for *j* = 1, $\ldots$, *n*.

According to the generalised test (due to Bednarek), that the property to be verified holds if and only if *L*(*t*) = *R*(*t*) for all *t* in *T*. When *X* = *T*, Bednarek's test reduces to Light's test.

:::

## More advanced algorithms {#More_advanced_algorithms}

There is a randomized algorithm by Rajagopalan and [Schulman](https://en.wikipedia.org/wiki/Leonard_Schulman) to test associativity in time proportional to the input size. (The method also works for testing certain other identities.) Specifically, the runtime is $O(n^2 \log \frac1\delta)$ for an $n\times n$ table and error probability $\delta$. The algorithm can be modified to produce a triple $\langle a,b,c\rangle$ for which $(ab)c\ne a(bc)$, if there is one, in time $O(n^2 \log n \cdot\log \frac1\delta)$.[^o27]
