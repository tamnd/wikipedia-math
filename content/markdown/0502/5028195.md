# Suslin tree

::: {#o1 .subject cue=lead name="Suslin tree"}

In mathematics, a **Suslin tree** is a [tree](wikipedia://en/704160) of height [ω<sub>1</sub>](wikipedia://en/20860540) such that every branch and every [antichain](wikipedia://en/348973) is [countable](wikipedia://en/6026). They are named after [Mikhail Yakovlevich Suslin](https://en.wikipedia.org/wiki/Mikhail_Yakovlevich_Suslin).

:::

Every Suslin tree is an [Aronszajn tree](wikipedia://en/12774077).

The existence of a Suslin tree is [independent](wikipedia://en/1141208) of ZFC, and is equivalent to the existence of a [Suslin line](https://en.wikipedia.org/wiki/Suslin_line) (shown by (Kurepa 1935)) or a [Suslin algebra](wikipedia://en/43236771). The [diamond principle](wikipedia://en/691736), a consequence of [V=L](https://en.wikipedia.org/wiki/V=L), implies that there is a Suslin tree, and [Martin's axiom](wikipedia://en/1550783) MA(ℵ<sub>1</sub>) implies that there are no Suslin trees.

More generally, for any infinite cardinal κ, a κ-Suslin tree is a tree of height κ such that every branch and antichain has cardinality less than κ. In particular a Suslin tree is the same as a ω<sub>1</sub>-Suslin tree. (Jensen 1972) showed that if [V=L](https://en.wikipedia.org/wiki/V=L) then there is a κ-Suslin tree for every infinite [successor cardinal](wikipedia://en/375210) κ. Whether the [Generalized Continuum Hypothesis](https://en.wikipedia.org/wiki/Generalized_Continuum_Hypothesis) implies the existence of an ℵ<sub>2</sub>-Suslin tree, is a longstanding open problem.
