# Markov operator

::: {#o1 .subject cue=lead name="Markov operator"}

In [probability theory](wikipedia://en/23542) and [ergodic theory](wikipedia://en/258986), a **Markov operator** is an [operator](wikipedia://en/22213) on a certain [function space](wikipedia://en/340630) that conserves the mass (the so-called [Markov property](wikipedia://en/306422)). If the underlying [measurable space](wikipedia://en/43333) is [topologically](wikipedia://en/30450) sufficiently rich enough, then the Markov operator admits a [kernel](https://en.wikipedia.org/wiki/Probability_kernel) representation. Markov operators can be [linear](https://en.wikipedia.org/wiki/Linear_operator) or non-linear. Closely related to Markov operators is the **Markov semigroup**.[^o2]

:::

The definition of Markov operators is not entirely consistent in the literature. Markov operators are named after the Russian mathematician [Andrey Markov](wikipedia://en/915).

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

### Markov operator {#Markov_operator}

Let $(E,\mathcal{F})$ be a [measurable space](wikipedia://en/43333) and $V$ a set of real, measurable functions $f:(E,\mathcal{F})\to (\mathbb{R},\mathcal{B}(\mathbb{R}))$.

A linear operator $P$ on $V$ is a **Markov operator** if the following is true[^o2]

1. $P$ maps bounded, [measurable function](wikipedia://en/44055) on bounded, measurable functions.
1. Let $\mathbf{1}$ be the constant function $x\mapsto 1$, then $P(\mathbf{1})=\mathbf{1}$ holds. (*conservation of mass* / *Markov property*)
1. If $f\geq 0$ then $Pf\geq 0$. (*conservation of positivity*)

::: {#o7 .definition cue=heading name="Alternative definitions"}

#### Alternative definitions {#Alternative_definitions}

Some authors define the operators on the [L<sup>p</sup> spaces](wikipedia://en/45194) as $P:L^p(X)\to L^p(Y)$ and replace the first condition (bounded, measurable functions on such) with the property[^o8][^o9]

$$\|Pf\|_Y = \|f\|_X,\quad \forall f\in L^p(X)$$

:::

### Markov semigroup {#Markov_semigroup}

Let $\mathcal{P}=\{P_t\}_{t\geq 0}$ be a family of Markov operators defined on the set of bounded, measurables function on $(E,\mathcal{F})$. Then $\mathcal{P}$ is a **Markov semigroup** when the following is true[^o2]

1. $$P_0=\operatorname{Id}.$$
1. $P_{t+s}=P_t\circ P_s$ for all $t,s\geq 0$.
1. There exist a [σ-finite measure](wikipedia://en/4316174) $\mu$ on $(E,\mathcal{F})$ that is [invariant](wikipedia://en/7635201) under $\mathcal{P}$, that means for all bounded, positive and measurable functions $f:E\to \mathbb{R}$ and every $t\geq 0$ the following holds

$$\int_E P_tf\mathrm{d}\mu =\int_E f\mathrm{d}\mu.$$

### Dual semigroup {#Dual_semigroup}

Each Markov [semigroup](wikipedia://en/27799) $\mathcal{P}=\{P_t\}_{t\geq 0}$ induces a *dual semigroup* $(P^*_t)_{t\geq 0}$ through

$$\int_EP_tf\mathrm{d\mu} =\int_E f\mathrm{d}\left(P^*_t\mu\right).$$

If $\mu$ is invariant under $\mathcal{P}$ then $P^*_t\mu=\mu$.

### Infinitesimal generator of the semigroup {#Infinitesimal_generator_of_the_semigroup}

Let $\{P_t\}_{t\geq 0}$ be a family of bounded, linear Markov operators on the [Hilbert space](wikipedia://en/20598932) $L^2(\mu)$, where $\mu$ is an invariant measure. The **infinitesimal generator** $L$ of the Markov semigroup $\mathcal{P}=\{P_t\}_{t\geq 0}$ is defined as

$$Lf=\lim\limits_{t\downarrow 0}\frac{P_t f-f}{t},$$

and the domain $D(L)$ is the $L^2(\mu)$-space of all such functions where this limit exists and is in $L^2(\mu)$ again.[^o2][^o13]

$$D(L)=\left\{f\in L^2(\mu): \lim\limits_{t\downarrow 0}\frac{P_t f-f}{t}\text{ exists and is in } L^2(\mu)\right\}.$$

The [carré du champ operator](wikipedia://en/74738076) $\Gamma$ measures how far $L$ is from being a [derivation](wikipedia://en/897658).

### Kernel representation of a Markov operator {#Kernel_representation_of_a_Markov_operator}

A Markov operator $P_t$ has a kernel representation

$$(P_tf)(x)=\int_E f(y)p_t(x,\mathrm{d}y),\quad x\in E,$$

with respect to some [probability kernel](https://en.wikipedia.org/wiki/Probability_kernel) $p_t(x,A)$, if the underlying measurable space $(E,\mathcal{F})$ has the following sufficient topological properties:

1. Each [probability measure](wikipedia://en/45437) $\mu:\mathcal{F}\times \mathcal{F}\to [0,1]$ can be decomposed as $\mu(\mathrm{d}x,\mathrm{d}y)=k(x,\mathrm{d}y)\mu_1(\mathrm{d}x)$, where $\mu_1$ is the projection onto the first component and $k(x,\mathrm{d}y)$ is a probability kernel.
1. There exist a countable family that generates the [σ-algebra](wikipedia://en/29586) $\mathcal{F}$.

If one defines now a [σ-finite](https://en.wikipedia.org/wiki/Σ-finite) measure on $(E,\mathcal{F})$ then it is possible to prove that every Markov operator $P$ admits such a kernel representation with respect to $k(x,\mathrm{d}y)$.[^o2]
