# Stochastic homogenization

::: {#o1 .subject cue=lead name="Stochastic homogenization"}

In [homogenization theory](https://en.wikipedia.org/wiki/Homogenization_%28mathematics%29), a branch of [mathematics](wikipedia://en/18831), **stochastic homogenization** is a technique for understanding solutions to [partial differential equations](https://en.wikipedia.org/wiki/Partial_differential_equations) with [oscillatory](https://en.wikipedia.org/wiki/Oscillatory) [random](wikipedia://en/25685) coefficients.[^o2]

:::
