# Loop sectioning

::: {#o1 .subject cue=lead name="Loop sectioning"}

In [geometry](wikipedia://en/18973446) and the mathematical discipline of [topology](wikipedia://en/29954), **loop strip-mining**, or **sectioning**,[^o2] is a special case of [tiling](wikipedia://en/321671), namely 1-dimensional tiling: a loop is transformed into a depth-2 loop nest, where the outer loop is called tile/block loop and the innermost loop is called element loop. Strip-mining was introduced for [vector processors](https://en.wikipedia.org/wiki/Vector_processor). It is a loop-transformation technique for enabling vectorization of loops and improving memory performance.

:::

The term *strip-mine* is really inspired from mining coal, for example, with the excavator, which uses a bucket (or bucket wheel) to "strip" the coal.
