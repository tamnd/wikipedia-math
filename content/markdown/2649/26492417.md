# Hypercyclic operator

::: {#o1 .subject cue=lead name="Hypercyclic operator"}

In [mathematics](wikipedia://en/18831), especially [functional analysis](wikipedia://en/11180), a **hypercyclic operator** on a [topological vector space](wikipedia://en/45752) *X* is a continuous [linear operator](https://en.wikipedia.org/wiki/Linear_operator) *T*: *X* → *X* such that there is a vector *x* ∈ *X* for which the sequence {*T*<sup>*n*</sup> *x*: *n* = 0, 1, 2, …} is [dense](wikipedia://en/23523594) in the whole space *X*. In other words, the smallest [closed](wikipedia://en/47279) invariant subset containing *x* is the whole space. Such an *x* is then called *hypercyclic vector*. There is no hypercyclic operator in [finite-dimensional](wikipedia://en/38267) spaces, but the property of hypercyclicity in spaces of infinite dimension is not a rare phenomenon: many operators are hypercyclic.

:::

The hypercyclicity is a special case of broader notions of *topological transitivity* (see [topological mixing](https://en.wikipedia.org/wiki/Topological_mixing)), and *universality*. *Universality* in general involves a set of mappings from one [topological space](wikipedia://en/30450) to another (instead of a sequence of powers of a single operator mapping from *X* to *X*), but has a similar meaning to hypercyclicity. Examples of universal objects were discovered already in 1914 by Julius Pál, in 1935 by [Józef Marcinkiewicz](https://en.wikipedia.org/wiki/Józef_Marcinkiewicz), or MacLane in 1952. However, it was not until the 1980s when hypercyclic operators started to be more intensively studied.

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

An example of a hypercyclic operator is two times the backward [shift operator](wikipedia://en/467384) on the [ℓ<sup>2</sup> sequence space](https://en.wikipedia.org/wiki/Lp_sequence_space), that is, the operator which takes a sequence

(*a*<sub>1</sub>, *a*<sub>2</sub>, *a*<sub>3</sub>, …) ∈ ℓ<sup>2</sup>

to the sequence

(2*a*<sub>2</sub>, 2*a*<sub>3</sub>, 2*a*<sub>4</sub>, …) ∈ ℓ<sup>2</sup>.

This was [proved](wikipedia://en/82285) in 1969 by Rolewicz.

:::

## Known results {#Known_results}

- On every infinite-dimensional [separable](wikipedia://en/27855) [Fréchet space](wikipedia://en/233801) there is a hypercyclic operator. On the other hand, there is no hypercyclic operator on a finite-dimensional space, nor on a non-separable space.
- If *x* is a hypercyclic vector, then *T*<sup>*n*</sup>*x* is hypercyclic as well, so there is always a dense set of hypercyclic vectors.
- Moreover, the set of hypercyclic vectors is a [connected](wikipedia://en/87141) [*G*<sub>δ</sub>](https://en.wikipedia.org/wiki/G_delta) set when *X* is a [metrizable space](wikipedia://en/19738), and always contains a dense [vector space](wikipedia://en/32370), up to {0}.
- (txt) constructed an operator on [ℓ<sup>1</sup>](https://en.wikipedia.org/wiki/Lp_sequence_space), such that all the non-zero vectors are hypercyclic, providing a [counterexample](wikipedia://en/143151) to the [invariant subspace problem](wikipedia://en/691927) (and even the *invariant subset problem*) in the class of [Banach spaces](wikipedia://en/3989). The problem, whether such an operator (sometimes called *hypertransitive*, or *orbit transitive*) exists on a separable Hilbert space, is still [open](wikipedia://en/1333335) (as of 2022).
