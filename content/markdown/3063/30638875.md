# Damping matrix

::: {#o1 .subject cue=lead name="Damping matrix"}

In [applied mathematics](wikipedia://en/24295969), a **damping matrix** is a matrix corresponding to any of certain systems of linear ordinary differential equations. A damping [matrix](wikipedia://en/20556859) is defined as follows. If the system has *n* [degrees of freedom](wikipedia://en/2321587) *u*<sub>*n*</sub> and is under application of *m* [damping](https://en.wikipedia.org/wiki/Damping_ratio) [forces](https://en.wikipedia.org/wiki/Force). Each [force](https://en.wikipedia.org/wiki/Force) can be expressed as follows:

:::

$$f_{Di}=c_{i1} \dot{u_1}+c_{i2} \dot{u_2}+\cdots+c_{in} \dot{u_n}=\sum_{j=1}^n c_{i,j}\dot{u_j}$$

It yields in [matrix](wikipedia://en/20556859) form;

$$F_D=C \dot{U}$$

where **C is the damping matrix** composed by the damping coefficients:

$$C=(c_{i,j})_{1\le i\le n,1\le j\le m}$$
