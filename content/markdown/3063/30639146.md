# Wiener's attack

::: {#o1 .subject cue=lead name="Wiener's attack"}

The **Wiener's attack**, named after cryptologist Michael J. Wiener, is a type of [cryptographic attack](https://en.wikipedia.org/wiki/Cryptographic_attack) against [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29). The attack uses [continued fraction representation](wikipedia://en/46802) to expose the private key *d* when *d* is small.

:::

## Background on RSA {#Background_on_RSA}

Fictional characters [Alice and Bob](wikipedia://en/679079) are people who want to communicate securely. More specifically, Alice wants to send a message to Bob which only Bob can read. First Bob chooses two secret [primes](https://en.wikipedia.org/wiki/Primes) *p* and *q*. Then he calculates the RSA [modulus](wikipedia://en/20087) *N* = *pq*. This RSA modulus is made public together with the [encryption](wikipedia://en/10294) exponent *e*. *N* and *e* form the public key pair (*e*, *N*). By making this information public, anyone can [encrypt](https://en.wikipedia.org/wiki/Encrypt) messages to Bob. The [decryption](https://en.wikipedia.org/wiki/Decryption) exponent *d* satisfies *ed* ≡ 1 (mod *λ*(*N*)), where *λ*(*N*) denotes the [Carmichael function](wikipedia://en/1181756), though sometimes *φ*(*N*), the [Euler's totient function](wikipedia://en/53452), is used (note: this is the order of the [multiplicative group](wikipedia://en/1110742) (**Z**/*N***Z**)<sup>×</sup>, which is not necessarily a [cyclic group](wikipedia://en/52327)). The encryption exponent *e* and *λ*(*N*) also must be [relatively prime](https://en.wikipedia.org/wiki/Coprime) so that there is a [modular inverse](wikipedia://en/9815338). The [factorization](wikipedia://en/82341) of *N* and the private key *d* are kept secret, so that only Bob can [decrypt](https://en.wikipedia.org/wiki/Decrypt) the message. We denote the private key pair as (*d*, *N*). The encryption of the message *M* is given by *C* ≡ *M*<sup>*e*</sup> (mod *N*) and the decryption of cipher text *C* is given by *C*<sup>*d*</sup> ≡ (*M*<sup>*e*</sup>)<sup>*d*</sup> ≡ *M*<sup>*ed*</sup> ≡ *M* (mod *N*) (using [Euler's Theorem](wikipedia://en/69566)).

Using the [Euclidean algorithm](wikipedia://en/10377), one can efficiently recover the secret key *d* if one knows the [factorization](wikipedia://en/82341) of *N*. By having the secret key *d*, one can efficiently factor the modulus of *N*.[^o3]

## Small private key {#Small_private_key}

In the RSA [cryptosystem](wikipedia://en/506383), Bob might tend to use a small value of *d*, rather than a large random number to improve the [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) [decryption](https://en.wikipedia.org/wiki/Decryption) performance. However, Wiener's attack shows that choosing a small value for *d* will result in an insecure system in which an attacker can recover all secret information, i.e., break the [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) system. This break is based on Wiener's theorem, which holds for small values of *d*. Wiener has proved that the attacker may efficiently find *d* when *d* \< $\tfrac{1}{3}$*N*<sup>1/4</sup>.[^o8]

Wiener's paper also presented some countermeasures against his attack that allow fast decryption. Two techniques are described as follows.

**Choosing large public key**: Replace *e* by *e*′, where *e*′ = *e* + *k* ⋅ *λ*(*N*) for some large of *k*. When *e*′ is large enough, i.e. *e*′ > *N*<sup>3/2</sup>, then Wiener's attack cannot be applied regardless of how small *d* is.

**Using the [Chinese remainder theorem](wikipedia://en/7713)**: Suppose one chooses *d* such that both *d*<sub>*p*</sub> ≡ *d* (mod (*p* − 1)) and *d*<sub>*q*</sub> ≡ *d* (mod (*q* − 1)) are small but *d* itself is not, then a fast [decryption](https://en.wikipedia.org/wiki/Decryption) of *C* can be done as follows:

1. First compute *M*<sub>*p*</sub> ≡ *C*<sup>*d*<sub>*p*</sub></sup> (mod *p*) and *M*<sub>*q*</sub> ≡ *C*<sup>*d*<sub>*q*</sub></sup> (mod *q*).
1. Use the [Chinese remainder theorem](wikipedia://en/7713) to compute the unique value of 0 ≤ *M* \< *N* that satisfies *M* ≡ *M*<sub>*p*</sub> (mod *p*) and *M* ≡ *M*<sub>*q*</sub> (mod *q*. The result of *M* satisfies *M* ≡ *C*<sup>*d*</sup> (mod *N*) as needed. The point is that Wiener's attack does not apply here because the value of *d* mod *λ*(*N*) can be large.

## How the attack works {#How_the_attack_works}

Note that

$$\lambda(N) = \operatorname{lcm}(p-1, q-1) = \frac{(p-1)(q-1)}{G} = \frac{\varphi(N)}{G}$$

where *G* = gcd(*p* − 1, *q* − 1).

Since *ed* ≡ 1 (mod *λ*(*N*)), there exists an integer *K* such that

$$ed = K \times \lambda(N)+1$$

$$ed = \frac {K}{G} (p-1)(q-1)+1$$

Defining *k* = $\tfrac{K}{\gcd(K, G)}$ and *g* = $\tfrac{G}{\gcd(K, G)}$, and substituting into the above gives:

$$ed = \frac {k}{g} (p-1) (q-1)+1.$$

Divided by *dpq*:

$\frac{e}{pq} = \frac{k}{dg} (1- \delta)$, where $\delta = \frac {p+q-1- \frac {g}{k}}{pq}$.

So, $\tfrac{e}{pq}$ is slightly smaller than $\tfrac{k}{dg}$, and the former is composed entirely of public [information](wikipedia://en/18985062). However, a method of checking and guess is still required.

By using simple [algebraic](wikipedia://en/18716923) manipulations and [identities](wikipedia://en/298428), a guess can be checked for [accuracy](https://en.wikipedia.org/wiki/Accuracy).[^o3]

::: {#o7 .statement kind=statement/theorem cue=named-heading name="Wiener's theorem"}

## Wiener's theorem {#Wiener's_theorem}

Let *N* = *pq* with *q* \< *p* \< 2*q*. Let *d* \< $\tfrac{1}{3}$*N*<sup>1/4</sup>.

Given $\langle N, e\rangle$ with *ed* ≡ 1 (mod *λ*(*N*)), the attacker can efficiently recover *d*.[^o8][^o9]

:::

::: {#o11 .example cue=heading name="Example"}

## Example {#Example}

section Suppose that the public keys are $\langle N, e\rangle$ = $\langle 90581, 17993\rangle$. The attack should determine *d*. By using Wiener's theorem and [continued fractions](https://en.wikipedia.org/wiki/Continued_fractions) to approximate *d*, first we try to find the [continued fractions](https://en.wikipedia.org/wiki/Continued_fractions) expansion of $\tfrac{e}{N}$. Note that this algorithm finds [fractions](https://en.wikipedia.org/wiki/Fractions) in their lowest terms. We know that

$$\frac{e}{N} = \frac{17993}{90581} = \cfrac{1}{5 + \cfrac{1}{29 +\dots + \cfrac{1}{3}}} = \left [0,5,29,4,1,3,2,4,3 \right ]$$

According to the [continued fractions](wikipedia://en/739199) expansion of $\tfrac{e}{N}$, all convergents $\tfrac{k}{d}$ are:

$$\frac{k}{d} = 0, \frac{1}{5}, \frac{29}{146}, \frac{117}{589}, \frac{146}{735}, \frac{555}{2794}, \frac{1256}{6323}, \frac{5579}{28086}, \frac{17993}{90581}$$

We can verify that the first [convergent](https://en.wikipedia.org/wiki/Convergent_%28continued_fraction%29) does not produce a factorization of *N*. However, the convergent $\tfrac{1}{5}$ yields

$$\varphi (N) = \frac{ed - 1}{k} = \frac{17993\times5 - 1}{1} = 89964$$

Now, if we solve the equation

$$x^2 - \left ( \left (N - \varphi (N) \right ) + 1 \right )x + N = 0$$

$$x^2 - \left ( \left (90581 - 89964 \right ) + 1 \right )x + 90581 = 0$$

$$x^2 - 618x + 90581 = 0$$

then we find the [roots](wikipedia://en/537048) which are *x* = 379; 239. Therefore we have found the factorization

$$N = 90581 = 379 \times 239 = p \times q.$$

Notice that, for the modulus *N* = 90581, Wiener's theorem will work if

$$d < \frac{N^{1/4}}{3} \approx 5.7828.$$

:::

## Proof of Wiener's theorem {#Proof_of_Wiener's_theorem}

The proof is based on approximations using continued fractions.[^o8]

Since *ed* = 1 (mod *λ*(*N*)), there exists a *k* such that *ed* − *kλ*(*N*) = 1. Therefore

$$\left | \frac {e}{\lambda (N)}- \frac {k}{d} \right \vert = \frac{1}{d \lambda (N)}.$$

Let *G* = gcd(*p* − 1, *q* − 1); note that if *φ*(*N*) is used instead of *λ*(*N*), then the proof can be replaced with *G* = 1 and *φ*(*N*) replaced with *λ*(*N*).

Then multiplying by $\tfrac{1}{G}$,

$$\left | \frac {e}{\varphi (N)}- \frac {k}{Gd} \right \vert = \frac{1}{d \varphi (N)}$$

Hence, $\tfrac{k}{Gd}$ is an approximation of $\tfrac{e}{\varphi(N)}$. Although the attacker does not know *φ*(*N*), he may use *N* to approximate it. Indeed, since *φ*(*N*) = *N* − *p* − *q* + 1 and *p* + *q* − 1 \< 3$\sqrt{N}$, we have:

$$\left \vert p+q-1 \right \vert < 3 \sqrt{N}$$

$$\left \vert N-\varphi (N) \right \vert < 3 \sqrt{N}$$

Using *N* in place of *φ*(*N*) we obtain:

$$\begin{aligned} \left \vert \frac{e}{N}- \frac{k}{Gd} \right \vert &= \left \vert \frac{edG-kN}{NGd} \right \vert \\ &= \left \vert \frac{edG-k \varphi (N)-kN+k \varphi (N)}{NGd} \right \vert \\ &= \left \vert \frac{1-k(N- \varphi (N))}{NGd} \right \vert \\ &< \left \vert \frac{-k(N- \varphi (N))}{NGd} \right \vert (\because 0 < |N-\varphi (N)|)\\ &< \left \vert \frac{3k \sqrt{N}}{NGd} \right \vert = \frac {3k \sqrt{N}}{\sqrt{N} \sqrt{N}Gd} \le \frac {3k}{d \sqrt{N}} \end{aligned}$$

Now, *kλ*(*N*) = *ed* − 1 \< *ed*, so *kλ*(*N*) \< *ed*. Since *e* \< *λ*(*N*), so *kλ*(*N*) \< *ed* \< *λ*(*N*)*d*, then we obtain:

$$k \lambda (N)<\lambda (N)d$$

$$k<d$$

Since *k* \< *d* and *d* \< $\tfrac{1}{3}$*N*<sup>1/4</sup>. Hence we obtain:

(1) $\left \vert \frac{e}{N}- \frac{k}{Gd} \right \vert < \frac{1}{dN^{\frac{1}{4}}}$

Since *d* \< $\tfrac{1}{3}$*N*<sup>1/4</sup>, 2*d* \< 3*d*, then 2*d* \< 3*d* \< *N*<sup>1/4</sup>, we obtain:

$2d<N^{1/4}$, so (2) $\frac{1}{2d} > \frac{1}{N^{1/4}}$

From (1) and (2), we can conclude that

$$\left \vert \frac{e}{N}- \frac{k}{Gd} \right \vert < \frac{3k}{d \sqrt{N}}< \frac{1}{d \cdot 2d}= \frac{1}{2d^2}$$

If $\lvert x - \tfrac{a}{b}\rvert$ \< $\tfrac{1}{2b^{2}}$, then $\tfrac{a}{b}$ is a convergent of *x*, thus $\tfrac{k}{Gd}$ appears among the convergents of $\tfrac{e}{N}$. Therefore the algorithm will indeed eventually find $\tfrac{k}{Gd}$.

:::
