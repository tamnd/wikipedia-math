# Axiomatic semantics

::: {#o1 .subject cue=lead name="Axiomatic semantics"}

**Axiomatic semantics** is an approach based on [mathematical logic](wikipedia://en/19636) for proving the [correctness of computer programs](https://en.wikipedia.org/wiki/Correctness_of_computer_programs).[^o2] It is closely related to [Hoare logic](wikipedia://en/182708).

:::

Axiomatic semantics define the meaning of a command in a program by describing its effect on assertions about the program state. The assertions are logical statements—predicates with variables, where the variables define the state of the program.
