# Discretization error

::: {#o1 .subject cue=lead name="Discretization error"}

In [numerical analysis](wikipedia://en/21506), [computational physics](https://en.wikipedia.org/wiki/Computational_physics), and [simulation](https://en.wikipedia.org/wiki/Simulation), **discretization error** is the [error](wikipedia://en/41118) resulting from the fact that a [function](wikipedia://en/185427) of a [continuous](wikipedia://en/24758677) variable is represented in the computer by a finite number of evaluations, for example, on a [lattice](wikipedia://en/291472). Discretization error can usually be reduced by using a more finely spaced lattice, with an increased [computational cost](wikipedia://en/7543).

:::

::: {#o3 .example cue=heading name="Examples"}

## Examples {#Examples}

Discretization error is the principal source of error in methods of [finite differences](wikipedia://en/39147) and the [pseudo-spectral method](wikipedia://en/474353) of computational physics.

When we define the derivative of $\,\!f(x)$ as $f'(x) = \lim_{h\rightarrow0}{\frac{f(x+h)-f(x)}{h}}$ or $f'(x)\approx\frac{f(x+h)-f(x)}{h}$, where $\,\!h$ is a finitely small number, the difference between the first formula and this approximation is known as discretization error.

:::

## Related phenomena {#Related_phenomena}

In [signal processing](wikipedia://en/29324), the analog of discretization is [sampling](https://en.wikipedia.org/wiki/Sampling_%28signal_processing%29), and results in no loss if the conditions of the [sampling theorem](https://en.wikipedia.org/wiki/Sampling_theorem) are satisfied, otherwise the resulting error is called [aliasing](wikipedia://en/151474).

Discretization error, which arises from finite resolution in the *domain,* should not be confused with [quantization error](https://en.wikipedia.org/wiki/Quantization_error), which is finite resolution in the *range* (values), nor in [round-off error](wikipedia://en/432450) arising from [floating-point arithmetic](wikipedia://en/11376). Discretization error would occur even if it were possible to represent the values exactly and use exact arithmetic – it is the error from representing a function by its values at a discrete set of points, not an error in these values.[^o5]
