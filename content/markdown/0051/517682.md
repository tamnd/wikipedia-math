# Zero-dimensional space

::: {#o1 .subject cue=lead name="Zero-dimensional space"}

In [mathematics](wikipedia://en/18831), a **zero-dimensional topological space** (or **nildimensional space**) is a [topological space](wikipedia://en/30450) that has dimension zero with respect to one of several inequivalent notions of assigning a [dimension](wikipedia://en/8398) to a given topological space.[^o2] A graphical illustration of a zero-dimensional space is a [point](wikipedia://en/593693).[^o3]

:::

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

Specifically:

- A topological space is zero-dimensional with respect to the [Lebesgue covering dimension](wikipedia://en/398886) if every [open cover](https://en.wikipedia.org/wiki/Open_cover) of the space has a [refinement](https://en.wikipedia.org/wiki/Refinement_%28topology%29) that is a cover by disjoint open sets.
- A topological space is zero-dimensional with respect to the finite-to-finite covering dimension if every finite open cover of the space has a refinement that is a finite open cover such that any point in the space is contained in exactly one open set of this refinement.
- A topological space is zero-dimensional with respect to the [small inductive dimension](https://en.wikipedia.org/wiki/Small_inductive_dimension) if it has a [base](wikipedia://en/59220) consisting of [clopen sets](wikipedia://en/233398).

The three notions above agree for [separable](wikipedia://en/27855), [metrisable spaces](https://en.wikipedia.org/wiki/Metrisable_space) (see Inductive dimension#Relationships between dimensions).

:::

## Properties of spaces with small inductive dimension zero {#Properties_of_spaces_with_small_inductive_dimension_zero}

- A zero-dimensional [Hausdorff space](wikipedia://en/13637) is necessarily [totally disconnected](https://en.wikipedia.org/wiki/Totally_disconnected), but the converse fails. However, a [locally compact](https://en.wikipedia.org/wiki/Locally_compact) Hausdorff space is zero-dimensional if and only if it is totally disconnected. (See (Arhangel'skii Tkachenko 2008, Proposition 3.1.7, p.136) for the non-trivial direction.)
- Zero-dimensional [Polish spaces](wikipedia://en/396622) are a particularly convenient setting for [descriptive set theory](wikipedia://en/396619). Examples of such spaces include the [Cantor space](wikipedia://en/352376) and [Baire space](wikipedia://en/2078245).
- Hausdorff zero-dimensional spaces are precisely the [subspaces](wikipedia://en/910926) of topological [powers](wikipedia://en/23799) $2^I$ where $2=\{0,1\}$ is given the [discrete topology](https://en.wikipedia.org/wiki/Discrete_topology). Such a space is sometimes called a [Cantor cube](wikipedia://en/4999981). If $I$ is [countably infinite](wikipedia://en/6026), $2^I$ is the Cantor space.

## Manifolds {#Manifolds}

All points of a zero-dimensional [manifold](wikipedia://en/2073470) are [isolated](wikipedia://en/390557).
