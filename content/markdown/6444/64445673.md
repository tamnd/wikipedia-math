# F. Riesz's theorem

::: {#o1 .subject cue=lead name="F. Riesz's theorem"}

In mathematics, **F. Riesz's theorem** (named after [Frigyes Riesz](wikipedia://en/1073126)) is a theorem in [functional analysis](wikipedia://en/11180) that states that a [Hausdorff](wikipedia://en/13637) [topological vector space](wikipedia://en/45752) is finite-dimensional if and only if it is [locally compact](https://en.wikipedia.org/wiki/Locally_compact). The theorem and its consequences are used ubiquitously in functional analysis, often used without being explicitly mentioned.

:::

::: {#o3 .statement cue=heading name="Statement"}

## Statement {#Statement}

Recall that a [topological vector space](wikipedia://en/45752) (TVS) $X$ is [Hausdorff](wikipedia://en/13637) if and only if the singleton set $\{ 0 \}$ consisting entirely of the origin is a closed subset of $X.$ A map between two TVSs is called a **TVS-isomorphism** or an **isomorphism in the category of TVSs** if it is a [linear](wikipedia://en/18102) [homeomorphism](wikipedia://en/13660).

::: {#o6 .statement kind=statement/theorem cue=math-theorem name="F. Riesz theorem"}

**F. Riesz theorem[^n1][^n2].**

A [Hausdorff](wikipedia://en/13637) TVS $X$ over the field $\mathbb{F}$ ( $\mathbb{F}$ is either the real or complex numbers) is finite-dimensional if and only if it is [locally compact](https://en.wikipedia.org/wiki/Locally_compact) (or equivalently, if and only if there exists a compact neighborhood of the origin). In this case, $X$ is TVS-isomorphic to $\mathbb{F}^{\text{dim} X}.$

:::

:::

## Consequences {#Consequences}

Throughout, $F, X, Y$ are TVSs (not necessarily Hausdorff) with $F$ a finite-dimensional vector space.

- Every finite-dimensional vector subspace of a Hausdorff TVS is a closed subspace.[^n1]
- All finite-dimensional Hausdorff TVSs are [Banach spaces](wikipedia://en/3989) and all norms on such a space are equivalent.[^n1]
- If $M$ is a closed vector subspace of a TVS $Y$ and if $F$ is a finite-dimensional vector subspace of $Y$ then $M + F$ is a closed vector subspace of $Y.$[^n1]
- Every [linear](wikipedia://en/18102) bijection between two finite-dimensional Hausdorff TVSs is a [TVS isomorphism](https://en.wikipedia.org/wiki/TVS_isomorphism).[^n1]
- If $\tau_1$ and $\tau_2$ are Hausdorff TVS topologies on the same finite-dimensional vector space then $\tau_1 = \tau_2.$[^n1]
- A [linear map](wikipedia://en/18102) $L : F \to Y$ between Hausdorff TVSs is necessarily continuous.[^n1]
  - In particular, every [linear functional](https://en.wikipedia.org/wiki/Linear_functional) of a finite-dimensional Hausdorff TVS is continuous.
- Any continuous [surjective](https://en.wikipedia.org/wiki/Surjective) linear map $L : X \to Y$ with a Hausdorff finite-dimensional range is an [open map](https://en.wikipedia.org/wiki/Open_map)[^n1] and thus a [topological homomorphism](wikipedia://en/63987005). In particular, the range of $L$ is TVS-isomorphic to $X / L^{-1}(0).$
- A TVS $X$ is locally compact if and only if $X / \overline{\{ 0 \}}$ is finite dimensional.
- The [convex hull](wikipedia://en/40634) of a [compact subset](https://en.wikipedia.org/wiki/Compact_subset) of a finite-dimensional Hausdorff TVS is compact.[^n1]
  - In particular, the convex hull of a compact set is equal to the closed convex hull of that set.
- A [locally bounded](https://en.wikipedia.org/wiki/Locally_bounded) Hausdorff TVS with the [Heine-Borel property](https://en.wikipedia.org/wiki/Heine-Borel_property) is finite-dimensional.[^n2]
