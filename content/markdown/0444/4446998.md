# SM4 (cipher)

::: {#o1 .subject cue=lead name="SM4"}

**ShāngMì 4** (**SM4, 商密4**) (formerly **SMS4**)[^o4] is a [block cipher](wikipedia://en/4594), standardised for commercial cryptography in China.[^o5] It is used in the [Chinese](https://en.wikipedia.org/wiki/China) National Standard for Wireless LAN [WAPI](https://en.wikipedia.org/wiki/WLAN_Authentication_and_Privacy_Infrastructure) (WLAN Authentication and Privacy Infrastructure), and with [Transport Layer Security](wikipedia://en/187813).[^o6]

:::

SM4 was a cipher proposed for the [IEEE 802.11i](https://en.wikipedia.org/wiki/IEEE_802.11i) standard, but it has so far been rejected. One of the reasons for the rejection has been opposition to the WAPI fast-track proposal by the [IEEE](https://en.wikipedia.org/wiki/IEEE).

SM4 was published as in 2012 and in 2021.

The SM4 algorithm was drafted by Data Assurance & Communication Security Center, [Chinese Academy of Sciences](https://en.wikipedia.org/wiki/Chinese_Academy_of_Sciences) (CAS), and Commercial Cryptography Testing Center, National Cryptography Administration. It is mainly developed by Lü Shuwang (吕述望). The algorithm was declassified in January, 2006, and it became a national standard (GB/T 32907-2016) in August 2016.[^o7]

## Cipher detail {#Cipher_detail}

The SM4 cipher has a key size and a block size of 128 bits each.[^o9][^o10] Encryption or decryption of one block of data is composed of 32 rounds. A non-linear [key schedule](wikipedia://en/609603) is used to produce the round keys and the decryption uses the same round keys as for encryption, except that they are in reversed order.

### Keys and key parameters {#Keys_and_key_parameters}

The length of encryption keys is 128 bits, represented as $MK=(MK_0,\ MK_1,\ MK_2,\ MK_3)$, in which $MK_i\ (i=0,\ 1,\ 2,\ 3)$ is a 32-bit word. The round keys are represented by $(rk_0,\ rk_1,\ \ldots,\ rk_{31})$, where each $rk_i(i=0,\ \ldots,\ 31)$ is a 32-bit word. It is generated by the encryption key and the following parameters:

- $$FK=(FK_0,\ FK_1,\ FK_2,\ FK_3)$$
- $$CK=(CK_0,\ CK_1,\ \ldots,\ CK_{31})$$

$FK_i$ and $CK_i$ are 32-bit words used to generate the round keys.

### Round {#Round}

Each round are computed from the four previous round outputs $X_i, X_{i+1}, X_{i+2}, X_{i+3}$ such that: $X_{i+4} = X_i \oplus F(X_{i+1} \oplus X_{i+2} \oplus X_{i+3} \oplus rk_i)$

Where $F$ is a substitution function composed of a non-linear transform, the S-box and linear transform $L$

### S-box {#S-box}

SM4's S-box is fixed for 8-bit input and 8-bit output, noted as Sbox(). As with [Advanced Encryption Standard](wikipedia://en/1260) (AES), the S-box is based on the [multiplicative inverse](wikipedia://en/229940) over $\operatorname{GF}(2^{8})$. The affine transforms and polynomial bases are different from that of AES, but due to [affine isomorphism](wikipedia://en/298834) it can be calculated efficiently given an [AES S-Box](wikipedia://en/1903857).[^o14]

## History {#History}

On March 21, 2012, the Chinese government published the industrial standard "GM/T 0002-2012 SM4 Block Cipher Algorithm", officially renaming SMS4 to SM4.[^o4]

A description of SM4 in English is available as an [Internet Draft](https://en.wikipedia.org/wiki/Internet_Draft). It contains a [reference implementation](https://en.wikipedia.org/wiki/Reference_implementation) in [ANSI C](https://en.wikipedia.org/wiki/ANSI_C).[^o16]

SM4 is part of the [ARMv8.4-A](https://en.wikipedia.org/wiki/ARMv8.4-A) expansion to the ARM architecture.[^o17] SM4 support for the [RISC-V](https://en.wikipedia.org/wiki/RISC-V_architecture) architecture was ratified in 2021 as the Zksed extension.[^o18]

SM4 is supported by Intel processors, starting from [Arrow Lake S](https://en.wikipedia.org/wiki/Arrow_Lake_%28microprocessor%29), [Lunar Lake](https://en.wikipedia.org/wiki/Lunar_Lake), Diamond Rapids and Clearwater Forest.[^o19]
