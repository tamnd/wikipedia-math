# K-frame

::: {#o1 .subject cue=lead name="K-frame"}

In [linear algebra](wikipedia://en/18422), a ***k*-frame** is an [ordered set](https://en.wikipedia.org/wiki/Ordered_set) of *k* [linearly independent](https://en.wikipedia.org/wiki/Linearly_independent) vectors in a [vector space](wikipedia://en/32370)[^o2]; thus, *k* ≤ *n*, where *n* is the [dimension](wikipedia://en/38267) of the space, and an ***n*-frame** is precisely an ordered [basis](wikipedia://en/18420).

:::

If the vectors are [orthogonal](wikipedia://en/102221), or [orthonormal](wikipedia://en/194743), the frame is called an **orthogonal frame**, or **[orthonormal frame](wikipedia://en/350995)**, respectively.

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- The set of *k*-frames (particularly the set of orthonormal *k*-frames) in a given vector space *X* is known as the [Stiefel manifold](wikipedia://en/1392495), and denoted *V*<sub>*k*</sub>(*X*).
- A *k*-frame defines a [parallelotope](wikipedia://en/23975#Parallelotope) (a generalized [parallelepiped](wikipedia://en/23975)); the volume can be computed via the [Gram determinant](https://en.wikipedia.org/wiki/Gram_determinant).

:::
