# Kernel perceptron

::: {#o1 .subject cue=lead name="Kernel perceptron"}

In [machine learning](wikipedia://en/233488), the **kernel perceptron** is a variant of the popular [perceptron](wikipedia://en/172777) learning algorithm that can learn [kernel machines](https://en.wikipedia.org/wiki/Kernel_trick), i.e. non-linear [classifiers](wikipedia://en/1579244) that employ a kernel function to compute the similarity of unseen samples to training samples. The algorithm was invented in 1964,[^o2] making it the first kernel classification learner.[^o3]

:::

## Preliminaries {#Preliminaries}

### The perceptron algorithm {#The_perceptron_algorithm}

The perceptron algorithm is an [online learning](https://en.wikipedia.org/wiki/Online_machine_learning) algorithm that operates by a principle called "error-driven learning". It iteratively improves a model by running it on training samples, then updating the model whenever it finds it has made an incorrect classification with respect to a [supervised](wikipedia://en/20926) signal. The model learned by the standard perceptron algorithm is a [linear](wikipedia://en/98974) binary classifier: a vector of weights $\mathbf{w}$ (and optionally an intercept term $b$, omitted here for simplicity) that is used to classify a sample vector $\mathbf{x}$ as class "one" or class "minus one" according to

$$\hat{y} = \operatorname{sgn}(\mathbf{w}^\top \mathbf{x})$$

where a zero is arbitrarily mapped to one or minus one. (The "[hat](https://en.wikipedia.org/wiki/Circumflex#Mathematics)" on $\text{ŷ}$ denotes an estimated value.)

In [pseudocode](https://en.wikipedia.org/wiki/Pseudocode), the perceptron algorithm is given by:

Initialize $\mathbf{w}$ to an all-zero vector of length $p$, the number of predictors (features).

For some fixed number of iterations, or until some stopping criterion is met:

For each training example $\mathbf{x}_{i}$ with ground truth label $y_{i} \in \{-1, 1$}:

Let $\text{ŷ} = \operatorname{sgn}(\mathbf{w}^{T} \mathbf{x}_{i})$.

If $\text{ŷ} \ne y_{i}$, update $\mathbf{w} \leftarrow \mathbf{w} + y_{i} \mathbf{x}_{i}$.

### Kernel Methods {#Kernel_Methods}

By contrast with the linear models learned by the perceptron, a kernel method[^o7] is a classifier that stores a subset of its training examples $\mathbf{x}_{i}$, associates with each a weight $\alpha_{i}$, and makes decisions for new samples $\mathbf{x'}$ by evaluating

$$\operatorname{sgn} \sum_i \alpha_i y_i K(\mathbf{x}_i, \mathbf{x'}).$$

Here, $K$ is some kernel function. Formally, a kernel function is a [non-negative semidefinite kernel](https://en.wikipedia.org/wiki/Positive_definite_kernel) (see [Mercer's condition](https://en.wikipedia.org/wiki/Mercer's_condition)), representing an [inner product](https://en.wikipedia.org/wiki/Inner_product) between samples in a high-dimensional space, as if the samples had been expanded to include additional features by a function $\Phi$: $K(\mathbf{x}, \mathbf{x'}) = \Phi(\mathbf{x}) \cdot \Phi(\mathbf{x'})$. Intuitively, it can be thought of as a [similarity function](https://en.wikipedia.org/wiki/Similarity_function) between samples, so the kernel machine establishes the class of a new sample by weighted comparison to the training set. Each function $\mathbf{x'} \mapsto K(\mathbf{x}_{i}, \mathbf{x'})$ serves as a [basis function](wikipedia://en/50909) in the classification.

## Algorithm {#Algorithm}

To derive a kernelized version of the perceptron algorithm, we must first formulate it in [dual form](wikipedia://en/3372717), starting from the observation that the weight vector $\mathbf{w}$ can be expressed as a [linear combination](wikipedia://en/55632) of the $n$ training samples. The equation for the weight vector is

$$\mathbf{w} = \sum_i^n \alpha_i y_i \mathbf{x}_i$$

where $\alpha_{i}$ is the number of times $\mathbf{x}_{i}$ was misclassified, forcing an update $\mathbf{w} \leftarrow \mathbf{w} + y_{i} \mathbf{x}_{i}$. Using this result, we can formulate the dual perceptron algorithm, which loops through the samples as before, making predictions, but instead of storing and updating a weight vector $\mathbf{w}$, it updates a "mistake counter" vector $\mathbf{\alpha}$. We must also rewrite the prediction formula to get rid of $\mathbf{w}$:

$$\begin{aligned} \hat{y} & = \operatorname{sgn}(\mathbf{w}^\mathsf{T} \mathbf{x}) \\ & = \operatorname{sgn} \left( \sum_i^n \alpha_i y_i \mathbf{x}_i \right)^\mathsf{T} \mathbf{x} \\ & = \operatorname{sgn} \sum_i^n \alpha_i y_i (\mathbf{x}_i \cdot \mathbf{x}) \end{aligned}$$

Plugging these two equations into the training loop turn it into the *dual perceptron* algorithm.

Finally, we can replace the [dot product](wikipedia://en/157093) in the dual perceptron by an arbitrary kernel function, to get the effect of a feature map $\Phi$ without computing $\Phi(\mathbf{x})$ explicitly for any samples. Doing this yields the kernel perceptron algorithm:[^o10]

Initialize $\mathbf{\alpha}$ to an all-zeros vector of length $n$, the number of training samples.

For some fixed number of iterations, or until some stopping criterion is met:

For each training example $\mathbf{x}_{j}, y_{j}$:

Let $\hat{y} = \operatorname{sgn} \sum_i^n \alpha_i y_i K(\mathbf{x}_i, \mathbf{x}_j)$

If $\text{ŷ} \ne y_{j}$, perform an update by incrementing the mistake counter:

$$\alpha_{j} \leftarrow \alpha_{j} + 1$$

## Variants and extensions {#Variants_and_extensions}

One problem with the kernel perceptron, as presented above, is that it does not learn [sparse](https://en.wikipedia.org/wiki/Sparsity) kernel machines. Initially, all the $\alpha_{i}$ are zero so that evaluating the decision function to get $\text{ŷ}$ requires no kernel evaluations at all, but each update increments a single $\alpha_{i}$, making the evaluation increasingly more costly. Moreover, when the kernel perceptron is used in an [online](https://en.wikipedia.org/wiki/Online_machine_learning) setting, the number of non-zero $\alpha_{i}$ and thus the evaluation cost grow linearly in the number of examples presented to the algorithm.

The forgetron variant of the kernel perceptron was suggested to deal with this problem. It maintains an [active set](https://en.wikipedia.org/wiki/Active_set_method) of examples with non-zero $\alpha_{i}$, removing ("forgetting") examples from the active set when it exceeds a pre-determined budget and "shrinking" (lowering the weight of) old examples as new ones are promoted to non-zero $\alpha_{i}$.[^o13]

Another problem with the kernel perceptron is that it does not [regularize](wikipedia://en/2009061), making it vulnerable to [overfitting](wikipedia://en/173332). The NORMA online kernel learning algorithm can be regarded as a generalization of the kernel perceptron algorithm with regularization.[^o14] The [sequential minimal optimization](https://en.wikipedia.org/wiki/Sequential_minimal_optimization) (SMO) algorithm used to learn [support vector machines](wikipedia://en/65309) can also be regarded as a generalization of the kernel perceptron.[^o14]

The voted perceptron algorithm of Freund and Schapire also extends to the kernelized case,[^o15] giving generalization bounds comparable to the kernel SVM.[^o3]
