# HP 10s

::: {#o4 .subject cue=lead name="HP 10s"}

Introduced by HP for students, the **HP 10s** (F2214A) is a scientific calculator with more than 240 built-in functions, with 2 lines x 10 digits [LCD](https://en.wikipedia.org/wiki/LCD). It is permitted to use on [SAT](wikipedia://en/144716) and [ACT](https://en.wikipedia.org/wiki/ACT_%28test%29) tests.[^o5]

:::

It has a standard scientific layout and function set that very closely correlates with the [Casio](https://en.wikipedia.org/wiki/Casio) fx-85MS, allowing for calculations to be done in a short time.

The 10s was replaced by the **HP 10s+** (NW276AA).

In 2022, [Moravia Consulting spol.&nbsp;s&nbsp;r.o.](https://en.wikipedia.org/wiki/Moravia_Consulting_spol.&nbsp;s&nbsp;r.o.) launched the **HP 10sII** for the Australian market.
