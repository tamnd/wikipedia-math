# Vanishing scalar invariant spacetime

::: {#o1 .subject cue=lead name="Vanishing scalar invariant spacetime"}

In [mathematical physics](wikipedia://en/173416), **vanishing scalar invariant (VSI) spacetimes** are [Lorentzian manifolds](https://en.wikipedia.org/wiki/Lorentzian_manifold) in which all polynomial [curvature invariants](wikipedia://en/2680414) of all orders are vanishing. Although the only [Riemannian manifold](wikipedia://en/144652) with the VSI property is flat space, the Lorentzian case admits nontrivial spacetimes with this property. Distinguishing these VSI spacetimes from [Minkowski spacetime](wikipedia://en/230488) requires comparing non-polynomial invariants[^o2] or carrying out the full [Cartan–Karlhede algorithm](https://en.wikipedia.org/wiki/Cartan–Karlhede_algorithm) on non-scalar quantities.[^o3][^o4]

:::

All VSI spacetimes are a subset of [Kundt spacetimes](wikipedia://en/28411451).[^o5] An example of a VSI spacetime in four dimensions is a [pp-wave](wikipedia://en/1447921). However, VSI spacetimes also contain some other four-dimensional Kundt spacetimes of [Petrov type](https://en.wikipedia.org/wiki/Petrov_type) N and III. VSI spacetimes in higher dimensions have similar properties to the four-dimensional case.[^o6][^o7]
