# First-player and second-player win

::: {#o1 .subject cue=lead name="First-player and second-player win"}

*Image: Tictactoe-X.svg.* Diagram showing optimal strategy for [tic-tac-toe](https://en.wikipedia.org/wiki/Tic-tac-toe). With perfect play, and from any initial move, both players can always force a draw.

In [combinatorial game theory](wikipedia://en/292231), a two-player deterministic [perfect information](wikipedia://en/321438) [turn-based game](https://en.wikipedia.org/wiki/Sequential_game) is a **first-player win** if with [perfect play](https://en.wikipedia.org/wiki/Solved_game#Perfect_play) the first player to move can always force a win. Similarly, a game is **second-player win** if with perfect play the second player to move can always force a win. With perfect play, if neither side can force a win, the game is a [draw](https://en.wikipedia.org/wiki/Draw_%28tie%29).

:::

Some games with relatively small [game trees](https://en.wikipedia.org/wiki/Game_tree) have been proven to be first- or second-player wins. For example, the game of [nim](wikipedia://en/21885) with the classic 3–4–5 starting position is a first-player-win game. However, nim with the 1–3–5–7 starting position is a second-player win. The classic game of [Connect Four](wikipedia://en/294075) has been mathematically proven to be first-player win.

With perfect play, [checkers](https://en.wikipedia.org/wiki/English_draughts) has been determined to be a draw; neither player can force a win.[^o2] Another example of a game which leads to a draw with perfect play is [tic-tac-toe](https://en.wikipedia.org/wiki/Tic-tac-toe), and this includes play from any opening move.

Significant theory has been completed in the effort to [solve chess](wikipedia://en/26811956). It has been speculated that there may be [first-move advantage](https://en.wikipedia.org/wiki/First-move_advantage_in_chess) which can be detected when the game is played imperfectly (such as with all humans and all current [chess engines](https://en.wikipedia.org/wiki/Chess_engine)). However, with perfect play, it remains unsolved as to whether the game is a first-player win (White), a second-player win (Black), or a forced draw.[^o3][^o4][^o5]
