# F-plane

::: {#o1 .subject cue=lead name="F-plane"}

In [geophysical](https://en.wikipedia.org/wiki/Geophysical) [fluid dynamics](wikipedia://en/11034), the ***f*-plane approximation** is an approximation where the [Coriolis parameter](https://en.wikipedia.org/wiki/Coriolis_parameter), denoted *f*, is set to a constant value.

:::

This approximation is frequently used for the analysis of highly idealized tropical cyclones. Using a constant Coriolis parameter prevents the formation of [beta gyres](https://en.wikipedia.org/wiki/Beta_gyre) which are largely responsible for the North-westward direction of most tropical cyclones. [Rossby waves](https://en.wikipedia.org/wiki/Rossby_waves) also depend on variations in *f*, and do not occur in the *f*-plane approximation.

In reality, the Coriolis parameter varies in the [meridional](https://en.wikipedia.org/wiki/Meridional) direction, and so the *f*-plane approximation is not appropriate when considering flows which span large changes in [latitude](wikipedia://en/17616). The *f*-plane approximation is also poor near the equator, where variations in *f* are on the same [order of magnitude](wikipedia://en/22657) as *f*. The [beta plane](wikipedia://en/5260710) approximation is an improvement on the *f*-plane approximation which takes leading-order variations in *f* into account.
