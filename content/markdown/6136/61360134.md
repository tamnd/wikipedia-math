# Babai's problem

::: {#o1 .subject cue=lead name="Babai's problem"}

::: {#o2 .problem cue=unsolved}

Which finite groups are BI-groups?

:::

**Babai's problem** is a problem in [algebraic graph theory](wikipedia://en/1620216) first proposed in 1979 by [László Babai](wikipedia://en/3461604).[^o3]

:::

## Babai's problem {#Babai's_problem}

Let $G$ be a finite group, let $\operatorname{Irr}(G)$ be the set of all [irreducible characters](https://en.wikipedia.org/wiki/Irreducible_character) of $G$, let $\Gamma=\operatorname{Cay}(G,S)$ be the [Cayley graph](wikipedia://en/358277) (or [directed Cayley graph](wikipedia://en/4367424#Directed_Cayley_graph)) corresponding to a [generating subset](wikipedia://en/99945) $S$ of $G\setminus \{1\}$, and let $\nu$ be a positive integer. Is the set

$$M_\nu^S=\left\{\sum_{s\in S} \chi(s)\;|\; \chi\in \operatorname{Irr}(G),\; \chi(1)=\nu \right\}$$

an [*invariant*](wikipedia://en/1126638) of the graph $\Gamma$? In other words, does $\operatorname{Cay}(G,S)\cong \operatorname{Cay}(G,S')$ imply that $M_\nu^S=M_\nu^{S'}$?

## BI-group {#BI-group}

A finite group $G$ is called a **BI-group** (**Babai Invariant group**)[^o6] if $\operatorname{Cay}(G,S)\cong \operatorname{Cay}(G,T)$ for some inverse closed subsets $S$ and $T$ of $G\setminus \{1\}$ implies that $M_\nu^S=M_\nu^T$ for all positive integers $\nu$.

::: {#o8 .statement kind=statement/conjecture cue=heading name="Open problem"}

## Open problem {#Open_problem}

Which finite groups are **BI-groups**?[^o9]

:::
