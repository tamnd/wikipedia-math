# Topological monoid

::: {#o1 .subject cue=lead name="Topological monoid"}

In [topology](wikipedia://en/29954), a branch of [mathematics](wikipedia://en/18831), a **topological monoid** is a [monoid object](wikipedia://en/3955446) in the [category](wikipedia://en/53759) of [topological spaces](wikipedia://en/30450). In other words, it is a monoid with a [topology](wikipedia://en/30450) with respect to which the monoid's binary operation is [continuous](https://en.wikipedia.org/wiki/Continuous_function_%28topology%29). Every [topological group](wikipedia://en/42315) is a topological monoid.

:::
