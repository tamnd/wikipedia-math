# Static key

::: {#o1 .subject cue=lead name="Static key"}

A [cryptographic](wikipedia://en/18934432) [key](wikipedia://en/53039) is called **static** if it is intended for use for a relatively long period of time and is typically intended for use in many instances of a cryptographic key establishment scheme. Contrast with an [ephemeral key](https://en.wikipedia.org/wiki/Ephemeral_key).

:::
