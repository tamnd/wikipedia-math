# Opportunistic Wireless Encryption

*Image: Android-WiFi-Security-Enhanced-Open.jpg.* Screenshot of Android Wi-Fi configuration with the Security set to "Enhanced Open"

::: {#o1 .subject cue=lead name="Opportunistic Wireless Encryption"}

**Opportunistic Wireless Encryption** (**OWE**) is a [Wi-Fi](https://en.wikipedia.org/wiki/Wi-Fi) standard which ensures that communication between a public hotspot and end devices is protected from other end devices. In contrast to conventional public hotspots, the data is transmitted in encrypted form. *OWE* was introduced by the [Wi-Fi Alliance](https://en.wikipedia.org/wiki/Wi-Fi_Alliance) in 2018 as part of the Wi-Fi Certified Enhanced Open program.[^o2]

:::

OWE is an extension to [IEEE 802.11](https://en.wikipedia.org/wiki/IEEE_802.11).[^o3] It is an encryption technique similar to that of [Simultaneous Authentication of Equals](wikipedia://en/59714120) (SAE) and is specified by [Internet Engineering Task Force](https://en.wikipedia.org/wiki/Internet_Engineering_Task_Force) (IETF) in RFC 8110 with devices certified as **Wi-Fi Certified Enhanced Open** by the [Wi-Fi Alliance](https://en.wikipedia.org/wiki/Wi-Fi_Alliance).[^o4][^o5]

With a network without a password, each WPA3 device that connects to it will still have its connection encrypted. OWE does encryption, not authentication; [evil twin](https://en.wikipedia.org/wiki/Evil_twin_%28wireless_networks%29) attack protection requires either WPA3-Personal or WPA3-Enterprise.[^o6]

Unlike conventional Wi-Fi, it provides "Individualized Data Protection" such that data traffic between a client and access point is "individualized." Other clients can still sniff and record this traffic, but they can't decrypt it.

> "OWE is a means of adding encryption to open networks...OWE only protects against passive attacks."[^o7]

*Opportunistic Wireless Encryption* is a Wi-Fi Enhanced Open authentication mode, as a part of [Wi-Fi Protected Access 3](wikipedia://en/422017).[^o8] OWE performs an unauthenticated [Diffie–Hellman (DH) key exchange](wikipedia://en/7903) at association time.[^o8]

For the wireless client to know the WLAN supports OWE, it must receive a Probe Response from the [wireless access point](https://en.wikipedia.org/wiki/Wireless_access_point) in response to its Probe Request. OWE still uses 802.11 Open System Authentication, then the *[Elliptic Curve Diffie-Hellman](https://en.wikipedia.org/wiki/Elliptic_Curve_Diffie-Hellman) Ephemeral* [exchange](wikipedia://en/7903) occurs in the Association process. After Association is successful the 4-way handshake can occur, and from then on data frames are encrypted.[^o9]
