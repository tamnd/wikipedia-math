# Matrix t-distribution

::: {#o1 .subject cue=lead name="Matrix t-distribution"}

In [statistics](wikipedia://en/26685), the **matrix *t*-distribution** (or **matrix variate *t*-distribution**) is the generalization of the [multivariate *t*-distribution](wikipedia://en/7984768) from vectors to [matrices](wikipedia://en/20556859).[^o2][^o3]

:::

The matrix *t*-distribution shares the same relationship with the multivariate *t*-distribution that the [matrix normal distribution](wikipedia://en/437758) shares with the [multivariate normal distribution](wikipedia://en/50347): If the matrix has only one row, or only one column, the distributions become equivalent to the corresponding (vector-)multivariate distribution. The matrix *t*-distribution is the [compound distribution](https://en.wikipedia.org/wiki/Compound_distribution) that results from an infinite [mixture](https://en.wikipedia.org/wiki/Mixture_density) of a matrix normal distribution with an [inverse Wishart distribution](https://en.wikipedia.org/wiki/Inverse_Wishart_distribution) placed over either of its covariance matrices,[^o2] and the multivariate *t*-distribution can be generated in a similar way.[^o3]

In a [Bayesian analysis](wikipedia://en/7522539) of a [multivariate linear regression](https://en.wikipedia.org/wiki/Multivariate_linear_regression) model based on the matrix normal distribution, the matrix *t*-distribution is the [posterior predictive distribution](wikipedia://en/35052447).[^o11]

::: {#o5 .definition cue=heading name="Definition"}

## Definition {#Definition}

For a matrix *t*-distribution, the [probability density function](wikipedia://en/43487) at the point $\mathbf{X}$ of an $n\times p$ space is

$$f(\mathbf{X} ; \nu,\mathbf{M},\boldsymbol\Sigma, \boldsymbol\Omega) = K \times \left|\mathbf{I}_n + \boldsymbol\Sigma^{-1}(\mathbf{X} - \mathbf{M})\boldsymbol\Omega^{-1}(\mathbf{X}-\mathbf{M})^{\rm T}\right|^{-\frac{\nu+n+p-1}{2}},$$

where the constant of integration *K* is given by

$$K = \frac{\Gamma_p\left(\frac{\nu+n+p-1}{2}\right)}{(\pi)^\frac{np}{2} \Gamma_p\left(\frac{\nu+p-1}{2}\right)} |\boldsymbol\Omega|^{-\frac{n}{2}} |\boldsymbol\Sigma|^{-\frac{p}{2}}.$$

Here $\Gamma_p$ is the [multivariate gamma function](wikipedia://en/946510).

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

If $\mathbf{X} \sim \mathcal{T}_{n\times p}(\nu, \mathbf{M}, \mathbf{\Sigma}, \mathbf{\Omega})$, then we have the following properties:[^o3]

### Expected values {#Expected_values}

The mean, or [expected value](wikipedia://en/9653) is, if $\nu > 1$:

$$E[\mathbf{X}] = \mathbf{M}$$

and we have the following second-order expectations, if $\nu > 2$:

$$E[(\mathbf{X} - \mathbf{M})(\mathbf{X} - \mathbf{M})^{T}] = \frac{\mathbf{\Sigma}\operatorname{tr}(\mathbf{\Omega})}{\nu-2}$$

$$E[(\mathbf{X} - \mathbf{M})^{T} (\mathbf{X} - \mathbf{M})] = \frac{\mathbf{\Omega}\operatorname{tr}(\mathbf{\Sigma}) }{\nu-2}$$

where $\operatorname{tr}$ denotes [trace](wikipedia://en/43270).

More generally, for appropriately dimensioned matrices **A**,**B**,**C**:

$$\begin{aligned} E[(\mathbf{X}- \mathbf{M})\mathbf{A}(\mathbf{X}- \mathbf{M})^{T}] &= \frac{\mathbf{\Sigma}\operatorname{tr}(\mathbf{A}^T\mathbf{\Omega})}{\nu - 2} \\ E[(\mathbf{X}- \mathbf{M})^T\mathbf{B}(\mathbf{X}- \mathbf{M})] &= \frac{\mathbf{\Omega}\operatorname{tr}(\mathbf{B}^T \mathbf{\Sigma})}{\nu - 2} \\ E[(\mathbf{X}- \mathbf{M})\mathbf{C}(\mathbf{X}- \mathbf{M})] &= \frac{\mathbf{\Sigma}\mathbf{C}^T\mathbf{\Omega}}{\nu - 2} \end{aligned}$$

### Transformation {#Transformation}

[Transpose](wikipedia://en/173844) transform:

$$\mathbf{X}^T \sim\mathcal{T}_{p\times n}(\nu, \mathbf{M}^T, \mathbf{\Omega}, \mathbf{\Sigma})$$

Linear transform: let **A** (*r*-by-*n*), be of full [rank](wikipedia://en/26561) *r ≤ n* and **B** (*p*-by-*s*), be of full rank *s ≤ p*, then:

$$\mathbf{AXB}\sim \mathcal{T}_{r\times s}(\nu,\mathbf{AMB}, \mathbf{A\Sigma A}^T, \mathbf{B}^T\mathbf{\Omega B} )$$

The [characteristic function](wikipedia://en/3229401) and various other properties can be derived from the re-parameterised formulation (see below).

:::

## Re-parameterized matrix *t*-distribution {#Re-parameterized_matrix_t-distribution}

An alternative parameterisation of the **matrix *t*-distribution** uses two parameters $\alpha$ and $\beta$ in place of $\nu$.[^o11]

This formulation reduces to the standard matrix *t*-distribution with $\beta=2, \alpha=\frac{\nu+p-1}{2}.$

This formulation of the matrix *t*-distribution can be derived as the [compound distribution](https://en.wikipedia.org/wiki/Compound_distribution) that results from an infinite [mixture](https://en.wikipedia.org/wiki/Mixture_density) of a matrix normal distribution with an [inverse multivariate gamma distribution](https://en.wikipedia.org/wiki/Inverse_multivariate_gamma_distribution) placed over either of its covariance matrices.

::: {#o13 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

If $\mathbf{X} \sim {\rm T}_{n,p}(\alpha,\beta,\mathbf{M},\boldsymbol\Sigma, \boldsymbol\Omega)$ then[^o3][^o11]

$$\mathbf{X}^{\rm T} \sim {\rm T}_{p,n}(\alpha,\beta,\mathbf{M}^{\rm T},\boldsymbol\Omega, \boldsymbol\Sigma).$$

The property above comes from [Sylvester's determinant theorem](wikipedia://en/8468#Sylvester's_determinant_theorem):

$$\det\left(\mathbf{I}_n + \frac{\beta}{2}\boldsymbol\Sigma^{-1}(\mathbf{X} - \mathbf{M})\boldsymbol\Omega^{-1}(\mathbf{X}-\mathbf{M})^{\rm T}\right) =$$

$$\det\left(\mathbf{I}_p + \frac{\beta}{2}\boldsymbol\Omega^{-1}(\mathbf{X}^{\rm T} - \mathbf{M}^{\rm T})\boldsymbol\Sigma^{-1}(\mathbf{X}^{\rm T}-\mathbf{M}^{\rm T})^{\rm T}\right) .$$

If $\mathbf{X} \sim {\rm T}_{n,p}(\alpha,\beta,\mathbf{M},\boldsymbol\Sigma, \boldsymbol\Omega)$ and $\mathbf{A}(n\times n)$ and $\mathbf{B}(p\times p)$ are [nonsingular matrices](https://en.wikipedia.org/wiki/Nonsingular_matrices) then[^o3][^o11]

$$\mathbf{AXB} \sim {\rm T}_{n,p}(\alpha,\beta,\mathbf{AMB},\mathbf{A}\boldsymbol\Sigma\mathbf{A}^{\rm T}, \mathbf{B}^{\rm T}\boldsymbol\Omega\mathbf{B}) .$$

The [characteristic function](wikipedia://en/3229401) is[^o11]

$$\phi_T(\mathbf{Z}) = \frac{\exp({\rm tr}(i\mathbf{Z}'\mathbf{M}))|\boldsymbol\Omega|^\alpha}{\Gamma_p(\alpha)(2\beta)^{\alpha p}} |\mathbf{Z}'\boldsymbol\Sigma\mathbf{Z}|^\alpha B_\alpha\left(\frac{1}{2\beta}\mathbf{Z}'\boldsymbol\Sigma\mathbf{Z}\boldsymbol\Omega\right),$$

where

$$B_\delta(\mathbf{WZ}) = |\mathbf{W}|^{-\delta} \int_{\mathbf{S}>0} \exp\left({\rm tr}(-\mathbf{SW}-\mathbf{S^{-1}Z})\right)|\mathbf{S}|^{-\delta-\frac12(p+1)}d\mathbf{S},$$

and where $B_\delta$ is the type-two [Bessel function](wikipedia://en/4700) of Herz of a matrix argument.

:::
