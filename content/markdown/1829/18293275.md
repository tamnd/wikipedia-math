# Maximising measure

::: {#o1 .subject cue=lead name="Maximising measure"}

In [mathematics](wikipedia://en/18831) — specifically, in [ergodic theory](wikipedia://en/258986) — a **maximising measure** is a particular kind of [probability measure](wikipedia://en/45437). Informally, a probability measure *μ* is a maximising measure for some function *f* if the [integral](https://en.wikipedia.org/wiki/Lebesgue_integration) of *f* with respect to *μ* is "as big as it can be". The theory of maximising measures is relatively young and quite little is known about their general structure and properties.

:::

::: {#o3 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let *X* be a [topological space](wikipedia://en/30450) and let *T* : *X* → *X* be a [continuous function](wikipedia://en/6122). Let Inv(*T*) denote the set of all [Borel](wikipedia://en/4322) probability measures on *X* that are [invariant](wikipedia://en/7635201) under *T*, i.e., for every Borel-measurable subset *A* of *X*, *μ*(*T*<sup>−1</sup>(*A*)) = *μ*(*A*). (Note that, by the [Krylov-Bogolyubov theorem](https://en.wikipedia.org/wiki/Krylov-Bogolyubov_theorem), if *X* is [compact](wikipedia://en/6042) and [metrizable](https://en.wikipedia.org/wiki/Metrizable), Inv(*T*) is non-empty.) Define, for continuous functions *f* : *X* → **R**, the maximum integral function *β* by

$$\beta(f) := \sup \left. \left\{ \int_{X} f \, \mathrm{d} \nu \right| \nu \in \mathrm{Inv}(T) \right\}.$$

A probability measure *μ* in Inv(*T*) is said to be a **maximising measure** for *f* if

$$\int_{X} f \, \mathrm{d} \mu = \beta(f).$$

:::

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- It can be shown that if *X* is a [compact space](wikipedia://en/6042), then Inv(*T*) is also compact with respect to the topology of [weak convergence of measures](https://en.wikipedia.org/wiki/Weak_convergence_of_measures). Hence, in this case, each continuous function *f* : *X* → **R** has at least one maximising measure.
- If *T* is a continuous map of a compact [metric space](wikipedia://en/20018) *X* into itself and *E* is a [topological vector space](wikipedia://en/45752) that is [densely](wikipedia://en/23523594) and [continuously embedded](https://en.wikipedia.org/wiki/Continuously_embedded) in *C*(*X*; **R**), then the set of all *f* in *E* that have a unique maximising measure is equal to a [countable](wikipedia://en/6026) [intersection](wikipedia://en/23476429) of [open](wikipedia://en/39358) dense subsets of *E*.

:::
