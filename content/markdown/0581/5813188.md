# Ricker model

::: {#o1 .subject cue=lead name="Ricker model"}

*Image: Ricker bifurcation.png.* [Bifurcation diagram](wikipedia://en/79173) of the Ricker model with carrying capacity of 1000

The **Ricker model**, named after [Bill Ricker](https://en.wikipedia.org/wiki/Bill_Ricker), is a classic discrete [population model](wikipedia://en/11397469) which gives the expected number *N*<sub>*t*+1</sub> (or density) of individuals in generation *t* + 1 as a function of the number of individuals in the previous generation,[^o2]

:::

$$N_{t+1} = N_t e^{r\left(1-\frac{N_t}{k}\right)}.\,$$

Here *r* is interpreted as an intrinsic growth rate and *k* as the [carrying capacity](wikipedia://en/47544) of the environment. Unlike some other models like the [Logistic map](wikipedia://en/18137), the carrying capacity in the Ricker model is not a hard barrier that cannot be exceeded by the population, but it only determines the overall scale of the population. The Ricker model was introduced in 1954 by Ricker in the context of [stock](https://en.wikipedia.org/wiki/Fish_stocks) and recruitment in [fisheries](https://en.wikipedia.org/wiki/Fisheries).

The model can be used to predict the number of fish that will be present in a fishery.[^o3][^o4] Subsequent work has derived the model under other assumptions such as [scramble competition](https://en.wikipedia.org/wiki/Scramble_competition),[^o5] within-year resource limited competition[^o8] or even as the outcome of source-sink Malthusian patches linked by density-dependent dispersal.[^o6][^o7] The Ricker model is a [limiting case](wikipedia://en/40400729) of the [Hassell model](https://en.wikipedia.org/wiki/Hassell_model)[^o8] which takes the form

$$N_{t+1} = k_1 \frac{N_t}{ \left(1+k_2 N_t\right)^c}.$$

When *c* = 1, the Hassell model is simply the [Beverton–Holt model](wikipedia://en/11185796).
