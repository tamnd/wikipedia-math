# Acyclic object

::: {#o1 .subject cue=lead name="Acyclic object"}

In [mathematics](wikipedia://en/18831), in the field of [homological algebra](wikipedia://en/139410), given an [abelian category](wikipedia://en/45063) $\mathcal{C}$ having enough injectives and an additive (covariant) [functor](wikipedia://en/10987)

:::

$$F :\mathcal{C}\to\mathcal{D},$$

an **acyclic object** with respect to $F$, or simply an $F$-acyclic object, is an object $A$ in $\mathcal{C}$ such that

${\rm R}^i F (A) = 0 \,\!$ for all $i>0 \,\!$,

where ${\rm R}^i F$ are the [right derived functors](wikipedia://en/433875) of $F$.[^o2]
