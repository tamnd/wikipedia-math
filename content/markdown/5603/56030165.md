# Gyárfás–Sumner conjecture

::: {#o1 .subject cue=lead name="Gyárfás–Sumner conjecture"}

::: {#o2 .problem cue=unsolved}

Does forbidding both a tree and a clique as induced subgraphs produce graphs of bounded chromatic number?

:::

In [graph theory](wikipedia://en/12401), the **Gyárfás–Sumner conjecture** says that for any fixed [tree](wikipedia://en/48560) $T$, the class of all $T$-free graphs is [$\chi$-bounded](https://en.wikipedia.org/wiki/Χ-bounded); that is, every graph that contains neither $T$ nor $K_t$ as an [induced subgraph](wikipedia://en/1655188) can be [properly colored](wikipedia://en/426743) using a constant number of colors, depending only on $T$ and $t$. Equivalently, it says that every $K_t$-free graph $G$ contains any arbitrarily chosen tree $T$ (as an induced subgraph), as long as $\chi(G)$ is large enough. It is named after [András Gyárfás](wikipedia://en/614969) and [David Sumner](wikipedia://en/47676305), who formulated it independently in 1975 and 1981 respectively. It remains unproven.

:::

In this conjecture, it is not possible to replace $T$ by a graph with cycles. As [Paul Erdős](wikipedia://en/601284) and [András Hajnal](wikipedia://en/21765779) have shown, there exist graphs with arbitrarily large chromatic number and, at the same time, arbitrarily large [girth](wikipedia://en/12013). Using these graphs, one can obtain graphs that avoid any fixed choice of a cyclic graph and clique (of more than two vertices) as induced subgraphs, and exceed any fixed bound on the chromatic number.

The conjecture is known to be true for certain special choices of $T$, including [paths](wikipedia://en/4587190), [stars](wikipedia://en/19310129), and trees of radius two. It is also known that, for any tree $T$, the graphs that do not contain any [subdivision](wikipedia://en/353021) of $T$ are $\chi$-bounded.
