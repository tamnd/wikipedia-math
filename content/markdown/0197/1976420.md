# Littlewood–Offord problem

::: {#o1 .subject cue=lead name="Littlewood–Offord problem"}

In the [mathematical](wikipedia://en/18831) field of [combinatorial geometry](https://en.wikipedia.org/wiki/Combinatorial_geometry), the **Littlewood–Offord problem** is the problem of determining the number of [subsums](https://en.wikipedia.org/wiki/Subsum) of a set of [vectors](wikipedia://en/32370) that fall in a given [convex set](wikipedia://en/6292). More formally, if *V* is a vector space of [dimension](wikipedia://en/38267) *d*, the problem is to determine, given a finite subset of vectors *S* and a convex subset *A*, the number of subsets of *S* whose [summation](wikipedia://en/246160) is in *A*.

:::

The first [upper bound](https://en.wikipedia.org/wiki/Upper_bound) for this problem was proven (for *d* = 1 and *d* = 2) in 1938 by [John Edensor Littlewood](wikipedia://en/158371) and [A. Cyril Offord](https://en.wikipedia.org/wiki/Albert_Cyril_Offord).[^o2] This **Littlewood–Offord lemma** states that if *S* is a set of *n* real or [complex numbers](wikipedia://en/5826) of [absolute value](wikipedia://en/991) at least one and *A* is any [disc](wikipedia://en/329542) of [diameter](wikipedia://en/8007) *r*, then not more than $cr2^n (\log n) n^{-1/2}$ of the 2<sup>*n*</sup> possible subsums of *S* fall into the disc.

In 1945 [Paul Erdős](wikipedia://en/601284) improved the upper bound for *d* = 1 and *r* = 1 to

$${n \choose \lfloor{n/2}\rfloor} \approx 2^n \, \frac{1}{\sqrt{n}}$$

using [Sperner's theorem](wikipedia://en/748844).[^o3] This bound is sharp; equality is attained when all vectors in *S* are equal. In 1966, Kleitman showed that the same bound held for complex numbers. In 1970, he extended this to the setting when *V* is a [normed space](https://en.wikipedia.org/wiki/Normed_space).[^o3]

Suppose *S* = {*v*<sub>1</sub>, …, *v*<sub>*n*</sub>}. By subtracting

$$\frac{1}{2} \sum_{i = 1}^n v_i$$

from each possible subsum (that is, by changing the origin and then scaling by a factor of 2), the Littlewood–Offord problem is equivalent to the problem of determining the number of sums of the form

$$\sum_{i = 1}^n \varepsilon_i v_i$$

that fall in the target set *A*, where $\varepsilon_i$ takes the value $\frac{1}{2}$ or $-\frac{1}{2}$. This makes the problem into a [probabilistic](https://en.wikipedia.org/wiki/Probabilistic) one, in which the question is of the distribution of these *[random vectors](https://en.wikipedia.org/wiki/Random_vector)*, and what can be said knowing nothing more about the *v*<sub>*i*</sub>.

If the $\varepsilon_i$'s take values from 1 or -1, instead of $\frac{1}{2}$ or $-\frac{1}{2}$, the target set *A* for the **Littlewood-Offord lemma** can be changed from a disk of [diameter](wikipedia://en/8007) one to a disk of [radius](wikipedia://en/1780815) one to account for the doubling of the coefficients.
