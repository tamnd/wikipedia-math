# Quantization (linguistics)

::: {#o1 .subject cue=lead name="Quantization"}

In [formal semantics](wikipedia://en/31395652), a [predicate](https://en.wikipedia.org/wiki/Predicate_%28grammar%29) is **quantized** if it being true of an entity requires that it is *not* true of any proper subparts of that entity. For example, if something is an "apple", then no proper subpart of that thing is an "apple". If something is "water", then many of its subparts will also be "water". Hence, the predicate "apple" is quantized, while "water" is not.[^o2][^o3]

:::

Formally, a **quantization** predicate *QUA* can be defined as follows, where $U$ is the [universe of discourse](https://en.wikipedia.org/wiki/Universe_of_discourse), $F$ is a variable over [sets](wikipedia://en/26691), and $p$ is a [mereological](wikipedia://en/375380) part [structure](wikipedia://en/1809181) on $U$ with $<_p$ the [mereological](wikipedia://en/375380) part-of [relation](wikipedia://en/22517558):[^o2][^o3]

$$(\forall F\subseteq U_p)(QUA(F) \iff (\forall x,y)(F(x)\wedge F(y) \Rightarrow \neg x<_p y))$$

Quantization was first proposed by [Manfred Krifka](https://en.wikipedia.org/wiki/Manfred_Krifka) as part of his [mereological](wikipedia://en/375380) approach to the semantics of nominals. It has since been applied to other phenomena such as [telicity](https://en.wikipedia.org/wiki/Telicity).
