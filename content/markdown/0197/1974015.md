# Wilson quotient

::: {#o1 .subject cue=lead name="Wilson quotient"}

The **Wilson quotient** *W*(*p*) is defined as:

:::

$$W(p) = \frac{(p-1)! + 1}{p}$$

If *p* is a [prime number](wikipedia://en/23666), the quotient is an [integer](wikipedia://en/14563) by [Wilson's theorem](wikipedia://en/227323); moreover, if *p* is [composite](wikipedia://en/82289), the quotient is not an integer. If *p* divides *W*(*p*), it is called a [Wilson prime](wikipedia://en/323646). The integer values of *W*(*p*) are :

*W*(2) = 1

*W*(3) = 1

*W*(5) = 5

*W*(7) = 103

*W*(11) = 329891

*W*(13) = 36846277

*W*(17) = 1230752346353

*W*(19) = 336967037143579

...

It is known that[^o2]

$$W(p)\equiv B_{2(p-1)}-B_{p-1}\pmod{p},$$

$$p-1+ptW(p)\equiv pB_{t(p-1)}\pmod{p^2},$$

where $B_k$ is the *k*-th [Bernoulli number](wikipedia://en/4964). Note that the first relation comes from the second one by subtraction, after substituting $t=1$ and $t=2$.
