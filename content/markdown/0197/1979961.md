# Torricelli's equation

::: {#o1 .subject cue=lead name="Torricelli's equation"}

In physics, **Torricelli's equation**, or **Torricelli's formula**, is an equation created by [Evangelista Torricelli](wikipedia://en/210413) to find the final [velocity](wikipedia://en/20491903) of a moving object with [constant acceleration](wikipedia://en/2443#Uniform_acceleration) along an axis (for example, the *x* axis) without having a known time interval.

:::

The equation itself is[^o2]

$$v_\text{f}^2 = v_\text{i}^2 + 2a\Delta x,$$

where

$v_\text{f}$ is the object's final [velocity](wikipedia://en/20491903) along the *x* axis on which the acceleration is constant,

$v_\text{i}$ is the object's initial velocity along the *x* axis,

$a$ is the object's [acceleration](wikipedia://en/2443) along the *x* axis, which is given as a constant,

$\Delta x$ is the object's change in position along the *x* axis, also called [displacement](https://en.wikipedia.org/wiki/Displacement_%28vector%29).

In this and all subsequent equations in this article, the subscript $x$ (as in ${v_\text{f}}_x$) is implied, but is not expressed explicitly for clarity in presenting the equations.

This equation is valid along any axis on which the acceleration is constant.

## Derivation {#Derivation}

### Without differentials and integration {#Without_differentials_and_integration}

Begin with the following relations for the case of uniform acceleration:

::: {#o5 .equation cue=numblk name="1"}

$$x_\text{f} - x_\text{i} = v_\text{i}t + \tfrac{1}{2}at^2 \tag{1}$$

:::

::: {#o6 .equation cue=numblk name="2"}

$$v_\text{f} - v_\text{i} = at \tag{2}$$

:::

Take ((1)), and multiply both sides with acceleration $a$

::: {#o7 .equation cue=numblk name="3"}

$$a(x_\text{f} - x_\text{i}) = av_\text{i}t + \tfrac{1}{2}a^2t^2 \tag{3}$$

:::

The following rearrangement of the right hand side makes it easier to recognize the coming substitution:

::: {#o8 .equation cue=numblk name="4"}

$$a(x_\text{f} - x_\text{i}) = v_\text{i}(at) + \tfrac{1}{2}(at)^2 \tag{4}$$

:::

Use ((2)) to substitute the product $at$:

::: {#o9 .equation cue=numblk name="5"}

$$a(x_\text{f} - x_\text{i}) = v_\text{i} (v_\text{f} - v_\text{i}) + \tfrac{1}{2}(v_\text{f} - v_\text{i})^2 \tag{5}$$

:::

Work out the multiplications:

::: {#o10 .equation cue=numblk name="6"}

$$a(x_\text{f} - x_\text{i}) = v_\text{i} v_\text{f} - v_\text{i}^2 + \tfrac{1}{2}v_\text{f}^2 - v_\text{i} v_\text{f} + \tfrac{1}{2}v_\text{i}^2 \tag{6}$$

:::

The crossterms $v_\text{i}v_\text{f}$ drop away against each other, leaving only squared terms:

::: {#o11 .equation cue=numblk name="7"}

$$a(x_\text{f} - x_\text{i}) = \tfrac{1}{2}v_\text{f}^2 - \tfrac{1}{2}v_\text{i}^2 \tag{7}$$

:::

((7)) rearranges to the form of Torricelli's equation as presented at the start of the article:

::: {#o12 .equation cue=numblk name="8"}

$$v_\text{f}^2 = v_\text{i}^2 + 2a\Delta x \tag{8}$$

:::

### Using differentials and integration {#Using_differentials_and_integration}

Begin with the definitions of velocity as the derivative of the position, and acceleration as the derivative of the velocity:

::: {#o14 .equation cue=numblk name="9"}

$$v = \frac{dx}{dt} \tag{9}$$

:::

::: {#o15 .equation cue=numblk name="10"}

$$a = \frac{dv}{dt} \tag{10}$$

:::

Set up integration from initial position $x_\text{i}$ to final position $x_\text{f}$

::: {#o16 .equation cue=numblk name="11"}

$$\int_{x_\text{i}}^{x_\text{f}}a\,dx \tag{11}$$

:::

In accordance with ((9)) we can substitute $dx$ with $v\,dt$, with corresponding change of limits.

::: {#o17 .equation cue=numblk name="12"}

$$\int_{t_\text{i}}^{t_\text{f}} a\,v\,dt \tag{12}$$

:::

Here changing the order of $a$ and $v$ makes it easier to recognize the upcoming substitution.

::: {#o18 .equation cue=numblk name="13"}

$$\int_{t_\text{i}}^{t_\text{f}} v\,a\,dt \tag{13}$$

:::

In accordance with ((10)) we can substitute $a\,dt$ with $dv$, with corresponding change of limits.

::: {#o19 .equation cue=numblk name="14"}

$$\int_{v_\text{i}}^{v_\text{f}} v\,dv \tag{14}$$

:::

So we have:

::: {#o20 .equation cue=numblk name="15"}

$$\int_{x_\text{i}}^{x_\text{f}} a\,dx=\int_{v_\text{i}}^{v_\text{f}}v\,dv \tag{15}$$

:::

Since the acceleration is constant, we can factor it out of the integration:

::: {#o21 .equation cue=numblk name="16"}

$$a\int_{x_\text{i}}^{x_\text{f}}dx=\int_{v_\text{i}}^{v_\text{f}}v\,dv \tag{16}$$

:::

Evaluating the integration:

::: {#o22 .equation cue=numblk name="17"}

$$a x\Big|_{x=x_\text{i}}^{x=x_\text{f}} = \tfrac{1}{2} v^2 \Big|_{v=v_\text{i}}^{v=v_\text{f}} \tag{17}$$

:::

::: {#o23 .equation cue=numblk name="18"}

$$a \left(x_\text{f} - x_\text{i}\right) = \tfrac{1}{2} \left(v_\text{f}^2 - v_\text{i}^2\right) \tag{18}$$

:::

The factor $x_\text{f}-x_\text{i}$ is the displacement $\Delta x$:

::: {#o24 .equation cue=numblk name="19"}

$$2a\Delta x=v_\text{f}^2-v_\text{i}^2 \tag{19}$$

:::

::: {#o25 .equation cue=numblk name="20"}

$$v_\text{f}^2=v_\text{i}^2+2a\Delta x \tag{20}$$

:::

::: {#o27 .application cue=heading name="Application"}

## Application {#Application}

Combining Torricelli's equation with $F=ma$ gives the work-energy theorem.

Torricelli's equation and the generalization to non-uniform acceleration have the same form:

Repeat of ((16)):

::: {#o28 .equation cue=numblk name="21"}

$$\int_{x_\text{i}}^{x_\text{f}}a\,dx=\int_{v_\text{i}}^{v_\text{f}}v\,dv \tag{21}$$

:::

Evaluating the right hand side:

::: {#o29 .equation cue=numblk name="22"}

$$\int_{x_\text{i}}^{x_\text{f}} a\,dx=\tfrac{1}{2}v_\text{f}^2 - \tfrac{1}{2}v_\text{i}^2 \tag{22}$$

:::

To compare with Torricelli's equation: repeat of ((7)):

::: {#o30 .equation cue=numblk name="23"}

$$a(x_\text{f} - x_\text{i}) = \tfrac{1}{2}v_\text{f}^2 - \tfrac{1}{2}v_\text{i}^2 \tag{23}$$

:::

To derive the [work-energy theorem](wikipedia://en/149861): start with $F=ma$ and on both sides state the integral with respect to the position coordinate. If both sides are integrable then the resulting expression is valid:

::: {#o31 .equation cue=numblk name="24"}

$$\int_{x_\text{i}}^{x_\text{f}} F\,dx = \int_{x_\text{i}}^{x_\text{f}} ma\,dx \tag{24}$$

:::

Use ((22)) to process the right hand side:

::: {#o32 .equation cue=numblk name="25"}

$$\int_{x_\text{i}}^{x_\text{f}} F\,dx = \tfrac{1}{2}mv_\text{f}^2 - \tfrac{1}{2}mv_\text{i}^2 \tag{25}$$

:::

The reason that the right hand sides of ((22)) and ((23)) are the same:

First consider the case with two consecutive stages of different uniform acceleration, first from $s_0$ to $s_1$, and then from $s_1$ to $s_2$.

Expressions for each of the two stages:

$$a_1(s_1-s_0) = \tfrac{1}{2}v_1^2 - \tfrac{1}{2}v_0^2$$

$$a_2(s_2-s_1) = \tfrac{1}{2}v_2^2 - \tfrac{1}{2}v_1^2$$

Since these expressions are for consecutive intervals they can be added; the result is a valid expression.

Upon addition the intermediate term $\tfrac{1}{2}v_1^2$ drops out; only the outer terms $\tfrac{1}{2}v_2^2$ and $\tfrac{1}{2}v_0^2$ remain:

::: {#o33 .equation cue=numblk name="26"}

$$a_1(s_1-s_0) + a_2(s_2-s_1) = \tfrac{1}{2}v_2^2 - \tfrac{1}{2}v_0^2 \tag{26}$$

:::

The above result generalizes: the total distance can be subdivided into any number of subdivisions; after adding everything together only the outer terms remain; all of the intermediate terms drop out.

The generalization of ((26)) to an arbitrary number of subdivisions of the total interval from $s_0$ to $s_n$ can be expressed as a summation:

::: {#o34 .equation cue=numblk name="27"}

$$\sum_{i=1}^n a_\text{i}(s_\text{i} - s_{i-1}) = \tfrac{1}{2}v_n^2 - \tfrac{1}{2}v_{i-1}^2 \tag{27}$$

:::
