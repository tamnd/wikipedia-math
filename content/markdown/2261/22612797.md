# PEGASUS

::: {#o1 .subject cue=lead name="PEGASUS"}

**PEGASUS** is an [encryption](wikipedia://en/10294) [algorithm](wikipedia://en/775) used for [satellite](https://en.wikipedia.org/wiki/Satellite) [telemetry](https://en.wikipedia.org/wiki/Telemetry), command link and mission [data transfers](https://en.wikipedia.org/wiki/Data_transfer).

:::

According to a budget item justification document for FY 2004–2005,[^o2] this cryptographic algorithm is used for [Global Positioning Systems](https://en.wikipedia.org/wiki/Global_Positioning_System) (GPS), [Space-Based Infrared Systems](https://en.wikipedia.org/wiki/Space-Based_Infrared_System) (SBIRS), [MILSATCOM](https://en.wikipedia.org/wiki/Military_Satellite_Communications_Systems_Wing), and other Special Project Systems.
