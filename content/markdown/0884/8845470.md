# Golod–Shafarevich theorem

::: {#o1 .subject cue=lead name="Golod–Shafarevich theorem"}

In [mathematics](wikipedia://en/18831), the **Golod–Shafarevich theorem** is a result in non-commutative [homological algebra](wikipedia://en/139410) which solves the **class field tower problem** by showing that [class field](wikipedia://en/3021036) towers can be infinite. It is named after [Evgeny Golod](https://en.wikipedia.org/wiki/Evgeny_Golod) and [Igor Shafarevich](wikipedia://en/1091815), who proved it in 1964.

:::

::: {#o3 .statement cue=named-heading name="Statement of the inequality"}

## Statement of the inequality {#Statement_of_the_inequality}

Let $A=K\langle x_1,\dots,x_n\rangle$ be the [free algebra](wikipedia://en/494669) over a [field](wikipedia://en/10603) $K$ in $n=d+1$ non-commuting variables, and let $J$ be the two-sided [ideal](wikipedia://en/25977) of $A$ generated by [homogeneous](wikipedia://en/1698977) elements $f_j$ of $A$ of degree $d_j$ with

$$2\leq d_1\leq d_2\leq \cdots$$

where $d_j$ tends to infinity. Let $r_i$ be the number of $d_j$ equal to $i$, for all $i\geq 2$.

Let $B = A/J$; this is a [graded algebra](https://en.wikipedia.org/wiki/Graded_algebra). Let $b_j=\dim B_j$. The *fundamental inequality* of Golod and Shafarevich states that

$$b_j\geq nb_{j-1} -\sum_{i=2}^{j} b_{j-i} r_i.$$

for all $j$. As a consequence, $B$ is infinite-dimensional if $r_i \leq d^2/4$ for all $i\geq 2$.

:::

::: {#o5 .application cue=heading name="Applications"}

## Applications {#Applications}

This result has important applications in [combinatorial group theory](wikipedia://en/979834):

- If $G$ is a non-trivial finite [$p$-group](wikipedia://en/24664), then $r > d^2/4$, where $d = \dim H^1(G,\mathbb{Z}/p\mathbb{Z})$ and $r = \dim H^2(G,\mathbb{Z}/p\mathbb{Z})$ (the mod $p$ [cohomology groups](wikipedia://en/248635) of $G$). In particular, if $G$ is a finite $p$-group with minimal number of generators $d$ and has $r$ relators in a given presentation, then $r > d^2/4$.
- For each prime $p$, there is an infinite group $G$ generated by three elements in which each element has order a power of $p$. The group $G$ provides a [counterexample](wikipedia://en/143151) to the [generalised Burnside conjecture](https://en.wikipedia.org/wiki/Burnside's_problem): it is a [finitely generated](wikipedia://en/963042) infinite [torsion group](wikipedia://en/3568695), although there is no uniform bound on the order of its elements.

### Class field theory {#Class_field_theory}

In [class field theory](wikipedia://en/242695), the **class field [tower](wikipedia://en/28194169)** of a [number field](https://en.wikipedia.org/wiki/Number_field) is created by iterating the [Hilbert class field](wikipedia://en/3021036) construction. The class field tower problem asks whether this tower is always finite. A consequence of the Golod–Shafarevich theorem is that such towers may be [infinite](https://en.wikipedia.org/wiki/Infinite_tower_of_fields) (in other words, do not always terminate in a field equal to its [Hilbert](wikipedia://en/8302) class field). Specifically, if $K$ is an [imaginary quadratic field](wikipedia://en/454781) whose [discriminant](wikipedia://en/3022963) has at least six prime factors, then the maximal [unramified](wikipedia://en/1190816) 2-extension of $K$ has infinite [degree](wikipedia://en/4382697).

More generally, a number field with sufficiently many prime factors in the discriminant has an infinite class field tower.
