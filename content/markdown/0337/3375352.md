# Positive and negative sets

::: {#o1 .subject cue=lead name="Positive and negative sets"}

In [measure theory](https://en.wikipedia.org/wiki/Measure_theory), given a [measurable space](https://en.wikipedia.org/wiki/Sigma-algebra) $(X, \Sigma)$ and a [signed measure](wikipedia://en/2985811) $\mu$ on it, a set $A \in \Sigma$ is called a **positive set** for $\mu$ if every $\Sigma$-measurable subset of $A$ has nonnegative measure; that is, for every $E \subseteq A$ that satisfies $E \in \Sigma,$ $\mu(E) \geq 0$ holds.[^o2]

:::

Similarly, a set $A \in \Sigma$ is called a **negative set** for $\mu$ if for every subset $E \subseteq A$ satisfying $E \in \Sigma,$ $\mu(E) \leq 0$ holds.[^o2]

Intuitively, a measurable set $A$ is positive (resp. negative) for $\mu$ if $\mu$ is nonnegative (resp. nonpositive) everywhere on $A.$ Of course, if $\mu$ is a [nonnegative measure](wikipedia://en/19873), every element of $\Sigma$ is a positive set for $\mu.$

In the light of [Radon–Nikodym theorem](wikipedia://en/338746), if $\nu$ is a σ-finite positive measure such that $|\mu| \ll \nu,$ a set $A$ is a positive set for $\mu$ [if and only if](wikipedia://en/14922) the Radon–Nikodym derivative $d\mu/d\nu$ is nonnegative $\nu$-almost everywhere on $A.$ Similarly, a negative set is a set where $d\mu/d\nu \leq 0$ $\nu$-almost everywhere.

::: {#o4 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

It follows from the definition that every measurable subset of a positive or negative set is also positive or negative. Also, the union of a sequence of positive or negative sets is also positive or negative; more formally, if $A_1, A_2, \ldots$ is a sequence of positive sets, then

$$\bigcup_{n=1}^\infty A_n$$

is also a positive set; the same is true if the word "positive" is replaced by "negative".

A set which is both positive and negative is a $\mu$-[null set](wikipedia://en/21520), for if $E$ is a measurable subset of a positive and negative set $A,$ then both $\mu(E) \geq 0$ and $\mu(E) \leq 0$ must hold, and therefore, $\mu(E) = 0.$

:::

## Hahn decomposition {#Hahn_decomposition}

The [Hahn decomposition theorem](wikipedia://en/2985858) states that for every measurable space $(X, \Sigma)$ with a signed measure $\mu,$ there is a [partition](wikipedia://en/340240) of $X$ into a positive and a negative set; such a partition $(P, N)$ is unique [up to](wikipedia://en/44787) $\mu$-null sets, and is called a *[Hahn decomposition](https://en.wikipedia.org/wiki/Hahn_decomposition)* of the signed measure $\mu.$[^o2]

Given a Hahn decomposition $(P, N)$ of $X,$ it is easy to show that $A \subseteq X$ is a positive set if and only if $A$ differs from a subset of $P$ by a $\mu$-null set; equivalently, if $A \smallsetminus P$ is $\mu$-null. The same is true for negative sets, if $N$ is used instead of $P.$
