# Peano–Jordan measure

::: {#o1 .subject cue=lead name="Peano–Jordan measure"}

In [mathematics](wikipedia://en/18831), the **Peano–Jordan measure** (also known as the **Jordan content**) is an extension of the notion of [size](https://en.wikipedia.org/wiki/Geometric_measure) ([length](wikipedia://en/1898401), [area](https://en.wikipedia.org/wiki/Area_%28mathematics%29), [volume](wikipedia://en/32498)) to shapes more complicated than, for example, a [triangle](wikipedia://en/30654), [disk](wikipedia://en/329542), or [parallelepiped](wikipedia://en/23975).

:::

For a set to have Jordan measure it should be [well-behaved](https://en.wikipedia.org/wiki/Well-behaved) in a certain restrictive sense. For this reason, it is now more common to work with the [Lebesgue measure](wikipedia://en/18198), which is an extension of the Jordan measure to a larger class of sets. Historically, the Jordan measure came first, towards the end of the nineteenth century.

The Peano–Jordan measure is named after its originators, the French mathematician [Camille Jordan](wikipedia://en/355931), and the Italian mathematician [Giuseppe Peano](wikipedia://en/13043).[^o2]

::: {#o4 .definition kind=definition/notation cue=heading name="Terminology"}

## Terminology {#Terminology}

For historical reasons, the term *Jordan measure* is now well-established for this [set function](wikipedia://en/25911217), despite the fact that it is not a true [measure](wikipedia://en/19873) in its modern definition, since Jordan-measurable sets do not form a [σ-algebra](wikipedia://en/29586). For example, singleton sets $\{x\}_{x \in \mathbb{R}}$in $\mathbb{R}$ each have a Jordan measure of 0, while $\mathbb{Q} \cap [0,1]$, a countable union of them, is not Jordan-measurable.[^o5] For this reason, some authors[^o6] prefer to use the term Jordan [content](wikipedia://en/9999200).

:::

## Jordan measure of "simple sets" {#Jordan_measure_of_"simple_sets"}

*Image: Simple set1.png.* A simple set is, by definition, a union of (possibly overlapping) rectangles.

*Image: Simple set2.png.* The simple set from above decomposed as a union of non-overlapping rectangles.

Consider [Euclidean space](wikipedia://en/9697) $\mathbb{R}^n.$ Jordan measure is first defined on [Cartesian products](wikipedia://en/24104095) of [bounded](wikipedia://en/48258) half-open [intervals](wikipedia://en/49172)

$$C = [a_1, b_1) \times [a_2, b_2) \times \cdots \times [a_n, b_n)$$

that are closed at the left and open at the right with all endpoints $a_i$ and $b_i$ finite real numbers (half-open intervals is a technical choice; as we see below, one can use closed or open intervals if preferred). Such a set will be called a $n$-dimensional rectangle, or simply a rectangle. The Jordan measure of such a rectangle is defined to be the product of the lengths of the intervals:

$$m(C) = (b_1 - a_1) (b_2 - a_2) \cdots (b_n - a_n).$$

Next, one considers simple sets, sometimes called polyrectangles, which are finite [unions](wikipedia://en/47949) of rectangles,

$$S = C_1 \cup C_2 \cup \cdots \cup C_k$$

for any $k \geq 1.$

One cannot define the Jordan measure of $S$ as simply the sum of the measures of the individual rectangles, because such a representation of $S$ is far from unique, and there could be significant overlaps between the rectangles.

Luckily, any such simple set $S$ can be rewritten as a union of another finite family of rectangles, rectangles which this time are mutually [disjoint](https://en.wikipedia.org/wiki/Disjoint_set), and then one defines the Jordan measure $m(S)$ as the sum of measures of the disjoint rectangles.

One can show that this definition of the Jordan measure of $S$ is independent of the representation of $S$ as a finite union of disjoint rectangles. It is in the "rewriting" step that the assumption of rectangles being made of half-open intervals is used.

## Extension to more complicated sets {#Extension_to_more_complicated_sets}

*Image: Jordan illustration.png.* A set (represented in the picture by the region inside the blue curve) is Jordan measurable if and only if it can be well-approximated both from the inside and outside by simple sets (their boundaries are shown in dark green and dark pink respectively).

Notice that a set which is a product of closed intervals,

$$[a_1, b_1] \times [a_2, b_2] \times \cdots \times [a_n, b_n]$$

is not a simple set, and neither is a [ball](wikipedia://en/160556). Thus, so far the set of Jordan measurable sets is still very limited. The key step is then defining a bounded set to be Jordan measurable if it is "well-approximated" by simple sets, exactly in the same way as a function is [Riemann integrable](wikipedia://en/26390) if it is well-approximated by piecewise-constant functions.

Formally, for a bounded set $B,$ define its inner Jordan measure as

$$m_*(B) = \sup_{S\subseteq B} m(S)$$

and its outer Jordan measure as

$$m^*(B) = \inf_{S\supseteq B} m(S)$$

where the [infimum](https://en.wikipedia.org/wiki/Infimum) and [supremum](https://en.wikipedia.org/wiki/Supremum) are taken over simple sets $S.$ The set $B$ is said to be a Jordan measurable set if the inner measure of $B$ equals the outer measure. The common value of the two measures is then simply called the Jordan measure of $B$. The Jordan measure is the [set function](wikipedia://en/25911217) that sends Jordan measurable sets to their Jordan measure.

It turns out that all rectangles (open or closed), as well as all balls, [simplexes](wikipedia://en/39781), etc., are Jordan measurable. Also, if one considers two [continuous functions](wikipedia://en/6122), the set of points between the graphs of those functions is Jordan measurable as long as that set is bounded and the common domain of the two functions is Jordan measurable. Any finite union and intersection of Jordan measurable sets is Jordan measurable, as well as the [set difference](https://en.wikipedia.org/wiki/Set_difference) of any two Jordan measurable sets. A [compact set](https://en.wikipedia.org/wiki/Compact_set) is not necessarily Jordan measurable. For example, the [ε-Cantor set](https://en.wikipedia.org/wiki/Smith-Volterra-Cantor_Set) is not. Its inner Jordan measure vanishes, since its [complement](wikipedia://en/54347) is [dense](wikipedia://en/23523594); however, its outer Jordan measure does not vanish, since it cannot be less than (in fact, is equal to) its Lebesgue measure. Also, a bounded [open set](wikipedia://en/39358) is not necessarily Jordan measurable. For example, the complement of the fat Cantor set (within the interval) is not. A bounded set is Jordan measurable if and only if its [indicator function](wikipedia://en/240790) is [Riemann-integrable](wikipedia://en/26390), and the value of the integral is its Jordan measure.<https://planetmath.org/RiemannMultipleIntegral>

Equivalently, for a bounded set $B$ the inner Jordan measure of $B$ is the Lebesgue measure of the [topological interior](wikipedia://en/55610) of $B$ and the outer Jordan measure is the Lebesgue measure of the [closure](wikipedia://en/42309).[^o9] From this it follows that a bounded set is Jordan measurable if and only if its [topological boundary](wikipedia://en/72824) has Lebesgue measure zero. (Or equivalently, if the boundary has Jordan measure zero; the equivalence holds due to compactness of the boundary.)

## The Lebesgue measure {#The_Lebesgue_measure}

This last property greatly limits the types of sets which are Jordan measurable. For example, the set of [rational numbers](wikipedia://en/19727024) contained in the interval \[0,1\] is then not Jordan measurable, as its boundary is \[0,1\] which is not of Jordan measure zero. Intuitively however, the set of rational numbers is a "small" set, as it is [countable](https://en.wikipedia.org/wiki/Countable), and it should have "size" zero. That is indeed true, but only if one replaces the Jordan measure with the [Lebesgue measure](wikipedia://en/18198). The Lebesgue measure of a set is the same as its Jordan measure as long as that set has a Jordan measure. However, the Lebesgue measure is defined for a much wider class of sets, like the set of rational numbers in an interval mentioned earlier, and also for sets which may be unbounded or [fractals](https://en.wikipedia.org/wiki/Fractal_set). Also, the Lebesgue measure, unlike the Jordan measure, is a true [measure](wikipedia://en/19873), that is, any countable union of Lebesgue measurable sets is Lebesgue measurable, whereas countable unions of Jordan measurable sets need not be Jordan measurable.
