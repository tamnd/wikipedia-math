# Completely-S matrix

::: {#o1 .subject cue=lead name="Completely-S matrix"}

In [linear algebra](wikipedia://en/18422), a **completely-S matrix** is a [square matrix](wikipedia://en/166022) such that for every principal submatrix *R* there exists a positive vector *u* such that *Ru > 0*.[^o2]

:::
