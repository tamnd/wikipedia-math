# RC algorithm

::: {#o1 .subject cue=lead name="RC algorithm"}

The **RC algorithms** are a set of [symmetric-key encryption algorithms](https://en.wikipedia.org/wiki/Symmetric-key_encryption_algorithm) invented by [Ron Rivest](https://en.wikipedia.org/wiki/Ron_Rivest). The "RC" may stand for either **Rivest's cipher** or, more informally, **Ron's code**.[^o2] Despite the similarity in their names, the algorithms are for the most part unrelated. There have been six RC algorithms so far:

:::

- RC1 was never published.
- [RC2](wikipedia://en/632592) was a 64-bit [block cipher](wikipedia://en/4594) developed in 1987.
- RC3 was broken before ever being used.
- [RC4](wikipedia://en/25831) is a [stream cipher](wikipedia://en/49007).
- [RC5](wikipedia://en/102600) is a 32/64/128-bit block cipher developed in 1994.
- [RC6](wikipedia://en/160216), a 128-bit block cipher based heavily on RC5, was an [AES finalist](https://en.wikipedia.org/wiki/AES_process) developed in 1997.
