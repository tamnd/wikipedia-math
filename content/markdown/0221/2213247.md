# Generic filter

::: {#o1 .subject cue=lead name="Generic filter"}

In the mathematical field of [set theory](wikipedia://en/27553), a **generic filter** is a kind of object used in the theory of [forcing](wikipedia://en/152205), a technique used for many purposes, but especially to establish the [independence](wikipedia://en/1141208) of certain propositions from certain [formal theories](https://en.wikipedia.org/wiki/Mathematical_theory), such as [ZFC](https://en.wikipedia.org/wiki/ZFC). For example, [Paul Cohen](https://en.wikipedia.org/wiki/Paul_Cohen_%28mathematician%29) used forcing to establish that ZFC, if [consistent](https://en.wikipedia.org/wiki/Consistent_theory), cannot prove the [continuum hypothesis](wikipedia://en/5705), which states that there are exactly [$\aleph_1$](https://en.wikipedia.org/wiki/Aleph-one) [real numbers](wikipedia://en/20646438). In the contemporary re-interpretation of Cohen's proof, it proceeds by constructing a generic filter that codes more than $\aleph_1$ reals, without changing the value of $\aleph_1$.

:::

Formally, let *P* be a [partially ordered set](wikipedia://en/23572), and let *F* be a [filter](wikipedia://en/19719) on *P*; that is, *F* is a subset of *P* such that:

1. *F* is nonempty
1. If *p*, *q* ∈ *P* and *p* ≤ *q* and *p* is an element of *F*, then *q* is an element of *F* (*F* is [closed upward](https://en.wikipedia.org/wiki/Upper_set))
1. If *p* and *q* are elements of *F*, then there is an element *r* of *F* such that *r* ≤ *p* and *r* ≤ *q* (*F* is [downward directed](wikipedia://en/9165))

Now if *D* is a collection of [dense](wikipedia://en/23523594) [open](wikipedia://en/39358) subsets of *P*, in the topology whose basic open sets are all sets of the form {*q*∈*P* | *q* ≤ *p*} for particular *p* in *P*, then *F* is said to be ***D*-generic** if *F* meets all sets in *D*; that is,

$F\cap E \ne \varnothing,\,$ for all *E* ∈ *D*.

Similarly, if *M* is a [transitive](wikipedia://en/2462396) [model](wikipedia://en/19858) of ZFC (or some sufficient fragment of ZFC), with *P* an element of *M* (partially ordered by ∈), then *F* is said to be ***M*-generic**, or sometimes **generic over *M***, if *F* meets all dense open subsets of *P* that are elements of *M*.
