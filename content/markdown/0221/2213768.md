# Property of Baire

::: {#o1 .subject cue=lead name="Property of Baire"}

A [subset](wikipedia://en/27631) $A$ of a [topological space](wikipedia://en/30450) $X$ has the **property of Baire** (**Baire property**, named after [René-Louis Baire](wikipedia://en/1550892)), or is called an **almost open** set, if it differs from an [open set](wikipedia://en/39358) by a [meager set](https://en.wikipedia.org/wiki/Meager_set); that is, if there is an open set $U\subseteq X$ such that $A \bigtriangleup U$ is meager (where $\bigtriangleup$ denotes the [symmetric difference](wikipedia://en/262288)).[^o2]

:::

::: {#o4 .definition cue=heading name="Definitions"}

## Definitions {#Definitions}

A subset $A \subseteq X$ of a [topological space](wikipedia://en/30450) $X$ is called **almost open** and is said to have the **property of Baire** or the **Baire property** if there is an open set $U\subseteq X$ such that $A \bigtriangleup U$ is a [meager subset](https://en.wikipedia.org/wiki/Meager_set), where $\bigtriangleup$ denotes the [symmetric difference](wikipedia://en/262288).[^o2] Further, $A$ has the **Baire property in the restricted sense** if for every subset $E$ of $X$ the intersection $A\cap E$ has the Baire property relative to $E$.[^o5]

:::

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

The family of sets with the property of Baire forms a [σ-algebra](wikipedia://en/29586). That is, the [complement](https://en.wikipedia.org/wiki/Complement_set) of an almost open set is almost open, and any [countable](https://en.wikipedia.org/wiki/Countable) [union](wikipedia://en/47949) or [intersection](wikipedia://en/23476429) of almost open sets is again almost open.[^o2] Since every open set is almost open (the empty set is meager), it follows that every [Borel set](wikipedia://en/43327) is almost open.

If a subset of a [Polish space](wikipedia://en/396622) has the property of Baire, then its corresponding [Banach–Mazur game](wikipedia://en/365811) is [determined](wikipedia://en/2596030). The converse does not hold; however, if every game in a given [adequate pointclass](wikipedia://en/10192324) $\Gamma$ is determined, then every set in $\Gamma$ has the property of Baire. Therefore, it follows from [projective determinacy](wikipedia://en/1236592), which in turn follows from sufficient [large cardinals](https://en.wikipedia.org/wiki/Large_cardinal_property), that every [projective set](https://en.wikipedia.org/wiki/Projective_set) (in a Polish space) has the property of Baire.[^o8]

It follows from the [axiom of choice](wikipedia://en/840) that there are sets of [reals](wikipedia://en/20646438) without the property of Baire. In particular, a [Vitali set](wikipedia://en/424189) does not have the property of Baire.[^o9] Already weaker versions of choice are sufficient: the [Boolean prime ideal theorem](wikipedia://en/314919) implies that there is a nonprincipal [ultrafilter](wikipedia://en/31911) on the set of [natural numbers](wikipedia://en/21474); each such ultrafilter induces, via binary representations of reals, a set of reals without the Baire property.[^o10]
