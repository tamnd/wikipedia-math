# Blum integer

::: {#o1 .subject cue=lead name="Blum integer"}

In [mathematics](wikipedia://en/18831), a [natural number](wikipedia://en/21474) *n* is a **Blum integer** if *n* = *p* × *q* is a [semiprime](wikipedia://en/339542) for which *p* and *q* are distinct [prime numbers](wikipedia://en/23666) congruent to 3 [mod](wikipedia://en/20087) 4.[^o2] That is, *p* and *q* must be of the form 4*t* + 3, for some integer *t*. Integers of this form are referred to as Blum primes.[^o3] This means that the factors of a Blum integer are [Gaussian primes](wikipedia://en/48628) with no imaginary part. ## Properties {#Properties}

Given *n* = *p* × *q* a Blum integer, *Q*<sub>*n*</sub> the set of all [quadratic residues](wikipedia://en/200091) modulo *n* and coprime to *n* and *a* ∈ *Q*<sub>*n*</sub>. Then:[^o3]

- *a* has four square roots modulo *n*, exactly one of which is also in *Q*<sub>*n*</sub>
- The unique square root of *a* in *Q*<sub>*n*</sub> is called the *principal square root* of *a* modulo *n*
- The function *f* : *Q*<sub>*n*</sub> → *Q*<sub>*n*</sub> defined by *f*(*x*) = *x*<sup>2</sup> mod *n* is a permutation. The inverse function of *f* is: *f*${}^{-1}$(*x*) = *x*<sup>((*p*−1)(*q*−1)+4)/8</sup> mod *n*.[^o6]
- For every Blum integer *n*, −1 has a [Jacobi symbol](wikipedia://en/97313) mod *n* of +1, although −1 is not a quadratic residue of *n*:

$$\left(\frac{-1}{n}\right)=\left(\frac{-1}{p}\right)\left(\frac{-1}{q}\right)=(-1)^2=1$$

No Blum integer is the [sum of two squares](https://en.wikipedia.org/wiki/Sum_of_two_squares).

:::

## History {#History}

Before modern factoring algorithms, such as [MPQS](https://en.wikipedia.org/wiki/MPQS) and [NFS](wikipedia://en/152734), were developed, it was thought to be useful to select Blum integers as [RSA](https://en.wikipedia.org/wiki/RSA_%28algorithm%29) moduli. This is no longer regarded as a useful precaution, since MPQS and NFS are able to factor Blum integers with the same ease as RSA moduli constructed from randomly selected primes.
