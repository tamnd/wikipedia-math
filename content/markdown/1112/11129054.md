# Cesàro equation

::: {#o1 .subject cue=lead name="Cesàro equation"}

In [geometry](wikipedia://en/18973446), the **Cesàro equation** of a [plane curve](wikipedia://en/971691) is an [equation](wikipedia://en/9284) relating the [curvature](wikipedia://en/60770) ($\kappa$) at a point of the curve to the [arc length](wikipedia://en/1898401) ($s$) from the start of the curve to the given point. It may also be given as an equation relating the [radius of curvature](https://en.wikipedia.org/wiki/Radius_of_curvature_%28mathematics%29) ($R$) to [arc length](wikipedia://en/1898401). (These are equivalent because $R = \tfrac{1}{\kappa}$.) Two [congruent](wikipedia://en/39330) curves will have the same Cesàro equation. Cesàro equations are named after [Ernesto Cesàro](wikipedia://en/605144).

:::

## Log-aesthetic curves {#Log-aesthetic_curves}

The family of log-aesthetic curves[^o3] is determined in the general ($\alpha \ne 0$) case by the following intrinsic equation:

$$R(s)^\alpha = c_0s + c_1$$

This is equivalent to the following explicit formula for curvature:

$$\kappa(s) = (c_0s+c_1)^{-1/\alpha}$$

Further, the $c_1$ constant above represents simple re-parametrization of the arc length parameter, while $c_0$ is equivalent to uniform scaling, so log-aesthetic curves are fully characterized by the $\alpha$ parameter.

In the special case of $\alpha=0$, the log-aesthetic curve becomes [Nielsen's spiral](https://en.wikipedia.org/wiki/Nielsen's_spiral), with the following Cesàro equation (where $a$ is a uniform scaling parameter):

$$\kappa(s) = \frac{e^{\frac{s}{a}}}{a}$$

A number of well known curves are instances of the log-aesthetic curve family. These include circle ($\alpha = \infty$), [Euler spiral](wikipedia://en/19107713) ($\alpha = -1$), [Logarithmic spiral](wikipedia://en/42373) ($\alpha = 1$), and [Circle involute](wikipedia://en/840704) ($\alpha = 2$).

## Examples {#Examples}

Some curves have a particularly simple representation by a Cesàro equation. Some examples are:

- [Line](wikipedia://en/946975): $\kappa = 0$.
- [Circle](wikipedia://en/6220): $\kappa = \frac{1}{\alpha}$, where ${\alpha}$ is the radius.
- [Logarithmic spiral](wikipedia://en/42373): $\kappa=\frac{a}{s}$, where ${a}$ is a constant.
- [Circle involute](wikipedia://en/840704): $\kappa=\frac{a}{\sqrt s}$, where ${a}$ is a constant.
- [Euler spiral](wikipedia://en/19107713): $\kappa=as$, where ${a}$ is a constant.
- [Catenary](wikipedia://en/7163): $\kappa=\frac{a}{s^2+a^2}$, where ${a}$ is a constant.

:::

## Related parameterizations {#Related_parameterizations}

The Cesàro equation of a curve is related to its [Whewell equation](wikipedia://en/11128841) in the following way: if the Whewell equation is $\varphi = f(s)$ then the Cesàro equation is $\kappa = f(s)$.
