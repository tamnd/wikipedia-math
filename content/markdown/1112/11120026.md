# Sum-free set

::: {#o1 .subject cue=lead name="Sum-free set"}

In [additive combinatorics](wikipedia://en/18243392) and [number theory](wikipedia://en/4460333), a [subset](wikipedia://en/27631) *A* of an [abelian group](wikipedia://en/2974) *G* is said to be **sum-free** if the [sumset](https://en.wikipedia.org/wiki/Sumset) *A* + *A* is [disjoint](wikipedia://en/39359) from *A*. In other words, *A* is sum-free if the equation $a + b = c$ has no solution with $a,b,c \in A$.

:::

For example, the set of [odd numbers](https://en.wikipedia.org/wiki/Odd_number) is a sum-free subset of the [integers](wikipedia://en/14563), and the set {*N* + 1, ..., 2*N*} forms a large sum-free subset of the set {1, ..., 2*N*}. [Fermat's Last Theorem](wikipedia://en/19021953) is the statement that, for a given integer *n* > 2, the set of all nonzero *n*<sup>th</sup> [powers](wikipedia://en/4023591) of the integers is a sum-free set.

Some basic questions that have been asked about sum-free sets are:

- How many sum-free subsets of {1, ..., *N*} are there, for an integer *N*? [Ben Green](https://en.wikipedia.org/wiki/Ben_J._Green) has shown[^o2] that the answer is $O(2^{N/2})$, as predicted by the [Cameron–Erdős conjecture](wikipedia://en/13587617).[^o3]
- How many sum-free sets does an abelian group *G* contain?[^o4]
- What is the size of the largest sum-free set that an abelian group *G* contains?[^o4]

A sum-free set is said to be **maximal** if it is not a [proper subset](https://en.wikipedia.org/wiki/Proper_subset) of another sum-free set.

Let $f: [1, \infty) \to [1, \infty)$ be defined by $f(n)$ is the largest number $k$ such that any set of *n* nonzero integers has a sum-free subset of size *k*. The [function](wikipedia://en/185427) is [subadditive](https://en.wikipedia.org/wiki/Subadditive), and by the [Fekete subadditivity lemma](wikipedia://en/745789#Properties), $\lim_n\frac{f(n)}{n}$ exists.

[Erdős](https://en.wikipedia.org/wiki/Erdős) [proved](wikipedia://en/82285) that $\lim_n\frac{f(n)}{n} \geq \frac 13$, and [conjectured](wikipedia://en/6138) that equality holds.[^o5] This was proved in 2014 by Eberhard, Green, and Manners giving an upper bound matching Erdős' lower bound up to a function or order $o(n)$, $f(n) \leq \frac{n}{3}+o(n)$.[^o6]

Erdős also asked if $f(n)\geq \frac{n}{3}+\omega(n)$ for some $\omega(n)\rightarrow \infty$, in 2025 Bedert in a preprint proved this giving the lower bound $f(n)\geq \frac{n}{3}+c\log\log n$.[^o7][^o8]
