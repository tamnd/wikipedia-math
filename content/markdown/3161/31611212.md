# CH-quasigroup

::: {#o1 .subject cue=lead name="CH-quasigroup"}

In mathematics, a **CH-quasigroup**, introduced by (Manin 1986, definition 1.3), is a symmetric [quasigroup](wikipedia://en/25223) in which any three elements generate an abelian quasigroup. "CH" stands for [cubic hypersurface](https://en.wikipedia.org/wiki/Cubic_hypersurface).

:::
