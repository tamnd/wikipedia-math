# Quillen–Lichtenbaum conjecture

::: {#o1 .subject cue=lead name="Quillen–Lichtenbaum conjecture"}

In [mathematics](wikipedia://en/18831), the **Quillen–Lichtenbaum conjecture** is a [conjecture](wikipedia://en/6138) relating [étale cohomology](wikipedia://en/396231) to [algebraic K-theory](wikipedia://en/598500) introduced by (Quillen 1975, 175), who was inspired by earlier conjectures of (Lichtenbaum 1973). (Kahn 1997) and (Rognes Weibel 2000) [proved](wikipedia://en/82285) the Quillen–Lichtenbaum conjecture at the [prime](wikipedia://en/23666) 2 for some [number fields](https://en.wikipedia.org/wiki/Number_field). [Voevodsky](https://en.wikipedia.org/wiki/Voevodsky), using some important results of [Markus Rost](wikipedia://en/6842771), proved the [Bloch–Kato conjecture](https://en.wikipedia.org/wiki/Bloch–Kato_conjecture), which implies the Quillen–Lichtenbaum conjecture for all primes.

:::

::: {#o7 .statement cue=heading name="Statement"}

## Statement {#Statement}

The conjecture in Quillen's original form states that if *A* is a finitely-generated algebra over the integers and *l* is prime, then there is a spectral sequence analogous to the [Atiyah–Hirzebruch spectral sequence](wikipedia://en/6795342), starting at

$E_2^{pq} = H^p_{\text{etale}}(\text{Spec }A[\ell^{-1}], Z_\ell(-q/2)),$ (which is understood to be 0 if *q* is [odd](wikipedia://en/143135))

and abutting to

$$K_{-p-q}A\otimes Z_\ell$$

for −*p* − *q* > 1 + dim *A*.

:::

## *K*-theory of the integers {#K-theory_of_the_integers}

Assuming the Quillen–Lichtenbaum conjecture and the [Vandiver conjecture](https://en.wikipedia.org/wiki/Vandiver_conjecture), the *K*-groups of the integers, *K*<sub>*n*</sub>(**Z**), are given by:

- 0 if *n* = 0 mod 8 and *n* > 0, **Z** if *n* = 0
- **Z** ⊕ **Z**/2 if *n* = 1 mod 8 and *n* > 1, **Z**/2 if *n* = 1.
- **Z**/*c*<sub>*k*</sub> ⊕ **Z**/2 if *n* = 2 mod 8
- **Z**/8*d*<sub>*k*</sub> if *n* = 3 mod 8
- 0 if *n* = 4 mod 8
- **Z** if *n* = 5 mod 8
- **Z**/*c*<sub>*k*</sub> if *n* = 6 mod 8
- **Z**/4*d*<sub>*k*</sub> if *n* = 7 mod 8

where *c*<sub>*k*</sub>/*d*<sub>*k*</sub> is the [Bernoulli number](wikipedia://en/4964) *B*<sub>2*k*</sub>/*k* in lowest terms and *n* is 4*k* − 1 or 4*k* − 2 (Weibel 2005).
