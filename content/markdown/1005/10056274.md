# Data transformation (statistics)

::: {#o1 .subject cue=lead name="Data transformation"}

*Image: Population vs area.svg.* A [scatterplot](https://en.wikipedia.org/wiki/Scatterplot) in which the [areas](https://en.wikipedia.org/wiki/List_of_countries_by_area) of the sovereign states and dependent territories in the world are plotted on the vertical axis against their [populations](https://en.wikipedia.org/wiki/List_of_countries_by_population) on the horizontal axis. The upper plot uses raw data. In the lower plot, both the area and population data have been transformed using the logarithm function.

In [statistics](wikipedia://en/26685), **data [transformation](https://en.wikipedia.org/wiki/Transformation_%28mathematics%29)** is the application of a [deterministic](wikipedia://en/522958) mathematical [function](wikipedia://en/185427) to each point in a [data](https://en.wikipedia.org/wiki/Data) set—that is, each data point *z<sub>i</sub>* is replaced with the transformed value *y<sub>i</sub>* = *f*(*z<sub>i</sub>*), where *f* is a function. Transforms are usually applied so that the data appear to more closely meet the assumptions of a [statistical inference](wikipedia://en/27577) procedure that is to be applied, or to improve the interpretability or appearance of [graphs](wikipedia://en/15934463).

:::

Nearly always, the function that is used to transform the data is [invertible](wikipedia://en/14907), and generally is [continuous](wikipedia://en/6122). The transformation is usually applied to a collection of comparable measurements. For example, if we are working with data on peoples' incomes in some [currency](https://en.wikipedia.org/wiki/Currency) unit, it would be common to transform each person's income value by the [logarithm](wikipedia://en/17860) function.

## Motivation {#Motivation}

Guidance for how data should be transformed, or whether a transformation should be applied at all, should come from the particular statistical analysis to be performed. For example, a simple way to construct an approximate 95% [confidence interval](wikipedia://en/280911) for the population mean is to take the [sample mean](wikipedia://en/612) plus or minus two [standard error](wikipedia://en/552520) units. However, the constant factor 2 used here is particular to the [normal distribution](wikipedia://en/21462), and is only applicable if the sample mean varies approximately normally. The [central limit theorem](wikipedia://en/39406) states that in many situations, the sample mean does vary normally if the sample size is reasonably large. However, if the [population](wikipedia://en/27585) is substantially [skewed](wikipedia://en/28212) and the sample size is at most moderate, the approximation provided by the central limit theorem can be poor, and the resulting confidence interval will likely have the wrong [coverage probability](wikipedia://en/22856967). Thus, when there is evidence of substantial skew in the data, it is common to transform the data to a [symmetric](wikipedia://en/53741) [distribution](wikipedia://en/23543)[^o3] before constructing a confidence interval. If desired, the confidence interval for the quantiles (such as the median) can then be transformed back to the original scale using the inverse of the transformation that was applied to the data.[^o4][^o5]

Data can also be transformed to make them easier to visualize. For example, suppose we have a scatterplot in which the points are the countries of the world, and the data values being plotted are the land area and population of each country. If the plot is made using untransformed data (e.g. square kilometers for area and the number of people for population), most of the countries would be plotted in tight cluster of points in the lower left corner of the graph. The few countries with very large areas and/or populations would be spread thinly around most of the graph's area. Simply rescaling units (e.g., to thousand square kilometers, or to millions of people) will not change this. However, following [logarithmic](wikipedia://en/17860) transformations of both area and population, the points will be spread more uniformly in the graph.

Another reason for applying data transformation is to improve interpretability, even if no formal statistical analysis or visualization is to be performed. For example, suppose we are comparing cars in terms of their fuel economy. These data are usually presented as "kilometers per liter" or "miles per gallon". However, if the goal is to assess how much additional fuel a person would use in one year when driving one car compared to another, it is more natural to work with the data transformed by applying the [reciprocal function](wikipedia://en/229940), yielding liters per kilometer, or gallons per mile.

## In regression {#In_regression}

Data transformation may be used as a remedial measure to make data suitable for modeling with [linear regression](wikipedia://en/48758386) if the original data violates one or more assumptions of linear regression.[^o7] For example, the simplest linear regression models assume a [linear](https://en.wikipedia.org/wiki/Linear) relationship between the [expected value](wikipedia://en/9653) of *Y* (the [response variable](wikipedia://en/437701#Statistics_synonyms) to be predicted) and each [independent variable](wikipedia://en/437701) (when the other independent variables are held fixed). If linearity fails to hold, even approximately, it is sometimes possible to transform either the independent or dependent variables in the regression model to improve the linearity.[^o8] For example, addition of quadratic functions of the original independent variables may lead to a linear relationship with [expected value](wikipedia://en/9653) of *Y,* resulting in a [polynomial regression](wikipedia://en/21893202) model, a special case of linear regression.

Another assumption of linear regression is [homoscedasticity](https://en.wikipedia.org/wiki/Homoscedasticity), that is the [variance](wikipedia://en/32344) of [errors](wikipedia://en/461509) must be the same regardless of the values of predictors. If this assumption is violated (i.e. if the data is [heteroscedastic](https://en.wikipedia.org/wiki/Heteroscedasticity)), it may be possible to find a transformation of *Y* alone, or transformations of both *X* (the [predictor variables](wikipedia://en/437701#Statistics_synonyms)) and *Y*, such that the homoscedasticity assumption (in addition to the linearity assumption) holds true on the transformed variables[^o8] and linear regression may therefore be applied on these.

Yet another application of data transformation is to address the problem of lack of [normality](wikipedia://en/21462) in error terms. Univariate normality is not needed for [least squares](wikipedia://en/82359) estimates of the regression parameters to be meaningful (see [Gauss–Markov theorem](wikipedia://en/170353)). However confidence intervals and [hypothesis tests](https://en.wikipedia.org/wiki/Hypothesis_test) will have better statistical properties if the variables exhibit [multivariate normality](wikipedia://en/50347). Transformations that stabilize the variance of error terms (i.e. those that address heteroscedasticity) often also help make the error terms approximately normal.[^o8][^o9]

### Examples {#Examples}

**Equation:** $Y = a + bX$

**Meaning:** A unit increase in X is associated with an average of b units increase in Y.

**Equation:** $\log(Y) = a + bX$

(From exponentiating both sides of the equation: $Y = e^a e^{bX}$)

**Meaning:** A unit increase in X is associated with an average increase of b units in $\log(Y)$, or equivalently, Y increases on an average by a multiplicative factor of $e^{b}\!$. For illustrative purposes, if [base-10 logarithm](wikipedia://en/174482) were used instead of [natural logarithm](wikipedia://en/21476) in the above transformation and the same symbols (*a* and *b*) are used to denote the regression coefficients, then a unit increase in X would lead to a $10^{b}$times increase in Y on an average. If b were 1, then this implies a 10-fold increase in Y for a unit increase in X

**Equation:** $Y = a + b \log(X)$

**Meaning:** A k-fold increase in X is associated with an average of $b \times \log(k)$units increase in Y. For illustrative purposes, if [base-10 logarithm](wikipedia://en/174482) were used instead of [natural logarithm](wikipedia://en/21476) in the above transformation and the same symbols (*a* and *b*) are used to denote the regression coefficients, then a tenfold increase in X would result in an average increase of $b \times \log_{10}(10) = b$ units in Y

**Equation:** $\log(Y) = a + b \log(X)$

(From exponentiating both sides of the equation: $Y = e^a X^{b}$)

**Meaning:** A k-fold increase in X is associated with a $k^{b}$multiplicative increase in Y on an average. Thus if X doubles, it would result in Y changing by a multiplicative factor of $2^{b}\!$.[^o12]

:::

### Alternative {#Alternative}

[Generalized linear models](https://en.wikipedia.org/wiki/Generalized_linear_models) (GLMs) provide a flexible generalization of ordinary linear regression that allows for response variables that have error distribution models other than a normal distribution. GLMs allow the linear model to be related to the response variable via a link function and allow the magnitude of the variance of each measurement to be a function of its predicted value.[^o14][^o15]

## Common cases {#Common_cases}

The **[logarithm](wikipedia://en/17860) transformation** and **[square root](wikipedia://en/29208) transformation** are commonly used for positive data, and the **[multiplicative inverse](wikipedia://en/229940) transformation** (**reciprocal transformation**) can be used for non-zero data. The *[power transformation](https://en.wikipedia.org/wiki/Power_transformation_%28statistics%29)* is a family of transformations parameterized by a non-negative value λ that includes the logarithm, square root, and multiplicative inverse transformations as special cases. To approach data transformation systematically, it is possible to use [statistical estimation](wikipedia://en/1565926) techniques to estimate the parameter λ in the power transformation, thereby identifying the transformation that is approximately the most appropriate in a given setting. Since the power transformation family also includes the identity transformation, this approach can also indicate whether it would be best to analyze the data without a transformation. In regression analysis, this approach is known as the *[Box–Cox transformation](https://en.wikipedia.org/wiki/Box–Cox_transformation)*.

The reciprocal transformation, some power transformations such as the [Yeo–Johnson transformation](https://en.wikipedia.org/wiki/Yeo–Johnson_transformation), and certain other transformations such as applying the [inverse hyperbolic sine](wikipedia://en/3804557), can be meaningfully applied to data that include both positive and negative values[^o18] (the power transformation is invertible over all real numbers if λ is an odd integer). However, when both negative and positive values are observed, it is sometimes common to begin by adding a constant to all values, producing a set of non-negative data to which any power transformation can be applied.[^o5]

A common situation where a data transformation is applied is when a value of interest ranges over several [orders of magnitude](wikipedia://en/22657). Many physical and social phenomena exhibit such behavior — incomes, species populations, galaxy sizes, and rainfall volumes, to name a few. Power transforms, and in particular the logarithm, can often be used to induce symmetry in such data. The logarithm is often favored because it is easy to interpret its result in terms of "fold changes".

The logarithm also has a useful effect on ratios. If we are comparing positive quantities *X* and *Y* using the ratio *X* / *Y*, then if *X* \< *Y*, the ratio is in the interval (0,1), whereas if *X* > *Y*, the ratio is in the half-line (1,∞), where the ratio of 1 corresponds to equality. In an analysis where *X* and *Y* are treated symmetrically, the log-ratio log(*X* / *Y*) is zero in the case of equality, and it has the property that if *X* is *K* times greater than *Y*, the log-ratio is the equidistant from zero as in the situation where *Y* is *K* times greater than *X* (the log-ratios are log(*K*) and −log(*K*) in these two situations).

If values are naturally restricted to be in the range 0 to 1, not including the end-points, then a [logit transformation](wikipedia://en/172068) may be appropriate: this yields values in the range (−∞,∞).

### Transforming to normality {#Transforming_to_normality}

\1. It is not always necessary or desirable to transform a data set to resemble a normal distribution. However, if symmetry or normality are desired, they can often be induced through one of the power transformations.

\2. A linguistic power function is distributed according to the [Zipf-Mandelbrot law](https://en.wikipedia.org/wiki/Zipf-Mandelbrot_law). The distribution is extremely spiky and [leptokurtic](https://en.wikipedia.org/wiki/Leptokurtic), this is the reason why researchers had to turn their backs to statistics to solve e.g. [authorship attribution](https://en.wikipedia.org/wiki/Authorship_attribution) problems. Nevertheless, usage of Gaussian statistics is perfectly possible by applying data transformation.[^o20]

\3. To assess whether normality has been achieved after transformation, any of the standard [normality tests](wikipedia://en/8617378) may be used. A graphical approach is usually more informative than a formal statistical test and hence a [normal quantile plot](wikipedia://en/4031859) is commonly used to assess the fit of a data set to a normal population. Alternatively, rules of thumb based on the sample [skewness](wikipedia://en/28212) and [kurtosis](wikipedia://en/16848) have also been proposed.[^o21][^o22]

### Transforming to a uniform distribution or an arbitrary distribution {#Transforming_to_a_uniform_distribution_or_an_arbitrary_distribution}

If we observe a set of *n* values *X*<sub>1</sub>, ..., *X*<sub>*n*</sub> with no ties (i.e., there are *n* distinct values), we can replace *X*<sub>*i*</sub> with the transformed value *Y*<sub>*i*</sub> = *k*, where *k* is defined such that *X*<sub>*i*</sub> is the *k*<sup>th</sup> largest among all the *X* values. This is called the *rank transform*,[^o24] and creates data with a perfect fit to a [uniform distribution](https://en.wikipedia.org/wiki/Uniform_distribution_%28discrete%29). This approach has a [population](wikipedia://en/27585) analogue.

Using the [probability integral transform](wikipedia://en/8405353), if *X* is any [random variable](wikipedia://en/25685), and *F* is the [cumulative distribution function](wikipedia://en/5793) of *X*, then as long as *F* is invertible, the random variable *U* = *F*(*X*) follows a uniform distribution on the [unit interval](wikipedia://en/49324) \[0,1\].

From a uniform distribution, we can transform to any distribution with an invertible cumulative distribution function. If *G* is an invertible cumulative distribution function, and *U* is a uniformly distributed random variable, then the random variable *G*<sup>−1</sup>(*U*) has *G* as its cumulative distribution function.

Putting the two together, if *X* is any random variable, *F* is the invertible cumulative distribution function of *X*, and *G* is an invertible cumulative distribution function then the random variable *G*<sup>−1</sup>(*F*(*X*)) has *G* as its cumulative distribution function.

### Variance stabilizing transformations {#Variance_stabilizing_transformations}

Many types of statistical data exhibit a "[variance](wikipedia://en/32344)-on-mean relationship", meaning that the variability is different for data values with different [expected values](https://en.wikipedia.org/wiki/Expected_values). As an example, in comparing different populations in the world, the variance of income tends to increase with mean income. If we consider a number of small area units (e.g., counties in the United States) and obtain the mean and variance of incomes within each county, it is common that the counties with higher mean income also have higher variances.

A [variance-stabilizing transformation](wikipedia://en/22715170) aims to remove a variance-on-mean relationship, so that the variance becomes constant relative to the mean. Examples of variance-stabilizing transformations are the [Fisher transformation](wikipedia://en/865764) for the sample correlation coefficient, the [square root](wikipedia://en/29208) transformation or [Anscombe transform](wikipedia://en/12382740) for [Poisson](wikipedia://en/23009144) data (count data), the [Box–Cox transformation](https://en.wikipedia.org/wiki/Box–Cox_transformation) for regression analysis, and the [arcsine square root transformation](wikipedia://en/3698838#Arcsine_transformation) or angular transformation for proportions ([binomial](wikipedia://en/3876) data). While commonly used for statistical analysis of proportional data, the arcsine square root transformation is not recommended because [logistic regression](wikipedia://en/226631) or a [logit transformation](https://en.wikipedia.org/wiki/Logit_transformation) are more appropriate for binomial or non-binomial proportions, respectively, especially due to decreased [type-II error](wikipedia://en/5657877).[^o26][^o5]

:::

## Transformations for multivariate data {#Transformations_for_multivariate_data}

Univariate functions can be applied point-wise to multivariate data to modify their marginal distributions. It is also possible to modify some attributes of a multivariate distribution using an appropriately constructed transformation. For example, when working with [time series](wikipedia://en/406624) and other types of sequential data, it is common to [difference](wikipedia://en/39147) the data to improve [stationarity](wikipedia://en/329898). If data generated by a random vector *X* are observed as vectors *X*<sub>i</sub> of observations with [covariance matrix](wikipedia://en/191752) Σ, a [linear transformation](https://en.wikipedia.org/wiki/Linear_transformation) can be used to [decorrelate](wikipedia://en/5839494) the data. To do this, the [Cholesky decomposition](wikipedia://en/134433) is used to express Σ = *A* *A**. Then the transformed vector*****Y*<sub>i</sub> =*A*<sup>−1</sup>*X*<sub>i</sub> has the [identity matrix](wikipedia://en/59718) as its covariance matrix.***
