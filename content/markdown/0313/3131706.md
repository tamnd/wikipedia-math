# Holomorphic functional calculus

::: {#o1 .subject cue=lead name="Holomorphic functional calculus"}

In [mathematics](wikipedia://en/18831), **holomorphic functional calculus** is [functional calculus](wikipedia://en/965348) with [holomorphic functions](wikipedia://en/14110). That is to say, given a holomorphic function *f* of a [complex](wikipedia://en/5826) argument *z* and an [operator](wikipedia://en/22213) *T*, the aim is to construct an operator, *f*(*T*), which naturally extends the function *f* from complex argument to operator argument. More precisely, the functional calculus defines a continuous algebra homomorphism from the holomorphic functions on a neighbourhood of the [spectrum](https://en.wikipedia.org/wiki/Spectrum_of_an_operator) of *T* to the bounded operators.

:::

This article will discuss the case where *T* is a [bounded linear operator](https://en.wikipedia.org/wiki/Bounded_linear_operator) on some [Banach space](wikipedia://en/3989). In particular, *T* can be a [square matrix](wikipedia://en/166022) with complex entries, a case which will be used to illustrate functional calculus and provide some heuristic insights for the assumptions involved in the general construction.

## Motivation {#Motivation}

### Need for a general functional calculus {#Need_for_a_general_functional_calculus}

In this section *T* will be assumed to be a *n* × *n* matrix with complex entries.

If a given function *f* is of certain special type, there are natural ways of defining *f*(*T*). For instance, if

$$p(z)= \sum_{i=0}^m a_i z^i$$

is a complex [polynomial](wikipedia://en/23000), one can simply substitute *T* for *z* and define

$$p(T) = \sum_{i=0}^m a_i T^i$$

where *T*<sup>0</sup> = *I*, the [identity matrix](wikipedia://en/59718). This is the **polynomial functional calculus**. It is a homomorphism from the ring of polynomials to the ring of *n* × *n* matrices.

Extending slightly from the polynomials, if *f* : **C** → **C** is holomorphic everywhere, i.e. an [entire function](wikipedia://en/10372), with [MacLaurin series](https://en.wikipedia.org/wiki/MacLaurin_series)

$$f(z)= \sum_{i=0}^{\infty} a_i z^i,$$

mimicking the polynomial case suggests we define

$$f(T)= \sum_{i=0}^{\infty} a_i T^i.$$

Since the MacLaurin series converges everywhere, the above series will converge, in a chosen [operator norm](wikipedia://en/246722). An example of this is the [exponential](wikipedia://en/9678) of a matrix. Replacing *z* by *T* in the MacLaurin series of *f*(*z*) = *e<sup>z</sup>* gives

$$f(T) = e^T = I+T+\frac{T^2}{2!}+\frac{T^3}{3!}+\cdots.$$

The requirement that the MacLaurin series of *f* converges everywhere can be relaxed somewhat. From above it is evident that all that is really needed is the radius of convergence of the MacLaurin series be greater than ǁ*T*ǁ, the operator norm of *T*. This enlarges somewhat the family of *f* for which *f*(*T*) can be defined using the above approach. However it is not quite satisfactory. For instance, it is a fact from matrix theory that every non-singular *T* has a logarithm *S* in the sense that *e<sup>S</sup>* = *T*. It is desirable to have a functional calculus that allows one to define, for a non-singular *T*, ln(*T*) such that it coincides with *S*. This can not be done via [power series](wikipedia://en/59958), for example the logarithmic series

$$\ln(z+1) = z - \frac{z^2}{2} + \frac{z^3}{3} - \cdots,$$

converges only on the open [unit disk](wikipedia://en/252738). Substituting *T* for *z* in the series fails to give a well-defined expression for ln(*T* + *I*) for invertible *T + I* with ǁ*T*ǁ ≥ 1. Thus a more general functional calculus is needed.

### Functional calculus and the spectrum {#Functional_calculus_and_the_spectrum}

It is expected that a necessary condition for *f*(*T*) to make sense is *f* be defined on the [spectrum](wikipedia://en/206137) of *T*. For example, the spectral theorem for normal matrices states every normal matrix is unitarily diagonalizable. This leads to a definition of *f*(*T*) when *T* is normal. One encounters difficulties if *f*(λ) is not defined for some eigenvalue λ of *T*.

Other indications also reinforce the idea that *f*(*T*) can be defined only if *f* is defined on the spectrum of *T*. If *T* is not invertible, then (recalling that T is an n x n matrix) 0 is an eigenvalue. Since the [natural logarithm](wikipedia://en/21476) is undefined at 0, one would expect that ln(*T*) can not be defined naturally. This is indeed the case. As another example, for

$$f(z)=\frac{1}{(z-2)(z-5)}$$

the reasonable way of calculating *f*(*T*) would seem to be

$$f(T)=(T-2I)^{-1}(T-5I)^{-1}.\,$$

However, this expression is not defined if the [inverses](https://en.wikipedia.org/wiki/Matrix_inverse) on the right-hand side do not exist, that is, if either 2 or 5 are [eigenvalues](https://en.wikipedia.org/wiki/Eigenvalue) of *T*.

For a given matrix *T*, the eigenvalues of *T* dictate to what extent *f*(*T*) can be defined; i.e., *f*(λ) must be defined for all eigenvalues λ of *T*. For a general bounded operator this condition translates to "*f* must be defined on the [spectrum](wikipedia://en/206137) of *T*". This assumption turns out to be an enabling condition such that the functional calculus map, *f* → *f*(*T*), has certain desirable properties.

## Functional calculus for a bounded operator {#Functional_calculus_for_a_bounded_operator}

*Image: Functional calculus illustration1.png.* The spectrum σ(T) in light blue and the path γ in red.

*Image: Functional calculus illustration2.png.* The case when the spectrum has multiple [connected components](wikipedia://en/6233) and the corresponding path γ.

*Image: Functional calculus illustration3.png.* The case when the spectrum is not [simply connected](https://en.wikipedia.org/wiki/Simply_connected).

Let *X* be a complex Banach space, and *L*(*X*) denote the family of bounded operators on *X*.

Recall the [Cauchy integral formula](https://en.wikipedia.org/wiki/Cauchy_integral_formula) from classical function theory. Let *f* : **C** → **C** be holomorphic on some [open set](wikipedia://en/39358) *D* ⊂ **C**, and Γ be a [rectifiable](https://en.wikipedia.org/wiki/Rectifiable_curve) [Jordan curve](https://en.wikipedia.org/wiki/Jordan_curve) in *D*, that is, a closed curve of finite length without self-intersections. Assume that the set *U* of points *z* lying in the *inside* of Γ, i.e. such that the [winding number](wikipedia://en/86113) of Γ about *z* is 1, is contained in *D*. The Cauchy integral formula states

$$f(z)=\frac{1}{2\pi i}\int\nolimits_{\Gamma} \frac{f(\zeta)}{\zeta-z}\,d\zeta$$

for any *z* in *U*.

The idea is to extend this formula to functions taking values in the Banach space *L*(*X*). Cauchy's integral formula suggests the following definition (purely formal, for now):

$$f(T)=\frac{1}{2\pi i}\int_{\Gamma} \frac{f(\zeta)}{\zeta-T}\,d\zeta,$$

where (ζ−*T*)<sup>−1</sup> is the [resolvent](wikipedia://en/3378540) of *T* at ζ.

Assuming this Banach space-valued integral is appropriately defined, this proposed functional calculus implies the following necessary conditions:

1. As the scalar version of Cauchy's integral formula applies to holomorphic *f*, we anticipate that is also the case for the Banach space case, where there should be a suitable notion of holomorphy for functions taking values in the Banach space *L*(*X*).
1. As the resolvent mapping ζ → (ζ−*T*)<sup>−1</sup> is undefined on the spectrum of *T*, σ(*T*), the Jordan curve Γ should not intersect σ(*T*). Now, the resolvent mapping will be holomorphic on the complement of σ(*T*). So to obtain a non-trivial functional calculus, Γ must enclose (at least part of) σ(*T*).
1. The functional calculus should be well-defined in the sense that *f*(*T*) has to be independent of Γ.

The full definition of the functional calculus is as follows: For *T* ∈ *L*(*X*), define

$$f(T)=\frac{1}{2\pi i}\int\nolimits_{\Gamma} \frac{f(\zeta)}{\zeta-T}\,d\zeta,$$

where *f* is a holomorphic function defined on an [open set](wikipedia://en/39358) *D* ⊂ **C** which contains σ(*T*), and Γ = {γ<sub>1</sub>, ..., γ<sub>*m*</sub>} is a collection of disjoint Jordan curves in *D* bounding an "inside" set *U*, such that σ(*T*) lies in *U*, and each γ<sub>*i*</sub> is oriented in the boundary sense.

The open set *D* may vary with *f* and need not be [connected](wikipedia://en/6233) or [simply connected](https://en.wikipedia.org/wiki/Simply_connected), as shown by the figures on the right.

The following subsections make precise the notions invoked in the definition and show *f*(*T*) is indeed well defined under given assumptions.

### Banach space-valued integral {#Banach_space-valued_integral}

*Cf. [Bochner integral](wikipedia://en/3675277)*

For a continuous function *g* defined in an open neighborhood of Γ and taking values in *L*(*X*), the contour integral ∫<sub>Γ</sub>*g* is defined in the same way as for the scalar case. One can parametrize each γ<sub>*i*</sub> ∈ Γ by a real interval \[*a*, *b*\], and the integral is the limit of the [Riemann sums](https://en.wikipedia.org/wiki/Riemann_sums) obtained from ever-finer partitions of \[*a*, *b*\]. The Riemann sums converge in the [uniform operator topology](https://en.wikipedia.org/wiki/Operator_topology). We define

$$\int_{\Gamma} g = \sum\nolimits_i \int_{\gamma_i} g.$$

In the definition of the functional calculus, *f* is assumed to be holomorphic in an open neighborhood of Γ. It will be shown below that the resolvent mapping is holomorphic on the [resolvent set](wikipedia://en/8721698). Therefore, the integral

$$\frac{1}{2\pi i}\int_{\Gamma} \frac{f(\zeta)}{\zeta-T}\,d\zeta$$

makes sense.

### The resolvent mapping {#The_resolvent_mapping}

The mapping ζ → (ζ−*T*)<sup>−1</sup> is called the **resolvent mapping** of *T*. It is defined on the complement of σ(*T*), called the **resolvent set** of *T* and will be denoted by ρ(*T*).

Much of classical function theory depends on the properties of the integral

$$\frac{1}{2\pi i}\int_{\Gamma}\frac{d \zeta}{\zeta-z}.$$

The holomorphic functional calculus is similar in that the resolvent mapping plays a crucial role in obtaining properties one requires from a nice functional calculus. This subsection outlines properties of the resolvent map that are essential in this context.

::: {#o9 .statement cue=named-heading name="The 1st resolvent formula"}

#### The 1st resolvent formula {#The_1st_resolvent_formula}

Direct calculation shows, for *z*<sub>1</sub>, *z<sub>2</sub>* ∈ ρ(*T*),

$$(z_1 - T)^{-1} - (z_2 - T)^{-1} = (z_1 - T)^{-1} (z_2 - z_1) (z_2 - T)^{-1}.\,$$

Therefore,

$$(z_1 - T)^{-1} (z_2 - T)^{-1} = \frac{(z_1 - T)^{-1} - (z_2 - T)^{-1} }{(z_2 - z_1)}.$$

This equation is called the **first resolvent formula**. The formula shows (*z*<sub>1</sub>−*T*)<sup>−1</sup> and (*z*<sub>2</sub>−*T*)<sup>−1</sup> commute, which hints at the fact that the image of the functional calculus will be a commutative algebra. Letting *z*<sub>2</sub> → *z*<sub>1</sub> shows the resolvent map is (complex-) differentiable at each *z*<sub>1</sub> ∈ ρ(*T*); so the integral in the expression of functional calculus converges in *L*(*X*).

:::

#### Analyticity {#Analyticity}

Stronger statement than differentiability can be made regarding the resolvent map. The resolvent set ρ(*T*) is actually an open set on which the resolvent map is analytic. This property will be used in subsequent arguments for the functional calculus. To verify this claim, let *z*<sub>1</sub> ∈ ρ(*T*) and notice the formal expression

$$\frac{1}{z_2 - T} = \frac{1}{z_1 - T} \cdot \frac{1}{1 - \frac{z_1 - z_2}{z_1 -T}}$$

suggests we consider

$$(z_1 - T)^{-1} \sum _{n \geq 0} \left ((z_1 - z_2) (z_1 - T)^{-1} \right )^n$$

for (*z*<sub>2</sub>−*T*)<sup>−1</sup>. The above series converges in *L*(*X*), which implies the existence of (*z*<sub>2</sub>−*T*)<sup>−1</sup>, if

$$|z_1 - z_2| < \frac{1}{\left \|(z_1 - T)^{-1} \right \| } .$$

Therefore, the resolvent set ρ(*T*) is open and the power series expression on an open disk centered at *z*<sub>1</sub> ∈ ρ(*T*) shows the resolvent map is analytic on ρ(*T*).

#### Neumann series {#Neumann_series}

Another expression for (*z*−*T*)<sup>−1</sup> will also be useful. The formal expression

$$\frac{1}{z - T} = \frac{1}{z} \cdot \frac{1}{1 - \frac{T}{z}}$$

leads one to consider

$$\frac{1}{z} \sum _{n \geq 0} \left(\frac{T}{z}\right)^n.$$

This series, the *[Neumann series](wikipedia://en/2533545)*, converges to (*z*−*T*)<sup>−1</sup> if

$$\left\| \frac{T}{z} \right\| < 1, \; \text{i.e.} \; |z| > \|T\|.$$

#### Compactness of σ(*T*) {#Compactness_of_σ(T)}

From the last two properties of the resolvent we can deduce that the spectrum σ(*T*) of a bounded operator *T* is a compact subset of **C**. Therefore, for any open set *D* such that σ(*T*) ⊂ *D*, there exists a positively oriented and smooth system of Jordan curves Γ = {γ<sub>1</sub>, ..., γ<sub>*m*</sub>} such that σ(*T*) is in the inside of *Γ* and the complement of *D* is contained in the outside of Γ. Hence, for the definition of the functional calculus, indeed a suitable family of Jordan curves can be found for each *f* that is holomorphic on some *D*.

### Well-definedness {#Well-definedness}

The previous discussion has shown that the integral makes sense, i.e. a suitable collection Γ of Jordan curves does exist for each *f* and the integral does converge in the appropriate sense. What has not been shown is that the definition of the functional calculus is unambiguous, i.e. does not depend on the choice of Γ. This issue we now try to resolve.

#### A preliminary fact {#A_preliminary_fact}

For a collection of Jordan curves Γ = {γ<sub>1</sub>, ..., γ<sub>*m*</sub>} and a point *a* ∈ **C**, the winding number of Γ with respect to *a* is the sum of the winding numbers of its elements. If we define:

$$n(\Gamma, a) = \sum\nolimits_i n(\gamma_i, a),$$

the following theorem is by Cauchy:

> **Theorem.** Let *G* ⊂ **C** be an open set and Γ ⊂ *G*. If *g* : *G* → **C** is holomorphic, and for all *a* in the complement of *G*, *n*(Γ, *a*) = 0, then the contour integral of *g* on Γ is zero.

We will need the vector-valued analog of this result when *g* takes values in *L*(*X*). To this end, let *g* : *G* → *L*(*X*) be holomorphic, with the same assumptions on Γ. The idea is use the [dual space](wikipedia://en/7988) *L*(*X*)\* of *L*(*X*), and pass to Cauchy's theorem for the scalar case.

Consider the integral

$$\int_{\Gamma} g \in L(X),$$

if we can show that all φ ∈ *L*(*X*)\* vanish on this integral then the integral itself has to be zero. Since φ is bounded and the integral converges in norm, we have:

$$\phi \left (\int_{\Gamma} g \right ) = \int_{\Gamma} \phi(g).$$

But *g* is holomorphic, hence the composition φ(*g*): *G* ⊂ **C** → **C** is holomorphic and therefore by Cauchy's theorem

$$\int_{\Gamma} \phi(g) = 0.$$

#### Main argument {#Main_argument}

The well-definedness of functional calculus now follows as an easy consequence. Let *D* be an open set containing σ(*T*). Suppose Γ = {γ<sub>*i*</sub>} and Ω = {ω<sub>*j*</sub>} are two (finite) collections of Jordan curves satisfying the assumption given for the functional calculus. We wish to show

$$\int_{\Gamma} \frac{f(\zeta)}{\zeta-T}\,d\zeta = \int_{\Omega} \frac{f(\zeta)}{\zeta-T}\,d\zeta .$$

Let Ω′ be obtained from Ω by reversing the orientation of each ω<sub>*j*</sub>, then

$$\int_{\Omega} \frac{f(\zeta)}{\zeta-T}\,d\zeta = - \int_{\Omega'} \frac{f(\zeta)}{\zeta-T}\,d\zeta.$$

Consider the union of the two collections Γ ∪ Ω′. Both Γ ∪ Ω′ and σ(*T*) are compact. So there is some open set *U* containing Γ ∪ Ω′ such that σ(*T*) lies in the complement of *U*. Any *a* in the complement of *U* has winding number *n*(Γ ∪ Ω′, *a*) = 0 and the function

$$\zeta \rightarrow \frac{f(\zeta)}{\zeta-T}$$

is holomorphic on *U*. So the vector-valued version of Cauchy's theorem gives

$$\int_{\Gamma \cup \Omega'} \frac{f(\zeta)}{\zeta-T}\,d\zeta = 0$$

i.e.

$$\int_{\Gamma}\frac{f(\zeta)}{\zeta-T}\,d\zeta + \int_{\Omega'} \frac{f(\zeta)}{\zeta-T}\,d\zeta = \int_{\Gamma}\frac{f(\zeta)}{\zeta-T}\,d\zeta - \int_{\Omega}\frac{f(\zeta)}{\zeta-T}\,d\zeta = 0.$$

Hence the functional calculus is well-defined.

Consequently, if *f*<sub>1</sub> and *f*<sub>2</sub> are two holomorphic functions defined on neighborhoods *D*<sub>1</sub> and *D*<sub>2</sub> of σ(*T*) and they are equal on an open set containing σ(*T*), then *f*<sub>1</sub>(*T*) = *f*<sub>2</sub>(*T*). Moreover, even though the *D*<sub>1</sub> may not be *D*<sub>2</sub>, the operator (*f*<sub>1</sub> + *f*<sub>2</sub>) (*T*) is well-defined. Same holds for the definition of (*f*<sub>1</sub>·*f*<sub>2</sub>)(*T*).

### On the assumption that *f* be holomorphic over an open neighborhood of σ(*T*) {#On_the_assumption_that_f_be_holomorphic_over_an_open_neighborhood_of_σ(T)}

So far the full strength of this assumption has not been used. For convergence of the integral, only continuity was used. For well-definedness, we only needed *f* to be holomorphic on an open set *U* containing the contours Γ ∪ Ω′ but not necessarily σ(*T*). The assumption will be applied in its entirety in showing the homomorphism property of the functional calculus.

::: {#o18 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

### Polynomial case {#Polynomial_case}

The linearity of the map *f* ↦ *f*(*T*) follows from the convergence of the integral and that linear operations on a Banach space are continuous.

We recover the polynomial functional calculus when *f*(*z*) = Σ<sub>0 ≤ *i* ≤ *m*</sub> *a<sub>i</sub> z<sup>i</sup>* is a polynomial. To prove this, it is sufficient to show, for *k* ≥ 0 and *f*(*z*) = *z<sup>k</sup>*, it is true that *f*(*T*) = *T<sup>k</sup>*, i.e.

$$\frac{1}{2 \pi i} \int_{\Gamma} \frac{\zeta ^k}{\zeta - T} \, d\zeta = T^k$$

for any suitable Γ enclosing σ(*T*). Choose Γ to be a circle of radius greater than the operator norm of *T*. As stated above, on such Γ, the resolvent map admits a power series representation

$$( z - T)^{-1} = \frac{1}{z} \sum_{n \geq 0} \left( \frac{T}{z} \right)^n.$$

Substituting gives

$$f(T) = \frac{1}{2 \pi i} \int_{\Gamma} \left( \sum_{n \geq 0} \frac{T^n}{\zeta^{n+1-k}} \right) \, d\zeta$$

which is

$$\sum_{n \geq 0} T^n \cdot \frac{1}{2 \pi i} \left ( \int_{\Gamma} \frac{d \zeta }{\zeta^{n+1-k}} \right) = \sum_{n \geq 0} T^n \cdot \delta_{nk} = T^k.$$

The δ is the Kronecker delta symbol.

### The homomorphism property {#The_homomorphism_property}

For any *f*<sub>1</sub> and *f*<sub>2</sub> satisfying the appropriate assumptions, the homomorphism property states

$$f_1 (T) f_2(T) = (f_1 \cdot f_2)(T).\,$$

We sketch an argument which invokes the first resolvent formula and the assumptions placed on *f*. First we choose the Jordan curves such that Γ<sub>1</sub> lies in the *inside* of Γ<sub>2</sub>. The reason for this will become clear below. Start by calculating directly

$$\begin{aligned} f_1 (T) f_2(T) &= \left (\frac{1}{2\pi i}\int_{\Gamma_1}\frac{f_1(\zeta)}{\zeta-T} d \zeta \right ) \left (\frac{1}{2 \pi i} \int_{\Gamma_2}\frac{f_2(\omega)}{\omega-T}\, d \omega \right )\\ &= \frac{1}{(2\pi i)^2} \int_{\Gamma_1} \int_{\Gamma_2} \frac{f_1(\zeta)f_2(\omega)}{(\zeta-T)(\omega-T)}\; d \omega \, d \zeta \\ &= \frac{1}{(2\pi i)^2} \int_{\Gamma_1} \int_{\Gamma_2} f_1(\zeta) f_2 (\omega) \left ( \frac{(\zeta - T)^{-1} - (\omega - T)^{-1}}{\omega - \zeta} \right ) d \omega \, d \zeta && \text{First Resolvent Formula}\\ &= \frac{1}{(2 \pi i)^2}\left \{\left (\int _{\Gamma_1} \frac{f_1(\zeta)}{\zeta-T}\left[\int_{\Gamma_2}\frac{f_2(\omega)}{\omega - \zeta} d\omega\right] d \zeta \right )- \left (\int_{\Gamma_2} \frac{f_2(\omega)}{\omega-T}\left[\int_{\Gamma_1}\frac{f_1(\zeta)}{\omega - \zeta}d\zeta\right] d \omega\right)\right \} \\ &= \frac{1}{(2 \pi i)^2} \int _{\Gamma_1} \frac{f_1(\zeta)}{\zeta-T}\left[\int_{\Gamma_2}\frac{f_2(\omega)}{\omega - \zeta} d\omega\right] d \zeta \end{aligned}$$

The last line follows from the fact that ω ∈ Γ<sub>2</sub> lies outside of Γ<sub>1</sub> and *f*<sub>1</sub> is holomorphic on some open neighborhood of σ(*T*) and therefore the second term vanishes. Therefore, we have:

$$\begin{aligned} f_1 (T) f_2 (T)&= \frac{1}{2\pi i} \int_{\Gamma_1} \frac{f_1 (\zeta)}{\zeta - T}\left[\frac{1}{2 \pi i}\int_{\Gamma_2}\frac{f_2(\omega)}{\omega - \zeta}d \omega\right] d \zeta\\ &= \frac{1}{2 \pi i} \int _{\Gamma_1} \frac{f_1 (\zeta)}{\zeta - T} \left [ f_2 (\zeta) \right ] d \zeta && \text{Cauchy's Integral Formula} \\ &= \frac{1}{2 \pi i} \int _{\Gamma_1} \frac{f_1 (\zeta) f_2 (\zeta)}{\zeta - T}d \zeta \\ &= (f_1 \cdot f_2)(T) \end{aligned}$$

### Continuity with respect to compact convergence {#Continuity_with_respect_to_compact_convergence}

Let *G* ⊂ **C** be open with σ(*T*) ⊂ *G*. Suppose a sequence {*f<sub>k</sub>*} of holomorphic functions on *G* converges uniformly on compact subsets of *G* (this is sometimes called *compact convergence*). Then {*f<sub>k</sub>*(*T*)} is convergent in *L*(*X*):

Assume for simplicity that Γ consists of only one Jordan curve. We estimate

$$\begin{aligned} \left \| f_k(T) - f_l(T) \right \| &= \frac{1}{2 \pi} \left\|\int_{\Gamma} \frac{(f_k - f_l)(\zeta)}{\zeta - T} d \zeta \right\| \\ &\leq \frac{1}{2 \pi} \int_{\Gamma} \left |(f_k - f_l)(\zeta) \right | \cdot \left \| (\zeta - T)^{-1} \right \| d \zeta \end{aligned}$$

By combining the uniform convergence assumption and various continuity considerations, we see that the above tends to 0 as *k*, *l* → ∞. So {*f<sub>k</sub>*(*T*)} is Cauchy, therefore convergent.

### Uniqueness {#Uniqueness}

To summarize, we have shown the holomorphic functional calculus, *f* → *f*(*T*), has the following properties:

1. It extends the polynomial functional calculus.
1. It is an algebra homomorphism from the algebra of holomorphic functions defined on a neighborhood of σ(*T*) to *L*(*X*)
1. It preserves uniform convergence on compact sets.

It can be proved that a calculus satisfying the above properties is unique.

We note that, everything discussed so far holds verbatim if the family of bounded operators *L*(*X*) is replaced by a [Banach algebra](wikipedia://en/4665) *A*. The functional calculus can be defined in exactly the same way for an element in *A*.

:::

## Spectral considerations {#Spectral_considerations}

::: {#o25 .statement kind=statement/theorem cue=named-heading name="Spectral mapping theorem"}

### Spectral mapping theorem {#Spectral_mapping_theorem}

It is known that the **spectral mapping theorem** holds for the polynomial functional calculus: for any polynomial *p*, *σ*(*p*(*T*)) = *p*(*σ*(*T*)). This can be extended to the holomorphic calculus. To show *f*(*σ*(*T*)) ⊂ *σ*(*f*(*T*)), let μ be any complex number. By a result from complex analysis, there exists a function *g* holomorphic on a neighborhood of *σ*(*T*) such that

$$f(z) - f(\mu) = (z - \mu)g(z). \,$$

According to the homomorphism property, *f*(*T*) − *f*(*μ*) = (*T* − *μ*)*g*(*T*). Therefore, *μ* ∈ *σ*(*T*) implies *f*(*μ*) ∈ *σ*(*f*(*T*)).

For the other inclusion, if *μ* is not in *f*(*σ*(*T*)), then the functional calculus is applicable to

$$g(z) = \frac{1}{f(z) - \mu}.$$

So *g*(*T*)(*f*(*T*) − *μ*) = *I*. Therefore, *μ* does not lie in *σ*(*f*(*T*)).

:::

### Spectral projections {#Spectral_projections}

The underlying idea is as follows. Suppose that *K* is a subset of *σ*(*T*) and *U*,*V* are disjoint neighbourhoods of *K* and *σ*(*T*) \\ *K* respectively. Define *e*(*z*) = 1 if *z* ∈ *U* and *e*(*z*) = 0 if *z* ∈ *V*. Then *e* is a holomorphic function with \[*e*(*z*)\]<sup>2</sup> = *e*(*z*) and so, for a suitable contour Γ which lies in *U* ∪ *V* and which encloses σ(*T*), the linear operator

$$e(T)=\frac{1}{2\pi i}\int_{\Gamma} \frac{e(z)}{z-T}\,dz$$

will be a bounded projection that commutes with *T* and provides a great deal of useful information.

It transpires that this scenario is possible if and only if *K* is both open and closed in the [subspace topology](wikipedia://en/910926) on *σ*(*T*). Moreover, the set *V* can be safely ignored since *e* is zero on it and therefore makes no contribution to the integral. The projection *e*(*T*) is called the **spectral projection of *T* at *K*** and is denoted by *P*(*K*;*T*). Thus every subset *K* of *σ*(*T*) that is both open and closed in the subspace topology has an associated spectral projection given by

$$P(K;T)=\frac{1}{2\pi i}\int\nolimits_{\Gamma} \frac{dz}{z-T}$$

where Γ is a contour that encloses *K* but no other points of σ(*T*).

Since *P* = *P*(*K*;*T*) is bounded and commutes with *T* it enables *T* to be expressed in the form *U* ⊕ *V* where *U* = *T*|<sub>*PX*</sub> and *V* = *T*|<sub>(1−*P*)*X*</sub>. Both *PX* and (1 − *P*)*X* are invariant subspaces of *T* moreover *σ*(*U*) = *K* and *σ*(*V*) = *σ*(*T*) \\ *K*. A key property is mutual orthogonality. If *L* is another open and closed set in the subspace topology on *σ*(*T*) then *P*(*K*;*T*)*P*(*L*;*T*) = *P*(*L*;*T*)*P*(*K*;*T*) = *P*(*K* ∩ *L*;*T*) which is zero whenever *K* and *L* are disjoint.

Spectral projections have numerous applications. Any isolated point of σ(*T*) is both open and closed in the subspace topology and therefore has an associated spectral projection. When *X* has finite dimension σ(*T*) consists of isolated points and the resultant spectral projections lead to a variant of [Jordan normal form](wikipedia://en/312877) wherein all the Jordan blocks corresponding to the same eigenvalue are consolidated. In other words there is precisely one block per distinct eigenvalue. The next section considers this decomposition in more detail.

Sometimes spectral projections inherit properties from their parent operators. For example if *T* is a positive matrix with spectral radius *r* then the [Perron–Frobenius theorem](wikipedia://en/1540333) asserts that *r* ∈ *σ*(*T*). The associated spectral projection *P* = *P*(*r*;*T*) is also positive and by mutual orthogonality no other spectral projection can have a positive row or column. In fact *TP* = *rP* and (*T*/*r*)<sup>*n*</sup> → *P* as *n* → ∞ so this projection *P* (which is called the Perron projection) approximates (*T*/*r*)<sup>*n*</sup> as *n* increases, and each of its columns is an eigenvector of *T*.

More generally if *T* is a compact operator then all non-zero points in σ(*T*) are isolated and so any finite subset of them can be used to decompose *T*. The associated spectral projection always has finite rank. Those operators in *L*(*X*) with similar spectral characteristics are known as [Riesz operators](wikipedia://en/1073126). Many classes of Riesz operators (including the compact operators) are ideals in *L*(*X*) and provide a rich field for research. However if *X* is a [Hilbert space](wikipedia://en/20598932) there is exactly one closed ideal sandwiched between the Riesz operators and those of finite rank.

Much of the foregoing discussion can be set in the more general context of a complex [Banach algebra](wikipedia://en/4665). Here spectral projections are referred to as **spectral idempotents** since there may no longer be a space for them to project onto.

### Invariant subspace decomposition {#Invariant_subspace_decomposition}

*If* the spectrum *σ*(*T*) is not connected, *X* can be decomposed into invariant subspaces of *T* using the functional calculus. Let *σ*(*T*) be a disjoint union

$$\sigma(T) = \bigcup_{i=1}^m F_i.$$

Define *e<sub>i</sub>* to be 1 on some neighborhood that contains only the component *F<sub>i</sub>* and 0 elsewhere. By the homomorphism property, *e<sub>i</sub>*(*T*) is a projection for all *i*. In fact it is just the spectral projection *P*(*F<sub>i</sub>*;*T*) described above. The relation *e<sub>i</sub>*(*T*) *T* = *T e<sub>i</sub>*(*T*) means the range of each *e<sub>i</sub>*(*T*), denoted by *X<sub>i</sub>*, is an invariant subspace of *T*. Since

$$\sum_i e_i(T) = I,\,$$

*X* can be expressed in terms of these complementary subspaces:

$$X = \sum_i X_i.\,$$

Similarly, if *T<sub>i</sub>* is *T* restricted to *X<sub>i</sub>*, then

$$T = \sum_i T_i.\,$$

Consider the direct sum

$$X' = \bigoplus_i X_i.$$

With the norm

$$\left \| \bigoplus_i x_i \right \| = \sum_i \|x_i\|,$$

*X'* is a Banach space. The mapping *R*: *X'* → *X* defined by

$$R \left (\bigoplus_i x_i \right ) = \sum_i x_i$$

is a Banach space isomorphism, and we see that

$$R T R^{-1} = \bigoplus_i T_i.$$

This can be viewed as a block diagonalization of *T*.

When *X* is finite-dimensional, *σ*(*T*) = {*λ*<sub>*i*</sub>} is a finite set of points in the complex plane. Choose *e<sub>i</sub>* to be 1 on an open disc containing only *λ*<sub>*i*</sub> from the spectrum. The corresponding block-diagonal matrix

$$\bigoplus_i T_i$$

is the [Jordan canonical form](https://en.wikipedia.org/wiki/Jordan_canonical_form) of *T*.

## Related results {#Related_results}

With stronger assumptions, when *T* is a [normal operator](wikipedia://en/190167) acting on a [Hilbert space](wikipedia://en/20598932), the domain of the functional calculus can be broadened. When comparing the two results, a rough analogy can be made with the relationship between the spectral theorem for normal matrices and the Jordan canonical form. When *T* is a normal operator, a [continuous functional calculus](wikipedia://en/784808) can be obtained, that is, one can evaluate *f*(*T*) with *f* being a [continuous function](wikipedia://en/6122) defined on *σ*(*T*). Using the machinery of measure theory, this can be extended to functions which are only [measurable](wikipedia://en/44055) (see [Borel functional calculus](wikipedia://en/876294)). In that context, if *E* ⊂ σ(*T*) is a Borel set and *1<sub>E</sub>* is the characteristic function of *E*, the projection operator *1<sub>E</sub>(T)* is a refinement of *e<sub>i</sub>(T*) discussed above.

The Borel functional calculus extends to unbounded self-adjoint operators on a Hilbert space.

In slightly more abstract language, the holomorphic functional calculus can be extended to any element of a [Banach algebra](wikipedia://en/4665), using essentially the same arguments as above. Similarly, the continuous functional calculus holds for normal elements in any [C\*-algebra](wikipedia://en/7184) and the measurable functional calculus for normal elements in any [von Neumann algebra](wikipedia://en/294185).

### Unbounded operators {#Unbounded_operators}

A holomorphic functional calculus can be defined in a similar fashion for unbounded [closed operators](https://en.wikipedia.org/wiki/Closed_operator) with non-empty resolvent set.
