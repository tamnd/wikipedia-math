# Mordell curve

*Image: Mordell curve example.png.* $y^2 = x^3 + 1$, with solutions at $(-1, 0)$, $(0, 1)$ and $(0, -1)$

::: {#o1 .subject cue=lead name="Mordell curve"}

In [algebra](wikipedia://en/18716923), a **Mordell curve** is an [elliptic curve](wikipedia://en/10225) of the form $y^2 = x^3 + n$, where $n$ is a fixed non-zero [integer](wikipedia://en/14563).

:::

These curves were closely studied by [Louis Mordell](https://en.wikipedia.org/wiki/Louis_Mordell),[^o3] from the point of view of determining their integer points. He showed that every Mordell curve contains only finitely many integer points $(x, y)$. In other words, the differences of [perfect squares](wikipedia://en/213919) and [perfect cubes](https://en.wikipedia.org/wiki/Perfect_cube) tend to infinity. The question of how fast was dealt with in principle by [Baker's method](https://en.wikipedia.org/wiki/Baker's_method). Hypothetically this issue is dealt with by [Marshall Hall's conjecture](https://en.wikipedia.org/wiki/Marshall_Hall's_conjecture).

::: {#o5 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If $(x, y)$ is an integer point on a Mordell curve, then so is $(x, -y)$.
- If $(x, y)$ is a rational point on a Mordell curve with $y \ne 0$, then so is $\left( \frac{x^4 - 8nx}{4y^2}, \frac{-x^6 - 20nx^3 + 8n^2}{8y^3} \right)$. Moreover, if $xy \ne 0$ and $n$ is not 1 or −432, an infinite number of rational solutions can be generated this way. This formula is known as **Bachet's duplication formula**.[^o6]
- When $n \ne 0$, the Mordell curve only has finitely many integer solutions (see [Siegel's theorem on integral points](wikipedia://en/3989092)).
- There are certain values of $n$ for which the corresponding Mordell curve has no integer solutions;[^o2] these values are:

6, 7, 11, 13, 14, 20, 21, 23, 29, 32, 34, 39, 42, ... .

−3, −5, −6, −9, −10, −12, −14, −16, −17, −21, −22, ... .

- The specific case where $n = -2$ is also known as **Fermat's Sandwich Theorem**.

:::
