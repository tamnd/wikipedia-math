# Cartwright's theorem

::: {#o1 .subject cue=lead name="Cartwright's theorem"}

**Cartwright's theorem** is a mathematical [theorem](wikipedia://en/30977) in [complex analysis](wikipedia://en/5759), discovered by the British mathematician [Mary Cartwright](wikipedia://en/1529094). It gives an estimate of the maximum [modulus](wikipedia://en/991) of an [analytical function](https://en.wikipedia.org/wiki/Analytical_function) when the unit [disc](https://en.wikipedia.org/wiki/Disc_%28functional_analysis%29) takes the same value no more than *p* times.[^o2]

:::

::: {#o4 .statement cue=heading name="Statement"}

## Statement {#Statement}

Cartwright's theorem says that, for every integer $p \ge 1$, there exists a constant $C_p$ such that for every $p$-valent [holomorphic function](wikipedia://en/14110) $f(z) = \sum_{i=0}^\infty a_n z^n$ in disc $|z| < 1$, we have the bound

$$|f(z)| \leq \frac{\max_{0 \leq i \leq p}|a_i|}{(1-r)^{2p}} C_p$$

in an absolute value for all $z$ in the disc $|z| \leq r$ and $r \leq 1$.[^o5][^o6]

:::
