# Bogdanov map

::: {#o1 .subject cue=lead name="Bogdanov map"}

*Image: Bogdanov map.png.* Example with ε=0, k=1.2, μ=0.

In [dynamical systems theory](wikipedia://en/990632), the **Bogdanov map** is a [chaotic](wikipedia://en/6295) 2D [map](wikipedia://en/516931) related to the [Bogdanov–Takens bifurcation](wikipedia://en/8564483). It is given by the transformation:

:::

$$\begin{cases} x_{n+1} = x_n + y_{n+1}\\ y_{n+1} = y_n + \epsilon y_n + k x_n (x_n - 1) + \mu x_n y_n \end{cases}$$

The Bogdanov map is named after [Rifkat Bogdanov](wikipedia://en/13493122).
