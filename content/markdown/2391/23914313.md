# Elementary definition

::: {#o1 .subject cue=lead name="Elementary definition"}

In [mathematical logic](wikipedia://en/19636), an **elementary definition** is a definition that can be made using only [finitary](wikipedia://en/404456) [first-order logic](wikipedia://en/10983), and in particular without reference to [set theory](wikipedia://en/27553) or using extensions such as [plural quantification](wikipedia://en/444789). Elementary definitions are of particular interest because they [admit a complete proof apparatus](wikipedia://en/12450) while still being expressive enough to support most everyday mathematics (via the addition of elementarily-expressible axioms such as [Zermelo–Fraenkel set theory](wikipedia://en/152214) (ZFC)).

:::

Saying that a definition is elementary is a weaker condition than saying it is algebraic.
