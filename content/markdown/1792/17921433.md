# Perfect map

::: {#o1 .subject cue=lead name="Perfect map"}

In [mathematics](wikipedia://en/18831), especially [topology](wikipedia://en/29954), a **perfect map** is a particular kind of [continuous function](wikipedia://en/6122) between [topological spaces](wikipedia://en/30450). Perfect maps are weaker than [homeomorphisms](wikipedia://en/13660), but strong enough to preserve some topological properties such as [local compactness](wikipedia://en/48632) that are not always preserved by continuous maps.

:::

::: {#o3 .definition cue=heading name="Formal definition"}

## Formal definition {#Formal_definition}

Let $X$ and $Y$ be [topological spaces](wikipedia://en/30450) and let $p$ be a map from $X$ to $Y$ that is [continuous](wikipedia://en/6122), [closed](https://en.wikipedia.org/wiki/Closed_map), [surjective](wikipedia://en/27873) and such that each [fiber](wikipedia://en/6603892) $p^{-1}(y)$ is [compact](wikipedia://en/6042) relative to $X$ for each $y$ in $Y$. Then $p$ is known as a perfect map.

:::

## Examples and properties {#Examples_and_properties}

1. If $p\colon X \to Y$ is a perfect map and $Y$ is [compact](wikipedia://en/6042), then $X$ is compact.
1. If $p\colon X \to Y$ is a perfect map and $X$ is [regular](wikipedia://en/53058), then $Y$ is regular. (If $p$ is merely continuous, then even if $X$ is regular, $Y$ need not be regular. An example of this is if $X$ is a regular space and $Y$ is an infinite set in the indiscrete topology.)
1. If $p\colon X \to Y$ is a perfect map and if $X$ is [locally compact](https://en.wikipedia.org/wiki/Locally_compact), then $Y$ is locally compact.
1. If $p\colon X \to Y$ is a perfect map and if $X$ is second countable, then $Y$ is [second countable](https://en.wikipedia.org/wiki/Second_countable).
1. Every [injective](https://en.wikipedia.org/wiki/Injective) perfect map is a [homeomorphism](wikipedia://en/13660). This follows from the fact that a bijective closed map has a continuous inverse.
1. If $p\colon X \to Y$ is a perfect map and if $Y$ is [connected](wikipedia://en/6233), then $X$ need not be connected. For example, the constant map from a compact disconnected space to a singleton space is a perfect map.
1. A perfect map need not be open. Indeed, consider the map $p\colon [1, 2] \cup [3, 4] \to [1, 3]$ given by $p(x) = x$ if $x\in [1, 2]$ and $p(x) = x - 1$ if $x\in{}[3, 4]$. This map is closed, continuous (by the [pasting lemma](wikipedia://en/21533030)), and surjective and therefore is a perfect map (the other condition is trivially satisfied). However, *p* is not open, for the image of \[1, 2\] under *p* is \[1, 2\] which is not open relative to \[1, 3\] (the range of *p*). Note that this map is a [quotient map](wikipedia://en/237213) and the quotient operation is 'gluing' two intervals together.
1. Notice how, to preserve properties such as [local connectedness](wikipedia://en/6959754), second countability, [local compactness](https://en.wikipedia.org/wiki/Local_compactness) etc. ... the map must be not only continuous but also open. A perfect map need not be open (see previous example), but these properties are still preserved under perfect maps.
1. Every homeomorphism is a perfect map. This follows from the fact that a [bijective](https://en.wikipedia.org/wiki/Bijective) open map is closed and that since a homeomorphism is injective, the inverse of each element of the range must be finite in the domain (in fact, the inverse must have precisely one element).
1. Every perfect map is a quotient map. This follows from the fact that a closed, continuous surjective map is always a quotient map.
1. Let *G* be a compact topological group which acts continuously on *X*. Then the quotient map from *X* to *X*/*G* is a perfect map.
1. Perfect maps are [proper](wikipedia://en/1190262). Surjective proper maps are perfect, provided the topology of *Y* is [Hausdorff](wikipedia://en/13637) and compactly generated.[^o5]
