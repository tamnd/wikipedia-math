# Type shifter

::: {#o1 .subject cue=lead name="Type shifter"}

In [formal semantics](wikipedia://en/31395652), a **type shifter** is an [interpretation](https://en.wikipedia.org/wiki/Compositionality) rule that changes an expression's [semantic type](wikipedia://en/40282). For instance, the [English](https://en.wikipedia.org/wiki/English_language) expression "John" might ordinarily [denote](https://en.wikipedia.org/wiki/Denotation) John himself, but a type shifting rule called Lift can raise its denotation to a [function](wikipedia://en/185427) which takes a property and returns "true" if John himself has that property. Lift can be seen as mapping an individual onto the [principal ultrafilter](https://en.wikipedia.org/wiki/Principal_ultrafilter) that it generates.[^o2][^o3][^o4]

:::

1. Without type shifting: $\, \, [\![John]\!] = j$
1. Type shifting with Lift: $[\![John]\!] = \lambda P_{\langle e,t \rangle} . P(j)$

Type shifters were proposed by [Barbara Partee](https://en.wikipedia.org/wiki/Barbara_Partee) and [Mats Rooth](https://en.wikipedia.org/wiki/Mats_Rooth) in 1983 to allow for systematic type [ambiguity](wikipedia://en/677). Work of the period assumed that [syntactic categories](https://en.wikipedia.org/wiki/Syntactic_category) corresponded directly with semantic types, and researchers thus had to "generalize to the worst case" when particular uses of particular expressions from a given category required an especially high type. Moreover, Partee argued that evidence, in fact, supported expressions having different types in different contexts. Thus, she and Rooth proposed type shifting as a principled mechanism for generating the ambiguity.[^o2][^o3][^o4]

Type shifters remain a standard tool in formal semantic work, particularly in [categorial grammar](https://en.wikipedia.org/wiki/Categorial_grammar) and related frameworks. Type shifters have also been used to interpret quantifiers in object position and to capture [scope ambiguities](wikipedia://en/65142269). In that regard, they serve as an alternative to syntactic operations such as [quantifier raising](https://en.wikipedia.org/wiki/Quantifier_raising) used in mainstream [generative](https://en.wikipedia.org/wiki/Generative_grammar) approaches to semantics. [^o5][^o6] Type shifters have also been used to generate and [compose](https://en.wikipedia.org/wiki/Compositionality) alternative sets without the need to fully adopt an [alternative-based semantics](wikipedia://en/66422858).[^o7][^o8]
