# Tate's algorithm

::: {#o1 .subject cue=lead name="Tate's algorithm"}

In the theory of [elliptic curves](https://en.wikipedia.org/wiki/Elliptic_curves), **Tate's algorithm** takes as input an [integral model](https://en.wikipedia.org/wiki/Integral_model) of an elliptic curve *E* over $\mathbb{Q}$, or more generally an [algebraic number field](wikipedia://en/28730822), and a prime or [prime ideal](wikipedia://en/24928) *p*. It returns the exponent *f*<sub>*p*</sub> of *p* in the [conductor](wikipedia://en/43604164) of *E*, the type of reduction at *p*, the local index

:::

$$c_p=[E(\mathbb{Q}_p):E^0(\mathbb{Q}_p)],$$

where $E^0(\mathbb{Q}_p)$ is the group of $\mathbb{Q}_p$-points whose reduction mod *p* is a [non-singular point](https://en.wikipedia.org/wiki/Non-singular_point). Also, the [algorithm](wikipedia://en/775) determines whether or not the given integral model is minimal at *p*, and, if not, returns an integral model with integral coefficients for which the valuation at *p* of the discriminant is minimal.

Tate's algorithm also gives the structure of the singular fibers given by the Kodaira symbol or Néron symbol, for which, see [elliptic surface](wikipedia://en/3073462): in turn this determines the exponent *f*<sub>*p*</sub> of the conductor *E*.

Tate's algorithm can be greatly simplified if the characteristic of the [residue class](wikipedia://en/20087) field is not 2 or 3; in this case the type and *c* and *f* can be read off from the valuations of *j* and Δ (defined below).

Tate's algorithm was introduced by () as an improvement of the description of the [Néron model](wikipedia://en/9190726) of an elliptic curve by (txt).

::: {#o5 .definition kind=definition/notation cue=heading name="Notation"}

## Notation {#Notation}

Assume that all the coefficients of the equation of the curve lie in a complete [discrete valuation ring](wikipedia://en/848633) *R* with [perfect](wikipedia://en/505088) [residue field](wikipedia://en/10789680) *K* and [maximal ideal](wikipedia://en/48164) generated by a [prime](https://en.wikipedia.org/wiki/Uniformizing_element) π. The elliptic curve is given by the equation

$$y^2+a_1xy+a_3y = x^3+a_2x^2+a_4x+a_6.$$

Define:

$v(\Delta)=$ the [p-adic valuation](wikipedia://en/16047618) of $\pi$ in $\Delta$, that is, exponent of $\pi$ in prime factorization of $\Delta$, or infinity if $\Delta = 0$

$$a_{i,m}=a_i/\pi^m$$

$$b_2=a_1^2+4a_2$$

$$b_4=a_1a_3+2a_4^{}$$

$$b_6=a_3^2+4a_6$$

$$b_8=a_1^2a_6-a_1a_3a_4+4a_2a_6+a_2a_3^2-a_4^2$$

$$c_4=b_2^2-24b_4$$

$$c_6=-b_2^3+36b_2b_4-216b_6$$

$$\Delta=-b_2^2b_8-8b_4^3-27b_6^2+9b_2b_4b_6$$

$$j=c_4^3/\Delta.$$

:::

::: {#o7 .definition kind=definition/construction cue=heading name="The algorithm"}

## The algorithm {#The_algorithm}

- Step 1: If π does not divide Δ then the type is I<sub>0</sub>, *c*=1 and *f*=0.
- Step 2: If π divides Δ but not c<sub>4</sub> then the type is I<sub>v</sub> with v = v(Δ), *c*=v, and *f*=1.
- Step 3. Otherwise, change coordinates so that π divides *a*<sub>3</sub>,*a*<sub>4</sub>,*a*<sub>6</sub>. If π<sup>2</sup> does not divide *a*<sub>6</sub> then the type is II, *c*=1, and *f*=v(Δ);
- Step 4. Otherwise, if π<sup>3</sup> does not divide *b*<sub>8</sub> then the type is III, *c*=2, and *f*=v(Δ)−1;
- Step 5. Otherwise, let *Q<sub>1</sub>* be the polynomial

$$Q_1(Y) = Y^2+a_{3,1}Y-a_{6,2}..$$

If π<sup>3</sup> does not divide *b*<sub>6</sub> then the type is IV, *c*=3 if $Q_1(Y)$ has two roots in K and 1 if it has two roots outside of K, and *f*=v(Δ)−2.

- Step 6. Otherwise, change coordinates so that π divides *a*<sub>1</sub> and *a*<sub>2</sub>, π<sup>2</sup> divides *a*<sub>3</sub> and *a*<sub>4</sub>, and π<sup>3</sup> divides *a*<sub>6</sub>. Let *P* be the polynomial

$$P(T) = T^3+a_{2,1}T^2+a_{4,2}T+a_{6,3}.$$

If $P(T)$ has 3 distinct roots modulo π then the type is I<sub>0</sub><sup>\*</sup>, *f*=v(Δ)−4, and *c* is 1+(number of roots of *P* in *K*).

- Step 7. If *P* has one single and one double root, then the type is I<sub>ν</sub><sup>\*</sup> for some ν>0, *f*=v(Δ)−4−ν, *c*=2 or 4: there is a "sub-algorithm" for dealing with this case.
- Step 8. If *P* has a triple root, change variables so the triple root is 0, so that π<sup>2</sup> divides *a*<sub>2</sub> and π<sup>3</sup> divides *a*<sub>4</sub>, and π<sup>4</sup> divides *a*<sub>6</sub>. Let *Q<sub>2</sub>* be the polynomial

$$Q_2(Y) = Y^2+a_{3,2}Y-a_{6,4}..$$

If $Q_2(Y)$ has two distinct roots modulo π then the type is IV<sup>\*</sup>, *f*=v(Δ)−6, and *c* is 3 if the roots are in *K*, 1 otherwise.

- Step 9. If $Q_2(Y)$ has a double root, change variables so the double root is 0. Then π<sup>3</sup> divides *a*<sub>3</sub> and π<sup>5</sup> divides *a*<sub>6</sub>. If π<sup>4</sup> does not divide *a*<sub>4</sub> then the type is III<sup>\*</sup> and *f*=v(Δ)−7 and *c* = 2.
- Step 10. Otherwise if π<sup>6</sup> does not divide *a*<sub>6</sub> then the type is II<sup>\*</sup> and *f*=v(Δ)−8 and *c* = 1.
- Step 11. Otherwise the equation is not minimal. Divide each *a*<sub>*n*</sub> by π<sup>*n*</sup> and go back to step 1.

:::
