# Polynomial functor (type theory)

::: {#o1 .subject cue=lead name="Polynomial functor"}

In [type theory](wikipedia://en/40282), a **polynomial functor** (or **container functor**) is a kind of [endofunctor](https://en.wikipedia.org/wiki/Endofunctor) of a [category](wikipedia://en/53759) of types that is intimately related to the concept of [inductive](wikipedia://en/22778065) and [coinductive](wikipedia://en/10904266) types. Specifically, all [W-types](https://en.wikipedia.org/wiki/W_type) (resp. M-types) are (isomorphic to) [initial algebras](wikipedia://en/4116488) (resp. [final coalgebras](https://en.wikipedia.org/wiki/Final_coalgebra)) of such functors.

:::

Polynomial functors have been studied in the more general setting of a [pretopos](wikipedia://en/21391464) with Σ-types;[^o2] this article deals only with the applications of this concept inside the category of types of a [Martin-Löf style type theory](wikipedia://en/345023).

::: {#o4 .definition cue=heading name="Definition"}

## Definition {#Definition}

Let $U$ be a [universe](wikipedia://en/296838) of types, let $A$ : $U$, and let $B$ : $A$ → $U$ be a family of types indexed by $A$. The pair ($A$, $B$) is sometimes called a **signature**[^n1] or a **container**.[^n2] The **polynomial functor** associated to the container ($A$, $B$) is defined as follows:[^n3][^n4][^n5]

$$\begin{aligned} P : U &\longrightarrow U \\ X &\longmapsto \sum_{a:A} (B(a) \to X) \end{aligned}$$

Any functor naturally isomorphic to $P$ is called a **container functor**.[^n6] The action of $P$ on functions is defined by

$$\begin{aligned} P : (X\to Y) &\longrightarrow (PX\to PY) \\ f \qquad &\longmapsto \left((a,g) \mapsto (a,g\circ f)\right) \end{aligned}$$

Note that this assignment is only truly functorial in extensional type theories (see #Properties).

:::

::: {#o12 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

In intensional type theories, such functions are not truly functors, because the universe type is not strictly a category (the field of [homotopy type theory](wikipedia://en/33974223) is dedicated to exploring how the universe type behaves more like a [higher category](wikipedia://en/5274013)). However, it is functorial up to propositional equalities, that is, the following identity types are inhabited:

$$\begin{aligned} P(f\circ g) &= Pf\circ Pg \\ P(\mathsf{id}_X) &= \mathsf{id}_{PX} \end{aligned}$$

for any functions $f$ and $g$ and any type $X$, where $\mathsf{id}_X$ is the [identity function](wikipedia://en/15069) on the type $X$.[^n7]

:::
