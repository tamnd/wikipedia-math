# Conical combination

::: {#o1 .subject cue=lead name="Conical combination"}

Given a finite number of vectors $x_1, x_2, \dots, x_n$ in a [real](wikipedia://en/20646438) [vector space](wikipedia://en/32370), a **conical combination**, **conic combination**, **conical sum**, or **weighted sum**[^o2][^o3][^o4] of these vectors is a vector of the form

:::

$$\alpha_1x_1+\alpha_2x_2+\cdots+\alpha_nx_n$$

where $\alpha_i$ are [non-negative](https://en.wikipedia.org/wiki/Non-negative) real numbers.

The name derives from the fact that the set of all conical sum of vectors defines a [cone](wikipedia://en/3558266) (possibly in a lower-dimensional [subspace](wikipedia://en/56357)).

## Conical hull {#Conical_hull}

The [set](wikipedia://en/26691) of all conical combinations for a given set $S$ is called the **conical hull** (or **conic hull**) of $S$ and denoted $\operatorname{cone}(S)$[^o2] or $\operatorname{coni}(S)$.[^o3] That is,

$$\operatorname{coni} (S)=\left\{ \sum_{i=1}^k \alpha_i x_i : x_i \in S,\, \alpha_i \in \mathbb{R}_{\ge 0},\, k \in \mathbb{N} \right\}.$$

By taking $k = 0$, it follows the zero vector ([origin](wikipedia://en/1313432)) belongs to all conical hulls (since the summation becomes an [empty sum](wikipedia://en/209748)).

The conical hull of a set $S$ is a [convex set](wikipedia://en/6292). In fact, it is the intersection of all [convex cones](wikipedia://en/3558266) containing *S* plus the origin.[^o2] If $S$ is a [compact set](https://en.wikipedia.org/wiki/Compact_set) (in particular, when it is a finite [non-empty](wikipedia://en/9566) set of points), then the condition "plus the origin" is unnecessary.

If we discard the origin, we can divide all coefficients by their sum to see that a conical combination is a [convex combination](wikipedia://en/794534) scaled by a positive factor.

*Image: Circle-conic-hull.svg.* In the plane, the conical hull of a [circle](wikipedia://en/6220) passing through the origin is the open [half-plane](https://en.wikipedia.org/wiki/Half-plane) defined by the [tangent](wikipedia://en/31482) line to the circle at the origin plus the origin.

Therefore, "conical combinations" and "conical hulls" are in fact "convex conical combinations" and "convex conical hulls" respectively.[^o2] Moreover, the above remark about dividing the coefficients while discarding the origin implies that the conical combinations and hulls may be considered as convex combinations and [convex hulls](wikipedia://en/40634) in the [projective space](wikipedia://en/242135).

While the convex hull of a compact set is also a compact set, this is not so for the conical hull; first of all, the latter one is unbounded. Moreover, it is not even necessarily a [closed set](wikipedia://en/47279): a counterexample is a [sphere](wikipedia://en/27859) passing through the origin, with the conical hull being an open [half-space](wikipedia://en/647297) plus the origin. However, if $S$ is a non-empty convex compact set which does not contain the origin, then the convex conical hull of $S$ is a closed set.[^o2]
