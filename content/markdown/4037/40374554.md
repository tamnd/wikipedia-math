# Point-set registration

::: {#o1 .subject cue=lead name="Point-set registration"}

*Image: Cpd fish affine.gif.* Point set registration is the process of aligning two point sets. Here, the blue fish is being registered to the red fish.

In [computer vision](https://en.wikipedia.org/wiki/Computer_vision), [pattern recognition](wikipedia://en/126706), and [robotics](https://en.wikipedia.org/wiki/Robotics_engineering), **point-set registration**, also known as **point-cloud registration** or **scan matching**, is the process of finding a spatial [transformation](https://en.wikipedia.org/wiki/Mathematical_transformation) (*e.g.,* [scaling](wikipedia://en/651752), [rotation](wikipedia://en/39789) and [translation](wikipedia://en/204682)) that aligns two [point clouds](https://en.wikipedia.org/wiki/Point_cloud). The purpose of finding such a transformation includes merging multiple data sets into a globally consistent model (or coordinate frame), and mapping a new measurement to a known data set to identify features or to [estimate its pose](https://en.wikipedia.org/wiki/3D_pose_estimation). Raw 3D point cloud data are typically obtained from [Lidars](https://en.wikipedia.org/wiki/Lidar) and [RGB-D cameras](https://en.wikipedia.org/wiki/RGB-D_camera). 3D point clouds can also be generated from computer vision algorithms such as [triangulation](https://en.wikipedia.org/wiki/Triangulation_%28computer_vision%29), [bundle adjustment](https://en.wikipedia.org/wiki/Bundle_adjustment), and more recently, monocular image depth estimation using [deep learning](https://en.wikipedia.org/wiki/Deep_learning). For 2D point set registration used in image processing and feature-based [image registration](https://en.wikipedia.org/wiki/Image_registration), a point set may be 2D pixel coordinates obtained by [feature extraction](https://en.wikipedia.org/wiki/Feature_extraction) from an image, for example [corner detection](https://en.wikipedia.org/wiki/Corner_detection). Point cloud registration has extensive applications in [autonomous driving](https://en.wikipedia.org/wiki/Self-driving_car),[^o2] [motion estimation and 3D reconstruction](https://en.wikipedia.org/wiki/3D_reconstruction),[^o3] [object detection and pose estimation](https://en.wikipedia.org/wiki/Object_detection),[^o4][^o5] [robotic manipulation](https://en.wikipedia.org/wiki/Robotic_manipulation),[^o6] [simultaneous localization and mapping](https://en.wikipedia.org/wiki/Simultaneous_localization_and_mapping) (SLAM),[^o7][^o8] [panorama stitching](https://en.wikipedia.org/wiki/Image_stitching),[^o9] [virtual and augmented reality](https://en.wikipedia.org/wiki/Virtual_reality),[^o10] and [medical imaging](https://en.wikipedia.org/wiki/Medical_imaging).[^o11]

:::

As a special case, registration of two point sets that only differ by a 3D rotation (*i.e.,* there is no scaling and translation), is called the [Wahba Problem](wikipedia://en/31998221) and also related to the [orthogonal procrustes problem](wikipedia://en/13548016).

::: {#o13 .definition cue=heading name="Formulation"}

## Formulation {#Formulation}

*Image: Registration outdoor.png.* Data from two 3D scans of the same environment need to be aligned using point set registration.

*Image: Registration closeup.png.* Data from above, registered successfully using a variant of iterative closest point.

The problem may be summarized as follows:[^o14] Let $\lbrace\mathcal{M},\mathcal{S}\rbrace$ be two finite size point sets [in](https://en.wikipedia.org/wiki/Set_membership) a finite-dimensional real [vector space](wikipedia://en/32370) $\mathbb{R}^d$, which contain $M$ and $N$ points respectively (*e.g.,* $d=3$ recovers the typical case of when $\mathcal{M}$ and $\mathcal{S}$ are 3D point sets). The problem is to find a transformation to be applied to the moving "model" point set $\mathcal{M}$ such that the difference (typically defined in the sense of point-wise [Euclidean distance](wikipedia://en/53932)) between $\mathcal{M}$ and the static "scene" set $\mathcal{S}$ is minimized. In other words, a mapping from $\mathbb{R}^d$ to $\mathbb{R}^d$ is desired which yields the best alignment between the transformed "model" set and the "scene" set. The mapping may consist of a rigid or non-rigid transformation. The transformation model may be written as $T$, using which the transformed, registered model point set is:

::: {#o15 .equation cue=numblk name="1"}

$$T(\mathcal{M}) \tag{1}$$

:::

The output of a point set registration algorithm is therefore the *optimal transformation* $T^\star$ such that $\mathcal{M}$ is best aligned to $\mathcal{S}$, according to some defined notion of distance function $\operatorname{dist}(\cdot,\cdot)$:

::: {#o16 .equation cue=numblk name="2"}

$$T^\star = \arg\min_{T \in \mathcal{T} } \text{dist}(T(\mathcal{M}),\mathcal{S}) \tag{2}$$

:::

where $\mathcal{T}$ is used to denote the set of all possible transformations that the optimization tries to search for. The most popular choice of the distance function is to take the square of the [Euclidean distance](wikipedia://en/53932) for every pair of points:

::: {#o17 .equation cue=numblk name="3"}

$$\operatorname{dist}(T(\mathcal{M}), \mathcal{S}) = \sum_{m \in T(\mathcal{M})} \Vert m - s_m \Vert^2_2, \quad s_m = \arg\min_{s \in \mathcal{S} } \Vert s - m \Vert_2^2 \tag{3}$$

:::

where $\| \cdot \|_2$ denotes the [vector 2-norm](wikipedia://en/990534), $s_m$ is the *[corresponding point](https://en.wikipedia.org/wiki/Corresponding_point)* in set $\mathcal{S}$ that attains the *shortest distance* to a given point $m$ in set $\mathcal{M}$ after transformation. Minimizing such a function in rigid registration is equivalent to solving a [least squares](wikipedia://en/82359) problem.

:::

## Types of algorithms {#Types_of_algorithms}

When the correspondences (*i.e.,* $s_m \leftrightarrow m$) are given before the optimization, for example, using [feature matching](https://en.wikipedia.org/wiki/Feature_matching) techniques, then the optimization only needs to estimate the transformation. This type of registration is called **correspondence-based registration**. On the other hand, if the correspondences are unknown, then the optimization is required to jointly find out the correspondences and transformation together. This type of registration is called **simultaneous pose and correspondence registration**.

### Rigid registration {#Rigid_registration}

Given two point sets, rigid registration yields a [rigid transformation](wikipedia://en/27832980) which maps one point set to the other. A rigid transformation is defined as a transformation that does not change the distance between any two points. Typically such a transformation consists of [translation](wikipedia://en/204682) and [rotation](wikipedia://en/39789).[^o20] In rare cases, the point set may also be mirrored. In robotics and computer vision, rigid registration has the most applications.

### Non-rigid registration {#Non-rigid_registration}

*Image: Ouster OS1-64 lidar point cloud of intersection of Folsom and Dore St, San Francisco.png.* Registered point cloud from a [lidar](https://en.wikipedia.org/wiki/Lidar) mounted on a moving car.

Given two point sets, non-rigid registration yields a non-rigid transformation which maps one point set to the other. Non-rigid transformations include [affine transformations](https://en.wikipedia.org/wiki/Affine_transformations) such as [scaling](wikipedia://en/651752) and [shear mapping](wikipedia://en/799405). However, in the context of point set registration, non-rigid registration typically involves nonlinear transformation. If the [eigenmodes of variation](https://en.wikipedia.org/wiki/Eigenmode) of the point set are known, the nonlinear transformation may be parametrized by the eigenvalues.[^o82] A nonlinear transformation may also be parametrized as a [thin plate spline](wikipedia://en/8136546).[^o70][^o82]

### Other types {#Other_types}

Some approaches to point set registration use algorithms that solve the more general [graph matching](wikipedia://en/54414446) problem.[^o14] However, the computational complexity of such methods tend to be high and they are limited to rigid registrations. In this article, we will only consider algorithms for rigid registration, where the transformation is assumed to contain 3D rotations and translations (possibly also including a uniform scaling).

The [PCL (Point Cloud Library)](https://en.wikipedia.org/wiki/PCL_%28Point_Cloud_Library%29) is an open-source framework for n-dimensional point cloud and 3D [geometry processing](wikipedia://en/2214847). It includes several point registration algorithms.[^o23]

## Correspondence-based registration {#Correspondence-based_registration}

Correspondence-based methods assume the putative correspondences $m \leftrightarrow s_m$ are given for every point $m \in \mathcal{M}$. Therefore, we arrive at a setting where both point sets $\mathcal{M}$ and $\mathcal{S}$ have $N$ points and the correspondences $m_i \leftrightarrow s_i,i=1,\dots,N$ are given.

### Outlier-free registration {#Outlier-free_registration}

In the simplest case, one can assume that all the correspondences are correct, meaning that the points $m_i,s_i \in \mathbb{R}^3$ are generated as follows:

::: {#o26 .equation cue=numblk name="cb.1"}

$$s_i = lR m_i + t + \epsilon_i, i=1,\dots,N \tag{cb.1}$$

:::

where $l > 0$ is a uniform scaling factor (in many cases $l=1$ is assumed), $R \in \text{SO}(3)$ is a proper 3D [rotation matrix](wikipedia://en/856005) ($\text{SO}(d)$ is the [special orthogonal group](https://en.wikipedia.org/wiki/Special_orthogonal_group) of degree $d$), $t \in \mathbb{R}^3$ is a 3D translation vector and $\epsilon_i \in \mathbb{R}^3$ models the unknown additive noise (*e.g.,* [Gaussian noise](wikipedia://en/1387827)). Specifically, if the noise $\epsilon_i$ is assumed to follow a zero-mean isotropic Gaussian distribution with standard deviation $\sigma_i$, *i.e.,* $\epsilon_i \sim \mathcal{N}(0,\sigma_i^2 I_3 )$, then the following optimization can be shown to yield the [maximum likelihood estimate](wikipedia://en/140806) for the unknown scale, rotation and translation:

::: {#o27 .equation cue=numblk name="cb.2"}

$$l^\star, R^\star, t^\star = \arg\min_{l>0, R \in \text{SO}(3), t \in \mathbb{R}^3} \sum_{i=1}^N \frac{1}{\sigma_i^2} \left\Vert s_i - lRm_i - t \right\Vert_2^2 \tag{cb.2}$$

:::

Note that when the scaling factor is 1 and the translation vector is zero, then the optimization recovers the formulation of the [Wahba problem](wikipedia://en/31998221). Despite the [non-convexity](wikipedia://en/1674411) of the optimization ((cb.2)) due to non-convexity of the set $\text{SO}(3)$, seminal work by [Berthold K.P. Horn](https://en.wikipedia.org/wiki/Berthold_K.P._Horn) showed that ((cb.2)) actually admits a closed-form solution, by decoupling the estimation of scale, rotation and translation.[^o28] Similar results were discovered by Arun *et al*.[^o29] In addition, in order to find a unique transformation $(l,R,t)$, at least $N=3$ non-collinear points in each point set are required.

More recently, Briales and Gonzalez-Jimenez have developed a [semidefinite relaxation](wikipedia://en/4993539) using [Lagrangian duality](wikipedia://en/3372717), for the case where the model set $\mathcal{M}$ contains different 3D primitives such as points, lines and planes (which is the case when the model $\mathcal{M}$ is a 3D mesh).[^o30] Interestingly, the semidefinite relaxation is empirically tight, *i.e.,* a certifiably [globally optimal](https://en.wikipedia.org/wiki/Globally_optimal) solution can be extracted from the solution of the semidefinite relaxation.

### Robust registration {#Robust_registration}

The [least squares](wikipedia://en/82359) formulation ((cb.2)) is known to perform arbitrarily badly in the presence of [outliers](wikipedia://en/160951). An outlier correspondence is a pair of measurements $s_i \leftrightarrow m_i$ that departs from the [generative model](wikipedia://en/1222578) ((cb.1)). In this case, one can consider a different generative model as follows:[^o32]

::: {#o33 .equation cue=numblk name="cb.3"}

$$s_i = \begin{cases} l R m_i + t + \epsilon_i & \text{if } i- \text{th pair is an inlier} \\ o_i & \text{if } i- \text{th pair is an outlier} \end{cases} \tag{cb.3}$$

:::

where if the $i-$th pair $s_i \leftrightarrow m_i$ is an inlier, then it obeys the outlier-free model ((cb.1)), *i.e.,* $s_i$ is obtained from $m_i$ by a spatial transformation plus some small noise; however, if the $i-$th pair $s_i \leftrightarrow m_i$ is an outlier, then $s_i$ can be any arbitrary vector $o_i$. Since one does not know which correspondences are outliers beforehand, robust registration under the generative model ((cb.3)) is of paramount importance for computer vision and robotics deployed in the real world, because current feature matching techniques tend to output highly corrupted correspondences where over $95\%$ of the correspondences can be outliers.[^o34]

Next, we describe several common paradigms for robust registration.

#### Maximum consensus {#Maximum_consensus}

[Maximum consensus](https://en.wikipedia.org/wiki/Consensus_%28computer_science%29) seeks to find the largest set of correspondences that are consistent with the generative model ((cb.1)) for some choice of spatial transformation $(l,R,t)$. Formally speaking, maximum consensus solves the following optimization:

::: {#o36 .equation cue=numblk name="cb.4"}

$$\max_{l>0,R \in \text{SO}(3), t \in \mathbb{R}^3, \mathcal{I} } \vert \mathcal{I} \vert, \quad \text{subject to } \frac{1}{\sigma_i^2} \Vert s_i - lRm_i - t\Vert_2^2 \leq \xi, \forall i \in \mathcal{I} \tag{cb.4}$$

:::

where $\vert \mathcal{I} \vert$ denotes the [cardinality](wikipedia://en/6174) of the set $\mathcal{I}$. The constraint in ((cb.4)) enforces that every pair of measurements in the inlier set $\mathcal{I}$ must have [residuals](https://en.wikipedia.org/wiki/Residuals_%28statistics%29) smaller than a pre-defined threshold $\xi$. Unfortunately, recent analyses have shown that globally solving problem (cb.4) is [NP-Hard](wikipedia://en/54681), and global algorithms typically have to resort to [branch-and-bound](wikipedia://en/456580) (BnB) techniques that take exponential-time complexity in the worst case.[^o37][^o38][^o39][^o40][^o41]

Although solving consensus maximization exactly is hard, there exist efficient heuristics that perform quite well in practice. One of the most popular heuristics is the [Random Sample Consensus (RANSAC)](wikipedia://en/1089270) scheme.[^o42] RANSAC is an iterative hypothesize-and-verify method. At each iteration, the method first randomly samples 3 out of the total number of $N$ correspondences and computes a hypothesis $(l,R,t)$ using Horn's method,[^o28] then the method evaluates the constraints in ((cb.4)) to count how many correspondences actually agree with such a hypothesis (i.e., it computes the residual $\Vert s_i - lRm_i - t \Vert_2^2 / \sigma_i^2$ and compares it with the threshold $\xi$ for each pair of measurements). The algorithm terminates either after it has found a consensus set that has enough correspondences, or after it has reached the total number of allowed iterations. RANSAC is highly efficient because the main computation of each iteration is carrying out the closed-form solution in Horn's method. However, RANSAC is non-deterministic and only works well in the low-outlier-ratio regime (*e.g.,* below $50\%$), because its runtime grows exponentially with respect to the outlier ratio.[^o34]

To fill the gap between the fast but inexact RANSAC scheme and the exact but exhaustive BnB optimization, recent researches have developed deterministic approximate methods to solve consensus maximization.[^o37][^o38][^o43][^o39]

#### Outlier removal {#Outlier_removal}

Outlier removal methods seek to pre-process the set of highly corrupted correspondences before estimating the spatial transformation. The motivation of outlier removal is to significantly reduce the number of outlier correspondences, while maintaining inlier correspondences, so that optimization over the transformation becomes easier and more efficient (*e.g.,* RANSAC works poorly when the outlier ratio is above $95\%$ but performs quite well when outlier ratio is below $50\%$).

Parra *et al.* have proposed a method called Guaranteed Outlier Removal (GORE) that uses geometric constraints to prune outlier correspondences while guaranteeing to preserve inlier correspondences.[^o34] GORE has been shown to be able to drastically reduce the outlier ratio, which can significantly boost the performance of consensus maximization using RANSAC or BnB. Yang and Carlone have proposed to build pairwise translation-and-rotation-invariant measurements (TRIMs) from the original set of measurements and embed TRIMs as the edges of a [graph](wikipedia://en/12401) whose nodes are the 3D points. Since inliers are pairwise consistent in terms of the scale, they must form a [clique](https://en.wikipedia.org/wiki/Clique) within the graph. Therefore, using efficient algorithms for computing the [maximum clique](wikipedia://en/249254) of a graph can find the inliers and effectively prune the outliers.[^o5] The maximum clique based outlier removal method is also shown to be quite useful in real-world point set registration problems.[^o32] Similar outlier removal ideas were also proposed by Parra *et al.*.[^o45]

#### M-estimation {#M-estimation}

[M-estimation](https://en.wikipedia.org/wiki/M-estimation) replaces the least squares objective function in ((cb.2)) with a robust cost function that is less sensitive to outliers. Formally, M-estimation seeks to solve the following problem:

::: {#o47 .equation cue=numblk name="cb.5"}

$$l^\star, R^\star, t^\star = \arg\min_{l>0, R \in \text{SO}(3), t \in \mathbb{R}^3} \sum_{i=1}^N \rho\left( \frac{1}{\sigma_i} \left\Vert s_i - lRm_i - t \right\Vert_2 \right) \tag{cb.5}$$

:::

where $\rho(\cdot)$ represents the choice of the robust cost function. Note that choosing $\rho(x) = x^2$ recovers the least squares estimation in ((cb.2)). Popular robust cost functions include $\ell_1$-norm loss, [Huber loss](wikipedia://en/26357083),[^o48] Geman-McClure loss[^o49] and [truncated least squares loss](wikipedia://en/18506510).[^o32][^o9][^o5] M-estimation has been one of the most popular paradigms for robust estimation in robotics and computer vision.[^o50][^o51] Because robust objective functions are typically non-convex (*e.g.,* the truncated least squares loss v.s. the least squares loss), algorithms for solving the non-convex M-estimation are typically based on [local optimization](wikipedia://en/52033), where first an initial guess is provided, following by iterative refinements of the transformation to keep decreasing the objective function. Local optimization tends to work well when the initial guess is close to the global minimum, but it is also prone to get stuck in local minima if provided with poor initialization.

#### Graduated non-convexity {#Graduated_non-convexity}

Graduated non-convexity (GNC) is a general-purpose framework for solving non-convex optimization problems without initialization. It has achieved success in early vision and machine learning applications.[^o53][^o54] The key idea behind GNC is to solve the hard non-convex problem by starting from an easy convex problem. Specifically, for a given robust cost function $\rho(\cdot)$, one can construct a surrogate function $\rho_{\mu}(\cdot)$ with a hyper-parameter $\mu$, tuning which can gradually increase the non-convexity of the surrogate function $\rho_{\mu}(\cdot)$ until it converges to the target function $\rho(\cdot)$.[^o54][^o55] Therefore, at each level of the hyper-parameter $\mu$, the following optimization is solved:

::: {#o56 .equation cue=numblk name="cb.6"}

$$l_{\mu}^\star, R_{\mu}^\star, t_{\mu}^\star = \arg\min_{l>0, R \in \text{SO}(3), t \in \mathbb{R}^3} \sum_{i=1}^N \rho_{\mu}\left( \frac{1}{\sigma_i} \left\Vert s_i - l Rm_i - t \right\Vert_2 \right) \tag{cb.6}$$

:::

Black and Rangarajan proved that the objective function of each optimization ((cb.6)) can be dualized into a sum of [weighted least squares](wikipedia://en/2407860) and a so-called outlier process function on the weights that determine the confidence of the optimization in each pair of measurements.[^o53] Using Black-Rangarajan duality and GNC tailored for the Geman-McClure function, Zhou *et al.* developed the fast global registration algorithm that is robust against about $80\%$ outliers in the correspondences.[^o49] More recently, Yang *et al.* showed that the joint use of GNC (tailored to the Geman-McClure function and the truncated least squares function) and Black-Rangarajan duality can lead to a general-purpose solver for robust registration problems, including point clouds and mesh registration.[^o55]

#### Certifiably robust registration {#Certifiably_robust_registration}

Almost none of the robust registration algorithms mentioned above (except the BnB algorithm that runs in exponential-time in the worst case) comes with **performance guarantees**, which means that these algorithms can return completely incorrect estimates without notice. Therefore, these algorithms are undesirable for safety-critical applications like autonomous driving.

Very recently, Yang *et al.* has developed the first certifiably robust registration algorithm, named *Truncated least squares Estimation And SEmidefinite Relaxation* (TEASER).[^o32] For point cloud registration, TEASER not only outputs an estimate of the transformation, but also quantifies the optimality of the given estimate. TEASER adopts the following truncated least squares (TLS) estimator:

::: {#o58 .equation cue=numblk name="cb.7"}

$$l^\star, R^\star, t^\star = \arg\min_{l >0, R \in \text{SO}(3), t \in \mathbb{R}^3} \sum_{i=1}^N \min \left( \frac{1}{\sigma_i^2} \left\Vert s_i - l Rm_i - t \right\Vert_2^2, \bar{c}^2 \right) \tag{cb.7}$$

:::

which is obtained by choosing the TLS robust cost function $\rho(x) = \min (x^2, \bar{c}^2)$, where $\bar{c}^2$is a pre-defined constant that determines the maximum allowed residuals to be considered inliers. The TLS objective function has the property that for inlier correspondences ($\Vert s_i - l Rm_i - t \Vert_2^2 / \sigma_i^2 < \bar{c}^2$), the usual least square penalty is applied; while for outlier correspondences ($\Vert s_i - l Rm_i - t \Vert_2^2 / \sigma_i^2 > \bar{c}^2$), no penalty is applied and the outliers are discarded. If the TLS optimization ((cb.7)) is solved to global optimality, then it is equivalent to running Horn's method on only the inlier correspondences.

However, solving ((cb.7)) is quite challenging due to its combinatorial nature. TEASER solves ((cb.7)) as follows : (i) It builds invariant measurements such that the estimation of scale, rotation and translation can be decoupled and solved separately, a strategy that is inspired by the original Horn's method; (ii) The same TLS estimation is applied for each of the three sub-problems, where the scale TLS problem can be solved exactly using an algorithm called adaptive voting, the rotation TLS problem can relaxed to a [semidefinite program](wikipedia://en/4993539) (SDP) where the relaxation is exact in practice,[^o9] even with large amount of outliers; the translation TLS problem can solved using component-wise adaptive voting. A fast implementation leveraging GNC is [open-sourced here](https://github.com/MIT-SPARK/TEASER-plusplus). In practice, TEASER can tolerate more than $99\%$ outlier correspondences and runs in milliseconds.

In addition to developing TEASER, Yang *et al.* also prove that, under some mild conditions on the point cloud data, TEASER's estimated transformation has bounded errors from the ground-truth transformation.[^o32]

## Simultaneous pose and correspondence registration {#Simultaneous_pose_and_correspondence_registration}

### Iterative closest point {#Iterative_closest_point}

The [iterative closest point](https://en.wikipedia.org/wiki/Iterative_closest_point) (ICP) algorithm was introduced by Besl and McKay.[^o61] The algorithm performs rigid registration in an iterative fashion by alternating in (i) given the transformation, finding [the closest point](https://en.wikipedia.org/wiki/Nearest_neighbor_search) in $\mathcal{S}$ for every point in $\mathcal{M}$; and (ii) given the correspondences, finding the best rigid transformation by solving the [least squares](wikipedia://en/82359) problem ((cb.2)). As such, it works best if the initial pose of $\mathcal{M}$ is sufficiently close to $\mathcal{S}$. In [pseudocode](https://en.wikipedia.org/wiki/Pseudocode), the basic algorithm is implemented as follows:

**algorithm** ICP(*M*, *S*) *θ* := *θ*<sub>0</sub> **while not** registered:

*X* := ∅ **for** *m*<sub>*i*</sub> ∊ *T*(*M*, *θ*): *ŝ*<sub>*i*</sub> := closest point in *S* to *m*<sub>*i*</sub> *X* := *X* + ⟨*m*<sub>*i*</sub>, *ŝ*<sub>*i*</sub>⟩

*θ* := least\_squares(*X*) **return** *θ*

Here, the function `least_squares` performs [least squares](wikipedia://en/82359) optimization to minimize the distance in each of the $\langle m_i, \hat{s}_i \rangle$ pairs, using the closed-form solutions by Horn[^o28] and Arun.[^o29]

Because the [cost function](wikipedia://en/442137) of registration depends on finding the closest point in $\mathcal{S}$ to every point in $\mathcal{M}$, it can change as the algorithm is running. As such, it is difficult to prove that ICP will in fact converge exactly to the local optimum.[^o72] In fact, empirically, ICP and [EM-ICP](https://en.wikipedia.org/wiki/EM-ICP) do not converge to the local minimum of the cost function.[^o72] Nonetheless, because ICP is intuitive to understand and straightforward to implement, it remains the most commonly used point set registration algorithm.[^o72] Many variants of ICP have been proposed, affecting all phases of the algorithm from the selection and matching of points to the minimization strategy.[^o82][^o62] For example, the [expectation maximization](https://en.wikipedia.org/wiki/Expectation_maximization) algorithm is applied to the ICP algorithm to form the EM-ICP method, and the [Levenberg-Marquardt algorithm](https://en.wikipedia.org/wiki/Levenberg-Marquardt_algorithm) is applied to the ICP algorithm to form the [LM-ICP](https://en.wikipedia.org/wiki/LM-ICP) method.[^o20]

### Robust point matching {#Robust_point_matching}

Robust point matching (RPM) was introduced by Gold et al.[^o64] The method performs registration using [deterministic annealing](https://en.wikipedia.org/wiki/Deterministic_annealing) and soft assignment of correspondences between point sets. Whereas in ICP the correspondence generated by the nearest-neighbour heuristic is binary, RPM uses a *soft* correspondence where the correspondence between any two points can be anywhere from 0 to 1, although it ultimately converges to either 0 or 1. The correspondences found in RPM is always one-to-one, which is not always the case in ICP.[^o70] Let $m_i$ be the $i$th point in $\mathcal{M}$ and $s_j$ be the $j$th point in $\mathcal{S}$. The *match matrix* $\mathbf{\mu}$ is defined as such:

::: {#o65 .equation cue=numblk name="rpm.1"}

$$\mu_{ij} = \begin{cases} 1 & \text{if point }m_i\text{ corresponds to point }s_j\\ 0 & \text{otherwise} \end{cases} \tag{rpm.1}$$

:::

The problem is then defined as: Given two point sets $\mathcal{M}$ and $\mathcal{S}$ find the [Affine transformation](wikipedia://en/38449) $T$ and the match matrix $\mathbf{\mu}$ that best relates them.[^o64] Knowing the optimal transformation makes it easy to determine the match matrix, and vice versa. However, the RPM algorithm determines both simultaneously. The transformation may be decomposed into a translation vector and a [transformation matrix](wikipedia://en/692458):

$$T(m) = \mathbf{A}m + \mathbf{t}$$

The matrix $\mathbf{A}$ in 2D is composed of four separate parameters $\lbrace a, \theta, b, c\rbrace$, which are scale, rotation, and the vertical and horizontal shear components respectively. The cost function is then:

::: {#o66 .equation cue=numblk name="rpm.2"}

$$\operatorname{cost} = \sum_{j=1}^N \sum_{i=1}^M \mu_{ij} \lVert s_j - \mathbf{t} - \mathbf{A} m_i \rVert^2 + g(\mathbf{A}) - \alpha \sum_{j=1}^N \sum_{i=1}^M \mu_{ij} \tag{rpm.2}$$

:::

subject to $\forall j~\sum_{i=1}^M \mu_{ij} \leq 1$, $\forall i~\sum_{j=1}^N \mu_{ij} \leq 1$, $\forall ij~\mu_{ij} \in \lbrace0, 1\rbrace$. The $\alpha$ term biases the objective towards stronger correlation by decreasing the cost if the match matrix has more ones in it. The function $g(\mathbf{A})$ serves to regularize the Affine transformation by penalizing large values of the scale and shear components:

$$g(\mathbf{A}(a,\theta, b, c)) = \gamma(a^2 + b^2 + c^2)$$

for some regularization parameter $\gamma$.

The RPM method optimizes the cost function using the [Softassign](https://en.wikipedia.org/wiki/Softassign) algorithm. The 1D case will be derived here. Given a set of variables $\lbrace Q_j\rbrace$ where $Q_j\in \mathbb{R}^1$. A variable $\mu_j$ is associated with each $Q_j$ such that $\sum_{j=1}^J \mu_j = 1$. The goal is to find $\mathbf{\mu}$ that maximizes $\sum_{j=1}^J \mu_j Q_j$. This can be formulated as a continuous problem by introducing a control parameter $\beta > 0$. In the [deterministic annealing](https://en.wikipedia.org/wiki/Deterministic_annealing) method, the control parameter $\beta$ is slowly increased as the algorithm runs. Let $\mathbf{\mu}$ be:

::: {#o67 .equation cue=numblk name="rpm.3"}

$$\mu_{\hat{j}} = \frac{\exp{(\beta Q_{\hat{j}})}}{\sum_{j=1}^J \exp{(\beta Q_j)}} \tag{rpm.3}$$

:::

this is known as the [softmax function](wikipedia://en/6152185). As $\beta$ increases, it approaches a binary value as desired in Equation ((rpm.1)). The problem may now be generalized to the 2D case, where instead of maximizing $\sum_{j=1}^J \mu_j Q_j$, the following is maximized:

::: {#o68 .equation cue=numblk name="rpm.4"}

$$E(\mu) = \sum_{j=1}^N \sum_{i=0}^M \mu_{ij} Q_{ij} \tag{rpm.4}$$

:::

where

$$Q_{ij} = -(\lVert s_j - \mathbf{t} - \mathbf{A} m_i \rVert^2 - \alpha) = -\frac{\partial \operatorname{cost}}{\partial \mu_{ij}}$$

This is straightforward, except that now the constraints on $\mu$ are [doubly stochastic matrix](wikipedia://en/2906180) constraints: $\forall j~\sum_{i=1}^M \mu_{ij} = 1$ and $\forall i~\sum_{j=1}^N \mu_{ij} = 1$. As such the denominator from Equation ((rpm.3)) cannot be expressed for the 2D case simply. To satisfy the constraints, it is possible to use a result due to Sinkhorn,[^o64] which states that a doubly stochastic matrix is obtained from any [square matrix](wikipedia://en/166022) with all positive entries by the iterative process of alternating row and column normalizations. Thus the algorithm is written as such:[^o64]

**algorithm RPM2D**$(\mathcal{M}, \mathcal{S})$ $\mathbf{t} := 0$ *a*, *θ* *b*, *c* := 0 *β* := *β*<sub>0</sub> $\hat{\mu}_{ij} := 1 + \epsilon$ **while** *β* \< *β<sub>f</sub>*:

**while** $\mu$ has not converged: *// update correspondence parameters by softassign*

$Q_{ij} := -\frac{\partial \operatorname{cost}}{\partial \mu_{ij}}$ $\mu^0_{ij} := \exp(\beta Q_{ij})$

*// apply Sinkhorn's method*

**while** $\hat{\mu}$ has not converged: *// update $\hat{\mu}$ by normalizing across all rows:* $\hat{\mu}^1_{ij} := \frac{\hat{\mu}^0_{ij}}{\sum_{i=1}^{M+1} \hat{\mu}^0_{ij}}$ *// update $\hat{\mu}$ by normalizing across all columns:* $\hat{\mu}^0_{ij} := \frac{\hat{\mu}^1_{ij}}{\sum_{j=1}^{N+1} \hat{\mu}^1_{ij}}$

*// update pose parameters by coordinate descent* update $\theta$ using analytical solution update $\mathbf{t}$ using analytical solution update $a, b, c$ using [Newton's method](wikipedia://en/22145)

$\beta := \beta_r \beta$ $\gamma := \frac{\gamma}{\beta_r}$

**return** $a, b, c, \theta$ and $\mathbf{t}$

where the deterministic annealing control parameter $\beta$ is initially set to $\beta_0$ and increases by factor $\beta_r$ until it reaches the maximum value $\beta_f$. The summations in the normalization steps sum to $M+1$ and $N+1$ instead of just $M$ and $N$ because the constraints on $\mu$ are inequalities. As such the $M+1$th and $N+1$th elements are [slack variables](wikipedia://en/6002878).

The algorithm can also be extended for point sets in 3D or higher dimensions. The constraints on the correspondence matrix $\mathbf{\mu}$ are the same in the 3D case as in the 2D case. Hence the structure of the algorithm remains unchanged, with the main difference being how the rotation and translation matrices are solved.[^o64]

#### Thin plate spline robust point matching {#Thin_plate_spline_robust_point_matching}

*Image: TPS RPM example.gif.* Animation of 2D non-rigid registration of the green point set $\mathcal{M}$ to the magenta point set $\mathcal{S}$ corrupted with noisy outliers. The size of the blue circles is inversely related to the control parameter $\beta$. The yellow lines indicate correspondence.

The thin plate spline robust point matching (TPS-RPM) algorithm by Chui and Rangarajan augments the RPM method to perform non-rigid registration by parametrizing the transformation as a [thin plate spline](wikipedia://en/8136546).[^o70] However, because the thin plate spline parametrization only exists in three dimensions, the method cannot be extended to problems involving four or more dimensions.

### Kernel correlation {#Kernel_correlation}

The kernel correlation (KC) approach of point set registration was introduced by Tsin and Kanade.[^o72] Compared with ICP, the KC algorithm is more robust against noisy data. Unlike ICP, where, for every model point, only the closest scene point is considered, here every scene point affects every model point.[^o72] As such this is a *multiply-linked* registration algorithm. For some [kernel function](https://en.wikipedia.org/wiki/Kernel_function) $K$, the kernel correlation $KC$ of two points $x_i, x_j$ is defined thus:[^o72]

::: {#o73 .equation cue=numblk name="kc.1"}

$$KC(x_i, x_j) = \int K(x, x_i) \cdot K(x, x_j) dx \tag{kc.1}$$

:::

The [kernel function](wikipedia://en/8771473#In_non-parametric_statistics) $K$ chosen for point set registration is typically symmetric and non-negative kernel, similar to the ones used in the [Parzen window](https://en.wikipedia.org/wiki/Parzen_window) [density estimation](wikipedia://en/554671). The [Gaussian kernel](https://en.wikipedia.org/wiki/Gaussian_kernel) typically used for its simplicity, although other ones like the [Epanechnikov kernel](https://en.wikipedia.org/wiki/Epanechnikov_kernel) and the tricube kernel may be substituted.[^o72] The kernel correlation of an entire point set $\mathcal{\chi}$ is defined as the sum of the kernel correlations of every point in the set to every other point in the set:[^o72]

::: {#o74 .equation cue=numblk name="kc.2"}

$$KC(\mathcal{X}) = \sum_{i\neq j}KC(x_i, x_j) = 2\sum_{i<j}KC(x_i, x_j) \tag{kc.2}$$

:::

The logarithm of KC of a point set is proportional, within a constant factor, to the [information entropy](wikipedia://en/15445). Observe that the KC is a measure of a "compactness" of the point set—trivially, if all points in the point set were at the same location, the KC would evaluate to a large value. The [cost function](wikipedia://en/442137) of the point set registration algorithm for some transformation parameter $\theta$ is defined thus:

::: {#o75 .equation cue=numblk name="kc.3"}

$$\operatorname{cost}(\mathcal{S}, \mathcal{M}, \theta) = -\sum_{m \in \mathcal{M}} \sum_{s \in \mathcal{S}} KC(s, T(m, \theta)) \tag{kc.3}$$

:::

Some algebraic manipulation yields:

::: {#o76 .equation cue=numblk name="kc.4"}

$$KC(\mathcal{S} \cup T(\mathcal{M}, \theta)) = KC(\mathcal{S}) + KC(T(\mathcal{M}, \theta)) - 2 \operatorname{cost}(\mathcal{S}, \mathcal{M}, \theta) \tag{kc.4}$$

:::

The expression is simplified by observing that $KC(\mathcal{S})$ is independent of $\theta$. Furthermore, assuming rigid registration, $KC(T(\mathcal{M}, \theta))$ is invariant when $\theta$ is changed because the Euclidean distance between every pair of points stays the same under [rigid transformation](wikipedia://en/27832980). So the above equation may be rewritten as:

::: {#o77 .equation cue=numblk name="kc.5"}

$$KC(\mathcal{S} \cup T(\mathcal{M}, \theta)) = C - 2 \operatorname{cost}(\mathcal{S}, \mathcal{M}, \theta) \tag{kc.5}$$

:::

The [kernel density estimates](wikipedia://en/2090057) are defined as:

$$P_{\mathcal{M}}(x, \theta) = \frac{1}{M} \sum_{m \in \mathcal{M}} K(x, T(m, \theta))$$

$$P_{\mathcal{S}}(x) = \frac{1}{N} \sum_{s \in \mathcal{S}} K(x, s)$$

The cost function can then be shown to be the correlation of the two kernel density estimates:

::: {#o78 .equation cue=numblk name="kc.6"}

$$\operatorname{cost}(\mathcal{S}, \mathcal{M}, \theta) = -N^2 \int_x P_{\mathcal{M}}\cdot P_{\mathcal{S}} ~ dx \tag{kc.6}$$

:::

Having established the [cost function](wikipedia://en/442137), the algorithm simply uses [gradient descent](wikipedia://en/201489) to find the optimal transformation. It is computationally expensive to compute the cost function from scratch on every iteration, so a discrete version of the cost function Equation ((kc.6)) is used. The kernel density estimates $P_{\mathcal{M}}, P_{\mathcal{S}}$ can be evaluated at grid points and stored in a [lookup table](https://en.wikipedia.org/wiki/Lookup_table). Unlike the ICP and related methods, it is not necessary to find the nearest neighbour, which allows the KC algorithm to be comparatively simple in implementation.

Compared to ICP and EM-ICP for noisy 2D and 3D point sets, the KC algorithm is less sensitive to noise and results in correct registration more often.[^o72]

#### Gaussian mixture model {#Gaussian_mixture_model}

The kernel density estimates are sums of Gaussians and may therefore be represented as [Gaussian mixture models](https://en.wikipedia.org/wiki/Gaussian_mixture_model) (GMM).[^o80] Jian and Vemuri use the GMM version of the KC registration algorithm to perform non-rigid registration parametrized by [thin plate splines](wikipedia://en/8136546).

### Coherent point drift {#Coherent_point_drift}

*Image: Cpd fish rigid.gif.* Rigid (with the addition of scaling) registration of a blue point set $\mathcal{M}$ to the red point set $\mathcal{S}$ using the Coherent Point Drift algorithm. Both point sets have been corrupted with removed points and random spurious outlier points.

*Image: Cpd fish affine.gif.* Affine registration of a blue point set $\mathcal{M}$ to the red point set $\mathcal{S}$ using the Coherent Point Drift algorithm.

*Image: Cpd fish nonrigid.gif.* Non-rigid registration of a blue point set $\mathcal{M}$ to the red point set $\mathcal{S}$ using the Coherent Point Drift algorithm. Both point sets have been corrupted with removed points and random spurious outlier points.

Coherent point drift (CPD) was introduced by Myronenko and Song.[^o82][^o83] The algorithm takes a probabilistic approach to aligning point sets, similar to the GMM KC method. Unlike earlier approaches to non-rigid registration which assume a [thin plate spline](wikipedia://en/8136546) transformation model, CPD is agnostic with regard to the transformation model used. The point set $\mathcal{M}$ represents the [Gaussian mixture model](https://en.wikipedia.org/wiki/Gaussian_mixture_model) (GMM) centroids. When the two point sets are optimally aligned, the correspondence is the maximum of the GMM [posterior probability](wikipedia://en/357672) for a given data point. To preserve the topological structure of the point sets, the GMM centroids are forced to move coherently as a group. The [expectation maximization](https://en.wikipedia.org/wiki/Expectation_maximization) algorithm is used to optimize the cost function.[^o82]

Let there be $M$ points in $\mathcal{M}$ and $N$ points in $\mathcal{S}$. The GMM [probability density function](wikipedia://en/43487) for a point $s$ is:

::: {#o84 .equation cue=numblk name="cpd.1"}

$$p(s) = \sum_{i=1}^{M+1} P(i) p(s|i) \tag{cpd.1}$$

:::

where, in $D$ dimensions, $p(s|i)$ is the [Gaussian distribution](https://en.wikipedia.org/wiki/Gaussian_distribution) centered on point $m_i \in \mathcal{M}$.

$$p(s|i) = \frac{1}{(2\pi \sigma^2)^{D/2}} \exp{\left(-\frac{\lVert s - m_i \rVert^2}{2\sigma^2}\right)}$$

The membership probabilities $P(i)=\frac{1}{M}$ is equal for all GMM components. The weight of the uniform distribution is denoted as $w\in[0,1]$. The mixture model is then:

::: {#o85 .equation cue=numblk name="cpd.2"}

$$p(s) = w \frac{1}{N} + (1-w) \sum_{i=1}^M \frac{1}{M} p(s|i) \tag{cpd.2}$$

:::

The GMM centroids are re-parametrized by a set of parameters $\theta$ estimated by maximizing the likelihood. This is equivalent to minimizing the negative [log-likelihood function](wikipedia://en/44968#Log-likelihood):

::: {#o86 .equation cue=numblk name="cpd.3"}

$$E(\theta, \sigma^2) = -\sum_{j=1}^N \log \sum_{i=1}^{M+1} P(i)p(s|i) \tag{cpd.3}$$

:::

where it is assumed that the data is [independent and identically distributed](https://en.wikipedia.org/wiki/Independent_and_identically_distributed). The correspondence probability between two points $m_i$ and $s_j$ is defined as the [posterior probability](wikipedia://en/357672) of the GMM centroid given the data point:

$$P(i|s_j) = \frac{P(i)p(s_j|i)}{p(s_j)}$$

The [expectation maximization](https://en.wikipedia.org/wiki/Expectation_maximization) (EM) algorithm is used to find $\theta$ and $\sigma^2$. The EM algorithm consists of two steps. First, in the E-step or *estimation* step, it guesses the values of parameters ("old" parameter values) and then uses [Bayes' theorem](wikipedia://en/49569) to compute the posterior probability distributions $P^{\text{old}}(i,s_j)$ of mixture components. Second, in the M-step or *maximization* step, the "new" parameter values are then found by minimizing the expectation of the complete negative log-likelihood function, i.e. the cost function:

::: {#o87 .equation cue=numblk name="cpd.4"}

$$\operatorname{cost}=-\sum_{j=1}^N \sum_{i=1}^{M+1} P^{\text{old}}(i|s_j) \log(P^{\text{new}}(i) p^{\text{new}}(s_j|i)) \tag{cpd.4}$$

:::

Ignoring constants independent of $\theta$ and $\sigma$, Equation ((cpd.4)) can be expressed thus:

::: {#o88 .equation cue=numblk name="cpd.5"}

$$\operatorname{cost}(\theta, \sigma^2)=\frac{1}{2\sigma^2} \sum_{j=1}^N \sum_{i=1}^{M+1} P^{\text{old}}(i|s_j) \lVert s_j - T(m_i,\theta) \rVert^2 + \frac{N_\mathbf{P}D}{2}\log{\sigma^2} \tag{cpd.5}$$

:::

where

$$N_\mathbf{P} = \sum_{j=0}^N \sum_{i=0}^M P^{\text{old}}(i|s_j) \leq N$$

with $N=N_\mathbf{P}$ only if $w=0$. The posterior probabilities of GMM components computed using previous parameter values $P^{\text{old}}$ is:

::: {#o89 .equation cue=numblk name="cpd.6"}

$$P^{\text{old}}(i|s_j) = \frac {\exp \left( -\frac{1}{2\sigma^{\text{old}2}} \lVert s_j - T(m_i, \theta^{\text{old}})\rVert^2 \right) } {\sum_{k=1}^{M} \exp \left( -\frac{1}{2\sigma^{\text{old}2}} \lVert s_j - T(m_k, \theta^{\text{old}})\rVert^2 \right) + (2\pi \sigma^2)^\frac{D}{2} \frac{w}{1-w} \frac{M}{N}} \tag{cpd.6}$$

:::

Minimizing the cost function in Equation ((cpd.5)) necessarily decreases the negative log-likelihood function $E$ in Equation ((cpd.3)) unless it is already at a local minimum.[^o82] Thus, the algorithm can be expressed using the following pseudocode, where the point sets $\mathcal{M}$ and $\mathcal{S}$ are represented as $M\times D$ and $N\times D$ matrices $\mathbf{M}$ and $\mathbf{S}$ respectively:[^o82]

**algorithm CPD**$(\mathcal{M}, \mathcal{S})$ *θ* := *θ*<sub>0</sub> initialize 0 ≤ *w* ≤ 1 $\sigma^2 := \frac{1}{DNM}\sum_{j=1}^N \sum_{i=1}^M \lVert s_j - m_i \rVert^2$

**while** not registered: *// E-step, compute $\mathbf{P}$*

**for** *i* ∊ \[1, *M*\] and *j* ∊ \[1, *N*\]: $p_{ij} := \frac {\exp \left( -\frac{1}{2\sigma^2} \lVert s_j - T(m_i, \theta)\rVert^2 \right)} {\sum_{k=1}^{M} \exp \left( -\frac{1}{2\sigma^2} \lVert s_j - T(m_k, \theta)\rVert^2 \right) + (2\pi \sigma^2)^\frac{D}{2} \frac{w}{1-w} \frac{M}{N}}$

*// M-step, solve for optimal transformation*

{*θ*, *σ*<sup>2</sup>} := **solve**(**S**, **M**, **P**)

**return** *θ*

where the vector $\mathbf{1}$ is a column vector of ones. The `'''solve'''` function differs by the type of registration performed. For example, in rigid registration, the output is a scale $a$, a rotation matrix $\mathbf{R}$, and a translation vector $\mathbf{t}$. The parameter $\theta$ can be written as a tuple of these:

$$\theta = \lbrace a, \mathbf{R}, \mathbf{t}\rbrace$$

which is initialized to one, the [identity matrix](wikipedia://en/59718), and a column vector of zeroes:

$$\theta_0 = \lbrace 1, \mathbf{I}, \mathbf{0}\rbrace$$

The aligned point set is:

$$T(\mathbf{M}) = a\mathbf{M}\mathbf{R}^T + \mathbf{1}\mathbf{t}^T$$

The `'''solve_rigid'''` function for rigid registration can then be written as follows, with derivation of the algebra explained in Myronenko's 2010 paper.[^o82]

**solve\_rigid**(**S**, **M**, **P**) *N*<sub>**P**</sub> := **1**<sup>T</sup>**P1** $\mu_s:=\frac{1}{N_\mathbf{P}}\mathbf{S}^T\mathbf{P}^T\mathbf{1}$ $\mu_m:=\frac{1}{N_\mathbf{P}}\mathbf{M}^T\mathbf{P}\mathbf{1}$ $\hat{\mathbf{S}}:=\mathbf{S} - \mathbf{1}\mu_s^T$ $\hat{\mathbf{M}}:=\mathbf{M} - \mathbf{1}\mu_m^T$ $\mathbf{A}:=\hat{\mathbf{S}^T}\mathbf{P}^T\hat{\mathbf{M}}$ **U**, **V** := **svd**(**A**) *// the [singular value decomposition](wikipedia://en/142207) of* **A** = **UΣV**<sup>T</sup> **C** := diag(1, …, 1, det(**UV**<sup>T</sup>)) *//* diag(*ξ*)*is the [diagonal matrix](wikipedia://en/174080) formed from vector ξ* **R** := **UCV**<sup>T</sup> $a := \frac{\operatorname{tr}(\mathbf{A}^T\mathbf{R})}{\operatorname{tr}(\mathbf{\hat{\mathbf{M}}^T \operatorname{diag}(\mathbf{P}\mathbf{1})\hat{\mathbf{M}}})}$ *//* $\operatorname{tr}$ *is the [trace](wikipedia://en/43270) of a matrix* **t** := *μ*<sub>*s*</sub> − *a***R***μ*<sub>*m*</sub> $\sigma^2:=\frac{1}{N_\mathbf{P} D}(\operatorname{tr}(\mathbf{\hat{\mathbf{S}}^T \operatorname{diag}(\mathbf{P}^T\mathbf{1})\hat{\mathbf{S}}})-a\operatorname{tr}(\mathbf{A}^T\mathbf{R}))$ **return** {*a*, **R**, **t**}, *σ*<sup>2</sup>

For affine registration, where the goal is to find an [affine transformation](wikipedia://en/38449) instead of a rigid one, the output is an affine transformation matrix $\mathbf{B}$ and a translation $\mathbf{t}$ such that the aligned point set is:

$$T(\mathbf{M}) = \mathbf{M}\mathbf{B}^T + \mathbf{1}\mathbf{t}^T$$

The `'''solve_affine'''` function for rigid registration can then be written as follows, with derivation of the algebra explained in Myronenko's 2010 paper.[^o82]

**solve\_affine**(**S**, **M**, **P**) *N*<sub>**P**</sub> := **1**<sup>T</sup>**P1** $\mu_s := \frac{1}{N_\mathbf{P}}\mathbf{S}^T\mathbf{P}^T\mathbf{1}$ $\mu_m := \frac{1}{N_\mathbf{P}}\mathbf{M}^T\mathbf{P}\mathbf{1}$ $\hat{\mathbf{S}} := \mathbf{S} - \mathbf{1}\mu_s^T$ $\hat{\mathbf{M}} := \mathbf{M} - \mathbf{1}\mu_m^T$ $\mathbf{B} := (\hat{\mathbf{S} }^T\mathbf{P}^T\hat{\mathbf{M} })(\hat{\mathbf{M} }^T\operatorname{diag}(\mathbf{P}\mathbf{1})\hat{\mathbf{M} })^{-1}$ **t** := *μ*<sub>*s*</sub> − **B***μ*<sub>*m*</sub> $\sigma^2 := \frac{1}{N_\mathbf{P} D}(\operatorname{tr}(\hat{\mathbf{S} }^T \operatorname{diag}(\mathbf{P}^T\mathbf{1})\hat{\mathbf{S} })-\operatorname{tr}(\hat{\mathbf{S} }^T\mathbf{P}^T\hat{\mathbf{M} }\mathbf{B}^T))$ **return** {**B**, **t**}, *σ*<sup>2</sup>

It is also possible to use CPD with non-rigid registration using a parametrization derived using [calculus of variations](wikipedia://en/171882).[^o82]

Sums of Gaussian distributions can be computed in [linear time](https://en.wikipedia.org/wiki/Linear_time) using the [fast Gauss transform](https://en.wikipedia.org/wiki/Fast_Gauss_transform) (FGT).[^o82] Consequently, the [time complexity](wikipedia://en/405944) of CPD is $O(M+N)$, which is asymptotically much faster than $O(MN)$ methods.[^o82]

#### Bayesian coherent point drift (BCPD) {#Bayesian_coherent_point_drift_(BCPD)}

A variant of coherent point drift, called Bayesian coherent point drift (BCPD), was derived through a Bayesian formulation of point set registration. [^o91] BCPD has several advantages over CPD, e.g., (1) nonrigid and rigid registrations can be performed in a single algorithm, (2) the algorithm can be accelerated regardless of the Gaussianity of a Gram matrix to define motion coherence, (3) the algorithm is more robust against outliers because of a more reasonable definition of an outlier distribution. Additionally, in the Bayesian formulation, motion coherence was introduced through a prior distribution of displacement vectors, providing a clear difference between tuning parameters that control motion coherence. BCPD was further accelerated by a method called BCPD++, which is a three-step procedure composed of (1) downsampling of point sets, (2) registration of downsampled point sets, and (3) interpolation of a deformation field. [^o92] The method can register point sets composed of more than 10M points while maintaining its registration accuracy.

#### Coherent point drift with local surface geometry (LSG-CPD) {#Coherent_point_drift_with_local_surface_geometry_(LSG-CPD)}

An variant of coherent point drift called CPD with Local Surface Geometry (LSG-CPD) for rigid point cloud registration.[^o94] The method adaptively adds different levels of point-to-plane penalization on top of the point-to-point penalization based on the flatness of the local surface. This results in GMM components with anisotropic covariances, instead of the isotropic covariances in the original CPD.[^o82] The anisotropic covariance matrix is modeled as:

::: {#o95 .equation cue=numblk name="lsg-cpd.1"}

$$\Sigma_m^{-1}=\frac{1}{\sigma^2}\left(\alpha_m \mathbf{n}_m \mathbf{n}_m^T+\mathbf{I}\right) \tag{lsg-cpd.1}$$

:::

where

::: {#o96 .equation cue=numblk name="lsg-cpd.2"}

$$\alpha_m=\frac{1-\exp\left(\lambda\left(3-\frac{1}{\kappa_m}\right)\right)}{1+\exp\left(\lambda\left(3-\frac{1}{\kappa_m}\right)\right)}\alpha_{max} \tag{lsg-cpd.2}$$

:::

$\Sigma_m$ is the anisotropic covariance matrix of the m-th point in the target set; $\mathbf{n}_m$ is the normal vector corresponding to the same point; $\mathbf{I}$ is an identity matrix, serving as a regularizer, pulling the problem away from ill-posedness. $\alpha_m$ is penalization coefficient (a modified sigmoid function), which is set adaptively to add different levels of point-to-plane penalization depending on how flat the local surface is. This is realized by evaluating the surface variation $\kappa_m$[^o97] within the neighborhood of the m-th target point. $\alpha_{max}$ is the upper bound of the penalization.

The point cloud registration is formulated as a maximum likelihood estimation (MLE) problem and solve it with the Expectation-Maximization (EM) algorithm. In the E step, the correspondence computation is recast into simple matrix manipulations and efficiently computed on a GPU. In the M step, an unconstrained optimization on a matrix Lie group is designed to efficiently update the rigid transformation of the registration. Taking advantage of the local geometric covariances, the method shows a superior performance in accuracy and robustness to noise and outliers, compared with the baseline CPD.[^o98] An enhanced runtime performance is expected thanks to the GPU accelerated correspondence calculation. An implementation of the LSG-CPD is [open-sourced here](https://github.com/ChirikjianLab/LSG-CPD).

### Sorting the Correspondence Space (SCS) {#Sorting_the_Correspondence_Space_(SCS)}

This algorithm was introduced in 2013 by H. Assalih to accommodate sonar image registration.[^o100] These types of images tend to have high amounts of noise, so it is expected to have many outliers in the point sets to match. SCS delivers high robustness against outliers and can surpass ICP and CPD performance in the presence of outliers. SCS doesn't use iterative optimization in high dimensional space and is neither probabilistic nor spectral. SCS can match rigid and non-rigid transformations, and performs best when the target transformation is between three and six [degrees of freedom](wikipedia://en/176622).
