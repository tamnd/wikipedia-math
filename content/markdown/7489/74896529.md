# ISO/IEC 19790

::: {#o1 .subject cue=lead name="ISO/IEC 19790"}

**ISO/IEC 19790** is an [ISO/IEC](https://en.wikipedia.org/wiki/ISO/IEC) standard for security requirements for [cryptographic modules](wikipedia://en/5161053). It addresses a wide range of issues regarding their implementation, including specifications, interface definitions, authentication, operational and physical security, configuration management, testing, and life-cycle management.[^o2] The first version of ISO/IEC 19790 was derived from the U.S. government computer security standard [FIPS 140-2](wikipedia://en/885948), *Security Requirements for Cryptographic Modules*.[^o3]

:::

, the current version of the standard is ISO/IEC 19790:2025[^o4] that replaced the previous versions, ISO/IEC 19790:2012[^o5] and ISO/IEC 19790:2006,[^o6] which are now obsolete.

Use of ISO/IEC 19790 is referenced in the U.S. government standard [FIPS 140-3](wikipedia://en/25191344).[^o7] Unlike most ISO/IEC standards, access to it does not require payment, and it is available for free on the ISO website.[^o4]

ISO/IEC 24759 is a related standard for the testing of cryptographic modules,[^o8] the first version of which derived from NIST's *Derived Test Requirements for FIPS PUB 140-2, Security Requirements for Cryptographic Modules*.[^o3]
