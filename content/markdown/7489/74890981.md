# Kreiss matrix theorem

::: {#o1 .subject cue=lead name="Kreiss matrix theorem"}

In [matrix analysis](wikipedia://en/40956141), **Kreiss matrix theorem** relates the so-called Kreiss constant of a matrix with the power iterates of this matrix. It was originally introduced by [Heinz-Otto Kreiss](wikipedia://en/2070195) to analyze the stability of [finite difference methods](https://en.wikipedia.org/wiki/Finite_difference_methods) for [partial difference equations](https://en.wikipedia.org/wiki/Partial_difference_equation).[^o2][^o3]

:::

## Kreiss constant of a matrix {#Kreiss_constant_of_a_matrix}

Given a matrix *A*, the **Kreiss constant** 𝒦(*A*) (with respect to the closed unit circle) of *A* is defined as[^o5]

$$\mathcal{K}(\mathbf{A})=\sup _{|z|>1}(|z|-1)\left\|(z-\mathbf{A})^{-1}\right\|,$$

while the Kreiss constant 𝒦${}_{\operatorname{lhp}}$(*A*) with respect to the left-half plane is given by[^o5]

$$\mathcal{K}_{\textrm{lhp}}(\mathbf{A})=\sup _{\Re(z)>0}(\Re(z))\left\|(z-\mathbf{A})^{-1}\right\|.$$

::: {#o7 .statement kind=statement/fact cue=heading name="Properties"}

### Properties {#Properties}

- For any matrix *A*, one has that 𝒦(*A*) ≥ 1 and 𝒦${}_{\operatorname{lhp}}$(*A*) ≥ 1. In particular, 𝒦(*A*) (resp. 𝒦${}_{\operatorname{lhp}}$(*A*)) are finite only if the matrix *A* is [Schur stable](wikipedia://en/2057699#Schur_matrix) (resp. [Hurwitz stable](wikipedia://en/78291990)).
- Kreiss constant can be interpreted as a measure of [normality](wikipedia://en/170366) of a matrix.[^o8] In particular, for normal matrices *A* with [spectral radius](wikipedia://en/386169) less than 1, one has that 𝒦(*A*) = 1. Similarly, for normal matrices *A* that are [Hurwitz stable](wikipedia://en/78291990), 𝒦${}_{\operatorname{lhp}}$(*A*) = 1.
- 𝒦(*A*) and 𝒦${}_{\operatorname{lhp}}$(*A*) have alternative definitions through the [pseudospectrum](wikipedia://en/3528170) Λ${}_{\varepsilon}$(A):[^o9]
  - $\mathcal{K}(A)=\sup _{\varepsilon>0} \frac{\rho_{\varepsilon}(A)-1}{\varepsilon}$ , where *p*${}_{\varepsilon}$(A) = max{$|$*λ*| : *λ* ∈ Λ${}_{\varepsilon}$(*A*)},
  - $\mathcal{K}_{\textrm{lhp}}(A)=\sup _{\varepsilon>0} \frac{\alpha_{\varepsilon}(A)}{\varepsilon}$, where *α*${}_{\varepsilon}$(A) = max{Re|*λ*| : *λ* ∈ Λ${}_{\varepsilon}$(*A*)}.
- 𝒦${}_{\operatorname{lhp}}$(*A*) can be computed through [robust control](wikipedia://en/3282143) methods.[^o10]

:::

::: {#o12 .statement cue=heading name="Statement of Kreiss matrix theorem"}

## Statement of Kreiss matrix theorem {#Statement_of_Kreiss_matrix_theorem}

Let *A* be a square matrix of order *n* and *e* be the [Euler's number](wikipedia://en/9633). The modern and sharp version of Kreiss matrix theorem states that the inequality below is tight[^o5][^o13]

$$\mathcal{K}(\mathbf{A}) \leq \sup_{k \geq 0}\left\|\mathbf{A}^k\right\| \leq e\, n\, \mathcal{K}(\mathbf{A}),$$

and it follows from the application of [Spijker's lemma](https://en.wikipedia.org/wiki/Spijker's_lemma).[^o14]

There also exists an analogous result in terms of the Kreiss constant with respect to the left-half plane and the matrix exponential:[^o5][^o15]

$$\mathcal{K}_{\mathrm{lhp}}(\mathbf{A}) \leq \sup _{t \geq 0}\left\|\mathrm{e}^{t \mathbf{A}}\right\| \leq e \, n \, \mathcal{K}_{\mathrm{lhp}}(\mathbf{A})$$

:::

## Consequences and applications {#Consequences_and_applications}

The value $\sup_{k \geq 0}\left\|\mathbf{A}^k\right\|$ (respectively, $\sup _{t \geq 0}\left\|\mathrm{e}^{t \mathbf{A}}\right\|$) can be interpreted as the *maximum transient growth* of the [discrete-time system](https://en.wikipedia.org/wiki/Discrete-time_system) $x_{k+1}=A x_k$ (respectively, continuous-time system $\dot{x}=A x$).

Thus, the Kreiss matrix theorem gives both upper and lower bounds on the transient behavior of the system with dynamics given by the matrix *A*: a large (and finite) Kreiss constant indicates that the system will have an accentuated transient phase before decaying to zero.[^o9][^o10]
