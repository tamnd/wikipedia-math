# Grafana

::: {#o4 .subject cue=lead name="Grafana"}

**Grafana** is an open-source [analytics and visualization](https://en.wikipedia.org/wiki/Data_visualization) [web application](https://en.wikipedia.org/wiki/Web_application). It connects to [time series databases](https://en.wikipedia.org/wiki/Time_series_database) and other data sources, allowing users to build dashboards that display metrics, logs, and traces. Grafana supports data sources including [Prometheus](https://en.wikipedia.org/wiki/Prometheus_%28software%29), [AWS CloudWatch](https://en.wikipedia.org/wiki/Amazon_Elastic_Compute_Cloud#Amazon_CloudWatch), [Graphite](https://en.wikipedia.org/wiki/Graphite_%28software%29), [InfluxDB](https://en.wikipedia.org/wiki/InfluxDB), [Elasticsearch](https://en.wikipedia.org/wiki/Elasticsearch), [PostgreSQL](https://en.wikipedia.org/wiki/PostgreSQL), and [MySQL](https://en.wikipedia.org/wiki/MySQL).[^o5]

:::

Torkel Ödegaard released Grafana in January 2014 as an outgrowth of work on [Graphite](https://en.wikipedia.org/wiki/Graphite_%28software%29) at [Orbitz](https://en.wikipedia.org/wiki/Orbitz). The user interface was originally based on version 3 of [Kibana](https://en.wikipedia.org/wiki/Kibana).[^o6] The company behind the project, initially named Raintank, rebranded as Grafana Labs and has raised over \$500 million in venture capital funding, reaching a \$6 billion valuation in 2024.[^o7]

Since 2021, Grafana has been licensed under the [AGPLv3](https://en.wikipedia.org/wiki/GNU_Affero_General_Public_License) (previously [Apache 2.0](https://en.wikipedia.org/wiki/Apache_License)).[^o3] Grafana Labs provides two commercial Grafana offerings: Grafana Cloud for managed deployments and Grafana Enterprise for self-managed environments.

Grafana Cloud provides hosted Grafana, managed telemetry services, and additional capabilities such as Adaptive Telemetry for telemetry optimization and Grafana Assistant for AI-assisted observability workflows.[^o8] Grafana Enterprise contains features including LDAP team synchronization, data source permissions, and reporting.[^o9]

## History {#History}

Grafana was first released in January 2014, initially targeting Graphite and InfluxDB as data sources. It later added support for relational databases including MySQL, PostgreSQL, and [Microsoft SQL Server](https://en.wikipedia.org/wiki/Microsoft_SQL_Server).[^o11]

Grafana Labs was founded in 2014 as Raintank and later adopted the name, Grafana, which combines Graphite and Kibana.[^o12] The company raised \$24 million in Series A funding in 2019,[^o13] \$50 million in Series B in 2020,[^o14] \$220 million in Series C in 2021 (at a \$3 billion valuation),[^o15] and \$270 million in 2024 at a \$6 billion valuation.[^o7]

Grafana Labs has acquired several companies to expand its observability stack: Kausal (2018),[^o16] [k6](https://en.wikipedia.org/wiki/K6_%28software%29) (2021, load testing),[^o17] Pace (2021, developer tooling),[^o18] Amixr (2021, incident response),[^o19] Pyroscope (2023, continuous profiling),[^o20] Asserts.ai (2023, AI-assisted observability),[^o21] TailCtrl (2024, trace sampling), [^o22] and LogLine (2026, log querying).[^o23]

## Architecture {#Architecture}

Grafana's backend is written in [Go](https://en.wikipedia.org/wiki/Go_%28programming_language%29) and its frontend in [TypeScript](https://en.wikipedia.org/wiki/TypeScript) using [React](https://en.wikipedia.org/wiki/React_%28JavaScript_library%29).[^o2] The application runs as a single binary that serves a web interface and connects to external data sources through a plugin system. Plugins fall into three categories: data source plugins (for querying backends), panel plugins (for visualization types), and app plugins (for bundled functionality).[^o9]

Grafana does not store the metrics, logs, or traces it visualizes; it queries external data sources when a dashboard is rendered and can combine results from several sources in a single panel. It maintains its own relational database (SQLite by default, or MySQL or PostgreSQL) for dashboards, users, annotations and alert state.[^o25] Core data sources shipped with Grafana include [Prometheus](https://en.wikipedia.org/wiki/Prometheus_%28software%29), [Graphite](https://en.wikipedia.org/wiki/Graphite_%28software%29), [InfluxDB](https://en.wikipedia.org/wiki/InfluxDB) and OpenTSDB for metrics; Loki and Elasticsearch for logs; Tempo, Jaeger and Zipkin for traces; Pyroscope and Parca for profiles; and [MySQL](https://en.wikipedia.org/wiki/MySQL), PostgreSQL and Microsoft SQL Server. Other backends, including [OpenSearch](https://en.wikipedia.org/wiki/OpenSearch_%28software%29) and [Splunk](wikipedia://en/19135734), are available as separately installed plugins.

Dashboards are defined as JSON documents and can be provisioned from files, version-controlled, and shared via Grafana's public dashboard library. Alerting rules can be defined against any data source, with notifications routed to email, [Slack](https://en.wikipedia.org/wiki/Slack_%28software%29), [PagerDuty](https://en.wikipedia.org/wiki/PagerDuty), and other channels.[^o9]

## LGTM Stack {#LGTM_Stack}

Grafana Labs develops a set of open-source backends that are often deployed together as the "LGTM Stack" (Loki, Grafana, Tempo, Mimir):[^o27]

- **Loki:** A horizontally scalable, highly available, multi-tenant log aggregation system inspired by Prometheus.[^o28] Loki indexes metadata rather than the full text of the log lines. The Loki project started at Grafana Labs in 2018 and is released under the AGPLv3 license.[^o29]
- **Mimir:** A horizontally scalable, highly available, multi-tenant time-series database for long-term storage of Prometheus metrics. The Mimir project was announced by Grafana Labs in 2022 as a replacement for Cortex and is released under the AGPLv3 license.[^o30]
- **Tempo:** A high-scale distributed tracing database that requires only object storage to operate and does not index trace data. Tempo can ingest common open source tracing protocols, including Jaeger, Zipkin and OpenTelemetry. The Tempo project was announced by Grafana Labs in 2020 and is released under the AGPLv3 license.[^o31]
- **Pyroscope:** A highly available, multi-tenant continuous profiling database for storing and querying profiling data at scale. Pyroscope integrates natively with Grafana to correlate profiles with metrics, logs and traces. The Pyroscope project was announced by Grafana Labs in 2023 and is released under the AGPLv3 license.[^o32]

## Other open source projects {#Other_open_source_projects}

In addition to the LGTM Stack, Grafana Labs, has developed additional open-source projects:

- **Alloy:** A vendor-neutral distribution of the OpenTelemetry Collector, offering native pipelines for OpenTelemetry, Prometheus, Loki, Tempo, and Pyroscope telemetry formats to collect metrics, logs, traces, and profiles. Alloy replaced Grafana Agent, which entered long-term support in 2024 and reached end-of-life in November 2025. The Alloy project was announced by Grafana Labs at GrafanaCON in 2024 and is released under the Apache 2.0 license.[^o34]
- **Beyla:** An eBPF-based automatic instrumentation tool that captures RED (rate, error, duration) metrics and trace spans for Linux HTTP/S and gRPC services without modifying application code. Beyla supports applications written in Go, C/C++, Rust, Python, Ruby, Java, Node.js, and .NET. The Beyla project was started at Grafana Labs and announced in 2023.[^o35] It was donated to the OpenTelemetry project in 2025 as OpenTelemetry eBPF Instrumentation, [^o36] and is released under the Apache 2.0 license.
- **Faro:** A web SDK for real user monitoring (RUM) that instruments browser-based frontend applications to capture performance metrics, logs, exceptions, user events, and traces. Faro data can be correlated with backend and infrastructure telemetry in the LGTM stack for full-stack observability. The Faro project was announced by Grafana Labs in 2022 and is released under the Apache 2.0 license.[^o37][^o38]
- **[k6](https://en.wikipedia.org/wiki/K6_%28software%29):** Load and performance testing tool that uses test scripts written in JavaScript or TypeScript to help identify and fix performance issues before they reach production. The k6 project was started in 2016 as LoadImpact and was acquired by Grafana Labs in 2021, and is released under the AGPLv3 license.[^o39]

## Adoption {#Adoption}

Grafana is used by [Wikimedia](https://en.wikipedia.org/wiki/Wikimedia)'s infrastructure,[^o41] [NASA](https://en.wikipedia.org/wiki/NASA) and the [Tour de France](https://en.wikipedia.org/wiki/Tour_de_France) (for real-time race telemetry).[^o42] As of 2026, Grafana Labs has more than 10,000 paying customers, [^o43] including [Nvidia](https://en.wikipedia.org/wiki/Nvidia), [Anthropic](https://en.wikipedia.org/wiki/Anthropic) and [Uber](https://en.wikipedia.org/wiki/Uber).[^o42]
