# Robbins' theorem

Robbins' theorem in graph theory

::: {#o1 .subject cue=lead name="Robbins' theorem"}

In [graph theory](wikipedia://en/12401), **Robbins' theorem**, named after (txt), states that the graphs that have [strong orientations](wikipedia://en/16678715) are exactly the [2-edge-connected graphs](https://en.wikipedia.org/wiki/K-edge-connected_graph). That is, it is possible to choose a direction for each edge of an [undirected graph](https://en.wikipedia.org/wiki/Undirected_graph) $G$, turning it into a [directed graph](wikipedia://en/19721986) that has a path from every vertex to every other vertex, if and only if $G$ is [connected](https://en.wikipedia.org/wiki/Connected_graph) and has no [bridge](wikipedia://en/1305071).

:::

## Orientable graphs {#Orientable_graphs}

*Image: Ear decomposition.png.* An [ear decomposition](wikipedia://en/32183016) of a bridgeless graph. Orienting each ear as a directed path or a directed cycle makes the whole graph strongly connected.

Robbins' characterization of the graphs with strong orientations may be proven using [ear decomposition](wikipedia://en/32183016), a tool introduced by Robbins for this task.

If a graph has a bridge, then it cannot be strongly orientable, for no matter which orientation is chosen for the bridge there will be no path from one of the two endpoints of the bridge to the other.

In the other direction, it is necessary to show that every connected bridgeless graph can be strongly oriented. As Robbins proved, every such graph has a partition into a sequence of subgraphs called "ears", in which the first subgraph in the sequence is a cycle and each subsequent subgraph is a path, with the two path endpoints both belonging to earlier ears in the sequence. (The two path endpoints may be equal, in which case the subgraph is a cycle.) Orienting the edges within each ear so that it forms a directed cycle or a directed path leads to a strongly connected orientation of the overall graph.[^o4]

## Related results {#Related_results}

An extension of Robbins' theorem to [mixed graphs](wikipedia://en/38713429) by (Boesch Tindell 1980) shows that, if $G$ is a graph in which some edges may be directed and others undirected, and $G$ contains a path respecting the edge orientations from every vertex to every other vertex, then any undirected edge of $G$ that is not a bridge may be made directed without changing the connectivity of $G$. In particular, a bridgeless undirected graph may be made into a strongly connected directed graph by a [greedy algorithm](wikipedia://en/89247) that directs edges one at a time while preserving the existence of paths between every pair of vertices; it is impossible for such an algorithm to get stuck in a situation in which no additional orientation decisions can be made.

:::

## Algorithms and complexity {#Algorithms_and_complexity}

A strong orientation of a given bridgeless undirected graph may be found in [linear time](https://en.wikipedia.org/wiki/Linear_time) by performing a [depth-first search](wikipedia://en/97034) of the graph, orienting all edges in the depth-first search tree away from the tree root, and orienting all the remaining edges (which must necessarily connect an ancestor and a descendant in the depth-first search tree) from the descendant to the ancestor.[^o9] Although this algorithm is not suitable for [parallel computers](https://en.wikipedia.org/wiki/Parallel_computer), due to the difficulty of performing depth-first search on them, alternative algorithms are available that solve the problem efficiently in the parallel model.[^o10] Parallel algorithms are also known for finding strongly connected orientations of mixed graphs.[^o11]

## Applications {#Applications}

Robbins originally motivated his work by an application to the design of one-way streets in cities. Another application arises in [structural rigidity](wikipedia://en/23547165), in the theory of [grid bracing](https://en.wikipedia.org/wiki/Grid_bracing). This theory concerns the problem of making a square grid, constructed from rigid rods attached at flexible joints, rigid by adding more rods or wires as [cross bracing](https://en.wikipedia.org/wiki/Cross_bracing) on the diagonals of the grid. A set of added rods makes the grid rigid if an associated undirected graph is connected, and is doubly braced (remaining rigid if any edge is removed) if in addition it is bridgeless. Analogously, a set of added wires (which can bend to reduce the distance between the points they connect, but cannot expand) makes the grid rigid if an associated directed graph is strongly connected.[^n1] Therefore, reinterpreting Robbins' theorem for this application, the doubly braced structures are exactly the structures whose rods can be replaced by wires while remaining rigid.

:::
