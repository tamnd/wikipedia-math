# Deal.II

::: {#o2 .subject cue=lead name="Deal.II"}

**deal.II** is a free, [open-source](https://en.wikipedia.org/wiki/Open-source_software) library to solve [partial differential equations](wikipedia://en/52564) using the [finite element method](wikipedia://en/18233581).[^o3][^o4] The current release is version 9.8, released in August 2026.[^o5] The founding authors of the project — Wolfgang Bangerth, Ralf Hartmann, and Guido Kanschat — won the 2007 [J. H. Wilkinson Prize for Numerical Software](https://en.wikipedia.org/wiki/J._H._Wilkinson_Prize_for_Numerical_Software) for deal.II.[^o6] The library's then-developers also won the 2025 SIAM/ACM Computational Science and Engineering Prize. Today, it is a worldwide project managed by around a dozen "Principal Developers";[^o7] over the years several hundred people have contributed substantial pieces of code or documentation to the project.

:::

## Features {#Features}

The library features

- dimension independent programming using [C++ templates](https://en.wikipedia.org/wiki/Template_%28C++%29) on [locally adapted meshes](wikipedia://en/1822182),
- a large collection of different finite elements of any order: continuous and discontinuous Lagrange elements, Nedelec elements, Raviart-Thomas elements, and combinations,
- parallelization using multithreading through [TBB](https://en.wikipedia.org/wiki/Threading_Building_Blocks) and massively parallel using [MPI](https://en.wikipedia.org/wiki/Message_Passing_Interface). deal.II has been shown to scale to at least 16,000 processors[^o9] and has been used in applications on up to 300,000 processor cores.
- [multigrid method](wikipedia://en/1747763) with local smoothing on adaptively refined meshes[^o10][^o11]
- [hp-FEM](wikipedia://en/19719776)
- extensive documentation and tutorial programs,
- interfaces to several libraries including [Gmsh](wikipedia://en/24126101), [PETSc](https://en.wikipedia.org/wiki/PETSc), [Trilinos](https://en.wikipedia.org/wiki/Trilinos), [METIS](https://en.wikipedia.org/wiki/METIS), [SUNDIALS](https://en.wikipedia.org/wiki/SUNDIALS), [VTK](https://en.wikipedia.org/wiki/VTK), [p4est](https://en.wikipedia.org/wiki/P4est), [BLAS](https://en.wikipedia.org/wiki/BLAS), [LAPACK](wikipedia://en/1013768), [HDF5](https://en.wikipedia.org/wiki/HDF5), [NetCDF](https://en.wikipedia.org/wiki/NetCDF), and [Open Cascade Technology](https://en.wikipedia.org/wiki/Open_Cascade_Technology).

## History and impact {#History_and_impact}

The software started from work at the Numerical Methods Group at [Heidelberg University](https://en.wikipedia.org/wiki/Heidelberg_University) in Germany in 1998. The first public release was version 3.0.0 in 2000. Since then deal.II has gotten contributions from several hundred authors and has been used in more than 2,400 research publications.[^o13]

In March 2025, the principal developers of the project received the SIAM/ACM Prize in Computational Science and Engineering for their "highly impactful library supporting finite element calculations. The software achieved a very high standard of software quality and modularity by providing packaged algorithms and data structures in a comprehensive and well-documented manner that enables and elevates whole communities to achieve more computationally advanced models than they could possibly otherwise."[^o14]

The primary maintainers, coordinating the worldwide development of the library, are today located at [Colorado State University](https://en.wikipedia.org/wiki/Colorado_State_University), [Clemson University](https://en.wikipedia.org/wiki/Clemson_University), [Texas A&M University](https://en.wikipedia.org/wiki/Texas_A&M_University), [Oak Ridge National Laboratory](https://en.wikipedia.org/wiki/Oak_Ridge_National_Laboratory) and a number of other institutions.[^o15] It is developed as a worldwide community of contributors through [GitHub](https://en.wikipedia.org/wiki/GitHub)[^o16] that incorporates several hundred changes by dozens of authors every month.
