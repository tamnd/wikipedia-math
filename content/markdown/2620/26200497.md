# TC (complexity)

::: {#o1 .subject cue=lead name="TC"}

In [theoretical computer science](wikipedia://en/323392), and specifically [computational complexity theory](wikipedia://en/7543) and [circuit complexity](wikipedia://en/7641969), **TC** (Threshold Circuit) is a [complexity class](wikipedia://en/502426) of [decision problems](wikipedia://en/8336) that can be recognized by threshold circuits, which are [Boolean circuits](wikipedia://en/7087423) with [AND](https://en.wikipedia.org/wiki/AND_gate), [OR](https://en.wikipedia.org/wiki/OR_gate), and [Majority gates](https://en.wikipedia.org/wiki/Majority_gate), or equivalently, [threshold gates](https://en.wikipedia.org/wiki/Threshold_Logic_Unit). For each fixed *i*, the complexity class **TC<sup>i</sup>** consists of all languages that can be recognized by a family of threshold circuits of depth $O(\log^i n)$, [polynomial](wikipedia://en/23000) size, and unbounded [fan-in](https://en.wikipedia.org/wiki/Fan-in). The class **TC** is defined via

:::

$$\mbox{TC} = \bigcup_{i \geq 0} \mbox{TC}^i.$$

The class was proposed in 1988 to formalize the computational complexity of [artificial neural networks](wikipedia://en/21523).[^o2]

## Relation to NC and AC {#Relation_to_NC_and_AC}

The relationship between the TC, [NC](wikipedia://en/22073) and the [AC](wikipedia://en/7401755) hierarchy can be summarized as follows:

$$\mbox{NC}^i \subseteq \mbox{AC}^i \subseteq \mbox{TC}^i \subseteq \mbox{NC}^{i+1}.$$

In particular, we know that

$$\mbox{NC}^0 \subsetneq \mbox{AC}^0 \subsetneq \mbox{TC}^0 \subseteq \mbox{NC}^{1}.$$

The first strict containment follows from the fact that **NC<sup>0</sup>** cannot compute any function that depends on all the input bits. Thus choosing a problem that is trivially in **AC<sup>0</sup>** and depends on all bits separates the two classes. (For example, consider the OR function.) The strict containment **AC<sup>0</sup>** ⊊ **TC<sup>0</sup>** follows because parity and majority (which are both in **TC<sup>0</sup>**) were shown to be not in **AC<sup>0</sup>**.[^o4][^o5]

As an immediate consequence of the above containments, we have that NC = AC = TC.
