# CIKS-1

::: {#o1 .subject cue=lead name="CIKS-1"}

In [cryptography](wikipedia://en/18934432), **CIKS-1** is a [block cipher](wikipedia://en/4594) designed in 2002 by A.A. Moldovyan and N.A. Moldovyan. Like its predecessor, [Spectr-H64](wikipedia://en/9127502), it relies heavily on [permutations](wikipedia://en/44027) of bits, so is better suited to implementation in hardware than in software.

:::

The algorithm has a [block size](wikipedia://en/294065) of 64 bits. It uses an 8 round structure in which half of the block determines the transformation of the other half in each round, similar to a [Feistel cipher](wikipedia://en/352709) or [RC5](wikipedia://en/102600). In each round the [key](wikipedia://en/53039) also undergoes a transformation dependent on the data. CIKS-1 uses four types of operations: data-dependent permutations, fixed permutations, [XORs](https://en.wikipedia.org/wiki/XOR), and [addition mod 4](wikipedia://en/20087).

The designers of CIKS-1 didn't specify any [key schedule](wikipedia://en/609603) for the cipher, but it uses a total [key size](wikipedia://en/5749) of 256 bits. Kidney, Heys, and Norvell showed that round keys of low [Hamming weight](wikipedia://en/1127884) are relatively [weak](wikipedia://en/719388), so keys should be chosen carefully. The same researchers have also proposed a [differential cryptanalysis](wikipedia://en/8536) of CIKS-1 which uses 2<sup>56</sup> chosen plaintexts.
