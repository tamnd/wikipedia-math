# Graph operations

::: {#o1 .subject cue=lead name="Graph operations"}

In the [mathematical](https://en.wikipedia.org/wiki/Mathematical) field of [graph theory](wikipedia://en/12401), **graph operations** are [operations](wikipedia://en/4140245) which produce new [graphs](wikipedia://en/325806) from initial ones. They include both [unary](wikipedia://en/161006) (one input) and [binary](wikipedia://en/3948) (two input) operations.

:::

## Unary operations {#Unary_operations}

Unary operations create a new graph from a single initial graph.

::: {#o4 .pointer-item cue=pointer name="Elementary graph operation"}

### Elementary operations {#Elementary_operations}

Elementary operations or editing operations, which are also known as graph edit operations, create a new graph from one initial one by a simple local change, such as addition or deletion of a vertex or of an edge, merging and splitting of vertices, [edge contraction](wikipedia://en/3758115), etc. The [graph edit distance](wikipedia://en/49270083) between a pair of graphs is the minimum number of elementary operations required to transform one graph into the other.

:::

### Advanced operations {#Advanced_operations}

Advanced operations create a new graph from an initial one by a complex change, such as:

- [transpose graph](wikipedia://en/5966396);
- [complement graph](wikipedia://en/1175649);
- [line graph](wikipedia://en/675231);
- [graph minor](wikipedia://en/353042);
- [graph rewriting](wikipedia://en/1252846);
- [power of graph](https://en.wikipedia.org/wiki/Power_of_graph);
- [dual graph](wikipedia://en/2536864);
- [medial graph](wikipedia://en/28280731);
- [quotient graph](wikipedia://en/46261775);
- [double graph](wikipedia://en/81397754);
- [simplex graph](wikipedia://en/20752774);
- [YΔ- and ΔY-transformation](wikipedia://en/74743071);
- [Mycielskian](wikipedia://en/7685346).

## Binary operations {#Binary_operations}

Binary operations create a new graph from two initial graphs *G*<sub>1</sub> = (*V*<sub>1</sub>, *E*<sub>1</sub>) and *G*<sub>2</sub> = (*V*<sub>2</sub>, *E*<sub>2</sub>), such as:

- graph union: *G*<sub>1</sub> ∪ *G*<sub>2</sub>. There are two definitions. In the most common one, the [disjoint union of graphs](wikipedia://en/9938459), the union is assumed to be disjoint. Less commonly (though more consistent with the general definition of [union](wikipedia://en/47949) in mathematics) the union of two graphs is defined as the graph (*V*<sub>1</sub> ∪ *V*<sub>2</sub>, *E*<sub>1</sub> ∪ *E*<sub>2</sub>).
- graph intersection: *G*<sub>1</sub> ∩ *G*<sub>2</sub> = (*V*<sub>1</sub> ∩ *V*<sub>2</sub>, *E*<sub>1</sub> ∩ *E*<sub>2</sub>);[^o7]
- [graph join](wikipedia://en/81278692): $G_1 \nabla G_2$. Graph with all the edges that connect the vertices of the first graph with the vertices of the second graph. It is a commutative operation (for unlabelled graphs);[^o8]
- [graph products](https://en.wikipedia.org/wiki/Graph_products) based on the [cartesian product](wikipedia://en/24104095) of the vertex sets:
  - [cartesian graph product](wikipedia://en/2856852): it is a commutative and associative operation (for unlabelled graphs),[^o8]
  - [lexicographic graph product](wikipedia://en/6026731) (or graph composition): it is an associative (for unlabelled graphs) and non-commutative operation,[^o8]
  - [strong graph product](wikipedia://en/11494014): it is a commutative and associative operation (for unlabelled graphs),
  - [tensor graph product](https://en.wikipedia.org/wiki/Tensor_product_of_graphs) (or direct graph product, categorical graph product, cardinal graph product, Kronecker graph product): it is a commutative and associative operation (for unlabelled graphs),
  - [replacement product](wikipedia://en/44734124),
  - [zig-zag graph product](https://en.wikipedia.org/wiki/Zig-zag_product_of_graphs);[^o9]
- graph product based on other products:
  - [rooted graph product](wikipedia://en/1373338): it is an associative operation (for unlabelled but rooted graphs),
  - [corona graph product](https://en.wikipedia.org/wiki/Corona_product_of_graphs): it is a non-commutative operation;[^o10]
- [series–parallel graph composition](wikipedia://en/9938559):
  - parallel graph composition: it is a commutative operation (for unlabelled graphs),
  - series graph composition: it is a non-commutative operation,
  - source graph composition: it is a commutative operation (for unlabelled graphs);
- [Hajós construction](wikipedia://en/32490744).
