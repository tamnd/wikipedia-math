# Sparsely totient number

::: {#o1 .subject cue=lead name="Sparsely totient number"}

In [mathematics](wikipedia://en/18831), specifically [number theory](wikipedia://en/21527), a **sparsely totient number** is a [natural number](wikipedia://en/21474), *n*, such that for all *m* > *n*,

:::

$$\varphi(m)>\varphi(n)$$

where $\varphi$ is [Euler's totient function](wikipedia://en/53452). The first few sparsely totient numbers are:

[2](https://en.wikipedia.org/wiki/2_%28number%29), [6](https://en.wikipedia.org/wiki/6_%28number%29), [12](wikipedia://en/208155), [18](wikipedia://en/208294), [30](wikipedia://en/341668), [42](https://en.wikipedia.org/wiki/42_%28number%29), [60](wikipedia://en/343325), [66](https://en.wikipedia.org/wiki/66_%28number%29), [90](wikipedia://en/343340), [120](https://en.wikipedia.org/wiki/120_%28number%29), [126](https://en.wikipedia.org/wiki/126_%28number%29), [150](https://en.wikipedia.org/wiki/150_%28number%29), [210](https://en.wikipedia.org/wiki/210_%28number%29), [240](https://en.wikipedia.org/wiki/240_%28number%29), [270](https://en.wikipedia.org/wiki/270_%28number%29), [330](https://en.wikipedia.org/wiki/330_%28number%29), [420](wikipedia://en/27033107), 462, 510, 630, 660, 690, 840, 870, 1050, 1260, 1320, 1470, 1680, 1890, 2310, 2730, 2940, 3150, 3570, 3990, 4620, 4830, 5460, 5610, 5670, 6090, 6930, 7140, 7350, 8190, 9240, 9660, 9870, ... .

The concept was introduced by [David Masser](wikipedia://en/2172777) and Peter Man-Kit Shiu in 1986. As they showed, every [primorial](wikipedia://en/422786) is sparsely totient.

::: {#o3 .statement kind=statement/fact cue=heading name="Properties"}

## Properties {#Properties}

- If *P*(*n*) is the largest [prime factor](https://en.wikipedia.org/wiki/Prime_factor) of *n*, then $\liminf P(n)/\log n=1$.
- $P(n)\ll \log^\delta n$ holds for an exponent $\delta=37/20$.
- It is conjectured that $\limsup P(n) / \log n = 2$.
- They are always even because if x is odd, then 2x also has the same Totient function, trivially failing the condition that all numbers more than it has more value of Totient function than it.

:::
