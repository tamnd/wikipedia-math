# Nichols plot

*Image: Nichols plot.svg.* A Nichols plot.

::: {#o1 .subject cue=lead name="Nichols plot"}

The **Nichols plot** is a [plot](wikipedia://en/19774918) used in [signal processing](wikipedia://en/29324) and [control design](wikipedia://en/7039), named after American engineer [Nathaniel B. Nichols](https://en.wikipedia.org/wiki/Nathaniel_B._Nichols).[^o2][^o3][^o4] It plots the [phase response](https://en.wikipedia.org/wiki/Phase_response) versus the response magnitude of a [transfer function](wikipedia://en/31146) for any given frequency, and as such is useful in characterizing a system's [frequency response](wikipedia://en/302033).

:::

## Use in control design {#Use_in_control_design}

Given a [transfer function](wikipedia://en/31146),

$$G(s) = \frac{Y(s)}{X(s)}$$

with the [closed-loop transfer function](wikipedia://en/40885) defined as,

$$M(s) = \frac{G(s)}{1+G(s)}$$

the Nichols plots displays $20 \log_{10}(|G(s)|)$ versus $\arg(G(s))$. Loci of constant $20 \log_{10}(|M(s)|)$ and $\arg(M(s))$ (so-called [Hall circles](https://en.wikipedia.org/wiki/Hall_circles)) are overlaid to allow the designer to obtain the closed loop transfer function directly from the open loop transfer function. Thus, the frequency $\omega$ is the parameter along the curve. This plot may be compared to the [Bode plot](wikipedia://en/155562) in which the two inter-related graphs - $20 \log_{10}(|G(s)|)$ versus $\log_{10}(\omega)$ and $\arg(G(s))$ versus $\log_{10}(\omega)$) - are plotted.

In [feedback control design](https://en.wikipedia.org/wiki/Control_system), the plot is useful for assessing the stability and robustness of a linear system. This application of the Nichols plot is central to the [quantitative feedback theory (QFT)](https://en.wikipedia.org/wiki/Quantitative_feedback_theory) of Horowitz and Sidi, which is a well known method for robust control system design.

In most cases, $\arg(G(s))$ refers to the phase of the system's response. Although similar to a [Nyquist plot](https://en.wikipedia.org/wiki/Nyquist_plot), a Nichols plot is plotted in a [Polar coordinate system](wikipedia://en/25120) while a Nyquist plot is plotted in a [Cartesian coordinate system](wikipedia://en/7706).
