# Glossary of functional analysis

::: {#o1 .subject cue=lead name="Glossary of functional analysis"}

This is a [glossary](https://en.wikipedia.org/wiki/Glossary) for the terminology in a mathematical field of [functional analysis](wikipedia://en/11180).

:::

Throughout the article, unless stated otherwise, the base field of a vector space is the field of real numbers or that of complex numbers. Algebras are not assumed to be unital.

See also: [List of Banach spaces](wikipedia://en/17542489), [glossary of real and complex analysis](wikipedia://en/77414703).

## \* {#*}

::: {#o3 .entry cue=term name="*"}

**\**

[\*-homomorphism](https://en.wikipedia.org/wiki/*-homomorphism) between [involutive Banach algebras](https://en.wikipedia.org/wiki/Involutive_Banach_algebra) is an algebra homomorphism preserving \*.

:::

## A {#A}

::: {#o5 .entry cue=term name="abelian"}

**abelian**

Synonymous with "commutative"; e.g., an abelian Banach algebra means a commutative Banach algebra.

:::

::: {#o6 .entry cue=term name="Anderson–Kadec"}

**Anderson–Kadec**

The [Anderson–Kadec theorem](wikipedia://en/58422881) says a separable infinite-dimensional Fréchet space is isomorphic to $\mathbb{R}^{\mathbb{N}}$.

:::

::: {#o7 .entry cue=term name="Alaoglu"}

**Alaoglu**

[Alaoglu's theorem](https://en.wikipedia.org/wiki/Alaoglu's_theorem) states that the closed unit ball in a normed space is compact in the [weak-\* topology](https://en.wikipedia.org/wiki/Weak-*_topology).

:::

::: {#o8 .entry cue=term name="adjoint"}

**adjoint**

The [adjoint](https://en.wikipedia.org/wiki/Adjoint_operator) of a bounded linear operator $T: H_1 \to H_2$ between Hilbert spaces is the bounded linear operator $T^* : H_2 \to H_1$ such that $\langle Tx, y \rangle = \langle x, T^* y \rangle$ for each $x \in H_1, y \in H_2$.

:::

::: {#o9 .entry cue=term name="approximate identity"}

**approximate identity**

In a not-necessarily-unital Banach algebra, an [approximate identity](wikipedia://en/949628) is a sequence or a net $\{ u_i \}$ of elements such that $u_i x \to x, x u_i \to x$ as $i \to \infty$ for each *x* in the algebra.

:::

::: {#o10 .entry cue=term name="approximation property"}

**approximation property**

A Banach space is said to have the [approximation property](wikipedia://en/628962) if every compact operator is a limit of finite-rank operators.

:::

## B {#B}

::: {#o12 .entry cue=term name="Baire"}

**Baire**

The [Baire category theorem](wikipedia://en/55227) states that a [complete metric space](wikipedia://en/7832) is a [Baire space](wikipedia://en/200550); if $U_i$ is a sequence of open dense subsets, then $\cap_1^{\infty} U_i$ is dense.

:::

::: {#o13 .entry cue=term name="Banach"}

**Banach**

A [Banach space](wikipedia://en/3989) is a normed vector space that is complete as a metric space.

A [Banach algebra](wikipedia://en/4665) is a Banach space that has a structure of a possibly non-unital [associative algebra](wikipedia://en/2112) such that

$\|x y \| \le \|x\| \|y\|$ for every $x, y$ in the algebra.

A [Banach disc](https://en.wikipedia.org/wiki/Banach_disc) is a continuous linear image of a unit ball in a Banach space.

:::

::: {#o14 .entry cue=term name="balanced"}

**balanced**

A subset *S* of a vector space over real or complex numbers is [balanced](https://en.wikipedia.org/wiki/Balanced_subset) if $\lambda S \subset S$ for every scalar $\lambda$ of length at most one.

:::

::: {#o15 .entry cue=term name="barrel"}

**barrel**

A [barrel](wikipedia://en/1733629) in a topological vector space is a subset that is closed, convex, balanced and absorbing.

A topological vector space is [barrelled](wikipedia://en/1733592) if every barrel is a neighborhood of zero (that is, contains an open neighborhood of zero).

:::

::: {#o16 .entry cue=term name="Bessel"}

**Bessel**

[Bessel's inequality](wikipedia://en/1446277) states: given an orthonormal set *S* and a vector *x* in a Hilbert space,

$\sum_{u \in S} |\langle x, u \rangle|^2 \le \|x\|^2$,[^o88] where the equality holds if and only if *S* is an orthonormal basis; i.e., maximal orthonormal set.

:::

::: {#o17 .entry cue=term name="bipolar"}

**bipolar**

[bipolar theorem](wikipedia://en/35128576).

:::

::: {#o18 .entry cue=term name="bounded"}

**bounded**

A [bounded operator](wikipedia://en/455961) is a linear operator between Banach spaces for which the image of the unit ball is bounded.

:::

::: {#o19 .entry cue=term name="bornological"}

**bornological**

A [bornological space](wikipedia://en/1804457).

:::

::: {#o20 .entry cue=term name="Birkhoff orthogonality"}

**Birkhoff orthogonality**

Two vectors *x* and *y* in a [normed linear space](https://en.wikipedia.org/wiki/Normed_linear_space) are said to be **Birkhoff orthogonal** if $\| x + \lambda y \| \ge \|x\|$ for all scalars λ. If the normed linear space is a Hilbert space, then it is equivalent to the usual orthogonality.

:::

::: {#o21 .entry cue=term name="Borel"}

**Borel**

[Borel functional calculus](wikipedia://en/876294)

:::

## C {#C}

::: {#o23 .entry cue=term name="c"}

**c**

[c space](wikipedia://en/17543372).

:::

::: {#o24 .entry cue=term name="Calkin"}

**Calkin**

The [Calkin algebra](wikipedia://en/945565) on a Hilbert space is the quotient of the algebra of all bounded operators on the Hilbert space by the ideal generated by compact operators.

:::

::: {#o25 .entry cue=term name="Cauchy–Schwarz inequality"}

**Cauchy–Schwarz inequality**

The [Cauchy–Schwarz inequality](wikipedia://en/38128) states: for each pair of vectors $x, y$ in an inner-product space,

$$|\langle x, y \rangle| \le \|x\| \|y\|.$$

:::

::: {#o26 .entry cue=term name="Centraliser"}

**Centraliser**

The centraliser of an algebra A on which a weight w is defined is the subset K of A such that for a, b in K, w(ab)=w(ba), finite - i.e. w behaves like a trace on K.

:::

::: {#o27 .entry cue=term name="Centre"}

**Centre**

The centre Z of an algebra A is the subset of A which elements commute with all elements of A.

:::

::: {#o28 .entry cue=term name="Closed"}

**Closed**

The [closed graph theorem](wikipedia://en/497834) states that a linear operator between Banach spaces is continuous (bounded) if and only if it has closed graph.

A [closed operator](https://en.wikipedia.org/wiki/Closed_operator) is a linear operator whose graph is closed.

The [closed range theorem](wikipedia://en/23483982) says that a densely defined closed operator has closed image (range) if and only if the transpose of it has closed image.

:::

::: {#o29 .entry cue=term name="Commutant"}

**Commutant**

The commutant of a subset *S* of an algebra A is the subalgebra of the elements of A commuting with each element of *S* and is denoted by $S'$.

The [von Neumann double commutant theorem](https://en.wikipedia.org/wiki/Von_Neumann_double_commutant_theorem) states that a nondegenerate \*-algebra $\mathfrak{M}$ of operators on a Hilbert space is a von Neumann algebra (i.e. is closed in the weak operator topology) if and only if $\mathfrak{M}'' = \mathfrak{M}$. Taking the double commutant is often a convenient way to build a weak closure - but one has to be explicit on the complete algebra A that is considered in the procedure.

:::

::: {#o30 .entry cue=term name="Compact"}

**Compact**

A [compact operator](wikipedia://en/577441) is a linear operator between Banach spaces for which the image of the unit ball is precompact.

:::

::: {#o31 .entry cue=term name="Connes"}

**Connes**

[Connes fusion](https://en.wikipedia.org/wiki/Connes_fusion).

:::

::: {#o32 .entry cue=term name="C*"}

**C\**

A [C\*-algebra](wikipedia://en/7184) is an involutive Banach algebra satisfying $\|x^* x\| = \|x^*\| \|x\|$. It is closed in the operator norm topology. Von Neumann algebras that are closed in the weak operator topology are particular C\*-algebras.

:::

::: {#o33 .entry cue=term name="Convex"}

**Convex**

A [locally convex space](https://en.wikipedia.org/wiki/Locally_convex_space) is a topological vector space whose topology is generated by convex subsets.

:::

::: {#o34 .entry cue=term name="Cyclic"}

**Cyclic**

Given a representation $(\pi, V)$ of a Banach algebra $A$, a [cyclic vector](wikipedia://en/58713633) is a vector $v \in V$ such that $\pi(A)v$ is dense in $V$.

:::

**dual**

The [algebraic dual](https://en.wikipedia.org/wiki/Algebraic_dual) of a topological vector space is the dual vector space of the underlying vector space.

## F {#F}

::: {#o45 .entry cue=term name="factor"}

**factor**

A [factor](https://en.wikipedia.org/wiki/Factor_%28functional_analysis%29) is a von Neumann algebra with trivial center.

:::

::: {#o46 .entry cue=term name="faithful"}

**faithful**

A linear functional $\omega$ on an involutive algebra is [faithful](https://en.wikipedia.org/wiki/Faithful_linear_functional) if $\omega(x^*x) \ne 0$ for each nonzero element $x$ in the algebra.

:::

::: {#o47 .entry cue=term name="Fréchet"}

**Fréchet**

A [Fréchet space](wikipedia://en/233801) is a topological vector space whose topology is given by a countable family of seminorms (which makes it a metric space) and that is complete as a metric space.

:::

::: {#o48 .entry cue=term name="Fredholm"}

**Fredholm**

A [Fredholm operator](wikipedia://en/279722) is a bounded operator such that it has closed range and the kernels of the operator and the adjoint have finite-dimension.

:::

## G {#G}

::: {#o50 .entry cue=term name="Gelfand"}

**Gelfand**

The [Gelfand–Mazur theorem](wikipedia://en/9129699) states that a Banach algebra that is a division ring is the field of complex numbers.

The [Gelfand representation](wikipedia://en/364372) of a commutative Banach algebra $A$ with spectrum $\Omega(A)$ is the algebra homomorphism $F: A \to C_0(\Omega(A))$, where $C_0(X)$ denotes the algebra of continuous functions on $X$ vanishing at infinity, that is given by $F(x)(\omega) = \omega(x)$. It is a \*-preserving isometric isomorphism if $A$ is a commutative C\*-algebra.

:::

::: {#o51 .entry cue=term name="Grothendieck"}

**Grothendieck**

[Grothendieck's inequality](https://en.wikipedia.org/wiki/Grothendieck's_inequality).

[Grothendieck's factorization theorem](https://en.wikipedia.org/wiki/Grothendieck's_factorization_theorem).

:::

## H {#H}

::: {#o53 .entry cue=term name="Hahn–Banach"}

**Hahn–Banach**

The [Hahn–Banach theorem](wikipedia://en/13860) states: given a linear functional $\ell$ on a subspace of a complex vector space *V*, if the absolute value of $\ell$ is bounded above by a seminorm on *V*, then it extends to a linear functional on *V* still bounded by the seminorm. Geometrically, it is a generalization of the [hyperplane separation theorem](wikipedia://en/4739827).

:::

::: {#o54 .entry cue=term name="Heine"}

**Heine**

A topological vector space is said to have the [Heine–Borel property](https://en.wikipedia.org/wiki/Heine–Borel_property) if every closed and bounded subset is compact. Riesz's lemma says a Banach space with the Heine–Borel property must be finite-dimensional.

:::

::: {#o55 .entry cue=term name="Hilbert"}

**Hilbert**

A [Hilbert space](wikipedia://en/20598932) is an inner product space that is complete as a metric space.

In the [Tomita–Takesaki theory](wikipedia://en/2898625), a (left or right) Hilbert algebra is a certain algebra with an involution.

:::

::: {#o56 .entry cue=term name="Hilbert–Schmidt"}

**Hilbert–Schmidt**

The [Hilbert–Schmidt norm](https://en.wikipedia.org/wiki/Hilbert–Schmidt_norm) of a bounded operator $T$ on a Hilbert space is $\sum_i \|T e_i \|^2$ where $\{ e_i \}$ is an orthonormal basis of the Hilbert space.

A [Hilbert–Schmidt operator](wikipedia://en/976673) is a bounded operator with finite Hilbert–Schmidt norm.

:::

## I {#I}

::: {#o58 .entry cue=term name="index"}

**index**

The index of a Fredholm operator $T : H_1 \to H_2$ is the integer $\operatorname{dim}(\operatorname{ker}(T^*)) - \operatorname{dim}(\operatorname{ker}(T))$.

The [Atiyah–Singer index theorem](wikipedia://en/324752).

:::

::: {#o59 .entry cue=term name="index group"}

**index group**

The [index group](wikipedia://en/10474727) of a unital Banach algebra is the quotient group $G(A)/G_0(A)$ where $G(A)$ is the unit group of *A* and $G_0(A)$ the identity component of the group.

:::

::: {#o60 .entry cue=term name="infra-barrelled"}

**infra-barrelled**

[infra-barrelled](https://en.wikipedia.org/wiki/Infra-barrelled)

:::

::: {#o61 .entry cue=term name="inner product"}

**inner product**

An [inner product](https://en.wikipedia.org/wiki/Inner_product) on a real or complex vector space $V$ is a function $\langle \cdot, \cdot \rangle : V \times V \to \mathbb{R}$ such that for each $v, w \in V$, (1) $x \mapsto \langle x, v \rangle$ is linear and (2) $\langle v, w \rangle = \overline{\langle w, v\rangle}$ where the bar means complex conjugate.

An [inner product space](wikipedia://en/14856) is a vector space equipped with an inner product.

:::

::: {#o62 .entry cue=term name="involution"}

**involution**

An [involution](wikipedia://en/293450) of a Banach algebra *A* is an isometric endomorphism $A \to A, \, x \mapsto x^*$ that is conjugate-linear and such that $(xy)^* = (yx)^*$.

An [involutive Banach algebra](https://en.wikipedia.org/wiki/Involutive_Banach_algebra) is a Banach algebra equipped with an involution.

:::

::: {#o63 .entry cue=term name="isometry"}

**isometry**

A [linear isometry](https://en.wikipedia.org/wiki/Linear_isometry) between normed vector spaces is a linear map preserving norm.

:::

## N {#N}

::: {#o76 .entry cue=term name="nondegenerate"}

**nondegenerate**

A representation $(\pi, V)$ of an algebra $A$ is said to be nondegenerate if for each vector $v \in V$, there is an element $a \in A$ such that $\pi(a) v \ne 0$.

:::

::: {#o77 .entry cue=term name="noncommutative"}

**noncommutative**

[noncommutative integration](https://en.wikipedia.org/wiki/Noncommutative_integration)

[noncommutative torus](wikipedia://en/37990843)

:::

::: {#o78 .entry cue=term name="norm"}

**norm**

A [norm](wikipedia://en/990534) on a vector space *X* is a real-valued function $\| \cdot \| : X \to \mathbb{R}$ such that for each scalar $a$ and vectors $x, y$ in $X$, (1) $\| ax\| = |a| \| x \|$, (2) (triangular inequality) $\| x + y \| \le \| x \| + \| y \|$ and (3) $\| x \| \ge 0$ where the equality holds only for $x = 0$.

A [normed vector space](wikipedia://en/21538) is a real or complex vector space equipped with a norm $\| \cdot \|$. It is a metric space with the distance function $d(x, y) = \| x - y \|$.

:::

::: {#o79 .entry cue=term name="normal"}

**normal**

An operator is [normal](wikipedia://en/190167) if it and its adjoint commute.

:::

::: {#o80 .entry cue=term name="nuclear"}

## O {#O}

::: {#o82 .entry cue=term name="one"}

**one**

A [one parameter group](https://en.wikipedia.org/wiki/One_parameter_group) of a unital Banach algebra *A* is a continuous group homomorphism from $(\mathbb{R}, +)$ to the unit group of *A*.

:::

::: {#o83 .entry cue=term name="open"}

**open**

The [open mapping theorem](wikipedia://en/17395276) says a surjective continuous linear operator between Banach spaces is an open mapping.

:::

::: {#o84 .entry cue=term name="orthonormal"}

**orthonormal**

A subset *S* of a Hilbert space is [orthonormal](https://en.wikipedia.org/wiki/Orthonormal) if, for each *u*, *v* in the set, $\langle u, v \rangle$ = 0 when $u \ne v$ and $= 1$ when $u = v$.

An [orthonormal basis](wikipedia://en/195063) is a maximal orthonormal set (note: it is \*not\* necessarily a vector space basis.)

:::

::: {#o85 .entry cue=term name="orthogonal"}

**orthogonal**

Given a Hilbert space *H* and a closed subspace *M*, the [orthogonal complement](wikipedia://en/1058833) of *M* is the closed subspace $M^{\bot} = \{ x \in H | \langle x, y \rangle = 0, y \in M \}$.

In the notations above, the [orthogonal projection](https://en.wikipedia.org/wiki/Orthogonal_projection) $P$ onto *M* is a (unique) bounded operator on *H* such that $P^2 = P, P^* = P, \operatorname{im}(P) = M, \operatorname{ker}(P) = M^{\bot}.$

:::

## P {#P}

::: {#o87 .entry cue=term name="Parseval"}

**Parseval**

[Parseval's identity](wikipedia://en/418615) states: given an orthonormal basis *S* in a Hilbert space, $\| x \|^2 = \sum_{u \in S} |\langle x, u \rangle|^2$.[^o88]

:::

::: {#o89 .entry cue=term name="positive"}

**positive**

A linear functional $\omega$ on an involutive Banach algebra is said to be [positive](wikipedia://en/454930) if $\omega(x^* x) \ge 0$ for each element $x$ in the algebra.

:::

**projection**

::: {#o105 .entry cue=term name="self-adjoint"}

**self-adjoint**

A [self-adjoint operator](wikipedia://en/187408) is a bounded operator whose adjoint is itself. More generally, a closed densely defined operator is called self-adjoint if it coincides with the adjoint including the domain.

:::

::: {#o106 .entry cue=term name="semi-reflexive"}

**semi-reflexive**

A locally convex space is called [semi-reflexive space](https://en.wikipedia.org/wiki/Semi-reflexive) if the canonical map to the second continuous dual is surjective.

:::

::: {#o107 .entry cue=term name="separable"}

**separable**

A [separable Hilbert space](https://en.wikipedia.org/wiki/Separable_Hilbert_space) is a Hilbert space admitting a finite or countable orthonormal basis.

:::

::: {#o108 .entry cue=term name="spectrum"}

**spectrum**

The spectrum of an element *x* of a unital Banach algebra is the set of complex numbers $\lambda$ such that $x - \lambda$ is not invertible.

The [spectrum of a commutative Banach algebra](https://en.wikipedia.org/wiki/Spectrum_of_a_commutative_Banach_algebra) is the set of all characters (a homomorphism to $\mathbb{C}$) on the algebra.

:::

::: {#o109 .entry cue=term name="spectral"}

**spectral**

The [spectral radius](wikipedia://en/386169) of an element *x* of a unital Banach algebra is $\sup_{\lambda} |\lambda|$ where the sup is over the spectrum of *x*.

The [spectral mapping theorem](https://en.wikipedia.org/wiki/Spectral_mapping_theorem) states: if *x* is an element of a unital Banach algebra and *f* is a holomorphic function in a neighborhood of the spectrum $\sigma(x)$ of *x*, then $f(\sigma(x)) = \sigma(f(x))$, where $f(x)$ is an element of the Banach algebra defined via the [Cauchy's integral formula](wikipedia://en/72827).

:::

::: {#o110 .entry cue=term name="state"}

**state**

A [state](wikipedia://en/454959) is a positive linear functional of norm one.

:::

::: {#o111 .entry cue=term name="Stone"}

**Stone**

[Stone lemma](https://en.wikipedia.org/wiki/Stone_lemma).

:::

::: {#o112 .entry cue=term name="symmetric"}

**symmetric**

A linear operator *T* on a pre-Hilbert space is [symmetric](https://en.wikipedia.org/wiki/Symmetric_operator) if $(Tx, y) = (x, Ty).$

:::

## T {#T}

::: {#o114 .entry cue=term name="tensor product"}

**tensor product**

See [topological tensor product](wikipedia://en/2702982). Note it is still somewhat of an open problem to define or work out a correct tensor product of topological vector spaces, including Banach spaces.

A [projective tensor product](wikipedia://en/63566617).

:::

::: {#o115 .entry cue=term name="topological"}

**topological**

A [topological vector space](wikipedia://en/45752) is a vector space equipped with a [topology](https://en.wikipedia.org/wiki/Topology_%28mathematics%29) such that (1) the topology is [Hausdorff](https://en.wikipedia.org/wiki/Hausdorff_topology) and (2) the addition $(x, y) \mapsto x + y$ as well as scalar multiplication $(\lambda, x) \mapsto \lambda x$ are continuous.

A linear map $f: E \to F$ is called a [topological homomorphism](wikipedia://en/63987005) if $f : E \to \operatorname{im}(f)$ is an open mapping.

A sequence $\cdots \to E_{n -1} \to E_n \to E_{n+1} \to \cdots$ is called [topologically exact](https://en.wikipedia.org/wiki/Topologically_exact) if it is an [exact sequence](wikipedia://en/138215) on the underlying vector spaces and, moreover, each $E_n \to E_{n+1}$ is a topological homomorphism.

:::

**unbounded operator**

An [unbounded operator](wikipedia://en/1422584) is a partially defined linear operator, usually defined on a dense subspace.

:::

::: {#o119 .entry cue=term name="uniform boundedness principle"}

**uniform boundedness principle**

The [uniform boundedness principle](wikipedia://en/247392) states: given a set of operators between Banach spaces, if $\sup_T |Tx| < \infty$, sup over the set, for each *x* in the Banach space, then $\sup_T \|T\| < \infty$.

:::

::: {#o120 .entry cue=term name="unitary"}

**unitary**

A [unitary operator](wikipedia://en/225999) between Hilbert spaces is an invertible bounded linear operator such that the inverse is the adjoint of the operator.

Two representations $(\pi_1, H_1), (\pi_2, H_2)$ of an involutive Banach algebra *A* on Hilbert spaces $H_1, H_2$ are said to be [unitarily equivalent](wikipedia://en/292788) if there is a unitary operator $U: H_1 \to H_2$ such that $\pi_2(x) U = U \pi_1(x)$ for each *x* in *A*.

:::
